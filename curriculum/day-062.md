## 3. 新语法（含先修）
- `G0081` **普通形 + くせに / ものの / とはいえ** — 明明…却（责备）／虽然…但是／虽说…然而｜接续：くせに：普通形（な形/名词 用 な／である）；ものの：普通形（书面让步）；とはいえ：名词/普通形＋とはいえ
- `G0082` **普通形 + わりに(は) / N + に しては** — （相较…）却…；按…来说倒是…｜接续：動詞・い形 普通形 / 名詞＋の + わりに；名詞 + にしては；后项是与前项预期不符的评价

## 4. 新汉字（中日差异）
- `K0134` **味** 音:ミ 训:あじ｜中文「味」wèi；日语 味 音读 ミ（意味 いみ）、训读 あじ（味道）；「意味」是「意思」，与「味道」无关，中文易按「味」猜成「滋味」，典型陷阱，不能靠汉字猜。
- `K0135` **由** 音:ユ/ユウ 训:よし｜中文「由」yóu；日语 由 音读 ユ（経由 けいゆ）/ユウ（理由 りゆう）/ユイ，训读 よし（古语，现代罕用）；「理由」是「理由」。【疑点】ユ/ユウ/ユイ 三读随词分布、训读 よし 是否列常用建议二次核实，故标 needs_review；不可按中文 yóu 类推成单一读音。
