# Day 122 · 〜最中に、〜ついでに

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜最中に、〜ついでに」造两句自己的话，表达：正当…的时候；顺便…

## 新词 14

- **植物**（しょくぶつ）植物｜朝鲜语：식물<br>
  例：植物や生き物は持っていませんね？（你没有养植物和动物吧？）
- **食物**（しょくもつ）食物<br>
  例：私はたくさんの食物を持って帰ろう。（我要带很多食物回去。）
- **食欲**（しょくよく）食欲｜朝鲜语：식욕<br>
  例：最近食欲がないんです。（最近没什么食欲。）
- **食料**（しょくりょう）食物；粮食｜朝鲜语：식료<br>
  例：彼らはじゅうぶんな食料を手に入れられなかった。（他们没能弄到足够的食物。）
- **食糧**（しょくりょう）粮食｜朝鲜语：식량<br>
  例：食糧が不足している。（粮食短缺。）
- **書斎**（しょさい）书房｜朝鲜语：서재<br>
  例：このドアは書斎に通じている。（这扇门通向书房。）
- **女子**（じょし）女子；女生｜朝鲜语：여자<br>
  例：この学校は男子よりも女子が多い。（这所学校女生比男生多。）
- **助手**（じょしゅ）助手｜朝鲜语：조수<br>
  例：私は助手を探している。（我正在找助手。）
- **徐々に**（じょじょに）逐渐｜朝鲜语：서서히<br>
  例：単語は徐々に増えますので、こまめにチェックしてください。（单词会逐渐增加，请经常查看。）
- **書物**（しょもつ）书籍<br>
  例：私たちは、書物から楽しみを得ることができる。（我们能从书籍中获得乐趣。）
- **女優**（じょゆう）女演员｜朝鲜语：여우<br>
  例：その女優はせりふを台なしにした。（那个女演员把台词念砸了。）
- **処理**（しょり）处理｜朝鲜语：처리<br>
  例：あなたはあの車をどう処理したのですか？（那辆车你是怎么处理的？）
- **知らせ**（しらせ）通知；消息<br>
  例：その悪い知らせは残念ながら本当だ。（遗憾的是，那个坏消息是真的。）
- **尻**（しり）屁股<br>
  例：彼は女の子の尻ばかり追いかけている。（他老是追着女孩子跑。）

## 语法

- **〜最中に**：正当…的时候
  接续：动词ている + 最中に；名词 + の + 最中に
  朝鲜语：-는 중에（韩语「-는 중에」只表“进行中”；日语「最中に」还隐含“被打断、扫兴”的语感。）
- **〜ついでに**：顺便…
  接续：动词辞书形/た形 + ついでに；名词 + の + ついでに
  朝鲜语：-는 김에（韩语「-는 김에」同样表“顺便”，与「ついでに」对应；但日语可接名词+の，韩语只接动词。）
