## 语法

- **と（并列／共同／引用）**：和…／与…（一起）；「…」地
  接续：名詞 + と + 名詞／動詞；引用从句 + と + 思う/言う
  朝鲜语：와/과 / 하고 / (이)라고（韩语并列用와/과、口语하고，引用用라고且随词性变；日语と一形通用。）
- **から ～ まで**：从…到…
  接续：名詞（时/处） + から + 名詞 + まで
  朝鲜语：부터 ~ 까지（韩语起点用부터、终点까지，与日语基本对应；但韩语时间起点口语可用에，日语から不可省。）
