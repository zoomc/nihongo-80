Day 039 · 〜せる / 〜させる、〜せられる / 〜させられる、〜おう / 〜よう、〜(よ)うと思う

语法 4 条

〜せる / 〜させる
발음〜세루 / 〜사세루
让…做；使…做
五段动词未然形+せる；一段动词未然形+させる；する→させる；来る→来させる
表示使役，可指命令、允许或放任，视上下文而定。
韩语对应-게 하다
-게 하다 可先理解使役意思。日语要留意助词：让学生读课文用 学生に本を読ませる；「让孩子在外面玩」可说 子供を外で遊ばせる。
母は毎日弟に野菜を食べさせる。
母亲每天让弟弟吃蔬菜。
코오치 와 마이니치, 센슈타치 오 하시라세타.
コーチは毎日、選手たちを走らせた。
教练每天让选手们跑步。
息子が行きたいと言ったので、一人で旅行に行かせました。
儿子说想去，我就让他一个人去旅行了。
易错易混点
  • ✗ 母は毎日弟を野菜を食べさせる。✓ 母は毎日弟に野菜を食べさせる。使役对象用 に，不能再用 を 标记同一成分
〜せられる / 〜させられる
발음〜세라레루 / 〜사세라레루
被迫做…
五段词尾变あ段 + せられる（可缩为 される 的词很多，す结尾通常不缩）；一段去 る + させられる；する→させられる；来る→来させられる。
表示不情愿地被迫做某事，含有受害或无奈的语气。
韩语对应-도록 강요받다 / 억지로 …하게 되다
억지로 다시 쓰게 됐다 对照 書き直させられた。「書き直す」是 す 结尾，别按 読む→読まされる 的缩约方式造形。
코도모 노 코로, 하하 니 마이니치피아노 오 렌슈우사세라레타.
子どものころ、母に毎日ピアノを練習させられた。
小时候母亲每天逼我练钢琴。
에키 데 산주뿐 모 마타사레마시타.
駅で三十分も待たされました。
我在车站被迫等了三十分钟。
카이샤 노 노미카이 데 우타 오 우타와사레타.
会社の飲み会で歌を歌わされた。
公司聚会上我被逼着唱了歌。
易错易混点
  • ✗ もう一度書き直さされた。✓ もう一度書き直させられた。書き直す 的使役是 書き直させる，被迫是 書き直させられる，不缩成 さされる。
〜おう / 〜よう
발음〜오우 / 〜요우
…吧；我要…
五段动词词尾改お段+う；一段动词去る+よう；する→しよう；来る→来よう
表示提议、劝诱或说话人自己的意志，口语中常用于自言自语。
韩语对应-자 / -(으)ㄹ게
韩语 -자 表提议，-(으)ㄹ게 表说话人意志；日语同一个意志形兼表两者，靠语境和语气区分。
쓰카레타 네. 스코시야스모우.
疲れたね。少し休もう。
累了吧，稍微休息一下吧。
슈우마쓰, 이쑈 니 에이가 오 미요우 요.
週末、一緒に映画を見ようよ。
周末一起去看电影吧。
よし、今日から毎日日記を書こう。
好，从今天起我每天写日记。
易错易混点
  • ✗ 週末、一緒に映画を見ろうよ。✓ 週末、一緒に映画を見ようよ。見る 是上一段动词，“…吧”的形式是 見よう，不是 見ろう。
〜(よ)うと思う
발음〜우토오모우
我想…；打算…
动词意志形 + と思う／と思っている
表示说话人正在考虑或已下的决心，持续想法用「と思っている」。
韩语对应-(으)려고 하다
韩语 -(으)려고 하다 与 ようと思う 对应；但日语用「と思っている」可表持续的想法，韩语则靠现在时或 고 있다 区分。
코토시 노 나쓰 와 우미 니 이코우 토 오모떼이마스.
今年の夏は海に行こうと思っています。
今年夏天我想去海边。
아시타 와 하야쿠오키테, 코우엔 오 하시로우 토 오모우.
明日は早く起きて、公園を走ろうと思う。
我打算明天早起去公园跑步。
아타라시이파소콘 오 카오우 토 오모따케도, 야메마시타.
新しいパソコンを買おうと思ったけど、やめました。
我本来想买台新电脑，后来放弃了。
易错易混点
  • ✗ 今年の夏は海に行きようと思っています。✓ 今年の夏は海に行こうと思っています。行く 是五段动词，“打算…”的形式是 行こう，不是 行きよう。
