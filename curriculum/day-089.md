# Day 089 · 〜らしい（typical of）、〜っぽい

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜らしい（typical of）、〜っぽい」各造一句自己的话，表达：像…样的；典型的…；有点…；容易…；带…色

## 新词 25

- **工場**（こうば）工厂｜韩语参考：공장<br>
  例：私の父と兄はこの工場で働いている。（我父亲和哥哥在这家工厂工作。）
- **幸福**（こうふく）幸福｜韩语参考：행복（幸福）<br>
  例：金持ちが必ずしも幸福とは限らない。（有钱人不一定幸福。）
- **公平**（こうへい）公平｜韩语参考：공평（公平，平等）<br>
  例：法が常に公平であるとは限らない。（法律未必总是公平的。）
- **候補**（こうほ）候选；候选人｜韩语参考：후보（候选人）<br>
  例：スミス氏は市長候補である。（史密斯先生是市长候选人。）
- **考慮**（こうりょ）考虑｜韩语参考：고려（考虑，斟酌）<br>
  例：彼らに同行しようかと考慮中です。（我正在考虑要不要跟他们一起去。）
- **越える**（こえる）超过；越过｜韩语参考：넘다（过，超过） / 넘기다（越过） / 넘어가다（超过，超）<br>
  例：それは人知の限界を越えている。（那超出了人类智慧的极限。）
- **コーチ**（コーチ）教练｜韩语参考：코치（教练，训练）<br>
  例：コーチが助言をしてくれた。（教练给了我建议。）
- **コード**（コード）代码；软线｜韩语参考：코드（代码，编码）<br>
  例：パソコンのコードを抜かないでください。（请不要拔掉电脑的电源线。）
- **氷**（こおり）冰｜韩语参考：얼음（冰）<br>
  例：船は氷に閉じ込められてしまった。（船被冰封住了。）
- **凍る**（こおる）结冰；冻｜韩语参考：얼다（冻结，冻）<br>
  例：道が凍っているから気を付けなさい。（路面结冰了，小心点。）
- **ゴール**（ゴール）终点；球门｜韩语参考：골（球门，球篮） / 골문（球门） / 결승점（终点）<br>
  例：ゴールまであと百メートルです。（离终点还有一百米。）
- **誤解**（ごかい）误解｜韩语参考：오해（误解，误会）<br>
  例：あなたを誤解してしまってごめんなさい。（对不起，我误会你了。）
- **語学**（ごがく）外语学习｜韩语参考：어학（外语）<br>
  例：これは私の語学の能力を有利に使える好機である。（这是能发挥我语言能力的好机会。）
- **呼吸**（こきゅう）呼吸；诀窍｜韩语参考：호흡（呼吸） / 숨（呼吸） / 숨쉬기（呼吸）<br>
  例：英語の発音の呼吸がなかなか飲み込めない。（英语发音的诀窍我怎么也掌握不了。）
- **故郷**（こきょう）故乡｜韩语参考：향토（乡土，故乡，家乡，家园）<br>
  例：故郷の老いた両親のことを考えて見るべきだ。（你该想想老家年迈的父母。）
- **極**（ごく）极其｜韩语参考：극히<br>
  例：今、ごく小さなペットが流行っている。（现在很流行极小的宠物。）
- **国語**（こくご）国语；语文｜韩语参考：국어（国语） / 나라말（国语） / 우리말（国语）<br>
  例：彼は国語が好きだし得意だ。（他喜欢语文，也很擅长。）
- **黒板**（こくばん）黑板｜韩语参考：흑판（黑板） / 칠판（黑板）<br>
  例：黒板に書きますね。（我写在黑板上哦。）
- **克服**（こくふく）克服｜韩语参考：극복（克服）<br>
  例：彼は多くの困難を克服した。（他克服了许多困难。）
- **国民**（こくみん）国民｜韩语参考：국민（国民）<br>
  例：国民は歓呼して彼を国王に迎えた。（国民欢呼着拥立他为国王。）
- **穀物**（こくもつ）谷物｜韩语参考：곡물（谷物，粮食） / 곡식（庄稼，谷物）<br>
  例：彼は穀物を商っている。（他做谷物生意。）
- **腰**（こし）腰｜韩语参考：허리（腰）<br>
  例：長く座っていたので腰が痛いです。（坐了很久，腰疼。）
- **個人**（こじん）个人｜韩语参考：개인（个人）<br>
  例：社会は個人からなりたっている。（社会由个人组成。）
- **越す**（こす）越过；搬家｜韩语参考：넘다（越过） / 넘어오다（跨越过来）<br>
  例：船は今夜赤道を越すだろう。（船今晚会越过赤道。）
- **国家**（こっか）国家｜韩语参考：국가（国家） / 나라（国，国家）<br>
  例：同じ事が国家についても当てはまる。（同样的事对国家也适用。）

## 语法

- **〜らしい（typical of）**：像…样的；典型的…
  接续：名词 + らしい（らしくない 表“不像”）
  朝鲜语：-다운（韩语「-다운」同样表“符合其本色”；但日语「らしい」还有传闻用法，韩语传闻用「-라고 한다」，不会混淆。）
- **〜っぽい**：有点…；容易…；带…色
  接续：名词/动词ます形词干/い形容词词干 + っぽい
  朝鲜语：-스럽다（韩语「-스럽다」多带正面或中性色彩；日语「っぽい」常含“不够纯正”的轻微贬义，语气更随意。）
