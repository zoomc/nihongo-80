# Day 061 · 〜(よ)うと思う、〜え / 〜ろ

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜(よ)うと思う、〜え / 〜ろ」造两句自己的话，表达：我想…；打算…；（命令）做！

## 新词 14

- **道具**（どうぐ）工具｜韩语参考：도구（工具，方式） / 연장（工具，器具）<br>
  例：この道具はなんの役にもたたない。（这个工具一点用都没有。）
- **とうとう**（とうとう）终于；到底｜韩语参考：그예（终于，最后，结果） / 기어이（最终，终于） / 기어코（最终，终于）<br>
  例：トムはとうとうタバコをやめた。（汤姆终于戒烟了。）
- **動物園**（どうぶつえん）动物园｜韩语参考：동물원（动物园）<br>
  例：コンドルは動物園では決して育たない。（神鹫在动物园里从不繁殖。）
- **遠く**（とおく）远处｜韩语参考：멀리（远处，远方）<br>
  例：遠くにぼんやりした明かりが見えた。（远处隐约看见一点灯光。）
- **通る**（とおる）通过；经过｜韩语参考：통하다（通，通过，流经） / 지나가다（通过，路过） / 통과되다（通过，许可，合格）<br>
  例：私は毎日その教会の前を通る。（我每天从那座教堂前经过。）
- **特に**（とくに）特别；尤其｜韩语参考：특히（特别，尤其，尤为）<br>
  例：私は音楽、特にロックが大好きだ。（我喜欢音乐，尤其是摇滚。）
- **特別**（とくべつ）特别｜韩语参考：특별（特别）<br>
  例：特別料理がございますが。（我们有特别料理。）
- **とこや**（とこや）理发店｜韩语参考：이발소<br>
  例：おや、床屋へ行ってきたのだね。（哎，你去理发店了吧。）
- **特急**（とっきゅう）特快列车｜韩语参考：특급（特快）<br>
  例：時計がおくれていたので、私は特急にのりそこねた。（因为表慢了，我没赶上特快列车。）
- **届ける**（とどける）送达；申报｜韩语参考：전달하다 / 신고하다<br>
  例：家に届けていただけますか。（能送到我家吗？）
- **泊まる**（とまる）住宿；投宿｜韩语参考：투숙하다（投宿，住店）<br>
  例：私は先週おじの家に泊まりました。（我上周住在叔叔家。）
- **止める**（とめる）停下；阻止｜韩语参考：세우다（使停下）<br>
  例：急にジムは銀行の前で車を止めた。（吉姆突然把车停在银行前。）
- **取り替える**（とりかえる）更换；调换｜韩语参考：갈다（换，更换） / 바꾸다（更换，互换，对调）<br>
  例：これを青いのと取り替えてください。（请把这个换成蓝色的。）
- **泥棒**（どろぼう）小偷｜韩语参考：도둑（小偷，盗贼，窃贼）<br>
  例：そこの乞食が泥棒である事がわかった。（那个乞丐原来是小偷。）

## 语法

- **〜(よ)うと思う**：我想…；打算…
  接续：动词意志形 + と思う／と思っている
  朝鲜语：-(으)려고 하다（韩语 -(으)려고 하다 与 ようと思う 对应；但日语用「と思っている」可表持续的想法，韩语则靠现在时或 고 있다 区分。）
- **〜え / 〜ろ**：（命令）做！
  接续：五段动词词尾改え段；一段动词去る+ろ；する→しろ；来る→来い
  朝鲜语：-아/어라（韩语 -아/어라 与命令形对应，但韩语还有 -(으)세요 等礼貌命令；日语命令形语气更硬，且来る 的命令形是特殊形「来い」。）
