# Day 089 · Vた形 + ところで、普通形 + ものだから / もので

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「Vた形 + ところで、普通形 + ものだから / もので」造两句自己的话，表达：即使…也（不会有预期结果）；因为…（所以…）；由于…

## 新词 14

- **売れる**（うれる）畅销；卖出｜韩语参考：나가다（卖出，租出） / 팔리다（被卖掉，被卖出）<br>
  例：この本は最近よく売れている。（这本书最近卖得很好。）
- **上**（うわ）上面；表面｜韩语参考：위 / 표면<br>
  例：彼は上の空で話を聞いていました。（他心不在焉地听着。）
- **噂**（うわさ）传闻；谣言｜韩语参考：소문（传闻，传言）<br>
  例：うわさは四方八方に広がった。（传闻传到了四面八方。）
- **運**（うん）运气｜韩语参考：운（运气） / 운수（运数，运气） / 재수（运气，财运）<br>
  例：そうすればやがて運が開けるでしょう。（那样的话，运气迟早会好起来。）
- **柄**（え）柄；把手｜韩语参考：자루（柄，把柄，把）<br>
  例：傘の柄が折れました。（伞柄折断了。）
- **永遠**（えいえん）永远｜韩语参考：영원（永远，永久）<br>
  例：その画家は、いわば永遠の少年だ。（那位画家可以说是永远的少年。）
- **永久**（えいきゅう）永久｜韩语参考：영구（永久，永远，永恒）<br>
  例：彼は永久に日本を離れた。（他永远离开了日本。）
- **営業**（えいぎょう）营业；销售｜韩语参考：영업（营业）<br>
  例：営業の者と話をしてみました。（我和营业部门的人谈过了。）
- **衛星**（えいせい）卫星｜韩语参考：위성（卫星）<br>
  例：衛星は今軌道に乗っている。（卫星现在已进入轨道。）
- **笑顔**（えがお）笑容；笑脸｜韩语参考：웃는 얼굴<br>
  例：彼らは私を笑顔で迎えてくれた。（他们笑着迎接我。）
- **描く**（えがく）画；描绘｜韩语参考：그리다（描写，描绘）<br>
  例：やっと絵を描き終えた。（终于把画画完了。）
- **餌**（えさ）饲料；诱饵｜韩语参考：밥（饲料，食儿） / 먹이（饲料，食物） / 미끼（饵，诱饵）<br>
  例：犬に毎日えさをあげてください。（请每天喂狗。）
- **エネルギー**（エネルギー）能量；能源｜韩语参考：에너지（能量，能源）<br>
  例：熱はエネルギーの一種である。（热是能量的一种。）
- **得る**（える）得到；获得｜韩语参考：따다（取得，获得） / 맡다（取得，获得） / 얻다（取得，博得，得到，获得）<br>
  例：１０チームが賞を得ようと争った。（十支队伍为得奖而竞争。）

## 语法

- **Vた形 + ところで**：即使…也（不会有预期结果）
  接续：動詞た形 + ところで；后项多为否定或无意义的结果
  朝鲜语：-아/어도 / -더라도（韩语让步用아/어도，强调用더라도；日语ところで后项必为否定性结果，韩语无此限制。）
- **普通形 + ものだから / もので**：因为…（所以…）；由于…
  接续：動詞・い形 普通形 + ものだから；な形・名詞 + な/だ + ものだから；もので 更书面
  朝鲜语：-는 바람에 / -기 때문에（韩语辩解多用는 바람에(多坏事)或기 때문에；日语ものだから带撒娇式辩解，韩语靠语调体现。）
