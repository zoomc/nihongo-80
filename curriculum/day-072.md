# Day 072 · 普通形 + 一方(で) / 反面 / 代わりに、V辞書形 / Nの + たびに

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「普通形 + 一方(で) / 反面 / 代わりに、V辞書形 / Nの + たびに」造两句自己的话，表达：一方面…另一方面…／…但另一方面／取而代之、作为交换；每当…就…；每次…都…

## 新词 25

- **祝う**（いわう）祝贺；庆祝｜韩语参考：축하하다（祝贺，庆贺，道贺）<br>
  例：私たちは彼の試験合格を祝った。（我们庆祝他考试及格。）
- **言わば**（いわば）可以说；可谓｜韩语参考：말하자면<br>
  例：この犬は言わばうちの家族の一員だ。（这条狗可以说是我们家的一员。）
- **いわゆる**（いわゆる）所谓的｜韩语参考：이른바<br>
  例：これがいわゆる「天ぷら」というものです。（这就是所谓的「天妇罗」。）
- **インク**（インク）墨水｜韩语参考：잉크（墨水）<br>
  例：あなたの名前はインクで書かなければならない。（你的名字必须用墨水写。）
- **印刷**（いんさつ）印刷｜韩语参考：인쇄（印刷，打印） / 프린트（印，打印，印刷）<br>
  例：そのニュースは急いで印刷された。（那条新闻被匆忙印了出来。）
- **印象**（いんしょう）印象｜韩语参考：인상（印象）<br>
  例：彼女は気の利く女の子である印象を強く受けた。（她给我留下了机灵女孩的强烈印象。）
- **引退**（いんたい）引退；退役｜韩语参考：은퇴（隐退，退役，退休） / 퇴역（退役，隐退）<br>
  例：彼は商売をたたんで引退した。（他结束了生意，退了下来。）
- **引用**（いんよう）引用｜韩语参考：인용（引用）<br>
  例：ハムレットから１行引用できますか。（你能引用《哈姆雷特》里的一行吗？）
- **ウイスキー**（ウイスキー）威士忌｜韩语参考：위스키（威士忌）<br>
  例：ウイスキーは紅茶とよく合う。（威士忌和红茶很搭。）
- **うがい**（うがい）漱口｜韩语参考：가글 / 입 헹구기<br>
  例：熱があるので家にいたほうがいい。（发烧了，最好待在家里。）
- **受け取る**（うけとる）收到；接受｜韩语参考：받다（收到 ，得到） / 받아들이다（接受）<br>
  例：この贈り物は受け取れません。（这份礼物我不能收。）
- **動かす**（うごかす）移动；打动｜韩语参考：움직이다（动，移动，动弹）<br>
  例：音楽は気持ちを動かします。（音乐能打动人心。）
- **兎**（うさぎ）兔子｜韩语参考：토끼（兔，兔子）<br>
  例：私はウサギの世話をしなければならない。（我必须照顾兔子。）
- **牛**（うし）牛｜韩语参考：소（牛）<br>
  例：彼は市場に出す牛を育てている。（他养牛拿到市场去卖。）
- **失う**（うしなう）失去｜韩语参考：잃다（失去） / 여의다（失去，死别） / 상실하다（丧失，失去）<br>
  例：ミスで財産を失った。（因为一个失误丢了财产。）
- **疑う**（うたがう）怀疑｜韩语参考：의심하다（怀疑，疑心）<br>
  例：僕の言葉をまだ疑っているんですか。（你还在怀疑我说的话吗？）
- **宇宙**（うちゅう）宇宙｜韩语参考：우주（宇宙）<br>
  例：宇宙には限りはない。（宇宙没有尽头。）
- **撃つ**（うつ）射击；打击｜韩语参考：쏘다 / 공격하다<br>
  例：警察官が銃を撃ちました。（警察开了枪。）
- **移す**（うつす）移动；付诸｜韩语参考：옮기다（移动）<br>
  例：知っていることと行動に移すことは別だ。（知道和付诸行动是两回事。）
- **訴える**（うったえる）控诉；呼吁｜韩语参考：호소하다（诉苦，控诉）<br>
  例：その患者はいつも頭が痛いと訴えている。（那位患者总说头疼。）
- **うなる**（うなる）低吼；呻吟｜韩语参考：으르렁거리다 / 신음하다<br>
  例：その犬は小さな男の子に向かって唸った。（那条狗冲着小男孩低吼。）
- **奪う**（うばう）夺取；抢走｜韩语参考：뺏다（夺走，抢走） / 빼앗다（夺走，抢走）<br>
  例：彼女は若い男にバッグを奪われた。（她的包被一个年轻男子抢走了。）
- **馬**（うま）马｜韩语参考：말（马）<br>
  例：馬に乗ることができますか？（你会骑马吗？）
- **生まれ**（うまれ）出生；出身｜韩语参考：태생（出生，籍贯）<br>
  例：私は生まれも育ちも東京だ。（我出生和成长都在东京。）
- **梅**（うめ）梅；梅子｜韩语参考：매실（梅子）<br>
  例：梅の花は今週が見頃です。（梅花这周开得最好。）

## 语法

- **普通形 + 一方(で) / 反面 / 代わりに**：一方面…另一方面…／…但另一方面／取而代之、作为交换
  接续：動詞・い形普通形／な形容词 + な／名词 + である + 一方(で)・反面；名詞 + の／普通形 + 代わりに
  朝鲜语：-는 한편 / -반면에 / -대신에（韩语는 한편表一方面、반면에表相反、대신에表代替，与日语三形对应整齐，반면对比更强。）
- **V辞書形 / Nの + たびに**：每当…就…；每次…都…
  接续：動詞辞書形 + たびに；名詞 + の + たびに（する名詞可直接 するたびに）
  朝鲜语：-(으)ㄹ 때마다（韩语때마다表每当，接名词或动词定语形；日语たびに只接辞书形或の，后项限制更严。）
