# Day 066 · 〜のに（purpose）、〜ので

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜のに（purpose）、〜ので」造两句自己的话，表达：用于…；做…需要；因为…；由于…

## 新词 14

- **増える**（ふえる）增加｜韩语参考：늘다（增大，增长，增加） / 붇다（上涨，增加，增多） / 증가되다（被增加）<br>
  例：大雨で川の水が急に増えた。（大雨让河水一下子涨了起来。）
- **深い**（ふかい）深的｜韩语参考：깊다<br>
  例：湖の深さはどのくらいですか。（湖水有多深。）
- **複雑**（ふくざつ）复杂｜韩语参考：착잡（复杂，烦杂，心烦意乱，心乱如麻）<br>
  例：どのぐらい複雑なのだろうか。（到底有多复杂呢。）
- **復習**（ふくしゅう）复习｜韩语参考：복습<br>
  例：その課の復習をしましたか。（那一课复习了吗。）
- **部長**（ぶちょう）部长；部门经理｜韩语参考：부장（部长）<br>
  例：社長は新しい部長を任命した。（社长任命了新的部长。）
- **普通**（ふつう）普通；通常｜韩语参考：보통（普通，一般） / 일반（普通） / 통상（通常，平常）<br>
  例：私はふつう自転車で通学します。（我通常骑自行车上学。）
- **ぶどう**（ぶどう）葡萄｜韩语参考：포도<br>
  例：私たちはぶどうをたくさん手に入れた。（我们弄到了很多葡萄。）
- **太る**（ふとる）发胖｜韩语参考：붇다（长胖，发胖） / 찌다（发胖，长膘） / 살찌다（长胖，发胖）<br>
  例：あまり太ったのでカラーの前が合わなかった。（因为太胖了，衣领扣不上。）
- **布団**（ふとん）被褥｜韩语参考：자리（被褥） / 이부자리（被褥，铺盖）<br>
  例：布団をたたみなさい。（把被褥叠起来。）
- **舟**（ふね）船；小船｜韩语参考：배 / 작은 배<br>
  例：船は３時に出ることになっている。（船定在三点开。）
- **不便**（ふべん）不方便｜韩语参考：불편（不便，不方便）<br>
  例：もし電話がなければ、不便だろう。（要是没有电话，大概很不方便吧。）
- **踏む**（ふむ）踩｜韩语参考：딛다（踩，踏） / 밟다（踩）<br>
  例：足を踏むつもりはなかったのです。（我并不是故意踩你的脚。）
- **降り出す**（ふりだす）下起来｜韩语参考：내리기 시작하다<br>
  例：その上雨が降り出している。（而且雨也开始下了。）
- **プレゼント**（プレゼント）礼物｜韩语参考：선물（礼物）<br>
  例：ハーモニカはお父さんからのプレゼントですか。（口琴是爸爸送的礼物吗？）

## 语法

- **〜のに（purpose）**：用于…；做…需要
  接续：动词辞书形 + のに（用途・所需）；名词 + に
  朝鲜语：-는 데（韩语 -는 데 与用途、所需的 のに 对应（걷는 데 20분 걸린다）；日语 のに 与转折的 のに 同形，韩语则用 데 区分。）
- **〜ので**：因为…；由于…
  接续：动词普通形／い形容词 + ので；な形容词+な／名词+な + ので
  朝鲜语：-아서/어서（韩语 -아서/어서 与 ので 都表客观原因，但日语 ので 可接意志、请求，韩语 -아서/어서 后项一般不能是命令、劝诱。）
