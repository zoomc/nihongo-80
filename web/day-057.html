今日语法 3 条

N + に 対して / に 関して
발음〜니타이시테 / 〜니칸시테
对…（针对对象/对比）／关于…（书面）
名詞 + に対して（动作/态度的对象，或「与此相对」的对比）；名詞 + に関して（＝について 的书面语）
に対して 后接对人/物的动作、态度或对比；に関して 多用于正式文书、新闻
先生に対して失礼なことを言いました。
对老师说了失礼的话。
この問題に関して、後ほど報告します。
关于这个问题稍后汇报。
朝鲜语：-에 대해 / -에 관해
韩语에 대해表针对，에 관해表关于，二者都可书面；日语に対して还表对比，韩语须用에 비해。
易错点

先生に対してに失礼しました。 → 先生に対して失礼しました。（に対して 已含 に，不再叠 に；中文「对老师」直译叠加助词错）

N / V辞書形 + に 伴って / に つれて / に 従って
발음〜니토모나떼
随着…（前项变化，后项也跟着变化）
名詞 + に／動詞 辞書形 + に + 伴って・つれて・従って；后项须是变化动词（増える／変わる／高くなる 等）
书面，表伴随变化；につれて/に従って 偏比例变化，に伴って 偏伴随发生（常带同时性）
気温が上がるにつれて、売上が増えます。
随着气温升高，销量增加。
技術の進歩に伴って、仕事のやり方が変わりました。
随着技术进步，工作方式变了。
朝鲜语：-에 따라 / -(으)면서
韩语伴随变化用에 따라或면서，比例变化多用ㄹ수록；日语三形语感细分更多。
易错点

気温が上がるにつれて、ビールがおいしいです。 → 気温が上がるにつれて、ビールが売れるようになります。（后项须是变化（増える／高くなる），静态形容词 おいしい 不接；中文「随着…很…」直译错）

N + に 基づいて / を もとに / どおり(に)
발음〜니쿠즈이테
基于…／以…为依据／按照…
名詞 + に基づいて（依据资料/规则/数据）；名詞 + をもとに（以…为素材/基础）；名詞 + どおり(に)（照原样、按预定）
书面；に基づいて 偏「依据权威来源」，をもとに 偏「以…为材料加工」，どおり 偏「不改动地照做」
調査結果に基づいて、報告書を作成しました。
依据调查结果写成了报告。
요테이도오리니,카이기오하지메마스.
予定どおりに、会議を始めます。
按预定开始会议。
朝鲜语：-에 근거해 / -을 바탕으로 / -대로
韩语에 근거해表依据、을 바탕으로表以…为基础、대로表按照，与日语三形基本对应。
易错点

資料に基づいてに書きました。 → 資料に基づいて書きました。（に基づいて 已含 に，不再叠 に；中文「基于资料」直译叠加助词错）
