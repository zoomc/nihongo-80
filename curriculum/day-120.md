# Day 120 · 〜はずだ、〜はずがない

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜はずだ、〜はずがない」各造一句自己的话，表达：应该…；按理说…；不可能…；不会…

## 新词 25

- **発見**（はっけん）发现｜韩语参考：발견（发现）<br>
  例：だれがそれを発見したのかと思う。（我想知道是谁发现了它。）
- **発行**（はっこう）发行；出版｜韩语参考：발행（发行）<br>
  例：この地方新聞は週に１回発行される。（这份地方报纸每周发行一次。）
- **発車**（はっしゃ）发车｜韩语参考：발차（发车）<br>
  例：バスは五分後に発車します。（公交车五分钟后发车。）
- **罰する**（ばっする）惩罚｜韩语参考：벌주다（罚，惩罚） / 벌하다（罚，惩罚） / 벌세우다（罚，惩罚）<br>
  例：どうしてあなたは彼らを罰しているのですか。（你为什么惩罚他们？）
- **発達**（はったつ）发达；发育｜韩语参考：발달（发达，发育）<br>
  例：水泳は筋肉を発達させる。（游泳能使肌肉发达。）
- **ばったり**（ばったり）突然；碰巧｜韩语参考：발딱（突然，一下子）<br>
  例：道でばったり彼女に会いましてね。（我在路上碰巧遇见了她。）
- **発展**（はってん）发展｜韩语参考：발전（发展）<br>
  例：商業は都市の発展をもたらした。（商业带动了城市的发展。）
- **発明**（はつめい）发明｜韩语参考：발명（发明）<br>
  例：エジソンが電球を発明した。（爱迪生发明了电灯泡。）
- **話し合う**（はなしあう）商谈；商量｜韩语参考：서로 이야기하다 / 협의하다<br>
  例：ここでその問題について話し合いましょう。（我们在这里商量一下这个问题吧。）
- **放す**（はなす）放开；放走｜韩语参考：내놓다（放，放开）<br>
  例：その犬はボールを放そうとしなかった。（那条狗不肯放开球。）
- **離す**（はなす）分开；隔开｜韩语参考：떨어뜨리다（隔开） / 떨어트리다（拉开，隔开）<br>
  例：すみません。いま手が離せないんです。（抱歉，我现在手腾不开。）
- **離れる**（はなれる）离开；分开｜韩语参考：떠나다（离开，离去） / 갈라서다（分开，分开走） / 떠나오다（离开）<br>
  例：彼女に愛着があって離れられない。（我对她有感情，离不开她。）
- **羽**（はね）羽毛；翅膀｜韩语参考：깃（羽毛） / 깃털（羽毛） / 새털（羽毛）<br>
  例：同じ色の羽の鳥は共に集まるものだ。（羽毛颜色相同的鸟会聚在一起。）
- **幅**（はば）宽度；幅度｜韩语参考：폭（宽度，幅） / 너비（宽度，幅）<br>
  例：この川の幅が１マイルある。（这条河宽一英里。）
- **母親**（ははおや）母亲｜韩语参考：모친（母亲） / 어머니（母亲，妈妈）<br>
  例：その女の子は彼女の母親と似ている。（那个女孩长得很像她母亲。）
- **省く**（はぶく）省略；节省｜韩语参考：생략하다（省略，缩略）<br>
  例：細かい所は省いて構わない。（细节可以省略。）
- **場面**（ばめん）场面；场景｜韩语参考：장면（场面）<br>
  例：特にこの場面が好きですねえ。（我特别喜欢这个场景。）
- **原**（はら）原野；荒野｜韩语参考：들（平原，原野） / 벌판（原野）<br>
  例：私達がよく野球をして遊んだ原は今すっかり家が建て込んでしまった。（我们常去打球的那片空地如今盖满了房子。）
- **腹**（はら）肚子；内心｜韩语参考：배（肚子）<br>
  例：あの人は口と腹が反対だ。（那个人口是心非。）
- **針**（はり）针；指针｜韩语参考：땀（针） / 바늘（针，缝衣针） / 지침（指针）<br>
  例：針で親指を突いてしまった。（针扎到了我的拇指。）
- **張る**（はる）贴；撑起｜韩语参考：붙이다 / 팽팽하게 하다<br>
  例：問題はどこにテントを張るかだった。（问题是在哪里搭帐篷。）
- **バン**（バン）厢式车｜韩语参考：밴 / 화물차<br>
  例：荷物をバンに積みました。（把行李装进了厢式车。）
- **番**（ばん）号；编号｜韩语参考：번（号）<br>
  例：列車は１０番ホームに到着します。（列车将到达10号站台。）
- **範囲**（はんい）范围｜韩语参考：범위（范围）<br>
  例：それらの範囲や形は不明確である。（它们的范围和形状都不明确。）
- **反抗**（はんこう）反抗；违抗｜韩语参考：반항（反抗，抗拒）<br>
  例：彼らは王様の作った法律に反抗した。（他们违抗了国王制定的法律。）

## 语法

- **〜はずだ**：应该…；按理说…
  接续：动词普通形／い形容词 + はずだ；な形容词+な／名词+の + はずだ
  朝鲜语：-(으)ㄹ 것이다（韩语 -(으)ㄹ 것이다 既可表推测也可表意志，日语 はずだ 只表基于根据的推断，不含意志；两者不能完全对应。）
- **〜はずがない**：不可能…；不会…
  接续：动词普通形／い形容词 + はずがない；な形容词+な／名词+の + はずがない
  朝鲜语：-(으)ㄹ 리가 없다（韩语 -(으)ㄹ 리가 없다 与 はずがない 对应度很高，都表根据理由的强烈否定；语序上韩语「리가」在前，日语「はず」在后。）
