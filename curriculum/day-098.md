# Day 098 · 〜ことになっている、〜こと（instruction）

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜ことになっている、〜こと（instruction）」造两句自己的话，表达：规定…；按理…；必须…；不得…

## 新词 19

- **髪の毛**（かみのけ）头发｜韩语参考：머리（头发） / 머리숱（头发疏密） / 머리털（发丝，头发）<br>
  例：どこで髪の毛を切ったの。（你在哪儿剪的头发？）
- **科目**（かもく）科目｜韩语参考：과목（科目）<br>
  例：どの科目が一番好きですか。（你最喜欢哪门科目？）
- **かもしれない**（かもしれない）也许｜韩语参考：~일지도 모른다<br>
  例：あなたの言うことは正しいかもしれない。（你说的也许是对的。）
- **火曜**（かよう）星期二｜韩语参考：화요일<br>
  例：火曜の朝までにすべて終えなければならないのです。（必须在周二早上之前全部做完。）
- **空**（から）空的｜韩语参考：비다 / 공복이다<br>
  例：ほとんど空なのでガソリンを入れなくてはなりません。（油箱几乎是空的，得加油了。）
- **刈る**（かる）剪；割｜韩语参考：깎다（剪）<br>
  例：彼らはジャックの髪の刈り方をひやかした。（他们取笑杰克剪头发的方式。）
- **河**（かわ）河｜韩语参考：강（江，河）<br>
  例：この河はニューオリンズまで続いている。（这条河一直延伸到新奥尔良。）
- **革**（かわ）皮革｜韩语参考：가죽<br>
  例：くつは革でつくられている。（鞋是用皮革做的。）
- **皮**（かわ）皮；表皮｜韩语参考：가죽（皮） / 까풀（皮，皮层） / 꺼풀（层，表皮）<br>
  例：動物の皮は毛でおおわれている。（动物的皮上覆盖着毛。）
- **かわいそう**（かわいそう）可怜｜韩语参考：불쌍하다<br>
  例：彼女は可哀想に思って、その子達の面倒をみた。（她觉得那些孩子可怜，就照顾了他们。）
- **かわいらしい**（かわいらしい）可爱｜韩语参考：귀엽다<br>

- **勘**（かん）直觉；灵感｜韩语参考：감 / 직감<br>
  例：その新聞記者はニュースを嗅ぎつける鋭い勘を持っている。（那名记者有敏锐的直觉，能嗅出新闻。）
- **缶**（かん）罐｜韩语参考：캔（罐，易拉罐，听） / 깡통（桶，罐，易拉罐）<br>
  例：この缶にはおよそ４ガロン入る。（这个罐子大约能装四加仑。）
- **考え**（かんがえ）想法｜韩语参考：생각（念头，想法） / 소리（声音，想法，消息）<br>
  例：あなたの考えを言ってください。（请说说你的想法。）
- **感覚**（かんかく）感觉｜韩语参考：감각（感觉）<br>
  例：私は指に感覚が無かった。（我的手指没有知觉。）
- **観客**（かんきゃく）观众｜韩语参考：관객（观众） / 손님（观众，访客）<br>
  例：そのショーで観客は大喜びだった。（那场演出让观众非常开心。）
- **歓迎**（かんげい）欢迎｜韩语参考：환영（欢迎）<br>
  例：あなたはうちのクラスで歓迎されています。（你在我们班很受欢迎。）
- **観察**（かんさつ）观察｜韩语参考：관찰（观察）<br>
  例：科学は観察に基づいている。（科学建立在观察之上。）
- **感じ**（かんじ）感觉｜韩语参考：감（感觉） / 느낌（感觉，感受）<br>
  例：その部屋は居心地の良い感じがした。（那个房间让人感觉很舒服。）

## 语法

- **〜ことになっている**：规定…；按理…
  接续：动词辞书形/ない形 + ことになっている
  朝鲜语：-기로 되어 있다（韩语「-기로 되어 있다」同样表既定安排；但日语还能暗示“规定如此、实际未必”，带距离感，韩语较少这层含义。）
- **〜こと（instruction）**：必须…；不得…
  接续：动词辞书形/ない形 + こと（用于告示、规章结句）
  朝鲜语：-할 것（韩语规章也用「-할 것」，与日语「こと」结句几乎一致；但禁止句韩语用「-하지 말 것」，日语用「ないこと」。）
