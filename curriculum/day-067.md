# Day 067 · 〜て（reason）、〜し

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜て（reason）、〜し」造两句自己的话，表达：因为…（造成某种状态）；既…又…；而且…

## 新词 19

- **文化**（ぶんか）文化｜韩语参考：문화（文化）<br>
  例：私はギリシャ文化について学んだ。（我学过希腊文化。）
- **文学**（ぶんがく）文学｜韩语参考：문학（文学）<br>
  例：彼女はスペイン文学に明るいです。（她精通西班牙文学。）
- **文法**（ぶんぽう）语法｜韩语参考：문법（语法）<br>
  例：文法なんかくそくらえだ。（语法什么的去他的。）
- **別**（べつ）别的；另外｜韩语参考：다른 / 별도<br>
  例：また別のときにチェスをしましょう。（下次再一起下棋吧。）
- **ベル**（ベル）铃；贝尔｜韩语参考：벨（铃，电铃） / 방울（铃，铃铛）<br>
  例：電話はベルによって発明された。（电话是贝尔发明的。）
- **変**（へん）奇怪｜韩语参考：이상하다<br>
  例：そのオレンジは後味が変だった。（那个橙子后味很奇怪。）
- **返事**（へんじ）回答；回复｜韩语参考：답（回答，答话） / 답장（回信，回复） / 대답（应答，回应，回复）<br>
  例：すぐ返事をしてもらいたいと思っています。（希望你能马上回复我。）
- **貿易**（ぼうえき）贸易｜韩语参考：무역（国内贸易）<br>
  例：日本は貿易に頼っている。（日本依靠贸易。）
- **放送**（ほうそう）播放；广播｜韩语参考：방송（广播，电视）<br>
  例：ニュースは毎時放送しています。（新闻每小时播一次。）
- **法律**（ほうりつ）法律｜韩语参考：법률（法律） / 법（法律）<br>
  例：この法律はすべての人に適用される。（这条法律适用于所有人。）
- **僕**（ぼく）我（男性）｜韩语参考：나（我） / 내（我）<br>
  例：僕をかもだと思っているんだろう。（你以为我好骗吧。）
- **星**（ほし）星星｜韩语参考：별（星星）<br>
  例：ドアには大きな金色の星がついていました。（门上有一颗很大的金色星星。）
- **ほど**（ほど）程度；大约｜韩语参考：정도 / 약<br>
  例：スージーほど上手にピアノをひけるとよいのだが。（我要能弹得像苏西那么好就好了。）
- **ほとんど**（ほとんど）几乎｜韩语参考：거의<br>
  例：ケイトは中国語をほとんど話せない。（凯特几乎不会说中文。）
- **ほめる**（ほめる）表扬｜韩语参考：칭찬하다<br>
  例：ヘレンはみんなにほめられて顔を赤くした。（海伦被大家一夸，脸红了。）
- **翻訳**（ほんやく）翻译；笔译｜韩语参考：번역（翻译）<br>
  例：彼女はそれを一語一語翻訳した。（她把它逐词翻译了一遍。）
- **参る**（まいる）去；来（自谦）｜韩语参考：가다 / 오다（겸양）<br>
  例：ジョーはその女の子にすっかり参っている。（乔完全被那个女孩迷住了。）
- **負ける**（まける）输｜韩语参考：지다（输）<br>
  例：３対０で彼には負けています。（我以零比三输给了他。）
- **まじめ**（まじめ）认真｜韩语参考：성실하다<br>
  例：サムは仕事に関してまじめです。（山姆对工作很认真。）

## 语法

- **〜て（reason）**：因为…（造成某种状态）
  接续：动词て形／い形容词去い+くて／な形容词・名词+で
  朝鲜语：-아서/어서（韩语 -아서/어서 与 て 的原因用法对应，但日语 て 形还可表并列、先后，功能更多；韩语需靠上下文或另加连接词。）
- **〜し**：既…又…；而且…
  接续：动词普通形／い形容词 + し；な形容词・名词 + だ + し
  朝鲜语：-고（韩语 -고 可并列理由，但语气中性；日语 し 暗示「还有别的理由」，主观色彩更强，韩语常需加 -기도 하고 才接近。）
