# Day 068 · 〜けど / 〜けれども、〜ために

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜けど / 〜けれども、〜ために」造两句自己的话，表达：但是…；虽然…；为了…；因为…

## 新词 14

- **息子**（むすこ）儿子<br>
  例：母親は息子にやかましく言って聞かせた。（母亲狠狠训了儿子一顿。）
- **娘**（むすめ）女儿<br>
  例：私はヘレンカートライトの娘です。（我是海伦·卡特赖特的女儿。）
- **無理**（むり）不可能；勉强｜朝鲜语：무리<br>
  例：それは無理な注文だ。（这个要求太过分了。）
- **召し上がる**（めしあがる）吃；喝（尊敬）<br>
  例：ここで召し上がりますか、それともお持ち帰りですか。（您在这儿吃还是带走。）
- **珍しい**（めずらしい）少见；稀奇<br>
  例：これは珍しい種類の魚です。（这是很稀奇的一种鱼。）
- **申し上げる**（もうしあげる）说（自谦）<br>
  例：お礼の申し上げようもありません。（实在不知怎么感谢您才好。）
- **もうすぐ**（もうすぐ）马上<br>
  例：明るくなってきた。もうすぐ朝だ。（天亮了，马上就要早晨了。）
- **もし**（もし）如果<br>
  例：もし電話がなったら出てくれますか。（要是电话响了，你能接一下吗。）
- **もちろん**（もちろん）当然<br>
  例：「ご一緒してもいいですか」「もちろんです」（「我可以一起去吗？」「当然。」。）
- **もっとも**（もっとも）最<br>
  例：ケンは三人のなかでもっとも速く走ります。（健在三跑得最快。）
- **戻る**（もどる）返回<br>
  例：やってしまったことは元に戻らない。（做过的事回不到原样。）
- **木綿**（もめん）棉；棉布<br>
  例：このブラウスは木綿製です。（这件衬衫是棉的。）
- **もらう**（もらう）得到；请人做<br>
  例：あさって彼にここへ来てもらうつもりです。（打算后天请他来这里。）
- **森**（もり）森林<br>
  例：私は森の中で野うさぎをみつけた。（我在森林里发现了一只野兔。）

## 语法

- **〜けど / 〜けれども**：但是…；虽然…
  接续：句子普通形 + けど／けれども（礼貌体可直接接）
  朝鲜语：-지만（韩语 -지만 与 けど 对应，但日语 けど 还可放在句末缓和语气、引出下文；韩语 -지만 一般不能这样独立使用。）
- **〜ために**：为了…；因为…
  接续：动词辞书形／动词た形 + ために；名词 + の + ために
  朝鲜语：-기 위해(서) / 때문에（韩语 -기 위해(서) 表目的，때문에 表原因，两者形式不同；日语 ために 一个形式兼表目的与原因，需靠前接成分判断。）

- **内** 内部；里面｜音：ナイ、ダイ｜训：うち
