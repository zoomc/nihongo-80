今日语法 3 条

～と 思う / ～と 言う
발음～토 오모우 / ～토 이우
觉得…／说「…」
普通形从句 + と + 思う／言う
引用助词 と；从句用普通形，不用 です/ます
아시타와아메다토오모이마스.
明日は雨だと思います。
我觉得明天会下雨。
카레와이키타쿠나이토이이마시타.
彼は行きたくないと言いました。
他说不想去。
朝鲜语：-다고 생각하다 / -라고 말하다
韩语引用按句类选다고/라고/냐고，动词要变化；日语と引用保留原形即可。
易错点

明日は雨です と思います。 → 明日は雨だと思います。（「です」不能直接接「と思います」（引用从句要用普通体）。应说「明日は雨だと思います」。这不是 です 本身错，而是嵌在引用从句里的语体不对。）

～から / ～ので（原因）
발음～카라 / ～노데
因为…所以…
普通形/丁寧形 + から；普通形 + ので（名/な形 + なので）
から 偏主观、可接意志/命令；ので 偏客观、语气柔和
아메가후떼이루카라,이키마센.
雨が降っているから、行きません。
因为在下雨，所以不去。
이소가시이노데,이케마센.
忙しいので、行けません。
因为忙，去不了。
朝鲜语：-아/어서 / -(으)니까
韩语아/어서后不接命令请求，니까可接；日语から可接命令，ので语气较柔。
易错点

雨 ので、行きません。 → 雨なので、行きません。（名词接 ので 要加 な：雨なので；な形容词同理）

条件形 使い分け（たら／ば／なら／と）
如果／要是／一…就（四条件辨析）
たら 既定/假定通用；ば 假定；なら 承接话题；と 自然/必然结果
在 G0025 变形基础上区分语用：と 后不接意志，なら 承接对方刚提的话题
아메가후따라,이키마센.
雨が降ったら、行きません。
下雨的话就不去。
朝鲜语：-(으)면 / -다면 / -자마자
韩语条件主要靠면，假设用다면，一…就用자마자；无日语と/なら的意志限制。
易错点

雨が降るたら、出かけません。 → 雨が降ったら、出かけません。（たら接た形，降る的た形是降った。）
