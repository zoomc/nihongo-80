# Day 020 · 〜から（from）、〜まで（until）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 新词 25

- **初め**（はじめ）开始；起初｜韩语参考：시초（开始，一开始） / 초두（起初，最初） / 초장（开端，开始）<br>
  例：旅行の初めの二日間は雨降りだった。（旅行最初的两天都在下雨。）
- **初めて**（はじめて）第一次｜韩语参考：처음으로<br>
  例：初めてドリアンを食べました。（我第一次吃了榴莲。）
- **はじめまして**（はじめまして）初次见面｜韩语参考：처음 뵙겠습니다<br>
  例：初めましてケン。（初次见面，肯。）
- **走る**（はしる）跑｜韩语参考：뛰다（跑，奔跑） / 달리다（跑，奔跑，快跑）<br>
  例：あの走ってる少年をごらんなさい。（你看那个在跑的男孩。）
- **バター**（バター）黄油｜韩语参考：버터（黄油）<br>
  例：バターはミルクから出来る。（黄油是用牛奶做的。）
- **鼻**（はな）鼻子｜韩语参考：코（鼻，鼻子）<br>
  例：鼻が出ているよ。かみなさい。（流鼻涕了，擤一擤。）
- **話**（はなし）话；故事｜韩语参考：말씀（话） / 얘기（故事） / 이야기（故事）<br>
  例：話を聞かせてくれ。（说给我听听。）
- **早い**（はやい）早；快｜韩语参考：빠르다（早） / 이르다（早）<br>
  例：時のたつのは早いものだ。（时间过得太快了。）
- **速い**（はやい）快；迅速｜韩语参考：빠르다（快，迅速）<br>
  例：ショットはとても速いものもある。（有些人的球速也非常快。）
- **春**（はる）春天｜韩语参考：봄（春，春天，春季）<br>
  例：カッコウは春にここにやってくる。（布谷鸟春天会来这里。）
- **貼る**（はる）贴；粘贴｜韩语参考：붙이다<br>
  例：その写真はアルバムに貼ったほうがよい。（那些照片最好贴到相册里。）
- **晴れ**（はれ）晴天｜韩语参考：맑은 날씨<br>
  例：ロンドンの天気は晴れです。（伦敦的天气是晴天。）
- **晴れる**（はれる）放晴；转晴｜韩语参考：개다（放晴） / 걷다（放晴） / 걷히다（放晴）<br>
  例：あした晴れてくれるといいなあ。（明天要是能放晴就好了。）
- **半**（はん）半；一半｜韩语参考：반（一半，半）<br>
  例：半時間したら彼はここに来るでしょう。（过半个小时他就会来吧。）
- **晩**（ばん）晚上；晚间｜韩语参考：저녁 / 밤<br>
  例：晩までにはおそらく雨になるだろう。（到晚上大概会下雨吧。）
- **ハンカチ**（ハンカチ）手帕｜韩语参考：손수건（手帕，手绢）<br>
  例：このハンカチはいくらですか。（这条手帕多少钱？）
- **番号**（ばんごう）号码；编号｜韩语参考：번호（号码）<br>
  例：番号をまちがえじゃありませんか。（您是不是弄错号码了？）
- **晩御飯**（ばんごはん）晚饭｜韩语参考：석식（晚餐，晚饭）<br>
  例：晩ご飯ですよ、お父さん。（爸爸，晚饭好了。）
- **半分**（はんぶん）一半；半个｜韩语参考：반（一半，半） / 반쪽（一半，半）<br>
  例：ケーキのどちらの半分でもとりなさい。（蛋糕两半你随便拿哪一半。）
- **東**（ひがし）东；东方｜韩语参考：동（东方，东边） / 동녘（东方，东边） / 동쪽（东边，东方）<br>
  例：その市はロンドンの東にある。（那座城市位于伦敦以东。）
- **引く**（ひく）拉；查（词典）｜韩语参考：끌다（引，拉） / 당기다（拉，拖，拽）<br>
  例：カーテンがゆっくり引かれた。（窗帘被慢慢地拉上了。）
- **弾く**（ひく）弹奏（乐器）｜韩语参考：치다（弹，弹奏，打） / 타다（弹，弹奏，演奏）<br>
  例：ギターをひくのはおもしろい。（弹吉他很有意思。）
- **低い**（ひくい）低；矮｜韩语参考：낮다（低，矮，低洼） / 얕다（浅，低，矮） / 옅다（矮）<br>
  例：ラジオの音を低くして下さい。（请把收音机的声音调小。）
- **左**（ひだり）左；左边｜韩语参考：좌（左）<br>
  例：アラビア語は右から左へ書きます。（阿拉伯语是从右往左写的。）
- **一つ**（ひとつ）一个；一样｜韩语参考：하나 / 한 개<br>
  例：車にはハンドルが一つある。（汽车有一个方向盘。）

## 语法

- **〜から（from）**：从…（起点）
  接续：名词 + から（起点）
  朝鲜语：부터 / 에서（韩语时间起点用 부터，场所起点用 에서；日语 から 两者通用，范围更宽。）
- **〜まで（until）**：到…为止；直到…
  接续：名词 + まで（终点）
  朝鲜语：까지（韩语 까지 与 まで 对应，时间和空间都可用；日语 まで 还可表程度界限（駅まで歩く），韩语 까지 同样可延伸。）

- **外** 外面；以外；其他｜音：ガイ、ゲ｜训：そと、ほか、はず.す、はず.れる、と-
- **山** 山；山岳｜音：サン、セン｜训：やま
- **北** 北；北方｜音：ホク｜训：きた
- **午** 正午；午时；干支马｜音：ゴ｜训：うま
