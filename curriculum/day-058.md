# Day 058 · N / 普通形 + ばかりか、Vます形(去ます) + ようがない / ようもない、N / Vます形(去ます) + がちだ

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **N / 普通形 + ばかりか**：不仅…而且…
  接续：名詞 + ばかりか；動詞・い形 普通形 + ばかりか；な形・名詞 + な/である + ばかりか
  朝鲜语：-(으)ㄹ 뿐만 아니라（韩语뿐만 아니라表不仅而且，后项可同程度；日语ばかりか后项常程度更高，还可接まで/も。）
- **Vます形(去ます) + ようがない / ようもない**：无法…；没有办法…
  接续：動詞ます形去ます + ようがない；する→しようがない；句末 ようがありません
  朝鲜语：-(으)ㄹ 방법이 없다（韩语ㄹ 방법이 없다表无手段，与能力不足的ㄹ 수 없다区分；同日语ようがない与できない之别。）
- **N / Vます形(去ます) + がちだ**：容易…；往往…（多指不好的倾向）
  接续：名詞 + がちだ；動詞ます形去ます + がちだ；がちな + 名詞
  朝鲜语：-기 쉽다 / -는 경향이 있다（韩语기 쉽다表容易(中性)，负面倾向用는 경향이 있다；日语がちだ多负面，语感更窄。）
