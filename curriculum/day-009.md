# Day 009 · な形容词（～です）、い形容词 否定／过去／て形

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「な形容词（～です）、い形容词 否定／过去／て形」造两句自己的话，表达：…（な形容词谓语）；不…／曾…／又…（い形变形）

## 新词 20

- **時々**（ときどき）有时；时常｜韩语参考：가끔가다（偶尔，有时）<br>
  例：時々映画を見ます。（有时看电影。）
- **まだ**（まだ）还；尚未｜韩语参考：채（还，尚） / 미처（尚未，来不及）<br>
  例：まだ食べていません。（还没吃。）
- **もう**（もう）已经；再（一次）｜韩语参考：벌써（已经） / 이미（已经）<br>
  例：もう帰りました。（已经回去了。）
- **そして**（そして）然后；而且｜韩语参考：그리고（而且，并且，况且）<br>
  例：本を読んで、そして寝ます。（读书，然后睡觉。）
- **だから**（だから）所以；因此｜韩语参考：그러므로（因此，所以）<br>
  例：雨です。だから、行きません。（下雨，所以不去。）
- **でも**（でも）但是；不过；连…也｜韩语参考：그런데（可是，但是）<br>
  例：高いです。でも、買います。（贵，不过还是买。）
- **すぐ**（すぐ）马上；立刻；就近｜韩语参考：곧（马上，就） / 금방（马上，立刻，立马） / 당장（当前，立刻）<br>
  例：すぐ行きます。（马上就去。）
- **ゆっくり**（ゆっくり）慢慢地；好好地｜韩语参考：천천히（慢慢地，缓慢地） / 슬렁슬렁（慢慢地，轻轻地）<br>
  例：ゆっくり話してください。（请慢慢说。）
- **会う**（あう）见面｜韩语参考：보다（看，见，见面） / 만나다（见面，相逢）<br>
  例：もうスミスさんに会われましたね。（您已经见过史密斯先生了吧。）
- **青**（あお）蓝色；青色｜韩语参考：파랑 / 푸른색<br>
  例：信号が青に変わったわよ。（信号灯变绿了。）
- **青い**（あおい）蓝色的；不成熟｜韩语参考：파랗다 / 미숙하다<br>
  例：お前はまだ「青い」な。（你还嫩着呢。）
- **赤**（あか）红色｜韩语参考：빨강（红色，红色染料） / 붉은색（红色） / 빨간색（红色）<br>
  例：赤インクで書いてはいけない。（不能用红墨水写。）
- **赤い**（あかい）红色的｜韩语参考：빨갛다<br>
  例：彼女は赤いスカートをはいていた。（她穿着一条红裙子。）
- **明るい**（あかるい）明亮；开朗｜韩语参考：밝다（明亮） / 환하다（明亮，亮，亮堂）<br>
  例：外はだんだん明るくなっていく。（外面渐渐亮了起来。）
- **秋**（あき）秋天｜韩语参考：가을（秋天，秋季） / 가을날（秋日，秋天） / 가을철（秋季，秋天）<br>
  例：秋はもうすぐそこまで来ている。（秋天马上就要到了。）
- **開く**（あく）开；打开｜韩语参考：열리다（开）<br>
  例：ぐいと押すとドアは開いた。（用力一推，门就开了。）
- **開ける**（あける）打开｜韩语参考：열다（打开）<br>
  例：ドアはジムによって開けられます。（门被吉姆打开了。）
- **上げる**（あげる）举起；给｜韩语参考：주다（给予，给） / 쳐들다（举起，抬起，撑起） / 추켜들다（高举，举起）<br>
  例：左手を上げなさい。（把左手举起来。）
- **朝ごはん**（あさごはん）早饭｜韩语参考：아침밥<br>
  例：朝ごはんにはなにがよろしいですか。（早饭您想吃点什么？）
- **あさって**（あさって）后天｜韩语参考：모레<br>
  例：あさって彼にここへ来てもらうつもりです。（打算后天让他来这儿。）

## 语法

- **な形容词（～です）**：…（な形容词谓语）
  接续：な形容詞語幹 + です／だ
  朝鲜语：형용사(하다형)（韩语 하다 类形容词修饰名词时通常变成 -한，如 조용한 방；日语な形容词连体用 な。）
- **い形容词 否定／过去／て形**：不…／曾…／又…（い形变形）
  接续：高い→高くない／高かった／高くて
  朝鲜语：-지 않다 / -았·었- / -고（韩语否定用지 않다、过去用았/었、中顿用고，无日语くて的音便变化。）
