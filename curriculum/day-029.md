# Day 029 · 〜より、〜の方が〜より

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜より、〜の方が〜より」造两句自己的话，表达：比…；…比…更…

## 新词 19

- **橋**（はし）桥｜韩语参考：다리（桥，桥梁）<br>
  例：その橋はどれくらいの長さですか。（那座桥有多长？）
- **始まる**（はじまる）开始｜韩语参考：시작되다（被开始）<br>
  例：今コンサートが始まろうとしている。（音乐会现在就要开始了。）
- **初め**（はじめ）开始；起初｜韩语参考：시초（开始，一开始） / 초두（起初，最初） / 초장（开端，开始）<br>
  例：旅行の初めの二日間は雨降りだった。（旅行最初的两天都在下雨。）
- **初めて**（はじめて）第一次｜韩语参考：처음으로<br>
  例：初めてドリアンを食べました。（我第一次吃了榴莲。）
- **はじめまして**（はじめまして）初次见面｜韩语参考：처음 뵙겠습니다<br>
  例：初めましてケン。（初次见面，肯。）
- **走る**（はしる）跑｜韩语参考：뛰다（跑，奔跑） / 달리다（跑，奔跑，快跑）<br>
  例：あの走ってる少年をごらんなさい。（你看那个在跑的男孩。）
- **バター**（バター）黄油｜韩语参考：버터（黄油）<br>
  例：バターはミルクから出来る。（黄油是用牛奶做的。）
- **二十歳**（はたち）二十岁｜韩语参考：스무 살<br>
  例：ムーリエルは２０歳になりました。（缪里尔二十岁了。）
- **働く**（はたらく）工作｜韩语参考：일하다（工作）<br>
  例：スイッチは時間通りに働かなかった。（开关没有按时起作用。）
- **二十日**（はつか）二十天；二十号｜韩语参考：스무 날 / 이십 일<br>
  例：私は二十日までに帰るつもりです。（我打算二十号之前回去。）
- **花**（はな）花｜韩语参考：꽃（花，花朵）<br>
  例：テーブルの上に花が一本あります。（桌上有一枝花。）
- **鼻**（はな）鼻子｜韩语参考：코（鼻，鼻子）<br>
  例：鼻が出ているよ。かみなさい。（流鼻涕了，擤一擤。）
- **話**（はなし）话；故事｜韩语参考：말씀（话） / 얘기（故事） / 이야기（故事）<br>
  例：話を聞かせてくれ。（说给我听听。）
- **早い**（はやい）早；快｜韩语参考：빠르다（早） / 이르다（早）<br>
  例：時のたつのは早いものだ。（时间过得太快了。）
- **速い**（はやい）快；迅速｜韩语参考：빠르다（快，迅速）<br>
  例：ショットはとても速いものもある。（有些人的球速也非常快。）
- **春**（はる）春天｜韩语参考：봄（春，春天，春季）<br>
  例：カッコウは春にここにやってくる。（布谷鸟春天会来这里。）
- **貼る**（はる）贴；粘贴｜韩语参考：붙이다<br>
  例：その写真はアルバムに貼ったほうがよい。（那些照片最好贴到相册里。）
- **晴れ**（はれ）晴天｜韩语参考：맑은 날씨<br>
  例：ロンドンの天気は晴れです。（伦敦的天气是晴天。）
- **晴れる**（はれる）放晴；转晴｜韩语参考：개다（放晴） / 걷다（放晴） / 걷히다（放晴）<br>
  例：あした晴れてくれるといいなあ。（明天要是能放晴就好了。）

## 语法

- **〜より**：比…
  接续：名词 + より
  朝鲜语：보다（韩语 보다 与 より 对应，位置在比较对象后；日语 より 后直接接形容词，韩语 보다 后也直接接，语序相近。）
- **〜の方が〜より**：…比…更…
  接续：名词 + の方が + 名词 + より + 形容词
  朝鲜语：가/이 더 …（韩语用 이/가 더 表胜出项，보다 表基准；日语「の方が」是固定形式，不能换成 が。）
