今日语法 2 条

〜で（means）
발음〜데
用…；靠…；以…
名词（工具／手段／语言／材料）+ で
表示手段、工具、交通方式、语言或材料。
毎日電車で会社へ行きます。
每天坐电车去公司。
하시데고한오타베마스.
はしでご飯を食べます。
用筷子吃饭。
니혼고데테가미오카키마시타.
日本語で手紙を書きました。
我用日语写了信。
朝鲜语：로/으로（수단）
韩语 로/으로 表手段，与 で 对应；但日语 で 还表语言和材料，韩语语言用 로，材料常用 로 或 으로，范围相近。
易错点

毎日電車に会社へ行きます。 → 毎日電車で会社へ行きます。（交通手段用 で，に 表到达点）

〜と（and）
발음〜토
…和…（全部列举）
名词 + と + 名词（全部列举）
连接名词列举，可说「AとB」，也可在并列成分后重复と，如「AとBとが」。
카반노나카니펜토노오토가아리마스.
かばんの中にペンとノートがあります。
包里有笔和笔记本。
아사고한니판토타마고오타베마시타.
朝ご飯にパンとたまごを食べました。
早饭吃了面包和鸡蛋。
치치토하하와긴코우데하타라이테이마스.
父と母は銀行で働いています。
父亲和母亲在银行工作。
朝鲜语：와/과
韩语 와/과 与 と 对应，随收音换形；日语 と 还可表引用和共同对象，功能比韩语 와/과 更广。
易错点

かばんにペンととノートがあります。 → かばんにペンとノートがあります。（此处と是名词之间的并列助词，不重复写成「とと」。）
