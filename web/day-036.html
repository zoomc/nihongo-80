今日语法 3 条

受身形（～られる）
五段 う段→あ段+れる；一段 去る+られる；カ変 来られる；サ変 される
受身形（～られる）
被…／（迷惑）遭遇…
表被动；还有「迷惑受身」（雨に降られる）表受困扰，中文无此用法
雨に降られました。
被雨淋了（真倒霉）。
この本は多くの人に読まれています。
这本书被很多人读。
朝鲜语：-이/히/리/기 피동
韩语可用被动词尾、被动词或其他构式表达被动；遇到不愉快的事也可改述，日语有雨に降られる等受害被动。
易错点

雨が降られました。 → 雨に降られました。（迷惑受身用 に 标出处，が 错）

使役形（～せる／させる）
五段 う段→あ段+せる；一段 去る+させる；カ変 来させる；サ変 させる
使役形（～せる／させる）
让／使…（做）
表使役/强制/允许；他动词句使役对象用 に，自动词句用 を
先生は学生に本を読ませました。
老师让学生读书。
朝鲜语：-게 하다 / -시키다
韩语使役用게 하다或시키다，不区分自动他动的을/에게；日语せる/させる须分を/に。
易错点

先生は学生を本を読ませました。 → 先生は学生に本を読ませました。（他动词句已有 を 宾语，使役对象改用 に，不能两个 を）

～てみる / ～てしまう / ～ておく
動詞て形 + みる／しまう／おく
～てみる / ～てしまう / ～ておく
试着…／…完了／事先…
补助动词：てみる 尝试、てしまう 完了/遗憾、ておく 事先准备
この料理を食べてみます。
尝尝这道菜。
本を読んでしまいました。
把书看完了。
朝鲜语：-아/어 보다 / -아·어 버리다 / -아·어 두다
韩语分别用보다(尝试)、버리다(完了/遗憾)、두다(预先)，与日语三形基本对应。
易错点

食べてみる（写成 食べみる） → 食べてみます。（补助动词前必须 て形，漏 て 错）
