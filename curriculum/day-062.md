# Day 062 · ～によって / ～について / ～にとって、V辞書形 / Vない形 + ように する

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「～によって / ～について / ～にとって、V辞書形 / Vない形 + ように する」造两句自己的话，表达：因…而异／关于…／对…来说；努力做到…／设法不…（有意识地做）

## 新词 22

- **内容**（ないよう）内容｜韩语参考：내용（内容） / 내용물（内容物）<br>
  例：メールの内容を確認しました。（确认了邮件内容。）
- **情報**（じょうほう）信息；资讯｜韩语参考：정보（信息）<br>
  例：最新の情報を集めます。（收集最新信息。）
- **状態**（じょうたい）状态（事物/身体）｜韩语参考：상태（状态）<br>
  例：患者の状態が安定しています。（患者状态稳定。）
- **気持ち**（きもち）心情；感受；心意｜韩语参考：맘（心情，心绪） / 기분（心情） / 느낌（感觉，感受）<br>
  例：気持ちを言葉にするのは難しい。（把心情化成语言很难。）
- **気分**（きぶん）心情；身体状态；气氛｜韩语参考：맘（心情，心绪） / 기분（心情） / 마음（心情，心绪）<br>
  例：今日は気分が悪いです。（今天身体/心情不舒服。）
- **満足**（まんぞく）满足；满意｜韩语参考：만족（满足） / 흡족（满足，充足）<br>
  例：結果に満足しています。（对结果很满意。）
- **不満**（ふまん）不满；不满意｜韩语参考：불만（不满，不满意） / 불평（不满，牢骚）<br>
  例：給料に不満があります。（对工资有不满。）
- **不安**（ふあん）不安；担心｜韩语参考：불안（不安，不宁，担心）<br>
  例：試験の結果が不安です。（担心考试结果。）
- **残念**（ざんねん）遗憾；可惜｜韩语参考：유감（遗憾）<br>
  例：試合に負けて残念です。（输了比赛很遗憾。）
- **感動**（かんどう）感动｜韩语参考：감동（感动，打动）<br>
  例：映画を見て感動しました。（看了电影很感动。）
- **悩み**（なやみ）烦恼；苦恼｜韩语参考：고민（苦闷，苦恼，烦恼）<br>
  例：進路の悩みを相談します。（商量升学/出路的烦恼。）
- **嬉しい**（うれしい）高兴；开心｜韩语参考：기쁘다（高兴，开心） / 반갑다（高兴，开心，喜悦）<br>
  例：合格して嬉しいです。（考上了很开心。）
- **悲しい**（かなしい）悲伤；难过｜韩语参考：슬프다（悲伤的，伤心的） / 비감스럽다（悲伤，伤感）<br>
  例：別れは悲しいです。（离别令人难过。）
- **恥ずかしい**（はずかしい）害羞；难为情；惭愧｜韩语参考：수줍다（害羞，羞涩） / 부끄럽다（害羞，羞涩，腼腆） / 창피하다（丢脸，丢人，难为情，寒碜）<br>
  例：間違えて恥ずかしかったです。（弄错了，很不好意思。）
- **羨ましい**（うらやましい）羡慕｜韩语参考：부럽다（羡慕，眼馋） / 남부럽다（羡慕别人）<br>
  例：彼の語学力が羨ましいです。（羡慕他的语言能力。）
- **いただく**（いただく）承蒙给予；吃/喝（谦让语）｜韩语参考：받다 / 먹다（겸양어）<br>
  例：先生から資料をいただきました。（从老师那里拿到了资料。）
- **くださる**（くださる）给（我/我方）；赐予（尊敬语）｜韩语参考：주시다（높임）<br>
  例：先生が本をくださいました。（老师给了我一本书。）
- **さしあげる**（さしあげる）（谦让地）给；呈上｜韩语参考：드리다（겸양）<br>
  例：先生にお土産をさしあげました。（给老师送了土特产。）
- **いらっしゃる**（いらっしゃる）在/去/来（尊敬语）｜韩语参考：계시다 / 가시다 / 오시다（높임）<br>
  例：部長はもういらっしゃいますか。（部长已经到了吗？）
- **なさる**（なさる）做（尊敬语）｜韩语参考：하시다（높임）<br>
  例：部長が説明なさいました。（部长做了说明。）
- **おっしゃる**（おっしゃる）说（尊敬语）｜韩语参考：말씀하시다（높임）<br>
  例：先生がそうおっしゃいました。（老师是那样说的。）
- **伺う**（うかがう）拜访；请教；打听（谦让语）｜韩语参考：여쭤보다（请教，询问） / 찾아뵈다（拜访，看望） / 찾아뵙다（拜访，看望）<br>
  例：明日、先生の研究室に伺います。（明天去老师的研究室拜访。）

## 语法

- **～によって / ～について / ～にとって**：因…而异／关于…／对…来说
  接续：名詞 + によって／について／にとって
  朝鲜语：-에 따라 / -에 대해 / -에게（韩语에 따라表依据或随…而异，에 대해关于，에게表评价对象，三者分工比日语清楚。）
- **V辞書形 / Vない形 + ように する**：努力做到…／设法不…（有意识地做）
  接续：動詞 辞書形／ない形 + ように + する；する 按 サ変 变形（ようにしています／ようにした）
  朝鲜语：-도록 하다（韩语 -도록 하다 可表努力或指示；日语ようにする可用于自己的安排，也可用于要求他人注意。）
