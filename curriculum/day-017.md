# Day 017 · 〜に（frequency）、〜へ、〜で（place of action）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜に（frequency）**：每…（几次）
  接续：数量词 + に + 数量词（回数）
  朝鲜语：에（빈도）（한 달에 두 번 对照 一か月に二回。韩语口语也能省成 한 달 두 번，学习日语时先记住带 に 的完整频率句式。）
- **〜へ**：往…；朝…
  接续：名词（场所／方向）+ へ（读作 e）
  朝鲜语：로/으로（방향）（韩语 로/으로 与 へ 对应，随收音换形；日语 へ 读作 e，写法固定，不随名词变化。）
- **〜で（place of action）**：在…（做某事）
  接续：名词（场所）+ で
  朝鲜语：에서（동작 장소）（韩语 에서 与 で 对应，에 表存在；日语 で 与 に 的分工和韩语 에서 与 에 基本一致，较易迁移。）
