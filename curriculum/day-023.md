# Day 023 · 〜で（place of action）、〜で（means）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜で（place of action）、〜で（means）」造两句自己的话，表达：在…（做某事）；用…；靠…；以…

## 新词 20

- **生徒**（せいと）学生｜韩语参考：학생（学生）<br>
  例：この学校はたくさんの生徒がいます。（这所学校有很多学生。）
- **セーター**（セーター）毛衣｜韩语参考：스웨터（毛衣）<br>
  例：このセーターは気に入らない。（我不喜欢这件毛衣。）
- **せっけん**（せっけん）肥皂｜韩语参考：비누<br>
  例：せっけんだらけの手で私にさわらないで。（别用沾满肥皂的手碰我。）
- **背広**（せびろ）西装｜韩语参考：양복（西装）<br>
  例：私は新しい背広を買った。（我买了一套新西装。）
- **狭い**（せまい）窄｜韩语参考：좁다（窄，狭窄）<br>
  例：オランダは狭い国です。（荷兰是个狭小的国家。）
- **ゼロ**（ゼロ）零｜韩语参考：공（零） / 제로（零）<br>
  例：私たちは商売をゼロから始めなければならなかった。（我们的生意不得不从零开始。）
- **千**（せん）千｜韩语参考：천（千，一千）<br>
  例：このホールには人が二千人入れる。（这个大厅能容纳两千人。）
- **先月**（せんげつ）上个月｜韩语参考：지난달（上月，上个月）<br>
  例：先月は、ほとんど雨が降らなかった。（上个月几乎没下雨。）
- **先週**（せんしゅう）上周｜韩语参考：지난주（上周）<br>
  例：あの人は先週ここにいた人です。（那个人是上周在这里的人。）
- **全部**（ぜんぶ）全部｜韩语参考：전부（全部） / 다（全部，最好） / 몽땅（都，全部）<br>
  例：トッピングは全部のせて下さい。（配料请全部加上。）
- **そうして**（そうして）然后｜韩语参考：그리고<br>
  例：そうしてくださればとてもうれしい。（您要是那样做，我会非常高兴。）
- **そこ**（そこ）那里｜韩语参考：게（那儿，那里） / 거기（那儿，那边，那里） / 고기（那儿，那里）<br>
  例：バスでそこまで２時間かかります。（坐公交到那里要两个小时。）
- **そちら**（そちら）那边｜韩语参考：거기（那儿，那边，那里） / 고쪽（那边） / 그쪽（那边）<br>
  例：これとそちらとの違いは何だい。（这个和那个有什么区别？）
- **そっち**（そっち）那边｜韩语参考：고리（那边，那里） / 고쪽（那边） / 그쪽（那边）<br>
  例：そっちの天気は？（你那边天气怎么样？）
- **外**（そと）外面｜韩语参考：겉（外面，表面，表） / 밖（外面，外边） / 바깥（外，外面）<br>
  例：外に出してやってくれませんか。（能不能把它放到外面去？）
- **その**（その）那个｜韩语参考：고（那，那个） / 그（那个）<br>
  例：その本を見せてください。（请给我看看那本书。）
- **そば**（そば）旁边；附近｜韩语参考：곁 / 근처<br>
  例：ガレージは家のそばにあります。（车库在房子旁边。）
- **空**（そら）天空｜韩语参考：하늘（天空）<br>
  例：空はすっかりもやがかかっていた。（天空完全笼罩着雾霭。）
- **それ**（それ）那个｜韩语参考：거（那个） / 그（那样，那个） / 거기（那个）<br>
  例：わたしはそれを見てぎょっとした。（我看到那情景吓了一跳。）
- **それから**（それから）然后｜韩语参考：그리고 나서<br>
  例：それからすっきりきれいにしてくれ。（然后把它弄得干干净净。）

## 语法

- **〜で（place of action）**：在…（做某事）
  接续：名词（场所）+ で
  朝鲜语：에서（동작 장소）（韩语 에서 与 で 对应，에 表存在；日语 で 与 に 的分工和韩语 에서 与 에 基本一致，较易迁移。）
- **〜で（means）**：用…；靠…；以…
  接续：名词（工具／手段／语言／材料）+ で
  朝鲜语：로/으로（수단）（韩语 로/으로 表手段，与 で 对应；但日语 で 还表语言和材料，韩语语言用 로，材料常用 로 或 으로，范围相近。）
