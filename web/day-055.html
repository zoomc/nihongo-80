今日语法 3 条

V ます形(去ます) + 得る / V ない形(去ない) + ざるを 得ない
발음V 마스카타치 + 에루 / V 나이카타치 + 자루오 에나이
可能…、会有…／不得不…
動詞 ます形 去 ます + 得る（读 うる／える，否定 得ない えない）；動詞 ない形 去 ない + ざるを得ない（する→せざるを得ない 例外）
得る 表客观可能性（あり得る）；ざるを得ない 表「别无选择只好…」，书面
韩语对应-(으)ㄹ 수 있다 / -지 않을 수 없다
韩语可能用ㄹ 수 있다，不得不的用지 않을 수 없다或해야 한다；ざるを得ない更书面。
소노카노우세이 모 아리에마스.
その可能性もあり得ます。
那种可能性也存在。
덴샤 가 토마따노데, 아루이테카에라자루 오 에마센데시타.
電車が止まったので、歩いて帰らざるを得ませんでした。
电车停了，只好走路回去。

易错点 起こる得る → 起こり得ます／起こり得る（得る 接 ます形去ます（起こり得る），不接辞书形；中文「可能发生」直译错）

普通形 + 一方(で) / 反面 / 代わりに
발음〜이뽀우 / 〜함멘 / 〜카와리니
一方面…另一方面…／…但另一方面／取而代之、作为交换
動詞・い形普通形／な形容词 + な／名词 + である + 一方(で)・反面；名詞 + の／普通形 + 代わりに
一方で 并列同一事物的两面（可同褒贬）；反面 强调「反面/弊端」；代わりに 是替代或交换条件
韩语对应-는 한편 / -반면에 / -대신에
韩语는 한편表一方面、반면에表相反、대신에表代替，与日语三形对应整齐，반면对比更强。
코노시고토 와 큐우료우 가 타카이이뽀우 데, 잔교우 모 오오이데스.
この仕事は給料が高い一方で、残業も多いです。
这工作工资高，另一方面加班也多。
便利な反面、費用がかかります。
方便是方便，反面花费也高。

易错点 便利だ一方で、費用がかかります。 → 便利な一方で、費用がかかります。（な形/名词 接 一方で 用 便利な／である，不用 だ；中文「方便一方面」直译保留 だ 错）

V辞書形 / Nの + たびに
每当…就…；每次…都…
動詞辞書形 + たびに；名詞 + の + たびに（する名詞可直接 するたびに）
表示每次发生前项时，后项都随之发生；后项多为反复出现的习惯或自然结果，不用一次性的命令、请求。
韩语对应-(으)ㄹ 때마다
韩语때마다表每当，接名词或动词定语形；日语たびに只接辞书形或の，后项限制更严。
오오사카 에 슈쪼우스루타비 니, 코노미세 니 요리마스.
大阪へ出張するたびに、この店に寄ります。
每次去大阪出差，都会来这家店。
카이기 노 타비 니, 시료우 오 줌비시마스.
会議のたびに、資料を準備します。
每次开会都准备资料。

易错点 大阪へ出張するのたびに、この店に寄ります。 → 大阪へ出張するたびに、この店に寄ります。（辞书形后接 たびに 不加 の；の 只能接名词。中文“每次去…”直译容易多写の。）
