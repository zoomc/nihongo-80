## 新词 25

- **ああ**（ああ）啊；哦（感叹或回应）｜韩语参考：저렇게 / 저런<br>
  例：ああ、やっと着いた。（啊，终于到了。）
- **あいさつする**（あいさつする）打招呼；问候｜韩语参考：인사하다<br>
  例：私にあいさつするような人はいない。（没有人会跟我打招呼。）
- **間**（あいだ）之间；期间｜韩语参考：새（之间，以来） / 사이（间，之间，……的时候）<br>
  例：二人の間がしっくり行かない。（两人之间处得不太融洽。）
- **合う**（あう）合适；相符｜韩语参考：맞다（合适，合乎，对） / 합하다（符合，相符） / 맞아떨어지다（完全相符，正好，一点不差）<br>
  例：このチョッキは前が合わない。（这件背心前面扣不上。）
- **あかちゃん**（あかちゃん）婴儿；宝宝｜韩语参考：아기<br>
  例：その赤ちゃんは歯が生えはじめている。（那个宝宝开始长牙了。）
- **上がる**（あがる）上升；提高；（电池）没电（バッテリーが上がる）｜韩语参考：오르다（上升，上涨） / 상승하다（上升） / 올라가다（上升，提高）<br>
  例：車のバッテリーが上がってるよ。（车电瓶没电了。）
- **赤ん坊**（あかんぼう）婴儿｜韩语参考：아기（小孩，婴儿）<br>
  例：うちの赤ん坊は口をきくようになってきました。（我家宝宝开始会说话了。）
- **空く**（あく）空；有空｜韩语参考：비다（空）<br>
  例：放課後は空いてますか？（放学后有空吗？）
- **アクセサリー**（アクセサリー）首饰；配饰｜韩语参考：패물（首饰） / 장신구（首饰，装饰品） / 액세서리（饰品，首饰）<br>
  例：この服にはどんなアクセサリーを付けるの？（这身衣服配什么首饰？）
- **浅い**（あさい）浅；浅薄｜韩语参考：얇다（浅，淡） / 얕다（浅，低，矮） / 엷다（浅，薄）<br>
  例：この川はあそこで浅くなっている。（这条河在那里变浅了。）
- **味**（あじ）味道；口味｜韩语参考：맛（味，味道）<br>
  例：このチーズはピリッとした味がする。（这奶酪味道有点冲。）
- **アジア**（アジア）亚洲｜韩语参考：아시아（亚洲）<br>
  例：ヨーロッパはアジアより人口が少ない。（欧洲人口比亚洲少。）
- **明日**（あす）明天（比 あした 稍正式）｜韩语参考：낼（明天）<br>
  例：明日の会議は午前十時からです。（明天的会议从上午十点开始。）
- **遊び**（あそび）玩；游玩｜韩语参考：놀이（玩，玩法）<br>
  例：今度の旅行は仕事じゃなくて遊びです。（这次旅行不是出差，是去玩。）
- **集まる**（あつまる）聚集；集合｜韩语参考：모이다（被集，被聚，被聚集） / 모여들다（聚集）<br>
  例：通りに人がたくさん集まっている。（街上聚集了很多人。）
- **集める**（あつめる）收集；召集｜韩语参考：모으다（收集，收藏） / 모아들이다（召集，收集）<br>
  例：毎週月曜日にゴミを集めにきます。（每周一来收垃圾。）
- **アナウンサー**（アナウンサー）播音员｜韩语参考：아나운서（广播员，播音员）<br>
  例：アナウンサーは早口が出来る。（播音员能说得很快。）
- **アフリカ**（アフリカ）非洲｜韩语参考：아프리카（非洲）<br>
  例：アフリカにはたくさんの自然がある。（非洲有丰富的自然。）
- **アメリカ**（アメリカ）美国；美洲｜韩语参考：미국（美国） / 아메리카（美洲）<br>
  例：私は去年の秋にアメリカにいった。（我去年秋天去了美国。）
- **謝る**（あやまる）道歉｜韩语参考：사과하다（道歉）<br>
  例：私は彼女に謝らなければならない。（我必须向她道歉。）
- **アルコール**（アルコール）酒精｜韩语参考：알코올（酒精，乙醇）<br>
  例：このビールはアルコール分が５％だ。（这啤酒的酒精含量是5%。）
- **アルバイト**（アルバイト）打工；兼职｜韩语参考：알바（打工） / 아르바이트（打工）<br>
  例：週末は店でアルバイトをしています。（周末在店里打工。）
- **安全**（あんぜん）安全｜韩语参考：안전（安全）<br>
  例：私たちは思っているほど安全ではない。（我们并没有想的那么安全。）
- **あんな**（あんな）那样的｜韩语参考：저런（那样的） / 저만（那样的） / 조런（那样的）<br>
  例：あんないい男そうそういないぞ！！（那么好的男人可不多见！！）
- **案内**（あんない）向导；引导｜韩语参考：안내（带路，带领，向导）<br>
  例：私をあちこちに案内してください。（请带我到处转转。）

## 语法

- **～そうです（样态／传闻）**：看起来…／听说…
  接续：样态：ます形词干/い形去い/な形词干 + そう；传闻：普通形 + そうです
  朝鲜语：-아/어 보이다 / -다고 하다（韩语样态用아/어 보이다，传闻用다고 하다，形态完全不同；日语そうだ须按接续分辨。）
- **～ようだ / ～らしい**：好像…／似乎…（推测）
  接续：普通形 + ようだ／らしい（名 + の + ようだ）
  朝鲜语：-(으)ㄴ 것 같다 / -(으)ㄴ 모양이다（韩语推测最常用것 같다，传闻典型用다고 하다；日语ようだ主观、らしい客观传闻。）
- **～かもしれない / ～でしょう**：也许…／大概…吧
  接续：动词、い形容词普通形 + かもしれない／でしょう；名词、な形容词的非过去肯定词干直接接。
  朝鲜语：-(으)ㄹ지도 모르다 / -겠다（눈일지도 몰라요 对应 雪かもしれません，눈일 거예요 可对照 雪でしょう。名词「雪」后直接加表达，常见错误是多加一个 だ。）
