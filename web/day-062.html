今日语法 3 条

Nの / Vている + 最中に（だ）
발음〜사이추우니
正在…的时候（突然…）
名詞 + の + 最中に；動詞ている + 最中に；句末可 最中だ
强调某动作/状态正进行到一半时，发生了另一件事，后项常是打扰或意外。
카이기노사이추우니,덴와가나리마시타.
会議の最中に、電話が鳴りました。
正在开会时电话响了。
ご飯の最中に、突然停電しました。
正吃饭时突然停电了。
朝鲜语：-는 중에 / -는 도중에
韩语는 중表正在，도중에表途中；日语最中に强调正到一半被打断，语感更强。
易错点

会議の最中を、電話が鳴りました。 → 会議の最中に、電話が鳴りました。（最中 后接时间点用 に，不用 を；中文“在会议中”直译成 を。）

Vた形 + ところで
발음V타카타치 + 토코로데
即使…也（不会有预期结果）
動詞た形 + ところで；后项多为否定或无意义的结果
表示即使前项成立，后项也不会改变；常与「無駄だ／変わらない／〜ない」呼应。
今更謝ったところで、間に合いません。
事到如今再道歉也来不及了。
何度説明したところで、彼は分からないでしょう。
即使说明多少次，他也不会明白吧。
朝鲜语：-아/어도 / -더라도
韩语让步用아/어도，强调用더라도；日语ところで后项必为否定性结果，韩语无此限制。
易错点

何度説明するところで、彼は理解しないでしょう。 → 何度説明したところで、彼は理解しないでしょう。（ところで（即使）接た形，不接辞书形；中文“即使说明”直译用原形。）

普通形 + ものだから / もので
因为…（所以…）；由于…
動詞・い形 普通形 + ものだから；な形・名詞 + な/だ + ものだから；もので 更书面
用于说明原因，常带辩解/道歉语气；后项多为自己的行为或请求，不用于客观叙述自然现象。
朝寝坊したものだから、電車に遅れました。
因为睡过头，所以没赶上电车。
니혼고가와카라나이모노데스카라,유꾸리하나시테쿠다사이.
日本語が分からないものですから、ゆっくり話してください。
因为我不懂日语，请说慢一点。
朝鲜语：-는 바람에 / -기 때문에
韩语辩解多用는 바람에(多坏事)或기 때문에；日语ものだから带撒娇式辩解，韩语靠语调体现。
易错点

忙しいだものだから、行けません。 → 忙しいものだから、行けません。（い形「忙しい」后不能加 だ；ものだから 直接接普通形。中文“因为忙”直译容易保留“是”。）
