# Day 041 · 通知与手续｜～てみる / ～てしまう / ～ておく、授受 ～てあげる／てくれる／てもらう

- 阶段：P1｜60 分钟｜常规日
- Can-do：在「通知与手续」场景里，用 ～てみる / ～てしまう / ～ておく 说清一件事

## 新词 20

- **以下**（いか）以下｜朝鲜语：이하  
  例：それは千円以下では買えません。（那个一千日元以下买不到。）
- **以外**（いがい）以外；除…之外｜朝鲜语：이외  
  例：その仕事以外ならなんでもやる。（除了那份工作，什么都行。）
- **医学**（いがく）医学｜朝鲜语：의학  
  例：二人の医者が医学の話をしていた。（两位医生在聊医学方面的事。）
- **生きる**（いきる）活；生存  
  例：生きるものはすべていつかは死ぬ。（所有活着的生物终有一死。）
- **意見**（いけん）意见；看法｜朝鲜语：의견  
  例：ここではどんどん意見をおっしゃってかまいません。（在这里可以尽管提意见。）
- **石**（いし）石头  
  例：私にはこの石は持ち上がらない。（这块石头我举不起来。）
- **いじめる**（いじめる）欺负；捉弄  
  例：彼はよく友人をいじめたものだ。（他以前常欺负朋友。）
- **以上**（いじょう）以上；就这些｜朝鲜语：이상  
  例：以上ですか？（就这些吗？）
- **急ぐ**（いそぐ）赶紧；着急  
  例：ニックはバスに間に合うように急いだ。（尼克为了赶上公交加快了脚步。）
- **致す**（いたす）做（谦让语）  
  例：お取り寄せいたしましょうか。（要我帮您订购吗？）
- **一度**（いちど）一次；一遍  
  例：人間はこの世に一度しか生きない。（人在这世上只能活一次。）
- **一生懸命**（いっしょうけんめい）拼命；努力  
  例：もっと一生懸命勉強すべきだったのに。（本应该更拼命学习的。）
- **いっぱい**（いっぱい）满；很多  
  例：このボトルに水をいっぱい入れてください。（请把这个瓶子装满水。）
- **糸**（いと）线；丝  
  例：長い糸はからまりやすい。（长线容易缠在一起。）
- **以内**（いない）以内｜朝鲜语：이내  
  例：１週間以内に電話します。（一周内给你打电话。）
- **田舎**（いなか）乡下；老家  
  例：去年の夏、父の田舎に行きました。（去年夏天去了父亲的老家。）
- **祈る**（いのる）祈祷；祝愿  
  例：早くよくなられるように祈っています。（盼望您早日康复。）
- **植える**（うえる）种植  
  例：私は庭にバラを植えた。（我在院子里种了玫瑰。）
- **うかがう**（うかがう）拜访；请教  
  例：体重をおうかがいしてもよろしいですか。（可以问一下您的体重吗？）
- **受ける**（うける）接受；参加（考试）  
  例：病気なので試験が受けられません。（因为生病，没法参加考试。）

## 语法

- **～てみる / ～てしまう / ～ておく**：试着…／…完了／事先…
  接续：動詞て形 + みる／しまう／おく
  朝鲜语：-아/어 보다 / -아·어 버리다 / -아·어 두다（韩语分别用보다(尝试)、버리다(完了/遗憾)、두다(预先)，与日语三形基本对应。）
- **授受 ～てあげる／てくれる／てもらう**：给（别人）做…／给（我）做…／请（人）做…
  接续：動詞て形 + あげる／くれる／もらう
  朝鲜语：-아/어 주다 / -아·어 받다（韩语只用주다(给)与받다(受)，无あげる/くれる/もらう的方向三分；敬语用드리다/주시다。）
