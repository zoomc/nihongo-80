# Day 114 · 〜として、〜にとって

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜として、〜にとって」造两句自己的话，表达：作为…；以…身份；对…来说

## 新词 19

- **コンピューター**（コンピューター）电脑｜韩语参考：컴퓨터（电脑）<br>
  例：そのコンピューターは新しいです。（那台电脑是新的。）
- **婚約**（こんやく）婚约；订婚｜韩语参考：약혼（订婚） / 정혼（订婚） / 혼약（婚约，订婚）<br>
  例：とうとう私の姉は婚約した。（我姐姐终于订婚了。）
- **混乱**（こんらん）混乱｜韩语参考：혼란（混乱，杂乱）<br>
  例：国会は混乱のうちに散会した。（国会在混乱中散会了。）
- **差**（さ）差距｜韩语参考：차이<br>
  例：やつらに実力の差を見せ付けてやった。（我让那帮人见识了实力上的差距。）
- **サービス**（サービス）服务｜韩语参考：서비스（服务）<br>
  例：あの店はサービスが良い。（那家店服务很好。）
- **際**（さい）之际；时候｜韩语参考：결（时候，之中） / 즘（之际） / 차（刚好……的时候）<br>
  例：火事の際は１１９番に電話してください。（发生火灾时请拨打119。）
- **最高**（さいこう）最高；最棒｜韩语参考：최고（最高） / 최상（最高，最好）<br>
  例：彼は現存する最高の芸術家である。（他是当今最伟大的艺术家。）
- **財産**（ざいさん）财产｜韩语参考：재산（财产） / 자산（资产，财产）<br>
  例：ミスで財産を失った。（因为一个失误，我失去了财产。）
- **最終**（さいしゅう）最终；最后｜韩语参考：최종（最终） / 끝（完，到头，最后） / 최후（最后）<br>
  例：最終電車はいつ出ますか。（末班电车几点开？）
- **最中**（さいちゅう）正在…之中｜韩语参考：한창 ~하는 중<br>
  例：彼はスピーチの最中に気を失った。（他在演讲当中昏了过去。）
- **最低**（さいてい）最低；最差｜韩语参考：최저（最低）<br>
  例：私は最低２マイルは歩ける。（我至少能走两英里。）
- **才能**（さいのう）才能｜韩语参考：재능（才能） / 능력（能力，才能） / 재주（才干，才能，本事，本领）<br>
  例：君には音楽の才能がある。（你有音乐才能。）
- **裁判**（さいばん）审判；官司｜韩语参考：재판（审判，裁判）<br>
  例：裁判は公明正大であることが要求される。（审判要求公正无私。）
- **材料**（ざいりょう）材料｜韩语参考：재료（材料） / 기삿거리（新闻素材，新闻材料）<br>
  例：すぐれた材料で作られた家具は、売れ行きがよい。（用好材料做的家具很畅销。）
- **幸い**（さいわい）幸运；幸好｜韩语参考：행（幸运）<br>
  例：あなたがここに居たのは幸いでした。（幸好你当时在这儿。）
- **サイン**（サイン）签名｜韩语参考：서명（署名，签名）<br>
  例：ここにサインをお願いします。（请在这里签名。）
- **境**（さかい）边界；交界｜韩语参考：접경（交界）<br>
  例：彼は生死の境をさ迷った。（他在生死之间徘徊。）
- **逆らう**（さからう）违抗；逆着｜韩语参考：거스르다（违抗，违背）<br>
  例：彼は世の風潮に逆らう。（他逆时代潮流而行。）
- **盛り**（さかり）鼎盛期；正当时｜韩语参考：한창때 / 절정<br>
  例：彼は今男盛りだ。（他正处在男人的壮年。）

## 语法

- **〜として**：作为…；以…身份
  接续：名词 + として；名词 + としての + 名词
  朝鲜语：-로서（韩语「-로서」表资格，与「として」对应；但韩语另有「-로써」表手段，日语「として」不表手段，切勿混用。）
- **〜にとって**：对…来说
  接续：名词 + にとって；名词 + にとっての + 名词
  朝鲜语：-에게 있어서（韩语「-에게 있어서」同样表立场，但较长、偏书面；日语「にとって」口语也常用，后项多接评价性表达。）
