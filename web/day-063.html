今日语法 3 条

普通形 + からこそ
正因为…才…
動詞・い形 普通形 + からこそ；な形・名詞 + だ + からこそ
强调前项是后项成立的关键原因，常与「〜のだ／〜のです」呼应。
스키다카라코소,키비시쿠이우노데스.
好きだからこそ、厳しく言うのです。
正因为喜欢，才严格地说。
이소가시이카라코소,지칸노쓰카이카타오칸가에루히쓰요우가아리마스.
忙しいからこそ、時間の使い方を考える必要があります。
正因为忙，才需要思考如何使用时间。
朝鲜语：-니까 / -기 때문에야말로
韩语强调正因为用니까加야말로，或기 때문이다；无单一固定形，须组合表达。
易错点

好きだからこそで、続けられます。 → 好きだからこそ、続けられます。（からこそ 后不接 で；中文“正因为喜欢”直译加 で。）

N / 普通形 + ばかりか
不仅…而且…
名詞 + ばかりか；動詞・い形 普通形 + ばかりか；な形・名詞 + な/である + ばかりか
前项已成立，后项进一步追加，常与「も／まで」呼应；后项多比前项程度更高。
코노미세와야스이바카리카,아지모오이시이데스.
この店は安いばかりか、味も美味しいです。
这家店不仅便宜，味道也好。
카레와시고토바카리카,카지모요쿠테쓰다이마스.
彼は仕事ばかりか、家事もよく手伝います。
他不仅工作，还经常帮忙做家务。
朝鲜语：-(으)ㄹ 뿐만 아니라
韩语뿐만 아니라表不仅而且，后项可同程度；日语ばかりか后项常程度更高，还可接まで/も。
易错点

英語のばかりか、中国語も話せます。 → 英語ばかりか、中国語も話せます。（名词接 ばかりか 不加 の；中文“不仅英语”直译加 の。）

Vます形(去ます) + ようがない / ようもない
발음V마스카타치 + 요우가나이 / 요우모나이
无法…；没有办法…
動詞ます形去ます + ようがない；する→しようがない；句末 ようがありません
表示想做但客观上没有手段/方法，不是能力不足；常与「〜たくても」呼应。
나마에모주우쇼모와카라나이노데,렌라쿠시요우가아리마센.
名前も住所も分からないので、連絡しようがありません。
姓名和住址都不知道，所以没法联系。
덴겐가하이라나이노데,나오시요우가아리마센.
電源が入らないので、直しようがありません。
电源打不开，所以没法修。
朝鲜语：-(으)ㄹ 방법이 없다
韩语ㄹ 방법이 없다表无手段，与能力不足的ㄹ 수 없다区分；同日语ようがない与できない之别。
易错点

名前も分からないので、連絡するようがありません。 → 連絡しようがありません。（ようがない 接ます形去ます（し），不接辞书形；中文“没有办法联系”直译错。）
