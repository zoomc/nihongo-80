# 120 天怎么学

Day 1–30 打 N5 基础，Day 31–60 学 N4，Day 61–120 学 N3。前 3 天加入假名和拍子听辨。全程保留 45 篇精听、10 次分级精读和每 5 天一次复习。

打开线上首页，点「开始或继续学习」。网页只给资源，会话负责答疑、纠错和逼你输出。

## 网页：四个内容块 + 一个完成按钮

1. **今日复习**：课程复习清单，每行有日文、小假名、中文，以及「忘了 / 不熟 / 记得」三个小按钮。先回忆再核对，自评会随学习情况一起保存。
2. **今日新词**：所有新词（含选学拓展）直接列出，不翻页。中文上方有小假名，词形带 ruby 注音；每条例句有「朗读例句」。用本模块右上角的开关遮中文、遮日语或双向，点模糊处可临时揭开。
3. **今日语法**：句型、接续、中文释义、朝鲜语对照、例句与易错点。它也有自己的遮挡开关，和新词互不影响。
4. **练习**：题目一次列完，优先做前 9–12 道基础题，不翻页、不分段、没有「再练 n 题」。按知识点去重（每点最多 2 题），覆盖当天全部新词与全部新语法。听力日的音频、脚本和 3 道听力题也在这一块里。点选项即时判分，答错会把正确项标绿。

到底部点**「完成」**。它会把当天答题明细、正确率、错题、自评上报云端，**页面上没有任何学习口令或导出按钮**。断网时记录留在本机，按钮会提示重试。

## 会话：每天开新会话，先跑一条命令

新会话不知道昨天学到哪，也不需要你告诉它——固定第一步：

```sh
python3 scripts/today.py
```

它合并本机 `data/state.db` 的 finish-day 与云端「完成」快照，算出今天该学哪天、上次卡在哪，写 `TODAY.md`（同时刷新 `STATE.md` 和当天 `brief.md`）。会话读 `TODAY.md`，按里面的「会话怎么做」执行即可。云端不通加 `--offline`；回看旧课用 `--day N`。

网页保存的是**自报快照**，用于让会话快速知道你今天学了什么、错在哪；它不是掌握判定，也不等于「已达标」。

```sh
# 会话开始前：读取云端进度（密钥自动从 deploy/.sync-key 读，不打印）
python3 scripts/progress_read.py --latest
python3 scripts/progress_read.py --day 47 --json
```

然后按 [`skills/nh80-progress/SKILL.md`](../skills/nh80-progress/SKILL.md) 把「错题优先 + 自评忘了/不熟优先 + 当天新词与语法」整理成今天的复习重点，再开始答疑、追问和造句。

WorkBuddy / Claude Code / Codex 都能用：只要能读仓库文件、跑 Python。Skill 已同时放在仓库内、项目级 `.workbuddy/skills/` 与用户级 `~/.workbuddy/skills/`。

本机 `data/state.db`（只经 `python3 scripts/nh80.py finish-day` 写入）才是掌握与 FSRS 的权威，agent 只读云端、不回写、不据此宣布达标。主会话与每日会话仍用 `STATE.md` / `days/day-NNN/brief.md` / `report.md` 的文件协议。

## 听力与 N3 检验

每日精听是 45 篇原创文本的合成语音。[真人听力页](../web/listening.html) 有 4 条开放许可音频可在本页播放，以及官方样题、Irodori、Erin、NHK、免费播客的分阶段入口（跳转原站，本站不托管第三方音频）。

周测与阶段题用于发现薄弱项；Day 90、100、110 分别练官方词汇、语法、阅读与听力题型，Day 120 安排课外计时自测。本站原创建议题不冒充官方卷，也不换算官方标准分。
