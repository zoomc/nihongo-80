## 新词 25

- **すぐ**（すぐ）马上；立刻；就近｜韩语参考：곧（马上，就） / 금방（马上，立刻，立马） / 당장（当前，立刻）<br>
  例：すぐ行きます。（马上就去。）
- **ゆっくり**（ゆっくり）慢慢地；好好地｜韩语参考：천천히（慢慢地，缓慢地） / 슬렁슬렁（慢慢地，轻轻地）<br>
  例：ゆっくり話してください。（请慢慢说。）
- **会う**（あう）见面｜韩语参考：보다（看，见，见面） / 만나다（见面，相逢）<br>
  例：もうスミスさんに会われましたね。（您已经见过史密斯先生了吧。）
- **青**（あお）蓝色；青色｜韩语参考：파랑 / 푸른색<br>
  例：信号が青に変わったわよ。（信号灯变绿了。）
- **青い**（あおい）蓝色的；不成熟｜韩语参考：파랗다 / 미숙하다<br>
  例：お前はまだ「青い」な。（你还嫩着呢。）
- **赤**（あか）红色｜韩语参考：빨강（红色，红色染料） / 붉은색（红色） / 빨간색（红色）<br>
  例：赤インクで書いてはいけない。（不能用红墨水写。）
- **赤い**（あかい）红色的｜韩语参考：빨갛다<br>
  例：彼女は赤いスカートをはいていた。（她穿着一条红裙子。）
- **明るい**（あかるい）明亮；开朗｜韩语参考：밝다（明亮） / 환하다（明亮，亮，亮堂）<br>
  例：外はだんだん明るくなっていく。（外面渐渐亮了起来。）
- **秋**（あき）秋天｜韩语参考：가을（秋天，秋季） / 가을날（秋日，秋天） / 가을철（秋季，秋天）<br>
  例：秋はもうすぐそこまで来ている。（秋天马上就要到了。）
- **開く**（あく）开；打开｜韩语参考：열리다（开）<br>
  例：ぐいと押すとドアは開いた。（用力一推，门就开了。）
- **開ける**（あける）打开｜韩语参考：열다（打开）<br>
  例：ドアはジムによって開けられます。（门被吉姆打开了。）
- **上げる**（あげる）举起；给｜韩语参考：주다（给予，给） / 쳐들다（举起，抬起，撑起） / 추켜들다（高举，举起）<br>
  例：左手を上げなさい。（把左手举起来。）
- **朝ごはん**（あさごはん）早饭｜韩语参考：아침밥<br>
  例：朝ごはんにはなにがよろしいですか。（早饭您想吃点什么？）
- **あさって**（あさって）后天｜韩语参考：모레<br>
  例：あさって彼にここへ来てもらうつもりです。（打算后天让他来这儿。）
- **足**（あし）脚；腿｜韩语参考：굽（底座，脚） / 발（足，脚） / 다리（腿，下肢）<br>
  例：また足がしびれた。（脚又麻了。）
- **あそこ**（あそこ）那里｜韩语参考：게（那儿，那里） / 거기（那儿，那里） / 고기（那儿，那里）<br>
  例：先生、アソコがかゆいんです。（医生，我那儿痒。）
- **遊ぶ**（あそぶ）玩；游玩｜韩语参考：놀이하다（玩耍，玩）<br>
  例：ビルはよく一人でおもちゃで遊ぶ。（比尔常一个人玩玩具。）
- **暖かい**（あたたかい）温暖｜韩语参考：따습다（温暖） / 따사롭다（温暖，暖洋洋，暖融融） / 따스하다（温暖，和煦）<br>
  例：だんだん暖かくなります。（天渐渐暖和起来。）
- **あちら**（あちら）那边；那位｜韩语参考：고쪽（那里，那边） / 그쪽（那里，那边）<br>
  例：こっちの本はあっちの本よりやさしい。（这边的书比那边的书容易。）
- **厚い**（あつい）厚；深厚｜韩语参考：두껍다（厚，深厚） / 두텁다（厚，笃厚）<br>
  例：それは４ｃｍの厚さです。（那有4厘米厚。）
- **暑い**（あつい）热｜韩语参考：덥다（热，暑）<br>
  例：どうして、こんなに暑いのですか。（为什么这么热呢？）
- **熱い**（あつい）烫；热｜韩语参考：덥다（温，热，热乎乎） / 뜨겁다（烫，热）<br>
  例：熱いコーヒーを入れてあげましょう。（我给你冲杯热咖啡吧。）
- **あっち**（あっち）那边｜韩语参考：고쪽（那里，那边） / 그쪽（那里，那边）<br>
  例：こっちの本はあっちの本よりやさしい。（这边的书比那边的书容易。）
- **あの**（あの）那个｜韩语参考：그（那个） / 어（那个） / 조（那个）<br>
  例：あのおいしいワインをなぜ飲まないんだい。（为什么不喝喝那瓶好酒呢。）
- **アパート**（アパート）公寓｜韩语参考：아파트（公寓）<br>
  例：兄はアパートをさがしています。（哥哥在找公寓。）

## 语法

- **（场所）に ～ がある / いる**：（某地）有…
  接续：場所 + に + 物/人 + が + ある／いる
  朝鲜语：에 ~ 이/가 있다 / 계시다（韩语存在动词不分有无生命，一律있다，敬语用계시다；日语必须分ある/いる。）
- **い形容词（～い です）**：…（い形容词谓语）
  接续：い形容詞 + です
  朝鲜语：형용사 어간 + 다 / -아·어요（韩语形容词作谓语要加终结词尾，敬语靠어요/습니다；日语い形直接加です。）
- **な形容词（～です）**：…（な形容词谓语）
  接续：な形容詞語幹 + です／だ
  朝鲜语：형용사(하다형)（韩语 하다 类形容词修饰名词时通常变成 -한，如 조용한 방；日语な形容词连体用 な。）
