## 3. 新语法（含先修）
- `G0071` **普通形 + わけが ない / V辞書形 + わけには いかない** — 不可能…／不能…、不好…｜接续：普通形 + わけがない（强烈否定可能性）；辞書形 + わけにはいかない（因情理/规则不能做）
- `G0072` **普通形 + と は 限らない** — 未必…；不一定…；不见得…｜接续：動詞・い形 普通形 / 名詞・な形（＋だ 常省）+ とは 限らない；常与 必ずしも／すべて／〜からといって 呼应

## 4. 新汉字（中日差异）
- `K0120` **技** 音:ギ 训:わざ｜中文「技」jì；日语 技 音读 ギ（技術 ぎじゅつ）、训读 わざ（技）；「技術」是「技术」，与中文义近但读音完全不同，须按 ギ 验证，不能按中文 jì 推。
- `K0121` **術** 音:ジュツ 训:｜中文「术」shù；日语 術 音读 ジュツ（技術 ぎじゅつ、手術 しゅじゅつ，入声 -ツ）；简体「术」与「術」字形差异大，不可按中文形推，此字无常用训读。
