# Day 052 · 〜間 / 〜間に、〜そうだ（appearance）

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜間 / 〜間に、〜そうだ（appearance）」造两句自己的话，表达：在…期间；在…期间内；看起来…；好像要…

## 新词 14

- **しかる**（しかる）责备<br>
  例：親は子供が悪さをするのをしかる。（孩子做坏事父母会责备。）
- **試験**（しけん）考试｜朝鲜语：시험<br>
  例：とにかく、試験が終わってほっとしたよ。（总之，考完试松了口气。）
- **地震**（じしん）地震｜朝鲜语：지진<br>
  例：地震のときにはガスを止めなさい。（地震时要关掉煤气。）
- **時代**（じだい）时代｜朝鲜语：시대<br>
  例：大学時代に私は英字新聞をとっていた。（大学时我订过英文报纸。）
- **下着**（したぎ）内衣<br>
  例：私は新しい下着が気に入っている。（我很喜欢新买的内衣。）
- **支度**（したく）准备<br>
  例：すぐに旅の支度をしなさい。（赶紧准备旅行的东西。）
- **失敗**（しっぱい）失败｜朝鲜语：실패<br>
  例：１度や２度の失敗はだれにでもある。（一两次失败谁都会有。）
- **辞典**（じてん）辞典｜朝鲜语：사전<br>
  例：私はいつも辞典を３冊手元に置いています。（我手边总放着三本辞典。）
- **品物**（しなもの）物品<br>
  例：これらの品物は非売品です。（这些物品是非卖品。）
- **しばらく**（しばらく）暂时<br>
  例：ここしばらく彼にまるで会わない。（最近一直没见到他。）
- **島**（しま）岛<br>
  例：その島にはとても近づきにやすい。（那座岛很容易靠近。）
- **市民**（しみん）市民｜朝鲜语：시민<br>
  例：私は千葉市民ですが、東京で勤めています。（我是千叶市民，在东京上班。）
- **事務所**（じむしょ）事务所｜朝鲜语：사무소<br>
  例：私のおじはこの事務所で働いている。（我叔叔在这家事务所工作。）
- **社会**（しゃかい）社会｜朝鲜语：사회<br>
  例：彼の一生は社会の下積みで終わった。（他一生在社会底层度过。）

## 语法

- **〜間 / 〜間に**：在…期间；在…期间内
  接续：动词ている形／动词辞书形／名词+の + 間（に）
  朝鲜语：-는 동안（韩语 -는 동안 对应 間，-는 동안에 对应 間に；但日语 間に 的后项多为一次性动作，韩语 에 的区分没有这么严格。）
- **〜そうだ（appearance）**：看起来…；好像要…
  接续：动词ます形去ます／い形容词去い／な形容词词干 + そうだ
  朝鲜语：-아/어 보이다（韩语 -아/어 보이다 表外观，但与日语 そうだ 不同，不能用于「即将发生」的预测；那种场合韩语用 -(으)ㄹ 것 같다。）
