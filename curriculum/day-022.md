# Day 022 · 〜で（means）、〜と（and）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜で（means）、〜と（and）」各造一句自己的话，表达：用…；靠…；以…；…和…（全部列举）

## 新词 23

- **戸**（と）日式拉门｜韩语参考：미닫이문<br>
  例：誰かが戸をやかましくノックしている。（有人在使劲敲门。）
- **ドア**（ドア）门｜韩语参考：문（门）<br>
  例：入る前にドアをノックして下さい。（进来之前请先敲门。）
- **トイレ**（トイレ）厕所｜韩语参考：변소（厕所）<br>
  例：トイレの水が止まりません。（厕所的水关不上了。）
- **どう**（どう）怎样｜韩语参考：어떻게 / 어떻다<br>
  例：日本の生活はどうですか。（在日本的生活怎么样？）
- **どうして**（どうして）为什么｜韩语参考：왜（为什么） / 웬（什么，哪儿来的） / 무슨（什么）<br>
  例：どうしてあなたは一人になったの？（你怎么会变成一个人了？）
- **どうぞ**（どうぞ）请｜韩语参考：어서（请，快）<br>
  例：写真をどうぞ見せて下さい。（请把照片给我看看。）
- **どうぞよろしく**（どうぞよろしく）请多关照｜韩语参考：잘 부탁합니다<br>
  例：どうぞよろしく。（请多关照。）
- **動物**（どうぶつ）动物｜韩语参考：동물（动物）<br>
  例：私はその動物の名前を知っている。（我知道那种动物的名字。）
- **どうも**（どうも）谢谢；似乎｜韩语参考：고맙습니다 / 아무래도<br>
  例：あの二人はどうもできているらしい。（那两个人好像在一起了。）
- **遠い**（とおい）远｜韩语参考：멀다（远）<br>
  例：それはホテルから遠くありません。（那里离酒店不远。）
- **十日**（とおか）十天；十号｜韩语参考：열흘（十天）<br>
  例：ジャックは８月１０日に生まれた。（杰克出生在八月十号。）
- **どこ**（どこ）哪里｜韩语参考：어디（哪里，哪儿）<br>
  例：あなたはどこでテレビを見ますか。（你在哪里看电视？）
- **所**（ところ）地方｜韩语参考：곳 / 장소<br>
  例：どんな所でアルバイトできるの。（能在什么地方打工？）
- **年**（とし）年；年龄｜韩语参考：해（年） / 나이（年龄，年纪，岁数） / 춘추（年）<br>
  例：お年をお聞きしてよろしいでしょうか。（可以问一下您的年龄吗？）
- **どちら**（どちら）哪个｜韩语参考：어느 쪽<br>
  例：二つのうちでどちらが高いですか。（两个当中哪个贵？）
- **どっち**（どっち）哪个｜韩语参考：어느 쪽（구어）<br>
  例：この本とあの本とどっちがやさしい？（这本书和那本书哪个更容易？）
- **どなた**（どなた）哪位｜韩语参考：어느 분<br>
  例：「どなたですか」「お母さんよ」（“是哪位？”“是妈妈呀。”）
- **隣**（となり）旁边；隔壁｜韩语参考：옆（旁，旁边） / 옆집（邻居，隔壁）<br>
  例：あのビルのとなりです。（在那栋楼旁边。）
- **どの**（どの）哪个｜韩语参考：어느（哪，哪个）<br>
  例：これはほかのどの木よりも高い。（这棵树比别的任何树都高。）
- **飛ぶ**（とぶ）飞｜韩语参考：날다（飞，飞行，飞翔）<br>
  例：ヒューズが飛んだ。（保险丝烧断了。）
- **止まる**（とまる）停止｜韩语参考：멎다（停，停止） / 자다（停，停止） / 그치다（停止，结束）<br>
  例：ちょうどその時バスが止まった。（正好那时公交车停了。）
- **鳥**（とり）鸟｜韩语参考：새（鸟）<br>
  例：なんてきれいな鳥なんだろう。（多漂亮的鸟啊。）
- **鶏肉**（とりにく）鸡肉｜韩语参考：닭고기<br>
  例：鶏肉を３ポンド分ください。（请给我三磅鸡肉。）

## 语法

- **〜で（means）**：用…；靠…；以…
  接续：名词（工具／手段／语言／材料）+ で
  朝鲜语：로/으로（수단）（韩语 로/으로 表手段，与 で 对应；但日语 で 还表语言和材料，韩语语言用 로，材料常用 로 或 으로，范围相近。）
- **〜と（and）**：…和…（全部列举）
  接续：名词 + と + 名词（全部列举）
  朝鲜语：와/과（韩语 와/과 与 と 对应，随收音换形；日语 と 还可表引用和共同对象，功能比韩语 와/과 更广。）
