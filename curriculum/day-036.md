# Day 036 · 〜ようだ、〜みたい、〜すぎる

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ようだ**：好像…；似乎…
  接续：动词普通形／い形容词 + ようだ；な形容词+な／名词+の + ようだ
  朝鲜语：-(으)ㄴ/는 것 같다（지금 집에 없는 것 같다 对照 今は留守のようだ。日语名词接 ようだ 要加 の；口语换成 みたいだ 时去掉 の。）
- **〜みたい**：好像…；像…一样
  接续：动词普通形／い形容词／な形容词词干／名词 + みたいだ（口语）
  朝鲜语：-(으)ㄴ/는 것 같다 / 처럼（推测可说 …인 것 같다，比喻可说 …처럼／…같다。日语名词直接接 みたい；修饰另一个名词用 みたいな，修饰动作或状态用 みたいに。）
- **〜すぎる**：过于…；…过头
  接续：动词ます形去ます／い形容词去い／な形容词词干 + すぎる
  朝鲜语：너무 …하다（韩语用「너무」+形容词，位置在词前；日语 すぎる 是后缀，接在词干后，且可用于动词（食べすぎる），韩语需说 너무 많이 먹다。）
