今日语法 2 条

N も
발음N 모
…也…
名詞 + も（替代 は/が/を）
表同类追加；替代格助词，不与 は 叠加
와타시모가쿠세이데스.
私も学生です。
我也是学生。
朝鲜语：도
韩语 도 和日语 も 都可表示追加，常替换主格或宾格助词；叠加其他助词须按具体语境判断。
易错点

私はも学生です。 → 私も学生です。（「も」本身已含「也」，要替换 は，不能 は+も 并存）

これ / それ / あれ / どれ は N です
발음코레 / 소레 / 아레 / 도레 와 N 데스
这/那/那是…
指示代名词 + は + 名詞 + です
コソアド 指示词：近称/中称/远称/疑问
코레와혼데스.
これは本です。
这是书。
소레와이쿠라데스카.
それはいくらですか。
那个多少钱？
朝鲜语：이것 / 그것 / 저것 / 어느 것
韩语指示三分与日语相同，但修饰名词要用이/그/저且与것分写；日语可直接连体。
易错点

これ は 本です（分写） → これは本です。（指示词后主题助词 は 不能空格分开写）
