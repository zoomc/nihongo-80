Day 008 · い形容词 否定／过去／て形、な形容词 否定／过去／で、て形

语法 3 条

い形容词 否定／过去／て形
不…／曾…／又…（い形变形）
高い→高くない／高かった／高くて
去 い + くない(否定)、かった(过去)、くて(中顿)
韩语对应-지 않다 / -았·었- / -고
韩语否定用지 않다、过去用았/었、中顿用고，无日语くて的音便变化。
코노혼 와 타카쿠나이데스.
この本は高くないです。
这本书不贵。
키노우 와 사무카따데스.
昨日は寒かったです。
昨天冷。
易错易混点
  • ✗ 普通否定：本は高いないです。✓ 本は高くないです。い形容词否定：词尾 い 改成 く，再加 ない（高い→高くない）。いい 特殊，变 よくない。
  • ✗ 昨日は寒いでした。✓ 昨日は寒かったです。い形容词的过去是 〜かった（寒かった）；でした 只给名词和な形容词用。
な形容词 否定／过去／で
不…／曾…／而…（な形变形）
静か→静かではない／静かだった／静かで
词干 + ではない(否定)、だった(过去简体)、で(中顿)
韩语对应-지 않다 / -았·었- / -고
조용하지 않다、조용했다、조용하고 都沿用形容词词尾；日语的 静かではない、静かだった、静かで 按な形容词变，不能套 高くない 的规则。
코코 와 시즈카데 와 아리마센.
ここは静かではありません。
这里不安静。
키노우 와 겐키데시타.
昨日は元気でした。
昨天很精神。
易错易混点
  • ✗ 静かくないです。✓ 静かではありません。な形容词否定用 では／じゃ ない，不能套い形容词的 〜くない。
  • ✗ 元気だったです。✓ 元気でした。だった 已经含过去，后面不能再加 です；客气过去就是 でした。
て形
발음테카타치
动词て形（连接/中顿/请求基础）
五段：词尾 う／つ／る→って，む／ぶ／ぬ→んで，く→いて，ぐ→いで，す→して，行く→行って；一段去 る + て；来る→来て（きて），する→して。
表中顿、并列、请求（てください）、进行（ている）等
韩语对应-고 / -아·어서
韩语连接词尾按语义分고(并列)、서(顺序/原因)，不能一词尾通吃；日语て形用途更广。
혼 오 욘데이마스.
本を読んでいます。
正在读书。
타베테쿠다사이.
食べてください。
请吃。
易错易混点
  • ✗ 名前を書きてください。✓ 名前を書いてください。書く 的て形是 書いて（く→いて）；行く 是唯一例外，变 行って。
  • ✗ 食べって。✓ 食べて。一段动词去掉 る 直接加 て（食べて）；促音便（って）只给五段用。
