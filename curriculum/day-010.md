# Day 010 · ～て ください、～て いる

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 新词 25

- **お願いします**（おねがいします）请；拜托｜韩语参考：부탁합니다<br>
  例：ファーストクラスでお願いします。（我要头等舱。）
- **おばあさん**（おばあさん）祖母；老奶奶｜韩语参考：할머니<br>
  例：トムのおばあさんは元気そうですよ。（汤姆的奶奶看起来很健康。）
- **伯母さん**（おばさん）伯母；姑妈；姨妈（父母的姐姐。父母的妹妹或弟弟的妻子通常写 叔母）｜韩语参考：아주머니（婶婶，大婶，伯母，阿姨）<br>
  例：父の姉は、私の伯母さんです。（爸爸的姐姐是我的姑妈。）
- **おはよう**（おはよう）早上好｜韩语参考：좋은 아침<br>
  例：おはよう。ご飯をよそっても良いかしら？（早啊。要不要我盛饭？）
- **お風呂**（おふろ）洗澡；浴缸｜韩语参考：목욕 / 욕조<br>
  例：私はほとんど毎日お風呂に入ります。（我几乎每天都洗澡。）
- **お弁当**（おべんとう）便当；盒饭｜韩语参考：도시락<br>
  例：彼は今日、お弁当を持って来た。（他今天带了便当来。）
- **おまわりさん**（おまわりさん）警察｜韩语参考：경찰관<br>
  例：すみません、おまわりさん。ここはどこですか。（劳驾，警察先生，这是哪儿？）
- **重い**（おもい）重｜韩语参考：짙다（深，重） / 무겁다（重，沉） / 중하다（重）<br>
  例：トムはジャックよりも１０ポンド重い。（汤姆比杰克重十磅。）
- **おもしろい**（おもしろい）有趣｜韩语参考：재미있다<br>
  例：スケートはとてもおもしろかった。（滑冰非常有意思。）
- **泳ぐ**（およぐ）游泳｜韩语参考：수영하다（游泳） / 헤엄치다（游泳，游动，游水）<br>
  例：トムはすぐに泳げるようになるよ。（汤姆很快就能学会游泳。）
- **降りる**（おりる）下；下车｜韩语参考：치다（下） / 내리다（下，下去）<br>
  例：ここで降りましょう。（我们在这儿下车吧。）
- **終わる**（おわる）结束｜韩语参考：끝나다<br>
  例：会議は五時に終わります。（会议五点结束。）
- **女**（おんな）女人｜韩语参考：여인（女人，女子） / 여자（女子，女人）<br>
  例：人は男か女のどちらかである。（人不是男的就是女的。）
- **女の子**（おんなのこ）女孩｜韩语参考：계집애（女孩儿） / 계집아이（女孩儿）<br>
  例：女の子はほとんどみんなやさしい。（女孩子几乎都很温柔。）
- **外国**（がいこく）外国｜韩语参考：외국（外国） / 타국（异国，外国）<br>
  例：あなたは外国の本を持っていますか。（你有外国的书吗？）
- **返す**（かえす）归还｜韩语参考：돌려주다（还给，归还，退还）<br>
  例：車はいつ返したらいいでしょうか。（车什么时候还比较合适？）
- **かかる**（かかる）花费；启动｜韩语参考：걸리다 / 작동하다<br>
  例：どうしたらエンジンがかかりますか。（怎样才能发动引擎？）
- **かぎ**（かぎ）钥匙｜韩语参考：열쇠<br>
  例：出かける前に、かぎをかけます。（出门前我会锁门。）
- **かける**（かける）打电话；挂｜韩语参考：전화하다 / 걸다<br>
  例：１０円で電話がかけられますか。（十日元能打个电话吗？）
- **傘**（かさ）伞｜韩语参考：우산<br>
  例：タクシーに傘を忘れてしまった。（我把伞落在出租车上了。）
- **貸す**（かす）借出｜韩语参考：빌려주다<br>
  例：ホッチキスを貸してくれませんか。（能借我订书机用一下吗？）
- **風**（かぜ）风｜韩语参考：바람（风） / 바람결（风，随风）<br>
  例：カーテンが風になびいた。（窗帘随风飘动。）
- **風邪**（かぜ）感冒｜韩语参考：감기（感冒）<br>
  例：ただの風邪でしょう。（大概只是感冒吧。）
- **方**（かた）位；人（较礼貌，用于称呼）｜韩语参考：분 / 방법<br>
  例：受付にいる方に聞いてください。（请问一下在前台的那位。）
- **カップ**（カップ）杯子｜韩语参考：컵（杯子）<br>
  例：テーブルの上にカップがある。（桌上有个杯子。）

## 语法

- **～て ください**：请（做）…
  接续：動詞て形 + ください
  朝鲜语：-아/어 주세요（-아/어 주세요 和 てください 都能直接提出请求；想更委婉可用 -아/어 주시겠어요? 对照 ていただけますか。）
- **～て いる**：正在…／…着（结果状态）
  接续：動詞て形 + いる
  朝鲜语：-고 있다 / -아·어 있다（韩语进行用고 있다，结果状态多用아/어 있다；日语ている兼表两者，须按动词区分。）
