# Day 088 · 〜ばかりでなく、〜も〜ば〜も

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜ばかりでなく、〜も〜ば〜も」各造一句自己的话，表达：不仅…而且…；既…又…；也…也…

## 新词 22

- **恋**（こい）恋爱｜韩语参考：사랑 / 연애<br>
  例：それは片思いの恋だった。（那是一场单相思。）
- **恋人**（こいびと）恋人｜韩语参考：연인（恋人）<br>
  例：私は恋人を「ダーリン」と呼びます。（我叫我的恋人「达令」。）
- **幸運**（こううん）幸运｜韩语参考：행운（幸运）<br>
  例：私は幸運にもよい席がとれました。（我运气好，弄到了好座位。）
- **講演**（こうえん）演讲；报告｜韩语参考：강연（演讲，讲演，讲座）<br>
  例：今夜の講演は誰ですか。（今晚的演讲是谁讲？）
- **効果**（こうか）效果｜韩语参考：효과（效果，功效，效力，成效，作用）<br>
  例：その新薬はすぐに効果を示した。（那种新药很快就见效了。）
- **硬貨**（こうか）硬币｜韩语参考：동전<br>
  例：これらの硬貨はほとんど価値がない。（这些硬币几乎没什么价值。）
- **高価**（こうか）高价；昂贵｜韩语参考：고가（高价）<br>
  例：そんな高価な本は買えないよ。（那么贵的书我可买不起。）
- **豪華**（ごうか）豪华｜韩语参考：호화（豪华）<br>
  例：そのホテルは言葉で表現できないほど豪華だった。（那家酒店豪华得无法用语言形容。）
- **合格**（ごうかく）合格；考上｜韩语参考：합격（合格，及格，通过，录取） / 통과（通过，许可，合格）<br>
  例：私の兄は試験に合格できなかった。（我哥哥没能通过考试。）
- **交換**（こうかん）交换｜韩语参考：교환（调换，交换）<br>
  例：あなたと席を交換しよう。（跟你换个座位吧。）
- **航空**（こうくう）航空｜韩语参考：항공（航空）<br>
  例：航空料金の方が鉄道料金より高い。（机票比火车票贵。）
- **光景**（こうけい）景象｜韩语参考：광경（景象，情景，情境）<br>
  例：その光景を見てぎょっとした。（看到那番景象，我吓了一跳。）
- **合計**（ごうけい）合计｜韩语参考：합계（合计，总计） / 도합（总共，共计，合计）<br>
  例：この数字の列を合計しなさい。（把这一列数字加起来。）
- **攻撃**（こうげき）攻击｜韩语参考：공격（攻击） / 가격（攻击，加以攻击）<br>
  例：急所を除くすべての攻撃を認める。（除要害部位外，其他攻击都允许。）
- **貢献**（こうけん）贡献｜韩语参考：공헌（贡献） / 기여（贡献）<br>
  例：彼女は非常に会社に貢献した。（她为公司做出了很大贡献。）
- **広告**（こうこく）广告｜韩语参考：광고（广告）<br>
  例：その商品はテレビで広告された。（那件商品在电视上做了广告。）
- **交際**（こうさい）交往｜韩语参考：교제（交往）<br>
  例：その男は妻と交際し始めた。（那个男人开始和妻子交往了。）
- **後者**（こうしゃ）后者｜韩语参考：후자（后者）<br>
  例：このうち大事なのは後者の方です。（其中重要的是后者。）
- **構成**（こうせい）构成｜韩语参考：구성（构成）<br>
  例：委員会は８名から構成されている。（委员会由八名成员组成。）
- **高速**（こうそく）高速｜韩语参考：고속（高速） / 고속 도로（高速公路）<br>
  例：運転者は高速を出し続けた。（司机一直保持高速行驶。）
- **行動**（こうどう）行动｜韩语参考：행동（行动，行为，举动） / 행위（行为，行动）<br>
  例：私がこの行動の責任はすべて取る。（这次行动的责任全由我来负。）
- **強盗**（ごうとう）强盗；抢劫｜韩语参考：강도（强盗） / 강도질（当强盗，抢劫） / 날강도（强盗， 抢劫犯，匪贼）<br>
  例：父は強盗と取っ組み合いをした。（父亲和劫匪扭打了起来。）

## 语法

- **〜ばかりでなく**：不仅…而且…
  接续：普通形 + ばかりでなく；ナ形容词 + な + ばかりでなく；名词 + ばかりでなく
  朝鲜语：-뿐만 아니라（韩语「-뿐만 아니라」与日语几乎完全对应；但日语后项习惯加「も」，韩语可省，容易漏掉「も」。）
- **〜も〜ば〜も**：既…又…；也…也…
  接续：名词 + も + ば形 + 名词 + も；名词 + も + い形容词ければ + 名词 + も
  朝鲜语：-기도 하고 -기도 하다（韩语「-기도 하고 -기도 하다」只并列；日语「も〜ば〜も」用ば形连接，书面感更强，前半须是完整谓语。）
