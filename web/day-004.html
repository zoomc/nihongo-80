今日语法 3 条

が（主语／新信息／存在主体）
발음가
…（主语/新信息/存在主体/能力对象）
名詞 + が + 動詞／形容詞
表主语、新信息、疑问词主语、存在主体、能力/好恶对象
韩语对应이/가
이/가 与 が 都能聚焦是谁、是什么，也能标存在主体。自我介绍通常先定话题，用 저는／私は；回应「谁是学生」时可用 제가／私が。
네코 가 이마스.
猫がいます。
有猫。
다레 가 키마스 카.
誰が来ますか。
谁来？

易错点 私がは学生です。 → 私は学生です。（が 与 は 不能叠加；自我介绍用 は 提示主题，が 标记新信息焦点（如「誰が学生ですか」→「私が学生です」），两者分工不同。）

を（宾语／移动经过）
발음오
把…（标宾语）
名词 + を + 他动词（对象）；场所 + を + 移动动词（路线或离开的起点）
标动作直接宾语；也表移动经过的场所（空を飛ぶ）
韩语对应을/를
ご飯を食べる 对应 밥을 먹다，公園を通る 对应 공원을 지나가다。公園で遊ぶ 对应 공원에서 놀다，此时公园是动作发生的场所。
고한 오 타베마스.
ご飯を食べます。
吃饭。

易错点 公園が通ります。 → 公園を通ります。（「穿过公园」把公园当经过的路线，用 を。表示「穿过」的 通る 是自动词，不能按「を 只接他动词」理解。）

に（时点／归着点／存在场所／对象）
발음니
在／于／向…
名詞 + に
表时间点、动作归着点、存在场所、动作对象
韩语对应에 / 에게
七時に起きる 对应 일곱 시에 일어나다；部屋にいる 对应 방에 있다；友達に送る 对应 친구에게 보낸다。日语多用同一个 に。
시치지 니 오키마스.
七時に起きます。
七点起床。
가꼬우 니 이키마스.
学校に行きます。
去学校。

易错点 七時で起きます。 → 七時に起きます。（具体时点用 に，类似 일곱 시에。毎朝、今日等相对时间词常直接放在动词前。）
