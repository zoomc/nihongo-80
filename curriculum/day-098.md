# Day 098 · 〜にとって、〜にしては

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜にとって、〜にしては」各造一句自己的话，表达：对…来说；照…来说；以…而言

## 新词 25

- **少女**（しょうじょ）少女｜韩语参考：소녀<br>
  例：あのかわいい少女は私の妹です。（那个可爱的小姑娘是我妹妹。）
- **少々**（しょうしょう）稍微；少许｜韩语参考：조금<br>
  例：ぼくは少々君に腹が立っているんだ。（我有点生你的气。）
- **生じる**（しょうじる）产生；发生｜韩语参考：가다（产生，造成）<br>
  例：事故は不注意から生じる。（事故源于疏忽。）
- **上達**（じょうたつ）进步；提高｜韩语参考：향상 / 실력 향상<br>
  例：君の英語は上達している。（你的英语在进步。）
- **冗談**（じょうだん）玩笑｜韩语参考：농（玩笑） / 우스개（笑话，玩笑） / 농지거리（开玩笑，闹着玩儿，戏谑）<br>
  例：冗談はもうたくさんだ。（玩笑开够了吧。）
- **上等**（じょうとう）上等；高档｜韩语参考：고급 / 상등<br>
  例：どうしてこんな上等のぶどう酒を今まで取って置いたのか。（为什么把这么好的葡萄酒留到现在？）
- **衝突**（しょうとつ）冲突；碰撞｜韩语参考：충돌（冲突，碰撞，冲撞）<br>
  例：日米の利害がこの点で衝突した。（日美两国的利益在这一点上发生了冲突。）
- **商人**（しょうにん）商人｜韩语参考：장사꾼（商人，贩子，商贩）<br>
  例：商人は商品を売り買いする人だ。（商人是买卖商品的人。）
- **少年**（しょうねん）少年｜韩语参考：소년（少年，男孩）<br>
  例：少年は木に自分の名前を刻んだ。（少年把自己的名字刻在树上。）
- **商売**（しょうばい）生意；买卖｜韩语参考：장사（生意，经商）<br>
  例：彼は商売がうまくいったのを喜んだ。（他为生意顺利而高兴。）
- **消費**（しょうひ）消费｜韩语参考：소비（消费，消耗）<br>
  例：その車は多量の燃料を消費する。（那辆车消耗大量燃料。）
- **商品**（しょうひん）商品｜韩语参考：상품（商品） / 물건（商品，物品）<br>
  例：商人は商品を売り買いする人だ。（商人是买卖商品的人。）
- **消防**（しょうぼう）消防｜韩语参考：소방（消防）<br>
  例：彼が言うには、消防の仕事というのは大忙しか全く暇かのいずれかだそうだ。（据他说，消防工作不是忙得不可开交就是闲得没事。）
- **証明**（しょうめい）证明｜韩语参考：증명（证明）<br>
  例：私が間違っていない事を証明しよう。（我来证明我没错。）
- **女王**（じょおう）女王｜韩语参考：여왕（女王）<br>
  例：女王は国民に向けて演説をした。（女王向国民发表了演说。）
- **職**（しょく）工作；职务｜韩语参考：직（工作） / 노릇（工作，事，玩意）<br>
  例：職探しはどうなったの？（找工作的事怎么样了？）
- **職業**（しょくぎょう）职业｜韩语参考：직업（职业） / 직장（职业，职场，工作）<br>
  例：婦人に開放されている職業は多い。（向女性开放的职业很多。）
- **食卓**（しょくたく）餐桌｜韩语参考：식탁（餐桌）<br>
  例：彼女は食卓に料理を並べた。（她把菜摆上了餐桌。）
- **食品**（しょくひん）食品｜韩语参考：식품（食品）<br>
  例：この食品は有毒である。（这种食品有毒。）
- **植物**（しょくぶつ）植物｜韩语参考：식물（植物）<br>
  例：植物や生き物は持っていませんね？（你没有养植物和动物吧？）
- **食物**（しょくもつ）食物｜韩语参考：음식 / 식품<br>
  例：私はたくさんの食物を持って帰ろう。（我要带很多食物回去。）
- **食欲**（しょくよく）食欲｜韩语参考：식욕（食欲） / 밥맛（胃口，食欲） / 입맛（口味，胃口，食欲）<br>
  例：最近食欲がないんです。（最近没什么食欲。）
- **食料**（しょくりょう）食物；粮食｜韩语参考：식량 / 식품<br>
  例：彼らはじゅうぶんな食料を手に入れられなかった。（他们没能弄到足够的食物。）
- **食糧**（しょくりょう）粮食｜韩语参考：식량（粮食，食粮） / 양식（粮食）<br>
  例：食糧が不足している。（粮食短缺。）
- **書斎**（しょさい）书房｜韩语参考：서재（书斋，书室，书房，书屋） / 서실（书房，写字间）<br>
  例：このドアは書斎に通じている。（这扇门通向书房。）

## 语法

- **〜にとって**：对…来说
  接续：名词 + にとって；名词 + にとっての + 名词
  朝鲜语：-에게 있어서（韩语「-에게 있어서」同样表立场，但较长、偏书面；日语「にとって」口语也常用，后项多接评价性表达。）
- **〜にしては**：照…来说；以…而言
  接续：动词普通形／名词 + にしては；名词化的 の + にしては 也可用
  朝鲜语：-치고는（韩语「-치고는」与「にしては」几乎一一对应，都含“出乎预料”；但日语多接身份、时间名词。）
