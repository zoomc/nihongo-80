# Day 033 · 可能形、条件形（ば／たら／なら／と）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「可能形、条件形（ば／たら／なら／と）」造两句自己的话，表达：能／会…（动词可能形）；如果…／一…就…（条件形总览）

## 新词 20

- **ボタン**（ボタン）扣子；按钮｜韩语参考：단추（扣子，纽扣） / 버튼（按钮）<br>
  例：レーンコートのボタンがとれた。（雨衣的扣子掉了。）
- **本棚**（ほんだな）书架｜韩语参考：서가（书架） / 책꽂이（书架）<br>
  例：私は本棚の本をすべて読んだわけではない。（我并没有把书架上的书都读完。）
- **ほんとう**（ほんとう）真的；真实｜韩语参考：정말 / 진실<br>
  例：本当のマンションではありません。（这不是真正的公寓。）
- **毎朝**（まいあさ）每天早上｜韩语参考：매일 아침<br>
  例：毎朝ジョギングすることにした。（我决定每天早上跑步。）
- **毎月**（まいげつ）每月｜韩语参考：매달<br>
  例：毎月のガス代はいくらですか。（每月燃气费多少？）
- **毎週**（まいしゅう）每周｜韩语参考：매주（每周，每星期）<br>
  例：父は毎週日曜日にゴルフをします。（父亲每周日打高尔夫。）
- **毎年**（まいねん）每年｜韩语参考：매년<br>
  例：毎年ここに来なきゃ。（每年都得来这儿。）
- **毎晩**（まいばん）每天晚上｜韩语参考：매일 밤<br>
  例：私は毎晩家にいます。（我每天晚上都在家。）
- **曲る**（まがる）拐弯；弯曲｜韩语参考：돌다 / 구부러지다<br>
  例：２ブロック先まで歩き、左へ曲がりなさい。（往前走两个街区，然后向左拐。）
- **まずい**（まずい）难吃；糟糕｜韩语参考：맛없다 / 곤란하다<br>
  例：あ！まずい！ガソリンが切れてきた。（啊！糟了！汽油快没了。）
- **また**（また）又；再｜韩语参考：또（又）<br>
  例：ジムもまたパーティーに来ます。（吉姆也会来参加聚会。）
- **町**（まち）城镇；街道｜韩语参考：마을 / 거리<br>
  例：その町はロンドンのすぐ北にある。（那个小镇就在伦敦北边。）
- **まっすぐ**（まっすぐ）笔直；直接｜韩语参考：곧장 / 똑바로<br>
  例：まっすぐ前を見てください。（请一直往前看。）
- **マッチ**（マッチ）火柴｜韩语参考：성냥（火柴）<br>
  例：マッチありますか。（有火柴吗？）
- **窓**（まど）窗户｜韩语参考：창문（窗，窗户）<br>
  例：窓を開けっぱなしにしておいたの？（你就让窗户一直开着？）
- **丸い**（まるい）圆的｜韩语参考：동글다（圆圆的） / 둥글다（圆，圆圆的） / 둥그렇다（圆圆的）<br>
  例：ボールは丸い。（球是圆的。）
- **万**（まん）万｜韩语参考：만（万）<br>
  例：このテープレコーダーは４万円しました。（这台录音机花了我四万日元。）
- **万年筆**（まんねんひつ）钢笔｜韩语参考：만년필（钢笔）<br>
  例：新しい万年筆をなくしてしまった。（我把新买的钢笔弄丢了。）
- **磨く**（みがく）擦；刷；磨练｜韩语参考：닦다（刷，擦） / 연마하다（磨练，锻炼，钻研）<br>
  例：そのなべを磨いていただけませんか。（能不能把那口锅擦一擦？）
- **右**（みぎ）右；右边｜韩语参考：우（右） / 오른쪽（右侧，右边） / 오른편（右边，右侧）<br>
  例：アラビア語は右から左へ書きます。（阿拉伯语是从右往左写的。）

## 语法

- **可能形**：能／会…（动词可能形）
  接续：五段 う段→え段+る；一段 去る+られる；カ変 来られる；サ変 できる
  朝鲜语：-(으)ㄹ 수 있다（韩语可能用ㄹ 수 있다短语，不改动词形态；日语靠一段/五段变形，宾语可を→が。）
- **条件形（ば／たら／なら／と）**：如果…／一…就…（条件形总览）
  接续：ば えば/ければ；たら た形+ら；なら 名词/普通形+なら；と 辞书形+と
  朝鲜语：-(으)면（韩语条件基本用면一形，语用限制少；日语ば/たら/なら/と四分，と后不接意志。）
