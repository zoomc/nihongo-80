今日语法 2 条

～によって / ～について / ～にとって
발음～니요떼 / ～니쓰이테 / ～니토떼
因…而异／关于…／对…来说
名詞 + によって／について／にとって
によって 表「因…而不同/依据/手段被动」、について「关于」、にとって「对…而言（评价）」
히토니요떼이켄가치가이마스.
人によって意見が違います。
意见因人而异。
니혼고니쓰이테하나시마스.
日本語について話します。
谈谈日语。
와타시니토떼,니혼고와무즈카시이데스.
私にとって、日本語は難しいです。
对我来说日语很难。
朝鲜语：-에 따라 / -에 대해 / -에게
韩语에 따라表依据或随…而异，에 대해关于，에게表评价对象，三者分工比日语清楚。
易错点

私について、日本語は難しいです → 私にとって、日本語は難しいです。（「对…来说」用 にとって，について 是「关于」，中文「对」易混）

V辞書形 / Vない形 + ように する
努力做到…／设法不…（有意识地做）
動詞 辞書形／ない形 + ように + する；する 按 サ変 变形（ようにしています／ようにした）
ようにする 表有意识地努力或安排；ようになる 常侧重变化结果，但变化也可能来自努力。
毎日野菜を食べるようにしています。
我尽量每天吃蔬菜。
네루마에니스마호오미나이요우니시테이마스.
寝る前にスマホを見ないようにしています。
睡前尽量不看手机。
朝鲜语：-도록 하다
韩语 -도록 하다 可表努力或指示；日语ようにする可用于自己的安排，也可用于要求他人注意。
易错点

毎日走るようになりました。 → 毎日走るようにしています。（想表达「我坚持每天跑步」应用 ようにする（意志努力）；ようになる 是自然变化，中文「坚持」直译易混）
