## 新词 25

- **皆**（みな）大家；都｜韩语参考：다（全，都） / 모두（都，全）<br>
  例：私の親族は皆この町に住んでいる。（我的亲戚都住在这个镇上。）
- **港**（みなと）港口｜韩语参考：항구（港口）<br>
  例：その船はいま港にある。（那艘船现在在港口。）
- **向かう**（むかう）前往；朝向｜韩语参考：향하다<br>
  例：あなたは何処へ向かっているのですか。（你要去哪儿。）
- **迎える**（むかえる）迎接；接｜韩语参考：맞다（迎接，接待） / 받다（接待，迎接，接受，录用） / 맞이하다（迎接，迎）<br>
  例：６時にホテルに車で迎えて下さい。（六点请开车来酒店接我。）
- **昔**（むかし）从前｜韩语参考：과거（过去，从前）<br>
  例：この本を読むたびに昔を思い出す。（每次读这本书都会想起从前。）
- **虫**（むし）虫子｜韩语参考：벌레（虫子）<br>
  例：鳥は虫を探していた。（鸟在找虫子。）
- **息子**（むすこ）儿子｜韩语参考：아들（儿子） / 아들자식（儿子）<br>
  例：母親は息子にやかましく言って聞かせた。（母亲狠狠训了儿子一顿。）
- **娘**（むすめ）女儿｜韩语参考：딸（女儿） / 딸애（小女儿） / 여식（女儿）<br>
  例：私はヘレンカートライトの娘です。（我是海伦·卡特赖特的女儿。）
- **無理**（むり）不可能；勉强｜韩语参考：무리（过分，不合适，勉强，强人所难） / 억지（牵强，勉强）<br>
  例：それは無理な注文だ。（这个要求太过分了。）
- **召し上がる**（めしあがる）吃；喝（尊敬）｜韩语参考：잡수다（吃） / 잡숫다（吃） / 잡수시다（吃）<br>
  例：ここで召し上がりますか、それともお持ち帰りですか。（您在这儿吃还是带走。）
- **珍しい**（めずらしい）少见；稀奇｜韩语参考：희한하다（稀罕，稀奇）<br>
  例：これは珍しい種類の魚です。（这是很稀奇的一种鱼。）
- **申し上げる**（もうしあげる）说（自谦）｜韩语参考：말씀드리다（说，告知）<br>
  例：お礼の申し上げようもありません。（实在不知怎么感谢您才好。）
- **もうすぐ**（もうすぐ）马上｜韩语参考：곧<br>
  例：明るくなってきた。もうすぐ朝だ。（天亮了，马上就要早晨了。）
- **もし**（もし）如果｜韩语参考：만약（如果，假如，要是）<br>
  例：もし電話がなったら出てくれますか。（要是电话响了，你能接一下吗。）
- **もらう**（もらう）得到；请人做｜韩语参考：받다 / ~해 달라고 하다<br>
  例：あさって彼にここへ来てもらうつもりです。（打算后天请他来这里。）
- **森**（もり）森林｜韩语参考：숲<br>
  例：私は森の中で野うさぎをみつけた。（我在森林里发现了一只野兔。）
- **焼く**（やく）烤；晒｜韩语参考：굽다（烤，烧烤）<br>
  例：この夏はこんがり焼こうと思います。（今年夏天我想晒黑一点。）
- **役に立つ**（やくにたつ）有用｜韩语参考：도움이 되다<br>
  例：それ以上はお役に立てません。（再多的我就帮不上忙了。）
- **焼ける**（やける）烤好；烧｜韩语参考：구워지다 / 타다<br>
  例：このトーストはよく焼けていません。（这片吐司没烤透。）
- **優しい**（やさしい）温柔｜韩语参考：좋다（好，和善，温柔） / 살갑다（柔和，温柔） / 곰살맞다（温柔，和善）<br>
  例：みんなには優しく話してください。（请对大家说话温柔些。）
- **痩せる**（やせる）变瘦｜韩语参考：빠지다（掉，减轻，变瘦）<br>
  例：彼女はレールのように痩せていた。（她瘦得像根栏杆。）
- **やっと**（やっと）终于；好不容易｜韩语参考：겨우（勉强，好不容易） / 가까스로（好不容易） / 겨우겨우（勉勉强强，好不容易）<br>
  例：こ、こら！ナニやっとるかぁぁ！！（喂喂！你在搞什么啊。）
- **やはり**（やはり）果然；还是｜韩语参考：역시<br>
  例：やはり、この店の料理はおいしいですね。（这家店的菜果然好吃。）
- **止む**（やむ）停｜韩语参考：긋다（停，住） / 멎다（停，停止） / 멈추다（停，止）<br>
  例：雨がちょうど止んだ、出発しよう。（雨正好停了，出发吧。）
- **柔らかい**（やわらかい）柔软｜韩语参考：말랑하다（柔软） / 부드럽다（柔软） / 말랑말랑하다（柔软）<br>
  例：風が柔らかく木立に触れた。（风轻柔地拂过树丛。）

## 语法

- **〜たがる**：（第三人称）想做…
  接续：动词ます形去ます + たがる
  朝鲜语：-고 싶어 하다（韩语常用 -고 싶어 하다 描述他人表现出的愿望；日语たがる同样关注外显表现，人称选择需结合语境。）
- **〜がる**：（第三人称）显得…；表现出…
  接续：い形容词去い／な形容词词干 + がる
  朝鲜语：-아/어 하다（韩语可用 -아/어 하다 描述他人表现出的情绪，如 무서워하다；日语がる通常描述外显表现，也可客观回顾自己的倾向。）
- **〜かもしれない**：也许…；可能…
  接续：动词、い形容词普通形 + かもしれない；名词、な形容词的非过去肯定词干直接接。
  朝鲜语：-(으)ㄹ지도 모르다（선생님일지도 모른다 对照 先生かもしれない。韩语名词前后可出现 -이다 的活用形式，日语别在 先生 后多加 だ。）
- **〜だろう**：大概…吧
  接续：动词、い形容词普通形 + だろう；名词、な形容词的非过去肯定词干 + だろう。
  朝鲜语：-(으)ㄹ 것이다 / -겠다（韩语 -(으)ㄹ 것이다 与 だろう 对应，-겠다 更偏主观意志或推测；日语 だろう 只表推测，不表意志。）
