# Day 093 · 〜わけではない、〜わけがない

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜わけではない、〜わけがない」造两句自己的话，表达：并不是…；并非…；不可能…；绝不会…

## 语法

- **〜わけではない**：并不是…；并非…
  接续：普通形 + わけではない；ナ形容词 + な + わけではない；名词 + という + わけではない
  朝鲜语：-는 것은 아니다（韩语「-는 것은 아니다」也表部分否定，但常缩成「-는 게 아니다」；日语「わけではない」更明确针对“由此推出的结论”。）
- **〜わけがない**：不可能…；绝不会…
  接续：普通形 + わけがない；ナ形容词 + な + わけがない；名词 + の/な + わけがない
  朝鲜语：-ㄹ 리가 없다（韩语「-ㄹ 리가 없다」与「わけがない」几乎一一对应；但韩语口语常说「-ㄹ 리가 없잖아」反驳，日语习惯前加「そんな」。）
