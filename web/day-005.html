今日语法 3 条

で（动作场所／手段／材料／原因）
발음데
在…／用…／因为…
名詞 + で
表动作场所、手段/工具/交通、材料、原因
韩语对应에서 / (으)로
도서관에서 공부하다 的 에서 和 자전거로 가다 的 로 在日语都用 で。存在地点换成 に：図書館に本がある。
토쇼칸 데 벤쿄우시마스.
図書館で勉強します。
在图书馆学习。
덴샤 데 이키마스.
電車で行きます。
坐电车去。

易错点 図書館に勉強します。 → 図書館で勉強します。（学习这一动作发生在图书馆，用 で。图书馆是存在地点时才用 に，如 図書館に本があります。）

へ（移动方向）
발음〜에
往／向…
名詞 + へ + 移動動詞
表移动方向，读 e 不读 he；侧重方向，に 侧重到达点
韩语对应(으)로
東へ進む 对应 동쪽으로 가다。方向助词 へ 写法固定、这里读 e；在 行く 等动词前也可用 に，突出目的地。
아시타, 가꼬우 에 이키마스.
明日、学校へ行きます。
明天去学校。

易错点 学校へ 行きます（へ 读 he） → 学校へ行きます。（へ 读 e）（助词「へ」在此读 e，不读罗马字 he；中文无此音便）

と（并列／共同／引用）
발음토
和…／与…（一起）；「…」地
名詞 + と + 名詞／動詞；引用从句 + と + 思う/言う
完全并列、共同动作对象、引用内容
韩语对应와/과 / 하고 / (이)라고
并列可对照 와/과、하고，共同动作可对照 하고 함께。引述时韩语按句型选 -다고、-(이)라고、-냐고 等，日语引述的标记是 と。
토모다치 토 에이가 오 미마스.
友達と映画を見ます。
和朋友看电影。

易错点 友達とに映画を見ます。 → 友達と映画を見ます。（一起做动作的对象只用 と，不加 に。友達も映画を見ます 则是「朋友也看电影」。）
