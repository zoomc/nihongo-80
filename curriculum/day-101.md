# Day 101 · 〜一方で、〜に対して

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜一方で、〜に対して」造两句自己的话，表达：一方面…；同时…；对…；与…相对

## 新词 14

- **きちんと**（きちんと）好好地；端正｜韩语参考：바로（端正地，正确地） / 단정히（端正地，正经地）<br>
  例：私の時計はきちんと動いている。（我的表走得很准。）
- **きつい**（きつい）紧；够呛｜韩语参考：째다（瘦，紧，挤） / 뻑뻑하다（紧）<br>
  例：トムは頭にきつい一発を受けた。（汤姆头上挨了重重一击。）
- **気付く**（きづく）察觉｜韩语参考：채다（猜到，察觉，看出）<br>
  例：彼は危険に気づいていなかった。（他没有察觉到危险。）
- **気に入る**（きにいる）喜欢；中意｜韩语参考：마음에 들다<br>
  例：いくつかの点で私は彼女が気に入らない。（有几点我不喜欢她。）
- **記入**（きにゅう）填写｜韩语参考：기입（填写，记入）<br>
  例：この紙に記入するのを手伝ってください。（请帮我填一下这张表。）
- **記念**（きねん）纪念｜韩语参考：기념（纪念）<br>
  例：アメリカ旅行のよい記念になります。（这会成为美国之行的一个好纪念。）
- **機能**（きのう）功能｜韩语参考：기능（功能，机能）<br>
  例：こんな余計な機能なんでつけたんだろう。（干吗要加这么些多余的功能呢。）
- **気の毒**（きのどく）可怜；过意不去｜韩语参考：안됐다 / 미안하다<br>
  例：私たちはその老夫婦を気の毒に思った。（我们觉得那对老夫妻很可怜。）
- **寄付**（きふ）捐赠｜韩语参考：기부（捐赠，捐献，赠送） / 기증（捐赠）<br>
  例：彼女は赤十字に寄付した。（她向红十字会捐了款。）
- **希望**（きぼう）希望｜韩语参考：희망（希望，愿望） / 가망（指望，希望） / 바람（希望，期望，期待）<br>
  例：これが彼のたった一つの希望であった。（这是他唯一的希望。）
- **基本**（きほん）基础；基本｜韩语参考：기본（基本，基础）<br>
  例：父は園芸の基本を教えてくれた。（父亲教了我园艺的基础。）
- **決まり**（きまり）规矩；规定｜韩语参考：규정（规定，规章） / 법도（法度，规矩，礼仪）<br>
  例：学校の決まりは守らないといけないぞ。（学校的规矩可得遵守。）
- **気味**（きみ）感觉；苗头｜韩语参考：기미（苗头，迹象，征兆） / 기운（气势 ，迹象，征兆，苗头）<br>
  例：その事件には何となく気味の悪いところがあった。（那起事件总让人觉得有点瘆人。）
- **奇妙**（きみょう）奇怪｜韩语参考：기묘하다<br>
  例：これはとても奇妙な手紙です。（这是一封非常奇怪的信。）

## 语法

- **〜一方で**：一方面…；同时…
  接续：普通形 + 一方で；ナ形容词 + な + 一方で；名词 + である + 一方で
  朝鲜语：-는 반면에（韩语「-는 반면에」只表对比；日语「一方で」还能表“同时进行的两件事”，范围更宽。）
- **〜に対して**：对…；与…相对
  接续：名词 + に対して；动词/い形容词/ナ形容词 + な + のに対して
  朝鲜语：-에 대해서（韩语「-에 대해서」只表对象；日语「に対して」还常用于前后对比，相当于韩语「-는 반면」，用法更广。）
