今日语法 2 条

韩语对应설령 …해도
韩语提示按整块理解。换成日语时先套接续「たとえ + Verb-te + も / たとえ + i-Adj-ku + ても / たとえ + na-Adj + でも / たとえ + 名词 + でも」，再看下面的例句。
たとえ〜ても
발음타토에〜테모
即使…也…
たとえ + Verb-te + も / たとえ + i-Adj-ku + ても / たとえ + na-Adj + でも / たとえ + 名词 + でも
타토에한타이사레테모,지분노유메오아키라메루쓰모리와나이.
たとえ反対されても、自分の夢を諦めるつもりはない。
Even if people oppose me, I have no intention of giving up my dream.
타토에치이사나카이샤데모,야리가이노아루시고토가시타이.
たとえ小さな会社でも、やりがいのある仕事がしたい。
Even if it's a small company, I want to do rewarding work.
韩语对应하지 않아도 되었다
韩语提示按整块理解。换成日语时先套接续「Verb-nai stem + ずに済む / Verb-nai + で済む」，再看下面的例句。
〜ずに済む / 〜ないで済む
발음〜즈니스무 / 〜나이데스무
不用…就解决了
Verb-nai stem + ずに済む / Verb-nai + で済む
유우진가쿠루마데오쿠떼쿠레타노데,타쿠시이오쓰카와즈니슨다.
友人が車で送ってくれたので、タクシーを使わずに済んだ。
My friend gave me a ride, so I didn't have to take a taxi.
하야메니치료우오하지메타오카게데,슈주쓰시나이데슨다.
早めに治療を始めたおかげで、手術しないで済んだ。
Thanks to starting treatment early, I didn't need surgery.
