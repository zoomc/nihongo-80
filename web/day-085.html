今日语法 3 条

〜というのは
발음〜토이우노와
所谓…；是因为…
名词/句子 + というのは
提出一个词或现象加以解释，或引出理由。
韩语对应-라는 것은
韩语「-라는 것은」表定义时与「というのは」对应；但日语还能在句末引出理由，韩语要用「왜냐하면」。
「割り勘」というのは、食事代などをみんなで同じ金額ずつ払うことです。
所谓“割り勘”，就是大家平摊饭钱。
히토리데카이가이니스무토이우노와,오모따요리타이헨나코토다.
一人で海外に住むというのは、思ったより大変なことだ。
一个人住在国外，比想象中更难。
라이슈우노료코우니와이케나쿠나따.토이우노와,큐우니슈쪼우가하이따카라다.
来週の旅行には行けなくなった。というのは、急に出張が入ったからだ。
下周的旅行我去不了了，因为突然要出差。

易错点 「割り勘」というは、食事代をみんなで同じ金額ずつ払うことです。 → というのは（固定形式是「というのは」，「というは」不合法。）

〜というより
발음〜토이우요리
与其说…不如说…
动词普通形/い形容词/ナ形容词/名词 + というより
修正前面的说法，指出后项表达更准确。
韩语对应-라기보다
韩语「-라기보다」与「というより」对应；但日语名词后不加「だ」，韩语要按有无收音变形，形式更复杂。
쿄우와스즈시이토이우요리,사무이쿠라이다.
今日は涼しいというより、寒いくらいだ。
今天说凉快，不如说有点冷。
카노조와토모다치토이우요리,카조쿠노요우나손자이다.
彼女は友達というより、家族のような存在だ。
她与其说是朋友，不如说像家人。
소레와이켄토이우요리,타다노몬쿠다요.
それは意見というより、ただの文句だよ。
那与其说是意见，不如说只是抱怨。

易错点 今日は涼しいより、寒いくらいだ。 → 涼しいというより（固定形式是「というより」，不能省成「より」。）

〜わりに / 〜わりには
발음〜와리니 / 〜와리니와
照…来说；相对…而言
动词普通形/い形容词/ナ形容词な/名词の + わりに（は）
表示与某程度、数量、条件相比，结果出乎预料。
韩语对应-에 비해서
韩语没有与「わりに」完全对应的形式，常译成「-에 비해서」或「-치고는」；日语专表“比例上不符预期”。
코노미세와네단노와리니,하카가오오쿠테오이시이.
この店は値段のわりに、量が多くておいしい。
这家店相对价格来说，量多又好吃。
兄はよく食べるわりには、全然太らない。
哥哥吃得那么多，却完全不胖。
코노호테루와에키카라치카이와리니,시즈카데요쿠네무레타.
このホテルは駅から近いわりに、静かでよく眠れた。
这家宾馆离车站近，却意外地安静，睡得很好。

易错点 兄はよく食べるのわりには、全然太らない。 → よく食べるわりには（动词直接接「わりに」，只有名词才加「の」。）

听力 · 病院の予約・3

先听一遍再答题。答后核对原文，找出漏听的条件和转折。

60. 予約は何時ですか。
61. 三日前からどんな症状がありますか。
62. 今、飲んでいる薬はありますか。
核对原文

病院に電話して、診察の予約をしました。三日前からのどが痛くて、昨日から少し熱もあります。受付の人に、今日の午前中は予約でいっぱいだと言われたので、午後四時に行くことにしました。初めてこの病院を利用するので、予約時間の十五分前には着くように言われました。入口で名前を伝えてから、問診票を書く必要があります。飲んでいる薬があるかどうかも聞かれましたが、今は何も飲んでいません。病院へは電車で行きます。車で行くつもりでしたが、熱があるので自分で運転するのはやめました。受付では保険の資格を確認できる物も見せます。家を出る前に、必要な物を小さなかばんにまとめておきます。予約を取り消す場合は、できるだけ早く電話してくださいとのことでした。今日は仕事を休んで、診察が終わったらそのまま家に帰って休むつもりです。
