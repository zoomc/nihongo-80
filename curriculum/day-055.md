# Day 055 · V ます形(去ます) + 得る / V ない形(去ない) + ざるを 得ない、普通形 + 一方(で) / 反面 / 代わりに、V辞書形 / Nの + たびに

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **V ます形(去ます) + 得る / V ない形(去ない) + ざるを 得ない**：可能…、会有…／不得不…
  接续：動詞 ます形 去 ます + 得る（读 うる／える，否定 得ない えない）；動詞 ない形 去 ない + ざるを得ない（する→せざるを得ない 例外）
  朝鲜语：-(으)ㄹ 수 있다 / -지 않을 수 없다（韩语可能用ㄹ 수 있다，不得不的用지 않을 수 없다或해야 한다；ざるを得ない更书面。）
- **普通形 + 一方(で) / 反面 / 代わりに**：一方面…另一方面…／…但另一方面／取而代之、作为交换
  接续：動詞・い形普通形／な形容词 + な／名词 + である + 一方(で)・反面；名詞 + の／普通形 + 代わりに
  朝鲜语：-는 한편 / -반면에 / -대신에（韩语는 한편表一方面、반면에表相反、대신에表代替，与日语三形对应整齐，반면对比更强。）
- **V辞書形 / Nの + たびに**：每当…就…；每次…都…
  接续：動詞辞書形 + たびに；名詞 + の + たびに（する名詞可直接 するたびに）
  朝鲜语：-(으)ㄹ 때마다（韩语때마다表每当，接名词或动词定语形；日语たびに只接辞书形或の，后项限制更严。）
