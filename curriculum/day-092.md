# Day 092 · 普通形 + からこそ、N / 普通形 + ばかりか

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「普通形 + からこそ、N / 普通形 + ばかりか」造两句自己的话，表达：正因为…才…；不仅…而且…

## 新词 14

- **会合**（かいごう）聚会；会议｜韩语参考：회합（会合，会聚，相聚，聚会，集会） / 모임（聚会）<br>
  例：これはとても大切な会合だ。（这是一次非常重要的聚会。）
- **外交**（がいこう）外交｜韩语参考：외교（外交）<br>
  例：英語は外交や観光事業に有効である。（英语在外交和旅游业中很有用。）
- **開始**（かいし）开始｜韩语参考：개시（开始） / 시작（开始，开端，开头，起始，起头）<br>
  例：天候のためレースの開始は遅れるだろう。（因天气原因，比赛可能推迟开始。）
- **解釈**（かいしゃく）解释；理解｜韩语参考：해석（解释） / 풀이（解释，解答）<br>
  例：それは２通りに解釈できる。（那可以有两种理解。）
- **外出**（がいしゅつ）外出｜韩语参考：외출（外出，出行，出门） / 출타（外出，出门，出行） / 바깥출입（外出，出门，出行）<br>
  例：ヒーターをつけたまま外出した。（我开着暖气就出门了。）
- **改善**（かいぜん）改善｜韩语参考：개선（改善）<br>
  例：改善の余地は大いに残されている。（还有很大的改善余地。）
- **快適**（かいてき）舒适｜韩语参考：쾌적하다<br>
  例：この家は住むのにとても快適だ。（这房子住起来很舒适。）
- **飼う**（かう）饲养｜韩语参考：치다（饲养，喂） / 기르다（养，喂养，饲养，栽培） / 사육하다（饲养）<br>
  例：ナンシーは犬を飼いたがっていますか。（南希想养狗吗？）
- **換える**（かえる）交换；兑换｜韩语参考：바꾸다 / 교환하다<br>
  例：銀行に行けばその５０ドルの小切手を現金に換えてくれる。（去银行就能把那张五十美元支票换成现金。）
- **替える**（かえる）更换；替换｜韩语参考：갈다（换，替换） / 바꾸다（换，更换，调换）<br>
  例：お花の水を替えましょう。（我来给花换水吧。）
- **香り**（かおり）香味；香气｜韩语参考：향（香味） / 향기（香气，香味） / 향내（香味，香气）<br>
  例：そのバラはよい香りを発散した。（那朵玫瑰散发出好闻的香味。）
- **画家**（がか）画家｜韩语参考：화가（画家）<br>
  例：その画家は、いわば永遠の少年だ。（那位画家可以说是永远的少年。）
- **抱える**（かかえる）抱着；背负｜韩语参考：안다 / 떠안다<br>
  例：彼は両手に大きな箱を抱えていた。（他双手抱着一个大箱子。）
- **価格**（かかく）价格｜韩语参考：가격（价格，价钱） / 값（价格，价钱）<br>
  例：最も良い価格で見積もって下さい。（请报最好的价格。）

## 语法

- **普通形 + からこそ**：正因为…才…
  接续：動詞・い形 普通形 + からこそ；な形・名詞 + だ + からこそ
  朝鲜语：-니까 / -기 때문에야말로（韩语强调正因为用니까加야말로，或기 때문이다；无单一固定形，须组合表达。）
- **N / 普通形 + ばかりか**：不仅…而且…
  接续：名詞 + ばかりか；動詞・い形 普通形 + ばかりか；な形・名詞 + な/である + ばかりか
  朝鲜语：-(으)ㄹ 뿐만 아니라（韩语뿐만 아니라表不仅而且，后项可同程度；日语ばかりか后项常程度更高，还可接まで/も。）
