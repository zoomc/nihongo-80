## 新词 25

- **欲しい**（ほしい）想要｜韩语参考：원하다（希望，想要）<br>
  例：友人はマイカーを欲しがっている。（朋友想要一辆自己的车。）
- **ポスト**（ポスト）邮筒｜韩语参考：우체통（邮筒，邮箱，信箱，信筒）<br>
  例：ポストはどこにありますか。（邮筒在哪儿？）
- **細い**（ほそい）细；瘦｜韩语参考：가늘다（细，纤细）<br>
  例：彼は太っているくせに声は細い。（他明明很胖，声音却很细。）
- **ボタン**（ボタン）扣子；按钮｜韩语参考：단추（扣子，纽扣） / 버튼（按钮）<br>

- **まずい**（まずい）难吃；糟糕｜韩语参考：맛없다 / 곤란하다<br>
  例：あ！まずい！ガソリンが切れてきた。（啊！糟了！汽油快没了。）

- **丸い**（まるい）圆的｜韩语参考：동글다（圆圆的） / 둥글다（圆，圆圆的） / 둥그렇다（圆圆的）<br>

- **万**（まん）万｜韩语参考：만（万）<br>

- **万年筆**（まんねんひつ）钢笔｜韩语参考：만년필（钢笔）<br>

  例：二本の道はそこでクロスしている。（两条路在那里交叉。）
- **三日**（みっか）三天；三号｜韩语参考：사흘 / 삼 일<br>
  例：１０月３日です。（是十月三号。）
- **三つ**（みっつ）三个｜韩语参考：세 개<br>
  例：コーヒー三つおねがいします。（请来三杯咖啡。）

## 语法

- **〜より**：比…
  接续：名词 + より
  朝鲜语：보다（韩语 보다 与 より 对应，位置在比较对象后；日语 より 后直接接形容词，韩语 보다 后也直接接，语序相近。）
- **〜の方が〜より**：…比…更…
  接续：名词 + の方が + 名词 + より + 形容词
  朝鲜语：가/이 더 …（韩语用 이/가 더 表胜出项，보다 表基准；日语「の方が」是固定形式，不能换成 が。）
- **〜と〜とどちらが**：…和…哪个更…？
  接续：名词 + と + 名词 + とどちらが + 形容词 + か
  朝鲜语：A와 B 중 어느 쪽이（韩语用 와/과 중 어느 쪽이，日语用 と〜とどちらが；韩语需加 중，日语靠 どちら 本身表两者。）
