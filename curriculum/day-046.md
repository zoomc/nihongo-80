# Day 046 · 〜んです / 〜のです、〜かどうか、〜か（embedded question）、〜と思う

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜んです / 〜のです**：（解释）是…的；因为…
  接续：动词普通形／い形容词 + んです；な形容词+な／名词+な + んです
  朝鲜语：-ㄴ/는 것이다 / -거든요（韩语 -거든요 与 んです 的解释语气接近，但日语 んです 还可用于提问求解释；韩语 거든요 只用于陈述。）
- **〜かどうか**：是否…
  接续：动词、い形容词普通形 + かどうか；名词、な形容词非过去肯定词干直接接，或用 なのかどうか。
  朝鲜语：-인지 아닌지（오는지 아닌지 对照 来るかどうか，장소가 맞는지 对照 場所が合っているかどうか。有 どこ、誰 等疑问词时，用单独的 か 嵌入问句。）
- **〜か（embedded question）**：（嵌入）什么…、哪里…
  接续：疑问词 + …普通形 + か
  朝鲜语：-인지（어디서 열리는지 对照 どこで開かれるか。嵌入问句的 か 留在句内；外层句若也是问话，可另用 か，如 どこで開かれるか知っていますか。）
- **〜と思う**：我认为…
  接续：动词普通形／い形容词 + と思う；な形容词・名词 + だ + と思う
  朝鲜语：-다고 생각하다（조용하다고 생각해요 对照 静かだと思います。日语 な形容词、名词肯定谓语在 と 前加 だ；动词和い形容词普通形直接接 と。）
