# Day 106 · 〜ような / 〜ように（like）、まるで〜ようだ

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜ような / 〜ように（like）、まるで〜ようだ」造两句自己的话，表达：像…一样；如同…；简直像…一样

## 新词 14

- **クリーム**（クリーム）奶油｜韩语参考：크림（奶油）<br>
  例：彼女はデザート用にクリームを泡立てた。（她为做甜点打了奶油。）
- **繰り返す**（くりかえす）重复｜韩语参考：반복하다（反复，重复）<br>
  例：「いいえ」とイギリス人は繰り返しました。（那个英国人又说了一遍「不」。）
- **クリスマス**（クリスマス）圣诞节｜韩语参考：성탄（圣诞日，圣诞节） / 성탄절（圣诞节） / 크리스마스（圣诞节）<br>
  例：いいクリスマスを過ごしましたか。（圣诞节过得好吗？）
- **狂う**（くるう）失常；错乱｜韩语参考：돌다（失常，疯）<br>
  例：あなたの時計、時間は狂いませんか。（你的表走时准吗？）
- **グループ**（グループ）小组｜韩语参考：그룹（小组）<br>
  例：先生は私たちを二つのグループに分けた。（老师把我们分成两组。）
- **苦しい**（くるしい）痛苦；难受｜韩语参考：괴롭다（痛苦，难过） / 고통스럽다（痛苦，难受）<br>
  例：苦しい、やめろ。（难受死了，停下吧。）
- **苦しむ**（くるしむ）受苦｜韩语参考：괴로워하다<br>
  例：彼はどんなに苦しんだことだろう。（他不知道受了多少苦。）
- **暮れ**（くれ）年末；傍晚｜韩语参考：연말 / 해 질 녘<br>
  例：彼女はどうして良いか途方に暮れた。（她不知如何是好，束手无策。）
- **苦労**（くろう）辛苦；劳累｜韩语参考：고생（辛苦，艰苦，遭罪） / 수고（辛苦，受累）<br>
  例：せっかくの苦労もあだになった。（一番辛苦全白费了。）
- **加える**（くわえる）添加；加上｜韩语参考：더하다（加，加上）<br>
  例：水を加えてペースト状になるまでかき回しなさい。（加水搅成糊状。）
- **詳しい**（くわしい）详细；熟悉｜韩语参考：상세하다（详细） / 자상하다（仔细，详细） / 자세하다（仔细，详细）<br>
  例：このあたりはお詳しいですか。（您对这一带熟吗？）
- **加わる**（くわわる）加入；增加｜韩语参考：들다（入，加入） / 붙다（加入，投靠）<br>
  例：あなたはどちらのグループに加わりたいですか。（你想加入哪一组？）
- **訓**（くん）训读｜韩语参考：훈독<br>
  例：漢字の読み方には、音と訓の2通りがあるの。（汉字的读法有音读和训读两种。）
- **軍**（ぐん）军队｜韩语参考：군（军，军队） / 군대（部队，军队）<br>
  例：戦争は連合軍の勝利に終わった。（战争以盟军的胜利告终。）

## 语法

- **〜ような / 〜ように（like）**：像…一样；如同…
  接续：名词 + の + ような/ように；普通形 + ような/ように
  朝鲜语：-같은（韩语「-같은」修饰名词、「-같이」修饰动词，分工与日语相似；但日语名词前必须加「の」，韩语不加。）
- **まるで〜ようだ**：简直像…一样
  接续：まるで + 名词 + の + ようだ；まるで + 普通形 + ようだ
  朝鲜语：마치 -ㄴ 것 같다（韩语「마치」与日语「まるで」一样起强调作用；但韩语比喻常用「-처럼」，日语「ようだ」是断定结句，句法位置不同。）
