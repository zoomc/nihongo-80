# Day 073 · 〜だろう、～はずだ / ～わけではない

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜だろう、～はずだ / ～わけではない」造两句自己的话，表达：大概…吧；应该…／并不是…

## 新词 14

- **悩み**（なやみ）烦恼；苦恼<br>
  例：進路の悩みを相談します。（商量升学/出路的烦恼。）
- **嬉しい**（うれしい）高兴；开心<br>
  例：合格して嬉しいです。（考上了很开心。）
- **悲しい**（かなしい）悲伤；难过<br>
  例：別れは悲しいです。（离别令人难过。）
- **恥ずかしい**（はずかしい）害羞；难为情；惭愧<br>
  例：間違えて恥ずかしかったです。（弄错了，很不好意思。）
- **羨ましい**（うらやましい）羡慕<br>
  例：彼の語学力が羨ましいです。（羡慕他的语言能力。）
- **いただく**（いただく）承蒙给予；吃/喝（谦让语）<br>
  例：先生から資料をいただきました。（从老师那里拿到了资料。）
- **くださる**（くださる）给（我/我方）；赐予（尊敬语）<br>
  例：先生が本をくださいました。（老师给了我一本书。）
- **さしあげる**（さしあげる）（谦让地）给；呈上<br>
  例：先生にお土産をさしあげました。（给老师送了土特产。）
- **いらっしゃる**（いらっしゃる）在/去/来（尊敬语）<br>
  例：部長はもういらっしゃいますか。（部长已经到了吗？）
- **なさる**（なさる）做（尊敬语）<br>
  例：部長が説明なさいました。（部长做了说明。）
- **おっしゃる**（おっしゃる）说（尊敬语）<br>
  例：先生がそうおっしゃいました。（老师是那样说的。）
- **伺う**（うかがう）拜访；请教；打听（谦让语）<br>
  例：明日、先生の研究室に伺います。（明天去老师的研究室拜访。）
- **申す**（もうす）说；叫做（谦让语）<br>
  例：田中と申します。よろしくお願いします。（我姓田中，请多关照。）
- **遠慮**（えんりょ）客气；顾虑；谢绝<br>
  例：どうぞ遠慮なく召し上がってください。（请别客气，尽管吃。）

## 语法

- **〜だろう**：大概…吧
  接续：动词普通形／い形容词／な形容词／名词 + だろう
  朝鲜语：-(으)ㄹ 것이다 / -겠다（韩语 -(으)ㄹ 것이다 与 だろう 对应，-겠다 更偏主观意志或推测；日语 だろう 只表推测，不表意志。）
- **～はずだ / ～わけではない**：应该…／并不是…
  接续：普通形 + はずだ；普通形 + わけではない
  朝鲜语：-(으)ㄹ 것이다 / -는 것은 아니다（韩语理应推断用ㄹ 것이다或ㄹ 텐데，部分否定用는 것은 아니다；はずだ依据性更强。）
