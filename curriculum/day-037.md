# Day 037 · 〜方、〜中、〜つもり、〜予定

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜方**：…的方法；…的方式
  接续：动词ます形去ます + 方（かた）
  朝鲜语：-는 방법（쓰는 방법 对照 書き方。「写汉字的方法」整句是 漢字の書き方，动词变成复合名词后，原来的对象 漢字 用 の 连接。）
- **〜中**：正在…中；整个…；全…
  接续：名词 + 中（ちゅう／じゅう）
  朝鲜语：-중 / -내내（韩语 -중 对应 ちゅう（회의 중），-내내 对应 じゅう（하루 종일）；日语同一个汉字两种读法，韩语用不同词尾区分。）
- **〜つもり**：打算…；计划…
  接续：动词辞书形／动词ない形 + つもりだ
  朝鲜语：-(으)ㄹ 생각이다（韩语 -(으)ㄹ 생각이다 与 つもり 接近，但日语 つもり 可用于第二、三人称的确认；韩语 생각이다 多用于第一人称。）
- **〜予定**：预定…；计划…
  接续：动词辞书形 + 予定だ；名词 + の + 予定だ
  朝鲜语：-(으)ㄹ 예정이다（출장 예정입니다 对照 出張の予定です；去出差也可用 出張する予定です。日语名词和动词小句的接续不同。）
