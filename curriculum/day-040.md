# Day 040 · あげる / くれる / もらう、〜てあげる、〜てくれる

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「あげる / くれる / もらう、〜てあげる、〜てくれる」各造一句自己的话，表达：给…；别人给我…；从…得到；为别人做…（施惠）；（别人）为我做…

## 新词 20

- **聞こえる**（きこえる）听得见｜韩语参考：들리다<br>
  例：車が家の前に止まる音が聞こえた。（听到了车停在门前的声响。）
- **汽車**（きしゃ）火车｜韩语参考：기차（火车，列车）<br>
  例：汽車はまだ着きません。（火车还没到。）
- **季節**（きせつ）季节｜韩语参考：계절（季节，季） / 철（季节） / 시절（季节，时节）<br>
  例：秋は読書にもってこいの季節だ。（秋天正是读书的好季节。）
- **規則**（きそく）规则｜韩语参考：규칙（规则，规定，条例）<br>
  例：この規則はあなたにも当てはまる。（这条规则对你也适用。）
- **きっと**（きっと）一定｜韩语参考：필시（一定，肯定，必定，无疑） / 필연（一定，肯定，必定，无疑） / 필히（一定要，必须）<br>
  例：でもよー、オラのおとうさんは良い気しねーよ、きっと。（可是啊，俺爹肯定不高兴。）
- **絹**（きぬ）丝绸｜韩语参考：견（绢，丝绸） / 명주（绸子，丝绸）<br>
  例：この美しいドレスは絹で出来ている。（这条漂亮的裙子是丝绸做的。）
- **厳しい**（きびしい）严厉；严酷｜韩语参考：되다（狠毒，严厉） / 따갑다（严厉，逼人） / 매섭다（凛冽，严酷）<br>
  例：厳しい冬になるという話です。（听说今年冬天会很冷。）
- **決まる**（きまる）决定｜韩语参考：정해지다<br>
  例：いつ始めるのかはまだ決まっていない。（什么时候开始还没定。）
- **君**（きみ）你｜韩语参考：너（你） / 네（你） / 당신（你）<br>
  例：宿題を忘れるなんて君は不注意だった。（忘带作业，你太不小心了。）
- **着物**（きもの）和服｜韩语参考：기모노 / 일본 전통 의복<br>
  例：彼女はその着物を着ると変に見える。（她穿上那件和服看着很奇怪。）
- **客**（きゃく）客人｜韩语参考：손（客人） / 손님（客，客人）<br>
  例：春先だから客もあまりいませんでした。（因为刚开春，客人也不太多。）
- **急**（きゅう）急；陡｜韩语参考：급함 / 가파름<br>
  例：この川の流れは急だ。（这条河的水流很急。）
- **急行**（きゅうこう）快车｜韩语参考：급행（快巴，快车）<br>
  例：急行の料金は幾らですか。（快车票价多少钱？）
- **教育**（きょういく）教育｜韩语参考：교육（教育，培训）<br>
  例：この世界の教育にはがっかりしてしまう。（这个世界的教育让人失望。）
- **教会**（きょうかい）教堂｜韩语参考：교회（教会，教堂） / 성당（教堂，天主堂）<br>
  例：その教会は１１７３年までさかのぼる。（那座教堂的历史可追溯到1173年。）
- **競争**（きょうそう）竞争｜韩语参考：경쟁（竞争） / 경합（竞争，竞赛，角逐）<br>
  例：みんなでカブトムシを競争させた。（大家让独角仙比了一场。）
- **近所**（きんじょ）附近｜韩语参考：옆（旁边，附近） / 근처（附近，近处） / 가까이（近处，附近）<br>
  例：彼が近所に越してきた。（他搬到了附近。）
- **具合**（ぐあい）状况；身体｜韩语参考：상태 / 몸 상태<br>
  例：時計の具合が悪い。（手表出了毛病。）
- **空気**（くうき）空气｜韩语参考：공기（空气）<br>
  例：山の中では空気がとてもきれいだ。（山里空气非常清新。）
- **空港**（くうこう）机场｜韩语参考：공항（机场）<br>
  例：どの空港から出発しますか。（从哪个机场出发？）

## 语法

- **あげる / くれる / もらう**：给…；别人给我…；从…得到
  接续：给予者 は/が 接受者 に 物 を あげる；给予者 が 我方 に 物 を くれる；接受者 は 给予者 に/から 物 を もらう
  朝鲜语：주다 / 받다（韩语 주다 不分方向，日语必须按「谁给谁」区分 あげる／くれる；韩语 받다 对应 もらう，但日语 もらう 的来源可用 に 或 から。）
- **〜てあげる**：为别人做…（施惠）
  接续：动词て形 + あげる（对长辈用 さしあげる）
  朝鲜语：-아/어 주다（韩语 -아/어 주다 不区分谁受益，日语 てあげる 明确表示我方施惠；对长辈直接使用会显得失礼，韩语则靠敬语尾调整。）
- **〜てくれる**：（别人）为我做…
  接续：动词て形 + くれる（对长辈用 くださる）
  朝鲜语：-아/어 주다（韩语同样用 -아/어 주다，但日语 てくれる 的施益者必须作主语用 が；韩语靠语境，主语可省略。）
