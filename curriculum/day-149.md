## 语法

- **たとえ〜ても**：即使…也…
  接续：たとえ + Verb-te + も / たとえ + i-Adj-ku + ても / たとえ + na-Adj + でも / たとえ + 名词 + でも
  朝鲜语：설령 …해도（韩语提示按整块理解。换成日语时先套接续「たとえ + Verb-te + も / たとえ + i-Adj-ku + ても / たとえ + na-Adj + でも / たとえ + 名词 + でも」，再看下面的例句。）
- **〜ずに済む / 〜ないで済む**：不用…就解决了
  接续：Verb-nai stem + ずに済む / Verb-nai + で済む
  朝鲜语：하지 않아도 되었다（韩语提示按整块理解。换成日语时先套接续「Verb-nai stem + ずに済む / Verb-nai + で済む」，再看下面的例句。）
