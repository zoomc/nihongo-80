# Day 146 · 〜切る / 〜切れない

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜切る / 〜切れない」造两句自己的话，表达：…完；…不了

## 新词 21

- **苦手**（にがて）不擅长；怕｜韩语参考：서투르다 / 꺼리다<br>
  例：私は数学は苦手だ。（我不擅长数学。）
- **握る**（にぎる）握；掌握｜韩语参考：잡다（掌握，执掌） / 쥐다（握，攥） / 그러쥐다（掌握，掌控）<br>
  例：彼らが眠っている間私がハンドルを握った。（他们睡觉时由我握着方向盘。）
- **日**（にち）日；号｜韩语参考：일（日）<br>
  例：土日月の午前１０時半から午後４時まで開館。（周六、周日、周一上午10点半到下午4点开放。）
- **日常**（にちじょう）日常；平常｜韩语参考：일상（日常，日常生活，平常）<br>
  例：日常の運動はあなたのためになる。（日常运动对你有好处。）
- **日曜**（にちよう）星期日｜韩语参考：일요일<br>
  例：銀行は日曜にはやってません。（银行星期天不营业。）
- **日光**（にっこう）日光；阳光｜韩语参考：일광（日光） / 햇발（阳光，日光） / 햇볕（阳光，日光）<br>
  例：この部屋はあまり日光が当たらない。（这个房间晒不到多少太阳。）
- **にっこり**（にっこり）笑眯眯｜韩语参考：빙글（笑眯眯地，微微地） / 빙그레（笑眯眯地，微微地） / 해죽해죽（笑眯眯地）<br>
  例：彼女はにっこり笑ってそういった。（她笑眯眯地这样说了。）
- **日中**（にっちゅう）白天；日中｜韩语参考：날（白天） / 낮（白天，白日，日间） / 대낮（白天，大白天）<br>
  例：会社が日中合弁で経営しています。（这家公司由日中合资经营。）
- **日本**（にっぽん）日本｜韩语参考：일본<br>
  例：日本は中国の東方にある。（日本位于中国的东面。）
- **入場**（にゅうじょう）入场｜韩语参考：입장（入场，进场）<br>
  例：この切符で２名入場できます。（这张票可以两人入场。）
- **人気**（にんき）人气；受欢迎｜韩语参考：인기（人气）<br>
  例：人気がでて彼女はうぬぼれた。（走红之后她变得自负了。）
- **人間**（にんげん）人；人类｜韩语参考：인간（人，人类） / 사람（人）<br>
  例：彼は人間としてよくできた人です。（他为人很有修养。）
- **抜く**（ぬく）拔出；胜过｜韩语参考：빼내다（抽出，拔出）<br>
  例：最後まで戦い抜こう。（战斗到最后吧。）
- **抜ける**（ぬける）脱落；漏掉｜韩语参考：빠지다（脱落，掉）<br>
  例：歯が１本抜けた。（我掉了一颗牙。）
- **布**（ぬの）布｜韩语参考：천（布）<br>
  例：この布は値段の割に品質が良い。（这块布价格虽低，质量却好。）
- **ね**（ね）价值；价钱｜韩语参考：값 / 가격<br>
  例：彼はその絵にたいへん高い値をつけた。（他给那幅画定了很高的价。）
- **根**（ね）根；根性｜韩语参考：뿌리（根）<br>
  例：彼は根はやさしい男だった。（他骨子里是个善良的人。）
- **願い**（ねがい）愿望；请求｜韩语参考：원（愿，愿望，心愿） / 청（请求，委托，嘱托） / 소원（心愿，愿望）<br>
  例：市長は私達の願いを聞き入れてくれた。（市长接受了我们的请求。）
- **願う**（ねがう）希望；请求｜韩语参考：원하다（希望，想要）<br>
  例：足元に御用心願います。（请注意脚下。）
- **鼠**（ねずみ）老鼠｜韩语参考：쥐（老鼠，耗子）<br>
  例：猫がいなくなるとネズミたちが遊びだす。（猫一走，老鼠就闹起来了。）
- **熱帯**（ねったい）热带｜韩语参考：열대（热带）<br>
  例：あの島は熱帯性気候です。（那座岛是热带气候。）

## 语法

- **〜切る / 〜切れない**：…完；…不了
  接续：动词ます形词干 + 切る／切れない
  朝鲜语：-아/어 내다（韩语完成用「-아/어 내다」，日常更常说「다 -다」；日语「切る」强调“彻底做到最后”，还引申出“断然”的语感。）
