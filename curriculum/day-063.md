## 语法

- **普通形 + からこそ**：正因为…才…
  接续：動詞・い形 普通形 + からこそ；な形・名詞 + だ + からこそ
  朝鲜语：-니까 / -기 때문에야말로（韩语强调正因为用니까加야말로，或기 때문이다；无单一固定形，须组合表达。）
- **N / 普通形 + ばかりか**：不仅…而且…
  接续：名詞 + ばかりか；動詞・い形 普通形 + ばかりか；な形・名詞 + な/である + ばかりか
  朝鲜语：-(으)ㄹ 뿐만 아니라（韩语뿐만 아니라表不仅而且，后项可同程度；日语ばかりか后项常程度更高，还可接まで/も。）
- **Vます形(去ます) + ようがない / ようもない**：无法…；没有办法…
  接续：動詞ます形去ます + ようがない；する→しようがない；句末 ようがありません
  朝鲜语：-(으)ㄹ 방법이 없다（韩语ㄹ 방법이 없다表无手段，与能力不足的ㄹ 수 없다区分；同日语ようがない与できない之别。）
