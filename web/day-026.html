Day 026 · ～から / ～ので（原因）、条件形 使い分け（たら／ば／なら／と）、～ことが できる、～たことが ある

语法 4 条

～から / ～ので（原因）
발음～카라 / ～노데
因为…所以…
动词、い形普通形 + から／ので；名词、な形容词词干 + だから／なので；礼貌体后也可用 ですから／ですので。
から 偏主观、可接意志/命令；ので 偏客观、语气柔和
韩语对应-아/어서 / -(으)니까
韩语아/어서后不接命令请求，니까可接；日语から可接命令，ので语气较柔。
아메 가 후떼이루카라, 이키마센.
雨が降っているから、行きません。
因为在下雨，所以不去。
이소가시이노데, 이케마센.
忙しいので、行けません。
因为忙，去不了。
易错易混点
  • ✗ 雨 ので、行きません。✓ 雨なので、行きません。名词接 ので 要加 な（雨なので）；な形容词同理（静かなので）。
条件形 使い分け（たら／ば／なら／と）
如果／要是／一…就（四条件辨析）
たら 既定/假定通用；ば 假定；なら 承接话题；と 自然/必然结果
在 G0025 变形基础上区分语用：と 后不接意志，なら 承接对方刚提的话题
韩语对应-(으)면 / -다면 / -자마자
到达以后才做，用 駅に着いたら電話して（도착하면 전화해）。先确认对方计划再建议，用 京都に行くなら今のうちに予約して（갈 거라면 미리 예약해）。
아메 가 후따라, 이키마센.
雨が降ったら、行きません。
下雨的话就不去。
易错易混点
  • ✗ 雨が降るたら、出かけません。✓ 雨が降ったら、出かけません。たら 接た形（降ったら），降る 的た形是 降った。
～ことが できる
발음～코토가 데키루
会／能…（可能迂说）
動詞辞書形 + ことが + できる
表能力/可能；保留原动词的格助词（を），与可能形 G0024 可换
韩语对应-(으)ㄹ 수 있다
韩语与可能形同一表达ㄹ 수 있다，无迂说与形态之分；日语二者可换但接续不同。
니혼고 오 하나스코토 가 데키마스.
日本語を話すことができます。
会说日语。
易错易混点
  • ✗ 日本語が話すことができます。✓ 日本語を話すことができます。ことができる 前面的动词保留原来的 を，不要改成 が。
  • ✗ 話すことが できません（写成 話せことが）✓ 話すことができます。こと 前面用辞书形（話すこと），不能用可能形 話せる。
～たことが ある
발음～타코토가 아루
（曾经）做过…
動詞た形 + ことが + ある
表过去经验；与单纯过去 〜ました 不同，强调「有过这种经历」
韩语对应-(으)ㄴ 적이 있다
韩语经验用ㄴ 적이 있다，否定ㄴ 적이 없다；与单纯过去았/었的区分同日语。
코노혼 오 욘다코토 가 아리마스.
この本を読んだことがあります。
读过这本书。
易错易混点
  • ✗ 京都に行くたことがあります。✓ 京都に行ったことがあります。经历用た形＋ことがある（行ったことがある），不是辞书形。
