# Day 065 · 〜ても / 〜でも、〜のに（although）

- 阶段：P2｜60 分钟｜常规日

## 语法

- **〜ても / 〜でも**：即使…也…
  接续：动词て形+も；い形容词去い+くても；な形容词・名词+でも
  朝鲜语：-아/어도（韩语 -아/어도 与 ても 对应，但日语名词和な形容词用 でも，接续随词性变化；韩语则统一接词干。）
- **〜のに（although）**：明明…却…
  接续：动词普通形／い形容词 + のに；な形容词+な／名词+な + のに
  朝鲜语：-는데도（韩语 -는데도 与 のに 对应，同样带不满；但日语 のに 还可用于句末表遗憾，韩语 -는데도 不能单独结句。）
