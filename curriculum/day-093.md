# Day 093 · 〜まま、〜うちに

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜まま、〜うちに」各造一句自己的话，表达：就那样…；保持着…；趁着…；在…过程中

## 新词 22

- **参考**（さんこう）参考｜韩语参考：참고（参考，参照，参酌）<br>
  例：参考のためにカタログをお送りください。（请寄一份目录供参考。）
- **賛成**（さんせい）赞成｜韩语参考：찬성（赞成，赞同）<br>
  例：私たちの計画に賛成してくれますか。（你赞成我们的计划吗？）
- **酸素**（さんそ）氧气｜韩语参考：산소（氧，氧气）<br>
  例：酸素が無ければ生きられない。（没有氧气就无法生存。）
- **氏**（し）氏；先生｜韩语参考：씨 / 성씨<br>
  例：亡くなったスミス氏は医者でした。（已故的史密斯先生是医生。）
- **詩**（し）诗｜韩语参考：시（诗）<br>
  例：この詩は誰が書いたのですか。（这首诗是谁写的？）
- **幸せ**（しあわせ）幸福｜韩语参考：행복（幸福）<br>
  例：金持ちが幸せとは限らない。（有钱人不一定幸福。）
- **ジーンズ**（ジーンズ）牛仔裤｜韩语参考：청바지（牛仔裤）<br>
  例：私は日曜日はたいていジーンズをはいている。（我星期天大多穿牛仔裤。）
- **ジェット機**（ジェットき）喷气式飞机｜韩语参考：제트기（喷气式飞机）<br>
  例：ジェット機は東京に着陸した。（喷气式飞机在东京降落了。）
- **直に**（じかに）直接｜韩语参考：직접<br>
  例：あなたとじかに会ってじっくり話したいことがあるのです。（我有事想跟你当面好好谈谈。）
- **しかも**（しかも）而且；并且｜韩语参考：게다가<br>
  例：彼は音もなくしかもすばやく動ける。（他能又无声又迅速地移动。）
- **叱る**（しかる）责备；训斥｜韩语参考：책하다（责备，训斥，斥责） / 혼내다（训斥，呵斥） / 꾸중하다（责骂，训斥）<br>
  例：ママに叱られますよ。（会被妈妈骂的哦。）
- **式**（しき）仪式；公式｜韩语参考：식（仪式）<br>
  例：彼は事故でその式に出席できなかった。（他因事故没能出席那个仪式。）
- **時期**（じき）时期｜韩语参考：시기（时期，时节，季节）<br>
  例：１年のこの時期は天候がよく変わる。（每年这个时期天气变化很大。）
- **直**（じき）马上｜韩语参考：곧 / 즉시<br>
  例：彼女はじきよくなるだろう。（她很快就会好起来。）
- **支給**（しきゅう）发放；支付｜韩语参考：지급（支付，付给，颁发）<br>
  例：私たちは制服を支給された。（我们被发放了制服。）
- **しきりに**（しきりに）频频；一个劲儿｜韩语参考：자꾸 / 빈번하게<br>
  例：トムはしきりに新車を買いたがっている。（汤姆一个劲儿地想买新车。）
- **刺激**（しげき）刺激｜韩语参考：자극（刺激）<br>
  例：光が刺激となって花が咲く。（光是刺激，促使花开放。）
- **資源**（しげん）资源｜韩语参考：자원（资源）<br>
  例：海は各種の資源を与えてくれる。（大海给予我们各种资源。）
- **事件**（じけん）事件；案件｜韩语参考：사건（事件，案件）<br>
  例：この事件に手を貸してください。（请帮帮这个案子。）
- **時刻**（じこく）时刻｜韩语参考：시각（时刻，时候）<br>
  例：そろそろ寝る時刻だ。（快到睡觉的时间了。）
- **自殺**（じさつ）自杀｜韩语参考：자살（自杀）<br>
  例：自殺を防ぐための相談窓口があります。（有为预防自杀而设的咨询窗口。）
- **事実**（じじつ）事实｜韩语参考：사실（事实）<br>
  例：うわさは事実だとわかった。（传闻原来是真的。）

## 语法

- **〜まま**：就那样…；保持着…
  接续：动词た形/ない形 + まま；い形容词 + まま；ナ形容词 + な + まま；名词 + の + まま
  朝鲜语：-ㄴ 채로（韩语「-ㄴ 채로」与「まま」很接近；但日语可接名词「〜のまま」，韩语没有对应形式，要改说「그대로」。）
- **〜うちに**：趁着…；在…过程中
  接续：动词辞书形/ている/ない形 + うちに；い形容词 + うちに；ナ形容词 + な + うちに；名词 + の + うちに
  朝鲜语：-는 동안에（韩语「-는 동안에」只表时间范围；日语「うちに」还含“趁还没变、赶在期限前”的语感。）
