# Day 111 · 〜ば〜ほど、〜ほど

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜ば〜ほど、〜ほど」造两句自己的话，表达：越…越…；到了…的程度

## 新词 19

- **後者**（こうしゃ）后者｜韩语参考：후자（后者）<br>
  例：このうち大事なのは後者の方です。（其中重要的是后者。）
- **構成**（こうせい）构成｜韩语参考：구성（构成）<br>
  例：委員会は８名から構成されている。（委员会由八名成员组成。）
- **高速**（こうそく）高速｜韩语参考：고속（高速） / 고속 도로（高速公路）<br>
  例：運転者は高速を出し続けた。（司机一直保持高速行驶。）
- **行動**（こうどう）行动｜韩语参考：행동（行动，行为，举动） / 행위（行为，行动）<br>
  例：私がこの行動の責任はすべて取る。（这次行动的责任全由我来负。）
- **強盗**（ごうとう）强盗；抢劫｜韩语参考：강도（强盗） / 강도질（当强盗，抢劫） / 날강도（强盗， 抢劫犯，匪贼）<br>
  例：父は強盗と取っ組み合いをした。（父亲和劫匪扭打了起来。）
- **工場**（こうば）工厂｜韩语参考：공장<br>
  例：私の父と兄はこの工場で働いている。（我父亲和哥哥在这家工厂工作。）
- **幸福**（こうふく）幸福｜韩语参考：행복（幸福）<br>
  例：金持ちが必ずしも幸福とは限らない。（有钱人不一定幸福。）
- **公平**（こうへい）公平｜韩语参考：공평（公平，平等）<br>
  例：法が常に公平であるとは限らない。（法律未必总是公平的。）
- **候補**（こうほ）候选；候选人｜韩语参考：후보（候选人）<br>
  例：スミス氏は市長候補である。（史密斯先生是市长候选人。）
- **考慮**（こうりょ）考虑｜韩语参考：고려（考虑，斟酌）<br>
  例：彼らに同行しようかと考慮中です。（我正在考虑要不要跟他们一起去。）
- **越える**（こえる）超过；越过｜韩语参考：넘다（过，超过） / 넘기다（越过） / 넘어가다（超过，超）<br>
  例：それは人知の限界を越えている。（那超出了人类智慧的极限。）
- **コーチ**（コーチ）教练｜韩语参考：코치（教练，训练）<br>
  例：コーチが助言をしてくれた。（教练给了我建议。）
- **コード**（コード）代码；软线｜韩语参考：코드（代码，编码）<br>
  例：パソコンのコードを抜かないでください。（请不要拔掉电脑的电源线。）
- **氷**（こおり）冰｜韩语参考：얼음（冰）<br>
  例：船は氷に閉じ込められてしまった。（船被冰封住了。）
- **凍る**（こおる）结冰；冻｜韩语参考：얼다（冻结，冻）<br>
  例：道が凍っているから気を付けなさい。（路面结冰了，小心点。）
- **ゴール**（ゴール）终点；球门｜韩语参考：골（球门，球篮） / 골문（球门） / 결승점（终点）<br>
  例：ゴールまであと百メートルです。（离终点还有一百米。）
- **誤解**（ごかい）误解｜韩语参考：오해（误解，误会）<br>
  例：あなたを誤解してしまってごめんなさい。（对不起，我误会你了。）
- **語学**（ごがく）外语学习｜韩语参考：어학（外语）<br>
  例：これは私の語学の能力を有利に使える好機である。（这是能发挥我语言能力的好机会。）
- **呼吸**（こきゅう）呼吸；诀窍｜韩语参考：호흡（呼吸） / 숨（呼吸） / 숨쉬기（呼吸）<br>
  例：英語の発音の呼吸がなかなか飲み込めない。（英语发音的诀窍我怎么也掌握不了。）

## 语法

- **〜ば〜ほど**：越…越…
  接续：动词ば形 + 同一动词辞书形 + ほど；い形容词ければ + い形容词 + ほど；ナ形容词なら + ナ形容词な + ほど
  朝鲜语：-면 -ㄹ수록（韩语「-ㄹ수록」一个形式即可；日语要把同一词重复两次（すればするほど），形式负担更重。）
- **〜ほど**：到了…的程度
  接续：普通形 + ほど；名词 + ほど
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」与「ほど」基本对应；但日语「ほど」还用于「〜ほど〜ない」比较句，韩语要用「-만큼」。）

## 汉字 4

- **呼** 呼叫；呼唤｜音：コ｜训：よ.ぶ
- **達** 达到；们｜音：タツ、ダ｜训：-たち
- **良** 良好；好｜音：リョウ｜训：よ.い、-よ.い、い.い、-い.い
