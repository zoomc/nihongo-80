# Day 078 · 〜わけではない、〜わけがない

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜わけではない、〜わけがない」各造一句自己的话，表达：并不是…；并非…；不可能…；绝不会…

## 新词 25

- **欠ける**（かける）缺少；欠缺｜韩语参考：결하다（缺，缺乏，欠缺） / 부재하다（不在，不力，欠缺）<br>
  例：メアリーは思いやりに欠けている。（玛丽缺乏体贴。）
- **加減**（かげん）程度；火候｜韩语参考：정도 / 불 조절<br>
  例：お肉の焼き加減は、いかがなさいますか？（您的牛排要几分熟？）
- **過去**（かこ）过去｜韩语参考：과거（过去，从前） / 어제（过去，往日）<br>
  例：私はいつまでも過去にこだわらないようにと心がけている。（我一直提醒自己不要总纠结于过去。）
- **籠**（かご）篮子｜韩语参考：바구니（篮子，篮，筐）<br>
  例：そのかごはリンゴでいっぱいだった。（那个篮子装满了苹果。）

  例：火災の理由は何か。（火灾的原因是什么？）
- **菓子**（かし）点心；糕点｜韩语参考：과자<br>

- **家事**（かじ）家务｜韩语参考：가사（家务） / 집일（家务） / 가정일（家务）<br>

- **歌手**（かしゅ）歌手｜韩语参考：가수（歌手）<br>

- **数**（かず）数量；数目｜韩语参考：숫자（数字，数目）<br>
  例：旅行者の数が近年大きく増加した。（游客数量近年大幅增加。）
- **稼ぐ**（かせぐ）赚钱｜韩语参考：벌다<br>
  例：彼は使い切れない程のお金を稼ぐ。（他赚的钱多得花不完。）
- **数える**（かぞえる）数；计算｜韩语参考：세다（数） / 셈하다（数，计数） / 헤아리다（数，计）<br>

- **型**（かた）型；模型｜韩语参考：틀（模子，模具，模型） / 형（型，式）<br>
  例：その像は型に入れられて作られた。（那座像是用模具铸成的。）
- **肩**（かた）肩膀｜韩语参考：어깨（肩，肩膀）<br>
  例：肩が痛い。（肩膀疼。）

  例：わからなかったら方々の人に聞いた方がいいよ。（不懂的话最好到处问问人。）

- **勝ち**（かち）胜利｜韩语参考：승리<br>

- **がっかり**（がっかり）失望；沮丧｜韩语参考：실망하다<br>
  例：その知らせにはがっかりだ。（听到那个消息很失望。）
- **活気**（かっき）活力；生气｜韩语参考：활기（朝气，活力，生气，生机） / 생기（朝气，活力）<br>
  例：その街は活気にあふれていた。（那条街充满活力。）
- **学期**（がっき）学期｜韩语参考：학기（学期）<br>
  例：前学期は成績がよかった。（上学期成绩很好。）

## 语法

- **〜わけではない**：并不是…；并非…
  接续：普通形 + わけではない；ナ形容词 + な + わけではない；名词 + という + わけではない
  朝鲜语：-는 것은 아니다（韩语「-는 것은 아니다」也表部分否定，但常缩成「-는 게 아니다」；日语「わけではない」更明确针对“由此推出的结论”。）
- **〜わけがない**：不可能…；绝不会…
  接续：普通形 + わけがない；ナ形容词 + な + わけがない；名词 + の/な + わけがない
  朝鲜语：-ㄹ 리가 없다（韩语「-ㄹ 리가 없다」与「わけがない」几乎一一对应；但韩语口语常说「-ㄹ 리가 없잖아」反驳，日语习惯前加「そんな」。）
