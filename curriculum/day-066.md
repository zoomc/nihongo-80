# Day 066 · 〜によって / 〜による、〜によると / 〜によれば、〜ばかりでなく

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜によって / 〜による**：由…；由于…；因…而异
  接续：名词 + によって；名词 + による + 名词
  朝鲜语：…에 따라 / … 때문에 / …에 의해（역에 따라 다르다 对照 駅によって違う；비 때문에 지연되다 对照 雨によって遅れる；被动句中的行为者还可对应 …에 의해。）
- **〜によると / 〜によれば**：据…说
  接续：来源（名词） + によると／によれば，后面陈述该来源提供的信息。
  朝鲜语：-에 따르면（일기 예보에 따르면 对照 天気予報によると。后句常用 そうだ、とのことだ，也可用陈述句报告客观数据，无须每次都添传闻句末。）
- **〜ばかりでなく**：不仅…而且…
  接续：普通形 + ばかりでなく；ナ形容词 + な + ばかりでなく；名词 + ばかりでなく
  朝鲜语：-뿐만 아니라（韩语「-뿐만 아니라」与日语几乎完全对应；但日语后项习惯加「も」，韩语可省，容易漏掉「も」。）
