# Day 052 · N + に 対して / に 関して、N / V辞書形 + に 伴って / に つれて / に 従って、N + に 基づいて / を もとに / どおり(に)

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **N + に 対して / に 関して**：对…（针对对象/对比）／关于…（书面）
  接续：名詞 + に対して（动作/态度的对象，或「与此相对」的对比）；名詞 + に関して（＝について 的书面语）
  朝鲜语：-에 대해 / -에 관해（制度について／制度に関して 对照 제도에 관해，针对人的态度 客に対して丁寧に 对照 손님을 대할 때 정중하게。对比从句用 のに対して，可对应 반면에。）
- **N / V辞書形 + に 伴って / に つれて / に 従って**：随着…（前项变化，后项也跟着变化）
  接续：过程 + につれて／に伴って／に従って 常接随之发生的变化；名词 + に従って 也可表示遵循指示、规则。
  朝鲜语：-에 따라 / -(으)면서（韩语伴随变化用에 따라或면서，比例变化多用ㄹ수록；日语三形语感细分更多。）
- **N + に 基づいて / を もとに / どおり(に)**：基于…／以…为依据／按照…
  接续：名詞 + に基づいて（依据资料/规则/数据）；名詞 + をもとに（以…为素材/基础）；名詞 + どおり(に)（照原样、按预定）
  朝鲜语：-에 근거해 / -을 바탕으로 / -대로（韩语에 근거해表依据、을 바탕으로表以…为基础、대로表按照，与日语三形基本对应。）
