今日语法 2 条

N / Vます形(去ます) + がちだ
발음N / V마스카타치 + 가치다
容易…；往往…（多指不好的倾向）
名詞 + がちだ；動詞ます形去ます + がちだ；がちな + 名詞
表示某种（多负面）倾向容易发生；常用「〜がちです／がちな人」。
아사와덴샤가오쿠레가치데스.
朝は電車が遅れがちです。
早上电车容易晚点。
忙しい時期は、食事が不規則になりがちです。
忙碌时期，饮食容易不规律。
朝鲜语：-기 쉽다 / -는 경향이 있다
韩语기 쉽다表容易(中性)，负面倾向用는 경향이 있다；日语がちだ多负面，语感更窄。
易错点

彼は病気がちなです。 → 彼は病気がちです。（がち 是な形容詞型，接です 用「がちです」，不用「がちなです」；中文“容易生病”直译。）

普通形 + はずがない
不可能…；理应不会…
動詞・い形普通形 + はずがない；な形容詞 + な／名詞 + の + はずがない
根据事实/常识强烈否定某可能性；比单纯「ない」更有推断依据。
카레가야쿠소쿠오와스레루하즈가아리마센.
彼が約束を忘れるはずがありません。
他不可能忘记约定。
電車が止まっているので、今到着するはずがありません。
电车停了，现在不可能到达。
朝鲜语：-(으)ㄹ 리가 없다
韩语ㄹ 리가 없다表绝不可能，推断依据强；与单纯否定안不同，同日语はずがない。
易错点

彼が来るはずがないでした。 → 彼が来るはずがありませんでした。（はずがない 是现在否定，过去用「はずがありませんでした／はずがなかったです」；ないでした 不合法。）
