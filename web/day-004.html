今日语法 3 条

N の N
발음N 노 N
…的…；所属/修饰
名詞 + の + 名詞
连体修饰、所属、同位；中文「的」的对应，但不可滥用
와타시노혼데스.
私の本です。
是我的书。
니혼고노센세이데스.
日本語の先生です。
是日语老师。
朝鲜语：N의 N
韩语의多表所属，口语常省略；修饰关系更常用名词直接并列，使用范围比日语の窄。
易错点

私は本です。 → 私の本です。（该用 の 表所属却用 は；中文「我的书」直译成「我 是 书」）

が（主语／新信息／存在主体）
발음가
…（主语/新信息/存在主体/能力对象）
名詞 + が + 動詞／形容詞
表主语、新信息、疑问词主语、存在主体、能力/好恶对象
네코가이마스.
猫がいます。
有猫。
다레가키마스카.
誰が来ますか。
谁来？
朝鲜语：이/가
韩语主格助词按收音选이/가，口语가常被는替换表对比；日语が还表能力对象。
易错点

私がは学生です。 → 私は学生です。（が 与 は 不能叠加；自我介绍用 は 提示主题，が 标记新信息焦点（如「誰が学生ですか」→「私が学生です」），两者分工不同。）

を（宾语／移动经过）
발음오
把…（标宾语）
名詞 + を + 他動詞
标动作直接宾语；也表移动经过的场所（空を飛ぶ）
고한오타베마스.
ご飯を食べます。
吃饭。
朝鲜语：을/를
韩语宾格助词按收音选을/를，口语可省略；日语を还能表移动经过，韩语该义也用를。
易错点

ご飯が食べます。 → ご飯を食べます。（他动词宾语用 を；中文「饭」是主语感觉，直译成 が 错）
