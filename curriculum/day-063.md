# Day 063 · 〜ば、〜たら

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜ば、〜たら」造两句自己的话，表达：如果…；如果…；…之后

## 新词 19

- **盗む**（ぬすむ）偷；盗窃｜韩语参考：훔치다（偷，盗，盗取） / 도둑질하다（偷窃，盗窃）<br>
  例：盗まれたお金があきらめられない。（被偷的钱我放不下。）
- **塗る**（ぬる）涂；抹｜韩语参考：바르다（涂，抹）<br>
  例：ジョンがドアにペンキを塗っていた。（约翰在给门刷漆。）
- **ぬれる**（ぬれる）淋湿；湿｜韩语参考：젖다<br>
  例：木のおかげで雨にぬれずにすんだ。（多亏那些树，我才没被雨淋湿。）
- **ねだん**（ねだん）价格｜韩语参考：가격<br>
  例：このラジオの値段はいくらですか。（这台收音机多少钱？）
- **熱**（ねつ）发烧；热度｜韩语参考：신열（发烧，发热）<br>
  例：１０２゜Ｆの熱があります。（烧到华氏102度。）
- **ねっしん**（ねっしん）热心；勤奋｜韩语参考：열심이다<br>
  例：彼女は熱心に小鳥にえさをやった。（她热心地给小鸟喂食。）
- **寝坊**（ねぼう）睡懒觉；睡过头｜韩语参考：늦잠（懒觉）<br>
  例：彼はときどき寝坊する。（他有时会睡过头。）
- **眠い**（ねむい）困；发困｜韩语参考：졸리다（困）<br>
  例：テレビを見ているとすぐ眠くなる。（一看电视就容易犯困。）
- **眠る**（ねむる）睡；睡眠｜韩语参考：자다（睡，睡觉） / 잠자다（睡觉，睡眠）<br>
  例：もし眠るといけないので目覚し時計をセットしなさい。（免得睡着，把闹钟设好。）
- **残る**（のこる）剩下；留下｜韩语参考：남다（剩，剩下）<br>
  例：もう３ページ残っている。（还剩三页。）
- **のど**（のど）喉咙｜韩语参考：목 / 목구멍<br>
  例：のどがヒリヒリします。（喉咙火辣辣地疼。）
- **乗り換える**（のりかえる）换乘｜韩语参考：갈아타다（换乘，倒） / 환승하다（换乘，换车）<br>
  例：東京駅で列車を乗り換えなさい。（请在东京站换乘列车。）
- **乗り物**（のりもの）交通工具｜韩语参考：탈것（交通工具）<br>
  例：乗り物は子供向けである。（这些游乐设施是给小孩玩的。）
- **葉**（は）叶子｜韩语参考：잎（叶子） / 잎사귀（叶子）<br>
  例：こちらには大きなハスの葉があります。（这里有巨大的荷叶。）
- **場合**（ばあい）场合；情况｜韩语参考：경우<br>
  例：システムが作動しない場合がある。（有时系统会不工作。）
- **パート**（パート）兼职；计时工｜韩语参考：시간제 일 / 아르바이트<br>
  例：ごめんね。明日は朝からパートがあるのよ。（抱歉，明天一早我有兼职。）
- **倍**（ばい）倍｜韩语参考：배（倍） / 곱（倍） / 곱절（倍）<br>
  例：あの山はこの山の５倍の高さである。（那座山的高度是这座山的五倍。）
- **拝見**（はいけん）拜读；看｜韩语参考：뵙다 / 보다（겸양）<br>
  例：パスポートを拝見できますか。（能让我看一下您的护照吗？）
- **歯医者**（はいしゃ）牙医；牙科｜韩语参考：치과 의사 / 치과<br>
  例：今日歯医者へ行きました。（今天去看了牙医。）

## 语法

- **〜ば**：如果…
  接续：五段动词词尾改え段+ば；一段动词去る+れば；い形容词去い+ければ；な形容词・名词+なら
  朝鲜语：-(으)면（韩语 -(으)면 与 ば 对应，但日语 ば 的后项一般不能是意志、命令；韩语 -(으)면 没有这个限制。）
- **〜たら**：如果…；…之后
  接续：动词た形 + ら；い形容词去い+かったら；な形容词・名词+だったら
  朝鲜语：-(으)면 / -았/었더니（韩语 -(으)면 表条件，-았/었더니 表前项完成后的发现；日语 たら 一个形式兼表两者，使用范围更广。）

## 汉字 4

- **操** 操；操作；操弄｜音：ソウ｜训：あやつる
- **作** 作；制作；作品；操作｜音：サク、サ｜训：つくる
- **渋** 涩；涩滞；不流畅｜音：ジュウ｜训：しぶい
- **滞** 滞；停滞；滞留｜音：タイ｜训：とどこおる
