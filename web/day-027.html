今日语法 3 条

～そうです（样态／传闻）
발음～소우데스
看起来…／听说…
样态：ます形词干/い形去い/な形词干 + そう；传闻：普通形 + そうです
样态表肉眼推断，传闻表转述；两者接续不同，意义完全不同
韩语对应-아/어 보이다 / -다고 하다
韩语样态用아/어 보이다，传闻用다고 하다，形态完全不同；日语そうだ须按接续分辨。
아메 가 오리소우데스.
雨が降りそうです。
看起来要下雨。
아시타 와 아메다소우데스.
明日は雨だそうです。
听说明天有雨。

易错点 おいしいそうです（想表样态） → おいしそうです。（い形容词样态是 おいしそう（去 い）；おいしいそう 是传闻「听说好吃」）

～ようだ / ～らしい
발음～요우다 / ～라시이
好像…／似乎…（推测）
普通形 + ようだ／らしい（名 + の + ようだ）
ようだ 偏主观直感，らしい 偏传闻/典型特征；名词接 ようだ 要加 の
韩语对应-(으)ㄴ 것 같다 / -(으)ㄴ 모양이다
韩语推测最常用것 같다，传闻典型用다고 하다；日语ようだ主观、らしい客观传闻。
카레 와 이소가시이요우데스.
彼は忙しいようです。
他好像很忙。
아시타 와 아메라시이데스.
明日は雨らしいです。
明天好像有雨。

易错点 雨ようです。 → 雨のようです。（名词接 ようだ 要加 の：雨のようです）

～かもしれない / ～でしょう
발음～카모시레나이 / ～데쇼우
也许…／大概…吧
普通形 + かもしれない；普通形 + でしょう
かもしれない 表不确定推测，でしょう 表较有把握的推量/委婉断定
韩语对应-(으)ㄹ지도 모르다 / -겠다
韩语不确定用ㄹ지도 모르다，较强推量用겠다或ㄹ 것이다；でしょう无对应敬语分层。
아시타 와 아메 카모 시레마센.
明日は雨かもしれません。
明天也许下雨。
카레 와 쿠루데쇼우.
彼は来るでしょう。
他大概会来吧。

易错点 雨でしょう かもしれません → 雨でしょう。／雨かもしれません。（でしょう 与 かもしれない 是两种推测，不叠加）
