今日语法 3 条

〜よ
句子 + よ
〜よ
…哦；…呀（告知、强调）
用于告诉对方不知道的信息，或强调自己的判断，语气较强。
このラーメンはとてもおいしいですよ。
这拉面很好吃哦。
かさを忘れていますよ。
你忘了带伞哦。
明日はテストがありますよ。
明天有考试哦。
朝鲜语：-요 / -거든요
韩语 -요 是礼貌尾，不专门表告知；日语 よ 明确提示新信息，韩语需靠 -거든요 或语调表达。
易错点

このラーメンはとてもおいしいよです。 → このラーメンはとてもおいしいですよ。（よ 接句末，后不能加 です）

〜より
名词 + より
〜より
比…
表示比较的基准，常与「の方が」呼应。
今日はきのうより寒いです。
今天比昨天冷。
電車はバスより速いです。
电车比公交车快。
兄は父より背が高いです。
哥哥比父亲高。
朝鲜语：보다
韩语 보다 与 より 对应，位置在比较对象后；日语 より 后直接接形容词，韩语 보다 后也直接接，语序相近。
易错点

今日はきのうよりが寒いです。 → 今日はきのうより寒いです。（より 后不加 が）

〜の方が〜より
名词 + の方が + 名词 + より + 形容词
〜の方が〜より
…比…更…
明确指出两者中较优或程度更高的一方，より 引出比较基准。
犬の方が猫より好きです。
我更喜欢狗，而不是猫。
東京の方が大阪より人が多いです。
东京比大阪人多。
夏より冬の方が好きです。
比起夏天，我更喜欢冬天。
朝鲜语：가/이 더 …
韩语用 이/가 더 表胜出项，보다 表基准；日语「の方が」是固定形式，不能换成 が。
易错点

犬が方が猫より好きです。 → 犬の方が猫より好きです。（需要用「の方が」，不是「が方が」）
