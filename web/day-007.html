Day 007 · い形容词（～い です）、な形容词（～です）、ます形（丁寧体）

语法 3 条

い形容词（～い です）
…（い形容词谓语）
い形容詞 + です
い形容词作谓语，礼貌体直接加 です，不再加 だ
韩语对应형용사 어간 + 다 / -아·어요
비싸요 已在形容词内部变出礼貌词尾。日语 高い 自己承载活用，可直接结句；礼貌体 高いです 保留 い。
코노혼 와 타카이데스.
この本は高いです。
这本书贵。
易错易混点
  • ✗ 本は高いだ。✓ 本は高い。／本は高いです。い形容词可以直接结句（高い），客气一点加 です（高いです），不能加 だ。
  • ✗ 高い な 本✓ 高い本い形容词接名词直接连（高い本），中间不加 な。
な形容词（～です）
…（な形容词谓语）
な形容詞語幹 + です／だ
な形容词词干后接 です；连体形加 な，副词形加 に
韩语对应조용하다 → 조용한 방
用 조용해요 对照 静かです，用 조용한 방 对照 静かな部屋。な 只在 静か 直接修饰名词时出现。
코노헤야 와 시즈카데스.
この部屋は静かです。
这个房间安静。
카노조 와 겐키데스.
彼女は元気です。
她很精神。
易错易混点
  • ✗ 静か部屋です。✓ 静かな部屋です。な形容词接名词要带 な（静かな部屋）；结句时才用 だ／です。
  • ✗ 静か の 部屋✓ 静かな部屋な形容词接名词用 な，不是 の。
ます形（丁寧体）
발음마스카타치
动词礼貌形：ます／ません／ました／ませんでした
五段：う段→い段 + ます；一段：去 る + ます；する→します；来る（くる）→来ます（きます）
礼貌体现在/否定/过去/过去否定；是て/た/ない形的基础
韩语对应-습니다/ㅂ니다 / -아·어요
읽습니다／읽어요 都有礼貌，分属不同语体。日语动词礼貌体先掌握一套 ます 活用，遇到敬语动词再按对象选词。
마이니치, 가꼬우 에 이키마스.
毎日、学校へ行きます。
每天去学校。
고한 오 타베마스.
ご飯を食べます。
吃饭。
易错易混点
  • ✗ 食べります。✓ 食べます。食べる 是一段动词，去掉 る 直接接 ます（食べます），不会多出 り。
  • ✗ 行きませんだった。✓ 行きませんでした。过去否定固定是 ませんでした，不是 ません＋だった。
