# Day 066 · 普通形 + と は 限らない、Vて + いただけませんか / もらえませんか

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「普通形 + と は 限らない、Vて + いただけませんか / もらえませんか」各造一句自己的话，表达：未必…；不一定…；不见得…；能否请您…（很礼貌的请求）

## 新词 23

- **遅延**（ちえん）延误；晚点｜韩语参考：지연<br>
  例：電車に二十分の遅延が出ています。（电车晚点20分钟。）
- **運休**（うんきゅう）停运｜韩语参考：운휴（停运）<br>
  例：台風で電車が運休になりました。（台风导致电车停运。）
- **乗り換え**（のりかえ）换乘｜韩语参考：환승（换乘）<br>
  例：次の駅で乗り換えが必要です。（下一站需要换乘。）
- **到着**（とうちゃく）到达｜韩语参考：도착（到达）<br>
  例：電車は十時に到着します。（电车10点到达。）
- **出発**（しゅっぱつ）出发｜韩语参考：출발（出发）<br>
  例：バスは八時に出発します。（公交8点出发。）
- **混雑**（こんざつ）拥挤｜韩语参考：혼잡（混杂，纷杂，混乱，拥挤）<br>
  例：朝の電車はとても混雑します。（早上的电车非常拥挤。）
- **経由**（けいゆ）经由；途经｜韩语参考：경유（经由，路过，途经） / 경유지（经由地，中转站） / 기착지（经由地，临时着陆地）<br>
  例：このバスは図書館を経由します。（这趟公交途经图书馆。）
- **運賃**（うんちん）车费；运费｜韩语参考：운임（运费） / 교통비（交通费，车费） / 운송료（运费，运输费）<br>
  例：運賃は二百円です。（车费200日元。）
- **経済**（けいざい）经济｜韩语参考：경제（经济）<br>
  例：経済のニュースを毎朝見ます。（每天早上看经济新闻。）
- **企業**（きぎょう）企业｜韩语参考：기업（企业，公司） / 업체（企业） / 기업체（企业，企业实体）<br>
  例：この企業は新しい製品を作っています。（这家企业在做新产品。）
- **物価**（ぶっか）物价｜韩语参考：물가（物价）<br>
  例：最近、物価が上がっています。（最近物价在上涨。）
- **環境**（かんきょう）环境｜韩语参考：환경（环境）<br>
  例：環境を守るために、ごみを減らします。（为保护环境减少垃圾。）
- **台風**（たいふう）台风｜韩语参考：태풍（台风）<br>
  例：台風で学校が休みになりました。（台风导致学校停课。）
- **避難**（ひなん）避难｜韩语参考：피난（避难，逃难，避乱） / 피란（避难，逃难，避乱）<br>
  例：地震のときは高い場所へ避難してください。（地震时请到高处避难。）
- **観光**（かんこう）观光；旅游｜韩语参考：관광（旅游，观光）<br>
  例：週末に京都へ観光に行きます。（周末去京都观光。）
- **伝統**（でんとう）传统｜韩语参考：전통（传统）<br>
  例：この町には古い伝統があります。（这个镇有古老传统。）
- **増加**（ぞうか）增加｜韩语参考：증가（增加）<br>
  例：利用者の数が増加しています。（使用者数量在增加。）
- **減少**（げんしょう）减少｜韩语参考：감소（减少，下降）<br>
  例：今年は外出する人が減少しました。（今年外出的人减少了。）
- **傾向**（けいこう）倾向｜韩语参考：경향（倾向）<br>
  例：その傾向は今年も続いています。（那个趋势今年也在持续。）
- **割合**（わりあい）比例；比率｜韩语参考：비율（比率，比例）<br>
  例：女性の割合は半分以上です。（女性比例超过一半。）
- **調査**（ちょうさ）调查｜韩语参考：조사（调查）<br>
  例：市が住民に調査を行いました。（市里对居民进行了调查。）
- **発表**（はっぴょう）发布；发表｜韩语参考：발표（发表，发布）<br>
  例：結果は明日発表されます。（结果明天公布。）
- **見込み**（みこみ）预计；可能性｜韩语参考：가망성（希望，可能性）<br>
  例：雨は夜には止む見込みです。（预计雨夜里会停。）

## 语法

- **普通形 + と は 限らない**：未必…；不一定…；不见得…
  接续：動詞・い形 普通形 / 名詞・な形（＋だ 常省）+ とは 限らない；常与 必ずしも／すべて／〜からといって 呼应
  朝鲜语：-다고 해서 다 …는 것은 아니다（韩语用「다고 해서 다…는 아니다」表未必，比日语とは限らない冗长，口语常说꼭 그런 건 아니다。）
- **Vて + いただけませんか / もらえませんか**：能否请您…（很礼貌的请求）
  接续：動詞 て形 + いただく（谦让）可能形 いただけませんか；或 もらう 可能形 もらえませんか
  朝鲜语：-아/어 주시겠어요?（韩语敬语请求用주시겠어요，比주세요客气；日语いただけませんか用否定疑问，韩语用肯定疑问加시겠。）

- **能** 能；能力；可能；艺能｜音：ノウ｜训：
