今日语法 3 条

N に Vて ほしい / Vないで ほしい
발음N 니 V테 호시이 / V나이데 호시이
希望（别人）做…／希望别…
動詞 て形 + ほしい；否定 ない形 + で + ほしい；动作主体用 に（或 が）
てほしい 表说话人希望某事发生，动作主体可以是他人或自然事物；对人直接提出要求时要考虑关系与礼貌程度。
모우스코시마떼호시이데스.
もう少し待ってほしいです。
希望（你）再等一下。
오오키나코에데하나시사나이데호시이데스.
大きな声で話さないでほしいです。
希望别大声说话。
朝鲜语：-아/어 주기를 바라다
韩语希望别人做用주기를 바라다，对长辈须加시；日语てほしい不宜直接对长辈说。
易错点

私は映画を見てほしいです。 → 映画が見たいです。（「我想看」应用 見たい；てほしい 是希望别人做，中文「想」不分主体易错）

名詞/な形词干 + みたい(だ/な/に)
好像…；像…一样（口语推量/比喻）
名詞 + みたい（不加 の）；な形 词干 + みたい；動詞/い形 普通形 + みたい；みたいな＋名／みたいに＋動
口语版 〜ようだ（G0044）；比 らしい/そう 更随意；比喻用 まるで…みたい
카레와겐키자나이미타이데스.
彼は元気じゃないみたいです。
他好像不太精神。
쿄우와하루미타이니아타타카이데스.
今日は春みたいに暖かいです。
今天暖和得像春天。
朝鲜语：-(으)ㄴ 것 같다 / -처럼
韩语比喻和推测都用같다，口语最常用；日语みたい是ようだ口语版，韩语无正式口语两套。
易错点

彼は学生のみたいです。 → 彼は学生みたいです。（名词接 みたい 不加 の（ようだ 才要 の）；中文「像是学生」直译加 の 错）

V ます形(去ます) + やすい / にくい
발음V 마스카타치 + 야스이 / 니쿠이
容易…／难以…
動詞 ます形 去 ます + やすい・にくい；整体按 い形容詞 变形（読みやすくない／読みやすかった）
表示做该动作的难易程度（不是能力），主语多用 が；偏客观属性
코노혼와요미야스이데스.
この本は読みやすいです。
这本书好读。
코노펜와카키니쿠이데스.
このペンは書きにくいです。
这支笔不好写。
朝鲜语：-기 쉽다 / -기 어렵다
韩语用기 쉽다/어렵다分析形，书面感强；日语やすい/にくい是一体化后缀，更口语。
易错点

この本は読むやすいです。 → この本は読みやすいです。（必须接 ます形去ます（読み），不能用辞书形 読む；中文「容易读」直译错）
