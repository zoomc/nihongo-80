# Day 074 · Nの / Vている + 最中に（だ）、Vた形 + ところで

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「Nの / Vている + 最中に（だ）、Vた形 + ところで」造两句自己的话，表达：正在…的时候（突然…）；即使…也（不会有预期结果）

## 新词 24

- **老い**（おい）年老；老年｜韩语参考：노년 / 늙음<br>
  例：少年老い易く学成り難し。（少年易老学难成。）
- **追い付く**（おいつく）追上；赶上｜韩语参考：따라서다（赶上） / 따라오다（跟上，赶上） / 따라잡다（追上，赶上）<br>
  例：トムに追いつくために走らなければならなかった。（为了追上汤姆，我不得不跑。）
- **王**（おう）王；国王｜韩语参考：왕（王） / 임금（国王，君主）<br>
  例：彼らは王の殺害をたくらんでいる。（他们正密谋杀害国王。）
- **追う**（おう）追赶；追求｜韩语参考：좇다（追求） / 쫓다（赶，追赶） / 뒤쫓다（追赶，紧追）<br>
  例：今日は時間に追われていてね。（今天一直忙得团团转。）
- **王様**（おうさま）国王｜韩语参考：상감（国王陛下）<br>
  例：その王様はいつも王冠をかぶっている。（那位国王总是戴着王冠。）
- **王子**（おうじ）王子｜韩语参考：왕자（王子）<br>
  例：王子は森で道に迷った。（王子在森林里迷了路。）
- **応じる**（おうじる）响应；根据｜韩语参考：응하다 / 따르다<br>
  例：彼は収入に応じた生活をしている。（他过着与收入相称的生活。）
- **横断**（おうだん）横穿；横渡｜韩语参考：횡단（横穿，横过，横渡）<br>
  例：彼はヨットで太平洋を横断した。（他乘帆船横渡了太平洋。）
- **終える**（おえる）结束；完成｜韩语参考：맺다（结尾，结束） / 끝내다（结束，完成） / 끝맺다（结束，完结）<br>
  例：その仕事をもう終えましたか。（那份工作已经做完了吗？）
- **大いに**（おおいに）大大地；非常｜韩语参考：크게 / 대단히<br>
  例：私は彼を大いに尊敬しています。（我非常尊敬他。）
- **覆う**（おおう）覆盖；掩盖｜韩语参考：뒤덮다（覆盖，笼罩）<br>
  例：机はほこりで覆われている。（桌子上落满了灰尘。）
- **オーバー**（オーバー）大衣；超过｜韩语参考：외투 / 초과<br>
  例：あなたはオーバーなしですますつもりですか。（你打算不穿大衣就对付过去吗？）
- **大家**（おおや）房东｜韩语参考：주인집（房东，房东家） / 집주인（房主，房东）<br>
  例：その大家は以前は暮らし向きがよかったそうだ。（听说那个房东以前日子过得不错。）
- **丘**（おか）小山；丘陵｜韩语参考：둔덕（坎，岗，堤，丘陵） / 언덕（坡，丘陵，山坡，山丘）<br>
  例：その丘は見晴らしがよい。（那座小山视野很好。）
- **沖**（おき）海上；洋面｜韩语参考：먼바다<br>
  例：その島は海岸から１マイル沖にある。（那座岛在离海岸一英里的海上。）
- **奥**（おく）里面；深处｜韩语参考：속（里面，里头） / 안（里，里面）<br>
  例：彼らはレストランの奥の方に座った。（他们坐在餐厅里面。）
- **贈る**（おくる）赠送｜韩语参考：선사하다（赠送，馈赠，带来）<br>
  例：ドロシーは彼にすばらしい贈り物を贈った。（多萝西送了他一份很好的礼物。）
- **起こる**（おこる）发生｜韩语参考：나다（发，发生） / 생기다（发生，产生） / 벌어지다（发生）<br>
  例：あとで起こったことはなお悪かった。（后来发生的事更糟。）
- **幼い**（おさない）年幼；幼稚｜韩语参考：연소하다（年少，年幼）<br>
  例：彼の考えはとても幼い。（他的想法非常幼稚。）
- **収める**（おさめる）取得；收纳｜韩语参考：거두다（获得，取得，赢得） / 거둬들이다（取得，获得，赢得） / 거두어들이다（取得，获得，赢得）<br>
  例：そのアメリカ映画は大成功を収めた。（那部美国电影获得了巨大成功。）
- **おしゃべり**（おしゃべり）聊天；话多｜韩语参考：수다 / 수다스럽다<br>
  例：彼らは天気についておしゃべりした。（他们聊了聊天气。）
- **汚染**（おせん）污染｜韩语参考：오염（污染）<br>
  例：汚染が地球を傷つけている。（污染正在伤害地球。）
- **おそらく**（おそらく）恐怕；大概｜韩语参考：아마 / 어쩌면<br>
  例：首相はおそらく辞任するであろう。（首相恐怕会辞职。）
- **恐れる**（おそれる）害怕；担心｜韩语参考：겁나다（畏惧，害怕） / 겁내다（害怕，畏惧） / 겁먹다（受惊吓，害怕）<br>
  例：大人はしばしば変化を恐れる。（大人常常害怕变化。）

## 语法

- **Nの / Vている + 最中に（だ）**：正在…的时候（突然…）
  接续：名詞 + の + 最中に；動詞ている + 最中に；句末可 最中だ
  朝鲜语：-는 중에 / -는 도중에（韩语는 중表正在，도중에表途中；日语最中に强调正到一半被打断，语感更强。）
- **Vた形 + ところで**：即使…也（不会有预期结果）
  接续：動詞た形 + ところで；后项多为否定或无意义的结果
  朝鲜语：-아/어도 / -더라도（韩语让步用아/어도，强调用더라도；日语ところで后项必为否定性结果，韩语无此限制。）
