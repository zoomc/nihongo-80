# Day 019 · 〜が（subject）、〜を

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜が（subject）、〜を」造两句自己的话，表达：…是主语；提示新信息；…是宾语；经过的场所

## 新词 19

- **御飯**（ごはん）米饭；饭｜韩语参考：밥<br>
  例：ご飯とパンどちらがいいですか。（米饭和面包你要哪个？）
- **コピーする**（コピーする）复印｜韩语参考：복사하다（复印）<br>
  例：コピーするページに付箋をつけておいてください。（请在要复印的那几页贴上标签。）
- **困る**（こまる）为难；困扰｜韩语参考：딱하다（为难，难堪，尴尬） / 난처하다（为难，不好办）<br>
  例：時間がなくてたいへん困っている。（时间不够，我很为难。）
- **ごめんなさい**（ごめんなさい）对不起｜韩语参考：미안합니다<br>
  例：お話し中、ごめんなさい。（打扰您说话了，对不起。）
- **これ**（これ）这个｜韩语参考：요（这个） / 이것（这个）<br>
  例：これは兄です。かっこいいですね。（这是我哥哥。很帅吧。）
- **今月**（こんげつ）这个月｜韩语参考：이번 달 / 금월<br>
  例：今月の売り上げはよくない。（这个月销售额不好。）
- **こんな**（こんな）这样的｜韩语参考：이런（这样的）<br>
  例：こんな本を読んで何になるのか。（读这种书有什么用呢。）
- **今晩**（こんばん）今晚｜韩语参考：오늘 밤<br>
  例：今晩はパーティーがあるのかなあ。（今晚是有聚会吗？）
- **さあ**（さあ）来吧；这个嘛｜韩语参考：자 / 글쎄<br>
  例：さあ、パーティーをおしまいにしよう。（好了，聚会就到此结束吧。）
- **財布**（さいふ）钱包｜韩语参考：지갑（钱包，钱夹，钱袋） / 손지갑（小钱包）<br>
  例：サイフがないのにふと気がついた。（他忽然发觉钱包不见了。）
- **先**（さき）前面；先前｜韩语参考：앞 / 먼저<br>
  例：それから先の話を聞きたい。（我想听那之后的情节。）
- **咲く**（さく）开花｜韩语参考：꽃이 피다<br>
  例：チューリップがみごとに咲いた。（郁金香开得很漂亮。）
- **作文**（さくぶん）作文｜韩语参考：작문（作文，写作） / 글짓기（作文，写作）<br>
  例：作文は書いてしまいましたか。（作文写完了吗？）
- **差す**（さす）撑（伞）；照射｜韩语参考：들다（照射进来，涨，起） / 쓰다（撑，打） / 받치다（撑）<br>
  例：彼は雨の中を傘もささずに歩きつづけた。（他在雨中连伞也不撑，一直走着。）
- **雑誌**（ざっし）杂志｜韩语参考：잡지（杂志） / 잡지책（杂志）<br>
  例：その雑誌はどこで買えますか。（那本杂志在哪里能买到？）
- **砂糖**（さとう）糖｜韩语参考：설탕（糖，砂糖）<br>
  例：ポットにはあまり砂糖がなかった。（壶里没剩多少糖。）
- **さようなら**（さようなら）再见｜韩语参考：안녕히 가세요 / 안녕히 계세요<br>
  例：では今晩またね、さようなら。（那今晚见，再见。）
- **再来年**（さらいねん）后年｜韩语参考：후년（后年） / 내후년（大后年）<br>
  例：祖父は、再来年引退する予定です。（祖父打算后年退休。）
- **散歩**（さんぽ）散步｜韩语参考：산보（散步） / 산책（散步）<br>
  例：散歩に出かけてもよろしいですか。（我可以出去散散步吗？）

## 语法

- **〜が（subject）**：…是主语；提示新信息
  接续：名词 + が
  朝鲜语：이/가（주어·신정보）（韩语 이/가 同样标新信息主语；日语疑问词主语强制用 が，韩语疑问词后也强制 이/가，这点相近，差别在日语 は 的对比用法更重。）
- **〜を**：…是宾语；经过的场所
  接续：名词 + を（读作 o）
  朝鲜语：을/를（목적어）（韩语 을/를 只标宾语；日语 を 还标移动经过的场所（公園を歩く），韩语此处用 를 或 에서，需单独记。）
