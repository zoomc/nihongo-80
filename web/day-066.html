Day 066 · 〜によって / 〜による、〜によると / 〜によれば、〜ばかりでなく

语法 3 条

〜によって / 〜による
발음〜니요떼 / 〜니요루
由…；由于…；因…而异
名词 + によって；名词 + による + 名词
表被动句的动作主体、原因手段，或“依…而不同”。
韩语对应…에 따라 / … 때문에 / …에 의해
역에 따라 다르다 对照 駅によって違う；비 때문에 지연되다 对照 雨によって遅れる；被动句中的行为者还可对应 …에 의해。
この橋は、有名な建築家によって設計された。
这座桥是由著名建筑师设计的。
타이후우 니요루 히가이 와, 마다세이카쿠 니 와 와카떼이나이.
台風による被害は、まだ正確には分かっていない。
台风造成的损失还没有准确查明。
쿠니 니요떼, 쇼쿠지 노 마나아 와 즈이분치가우.
国によって、食事のマナーはずいぶん違う。
餐桌礼仪因国家不同而差别很大。
易错易混点
  • ✗ 台風によるの被害は大きかった。✓ 台風による被害は大きかった。说 による被害 或 によっての被害，不要说 によるの被害。
〜によると / 〜によれば
발음〜니요루토 / 〜니요레바
据…说
来源（名词） + によると／によれば，后面陈述该来源提供的信息。
引出消息来源，句末接「そうだ／らしい／ということだ」。
韩语对应-에 따르면
일기 예보에 따르면 对照 天気予報によると。后句常用 そうだ、とのことだ，也可用陈述句报告客观数据，无须每次都添传闻句末。
텐키요호우 니 요루토, 슈우마쓰 와 오오유키 니 나루소우다.
天気予報によると、週末は大雪になるそうだ。
据天气预报，周末会下大雪。
뉴우스 니 요레바, 지코 노 겐인 와 마다와카떼이나이라시이.
ニュースによれば、事故の原因はまだ分かっていないらしい。
据新闻说，事故原因似乎还不清楚。
아네 노 하나시 니 요루토, 아노레스토란 와 요야쿠 가 나이 토 이레나이 토이우 코토다.
姉の話によると、あのレストランは予約がないと入れないということだ。
听姐姐说，那家餐厅不预约进不去。
易错易混点
  • ✗ 天気予報によって、週末は大雪になるそうだ。✓ 天気予報によると消息来源用 によると／によれば；によって 是手段或原因。
〜ばかりでなく
발음〜바카리데나쿠
不仅…而且…
普通形 + ばかりでなく；ナ形容词 + な + ばかりでなく；名词 + ばかりでなく
追加同类或更高层次的事项，后项多带「も」。
韩语对应-뿐만 아니라
韩语「-뿐만 아니라」与日语几乎完全对应；但日语后项习惯加「も」，韩语可省，容易漏掉「も」。
코노에이가 와 코도모 바카리 데나쿠, 오토나 모 타노시메루.
この映画は子どもばかりでなく、大人も楽しめる。
这部电影不仅孩子爱看，大人也能享受。
新しいスマホは画面が大きいばかりでなく、電池も長持ちする。
新手机不仅屏幕大，电池也耐用。
運動は体にいいばかりでなく、ストレスを減らす効果もある。
运动不仅对身体好，还有减压的效果。
易错易混点
  • ✗ 新しいスマホは画面が大きばかりでなく、電池も長持ちする。✓ 画面が大きいばかりでなくい形容词要保留词尾 い：大きいばかりでなく。
