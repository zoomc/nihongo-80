# Day 008 · い形容词 否定／过去／て形、な形容词 否定／过去／で、て形

## 新词 25

- **言う**（いう）说｜韩语参考：보다（说） / 말하다（说，讲） / 얘기하다（说，评价）<br>
  例：「みんなひと休みしようぜ」とジョンは言った。（约翰说：“大家歇一会儿吧。”）
- **いかが**（いかが）怎么样｜韩语参考：어떠세요<br>
  例：コンタクトを入れるというのはいかがでしょう？（戴隐形眼镜怎么样？）
- **いくつ**（いくつ）几个；几岁｜韩语参考：몇 개 / 몇 살<br>
  例：あなたのお父さんはおいくつですか。（您父亲多大年纪了？）
- **池**（いけ）池塘｜韩语参考：못（池塘，水洼） / 연못（莲池，荷塘，池塘）<br>
  例：その池にはほとんど水がない。（那个池塘里几乎没有水。）
- **いす**（いす）椅子｜韩语参考：의자<br>
  例：ちょっと椅子をずらしてくれない？（能把椅子挪一下吗？）
- **いちばん**（いちばん）最；第一｜韩语参考：가장 / 첫째<br>
  例：このリンゴがいちばんおいしい。（这个苹果最好吃。）
- **いつ**（いつ）什么时候｜韩语参考：언제<br>
  例：いつ旅行においでになりますか。（您什么时候去旅行？）
- **五日**（いつか）五天；五号｜韩语参考：닷새（五天）<br>
  例：１月５日から１月１５日までおねがいします。（请订1月5日到1月15日。）
- **一緒**（いっしょ）一起｜韩语参考：함께<br>
  例：「ご一緒してもいいですか」「もちろんです」（“我可以跟您一起去吗？”“当然。”）
- **五つ**（いつつ）五个｜韩语参考：다섯 개<br>
  例：この箱にはリンゴが五つ入っている。（这个箱子里装着五个苹果。）
- **犬**（いぬ）狗｜韩语参考：개（狗，犬）<br>
  例：その犬はかみついたりしませんよ。（那条狗不会咬人的。）
- **嫌**（いや）讨厌；不愿意｜韩语参考：질색（讨厌，厌恶，厌烦）<br>
  例：毎日うっとうしくていやですね。（天天这么阴雨天，真烦人。）
- **入口**（いりぐち）入口｜韩语参考：입구<br>
  例：１台の車が入り口に止まった。（一辆车停在了入口处。）
- **要る**（いる）需要｜韩语参考：필요하다<br>
  例：今のところお金はいらない。（现在不需要钱。）
- **入れる**（いれる）放进；装入｜韩语参考：넣다（放进，装进） / 집어넣다（放进去）<br>
  例：それは引き出しに入れておきました。（那个我放进抽屉里了。）
- **色**（いろ）颜色｜韩语参考：색깔（颜色，色彩）<br>
  例：カメレオンはどんな色にでもなれる。（变色龙能变成任何颜色。）
- **いろいろ**（いろいろ）各种各样｜韩语参考：여러 가지<br>
  例：先生といってもいろいろある。（老师也分各种各样的。）
- **後ろ**（うしろ）后面｜韩语参考：뒤（后，后面） / 뒤쪽（后面，后头，后部） / 뒷면（后面，背面，反面）<br>
  例：校長が先生の後ろから入ってきた。（校长从老师身后走了进来。）
- **薄い**（うすい）薄；淡｜韩语参考：묽다（稀，薄） / 얇다（薄） / 엷다（薄）<br>
  例：コーヒーは薄いのが好きです。（我喜欢淡一点的咖啡。）
- **歌**（うた）歌｜韩语参考：노래（歌，歌曲，唱歌）<br>
  例：歌がうまければいいのになあ。（我要是唱歌好听就好了。）
- **歌う**（うたう）唱｜韩语参考：뽑다（唱） / 부르다（唱） / 뽑아내다（唱）<br>
  例：ジョンはステージで何を歌いましたか。（约翰在台上唱了什么？）
- **生まれる**（うまれる）出生｜韩语参考：나다（生，出生） / 출생되다（出生，出世） / 출생하다（出生，出世）<br>
  例：どんぐりからオークが生まれる。（橡树由橡子长成。）
- **海**（うみ）海｜韩语参考：바다（海，大海，海洋）<br>
  例：何としても海をひと目みたいものだ。（我真想看一眼大海。）
- **売る**（うる）卖｜韩语参考：팔다（卖，出售） / 팔아먹다（卖）<br>
  例：トムはメアリーにバイクを売った。（汤姆把摩托车卖给了玛丽。）
- **煩い**（うるさい）吵；烦人｜韩语参考：시끄럽다 / 귀찮다<br>
  例：あの子はなんてうるさい子だろう。（那孩子真够闹的。）

## 语法

- **い形容词 否定／过去／て形**：不…／曾…／又…（い形变形）
  接续：高い→高くない／高かった／高くて
  朝鲜语：-지 않다 / -았·었- / -고（韩语否定用지 않다、过去用았/었、中顿用고，无日语くて的音便变化。）
- **な形容词 否定／过去／で**：不…／曾…／而…（な形变形）
  接续：静か→静かではない／静かだった／静かで
  朝鲜语：-지 않다 / -았·었- / -고（韩语形容词否定与过去共用一套词尾，不分な形い形；中顿고不表原因。）
- **て形**：动词て形（连接/中顿/请求基础）
  接续：五段音便（って/んで/いて/いで/して）；一段 去る+て；カ変 来て；サ変 して
  朝鲜语：-고 / -아·어서（韩语连接词尾按语义分고(并列)、서(顺序/原因)，不能一词尾通吃；日语て形用途更广。）
