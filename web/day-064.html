今日语法 3 条

〜ようとする
발음〜요우토스루
想要…；正要…
动词意志形 + とする（否定形：ようとしない）
表示尝试做某动作，或动作即将发生的瞬间。
韩语对应-(으)려고 하다 / -(으)려던 참이다
韩语「-려고 하다」也表意图，但“正要…的瞬间”日语说「ようとしたとき」，韩语多用「-려던 참에」，形式不同。
ドアを開けようとしたが、鍵がかかっていて開かなかった。
我想开门，但锁着打不开。
家を出ようとしたとき、急に雨が降り出した。
正要出门时，突然下起雨来。
弟は何度注意しても、部屋を片付けようとしない。
弟弟不管怎么提醒，都不肯收拾房间。

易错点 ドアを開けますようとしたが、鍵がかかっていた。 → 開けようとした（「ようとする」前接意志形「開けよう」，不能插入「ます」。）

〜そうにない / 〜そうもない
발음〜소우니나이 / 〜소우모나이
看样子不会…；不像会…
动词ます形词干 + そうにない／そうもない
从现状判断某事难以实现，是样态「そうだ」的否定。
韩语对应-(으)ㄹ 것 같지 않다
韩语没有专门对应，常说「-ㄹ 것 같지 않다」；日语「そうにない」依据眼前迹象，主观判断色彩更强。
코노아메 와, 유우가타 마데 야미소우 니 나이.
この雨は、夕方までやみそうにない。
这场雨看样子到傍晚也停不了。
시고토 가 오오스기테, 쿄우주우 니 와 오와리소우 모 나이.
仕事が多すぎて、今日中には終わりそうもない。
工作太多，今天之内看样子做不完。
콘나니타쿠산 노 료우리, 후타리데 와 타베키레소우 니 나이 네.
こんなにたくさんの料理、二人では食べきれそうにないね。
这么多菜，两个人看样子吃不完。

易错点 この雨は、夕方までやむそうにない。 → やみそうにない（「そうにない」前接ます形词干「やみ」，「やむそう」不是合法形式。）

〜一方だ
발음〜이뽀우다
一直…；越来越…
动词辞书形 + 一方だ
表示某变化只朝一个方向持续发展，多用于负面趋势。
韩语对应계속 …하다 / 점점 더 …해지다
물가가 계속 오르다 可对照 物価は上がる一方だ，后者强调走势只向上涨一侧。-기만 하다 常说一个人只做某事，适合对照 てばかりいる。
この町の人口は、減る一方だ。
这个镇的人口一直在减少。
物価は上がる一方なのに、給料は全然上がらない。
物价一个劲上涨，工资却完全不涨。
벤쿄우 오 사보떼이타라, 세이세키 와 사가루이뽀우다따.
勉強をさぼっていたら、成績は下がる一方だった。
一直偷懒，成绩就一路下滑。

易错点 この町の人口は、減り一方だ。 → 減る一方だ（「一方だ」前接辞书形「減る」，不能接ます形词干「減り」。）
