## 新词 25

- **宇宙**（うちゅう）宇宙｜韩语参考：우주（宇宙）<br>
  例：宇宙には限りはない。（宇宙没有尽头。）
- **撃つ**（うつ）射击；打击｜韩语参考：쏘다 / 공격하다<br>

  例：私たちは会合を延期しなければならなかった。（我们不得不把会议延期。）

## 语法

- **Nの / Vている + 最中に（だ）**：正在…的时候（突然…）
  接续：名詞 + の + 最中に；動詞ている + 最中に；句末可 最中だ
  朝鲜语：-는 중에 / -는 도중에（韩语는 중表正在，도중에表途中；日语最中に强调正到一半被打断，语感更强。）
- **Vた形 + ところで**：即使…也（不会有预期结果）
  接续：動詞た形 + ところで；后项多为否定或无意义的结果
  朝鲜语：-아/어도 / -더라도（韩语让步用아/어도，强调用더라도；日语ところで后项必为否定性结果，韩语无此限制。）
- **普通形 + ものだから / もので**：因为…（所以…）；由于…
  接续：動詞・い形 普通形 + ものだから；な形・名詞 + な/だ + ものだから；もので 更书面
  朝鲜语：-는 바람에 / -기 때문에（韩语辩解多用는 바람에(多坏事)或기 때문에；日语ものだから带撒娇式辩解，韩语靠语调体现。）
