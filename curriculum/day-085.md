# Day 085 · 〜一方だ、〜一方で

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜一方だ、〜一方で」造两句自己的话，表达：一直…；越来越…；一方面…；同时…

## 新词 24

- **組合**（くみあい）工会；组合｜韩语参考：조합（组合）<br>
  例：組合はデモに参加しましたか。（工会参加游行了吗？）
- **組む**（くむ）组合；交叉｜韩语参考：짜다 / 엮다 / 꼬다<br>
  例：私は彼らが腕を組んで歩いているのを見た。（我看见他们挽着手臂走路。）
- **位**（くらい）位；左右｜韩语参考：자리（位） / 언저리（左右）<br>
  例：５８１４を千の位に四捨五入すれば何になりますか。（5814四舍五入到千位是多少？）
- **暮らし**（くらし）生活｜韩语参考：삶（生活） / 살림（生活，日子，持家） / 살림살이（生活，过日子，持家）<br>

- **クリスマス**（クリスマス）圣诞节｜韩语参考：성탄（圣诞日，圣诞节） / 성탄절（圣诞节） / 크리스마스（圣诞节）<br>

- **苦しい**（くるしい）痛苦；难受｜韩语参考：괴롭다（痛苦，难过） / 고통스럽다（痛苦，难受）<br>

  例：漢字の読み方には、音と訓の2通りがあるの。（汉字的读法有音读和训读两种。）
- **軍**（ぐん）军队｜韩语参考：군（军，军队） / 군대（部队，军队）<br>
  例：戦争は連合軍の勝利に終わった。（战争以盟军的胜利告终。）
- **軍隊**（ぐんたい）军队｜韩语参考：군대（部队，军队） / 군（军，军队）<br>
  例：軍隊は川のところまで進出した。（军队推进到了河边。）
- **訓練**（くんれん）训练｜韩语参考：훈련（训练）<br>
  例：私は馬をレース用に訓練している。（我在训练一匹马参加比赛。）

## 语法

- **〜一方だ**：一直…；越来越…
  接续：动词辞书形 + 一方だ
  朝鲜语：-기만 한다（韩语「-기만 한다」偏“只做某事”；日语「一方だ」专指程度单向加剧，常带忧虑，韩语更常说「계속 -고 있다」。）
- **〜一方で**：一方面…；同时…
  接续：普通形 + 一方で；ナ形容词 + な + 一方で；名词 + である + 一方で
  朝鲜语：-는 반면에（韩语「-는 반면에」只表对比；日语「一方で」还能表“同时进行的两件事”，范围更宽。）
