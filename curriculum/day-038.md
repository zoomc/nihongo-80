# Day 038 · 〜ことにする、〜ことになる、〜える / 〜られる（potential）、〜れる / 〜られる（passive）

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 新词 25

- **線**（せん）线｜韩语参考：선（线） / 줄（线） / 라인（线，线条）<br>
  例：この線の終点はどこですか。（这条线的终点在哪里？）
- **ぜんぜん**（ぜんぜん）完全（不）｜韩语参考：전혀（부정과 함께）<br>
  例：私はビールはぜんぜん飲みません。（我完全不喝啤酒。）
- **戦争**（せんそう）战争｜韩语参考：전쟁（战争）<br>
  例：戦争が起こらなければいいと思う。（我希望不要发生战争。）
- **先輩**（せんぱい）前辈；学长｜韩语参考：선배（前辈）<br>
  例：彼は仕事の上では私の先輩だ。（在工作上他是我的前辈。）
- **そう**（そう）似乎；那样｜韩语参考：그렇게 / 그런 것 같다<br>
  例：まもなく雨が降りそうだ。（看样子马上就要下雨了。）
- **育てる**（そだてる）养育；培育｜韩语参考：기르다（养，养育，抚育） / 키우다（培育，培养）<br>
  例：クッキーはケイトによって育てられた。（库琪是凯特养大的。）
- **卒業**（そつぎょう）毕业｜韩语参考：졸업（毕业）<br>
  例：私はポップ・ミュージックはそろそろ卒業しようと思っているの。（我想我差不多该告别流行音乐了。）
- **祖父**（そふ）祖父；外祖父｜韩语参考：조부（祖父，外祖父）<br>
  例：祖父はステッキがないと歩けない。（祖父没有拐杖就走不了路。）
- **ソフト**（ソフト）柔软；温和｜韩语参考：부드럽다 / 온화하다<br>
  例：スミスさんはソフトな語り口の人物です。（史密斯先生说话语气温和。）
- **祖母**（そぼ）祖母；外祖母｜韩语参考：조모（祖母，外祖母）<br>
  例：私は祖母が大好きです。（我很爱我的祖母。）
- **それで**（それで）因此；所以｜韩语参考：따라서（因此，所以）<br>
  例：それで、その金はどこから出るんだよ？（那么，那笔钱从哪里来？）
- **それに**（それに）而且；加上｜韩语参考：게다가<br>
  例：それに、みんなに仲間もできるしね。（而且，大家还能交到伙伴。）
- **それほど**（それほど）那么；那种程度｜韩语参考：그다지 / 그 정도로<br>
  例：いや、それほど混んでなかったよ。（不，没那么挤。）
- **大事**（だいじ）重要；宝贵｜韩语参考：소중하다 / 중요하다<br>
  例：彼は私たちにとって大事な人だ。（他对我们来说是重要的人。）
- **大体**（だいたい）大致；大概｜韩语参考：한（大概） / 대강（大致，大略，草草） / 대개（大部分，大概，大致）<br>
  例：それらはだいたい同じくらいの大きさだ。（它们大小差不多。）
- **たいてい**（たいてい）大都；通常｜韩语参考：대개 / 보통<br>
  例：夜はたいていの人が寝る時である。（夜晚是大多数人睡觉的时候。）
- **タイプ**（タイプ）类型；款式｜韩语参考：타입（类型，样式）<br>
  例：こういうタイプの人はおもしろくない。（这种类型的人很无趣。）
- **大分**（だいぶ）相当；很｜韩语参考：꽤 / 상당히<br>
  例：だいぶ痛みがなくなりました。（疼痛已经减轻了不少。）
- **倒れる**（たおれる）倒下；倒闭｜韩语参考：넘어가다（倒下，倾斜） / 넘어지다（倒闭，垮台，败北） / 쓰러지다（倒下）<br>
  例：彼は横にばったり倒れた。（他一下子倒在了地上。）
- **確か**（たしか）确实；大概｜韩语参考：확실히 / 아마<br>
  例：彼が間違っているのは確かです。（他错了，这是确实的。）
- **足す**（たす）加；添｜韩语参考：더하다（加，加上） / 플러스하다（加）<br>
  例：６０にするためには１７に何を足せばよいの。（要凑成60，17还得加上多少？）
- **尋ねる**（たずねる）询问｜韩语参考：묻다<br>
  例：お尋ねしてもよろしいでしょうか。（可以请教您一下吗？）
- **訪ねる**（たずねる）拜访｜韩语参考：찾다（拜访，寻访，探访） / 찾아보다（去找，去见，拜访，走访）<br>
  例：いつでも私のオフィスを訪ねなさい。（随时来我的办公室找我。）
- **正しい**（ただしい）正确｜韩语参考：맞다（正确，对） / 옳다（对，正确） / 바르다（正确，属实）<br>
  例：これが正しいかどうか自信がないんだ。（我不确定这是否正确。）
- **畳**（たたみ）榻榻米｜韩语参考：다다미<br>
  例：彼は畳の上に大の字になった。（他四肢摊开躺在榻榻米上。）

## 语法

- **〜ことにする**：决定…
  接续：动词辞书形／动词ない形 + ことにする
  朝鲜语：-기로 하다（韩语 -기로 하다 与 ことにする 对应，但日语 ことにしている 可表持续的习惯，韩语 -기로 하고 있다 较少这样用。）
- **〜ことになる**：决定…；结果变成…
  接续：动词辞书形／动词ない形 + ことになる
  朝鲜语：-게 되다（韩语 -게 되다 也与 ことになる 对应，但日语 ことになる 强调「被决定」的过程，韩语 게 되다 还可表能力或状态的自然变化。）
- **〜える / 〜られる（potential）**：能…；会…
  接续：五段动词词尾改え段+る；一段动词去る+られる；する→できる；来る→来られる
  朝鲜语：-(으)ㄹ 수 있다（韩语用 -(으)ㄹ 수 있다 表能力，与日语可能形对应；但日语可能形是动词活用，韩语是句尾构式，且日语宾语常改用 が。）
- **〜れる / 〜られる（passive）**：被…；遭受…
  接续：五段动词未然形+れる；一段动词未然形+られる；する→される；来る→来られる
  朝鲜语：피동 (-이/히/리/기-)（韩语用被动词尾或 -에 의해，日语用助动词 れる／られる；日语受害被动（足を踏まれた）在韩语中常改用主动句或 -당하다。）
