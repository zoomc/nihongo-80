今日语法 3 条

まるで〜ようだ
발음마루데〜요우다
简直像…一样
まるで + 名词 + の + ようだ；まるで + 普通形 + ようだ
用夸张比喻描述强烈的相似感，常与「まるで」呼应。
韩语对应마치 -ㄴ 것 같다
韩语「마치」与日语「まるで」一样起强调作用；但韩语比喻常用「-처럼」，日语「ようだ」是断定结句，句法位置不同。
코노헤야 와 히로쿠테아카루쿠테, 마루데호테루 노 요우다.
この部屋は広くて明るくて、まるでホテルのようだ。
这个房间又大又亮，简直像宾馆一样。
久しぶりに会った友達は、まるで別人のように変わっていた。
久别重逢的朋友变了个样，简直像另一个人。
三月なのに、今日はまるで真夏のように暑い。
才三月，今天却热得像盛夏一样。

易错点 この部屋は広くて明るくて、まるでホテルようだ。 → ホテルのようだ（名词接「ようだ」要加「の」，「ホテルようだ」不合法。）

〜に違いない
발음〜니치가이나이
一定…；肯定…
普通形 + に違いない；名词 + に違いない（不加「だ」）
依据某些迹象做很有把握的推断，语气比「だろう」强。
韩语对应-임에 틀림없다
韩语「-임에 틀림없다」同样表强推断；但日语名词后不加「だ」，韩语要加「임」，这是最容易出错的地方。
토나리 노 이에 와 난니치 모 덴키 가 키에테이루. 카조쿠 데 료코우 니 데카케타 니 치가이나이.
隣の家は何日も電気が消えている。家族で旅行に出かけたに違いない。
隔壁好几天没亮灯，一家人肯定出去旅行了。
콘나니히토 가 나란데이룬다카라, 코노미세 노 라아멘 와 오이시이 니 치가이나이.
こんなに人が並んでいるんだから、この店のラーメンはおいしいに違いない。
排这么多人，这家店的拉面一定好吃。
코노테가미 노 지 와, 치치 노 지 니 치가이나이.
この手紙の字は、父の字に違いない。
这封信的字迹肯定是父亲的。

易错点 この手紙の字は、父の字だに違いない。 → 父の字に違いない（名词直接接「に違いない」，不加「だ」。）

〜に決まっている
발음〜니키마떼이루
必然…；肯定…
普通形 + に決まっている；名词 + に決まっている
表示“按理必然如此”，带“这还用说”的强硬语气。
韩语对应분명 …하다 / 틀림없이 …할 거다
분명 잊어버렸을 거야 对照 忘れているに決まっている，是说话人很有把握的断言。-기 마련이다 陈述一般规律，用途不同。
렌슈우 모 시나이데시아이 니 데타라, 마케루 니 키마떼이루.
練習もしないで試合に出たら、負けるに決まっている。
不练习就上场比赛，肯定输。
一人で富士山に登るなんて、お母さんが心配するに決まってるでしょう。
一个人去爬富士山，妈妈肯定担心。
손나우마이하나시, 우소 니 키마떼이루 요.
そんなうまい話、うそに決まっているよ。
那么好的事，肯定是骗人的。

易错点 そんなうまい話、うそだに決まっているよ。 → うそに決まっている（名词直接接「に決まっている」，不加「だ」。）
