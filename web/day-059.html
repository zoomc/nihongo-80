今日语法 2 条

普通形 + わりに(は) / N + に しては
（相较…）却…；按…来说倒是…
動詞・い形 普通形 / 名詞＋の + わりに；名詞 + にしては；后项是与前项预期不符的评价
以某标准为参照，结果出乎意料；わりに 偏「付出/程度与结果不匹配」，にしては 偏「以该身份/条件而论」
타쿠산타베타와리니,후토리마센데시타.
たくさん食べたわりに、太りませんでした。
吃了那么多却没胖。
初心者にしては、上手に作りましたね。
作为初学者，做得挺不错呢。
朝鲜语：-에 비해 / -치고는
韩语에 비해表相较，치고는表按…来说；日语わりに偏不匹配，にしては偏身份标准。
易错点

初心者にしてはは上手です → 初心者にしては上手です。（にしては 已含 は，不叠加；中文「作为初学者」直译堆 は 错）

V ます形(去ます) + かねない / かねる
발음V 마스카타치 + 카네나이 / 카네루
难保不会…、恐怕会…／难以…、不便…
動詞 ます形 去 ます + かねない／かねる；かねる 按一段动词变形（かねます／かねた）
かねない 是「有可能（多指坏结果）」的负面推测；かねる 是「（因立场/情理）难以做到」，常用于委婉拒绝「〜しかねます」
코노마마데와지코니나리카네마센.
このままでは事故になりかねません。
这样下去难保会出事故。
ご期待に沿いかねますので、ご了承ください。
恕难满足您的期待，敬请谅解。
朝鲜语：-(으)ㄹ 수도 있다 / -기 어렵다
韩语ㄹ 수도 있다表恐怕会(坏结果)，委婉拒绝用하기 어렵습니다；かねる的立场限制韩语须另加说明。
易错点

事故になるかねません。 → 事故になりかねません。（必须接 ます形去ます（なり），不能用辞书形 なる；中文「难保会出事故」直译错）
