# Day 109 · 〜まま、〜うちに

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜まま、〜うちに」造两句自己的话，表达：就那样…；保持着…；趁着…；在…过程中

## 新词 19

- **言語**（げんご）语言｜韩语参考：언어（语言）<br>
  例：ドイツ語はやさしい言語ではありません。（德语不是一门容易的语言。）
- **健康**（けんこう）健康｜韩语参考：건강（健康）<br>
  例：煙草をすうことは健康に悪い。（吸烟对健康有害。）
- **検査**（けんさ）检查｜韩语参考：검사（检查）<br>
  例：検査は全くおざなりなものだった。（那次检查完全是敷衍了事。）
- **現在**（げんざい）现在；目前｜韩语参考：현재（现在，目前，此时） / 지금（现在，当前，眼下）<br>
  例：私は現在の地位に満足している。（我对现在的职位很满意。）
- **現実**（げんじつ）现实｜韩语参考：현실（现实） / 생시（醒着，现实）<br>
  例：あなたの夢が現実のものとなった。（你的梦想变成了现实。）
- **現象**（げんしょう）现象｜韩语参考：현상（现象）<br>
  例：生物学者はその現象の観察に集中した。（生物学家集中观察那个现象。）
- **現状**（げんじょう）现状｜韩语参考：현주소（现状）<br>
  例：彼は現状を大いに嘆いた。（他对现状大为感叹。）
- **建設**（けんせつ）建设｜韩语参考：건설<br>
  例：その金は体育館の建設に当てられた。（那笔钱被用于体育馆的建设。）
- **現代**（げんだい）现代；当代｜韩语参考：현대（现代） / 당대（当下，当代）<br>
  例：私は現代の音楽はあまり好きではない事を認めます。（我承认我不太喜欢现代音乐。）
- **建築**（けんちく）建筑；建设｜韩语参考：건축（建筑，建造）<br>
  例：彼らは家の建築にとりかかった。（他们开始盖房子了。）
- **見当**（けんとう）估计；头绪｜韩语参考：가늠（估计，估摸，掂量，估量） / 가량（估计，估摸，估量） / 대중（估计，掂量）<br>
  例：それがどこにあるのか、およその見当はついている。（它大概在哪儿，我心里有点数。）
- **現場**（げんば）现场｜韩语参考：현장（现场） / 현지（现场，实地）<br>
  例：警察はまもなく現場に着くだろう。（警察很快就会到现场。）
- **憲法**（けんぽう）宪法｜韩语参考：헌법（宪法）<br>
  例：平等は憲法で守られている。（平等受到宪法的保障。）
- **権利**（けんり）权利｜韩语参考：권리（权利）<br>
  例：あなたにはそこに行く権利がない。（你没有权利去那里。）
- **語**（ご）语言；词｜韩语参考：언어 / 단어<br>
  例：メキシコではなに語を話すのですか。（墨西哥人说什么语言？）
- **濃い**（こい）浓；深｜韩语参考：짙다（深） / 진하다（浓，稠）<br>
  例：コーヒーはどんなふうにしましょうか。濃いブラックがいいですか。（咖啡要怎么弄？浓的黑咖啡可以吗？）
- **恋**（こい）恋爱｜韩语参考：사랑 / 연애<br>
  例：それは片思いの恋だった。（那是一场单相思。）
- **恋人**（こいびと）恋人｜韩语参考：연인（恋人）<br>
  例：私は恋人を「ダーリン」と呼びます。（我叫我的恋人「达令」。）
- **幸運**（こううん）幸运｜韩语参考：행운（幸运）<br>
  例：私は幸運にもよい席がとれました。（我运气好，弄到了好座位。）

## 语法

- **〜まま**：就那样…；保持着…
  接续：动词た形/ない形 + まま；い形容词 + まま；ナ形容词 + な + まま；名词 + の + まま
  朝鲜语：-ㄴ 채로（韩语「-ㄴ 채로」与「まま」很接近；但日语可接名词「〜のまま」，韩语没有对应形式，要改说「그대로」。）
- **〜うちに**：趁着…；在…过程中
  接续：动词辞书形/ている/ない形 + うちに；い形容词 + うちに；ナ形容词 + な + うちに；名词 + の + うちに
  朝鲜语：-는 동안에（韩语「-는 동안에」只表时间范围；日语「うちに」还含“趁还没变、赶在期限前”的语感。）
