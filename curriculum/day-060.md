# Day 060 · 〜わけがない、〜わけにはいかない、〜ものだ

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜わけがない**：不可能…；绝不会…
  接续：普通形 + わけがない；ナ形容词 + な + わけがない；名词 + の/な + わけがない
  朝鲜语：-(으)ㄹ 리가 없다（韩语「-ㄹ 리가 없다」与「わけがない」几乎一一对应；但韩语口语常说「-ㄹ 리가 없잖아」反驳，日语习惯前加「そんな」。）
- **〜わけにはいかない**：不能…；不便…
  接续：动词辞书形 + わけにはいかない；动词ない形 + わけにはいかない
  朝鲜语：-ㄹ 수는 없다（韩语「-ㄹ 수는 없다」偏“能力或情况不允许”；日语「わけにはいかない」强调社会道义上的“不能”，含无奈。）
- **〜ものだ**：本来就…；应当…；过去常…
  接续：动词辞书形/た形 + ものだ；い形容词 + ものだ；ナ形容词 + な + ものだ
  朝鲜语：-는 법이다（韩语「-는 법이다」只表“理应如此”；日语「ものだ」还能用た形表“过去常常”，对应韩语「-곤 했다」，分工不同。）
