# Day 029 · 使役形（～せる／させる）、～てみる / ～てしまう / ～ておく、N が V(他動詞)て ある、Vて + いく / くる

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **使役形（～せる／させる）**：让／使…（做）
  接续：五段 う段→あ段+せる；一段 去る+させる；カ変 来させる；サ変 させる
  朝鲜语：-게 하다 / -시키다（시키다 与 -게 하다 都可以理解使役；日语需再判断使役对象的助词。句中已有被读的内容を 时，让谁读用 人に。）
- **～てみる / ～てしまう / ～ておく**：试着…／…完了／事先…
  接续：動詞て形 + みる／しまう／おく
  朝鲜语：-아/어 보다 / -아·어 버리다 / -아·어 두다（韩语分别用보다(尝试)、버리다(完了/遗憾)、두다(预先)，与日语三形基本对应。）
- **N が V(他動詞)て ある**：（人为地）已经…着；事先做好了…
  接续：他動詞て形 + ある；结果状态常用 が；已做好的准备也可用 を（例：本を置いてある）
  朝鲜语：-아/어 있다（韩语结果状态用아/어 있다，不强调人为施事；日语てある暗示某人有意为之，语感不同。）
- **Vて + いく / くる**：…下去／…起来（趋势）；去…再来／…过来（移动）
  接续：動詞 て形 + いく／くる；いく・くる 按五段/カ変变形（ていきます／てきました）
  朝鲜语：-아/어 가다 / -아·어 오다（韩语가다/오다补助同样表时间趋势，以说话人为基准；与日语いく/くる方向基准相近。）
