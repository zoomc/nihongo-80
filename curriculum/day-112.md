# Day 112 · 〜くらい / 〜ぐらい（extent）、〜さえ

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜くらい / 〜ぐらい（extent）、〜さえ」造两句自己的话，表达：到…地步；至少…；连…都…

## 新词 19

- **故郷**（こきょう）故乡｜韩语参考：향토（乡土，故乡，家乡，家园）<br>
  例：故郷の老いた両親のことを考えて見るべきだ。（你该想想老家年迈的父母。）
- **極**（ごく）极其｜韩语参考：극히<br>
  例：今、ごく小さなペットが流行っている。（现在很流行极小的宠物。）
- **国語**（こくご）国语；语文｜韩语参考：국어（国语） / 나라말（国语） / 우리말（国语）<br>
  例：彼は国語が好きだし得意だ。（他喜欢语文，也很擅长。）
- **黒板**（こくばん）黑板｜韩语参考：흑판（黑板） / 칠판（黑板）<br>
  例：黒板に書きますね。（我写在黑板上哦。）
- **克服**（こくふく）克服｜韩语参考：극복（克服）<br>
  例：彼は多くの困難を克服した。（他克服了许多困难。）
- **国民**（こくみん）国民｜韩语参考：국민（国民）<br>
  例：国民は歓呼して彼を国王に迎えた。（国民欢呼着拥立他为国王。）
- **穀物**（こくもつ）谷物｜韩语参考：곡물（谷物，粮食） / 곡식（庄稼，谷物）<br>
  例：彼は穀物を商っている。（他做谷物生意。）
- **腰**（こし）腰｜韩语参考：허리（腰）<br>
  例：長く座っていたので腰が痛いです。（坐了很久，腰疼。）
- **個人**（こじん）个人｜韩语参考：개인（个人）<br>
  例：社会は個人からなりたっている。（社会由个人组成。）
- **越す**（こす）越过；搬家｜韩语参考：넘다（越过） / 넘어오다（跨越过来）<br>
  例：船は今夜赤道を越すだろう。（船今晚会越过赤道。）
- **国家**（こっか）国家｜韩语参考：국가（国家） / 나라（国，国家）<br>
  例：同じ事が国家についても当てはまる。（同样的事对国家也适用。）
- **国会**（こっかい）国会｜韩语参考：국회（国会）<br>
  例：火曜日に国会が開かれる。（国会将在周二召开。）
- **国境**（こっきょう）国境｜韩语参考：국경（国境，边境）<br>
  例：明日中には国境を越えます。（明天之内就会越过国境。）
- **骨折**（こっせつ）骨折｜韩语参考：골절（骨折）<br>
  例：右腕を骨折したようです。（我的右臂好像骨折了。）
- **小包**（こづつみ）包裹｜韩语参考：소포（包裹）<br>
  例：この小包を船便で送ってください。（请把这个包裹寄海运。）
- **異なる**（ことなる）不同｜韩语参考：다르다（不同，不一致）<br>
  例：彼らの意見は私のとは異なっている。（他们的意见和我的不同。）
- **諺**（ことわざ）谚语｜韩语参考：속담（俗语，谚语）<br>
  例：このことわざが使われるのを聞いた事があります。（我听过有人用这句谚语。）
- **断る**（ことわる）拒绝｜韩语参考：거부하다（拒绝，反对） / 거절하다（拒绝，谢绝）<br>
  例：なぜ彼の申し出を断ったのですか。（你为什么拒绝了他的提议？）
- **粉**（こな）粉；面粉｜韩语参考：분（粉，粉末）<br>
  例：この小麦は粉にされる。（这些小麦被磨成面粉。）

## 语法

- **〜くらい / 〜ぐらい（extent）**：到…地步；至少…
  接续：普通形 + くらい／ぐらい；名词 + くらい
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」对应程度用法；“至少”韩语要说「적어도」，日语用「くらい」一并承担，范围更宽。）
- **〜さえ**：连…都…
  接续：名词 + さえ／でさえ／にさえ
  朝鲜语：-조차（韩语「-조차」多与否定呼应，这点与「さえ」相近；但日语「さえ」还能构成「さえ〜ば」条件句，韩语要用「-기만 하면」。）
