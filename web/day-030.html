今日语法 4 条

韩语对应-는지 / -(으)ㄴ지
韩语嵌入疑问用는지，按词性变인지；日语かどうか固定，且不能直接接名词。
普通形 + か どうか
是否…；…还是不…
動詞/い形 普通形 + かどうか；名詞・な形 词干 + かどうか（不加 だ/な）；疑问词问句不用 かどうか
把是非疑问嵌入句中，作 分かる／調べる／決める／聞く 等的内容；整体可当名词用（が／を／は）
이케루카도우카,마다와카리마센.
行けるかどうか、まだ分かりません。
还不知道能不能去。
카레가쿠루카도우카,키이테미마스.
彼が来るかどうか、聞いてみます。
我去问问他来不来。
易错点

行くかどうかを分かりません。 → 行くかどうか分かりません。（「分かる」的对象用 が，中文「知道是否…」直译加 を 错）

韩语对应-거든요 / -는데요 / -잖아요
韩语说明语气由거든요、는데요、잖아요等分担；日语んです一形统合，须按语境选择。
普通形 + んです / のだ
（是）因为…；其实是…（说明/强调语气）
動詞・い形 普通形 + んです；な形・名詞 + な + んです；礼貌体 んです，简体 のだ／んだ
解释原因、背景或强调；回答 どうして 时用；口语用 んです，书面/简体用 のだ
오소쿠나떼스미마센.덴샤가오쿠레탄데스.
遅くなってすみません。電車が遅れたんです。
抱歉迟到了，是电车晚点了。
코노미세와타카인데스카.
この店は高いんですか。
这家店（是）很贵吗？
易错点

電車が遅れたです。 → 電車が遅れたんです。（普通形过去 た 不能直接接 です；中文「晚点了」直译错，须 た＋んです）

韩语对应-아/어 주기를 바라다
韩语希望别人做用주기를 바라다，对长辈须加시；日语てほしい不宜直接对长辈说。
N に Vて ほしい / Vないで ほしい
발음N 니 V테 호시이 / V나이데 호시이
希望（别人）做…／希望别…
動詞 て形 + ほしい；否定 ない形 + で + ほしい；动作主体用 に（或 が）
てほしい 表说话人希望某事发生，动作主体可以是他人或自然事物；对人直接提出要求时要考虑关系与礼貌程度。
모우스코시마떼호시이데스.
もう少し待ってほしいです。
希望（你）再等一下。
오오키나코에데하나시사나이데호시이데스.
大きな声で話さないでほしいです。
希望别大声说话。
易错点

私は映画を見てほしいです。 → 映画が見たいです。（「我想看」应用 見たい；てほしい 是希望别人做，中文「想」不分主体易错）

韩语对应-(으)ㄴ 것 같다 / -처럼
韩语比喻和推测都用같다，口语最常用；日语みたい是ようだ口语版，韩语无正式口语两套。
名詞/な形词干 + みたい(だ/な/に)
好像…；像…一样（口语推量/比喻）
名詞 + みたい（不加 の）；な形 词干 + みたい；動詞/い形 普通形 + みたい；みたいな＋名／みたいに＋動
口语版 〜ようだ（G0044）；比 らしい/そう 更随意；比喻用 まるで…みたい
카레와겐키자나이미타이데스.
彼は元気じゃないみたいです。
他好像不太精神。
쿄우와하루미타이니아타타카이데스.
今日は春みたいに暖かいです。
今天暖和得像春天。
易错点

彼は学生のみたいです。 → 彼は学生みたいです。（名词接 みたい 不加 の（ようだ 才要 の）；中文「像是学生」直译加 の 错）
