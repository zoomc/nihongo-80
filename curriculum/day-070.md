## 新词 25

- **維持**（いじ）维持｜韩语参考：유지（维持，维护）<br>
  例：この車の維持は高くつく。（养这辆车很费钱。）
- **意識**（いしき）意识；顾及｜韩语参考：의식（意识）<br>
  例：このお料理は、パリのエスプリを意識して、味付けしてみました。（这道菜是顾及巴黎风味调味的。）
- **異常**（いじょう）异常｜韩语参考：이상（异常，反常，不正常）<br>
  例：そんなにたくさん食べるのは異常だ。（吃那么多是不正常的。）
- **泉**（いずみ）泉；喷泉｜韩语参考：샘（泉，泉水）<br>
  例：泉はおよそ１７０フィートの高さまで温水を吹き出す。（喷泉把温水喷到约一百七十英尺高。）
- **いずれ**（いずれ）早晚；哪个｜韩语参考：언젠가 / 어느 쪽<br>
  例：人間はいずれ死ぬのだ。（人早晚都会死。）
- **以前**（いぜん）以前｜韩语参考：이전（以前，之前） / 앞（前，以前） / 예（以前）<br>
  例：彼女はもはや以前の彼女ではない。（她已经不是从前的她了。）
- **板**（いた）板｜韩语参考：판 / 널빤지<br>

- **いたずら**（いたずら）恶作剧；淘气｜韩语参考：장난 / 개구쟁이짓<br>

  例：ここにしつこい痛みがあります。（我这里一直疼。）

  例：その語は広い意味を持つに至った。（那个词有了很广的含义。）
- **いち**（いち）集市｜韩语参考：시장<br>
  例：市は月曜ごとに立つ。（集市每周一开。）
- **位置**（いち）位置｜韩语参考：위치（位置，位于）<br>
  例：私はパレードが見えるいい位置にいた。（我站在能看清游行的好位置。）
- **一時**（いちじ）一时；暂时｜韩语参考：일시（一时，一会儿）<br>
  例：彼は一時ここに住んでいた。（他曾在这里住过一阵。）

  例：一度にひとつのことをするようにしなさい。（请一次只做一件事。）

- **一家**（いっか）一家｜韩语参考：일가（一家子，一家） / 한집（一家，一家人） / 일가족（一家，一家人）<br>
  例：ジョンソン一家はパーティーをするのが大好きだ。（约翰逊一家很喜欢办聚会。）
- **いつか**（いつか）总有一天｜韩语参考：언젠가<br>
  例：彼女はいつかあの山に登るだろう。（她总有一天会爬上那座山。）
- **一種**（いっしゅ）一种｜韩语参考：일종（一种）<br>
  例：記事の論調は一種の悲観論だった。（文章的论调是一种悲观论。）
- **一瞬**（いっしゅん）一瞬间｜韩语参考：순간（瞬间，刹那） / 일순（一瞬） / 한순간（一瞬间，一眨眼，一刹那，一转眼，刹那）<br>
  例：それは私にとってはらはらする一瞬だった。（那对我来说是提心吊胆的一瞬间。）
- **一生**（いっしょう）一生｜韩语参考：일생（一生） / 세상（一辈子，一生） / 종신（终身，一生，毕生）<br>
  例：あなたは、一生勉強しなければならない。（你必须学习一辈子。）
- **一層**（いっそう）更加｜韩语参考：더（更，更加） / 더욱（更加，进一步，越来越，愈加） / 일층（更加，进一步）<br>
  例：君が一緒だったおかげで休日がいっそう楽しめた。（多亏有你一起，假期过得更开心了。）
- **一体**（いったい）到底；究竟｜韩语参考：대관절（到底，究竟） / 도대체（到底，究竟）<br>
  例：一体どこで彼に会ったんだ。（到底是在哪儿见到他的？）
- **一致**（いっち）一致；相符｜韩语参考：일치（一致）<br>
  例：彼は言葉と行動が一致していない。（他的言行不一致。）

## 语法

- **N(＋助詞) + さえ／こそ／すら；V ば形 前 + さえ…ば**：甚至…／只要…就／正是…／连…都
  接续：さえ/すら 取代 が・を 或接在助词后（にさえ／でさえ）；さえ…ば 用 条件形(ば)；こそ 强调主语/原因（〜からこそ）
  朝鲜语：-조차 / -야말로 / -마저（韩语조차表连…都(多否定)、마저表连…也(消极)、야말로表正是，分工比日语さえ/すら细。）
- **普通形 + くせに / ものの / とはいえ**：明明…却（责备）／虽然…但是／虽说…然而
  接续：くせに：动词／い形普通形、な形容词 + な、名词 + の；ものの：普通形；とはいえ：名词或普通形 + とはいえ
  朝鲜语：-는데도 / -지만 / -라고는 해도（韩语责备用는데도，中性让步用지만，话虽如此用라고는 해도；くせに的轻蔑靠语调。）
- **普通形 + わりに(は) / N + に しては**：（相较…）却…；按…来说倒是…
  接续：動詞・い形 普通形 / 名詞＋の + わりに；名詞 + にしては；后项是与前项预期不符的评价
  朝鲜语：-에 비해 / -치고는（韩语에 비해表相较，치고는表按…来说；日语わりに偏不匹配，にしては偏身份标准。）
