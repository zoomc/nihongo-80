# Day 074 · 〜として、〜にとって、〜にしては

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜として**：作为…；以…身份
  接续：名词 + として；名词 + としての + 名词
  朝鲜语：-로서（韩语「-로서」表资格，与「として」对应；但韩语另有「-로써」表手段，日语「として」不表手段，切勿混用。）
- **〜にとって**：对…来说
  接续：名词 + にとって；名词 + にとっての + 名词
  朝鲜语：-에게 있어서（韩语「-에게 있어서」同样表立场，但较长、偏书面；日语「にとって」口语也常用，后项多接评价性表达。）
- **〜にしては**：照…来说；以…而言
  接续：动词普通形／名词 + にしては；名词化的 の + にしては 也可用
  朝鲜语：-치고는（초보자치고는 잘한다 对照 初心者にしては上手だ。前项也能是已经发生的动作，如 急いで作ったにしてはよくできている。）
