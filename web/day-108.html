③ 语法 6 分钟

〜ような / 〜ように（like）
名词 + の + ような/ように；普通形 + ような/ように
像…一样；如同…

举出相似例子、比喻，或表示“按照…的方式”。

私も、あなたのような優しい看護師になりたいです。
我也想成为像你这样温柔的护士。
先生が言ったように、この文法はテストによく出る。
正如老师所说，这个语法考试常考。
東京のような大きな都市では、家賃がとても高い。
在东京这样的大城市，房租很贵。
朝鲜语：-같은
韩语「-같은」修饰名词、「-같이」修饰动词，分工与日语相似；但日语名词前必须加「の」，韩语不加。

易错：東京のよう大きな都市では、家賃がとても高い。 → 東京のような大きな都市（名词后接「ような」须保留「な」，「よう大きな」不合法。）

まるで〜ようだ
まるで + 名词 + の + ようだ；まるで + 普通形 + ようだ
简直像…一样

用夸张比喻描述强烈的相似感，常与「まるで」呼应。

この部屋は広くて明るくて、まるでホテルのようだ。
这个房间又大又亮，简直像宾馆一样。
久しぶりに会った友達は、まるで別人のように変わっていた。
久别重逢的朋友变了个样，简直像另一个人。
三月なのに、今日はまるで真夏のように暑い。
才三月，今天却热得像盛夏一样。
朝鲜语：마치 -ㄴ 것 같다
韩语「마치」与日语「まるで」一样起强调作用；但韩语比喻常用「-처럼」，日语「ようだ」是断定结句，句法位置不同。

易错：この部屋は広くて明るくて、まるでホテルようだ。 → ホテルのようだ（名词接「ようだ」要加「の」，「ホテルようだ」不合法。）
