今日语法 3 条

〜すぎる
발음〜스기루
过于…；…过头
动词ます形去ます／い形容词去い／な形容词词干 + すぎる
表示程度超过适当范围，常带负面评价。
유우베노미스기테,아타마가이타이.
ゆうべ飲みすぎて、頭が痛い。
昨晚喝多了，头好痛。
코노쿠쓰와와타시니와오오키스기마스.
この靴は私には大きすぎます。
这双鞋对我来说太大了。
코노몬다이와칸탄스기테,쓰마라나이.
この問題は簡単すぎて、つまらない。
这道题太简单了，很无聊。
朝鲜语：너무 …하다
韩语用「너무」+形容词，位置在词前；日语 すぎる 是后缀，接在词干后，且可用于动词（食べすぎる），韩语需说 너무 많이 먹다。
易错点

この靴は私には大きいすぎます。 → この靴は私には大きすぎます。（い形容词接 すぎる 要去掉 い：大きすぎる）

〜方
발음〜카타
…的方法；…的方式
动词ます形去ます + 方（かた）
把动作名词化，表示做某事的方法，常与「使い方／読み方」搭配。
코노키카이노쓰카이카타오오시에테쿠다사이.
この機械の使い方を教えてください。
请告诉我这台机器的使用方法。
코노칸지노요미카타가와카리마센.
この漢字の読み方が分かりません。
我不知道这个汉字怎么读。
소보니오이시이미소시루노쓰쿠리카타오나라따.
祖母においしいみそ汁の作り方を習った。
我跟奶奶学了做味噌汤的方法。
朝鲜语：-는 방법
韩语 -는 방법 与 方 对应；但日语 方 直接接ます形去ます构成复合名词，韩语则用定语形加方法。
易错点

この機械を使い方を教えてください。 → この機械の使い方を教えてください。（「使い方」是名词短语，前面的名词要用 の 连接，不能同时保留 を）

〜中
발음〜추우／주우
正在…中；整个…；全…
名词 + 中（ちゅう／じゅう）
读 ちゅう 表示正在进行的活动，读 じゅう 表示整个范围或期间。
치치와이마,덴와추우데스.
父は今、電話中です。
父亲现在正在打电话。
키노우와이치니치주우아메가후떼이타.
昨日は一日中雨が降っていた。
昨天一整天都在下雨。
코노우타와세카이주우데시라레테이루.
この歌は世界中で知られている。
这首歌全世界都知道。
朝鲜语：-중 / -내내
韩语 -중 对应 ちゅう（회의 중），-내내 对应 じゅう（하루 종일）；日语同一个汉字两种读法，韩语用不同词尾区分。
易错点

父は今、電話の中です。 → 父は今、電話中です。（表示正在打电话用「電話中」，不是「電話の中」）
