今日语法 3 条

〜かどうか
动词普通形／い形容词／な形容词／名词 + かどうか
〜かどうか
是否…
把是非疑问句嵌入句中，表示不确定或需要确认。
明日行けるかどうか、まだ分かりません。
明天能不能去，我还不知道。
この服が似合うかどうか、ちょっと着てみます。
这件衣服合不合适，我试穿一下。
そのレストランがおいしいかどうか、友達に聞いてみよう。
那家餐厅好不好吃，问问朋友吧。
朝鲜语：-인지 아닌지
韩语 -인지 아닌지 与 かどうか 对应；但日语 かどうか 不能与疑问词同用，韩语 인지 아닌지 的限制相同，需注意。
易错点

明日行けるかどうかを、まだ分かりません。 → 明日行けるかどうか、まだ分かりません。（分かる 的对象用 が 或直接提示，不用 を）

〜か（embedded question）
疑问词 + …普通形 + か
〜か（embedded question）
（嵌入）什么…、哪里…
把含疑问词的问句嵌入句中作宾语或主语，句末不用疑问助词。
会議が何時に始まるか、教えてください。
请告诉我会议几点开始。
どこで財布をなくしたか、覚えていません。
我不记得在哪里丢了钱包。
誰が窓を割ったか、知っていますか。
你知道是谁打破了窗户吗？
朝鲜语：-인지
韩语 -인지 与嵌入疑问的 か 对应，但韩语疑问词位置较自由；日语嵌入句必须用普通形，且句末不再加 か。
易错点

会議が何時に始まるかどうか、教えてください。 → 会議が何時に始まるか、教えてください。（何時 是疑问词，只能用「か」，不能再用「かどうか」）

〜と思う
动词普通形／い形容词 + と思う；な形容词・名词 + だ + と思う
〜と思う
我认为…
表示说话人的判断或意见，礼貌体用「と思います」缓和语气。
この映画はきっと人気が出ると思う。
我觉得这部电影一定会受欢迎。
彼女は今日は来ないと思います。
我想她今天不会来。
日本の電車はとても便利だと思います。
我觉得日本的电车非常方便。
朝鲜语：-다고 생각하다
韩语 -다고 생각하다 与 と思う 对应，但日语 と思う 常省略主语，韩语则常出现 저는；日语疑问句用 と思いますか 更委婉。
易错点

この映画はきっと人気が出るだと思う。 → この映画はきっと人気が出ると思う。（动词普通形直接接 と思う，不加 だ）
