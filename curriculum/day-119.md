# Day 119 · 〜とともに、〜たびに

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜とともに、〜たびに」造两句自己的话，表达：与…一起；随着…；每当…就…

## 新词 19

- **質**（しつ）质量；质地｜韩语参考：질（质，质量）<br>
  例：お茶の質は下がりつつある。（茶叶的质量正在下降。）
- **失業**（しつぎょう）失业｜韩语参考：실업（失业） / 실직（失业）<br>
  例：この地域の失業はほぼないに等しい。（这个地区的失业几乎等于没有。）
- **実験**（じっけん）实验｜韩语参考：실험（实验）<br>
  例：この実験では不注意は許されない。（这个实验不允许有半点疏忽。）
- **実現**（じつげん）实现｜韩语参考：실현（实现） / 구현（体现，实现，贯彻）<br>
  例：あなたの夢がみんな実現されますように。（愿你的梦想都能实现。）
- **実行**（じっこう）实行；执行｜韩语参考：실행（实行，执行，实施）<br>
  例：彼は計画を立てれば必ず実行する。（他一旦订了计划就一定执行。）
- **実際**（じっさい）实际｜韩语参考：실제（实际） / 기실（其实，实际上） / 실상（实际上，其实）<br>
  例：人間は実際自然のなすがままである。（人类实际上只能听任自然摆布。）
- **実施**（じっし）实施｜韩语参考：실시（实施，实行）<br>
  例：その計画は実施された。（那个计划已经实施了。）
- **じっと**（じっと）一动不动；凝神｜韩语参考：떡（直挺挺，一动不动）<br>
  例：小さいおうちはお金で売れなかったのでじーとそこにとどまったままながめつづけていました。（小房子因为用钱买不到，就一直待在那里，目不转睛地看着。）
- **実に**（じつに）实在；确实｜韩语参考：참（真，实在，的确） / 정말로（真的，实在）<br>
  例：今日は実によい天気だ。（今天天气真好。）
- **実は**（じつは）其实｜韩语参考：기실（实际上，其实） / 실은（其实）<br>
  例：実はそれはただのうわさだったよ。（其实那只是传闻。）
- **失望**（しつぼう）失望｜韩语参考：실망（失望） / 낙심（灰心，失望，垂头丧气）<br>
  例：私はその結果に失望した。（我对那个结果很失望。）
- **支店**（してん）分店｜韩语参考：지점（分店）<br>
  例：新しい支店が来月シカゴに開店する。（新分店下个月在芝加哥开业。）
- **指導**（しどう）指导｜韩语参考：지도（指导）<br>
  例：彼は指導されなくても学ぶことができた。（即使没人指导，他也能学。）
- **自動**（じどう）自动｜韩语参考：자동（自动）<br>
  例：彼女は自動式の洗濯機をもっている。（她有一台自动洗衣机。）
- **品**（しな）商品；物品｜韩语参考：물건（商品，物品）<br>
  例：ここでお買い上げの品は無料で配達します。（在本店购买的商品免费送货。）
- **支配**（しはい）支配；统治｜韩语参考：지배（统治）<br>
  例：静けさが森を支配していた。（寂静笼罩着森林。）
- **芝居**（しばい）戏剧｜韩语参考：연극（话剧，戏剧）<br>
  例：どの芝居がいいですか。（哪出戏好呢？）
- **しばしば**（しばしば）屡次；常常｜韩语参考：누차（屡次）<br>
  例：貧困はしばしば犯罪の原因となる。（贫困常常成为犯罪的原因。）
- **芝生**（しばふ）草坪｜韩语参考：잔디<br>
  例：彼らは芝生の上に横になっていた。（他们躺在草坪上。）

## 语法

- **〜とともに**：与…一起；随着…
  接续：名词 + とともに；动词辞书形 + とともに
  朝鲜语：-와 함께（韩语「-와 함께」只表“一起”；日语「とともに」还能表“随着、同时”，韩语后者要用「-에 따라」。）
- **〜たびに**：每当…就…
  接续：动词辞书形 + たびに；名词 + の + たびに
  朝鲜语：-ㄹ 때마다（韩语「-ㄹ 때마다」与「たびに」基本对应；但日语「たびに」偏书面，口语常说「〜ときはいつも」。）
