Day 075 · 〜にしても、〜に関して / 〜に関する、〜に比べて

语法 3 条

〜にしても
발음〜니시테모
即使…；就算是…
动词普通形／名词 + にしても；名词化的 の + にしても 也可用
先承认前项成立，再指出后项仍不受影响，含不满或让步。
韩语对应-다고 해도
韩语「-다고 해도」与「にしても」对应；但日语常隐含责备，韩语语气更中性，需靠上下文补出不满。
忙しかったにしても、電話一本ぐらいできたでしょう。
就算再忙，至少也能打个电话吧。
조우단 니 시테 모, 손나이이카타 와 히도이 요.
冗談にしても、そんな言い方はひどいよ。
就算是开玩笑，那种说法也太过分了。
引っ越すにしても、来年の春以降になると思います。
就算要搬家，我想也要等到明年春天以后。
易错易混点
  • ✗ 雨にしてもも、出かけます。✓ 雨にしても、出かけます。にしても已有も，不叠加第二个も。
〜に関して / 〜に関する
발음〜니칸시테 / 〜니칸스루
关于…；就…
名词 + に関して；名词 + に関する／に関しての + 名词
引出话题，语气比「について」正式、郑重。
韩语对应-에 관해서
韩语「-에 관해서」表示关于；修饰名词时日语可用「に関する」或「に関しての」，韩语可用「-에 관한」。
新しいサービスに関してご質問がある方は、受付までどうぞ。
对新服务有疑问的人，请到前台咨询。
카레 와 니뽄 노 레키시 니칸스루 혼 오 타쿠삼모떼이루.
彼は日本の歴史に関する本をたくさん持っている。
他有很多关于日本历史的书。
事故の原因に関しては、現在調査中です。
关于事故原因，目前正在调查。
易错易混点
  • ✗ この問題に関するの資料です。✓ この問題に関する資料です。修饰名词用「に関する資料」或「に関しての資料」。
〜に比べて
발음〜니쿠라베테
与…相比
名词 + に比べて；动词辞书形 + のに比べて
拿两个对象作比较，指出差异。
韩语对应-에 비해서
名词用 작년에 비해／去年に比べて。想比一整件事时，日语常先用 の 把前面从句名词化，再接 に比べて。
코토시 노 나쓰 와, 쿄넨 니 쿠라베테즈이분스즈시이.
今年の夏は、去年に比べてずいぶん涼しい。
今年夏天比去年凉快得多。
토카이 니 쿠라베테, 이나카 와 야친 가 야스이.
都会に比べて、田舎は家賃が安い。
和城市相比，乡下房租便宜。
덴샤 데 이쿠노 니 쿠라베테, 쿠루마 데 이쿠토산주뿐 호도 나가쿠카카루.
電車で行くのに比べて、車で行くと三十分ほど長くかかる。
和坐电车去相比，开车要多花三十分钟左右。
易错易混点
  • ✗ 今年の夏は、去年を比べてずいぶん涼しい。✓ 今年の夏は、去年に比べてずいぶん涼しい。比较的基准用 に（去年に比べて）；を 只用在「AとBを比べる」这种把两样东西都当宾语的句子里。
