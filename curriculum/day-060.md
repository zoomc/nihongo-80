# Day 060 · 〜かどうか、〜か（embedded question）、〜と思う

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜かどうか、〜か（embedded question）、〜と思う」造两句自己的话，表达：是否…；（嵌入）什么…、哪里…；我认为…

## 新词 20

- **予習**（よしゅう）预习｜韩语参考：예습（预习）<br>
  例：予習を始めた方がいいですよ。（最好开始预习。）
- **寄る**（よる）顺路去；靠近｜韩语参考：들르다 / 가까이 가다<br>
  例：ちょっと寄って行きませんか。（要不要顺路进去坐坐。）
- **喜ぶ**（よろこぶ）高兴；乐意｜韩语参考：반기다（高兴，喜迎） / 기뻐하다（高兴，欢喜） / 좋아하다（欢喜，高兴）<br>
  例：喜んで質問に答えましょう。（我很乐意回答问题。）
- **よろしい**（よろしい）可以；好｜韩语参考：좋습니다 / 괜찮습니다<br>
  例：あなたに頼んでもよろしいですか。（能拜托您一件事吗。）
- **利用**（りよう）利用；使用｜韩语参考：이용（使用）<br>
  例：学生は図書館の本を利用すべきだ。（学生应该利用图书馆的书。）
- **両方**（りょうほう）两边；都｜韩语参考：양쪽（两边，两面） / 양편（两边）<br>
  例：この手袋は両方がそろっていない。（这副手套不成对。）
- **旅館**（りょかん）日式旅馆｜韩语参考：여관（旅馆，旅店）<br>
  例：あの旅館は家庭的だ。（那家旅馆很有家庭气氛。）
- **留守**（るす）不在家｜韩语参考：부재중<br>
  例：彼女に留守を頼んで外出しました。（我托她看家就出门了。）
- **冷房**（れいぼう）冷气｜韩语参考：냉방<br>
  例：冷房が効きすぎているのですが。（冷气好像开得太足了。）
- **歴史**（れきし）历史｜韩语参考：역사（历史）<br>
  例：私は地理より歴史が好きだ。（比起地理我更喜欢历史。）
- **レジ**（レジ）收银台｜韩语参考：계산대（柜台，收银台）<br>
  例：レジはどこですか。（收银台在哪里。）
- **レポート**（レポート）报告｜韩语参考：리포트（报告，报告书）<br>
  例：このレポートを終えたら休もうと思う。（这篇报告写完我就休息。）
- **ワープロ**（ワープロ）文字处理机｜韩语参考：워드프로세서<br>
  例：このワープロをお借りしていいですか。（可以借用这台文字处理机吗。）
- **沸かす**（わかす）烧开｜韩语参考：끓이다（煮沸，烧开）<br>
  例：お湯を少し沸かしてください。（请烧一点热水。）
- **別れる**（わかれる）分别；分手｜韩语参考：헤지다（分别，分离） / 갈라서다（分开，分手） / 갈라지다（分开，分手）<br>
  例：ジョンとメアリーは先週別れた。（约翰和玛丽上周分手了。）
- **沸く**（わく）沸腾；热闹｜韩语参考：끓다（沸腾，开）<br>
  例：市の産業はみんな好景気に沸いている。（市里的产业一片景气。）
- **訳**（わけ）缘由；道理｜韩语参考：까닭（缘由，缘故） / 사정（处境，情况，原因，缘由） / 연고（缘故，缘由）<br>
  例：そういうわけで私はこんなに早く帰って来たのです。（就因为这样我才这么早回来。）
- **忘れ物**（わすれもの）落下的东西｜韩语参考：두고 온 물건<br>
  例：今日忘れ物をした。（今天我把东西落下了。）
- **笑う**（わらう）笑｜韩语参考：웃다（笑）<br>
  例：しかし、彼はめったに笑いませんでした。（不过他很少笑。）
- **割れる**（われる）碎；裂｜韩语参考：깨지다 / 갈라지다<br>
  例：プラスチックは割れにくい。（塑料不容易碎。）

## 语法

- **〜かどうか**：是否…
  接续：动词普通形／い形容词／な形容词／名词 + かどうか
  朝鲜语：-인지 아닌지（韩语 -인지 아닌지 与 かどうか 对应；但日语 かどうか 不能与疑问词同用，韩语 인지 아닌지 的限制相同，需注意。）
- **〜か（embedded question）**：（嵌入）什么…、哪里…
  接续：疑问词 + …普通形 + か
  朝鲜语：-인지（韩语 -인지 与嵌入疑问的 か 对应，但韩语疑问词位置较自由；日语嵌入句必须用普通形，且句末不再加 か。）
- **〜と思う**：我认为…
  接续：动词普通形／い形容词 + と思う；な形容词・名词 + だ + と思う
  朝鲜语：-다고 생각하다（韩语 -다고 생각하다 与 と思う 对应，但日语 と思う 常省略主语，韩语则常出现 저는；日语疑问句用 と思いますか 更委婉。）
