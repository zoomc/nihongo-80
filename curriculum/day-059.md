# Day 059 · 〜かもしれない、〜だろう、〜んです / 〜のです

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜かもしれない、〜だろう、〜んです / 〜のです」造两句自己的话，表达：也许…；可能…；大概…吧；（解释）是…的；因为…

## 新词 21

- **もらう**（もらう）得到；请人做｜韩语参考：받다 / ~해 달라고 하다<br>
  例：あさって彼にここへ来てもらうつもりです。（打算后天请他来这里。）
- **森**（もり）森林｜韩语参考：숲<br>
  例：私は森の中で野うさぎをみつけた。（我在森林里发现了一只野兔。）
- **焼く**（やく）烤；晒｜韩语参考：굽다（烤，烧烤）<br>
  例：この夏はこんがり焼こうと思います。（今年夏天我想晒黑一点。）
- **役に立つ**（やくにたつ）有用｜韩语参考：도움이 되다<br>
  例：それ以上はお役に立てません。（再多的我就帮不上忙了。）
- **焼ける**（やける）烤好；烧｜韩语参考：구워지다 / 타다<br>
  例：このトーストはよく焼けていません。（这片吐司没烤透。）
- **優しい**（やさしい）温柔｜韩语参考：좋다（好，和善，温柔） / 살갑다（柔和，温柔） / 곰살맞다（温柔，和善）<br>
  例：みんなには優しく話してください。（请对大家说话温柔些。）
- **痩せる**（やせる）变瘦｜韩语参考：빠지다（掉，减轻，变瘦）<br>
  例：彼女はレールのように痩せていた。（她瘦得像根栏杆。）
- **やっと**（やっと）终于；好不容易｜韩语参考：겨우（勉强，好不容易） / 가까스로（好不容易） / 겨우겨우（勉勉强强，好不容易）<br>
  例：こ、こら！ナニやっとるかぁぁ！！（喂喂！你在搞什么啊。）
- **やはり**（やはり）果然；还是｜韩语参考：역시<br>
  例：やっぱり何とかやってのけたね。（你果然还是想办法办成了。）
- **止む**（やむ）停｜韩语参考：긋다（停，住） / 멎다（停，停止） / 멈추다（停，止）<br>
  例：雨がちょうど止んだ、出発しよう。（雨正好停了，出发吧。）
- **柔らかい**（やわらかい）柔软｜韩语参考：말랑하다（柔软） / 부드럽다（柔软） / 말랑말랑하다（柔软）<br>
  例：風が柔らかく木立に触れた。（风轻柔地拂过树丛。）
- **湯**（ゆ）热水｜韩语参考：뜨거운 물<br>
  例：いい湯だなあ。（这水真舒服啊。）
- **輸出**（ゆしゅつ）出口｜韩语参考：수출（出口，输出）<br>
  例：ドル安は輸出にはずみをつけています。（美元贬值正在推动出口。）
- **輸入**（ゆにゅう）进口｜韩语参考：수입（输入，进口，引进，舶来）<br>
  例：これはドイツから輸入した車です。（这是从德国进口的车。）
- **指**（ゆび）手指｜韩语参考：손（手指） / 손가락（手指）<br>
  例：ドアに指をはさみました。（我的手指被门夹了。）
- **指輪**（ゆびわ）戒指｜韩语参考：반지（戒指）<br>
  例：この指輪をある場所で買った。（这枚戒指是在某个地方买的。）
- **夢**（ゆめ）梦；梦想｜韩语参考：꿈（梦）<br>
  例：あなたの夢がみんな実現されますように。（愿你的梦想都能实现。）
- **揺れる**（ゆれる）摇晃｜韩语参考：흔들대다（摇摇晃晃，摇摇摆摆） / 흔들리다（晃，晃动，摇晃，摇摆） / 흔들거리다（晃来晃去，摇摇晃晃，摇摆）<br>
  例：大地が揺れるのが感じられた。（能感觉到大地在摇晃。）
- **用**（よう）事情｜韩语参考：용건（事情） / 용무（事务，事情）<br>
  例：何の用でここに来たのですか。（你来这里有什么事。）
- **用事**（ようじ）要办的事｜韩语参考：볼일（要办的事）<br>
  例：悪いけどほかに用事があるの。（不好意思，我还有别的事。）
- **汚れる**（よごれる）变脏｜韩语参考：더러워지다（变脏，污染）<br>
  例：この部屋の空気は汚れている。（这个房间的空气很脏。）

## 语法

- **〜かもしれない**：也许…；可能…
  接续：动词普通形／い形容词／な形容词／名词 + かもしれない
  朝鲜语：-(으)ㄹ지도 모르다（韩语 -(으)ㄹ지도 모르다 与 かもしれない 对应，但韩语字面含「不知道」，语气更不确定；日语 かもしれない 可直接表推测。）
- **〜だろう**：大概…吧
  接续：动词普通形／い形容词／な形容词／名词 + だろう
  朝鲜语：-(으)ㄹ 것이다 / -겠다（韩语 -(으)ㄹ 것이다 与 だろう 对应，-겠다 更偏主观意志或推测；日语 だろう 只表推测，不表意志。）
- **〜んです / 〜のです**：（解释）是…的；因为…
  接续：动词普通形／い形容词 + んです；な形容词+な／名词+な + んです
  朝鲜语：-ㄴ/는 것이다 / -거든요（韩语 -거든요 与 んです 的解释语气接近，但日语 んです 还可用于提问求解释；韩语 거든요 只用于陈述。）
