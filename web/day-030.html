③ 语法 6 分钟

加粗的是今日重点。先看句型与接续，再读例句。

〜と〜とどちらが
名词 + と + 名词 + とどちらが + 形容词 + か
…和…哪个更…？

用于两者之间比较提问，回答用「〜の方が」。

コーヒーと紅茶とどちらが好きですか。
咖啡和红茶你更喜欢哪个？
電車とバスとどちらが安いですか。
电车和公交车哪个便宜？
「山と海とどちらがいいですか。」「海の方がいいです。」
“山和海你更喜欢哪个？”“海更好。”
朝鲜语：A와 B 중 어느 쪽이
韩语用 와/과 중 어느 쪽이，日语用 と〜とどちらが；韩语需加 중，日语靠 どちら 本身表两者。
用法提醒

コーヒーと紅茶がどちらが好きですか。 → コーヒーと紅茶とどちらが好きですか。（比较的两个对象用 と 并列，疑问部分用 どちらが）

〜の中で〜が一番
名词（范围）+ の中で + 名词 + が一番 + 形容词
在…中最…

在三个以上的人或事物中选出程度最高者。

果物の中でりんごが一番好きです。
水果里我最喜欢苹果。
クラスの中でだれが一番背が高いですか。
班里谁最高？
家族の中で父が一番早く起きます。
家里父亲起得最早。
朝鲜语：… 중에서 …이 가장
韩语 중에서 与 の中で 对应，가장/제일 与 一番 对应；语序上韩语 가장 在形容词前，日语 一番 也在形容词前，较接近。
用法提醒

果物の中でりんごを一番好きです。 → 果物の中でりんごが一番好きです。（好き 的对象用 が，不用 を）
