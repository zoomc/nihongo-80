今日语法 2 条

〜ではありません / 〜じゃない
발음〜데와아리마센 / 〜자나이
不是…
名词／な形容词 + ではありません（礼貌）／じゃない（普通）
否定判断句，礼貌体用 ではありません，口语用 じゃない。
와타시와센세이데와아리마센.가쿠세이데스.
私は先生ではありません。学生です。
我不是老师，是学生。
쿄우와야스미자나이.
今日は休みじゃない。
今天不是休息日。
코노마치와아마리니기야카데와아리마센.
この町はあまりにぎやかではありません。
这个镇不太热闹。
朝鲜语：아니다 / 아닙니다
韩语 아니다 是独立形容词，需接 이/가（학생이 아닙니다）；日语 ではありません 直接接名词，不用助词，这是常见差异。
易错点

私は先生ではありませんだ。 → 私は先生ではありません。（ではありません 已是完整否定，不能再加 だ）

〜でした
발음〜데시타
（过去）是…
名词／な形容词 + でした
礼貌体的过去判断，表示过去的状态或身份。
키노우와와타시노탄조우비데시타.
きのうは私の誕生日でした。
昨天是我的生日。
코도모노코로,야사이가키라이데시타.
子どものころ、野菜がきらいでした。
我小时候讨厌蔬菜。
테스토와칸탄데시타.
テストはかんたんでした。
考试很简单。
朝鲜语：이었습니다 / 였습니다
韩语过去礼貌体 이었습니다/였습니다 随收音变化，日语 でした 形式固定；い形容词过去用 かったです，韩语则用过去时制。
易错点

きのうは私の誕生日ですでした。 → きのうは私の誕生日でした。（です 与 でした 不能叠用）
