# Day 068 · 〜けど / 〜けれども、〜ために

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜けど / 〜けれども、〜ために」造两句自己的话，表达：但是…；虽然…；为了…；因为…

## 新词 14

- **まず**（まず）首先｜韩语参考：우선<br>
  例：バリウムをまず一口飲んでください。（请先喝一口钡餐。）
- **または**（または）或者｜韩语参考：내지（或，或者） / 또는（或，或者，要么） / 혹은（或者）<br>
  例：紅茶またはコーヒーはいかが？（红茶或者咖啡，您要哪个。）
- **間違える**（まちがえる）弄错｜韩语参考：잘못하다（弄错，搞错）<br>
  例：急いで物事をすると間違えますよ。（做事太急就会出错。）
- **周り**（まわり）周围｜韩语参考：주위（周围） / 테두리（周围，四周，轮廓，沿，边）<br>
  例：周りを見渡しなさい。（看看你的周围。）
- **回る**（まわる）绕；转｜韩语参考：돌다（转，转动） / 휘돌다（绕，盘旋） / 돌아가다（转，转动）<br>
  例：私たちは車の後ろに回って押した。（我们绕到车后面推。）
- **漫画**（まんが）漫画｜韩语参考：만화（漫画） / 만화책（漫画书，漫画册）<br>
  例：仕事中に漫画の本を読むのはやめること。（上班时不要看漫画。）
- **真ん中**（まんなか）正中间｜韩语参考：중간（正当中，中间） / 중심（中心，正中） / 한가운데（正中间）<br>
  例：トラックが道の真ん中に止まっていた。（一辆卡车停在路中间。）
- **見える**（みえる）看得见｜韩语参考：보이다<br>
  例：すべてのものがすばらしく見えた。（一切看起来都很好。）
- **湖**（みずうみ）湖｜韩语参考：호（湖） / 호수（湖，湖泊）<br>
  例：湖の深さはどのくらいですか。（湖水有多深。）
- **味噌**（みそ）味噌；妙处｜韩语参考：된장 / 요점<br>
  例：この電子辞書は携帯しやすいところが味噌です。（这本电子词典的好处是方便携带。）
- **皆**（みな）大家；都｜韩语参考：다（全，都） / 모두（都，全）<br>
  例：私の親族は皆この町に住んでいる。（我的亲戚都住在这个镇上。）
- **港**（みなと）港口｜韩语参考：항구（港口）<br>
  例：その船はいま港にある。（那艘船现在在港口。）
- **向かう**（むかう）前往；朝向｜韩语参考：향하다<br>
  例：あなたは何処へ向かっているのですか。（你要去哪儿。）
- **迎える**（むかえる）迎接；接｜韩语参考：맞다（迎接，接待） / 받다（接待，迎接，接受，录用） / 맞이하다（迎接，迎）<br>
  例：６時にホテルに車で迎えて下さい。（六点请开车来酒店接我。）

## 语法

- **〜けど / 〜けれども**：但是…；虽然…
  接续：句子普通形 + けど／けれども（礼貌体可直接接）
  朝鲜语：-지만（韩语 -지만 与 けど 对应，但日语 けど 还可放在句末缓和语气、引出下文；韩语 -지만 一般不能这样独立使用。）
- **〜ために**：为了…；因为…
  接续：动词辞书形／动词た形 + ために；名词 + の + ために
  朝鲜语：-기 위해(서) / 때문에（韩语 -기 위해(서) 表目的，때문에 表原因，两者形式不同；日语 ために 一个形式兼表目的与原因，需靠前接成分判断。）
