# Day 089 · V辞書形 / Nの + たびに、V辞書形 / Vた形 / Nの + ついでに

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「V辞書形 / Nの + たびに、V辞書形 / Vた形 / Nの + ついでに」造两句自己的话，表达：每当…就…；每次…都…；顺便…；借…之便…

## 新词 14

- **横断**（おうだん）横穿；横渡｜韩语参考：횡단（横穿，横过，横渡）<br>
  例：彼はヨットで太平洋を横断した。（他乘帆船横渡了太平洋。）
- **終える**（おえる）结束；完成｜韩语参考：맺다（结尾，结束） / 끝내다（结束，完成） / 끝맺다（结束，完结）<br>
  例：その仕事をもう終えましたか。（那份工作已经做完了吗？）
- **大いに**（おおいに）大大地；非常｜韩语参考：크게 / 대단히<br>
  例：私は彼を大いに尊敬しています。（我非常尊敬他。）
- **覆う**（おおう）覆盖；掩盖｜韩语参考：뒤덮다（覆盖，笼罩）<br>
  例：机はほこりで覆われている。（桌子上落满了灰尘。）
- **オーバー**（オーバー）大衣；超过｜韩语参考：외투 / 초과<br>
  例：あなたはオーバーなしですますつもりですか。（你打算不穿大衣就对付过去吗？）
- **大家**（おおや）房东｜韩语参考：주인집（房东，房东家） / 집주인（房主，房东）<br>
  例：その大家は以前は暮らし向きがよかったそうだ。（听说那个房东以前日子过得不错。）
- **丘**（おか）小山；丘陵｜韩语参考：둔덕（坎，岗，堤，丘陵） / 언덕（坡，丘陵，山坡，山丘）<br>
  例：その丘は見晴らしがよい。（那座小山视野很好。）
- **沖**（おき）海上；洋面｜韩语参考：먼바다<br>
  例：その島は海岸から１マイル沖にある。（那座岛在离海岸一英里的海上。）
- **奥**（おく）里面；深处｜韩语参考：속（里面，里头） / 안（里，里面）<br>
  例：彼らはレストランの奥の方に座った。（他们坐在餐厅里面。）
- **贈る**（おくる）赠送｜韩语参考：선사하다（赠送，馈赠，带来）<br>
  例：ドロシーは彼にすばらしい贈り物を贈った。（多萝西送了他一份很好的礼物。）
- **起こる**（おこる）发生｜韩语参考：나다（发，发生） / 생기다（发生，产生） / 벌어지다（发生）<br>
  例：あとで起こったことはなお悪かった。（后来发生的事更糟。）
- **幼い**（おさない）年幼；幼稚｜韩语参考：연소하다（年少，年幼）<br>
  例：彼の考えはとても幼い。（他的想法非常幼稚。）
- **収める**（おさめる）取得；收纳｜韩语参考：거두다（获得，取得，赢得） / 거둬들이다（取得，获得，赢得） / 거두어들이다（取得，获得，赢得）<br>
  例：そのアメリカ映画は大成功を収めた。（那部美国电影获得了巨大成功。）
- **おしゃべり**（おしゃべり）聊天；话多｜韩语参考：수다 / 수다스럽다<br>
  例：彼らは天気についておしゃべりした。（他们聊了聊天气。）

## 语法

- **V辞書形 / Nの + たびに**：每当…就…；每次…都…
  接续：動詞辞書形 + たびに；名詞 + の + たびに（する名詞可直接 するたびに）
  朝鲜语：-(으)ㄹ 때마다（韩语때마다表每当，接名词或动词定语形；日语たびに只接辞书形或の，后项限制更严。）
- **V辞書形 / Vた形 / Nの + ついでに**：顺便…；借…之便…
  接续：動詞辞書形/た形 + ついでに；名詞 + の + ついでに
  朝鲜语：-는 김에（韩语는 김에表顺便，隐含「既然…就」的语气；日语ついでに纯表顺便，不含既然义。）

- **確** 确实；确认｜音：カク、コウ｜训：たし.か、たし.かめる
