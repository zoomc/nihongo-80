③ 语法 7 分钟

〜と思う
动词普通形／い形容词 + と思う；な形容词・名词 + だ + と思う
我认为…

表示说话人的判断或意见，礼貌体用「と思います」缓和语气。

この映画はきっと人気が出ると思う。
我觉得这部电影一定会受欢迎。
彼女は今日は来ないと思います。
我想她今天不会来。
日本の電車はとても便利だと思います。
我觉得日本的电车非常方便。
朝鲜语：-다고 생각하다
韩语 -다고 생각하다 与 と思う 对应，但日语 と思う 常省略主语，韩语则常出现 저는；日语疑问句用 と思いますか 更委婉。

易错：この映画はきっと人気が出るだと思う。 → この映画はきっと人気が出ると思う。（动词普通形直接接 と思う，不加 だ）

～おかげで / ～せいで
名/な形 + の/な + おかげで／せいで；普通形 + おかげで／せいで
多亏…／都怪…

おかげで 表积极原因（多亏），せいで 表消极原因（都怪）；感情色彩固定

先生のおかげで、日本語が上手になりました。
多亏老师，日语变好了。
雨のせいで、行けませんでした。
都怪下雨，没能去成。
朝鲜语：-덕분에 / -때문에
韩语积极原因用덕분에，消极原因用때문에(中性)；日语せいで专表负面，色彩更固定。

易错：雨のおかげで、行けませんでした → 雨のせいで、行けませんでした。（消极结果用 せいで，おかげで 只用于好事）
