# Day 002 · 家人与朋友｜N は N ではありません / じゃない、N は N でした

- 阶段：P0｜60 分钟｜常规日
- Can-do：在「家人与朋友」场景里，用 N は N ではありません / じゃない 说清一件事

## 新词 9

- **二**（に）二  
  例：二人で行きます。（两个人去。）
- **三**（さん）三  
  例：三時に会います。（三点见。）
- **四**（よん）四（し／よん）  
  例：四つください。（请给我四个。）
- **五**（ご）五  
  例：五円です。（五日元。）
- **六**（ろく）六  
  例：六時です。（六点。）
- **七**（なな）七（なな／しち）  
  例：七時に起きます。（七点起床。）
- **八**（はち）八  
  例：八日から休みます。（从八号开始休息。）
- **九**（きゅう）九（きゅう／く）  
  例：九時です。（九点。）
- **十**（じゅう）十  
  例：十人います。（有十个人。）

## 语法

- **N は N ではありません / じゃない**：…不是…
  接续：名詞 + は + 名詞 + ではありません（口语 じゃない）
  朝鲜语：이/가 아닙니다（韩语否定用이/가 아니다，助词随收音变化；日语では可缩成じゃ，韩语无对应缩略。）
- **N は N でした**：…（过去）是…
  接续：名詞 + は + 名詞 + でした
  朝鲜语：이었습니다 / 였습니다（韩语过去按有无收音选이었/였，且分层级；日语でした只有一形，无收音条件。）
