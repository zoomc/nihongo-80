今日语法 2 条

～おかげで / ～せいで
名/な形 + の/な + おかげで／せいで；普通形 + おかげで／せいで
～おかげで / ～せいで
多亏…／都怪…
おかげで 通常表达对好结果的感谢，也可反讽；せいで 常用于不理想结果，不应脱离语境机械判定。
先生のおかげで、日本語が上手になりました。
多亏老师，日语变好了。
雨のせいで、行けませんでした。
都怪下雨，没能去成。
朝鲜语：-덕분에 / -때문에
韩语 덕분에 通常表示多亏，也可反讽；때문에 可用于中性原因。日语 せいで 常带不满或归因。
易错点

先生のおかげで（漏 の） → 先生のおかげで…（名词后接 おかげで 要加 の：先生のおかげで）

～によって / ～について / ～にとって
名詞 + によって／について／にとって
～によって / ～について / ～にとって
因…而异／关于…／对…来说
によって 表「因…而不同/依据/手段被动」、について「关于」、にとって「对…而言（评价）」
人によって意見が違います。
意见因人而异。
日本語について話します。
谈谈日语。
私にとって、日本語は難しいです。
对我来说日语很难。
朝鲜语：-에 따라 / -에 대해 / -에게
韩语에 따라表依据或随…而异，에 대해关于，에게表评价对象，三者分工比日语清楚。
易错点

私について、日本語は難しいです → 私にとって、日本語は難しいです。（「对…来说」用 にとって，について 是「关于」，中文「对」易混）
