## 3. 新语法（含先修）
- `G0085` **普通形 + 一方(で) / 反面 / 代わりに** — 一方面…另一方面…／…但另一方面／取而代之、作为交换｜接续：動詞・い形 普通形 / な形・名詞 である + 一方(で)・反面；名詞＋の・普通形 + 代わりに
- `G0066` **V辞書形 / Vない形 + ことが ある** — 有时会…／有时不…（泛指倾向）｜接续：動詞 辞書形／ない形 + ことが ある；ある 可变形（ことがあります／あった）

## 4. 新汉字（中日差异）
- `K0122` **故** 音:コ 训:ゆえ｜中文「故」gù（故事/原因/旧的）；日语「故障」こしょう 是「故障/出毛病」，中文易按「故事/故意」误解；音读 コ、训读 ゆえ（故に），不能靠汉字猜词。
- `K0123` **障** 音:ショウ 训:さわる｜中文「障」zhàng；日语 障 音读 ショウ，「故障」こしょう「障害」しょうがい；「故障」与中文同形同义（少数一致），但「障害」しょうがい 是「障碍/残疾」，不能一律按中文推。
