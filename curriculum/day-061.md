# Day 061 · 〜ものではない、〜もの / 〜もん、〜ものだから / 〜もので

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ものではない**：不该…；不可以…
  接续：动词辞书形 + ものではない
  朝鲜语：-는 것이 아니다（韩语「-는 것이 아니다」多为客观否定；日语「ものではない」带明显劝诫和教养色彩，语气更重。）
- **〜もの / 〜もん**：因为…嘛（撒娇辩解）
  接续：普通形 + もの／もん（多与「だって」呼应）
  朝鲜语：-니까(요)（韩语「-니까(요)」只表原因，不带撒娇色彩；日语「もん」几乎总带“我也有苦衷”的辩解语气，只用于亲近关系。）
- **〜ものだから / 〜もので**：因为…；由于…
  接续：普通形 + ものだから；ナ形容词 + な + ものだから；名词 + な + ものだから
  朝鲜语：-는 통에（韩语「-는 통에」多引出坏结果；日语「ものだから」不限好坏，重点在“说明并求得谅解”，语气更软。）
