今日语法 3 条

に（时点／归着点／存在场所／对象）
발음니
在／于／向…
名詞 + に
表时间点、动作归着点、存在场所、动作对象
시치지니오키마스.
七時に起きます。
七点起床。
가꼬우니이키마스.
学校に行きます。
去学校。
朝鲜语：에 / 에게
韩语存在场所用에，人的对象用에게/한테；日语に一形多义，韩语须按对象分开。
易错点

七時で 起きます。 → 七時に起きます。（具体时点用 に，手段/场所用 で；中文「在七点」的「在」误对应 で）

で（动作场所／手段／材料／原因）
발음데
在…／用…／因为…
名詞 + で
表动作场所、手段/工具/交通、材料、原因
토쇼칸데벤쿄우시마스.
図書館で勉強します。
在图书馆学习。
덴샤데이키마스.
電車で行きます。
坐电车去。
朝鲜语：에서 / (으)로
韩语动作场所用에서，手段材料用(으)로；日语で一形统合，学习者易混。
易错点

図書館に 勉強します。 → 図書館で勉強します。（动作场所用 で；中文「在图书馆」的「在」一律误译成 に）

と（并列／共同／引用）
발음토
和…／与…（一起）；「…」地
名詞 + と + 名詞／動詞；引用从句 + と + 思う/言う
完全并列、共同动作对象、引用内容
토모다치토에이가오미마스.
友達と映画を見ます。
和朋友看电影。
朝鲜语：와/과 / 하고 / (이)라고
韩语并列用와/과、口语하고，引用用라고且随词性变；日语と一形通用。
易错点

友達も映画を見ます。 → 友達と映画を見ます。（「も」是追加「也」，共同动作用 と；中文「和/也」易混）
