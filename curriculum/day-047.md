# Day 047 · ～はずだ / ～わけではない、～おかげで / ～せいで、～によって / ～について / ～にとって

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **～はずだ / ～わけではない**：应该…／并不是…
  接续：普通形 + はずだ；普通形 + わけではない
  朝鲜语：-(으)ㄹ 것이다 / -는 것은 아니다（韩语理应推断用ㄹ 것이다或ㄹ 텐데，部分否定用는 것은 아니다；はずだ依据性更强。）
- **～おかげで / ～せいで**：多亏…／都怪…
  接续：名/な形 + の/な + おかげで／せいで；普通形 + おかげで／せいで
  朝鲜语：-덕분에 / -때문에（韩语 덕분에 通常表示多亏，也可反讽；때문에 可用于中性原因。日语 せいで 常带不满或归因。）
- **～によって / ～について / ～にとって**：因…而异／关于…／对…来说
  接续：名詞 + によって／について／にとって
  朝鲜语：-에 따라 / -에 대해 / -에게（韩语에 따라表依据或随…而异，에 대해关于，에게表评价对象，三者分工比日语清楚。）
