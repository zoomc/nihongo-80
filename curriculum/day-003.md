# Day 003 · N も、これ / それ / あれ / どれ は N です

- 阶段：P0｜60 分钟｜常规日
- Can-do：用「N も、これ / それ / あれ / どれ は N です」造两句自己的话，表达：…也…；这/那/那是…

## 新词 11

- **今日**（きょう）今天｜韩语参考：금일（今日，今天） / 오늘（今天，今日）<br>
  例：今日は月曜日です。（今天是周一。）
- **明日**（あした）明天｜韩语参考：내일（明天）<br>
  例：明日、学校へ行きます。（明天去学校。）
- **昨日**（きのう）昨天｜韩语参考：어제（昨天，昨日） / 어저께（在昨天，在昨日）<br>
  例：昨日は日曜日でした。（昨天是周日。）
- **朝**（あさ）早晨｜韩语参考：아침（早上，早晨）<br>
  例：朝ご飯を食べます。（吃早饭。）
- **時間**（じかん）时间；小时｜韩语参考：시간（时间）<br>
  例：時間がありません。（没时间。）
- **時計**（とけい）钟表；手表｜韩语参考：시계<br>
  例：時計を見ます。（看表。）
- **毎日**（まいにち）每天｜韩语参考：매일<br>
  例：毎日、学校へ行きます。（每天去学校。）
- **今週**（こんしゅう）本周｜韩语参考：금주（本周，这周，这星期）<br>
  例：今週は忙しいです。（这周很忙。）
- **月曜日**（げつようび）星期一｜韩语参考：월요일（星期一，周一，礼拜一）<br>
  例：月曜日に試験があります。（周一有考试。）
- **火曜日**（かようび）星期二｜韩语参考：화요일（星期二，周二，礼拜二）<br>
  例：火曜日に試験があります。（周二有考试。）
- **水曜日**（すいようび）星期三｜韩语参考：수（周三，星期三） / 수요일（星期三，周三，礼拜三）<br>
  例：水曜日は休みです。（周三休息。）

## 语法

- **N も**：…也…
  接续：名詞 + も（替代 は/が/を）
  朝鲜语：도（韩语 도 和日语 も 都可表示追加，常替换主格或宾格助词；叠加其他助词须按具体语境判断。）
- **これ / それ / あれ / どれ は N です**：这/那/那是…
  接续：指示代名词 + は + 名詞 + です
  朝鲜语：이것 / 그것 / 저것 / 어느 것（韩语指示三分与日语相同，但修饰名词要用이/그/저且与것分写；日语可直接连体。）
