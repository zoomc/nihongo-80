# Day 072 · 〜がる、〜かもしれない

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜がる、〜かもしれない」造两句自己的话，表达：（第三人称）显得…；表现出…；也许…；可能…

## 新词 20

- **理由**（りゆう）理由；缘由｜韩语参考：까닭（缘由，缘故） / 이유（理由）<br>
  例：遅刻した理由を説明してください。（请说明迟到的理由。）
- **原因**（げんいん）原因（客观）｜韩语参考：원인（原因，理由，缘由）<br>
  例：事故の原因を調べています。（正在调查事故原因。）
- **結果**（けっか）结果｜韩语参考：결과（结果，结局）<br>
  例：調査の結果、原因が分かりました。（调查的结果，弄清了原因。）
- **目的**（もくてき）目的｜韩语参考：목적（目的，目标）<br>
  例：留学の目的は日本語を学ぶことです。（留学目的是学日语。）
- **機会**（きかい）机会｜韩语参考：때（时机，机会） / 기회（机会，机遇，时机）<br>
  例：話す機会がありません。（没有说话的机会。）
- **経験**（けいけん）经验；经历｜韩语参考：경험（经验）<br>
  例：海外で働いた経験があります。（有在海外工作过的经历。）
- **可能性**（かのうせい）可能性｜韩语参考：가능성（可能性，可行性）<br>
  例：雨の可能性が高いです。（下雨的可能性很高。）
- **影響**（えいきょう）影响｜韩语参考：영향（影响）<br>
  例：円安が物価に影響を与えます。（日元贬值影响物价。）
- **関係**（かんけい）关系；关联｜韩语参考：관계（关系）<br>
  例：この件には関係ありません。（和这件事没关系。）
- **状況**（じょうきょう）状况；情形（外部局面）｜韩语参考：모습（样子，景象，状况） / 상황（状况，情况） / 정황（情况，情形）<br>
  例：今の状況を報告してください。（请报告目前的情况。）
- **内容**（ないよう）内容｜韩语参考：내용（内容） / 내용물（内容物）<br>
  例：メールの内容を確認しました。（确认了邮件内容。）
- **情報**（じょうほう）信息；资讯｜韩语参考：정보（信息）<br>
  例：最新の情報を集めます。（收集最新信息。）
- **状態**（じょうたい）状态（事物/身体）｜韩语参考：상태（状态）<br>
  例：患者の状態が安定しています。（患者状态稳定。）
- **気持ち**（きもち）心情；感受；心意｜韩语参考：맘（心情，心绪） / 기분（心情） / 느낌（感觉，感受）<br>
  例：気持ちを言葉にするのは難しい。（把心情化成语言很难。）
- **気分**（きぶん）心情；身体状态；气氛｜韩语参考：맘（心情，心绪） / 기분（心情） / 마음（心情，心绪）<br>
  例：今日は気分が悪いです。（今天身体/心情不舒服。）
- **満足**（まんぞく）满足；满意｜韩语参考：만족（满足） / 흡족（满足，充足）<br>
  例：結果に満足しています。（对结果很满意。）
- **不満**（ふまん）不满；不满意｜韩语参考：불만（不满，不满意） / 불평（不满，牢骚）<br>
  例：給料に不満があります。（对工资有不满。）
- **不安**（ふあん）不安；担心｜韩语参考：불안（不安，不宁，担心）<br>
  例：試験の結果が不安です。（担心考试结果。）
- **残念**（ざんねん）遗憾；可惜｜韩语参考：유감（遗憾）<br>
  例：試合に負けて残念です。（输了比赛很遗憾。）
- **感動**（かんどう）感动｜韩语参考：감동（感动，打动）<br>
  例：映画を見て感動しました。（看了电影很感动。）

## 语法

- **〜がる**：（第三人称）显得…；表现出…
  接续：い形容词去い／な形容词词干 + がる
  朝鲜语：-아/어 하다（韩语可用 -아/어 하다 描述他人表现出的情绪，如 무서워하다；日语がる通常描述外显表现，也可客观回顾自己的倾向。）
- **〜かもしれない**：也许…；可能…
  接续：动词普通形／い形容词／な形容词／名词 + かもしれない
  朝鲜语：-(으)ㄹ지도 모르다（韩语 -(으)ㄹ지도 모르다 与 かもしれない 对应，但韩语字面含「不知道」，语气更不确定；日语 かもしれない 可直接表推测。）

## 汉字 4

- **現** 现在；出现；现实｜音：ゲン｜训：あらわ.れる、あらわ.す、うつつ、うつ.つ
- **調** 调查；调整｜音：チョウ｜训：しら.べる、しら.べ、ととの.う、ととの.える
- **化** 变化；化成｜音：カ、ケ｜训：ば.ける、ば.かす、ふ.ける、け.する
- **当** 命中；相当；当前｜音：トウ｜训：あ.たる、あ.たり、あ.てる、あ.て、まさ.に、まさ.にべし
