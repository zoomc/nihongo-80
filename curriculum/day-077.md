# Day 077 · N / Vます形(去ます) + がちだ、普通形 + はずがない、〜わけだ

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「N / Vます形(去ます) + がちだ、普通形 + はずがない、〜わけだ」各造一句自己的话，表达：容易…；往往…（多指不好的倾向）；不可能…；理应不会…；难怪…；也就是说…

## 新词 22

- **香り**（かおり）香味；香气｜韩语参考：향（香味） / 향기（香气，香味） / 향내（香味，香气）<br>
  例：そのバラはよい香りを発散した。（那朵玫瑰散发出好闻的香味。）
- **画家**（がか）画家｜韩语参考：화가（画家）<br>
  例：その画家は、いわば永遠の少年だ。（那位画家可以说是永远的少年。）
- **抱える**（かかえる）抱着；背负｜韩语参考：안다 / 떠안다<br>
  例：彼は両手に大きな箱を抱えていた。（他双手抱着一个大箱子。）
- **価格**（かかく）价格｜韩语参考：가격（价格，价钱） / 값（价格，价钱）<br>
  例：最も良い価格で見積もって下さい。（请报最好的价格。）
- **化学**（かがく）化学｜韩语参考：화학（化学）<br>
  例：貴方は、化学を勉強しますか。（你学化学吗？）
- **輝く**（かがやく）闪耀；发光｜韩语参考：빛나다（发光，照射）<br>
  例：空には太陽が輝いています。（太阳在天空中闪耀。）
- **係**（かかり）负责人员｜韩语参考：담당자<br>
  例：今、誰か係りの者を差し向けます。（现在派个负责人过去。）
- **罹る**（かかる）患病｜韩语参考：병에 걸리다<br>
  例：私はかつて大病にかかったことがあった。（我曾经得过一场大病。）
- **限る**（かぎる）限于；限定｜韩语参考：한하다（限于，仅限） / 제한하다（限制，限定） / 한정하다（限定）<br>
  例：金持ちが必ずしも幸福とは限らない。（有钱人未必幸福。）
- **家具**（かぐ）家具｜韩语参考：가구（家具）<br>

- **学**（がく）学问；学识｜韩语参考：학문 / 학식<br>
  例：彼は非常に学がある。（他非常有学问。）
- **額**（がく）金额；额头｜韩语参考：금액（金额）<br>
  例：この額は税込みです。（这个金额含税。）
- **覚悟**（かくご）思想准备；决心｜韩语参考：각오（心理准备，思想准备）<br>
  例：私はすでに覚悟はできています。（我已经做好准备了。）
- **確実**（かくじつ）确实；可靠｜韩语参考：확실하다<br>
  例：これは遅いけど確実な方法だ。（这方法虽慢但可靠。）
- **学者**（がくしゃ）学者｜韩语参考：학자（学者） / 학사（学者）<br>
  例：その学者はライフワークを続けた。（那位学者继续着他毕生的事业。）
- **学習**（がくしゅう）学习｜韩语参考：학습（学习） / 공부（学习，读书）<br>
  例：これは生物の学習法としてはあまりよくないと思う。（我觉得这作为生物的学习方法不太好。）
- **隠す**（かくす）隐藏；遮掩｜韩语参考：감추다（藏，隐藏） / 숨기다（隐藏，藏匿） / 파묻다（埋藏，隐藏）<br>
  例：私は母がケーキを隠すのを見た。（我看见妈妈把蛋糕藏了起来。）

  例：太陽が雲のかげに隠れた。（太阳躲到了云后。）
- **陰**（かげ）背阴处；背后｜韩语参考：그늘（阴影，背阴） / 배후（背后，幕后）<br>
  例：あの木の陰に腰をおろしましょう。（我们在那棵树的阴凉处坐下吧。）
- **影**（かげ）影子；影像｜韩语参考：그림자（影子）<br>
  例：水たまりに映った影が見えた。（能看见映在水洼里的影子。）

## 语法

- **N / Vます形(去ます) + がちだ**：容易…；往往…（多指不好的倾向）
  接续：名詞 + がちだ；動詞ます形去ます + がちだ；がちな + 名詞
  朝鲜语：-기 쉽다 / -는 경향이 있다（韩语기 쉽다表容易(中性)，负面倾向用는 경향이 있다；日语がちだ多负面，语感更窄。）
- **普通形 + はずがない**：不可能…；理应不会…
  接续：動詞・い形普通形 + はずがない；な形容詞 + な／名詞 + の + はずがない
  朝鲜语：-(으)ㄹ 리가 없다（韩语ㄹ 리가 없다表绝不可能，推断依据强；与单纯否定안不同，同日语はずがない。）
- **〜わけだ**：难怪…；也就是说…
  接续：普通形 + わけだ；ナ形容词 + な + わけだ；名词 + という + わけだ
  朝鲜语：-는 셈이다（韩语「-는 셈이다」侧重“算作某种结果”；日语「わけだ」更强调说话人由事实推导的过程，常带“原来如此”的领悟语气。）
