## 新词 14

- **アイロン**（アイロン）熨斗｜韩语参考：다리미（熨斗）<br>
  例：アイロンで手をやけどしました。（我用熨斗把手烫伤了。）
- **アウト**（アウト）出局｜韩语参考：아웃（出局）<br>
  例：最初の打者はアウトになった。（第一个击球手出局了。）
- **明かり**（あかり）灯光｜韩语参考：불빛（灯光） / 전깃불（电灯，灯光） / 전등불（灯光）<br>
  例：どうか明かりをつけて下さい。（请把灯打开。）
- **空き**（あき）空隙；空位｜韩语参考：빈자리 / 틈<br>
  例：字と字の間の空きをもっと広くしなさい。（把字与字之间的空隙留大一些。）
- **明らか**（あきらか）明显｜韩语参考：명백하다<br>
  例：その船が沈んだのは明らかだ。（那艘船沉了，这是明摆着的。）
- **諦める**（あきらめる）放弃｜韩语参考：버리다（放弃，舍弃，放手） / 체념하다（死心，放弃，断念） / 포기하다（放弃）<br>
  例：その少年は死んだものとしてあきらめられた。（那个少年被当作死了而放弃了。）
- **飽きる**（あきる）腻；厌倦｜韩语参考：물리다（腻，厌烦） / 질리다（腻，厌烦）<br>
  例：息子はハンバーガーにあきています。（儿子吃腻了汉堡。）
- **握手**（あくしゅ）握手｜韩语参考：악수（握手）<br>
  例：彼は友人と握手した。（他和朋友握了手。）
- **悪魔**（あくま）恶魔｜韩语参考：악마（恶魔）<br>
  例：悪魔がやってくるかもしれないよ。（恶魔也许会来哦。）
- **明ける**（あける）天亮；开始｜韩语参考：밝다（亮，天亮） / 새다（天亮，破晓） / 동트다（天亮，破晓）<br>
  例：夜が明ける。（天亮了。）
- **預ける**（あずける）寄存；托付｜韩语参考：맡기다（委托，托付，寄托） / 예치하다（存放，寄存）<br>
  例：銀行にそのお金を預けてください。（请把钱存到银行。）
- **汗**（あせ）汗｜韩语参考：땀（汗）<br>
  例：額の汗をふきなさい。（擦擦额头上的汗。）
- **与える**（あたえる）给予｜韩语参考：주다（给予，给）<br>
  例：彼は娘にたくさんのお金を与えた。（他给了女儿很多钱。）
- **辺り**（あたり）附近｜韩语参考：언저리（边，边沿，附近，周边）<br>
  例：昔この辺りにホテルがあったんだ。（从前这附近有一家酒店。）

## 语法

- **N / Vた形 / V辞書形 / Vて + ばかり**：刚…；净是…、只…；一味…
  接续：名詞 + ばかり；動詞 た形 + ばかり（刚做完）；辞書形 + ばかり（只等/只剩）；て形 + ばかり いる（光顾着做）
  朝鲜语：방금 / -만 / -기만 하다（韩语「刚」用방금、「只」用만、「一味」用기만 하다，三义分用；日语ばかり一形靠语境。）
- **V辞書形/Vている/Vた形 + ところ(だ/に/を/で)**：正要…／正在…／刚…；在…时候；…之际
  接续：辞書形 + ところだ（正要）；ている + ところだ（正在）；た形 + ところだ（刚做完）；ところに/を/で 后接外部动作或发现
  朝鲜语：-(으)려고 하다 / -고 있다 / -(으)ㄴ 참이다（韩语正要려고 하다、正在고 있다、刚ㄴ 참이다；日语ところだ按だ/に/を/で四形变化。）
