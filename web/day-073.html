今日语法 2 条

V辞書形 / Vた形 / Nの + ついでに
顺便…；借…之便…
動詞辞書形/た形 + ついでに；名詞 + の + ついでに
做主要事情时，顺便做另一件次要事情；次要动作通常耗时短、顺路。
에키에이쿠쓰이데니,키뿌오카이마시타.
駅へ行くついでに、切符を買いました。
去车站时顺便买了车票。
시료우오토도케루쓰이데니,부초우니아이사쓰시마시타.
資料を届けるついでに、部長に挨拶しました。
送资料时顺便向部长打了招呼。
朝鲜语：-는 김에
韩语는 김에表顺便，隐含「既然…就」的语气；日语ついでに纯表顺便，不含既然义。
易错点

駅へ行くのついでに、切符を買いました。 → 駅へ行くついでに、切符を買いました。（辞书形后接 ついでに 不加 の；の 只能接名词。）

V辞書形 / Vない形 / い形 / な形な + うちに
趁着…；在…期间（不知不觉）…
動詞辞書形 + うちに；動詞ない形 + ないうちに；い形 + うちに；な形 + なうちに；名詞 + のうちに
表示在前项状态持续期间做后项；「〜ないうちに」=趁还没…；也可表示不知不觉发生变化。
와카이우치니,이로이로나케이켄오시타호우가이이데스.
若いうちに、いろいろな経験をしたほうがいいです。
趁年轻应该多积累各种经验。
와스레나이우치니,메모시테쿠다사이.
忘れないうちに、メモしてください。
趁还没忘，请记下来。
朝鲜语：-는 동안에 / -기 전에
韩语는 동안表期间，기 전에表趁还没；日语うちに还含不知不觉变化，韩语须用는 사이에。
易错点

暗いないうちに、帰りましょう。 → 暗くならないうちに、帰りましょう。（い形「暗い」的否定是「暗くない」，不能直接加 ない；中文“还没黑”直译错。）
