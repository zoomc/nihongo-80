# Day 076 · V辞書形 / Vない形 + ように する、V辞書形/Vない形 + ことに する / なる

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「V辞書形 / Vない形 + ように する、V辞書形/Vない形 + ことに する / なる」造两句自己的话，表达：努力做到…／设法不…（有意识地做）；（自己）决定…／（结果）定为…、将要…

## 新词 19

- **操作**（そうさ）操作（机器/界面）｜韩语参考：조작（操作）<br>
  例：この機械は操作が簡単です。（这台机器操作很简单。）
- **渋滞**（じゅうたい）堵车；拥堵｜韩语参考：정체（拥堵，堵车） / 교통 체증（交通堵塞，堵车）<br>
  例：朝は道が渋滞しています。（早上路上堵车。）
- **事故**（じこ）事故；意外事件｜韩语参考：탈（意外，变故） / 사고（事故）<br>
  例：高速道路で事故がありました。（高速上发生了事故。）
- **運転**（うんてん）驾驶；开车｜韩语参考：운전（驾驶，操纵，开）<br>
  例：父は毎日車を運転します。（爸爸每天开车。）
- **入院**（にゅういん）住院｜韩语参考：입원（住院）<br>
  例：祖母が入院しました。（奶奶住院了。）
- **看病**（かんびょう）护理；照料病人｜韩语参考：병간호（看护病人，护理病人） / 병구완（护理病人，伺候病人）<br>
  例：母が入院して、看病しています。（妈妈住院了，我在护理她。）
- **記事**（きじ）报道；文章；条目｜韩语参考：기사（报道，新闻） / 기사문（报道，纪实文）<br>
  例：新聞の記事を読みました。（读了报上的报道。）
- **確認**（かくにん）确认；核实｜韩语参考：확인（确认）<br>
  例：資料の内容を確認してください。（请确认资料内容。）
- **検討**（けんとう）探讨；研究；考虑｜韩语参考：검토（研究，考虑）<br>
  例：この案を検討することにしました。（决定研究这个方案。）
- **承認**（しょうにん）批准；认可｜韩语参考：승인（批准，同意）<br>
  例：部長が申請を承認しました。（部长批准了申请。）
- **提出**（ていしゅつ）提交；交出｜韩语参考：제출（提交，出具）<br>
  例：明日までに報告書を提出してください。（请在明天之前提交报告。）
- **締め切り**（しめきり）截止日期；截止｜韩语参考：마감（截至，截止日期）<br>
  例：応募の締め切りは今週の金曜日です。（报名截止日期是本周五。）
- **担当**（たんとう）负责；担任｜韩语参考：담당（负责，担任）<br>
  例：このお客様は田中さんが担当しています。（这位客户由田中负责。）

- **部下**（ぶか）部下；下属｜韩语参考：부하（部下，下级，下属）<br>

  例：同僚と昼ご飯を食べました。（和同事一起吃了午饭。）
- **取引先**（とりひきさき）交易对象；客户公司｜韩语参考：거래처（客户）<br>
  例：取引先との会議は来週です。（和客户公司的会议在下周。）

## 语法

- **V辞書形 / Vない形 + ように する**：努力做到…／设法不…（有意识地做）
  接续：動詞 辞書形／ない形 + ように + する；する 按 サ変 变形（ようにしています／ようにした）
  朝鲜语：-도록 하다（韩语 -도록 하다 可表努力或指示；日语ようにする可用于自己的安排，也可用于要求他人注意。）
- **V辞書形/Vない形 + ことに する / なる**：（自己）决定…／（结果）定为…、将要…
  接续：動詞 普通形 + ことに + する（主观决定）/ なる（客观决定、自然结果）；する・なる 可变形
  朝鲜语：-기로 하다 / -게 되다（韩语自己决定用기로 하다，外部决定或结果用게 되다；与日语ことにする/なる对应整齐。）
