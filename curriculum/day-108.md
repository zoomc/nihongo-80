# Day 108 · 〜ような / 〜ように（like）、まるで〜ようだ

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜ような / 〜ように（like）、まるで〜ようだ」造两句自己的话，表达：像…一样；如同…；简直像…一样

## 新词 14

- **交換**（こうかん）交换｜韩语参考：교환（调换，交换）<br>
  例：あなたと席を交換しよう。（跟你换个座位吧。）
- **航空**（こうくう）航空｜韩语参考：항공（航空）<br>
  例：航空料金の方が鉄道料金より高い。（机票比火车票贵。）
- **光景**（こうけい）景象｜韩语参考：광경（景象，情景，情境）<br>
  例：その光景を見てぎょっとした。（看到那番景象，我吓了一跳。）
- **合計**（ごうけい）合计｜韩语参考：합계（合计，总计） / 도합（总共，共计，合计）<br>
  例：この数字の列を合計しなさい。（把这一列数字加起来。）
- **攻撃**（こうげき）攻击｜韩语参考：공격（攻击） / 가격（攻击，加以攻击）<br>
  例：急所を除くすべての攻撃を認める。（除要害部位外，其他攻击都允许。）
- **貢献**（こうけん）贡献｜韩语参考：공헌（贡献） / 기여（贡献）<br>
  例：彼女は非常に会社に貢献した。（她为公司做出了很大贡献。）
- **広告**（こうこく）广告｜韩语参考：광고（广告）<br>
  例：その商品はテレビで広告された。（那件商品在电视上做了广告。）
- **交際**（こうさい）交往｜韩语参考：교제（交往）<br>
  例：その男は妻と交際し始めた。（那个男人开始和妻子交往了。）
- **後者**（こうしゃ）后者｜韩语参考：후자（后者）<br>
  例：このうち大事なのは後者の方です。（其中重要的是后者。）
- **構成**（こうせい）构成｜韩语参考：구성（构成）<br>
  例：委員会は８名から構成されている。（委员会由八名成员组成。）
- **高速**（こうそく）高速｜韩语参考：고속（高速） / 고속 도로（高速公路）<br>
  例：運転者は高速を出し続けた。（司机一直保持高速行驶。）
- **行動**（こうどう）行动｜韩语参考：행동（行动，行为，举动） / 행위（行为，行动）<br>
  例：私がこの行動の責任はすべて取る。（这次行动的责任全由我来负。）
- **強盗**（ごうとう）强盗；抢劫｜韩语参考：강도（强盗） / 강도질（当强盗，抢劫） / 날강도（强盗， 抢劫犯，匪贼）<br>
  例：父は強盗と取っ組み合いをした。（父亲和劫匪扭打了起来。）
- **工場**（こうば）工厂｜韩语参考：공장<br>
  例：私の父と兄はこの工場で働いている。（我父亲和哥哥在这家工厂工作。）

## 语法

- **〜ような / 〜ように（like）**：像…一样；如同…
  接续：名词 + の + ような/ように；普通形 + ような/ように
  朝鲜语：-같은（韩语「-같은」修饰名词、「-같이」修饰动词，分工与日语相似；但日语名词前必须加「の」，韩语不加。）
- **まるで〜ようだ**：简直像…一样
  接续：まるで + 名词 + の + ようだ；まるで + 普通形 + ようだ
  朝鲜语：마치 -ㄴ 것 같다（韩语「마치」与日语「まるで」一样起强调作用；但韩语比喻常用「-처럼」，日语「ようだ」是断定结句，句法位置不同。）
