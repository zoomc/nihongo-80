## 新词 25

- **説**（せつ）学说｜韩语参考：설 / 학설<br>
  例：私はこの説を信じることは出来ない。（我无法相信这种说法。）
- **設計**（せっけい）设计｜韩语参考：설계（设计）<br>
  例：私の設計にしたがって、作ってもらいました。（是照着我的设计做的。）
- **絶対**（ぜったい）绝对｜韩语参考：절대（绝对） / 절대로（绝对，绝）<br>
  例：アーア、絶対うまくいくと思ったのになあ。（唉，我明明觉得一定会成功的。）
- **セット**（セット）一套；设置｜韩语参考：세트 / 설정<br>
  例：目覚ましを７時にセットしよう。（把闹钟定到七点吧。）
- **絶滅**（ぜつめつ）灭绝｜韩语参考：멸종（灭绝，灭种，绝种）<br>
  例：絶滅は進化の一部である。（灭绝是进化的一部分。）
- **節約**（せつやく）节约｜韩语参考：절약（节约）<br>
  例：主婦は節約に努めるべきである。（家庭主妇应当努力节约。）
- **責める**（せめる）责备｜韩语参考：책하다（责备，训斥，斥责） / 책망하다（责备，训斥，指责、数落）<br>
  例：彼はうそをついたと彼女を責めた。（他责怪她撒谎。）
- **善**（ぜん）善；善行｜韩语参考：선（善，善行）<br>
  例：競争それ自体は善でも悪でもない。（竞争本身无所谓善恶。）
- **全**（ぜん）全；整个｜韩语参考：전（全） / 모든（全，所有）<br>
  例：全新聞がその事件を大きく取り上げた。（所有报纸都大篇幅报道了那起事件。）
- **全員**（ぜんいん）全体成员；所有人｜韩语参考：전원 / 모든 사람<br>
  例：学生のほとんど全員英語が好きだ。（学生几乎全都喜欢英语。）
- **専攻**（せんこう）专业；专攻｜韩语参考：전공（专业，专攻，主修）<br>
  例：私はフランス語を専攻するつもりです。（我打算专攻法语。）
- **全国**（ぜんこく）全国｜韩语参考：전국（全国）<br>
  例：その報道は全国に行き渡った。（那则报道传遍了全国。）
- **先日**（せんじつ）前几天｜韩语参考：며칠 전<br>
  例：先日小学校のクラス会に出席した。（前几天参加了小学同学会。）
- **前者**（ぜんしゃ）前者｜韩语参考：전자（前者）<br>
  例：前者より後者の方がいい。（后者比前者好。）
- **選手**（せんしゅ）选手；运动员｜韩语参考：선수（选手，运动员）<br>
  例：アキラは上手なテニス選手です。（阿明是个很棒的网球选手。）
- **前進**（ぜんしん）前进｜韩语参考：전진（前进）<br>
  例：彼は前進も後退もすまいと決めた。（他决定既不前进也不后退。）
- **センター**（センター）中心；中心站｜韩语参考：센터（中场，中锋，场地中心）<br>
  例：学生センターは話をするのに良いところだ。（学生活动中心是个聊天的好地方。）
- **相続**（そうぞく）继承｜韩语参考：상속（继承）<br>
  例：彼は父親の大きな土地を相続した。（他继承了父亲的大片土地。）
- **装置**（そうち）装置；设备｜韩语参考：장치（装置，装备，设备）<br>
  例：みんな、その装置にとても感心した。（大家都对那个装置很佩服。）
- **相当**（そうとう）相当；合适｜韩语参考：상당（相当于，合） / 상당히（相当多地）<br>
  例：その場所は今は相当建て込んでいる。（那个地方现在建得相当密集。）
- **速度**（そくど）速度｜韩语参考：속도（速度）<br>
  例：その男は一定の速度で車を運転した。（那个男人以稳定的速度开车。）
- **底**（そこ）底部；底｜韩语参考：밑（底，底下） / 밑창（底，底部） / 바닥（底）<br>
  例：靴の底がすり減ってしまった。（鞋底磨薄了。）
- **そこで**（そこで）于是；因此｜韩语参考：그래서 / 그리하여<br>
  例：そこで他人との相互作用が大切になる。（因此，与他人的互动就变得重要了。）
- **組織**（そしき）组织｜韩语参考：조직（组织） / 짜임（组织，结构）<br>
  例：彼らは労働組合を組織するだろう。（他们会组织工会吧。）
- **注ぐ**（そそぐ）注入；倾注｜韩语参考：쏟다（倾注） / 퍼붓다（倾注）<br>
  例：彼は友人を助けることに全力を注いだ。（他把全力倾注在帮助朋友上。）

## 语法

- **〜せいで**：都怪…；因为…
  接续：动词普通形/い形容词/ナ形容词な/名词の + せいで
  朝鲜语：-때문에（韩语「-때문에」中性，好坏结果都可用；日语「せいで」专用于坏结果并带责难，不能随便替换「おかげで」。）
- **〜たとたん / 〜たとたんに**：刚一…就…
  接续：动词た形 + とたん（に）
  朝鲜语：-자마자（韩语「-자마자」只表紧接发生；日语「とたん」还要求后项是意外、非意志的事，不能接自己的有意动作。）
- **〜たら〜た**：…了之后发现…
  接续：动词た形 + ら … た形
  朝鲜语：-았더니（韩语「-았더니」正好对应“做了之后发现”；但日语「たら」还兼表条件，需靠后半句的过去时和发现语气判断。）
- **〜に先立って**：在…之前先…
  接续：名词／动词辞书形 + に先立って
  朝鲜语：에 앞서（常用于正式活动之前的准备。）
