今日语法 2 条

〜なら
动词普通形／い形容词／な形容词／名词 + なら
〜なら
如果是…的话
承接对方已知或提到的话题，就此事给出判断、建议或条件。
京都へ行くなら、秋がいいですよ。
如果你要去京都，秋天最合适。
パソコンのことなら、兄に聞くといいよ。
电脑方面的事，问我哥哥就好。
そんなに眠いなら、今日は早く寝たら？
那么困的话，今天早点睡怎么样？
朝鲜语：-(이)라면 / -다면
韩语 -(이)라면 与名词搭配，-다면 与动词、形容词搭配；日语 なら 前接形式不随词性变化，接续更简单。
易错点

京都へ行くなれば、秋がいいですよ。 → 京都へ行くなら、秋がいいですよ。（なら 前接普通形，动词不用「なれば」）

〜と（conditional）
动词辞书形／ない形／い形容词 + と；な形容词・名词 + だ + と
〜と（conditional）
一…就…；如果…就…
表示反复出现的自然结果、必然条件或机械性反应，后项不能是意志、请求。
このボタンを押すと、お茶が出ます。
按下这个按钮，茶就会出来。
春になると、桜が咲きます。
一到春天，樱花就开了。
この道を右に曲がると、左に郵便局があります。
沿这条路向右转，左边有一家邮局。
朝鲜语：-(으)면
韩语 -(으)면 可表条件，也可接请求；日语 と 的后项必须是自然结果，不能是命令、请求，这一点需特别注意。
易错点

このボタンを押すと、お茶を出してください。 → このボタンを押すと、お茶が出ます。（と 的后项不能是请求、意志表达）
