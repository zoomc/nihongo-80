Day 036 · 〜ようだ、〜みたい、〜すぎる

语法 3 条

〜ようだ
발음〜요우다
好像…；似乎…
动词普通形／い形容词 + ようだ；な形容词+な／名词+の + ようだ
根据所见所闻的证据做较有把握的推断，也可用于委婉断定。
韩语对应-(으)ㄴ/는 것 같다
지금 집에 없는 것 같다 对照 今は留守のようだ。日语名词接 ようだ 要加 の；口语换成 みたいだ 时去掉 の。
다레 모 이나이요우데스 네.
誰もいないようですね。
好像没有人呢。
카제 오 히이타요우데, 아사 카라 노도 가 이타이.
かぜをひいたようで、朝からのどが痛い。
我好像感冒了，从早上起喉咙就痛。
소토 와 사무이요우다. 민나코오토 오 키테이루.
外は寒いようだ。みんなコートを着ている。
外面好像很冷，大家都穿着大衣。
易错易混点
  • ✗ 外は寒いようだです。✓ 外は寒いようです。ようだ 已是普通形断定，接礼貌体应说「ようです」，不能加 です
〜みたい
발음〜미타이
好像…；像…一样
动词普通形／い形容词／な形容词词干／名词 + みたいだ（口语）
口语中根据迹象推测，或表示比喻、举例。
韩语对应-(으)ㄴ/는 것 같다 / 처럼
推测可说 …인 것 같다，比喻可说 …처럼／…같다。日语名词直接接 みたい；修饰另一个名词用 みたいな，修饰动作或状态用 みたいに。
토나리 노 헤야 니 다레카 키타미타이.
隣の部屋に誰か来たみたい。
隔壁房间好像有人来了。
쿄우 노 카노조 와 겐키 가 나이미타이다 네.
今日の彼女は元気がないみたいだね。
她今天好像没什么精神。
코노케이키, 오미세 노 케이키미타이!
このケーキ、お店のケーキみたい！
这个蛋糕简直像店里卖的一样！
易错易混点
  • ✗ このケーキ、お店のケーキのみたい！✓ このケーキ、お店のケーキみたい！名词直接接 みたい，不加 の
〜すぎる
발음〜스기루
过于…；…过头
动词ます形去ます／い形容词去い／な形容词词干 + すぎる
表示程度超过适当范围，常带负面评价。
韩语对应너무 …하다
韩语用「너무」+形容词，位置在词前；日语 すぎる 是后缀，接在词干后，且可用于动词（食べすぎる），韩语需说 너무 많이 먹다。
유우베노미스기테, 아타마 가 이타이.
ゆうべ飲みすぎて、頭が痛い。
昨晚喝多了，头好痛。
코노쿠쓰 와 와타시 니 와 오오키스기마스.
この靴は私には大きすぎます。
这双鞋对我来说太大了。
코노몬다이 와 칸탄스기테, 쓰마라나이.
この問題は簡単すぎて、つまらない。
这道题太简单了，很无聊。
易错易混点
  • ✗ この靴は私には大きいすぎます。✓ この靴は私には大きすぎます。い形容词接 すぎる 要去掉 い：大きすぎる
