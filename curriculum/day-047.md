## 新词 25

- **美術館**（びじゅつかん）美术馆｜韩语参考：미술관（美术馆）<br>
  例：このバスは美術館まで行きますか。（这趟公交到美术馆吗？）
- **非常に**（ひじょうに）非常｜韩语参考：마냥（非常，十分） / 매우（非常，极其，很） / 몹시（十分，非常，太）<br>
  例：車を運転することは非常に楽しい。（开车非常愉快。）
- **びっくりする**（びっくりする）吃惊｜韩语参考：놀라다（惊吓，吃惊）<br>
  例：彼はびっくりするほどのアクロバットができる。（他会的杂技多得让人吃惊。）
- **引っ越す**（ひっこす）搬家｜韩语参考：이사하다（搬家）<br>
  例：去年の秋、私たちはニューヨークに引っ越した。（去年秋天，我们搬到了纽约。）
- **必要**（ひつよう）必要；需要｜韩语参考：필요（必要，需要）<br>
  例：歯医者に行く必要はないですよ。（没必要去看牙医。）
- **ひどい**（ひどい）糟糕的；过分的｜韩语参考：심하다 / 끔찍하다<br>
  例：この薬はひどい味がする。（这药味道很糟。）
- **開く**（ひらく）开；绽放｜韩语参考：갖다（开，举办，举行） / 내다（开） / 열다（开）<br>
  例：庭のバラの木のつぼみが少しずつ開き始める。（院子里玫瑰树的花蕾一点点开了。）
- **ビル**（ビル）大楼｜韩语参考：빌딩（大楼，高楼，大厦）<br>
  例：駅の前に高いビルがあります。（车站前有一栋高楼。）
- **昼間**（ひるま）白天｜韩语参考：주간（昼间，白天） / 날（白天） / 해（白昼，白天）<br>
  例：フクロウは昼間は目が見えない。（猫头鹰白天看不见东西。）
- **昼休み**（ひるやすみ）午休｜韩语参考：점심시간<br>
  例：お昼休みは、１時間です。（午休是一个小时。）
- **拾う**（ひろう）捡；接人｜韩语参考：줍다（捡，拾）<br>
  例：ホテルの前で私を車で拾ってください。（请在酒店门口开车接我。）
- **ファックス**（ファックス）传真｜韩语参考：팩스（传真，传真机） / 팩시밀리（传真，传真机）<br>
  例：ＦＡＸで地図を送っていただけませんか。（能麻烦您把地图传真给我吗。）
- **増える**（ふえる）增加｜韩语参考：늘다（增大，增长，增加） / 붇다（上涨，增加，增多） / 증가되다（被增加）<br>
  例：大雨で川の水が急に増えた。（大雨让河水一下子涨了起来。）
- **深い**（ふかい）深的｜韩语参考：깊다<br>
  例：湖の深さはどのくらいですか。（湖水有多深。）
- **複雑**（ふくざつ）复杂｜韩语参考：착잡（复杂，烦杂，心烦意乱，心乱如麻）<br>
  例：どのぐらい複雑なのだろうか。（到底有多复杂呢。）
- **復習**（ふくしゅう）复习｜韩语参考：복습<br>
  例：その課の復習をしましたか。（那一课复习了吗。）
- **部長**（ぶちょう）部长；部门经理｜韩语参考：부장（部长）<br>
  例：社長は新しい部長を任命した。（社长任命了新的部长。）
- **普通**（ふつう）普通；通常｜韩语参考：보통（普通，一般） / 일반（普通） / 통상（通常，平常）<br>
  例：私はふつう自転車で通学します。（我通常骑自行车上学。）
- **ぶどう**（ぶどう）葡萄｜韩语参考：포도<br>
  例：私たちはぶどうをたくさん手に入れた。（我们弄到了很多葡萄。）
- **太る**（ふとる）发胖｜韩语参考：붇다（长胖，发胖） / 찌다（发胖，长膘） / 살찌다（长胖，发胖）<br>
  例：あまり太ったのでカラーの前が合わなかった。（因为太胖了，衣领扣不上。）
- **布団**（ふとん）被褥｜韩语参考：자리（被褥） / 이부자리（被褥，铺盖）<br>
  例：布団をたたみなさい。（把被褥叠起来。）
- **舟**（ふね）船；小船｜韩语参考：배 / 작은 배<br>
  例：船は３時に出ることになっている。（船定在三点开。）
- **不便**（ふべん）不方便｜韩语参考：불편（不便，不方便）<br>
  例：もし電話がなければ、不便だろう。（要是没有电话，大概很不方便吧。）
- **踏む**（ふむ）踩｜韩语参考：딛다（踩，踏） / 밟다（踩）<br>
  例：足を踏むつもりはなかったのです。（我并不是故意踩你的脚。）
- **降り出す**（ふりだす）下起来｜韩语参考：내리기 시작하다<br>
  例：その上雨が降り出している。（而且雨也开始下了。）

## 语法

- **〜し**：既…又…；而且…
  接续：动词普通形／い形容词 + し；な形容词・名词 + だ + し
  朝鲜语：-고（韩语 -고 可并列理由，但语气中性；日语 し 暗示「还有别的理由」，主观色彩更强，韩语常需加 -기도 하고 才接近。）
- **〜けど / 〜けれども**：但是…；虽然…
  接续：句子普通形 + けど／けれども（礼貌体可直接接）
  朝鲜语：-지만（韩语 -지만 与 けど 对应，但日语 けど 还可放在句末缓和语气、引出下文；韩语 -지만 一般不能这样独立使用。）
- **〜ために**：为了…；因为…
  接续：动词辞书形／动词た形 + ために；名词 + の + ために
  朝鲜语：-기 위해(서) / 때문에（韩语 -기 위해(서) 表目的，때문에 表原因，两者形式不同；日语 ために 一个形式兼表目的与原因，需靠前接成分判断。）
- **〜ように（purpose）**：为了…；以便…
  接续：动词辞书形／动词ない形 + ように
  朝鲜语：-도록（韩语 -도록 与 ように 对应，且同样可接非意志动词；日语 ために 只能接意志动词，这一点韩语 -기 위해 的限制更严。）
