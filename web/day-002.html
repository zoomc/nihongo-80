金 金；钱；星期五

音读：キン、コン
训读：かね
韩语字音：금 / 김
금属、돈은 금；성씨는 김。
中文读 jīn；日语「金曜日」きんようび 音读 きん，「お金」かね 训读；中文「金」可指金属/金色，日语「金(かね)」主要是钱，义项收窄。

土 土；星期六

音读：ド、ト
训读：つち
韩语字音：토

中文读 tǔ；日语「土曜日」どようび 音读 ど，「土」训读 つち；「土」在日语不表「本土/国土」口语，那是 土地(とち)。

一 一

音读：イチ、イツ
训读：ひと、ひとつ
韩语字音：일

中文读 yī；日语「一」音读 いち（一人 ひとり、一日 ついたち 是训读/特殊）；「一つ」ひとつ 训读，不可一律 いち。

二 二

音读：ニ、ジ
训读：ふた、ふたつ
韩语字音：이

中文读 èr；日语「二人」ふたり、「二つ」ふたつ 训读，「二月」にがつ 音读；中文「两/二」有词形差，日语 二 无此差但读音分两套。

三 三

音读：サン
训读：み、みっつ
韩语字音：삼

中文读 sān；日语「三日」みっか、「三つ」みっつ 训读，「三人」さんにん 音读；训读 み 不可按 さん 推。

③ 语法 6 分钟

N は N ではありません / じゃない
名詞 + は + 名詞 + ではありません（口语 じゃない）
…不是…

判断句否定，礼貌体

私は先生ではありません。
我不是老师。
朝鲜语：이/가 아닙니다
韩语否定用이/가 아니다，助词随收音变化；日语では可缩成じゃ，韩语无对应缩略。

易错：私は先生ないです。 → 私は先生ではありません。（把「ではありません」拆成「ない＋です」，中文「不是」直译导致词类错误；「じゃありません」是合法的口语礼貌否定，不在纠错范围。）

N は N でした
名詞 + は + 名詞 + でした
…（过去）是…

判断句过去式，礼貌体

昨日は日曜日でした。
昨天是周日。
朝鲜语：이었습니다 / 였습니다
韩语过去按有无收音选이었/였，且分层级；日语でした只有一形，无收音条件。

易错：昨日は日曜日です。 → 昨日は日曜日でした。（时间词「昨日」要求过去，中文「是」无时态变化易漏 でした）
