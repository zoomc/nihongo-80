今日语法 2 条

〜ようだ
발음〜요우다
好像…；似乎…
动词普通形／い形容词 + ようだ；な形容词+な／名词+の + ようだ
根据所见所闻的证据做较有把握的推断，也可用于委婉断定。
다레모이나이요우데스네.
誰もいないようですね。
好像没有人呢。
카제오히이타요우데,아사카라노도가이타이.
かぜをひいたようで、朝からのどが痛い。
我好像感冒了，从早上起喉咙就痛。
소토와사무이요우다.민나코오토오키테이루.
外は寒いようだ。みんなコートを着ている。
外面好像很冷，大家都穿着大衣。
朝鲜语：-(으)ㄴ/는 것 같다
韩语 것 같다 与 ようだ 对应，但日语 ようだ 还常用于比喻和委婉断定；韩语 것 같다 的推测语气更单一。
易错点

外は寒いようだです。 → 外は寒いようです。（ようだ 已是普通形断定，接礼貌体应说「ようです」，不能加 です）

〜みたい
발음〜미타이
好像…；像…一样
动词普通形／い形容词／な形容词词干／名词 + みたいだ（口语）
口语中根据迹象推测，或表示比喻、举例。
토나리노헤야니다레카키타미타이.
隣の部屋に誰か来たみたい。
隔壁房间好像有人来了。
쿄우노카노조와겐키가나이미타이다네.
今日の彼女は元気がないみたいだね。
她今天好像没什么精神。
코노케이키,오미세노케이키미타이!
このケーキ、お店のケーキみたい！
这个蛋糕简直像店里卖的一样！
朝鲜语：-(으)ㄴ/는 것 같다 / 처럼
韩语表比喻用 처럼，表推测用 것 같다；日语 みたい 一个形式兼表两者，且接续不随词性变化。
易错点

このケーキ、お店のケーキのみたい！ → このケーキ、お店のケーキみたい！（名词直接接 みたい，不加 の）
