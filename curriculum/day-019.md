# Day 019 · 〜や、〜も、〜の（possessive）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 新词 25

- **七つ**（ななつ）七个｜韩语参考：일곱 개<br>
  例：りんごを七つ買いました。（我买了七个苹果。）
- **七日**（なのか）七天；七号｜韩语参考：이레（七天）<br>
  例：一週間は七日です。（一周有七天。）
- **習う**（ならう）学｜韩语参考：배우다（学，学习）<br>
  例：車の運転を習っています。（我在学开车。）
- **並ぶ**（ならぶ）排队｜韩语参考：줄짓다（排队，站队）<br>
  例：あんた、なぜに並んでいるのだい。（你排队做什么？）
- **並べる**（ならべる）排列｜韩语参考：늘어놓다<br>
  例：メイドはテーブルにナイフとフォークを並べた。（女仆把刀叉摆在桌上。）
- **賑やか**（にぎやか）热闹｜韩语参考：번화하다 / 떠들썩하다<br>
  例：この通りは賑やかだ。（这条街很热闹。）
- **西**（にし）西｜韩语参考：서（西）<br>
  例：列車は西へ走っていた。（列车一直向西行驶。）
- **荷物**（にもつ）行李｜韩语参考：짐（行李，货物） / 짐짝（行李卷儿，货包，货箱）<br>
  例：これ荷物を上にあげてもよろしい。（我把这件行李放上去可以吗？）
- **ニュース**（ニュース）新闻｜韩语参考：뉴스（新闻）<br>
  例：そのニュースはラジオで聞いたよ。（那条新闻我是在广播里听到的。）
- **庭**（にわ）院子｜韩语参考：뜰（院子） / 마당（院子，庭院）<br>
  例：その庭にはバラがまったくなかった。（那个院子里一朵玫瑰也没有。）
- **寝る**（ねる）睡觉｜韩语参考：자다（睡，睡觉） / 잠자다（睡觉，睡眠）<br>
  例：本を読んでるうちに寝てしまった。（看着书就睡着了。）
- **ノート**（ノート）笔记本｜韩语参考：공책（笔记本） / 노트（笔记本）<br>
  例：これらの語をノートに書きなさい。（把这些词写在笔记本上。）
- **登る**（のぼる）登；爬｜韩语参考：타다（爬，攀，登） / 오르다（上，登，攀登） / 치오르다（上，爬，去）<br>
  例：木は高ければ高いほど登りにくい。（树越高越难爬。）
- **飲み物**（のみもの）饮料｜韩语参考：음료（饮料） / 음료수（饮料）<br>
  例：何か飲み物をいただけますか。（能给我点喝的吗？）
- **歯**（は）牙｜韩语参考：치아（牙齿，牙，齿）<br>
  例：その赤ちゃんは歯が生えはじめている。（那个婴儿开始长牙了。）
- **パーティー**（パーティー）聚会｜韩语参考：파티（聚会，派对）<br>
  例：パーティーはたのしかったですか。（聚会玩得开心吗？）
- **はい**（はい）是；好｜韩语参考：네（是，是的，哎） / 예（是，唉）<br>
  例：「もしもし、ブラウンさんですか」「はい、そうです」（“喂，是布朗先生吗？”“是的。”）
- **灰皿**（はいざら）烟灰缸｜韩语参考：재떨이（烟灰缸）<br>
  例：灰皿を下さい。（请给我一个烟灰缸。）
- **入る**（はいる）进入｜韩语参考：들다（进入，陷入） / 들어가다（进入，转入） / 들어서다（进入，走进，踏进）<br>
  例：入る前にドアをノックして下さい。（进来之前请先敲门。）
- **葉書**（はがき）明信片｜韩语参考：엽서（明信片）<br>
  例：この店に葉書がたくさんある。（这家店有很多明信片。）
- **はく**（はく）穿（鞋袜）｜韩语参考：신다<br>
  例：この靴はきつすぎてはけない。（这双鞋太紧，穿不上。）
- **箱**（はこ）箱子｜韩语参考：함（箱 ，箱子） / 박스（盒子，箱子） / 상자（箱子）<br>
  例：その箱はほとんどいっぱいでした。（那个箱子几乎满了。）
- **はし**（はし）筷子｜韩语参考：젓가락<br>
  例：はしをもう一膳ください。（请再给我一双筷子。）
- **橋**（はし）桥｜韩语参考：다리（桥，桥梁）<br>
  例：その橋はどれくらいの長さですか。（那座桥有多长？）
- **始まる**（はじまる）开始｜韩语参考：시작되다（被开始）<br>
  例：今コンサートが始まろうとしている。（音乐会现在就要开始了。）

## 语法

- **〜や**：…和…等（部分列举）
  接续：名词 + や + 名词（部分列举）
  朝鲜语：나/이나（책이나 잡지 같은 것 对照 本や雑誌など，表示举些例子；要表达「书或杂志中选一个」，韩语还可用 이나，日语换成 本か雑誌。）
- **〜も**：也…；（否定）也不…
  接续：名词 + も
  朝鲜语：도（韩语 도 与 も 对应，且同样可叠用于否定并列（고기도 생선도）；日语 も 可顶替 は／が／を，韩语 도 也顶替主宾格助词。）
- **〜の（possessive）**：…的…
  接续：名词 + の + 名词
  朝鲜语：의（韩语 의 与 の 对应，但口语中 의 常省略；日语 の 不能省略，且还可代替名词（私の）。）
