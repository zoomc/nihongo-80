# Day 055 · 〜のに（purpose）、〜ので、〜て（reason）

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜のに（purpose）、〜ので、〜て（reason）」造两句自己的话，表达：用于…；做…需要；因为…；由于…；因为…（造成某种状态）

## 新词 20

- **冷える**（ひえる）变冷；冷却｜韩语参考：추워지다（变冷，冷起来）<br>
  例：冷えたビールがあればたまらないね。（要是有冰镇啤酒就太棒了。）
- **光**（ひかり）光；光线｜韩语参考：빛（光，光线）<br>
  例：光が世にやって来た。（光来到了世上。）
- **光る**（ひかる）发光；闪耀｜韩语参考：빛나다（发光，照射）<br>
  例：上部前方で何かが光っている。（前方上方有什么东西在发光。）
- **引き出し**（ひきだし）抽屉｜韩语参考：서랍（抽屉）<br>
  例：きれいなタオルは引き出しにありますよ。（干净的毛巾在抽屉里。）
- **引き出す**（ひきだす）取出；提取｜韩语参考：인출하다（支取，提取） / 찾아가다（取，取回，领取，提取）<br>
  例：彼のいいところを引き出すようにしなさい。（要设法把他好的一面引导出来。）
- **ひげ**（ひげ）胡子｜韩语参考：수염<br>
  例：お父さんがバスルームでひげを剃っている。（爸爸在浴室里刮胡子。）
- **飛行場**（ひこうじょう）机场｜韩语参考：비행장（机场）<br>
  例：その島の飛行場は、今では草がぼうぼうだ。（那个岛上的机场如今杂草丛生。）
- **久しぶり**（ひさしぶり）好久不见｜韩语参考：오랜만（好久，久违） / 오래간만（好久，久违）<br>
  例：彼女から久しぶりに電話があった。（好久没联系的她打来了电话。）
- **美術館**（びじゅつかん）美术馆｜韩语参考：미술관（美术馆）<br>
  例：このバスは美術館まで行きますか。（这趟公交到美术馆吗？）
- **非常に**（ひじょうに）非常｜韩语参考：마냥（非常，十分） / 매우（非常，极其，很） / 몹시（十分，非常，太）<br>
  例：車を運転することは非常に楽しい。（开车非常愉快。）
- **びっくりする**（びっくりする）吃惊｜韩语参考：놀라다（惊吓，吃惊）<br>
  例：彼はびっくりするほどのアクロバットができる。（他会的杂技多得让人吃惊。）
- **引っ越す**（ひっこす）搬家｜韩语参考：이사하다（搬家）<br>
  例：去年の秋、私たちはニューヨークに引っ越した。（去年秋天，我们搬到了纽约。）
- **必要**（ひつよう）必要；需要｜韩语参考：필요（必要，需要）<br>
  例：歯医者に行く必要はないですよ。（没必要去看牙医。）
- **ひどい**（ひどい）糟糕的；过分的｜韩语参考：심하다 / 끔찍하다<br>
  例：この薬はひどい味がする。（这药味道很糟。）
- **開く**（ひらく）开；绽放｜韩语参考：갖다（开，举办，举行） / 내다（开） / 열다（开）<br>
  例：庭のバラの木のつぼみが少しずつ開き始める。（院子里玫瑰树的花蕾一点点开了。）
- **ビル**（ビル）大楼｜韩语参考：빌딩（大楼，高楼，大厦）<br>
  例：駅の前に高いビルがあります。（车站前有一栋高楼。）
- **昼間**（ひるま）白天｜韩语参考：주간（昼间，白天） / 날（白天） / 해（白昼，白天）<br>
  例：フクロウは昼間は目が見えない。（猫头鹰白天看不见东西。）
- **昼休み**（ひるやすみ）午休｜韩语参考：점심시간<br>
  例：お昼休みは、１時間です。（午休是一个小时。）
- **拾う**（ひろう）捡；接人｜韩语参考：줍다（捡，拾）<br>
  例：ホテルの前で私を車で拾ってください。（请在酒店门口开车接我。）
- **ファックス**（ファックス）传真｜韩语参考：팩스（传真，传真机） / 팩시밀리（传真，传真机）<br>
  例：ＦＡＸで地図を送っていただけませんか。（能麻烦您把地图传真给我吗。）

## 语法

- **〜のに（purpose）**：用于…；做…需要
  接续：动词辞书形 + のに（用途・所需）；名词 + に
  朝鲜语：-는 데（韩语 -는 데 与用途、所需的 のに 对应（걷는 데 20분 걸린다）；日语 のに 与转折的 のに 同形，韩语则用 데 区分。）
- **〜ので**：因为…；由于…
  接续：动词普通形／い形容词 + ので；な形容词+な／名词+な + ので
  朝鲜语：-아서/어서（韩语 -아서/어서 与 ので 都表客观原因，但日语 ので 可接意志、请求，韩语 -아서/어서 后项一般不能是命令、劝诱。）
- **〜て（reason）**：因为…（造成某种状态）
  接续：动词て形／い形容词去い+くて／な形容词・名词+で
  朝鲜语：-아서/어서（韩语 -아서/어서 与 て 的原因用法对应，但日语 て 形还可表并列、先后，功能更多；韩语需靠上下文或另加连接词。）
