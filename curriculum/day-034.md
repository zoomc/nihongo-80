# Day 034 · 〜ておく、〜てみる、〜てある、〜とき

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ておく**：预先…好；…着（保持状态）
  接续：动词て形 + おく（口语缩约 とく）
  朝鲜语：-아/어 두다（韩语 -아/어 두다 也表预先做好并保持状态，对应度很高；日语口语缩约 とく 在韩语中没有同类的音变形式。）
- **〜てみる**：试着做…（看看效果）
  接续：动词て形 + みる
  朝鲜语：-아/어 보다（입어 보다 对照 着てみる，都是先尝试再说。补助动词相当于日语的 みる，练习时写成平假名。）
- **〜てある**：…着（有意为之的结果状态）
  接续：他动词て形 + ある；结果状态常用 が，已完成的准备可用 を。
  朝鲜语：-아/어 있다（韩语 -아/어 있다 可表状态持续，但不像日语 てある 那样明确区分他动词与自动词；日语用 が 提示结果主体，韩语用 이/가。）
- **〜とき**：…的时候
  接续：动词普通形／い形容词／な形容词+な／名词+の + とき
  朝鲜语：-(으)ㄹ 때 / -았/었을 때（京都へ行くとき 可指去之前或正在去的阶段；京都へ行ったとき 把到过京都作为后事的时间背景。韩语 갈 때／갔을 때 也有这一区别。）
