## 新词 25

- **地理**（ちり）地理｜韩语参考：지리（地理） / 지리학（地理学）<br>
  例：私はこの町の地理をよく知っている。（我很熟悉这个镇的地理。）
- **捕まえる**（つかまえる）抓住；逮住｜韩语参考：붙들다（抓住，逮住） / 붙잡다（抓住） / 포착하다（捕捉，抓住）<br>
  例：その男は少年の手をつかまえた。（那个男人抓住了男孩的手。）
- **つき**（つき）月亮；月｜韩语参考：달<br>
  例：まもなく月旅行が出来るだろう。（用不了多久就能去月球旅行了吧。）
- **付く**（つく）附带；沾上｜韩语参考：묻다（沾上） / 붙다（附带，附加） / 달리다（附带，附加）<br>
  例：うちの車にはエアコンが付いている。（我们家的车装有空调。）
- **漬ける**（つける）腌；浸泡｜韩语参考：재다（腌，喂） / 재우다（腌，喂） / 쟁이다（腌，喂）<br>
  例：彼はスプーンをスープの中につけた。（他把勺子浸到汤里。）
- **都合**（つごう）方便；情况｜韩语参考：사정（处境，情况，原因，缘由）<br>
  例：何時がご都合よいでしょうか。（您几点方便？）
- **伝える**（つたえる）传达；转告｜韩语参考：전달하다（传达，转达）<br>
  例：その話は親から子へと伝えられた。（那个故事从父母传给了孩子。）
- **続く**（つづく）持续；继续｜韩语参考：가다（持续） / 계속되다（继续，持续，接连） / 이어지다（连续，持续）<br>
  例：どれくらいこの寒い天気は続きますか。（这种冷天还要持续多久？）
- **包む**（つつむ）包；包裹｜韩语参考：싸다（包，裹） / 휩싸다（包围，包裹，裹住）<br>
  例：プレゼント用に包んでもらえますか。（能帮我包成礼物吗？）
- **妻**（つま）妻子｜韩语参考：처（妻子） / 아내（妻子，爱人，老婆）<br>
  例：妻と一緒に旅行します。（和妻子一起旅行。）
- **つもり**（つもり）打算｜韩语参考：셈（打算）<br>
  例：私は来年留学するつもりです。（我打算明年去留学。）
- **釣る**（つる）钓；钓鱼｜韩语参考：낚다（钓）<br>
  例：思っていたほど魚は釣れなかった。（鱼没有预想的那么好钓。）
- **連れる**（つれる）带（人）｜韩语参考：차다（带，领） / 데리다（带领，带）<br>
  例：でもさ、母を連れて行かなくてはいけないんだ。（可是啊，我必须带母亲一起去。）
- **丁寧**（ていねい）礼貌；仔细｜韩语参考：정중하다 / 꼼꼼하다<br>
  例：漢字を書くときは点やはらいに気をつけて、なるべく早くていねいに書きましょう。（写汉字时要注意点和撇捺，尽量又快又工整地书写。）
- **テキスト**（テキスト）教材；课本｜韩语参考：교재<br>
  例：このテキストは初心者向きにできている。（这本教材是为初学者编写的。）
- **適当**（てきとう）适当；随便｜韩语参考：적당하다 / 대충이다<br>
  例：あなたが適当だと思う本なら何でも読みなさい。（只要你觉得合适的书，什么都可以读。）
- **できるだけ**（できるだけ）尽量｜韩语参考：양껏（尽量，放量） / 될 수 있는 대로（尽量）<br>
  例：できるだけ多くの本を読みなさい。（尽量多读书。）
- **テニス**（テニス）网球｜韩语参考：테니스（网球）<br>

- **手袋**（てぶくろ）手套｜韩语参考：장갑（手套）<br>

- **寺**（てら）寺院｜韩语参考：절<br>

  例：店員はその荷物にラベルをつけた。（店员给那件行李贴上了标签。）
- **天気予報**（てんきよほう）天气预报｜韩语参考：일기 예보（天气预报，气象预报）<br>
  例：天気予報が当たったよ。（天气预报说准了。）
- **電灯**（でんとう）电灯｜韩语参考：전등（电灯）<br>
  例：ルーシーは電灯のスイッチをつけた。（露西打开了电灯的开关。）
- **電報**（でんぽう）电报｜韩语参考：전보（电报）<br>
  例：私は、彼女から電報を受け取った。（我收到了她发来的电报。）

## 语法

- **〜おう / 〜よう**：…吧；我要…
  接续：五段动词词尾改お段+う；一段动词去る+よう；する→しよう；来る→来よう
  朝鲜语：-자 / -(으)ㄹ게（韩语 -자 表提议，-(으)ㄹ게 表说话人意志；日语同一个意志形兼表两者，靠语境和语气区分。）
- **〜(よ)うと思う**：我想…；打算…
  接续：动词意志形 + と思う／と思っている
  朝鲜语：-(으)려고 하다（韩语 -(으)려고 하다 与 ようと思う 对应；但日语用「と思っている」可表持续的想法，韩语则靠现在时或 고 있다 区分。）
- **〜え / 〜ろ**：（命令）做！
  接续：五段动词词尾改え段；一段动词去る+ろ；する→しろ；来る→来い
  朝鲜语：-아/어라（韩语 -아/어라 与命令形对应，但韩语还有 -(으)세요 等礼貌命令；日语命令形语气更硬，且来る 的命令形是特殊形「来い」。）
- **〜な（prohibition）**：不许…；别…
  接续：动词辞书形 + な
  朝鲜语：-지 마라（韩语 -지 마라 与禁止形对应，语气同样强硬；日语禁止形只接辞书形，韩语则接词干，接续方式不同。）
