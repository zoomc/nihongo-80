# Day 073 · 〜かどうか、〜か（embedded question）

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜かどうか、〜か（embedded question）」造两句自己的话，表达：是否…；（嵌入）什么…、哪里…

## 新词 14

- **原因**（げんいん）原因（客观）｜韩语参考：원인（原因，理由，缘由）<br>
  例：事故の原因を調べています。（正在调查事故原因。）
- **結果**（けっか）结果｜韩语参考：결과（结果，结局）<br>
  例：調査の結果、原因が分かりました。（调查的结果，弄清了原因。）
- **目的**（もくてき）目的｜韩语参考：목적（目的，目标）<br>
  例：留学の目的は日本語を学ぶことです。（留学目的是学日语。）
- **機会**（きかい）机会｜韩语参考：때（时机，机会） / 기회（机会，机遇，时机）<br>
  例：話す機会がありません。（没有说话的机会。）
- **経験**（けいけん）经验；经历｜韩语参考：경험（经验）<br>
  例：海外で働いた経験があります。（有在海外工作过的经历。）
- **可能性**（かのうせい）可能性｜韩语参考：가능성（可能性，可行性）<br>
  例：雨の可能性が高いです。（下雨的可能性很高。）
- **影響**（えいきょう）影响｜韩语参考：영향（影响）<br>
  例：円安が物価に影響を与えます。（日元贬值影响物价。）
- **関係**（かんけい）关系；关联｜韩语参考：관계（关系）<br>
  例：この件には関係ありません。（和这件事没关系。）
- **状況**（じょうきょう）状况；情形（外部局面）｜韩语参考：모습（样子，景象，状况） / 상황（状况，情况） / 정황（情况，情形）<br>
  例：今の状況を報告してください。（请报告目前的情况。）
- **内容**（ないよう）内容｜韩语参考：내용（内容） / 내용물（内容物）<br>
  例：メールの内容を確認しました。（确认了邮件内容。）
- **情報**（じょうほう）信息；资讯｜韩语参考：정보（信息）<br>
  例：最新の情報を集めます。（收集最新信息。）
- **状態**（じょうたい）状态（事物/身体）｜韩语参考：상태（状态）<br>
  例：患者の状態が安定しています。（患者状态稳定。）
- **気持ち**（きもち）心情；感受；心意｜韩语参考：맘（心情，心绪） / 기분（心情） / 느낌（感觉，感受）<br>
  例：気持ちを言葉にするのは難しい。（把心情化成语言很难。）
- **気分**（きぶん）心情；身体状态；气氛｜韩语参考：맘（心情，心绪） / 기분（心情） / 마음（心情，心绪）<br>
  例：今日は気分が悪いです。（今天身体/心情不舒服。）

## 语法

- **〜かどうか**：是否…
  接续：动词普通形／い形容词／な形容词／名词 + かどうか
  朝鲜语：-인지 아닌지（韩语 -인지 아닌지 与 かどうか 对应；但日语 かどうか 不能与疑问词同用，韩语 인지 아닌지 的限制相同，需注意。）
- **〜か（embedded question）**：（嵌入）什么…、哪里…
  接续：疑问词 + …普通形 + か
  朝鲜语：-인지（韩语 -인지 与嵌入疑问的 か 对应，但韩语疑问词位置较自由；日语嵌入句必须用普通形，且句末不再加 か。）
