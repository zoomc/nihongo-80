# Day 009 · な形容词（～です）、い形容词 否定／过去／て形

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「な形容词（～です）、い形容词 否定／过去／て形」造两句自己的话，表达：…（な形容词谓语）；不…／曾…／又…（い形变形）

## 新词 19

- **新しい**（あたらしい）新｜韩语参考：새롭다（新）<br>
  例：新しいパソコンがほしいです。（想要新电脑。）
- **美味しい**（おいしい）好吃；美味｜韩语参考：맛나다（好吃，可口） / 맛있다（好吃，可口，香） / 맛깔나다（可口，美味）<br>
  例：この料理は美味しいです。（这道菜好吃。）
- **忙しい**（いそがしい）忙｜韩语参考：바쁘다（忙，忙碌，紧张）<br>
  例：今週は忙しいです。（这周很忙。）
- **寒い**（さむい）冷（天气/体感）｜韩语参考：춥다（冷）<br>
  例：今日は昨日ほど寒くないです。（今天没昨天冷。）
- **好き**（すき）喜欢｜韩语参考：좋아하다<br>
  例：魚が好きです。（喜欢鱼。）
- **元気**（げんき）精神；健康；有活力｜韩语参考：건강하다 / 활기차다<br>
  例：彼女は元気です。（她很精神。）
- **静か**（しずか）安静；宁静｜韩语参考：조용하다<br>
  例：この部屋は静かです。（这个房间安静。）
- **便利**（べんり）方便；便利｜韩语参考：편리（便利，方便）<br>
  例：この地図は便利です。（这张地图很方便。）
- **とても**（とても）非常；很｜韩语参考：된통（很，厉害） / 매우（非常，极其，很） / 몹시（十分，非常，太）<br>
  例：この本はとても高いです。（这本书很贵。）
- **少し**（すこし）稍微；一点｜韩语参考：좀（一点点，有一点） / 살짝（稍微） / 슬쩍（稍微）<br>
  例：少し休みます。（稍微休息一下。）
- **いつも**（いつも）总是；平时｜韩语参考：노상（老是，总是） / 매양（回回，总是，老是） / 백날（天天，总是）<br>
  例：いつも電車で行きます。（总是坐电车去。）
- **時々**（ときどき）有时；时常｜韩语参考：가끔가다（偶尔，有时）<br>
  例：時々映画を見ます。（有时看电影。）
- **まだ**（まだ）还；尚未｜韩语参考：채（还，尚） / 미처（尚未，来不及）<br>
  例：まだ食べていません。（还没吃。）
- **もう**（もう）已经；再（一次）｜韩语参考：벌써（已经） / 이미（已经）<br>
  例：もう帰りました。（已经回去了。）
- **そして**（そして）然后；而且｜韩语参考：그리고（而且，并且，况且）<br>
  例：本を読んで、そして寝ます。（读书，然后睡觉。）
- **だから**（だから）所以；因此｜韩语参考：그러므로（因此，所以）<br>
  例：雨です。だから、行きません。（下雨，所以不去。）
- **でも**（でも）但是；不过；连…也｜韩语参考：그런데（可是，但是）<br>
  例：高いです。でも、買います。（贵，不过还是买。）
- **すぐ**（すぐ）马上；立刻；就近｜韩语参考：곧（马上，就） / 금방（马上，立刻，立马） / 당장（当前，立刻）<br>
  例：すぐ行きます。（马上就去。）
- **ゆっくり**（ゆっくり）慢慢地；好好地｜韩语参考：천천히（慢慢地，缓慢地） / 슬렁슬렁（慢慢地，轻轻地）<br>
  例：ゆっくり話してください。（请慢慢说。）

## 语法

- **な形容词（～です）**：…（な形容词谓语）
  接续：な形容詞語幹 + です／だ
  朝鲜语：형용사(하다형)（韩语 하다 类形容词修饰名词时通常变成 -한，如 조용한 방；日语な形容词连体用 な。）
- **い形容词 否定／过去／て形**：不…／曾…／又…（い形变形）
  接续：高い→高くない／高かった／高くて
  朝鲜语：-지 않다 / -았·었- / -고（韩语否定用지 않다、过去用았/었、中顿用고，无日语くて的音便变化。）
