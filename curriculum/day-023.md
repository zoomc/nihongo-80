# Day 023 · 〜と（with）、〜や

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜と（with）、〜や」各造一句自己的话，表达：和…一起；…和…等（部分列举）

## 新词 23

- **撮る**（とる）拍摄｜韩语参考：찍다（拍，拍摄） / 촬영하다（摄影，摄制，拍摄）<br>
  例：外からなら撮ってもかまいません。（从外面拍的话没关系。）
- **取る**（とる）拿；取｜韩语参考：먹다（得， 取） / 취하다（取，拿，获得，获取，摄取）<br>
  例：そのお金はいざというときのために取っておくよ。（那笔钱我留着以备不时之需。）
- **どれ**（どれ）哪个｜韩语参考：어느 것<br>
  例：あなたのかばんはどれですか。（哪个是你的包？）
- **ナイフ**（ナイフ）刀｜韩语参考：칼（刀）<br>
  例：それはあなたのナイフではない。（那不是你的刀。）
- **長い**（ながい）长｜韩语参考：길다（长）<br>
  例：だんだん日が長くなっています。（白天渐渐变长了。）
- **鳴く**（なく）（动物）叫｜韩语参考：（동물이）울다<br>
  例：カエルが鳴いたら帰ろう。（青蛙叫了就回去吧。）
- **なぜ**（なぜ）为什么｜韩语参考：왜<br>
  例：あなたはなぜ働いているの。（你为什么在工作？）
- **夏**（なつ）夏天｜韩语参考：여름（夏，夏天，夏季）<br>
  例：アリは夏じゅうせっせとはたらく。（蚂蚁整个夏天都勤快地干活。）
- **夏休み**（なつやすみ）暑假｜韩语参考：여름휴가（暑假，暑期休假）<br>
  例：この夏休みはどこかへ行くのですか。（这个暑假你要去哪里吗？）
- **など**（など）等等｜韩语参考：등 / 따위<br>
  例：ぬくもりなどどこにも見つからない。（哪里都找不到温暖。）
- **七つ**（ななつ）七个｜韩语参考：일곱 개<br>
  例：７つの海って何ですか。（七大洋是什么？）
- **七日**（なのか）七天；七号｜韩语参考：이레（七天）<br>
  例：一週間は七日です。（一周有七天。）
- **習う**（ならう）学｜韩语参考：배우다（学，学习）<br>
  例：車の運転を習っています。（我在学开车。）
- **並ぶ**（ならぶ）排队｜韩语参考：줄짓다（排队，站队）<br>
  例：あんた、なぜに並んでいるのだい。（你排队做什么？）
- **並べる**（ならべる）排列｜韩语参考：늘어놓다<br>
  例：メイドはテーブルにナイフとフォークを並べた。（女仆把刀叉摆在桌上。）
- **賑やか**（にぎやか）热闹｜韩语参考：번화하다 / 떠들썩하다<br>
  例：この通りは賑やかだ。（这条街很热闹。）
- **西**（にし）西｜韩语参考：서（西）<br>
  例：列車は西へ走っていた。（列车一直向西行驶。）
- **荷物**（にもつ）行李｜韩语参考：짐（行李，货物） / 짐짝（行李卷儿，货包，货箱）<br>
  例：これ荷物を上にあげてもよろしい。（我把这件行李放上去可以吗？）
- **ニュース**（ニュース）新闻｜韩语参考：뉴스（新闻）<br>
  例：そのニュースはラジオで聞いたよ。（那条新闻我是在广播里听到的。）
- **庭**（にわ）院子｜韩语参考：뜰（院子） / 마당（院子，庭院）<br>
  例：その庭にはバラがまったくなかった。（那个院子里一朵玫瑰也没有。）
- **脱ぐ**（ぬぐ）脱（衣鞋）｜韩语参考：벗다<br>
  例：ここで靴を脱がなければなりませんか。（这里必须脱鞋吗？）
- **温い**（ぬるい）温的｜韩语参考：미지근하다<br>
  例：このコーヒーはぬるいです。（这咖啡不够烫。）
- **ネクタイ**（ネクタイ）领带｜韩语参考：타이（领带） / 넥타이（领带，领结）<br>
  例：このネクタイはいくらですか。（这条领带多少钱？）

## 语法

- **〜と（with）**：和…一起
  接续：名词（人）+ と（共同）
  朝鲜语：와/과 함께（韩语 와/과 可表共同，但口语更常用 하고；日语 と 后常可加 いっしょに，韩语 함께 的位置较固定。）
- **〜や**：…和…等（部分列举）
  接续：名词 + や + 名词（部分列举）
  朝鲜语：나/이나（韩语 나/이나 表选择或部分列举，与 や 接近；但韩语还可表示「或者」，日语 や 只表列举，不表选择。）

## 汉字 3

- **年** 年；年份｜音：ネン｜训：とし
- **長** 长；首领；年长｜音：チョウ｜训：なが.い、おさ
- **出** 出去；拿出；出现｜音：シュツ、スイ｜训：で.る、-で、だ.す、-だ.す、い.でる、い.だす
