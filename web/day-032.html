今日语法 4 条

N が V(他動詞)て ある
발음N 가 V테 아루
（人为地）已经…着；事先做好了…
他動詞て形 + ある；结果状态常用 が；已做好的准备也可用 を（例：本を置いてある）
表示某人有意为之、结果留存至今的状态，常用于准备已完成；不接自动词
쓰쿠에노우에니혼가오이테아리마스.
机の上に本が置いてあります。
桌上放着书（事先摆好的）。
호테루노요야쿠가시테아리마스.
ホテルの予約がしてあります。
酒店已经（事先）订好了。
朝鲜语：-아/어 있다
韩语结果状态用아/어 있다，不强调人为施事；日语てある暗示某人有意为之，语感不同。
易错点

ドアが開いてあります。 → ドアが開いています。（人为打开并保持则 開けてあります）（「開く」是自动词，自动词不能接 てある（应用 ている）；中文「开着」不区分自他）

Vて + いく / くる
발음V테 + 이쿠 / 쿠루
…下去／…起来（趋势）；去…再来／…过来（移动）
動詞 て形 + いく／くる；いく・くる 按五段/カ変变形（ていきます／てきました）
空间：做完某动作后去/来；时间：状态从现在向将来（いく）或从过去向现在（くる）变化
코레카라모니혼고오벤쿄우시테이키마스.
これからも日本語を勉強していきます。
今后也会继续学下去。
아메가후떼키마시타.
雨が降ってきました。
下起雨来了。
朝鲜语：-아/어 가다 / -아·어 오다
韩语가다/오다补助同样表时间趋势，以说话人为基准；与日语いく/くる方向基准相近。
易错点

これから勉強しています。 → これからも勉強していきます。（中文「学下去」易误用 ている；向将来延续应用 〜ていく）

普通形 + か どうか
是否…；…还是不…
動詞/い形 普通形 + かどうか；名詞・な形 词干 + かどうか（不加 だ/な）；疑问词问句不用 かどうか
把是非疑问嵌入句中，作 分かる／調べる／決める／聞く 等的内容；整体可当名词用（が／を／は）
이케루카도우카,마다와카리마센.
行けるかどうか、まだ分かりません。
还不知道能不能去。
카레가쿠루카도우카,키이테미마스.
彼が来るかどうか、聞いてみます。
我去问问他来不来。
朝鲜语：-는지 / -(으)ㄴ지
韩语嵌入疑问用는지，按词性变인지；日语かどうか固定，且不能直接接名词。
易错点

行くかどうかを分かりません。 → 行くかどうか分かりません。（「分かる」的对象用 が，中文「知道是否…」直译加 を 错）

普通形 + んです / のだ
（是）因为…；其实是…（说明/强调语气）
動詞・い形 普通形 + んです；な形・名詞 + な + んです；礼貌体 んです，简体 のだ／んだ
解释原因、背景或强调；回答 どうして 时用；口语用 んです，书面/简体用 のだ
오소쿠나떼스미마센.덴샤가오쿠레탄데스.
遅くなってすみません。電車が遅れたんです。
抱歉迟到了，是电车晚点了。
코노미세와타카인데스카.
この店は高いんですか。
这家店（是）很贵吗？
朝鲜语：-거든요 / -는데요 / -잖아요
韩语说明语气由거든요、는데요、잖아요等分担；日语んです一形统合，须按语境选择。
易错点

電車が遅れたです。 → 電車が遅れたんです。（普通形过去 た 不能直接接 です；中文「晚点了」直译错，须 た＋んです）
