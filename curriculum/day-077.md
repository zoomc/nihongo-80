# Day 077 · 〜につれて、〜とともに、〜たびに

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜につれて**：随着…
  接续：动词辞书形/名词 + につれて
  朝鲜语：-에 따라（韩语「-에 따라」同时承担“依照”和“随着”；日语「につれて」只表随之变化，前后都须是变化性表达。）
- **〜とともに**：与…一起；随着…
  接续：名词 + とともに；动词辞书形 + とともに
  朝鲜语：-와 함께（韩语「-와 함께」只表“一起”；日语「とともに」还能表“随着、同时”，韩语后者要用「-에 따라」。）
- **〜たびに**：每当…就…
  接续：动词辞书形 + たびに；名词 + の + たびに
  朝鲜语：-ㄹ 때마다（갈 때마다／行くたびに 都强调每次去都发生同一件事。固定计量间隔如「每隔十分钟」用 十分ごとに。）
