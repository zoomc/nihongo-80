# Day 014 · ～たり ～たり する、〜は、〜が（subject）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **～たり ～たり する**：又…又…／时而…时而…
  接续：動詞た形 + り + 動詞た形 + り + する
  朝鲜语：-기도 하고 -기도 하다（주말에는 영화를 보기도 하고 산책을 하기도 해요 对照 週末は映画を見たり散歩したりします，列举平时会做的几件事。た 是 たり 的接续，整句时态看最后的 する。）
- **〜は**：…是主题；至于…
  接续：名词 + は（读作 wa）
  朝鲜语：은/는（주제 조사）（은/는、は 都可以提示主题或拉出对比。日语 は 写作 ha 所对应的假名、这里读 wa。复习「茶喝，咖啡不喝」这种对比时可以说 お茶は飲むが、コーヒーは飲まない。）
- **〜が（subject）**：…是主语；提示新信息
  接续：名词 + が
  朝鲜语：이/가（주어·신정보）（누가 왔어요? 对照 誰が来ましたか。日语用 が 来标「谁」这一询问焦点。回答也可用 田中さんが来ました；韩语口语中偶尔会省略其他类型的主语助词。）
