# Day 059 · 〜れる / 〜られる（passive）、〜せる / 〜させる

- Can-do：用「〜れる / 〜られる（passive）、〜せる / 〜させる」造两句自己的话，表达：被…；遭受…；让…做；使…做

## 新词 14

- **ちっとも**（ちっとも）一点也不｜韩语参考：조금도（부정과 함께）<br>
  例：最近エリザベスにちっともあってない。（最近完全没见到伊丽莎白。）
- **ちゃん**（ちゃん）小…（昵称）｜韩语参考：~짱（친근한 호칭）<br>
  例：あら、あなたのところの娘のはるちゃんはとても陽気ですね。（哎呀，你家女儿小春真开朗啊。）
- **注意**（ちゅうい）注意；提醒｜韩语参考：주의（注意，留意） / 주의하다（注意，留意）<br>
  例：彼に遅れないように注意した。（我提醒他别迟到。）
- **中学校**（ちゅうがっこう）初中｜韩语参考：중학교（初中）<br>
  例：この歌を聞くと私の中学校時代を思い出します。（听到这首歌就想起我的初中时代。）
- **注射**（ちゅうしゃ）打针；注射｜韩语参考：주사（注射）<br>
  例：注射をしましょう。（打一针吧。）
- **駐車場**（ちゅうしゃじょう）停车场｜韩语参考：주차장（停车场）<br>
  例：駐車場には人ひとり見えなかった。（停车场里一个人也看不见。）
- **地理**（ちり）地理｜韩语参考：지리（地理） / 지리학（地理学）<br>
  例：私はこの町の地理をよく知っている。（我很熟悉这个镇的地理。）
- **捕まえる**（つかまえる）抓住；逮住｜韩语参考：붙들다（抓住，逮住） / 붙잡다（抓住） / 포착하다（捕捉，抓住）<br>
  例：その男は少年の手をつかまえた。（那个男人抓住了男孩的手。）
- **つき**（つき）月亮；月｜韩语参考：달<br>
  例：まもなく月旅行が出来るだろう。（用不了多久就能去月球旅行了吧。）
- **付く**（つく）附带；沾上｜韩语参考：묻다（沾上） / 붙다（附带，附加） / 달리다（附带，附加）<br>
  例：うちの車にはエアコンが付いている。（我们家的车装有空调。）
- **漬ける**（つける）腌；浸泡｜韩语参考：재다（腌，喂） / 재우다（腌，喂） / 쟁이다（腌，喂）<br>
  例：彼はスプーンをスープの中につけた。（他把勺子浸到汤里。）
- **都合**（つごう）方便；情况｜韩语参考：사정（处境，情况，原因，缘由）<br>
  例：何時がご都合よいでしょうか。（您几点方便？）
- **伝える**（つたえる）传达；转告｜韩语参考：전달하다（传达，转达）<br>
  例：その話は親から子へと伝えられた。（那个故事从父母传给了孩子。）
- **続く**（つづく）持续；继续｜韩语参考：가다（持续） / 계속되다（继续，持续，接连） / 이어지다（连续，持续）<br>
  例：どれくらいこの寒い天気は続きますか。（这种冷天还要持续多久？）

## 语法

- **〜れる / 〜られる（passive）**：被…；遭受…
  接续：五段动词未然形+れる；一段动词未然形+られる；する→される；来る→来られる
  朝鲜语：피동 (-이/히/리/기-)（韩语用被动词尾或 -에 의해，日语用助动词 れる／られる；日语受害被动（足を踏まれた）在韩语中常改用主动句或 -당하다。）
- **〜せる / 〜させる**：让…做；使…做
  接续：五段动词未然形+せる；一段动词未然形+させる；する→させる；来る→来させる
  朝鲜语：-게 하다（韩语 -게 하다 与使役对应，但日语使役对象用 に 还是 を 取决于动词；韩语统一用 을/를 或 에게，需按语义判断。）
