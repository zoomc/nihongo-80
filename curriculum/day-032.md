# Day 032 · 〜ではありません / 〜じゃない、〜でした

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜ではありません / 〜じゃない、〜でした」造两句自己的话，表达：不是…；（过去）是…

## 新词 19

- **辺**（へん）附近；一带｜韩语参考：근처 / 부근<br>
  例：この辺にホテルはありますか。（这附近有酒店吗？）
- **ペン**（ペン）笔；钢笔｜韩语参考：펜（笔）<br>
  例：リンゴと本の間にペンがあります。（苹果和书之间有一支笔。）
- **帽子**（ぼうし）帽子｜韩语参考：모자（帽子）<br>
  例：この帽子は１０００円なら安い。（这顶帽子一千日元的话很便宜。）
- **ボールペン**（ボールペン）圆珠笔｜韩语参考：볼펜（圆珠笔）<br>
  例：ボールペンのインクがなくなった。（圆珠笔没墨水了。）
- **ほか**（ほか）其他；其余｜韩语参考：다른 것 / 그 밖에<br>
  例：ほかの女の子たちはどこにいるの。（其他女孩子在哪儿呢？）
- **ポケット**（ポケット）口袋；衣兜｜韩语参考：주머니（衣袋，衣兜） / 호주머니（口袋）<br>
  例：ポケットに何を持っていますか。（你口袋里装着什么？）
- **欲しい**（ほしい）想要｜韩语参考：원하다（希望，想要）<br>
  例：友人はマイカーを欲しがっている。（朋友想要一辆自己的车。）
- **ポスト**（ポスト）邮筒｜韩语参考：우체통（邮筒，邮箱，信箱，信筒）<br>
  例：ポストはどこにありますか。（邮筒在哪儿？）
- **細い**（ほそい）细；瘦｜韩语参考：가늘다（细，纤细）<br>
  例：彼は太っているくせに声は細い。（他明明很胖，声音却很细。）
- **ボタン**（ボタン）扣子；按钮｜韩语参考：단추（扣子，纽扣） / 버튼（按钮）<br>
  例：レーンコートのボタンがとれた。（雨衣的扣子掉了。）
- **本棚**（ほんだな）书架｜韩语参考：서가（书架） / 책꽂이（书架）<br>
  例：私は本棚の本をすべて読んだわけではない。（我并没有把书架上的书都读完。）
- **ほんとう**（ほんとう）真的；真实｜韩语参考：정말 / 진실<br>
  例：本当のマンションではありません。（这不是真正的公寓。）
- **毎朝**（まいあさ）每天早上｜韩语参考：매일 아침<br>
  例：毎朝ジョギングすることにした。（我决定每天早上跑步。）
- **毎月**（まいげつ）每月｜韩语参考：매달<br>
  例：毎月のガス代はいくらですか。（每月燃气费多少？）
- **毎週**（まいしゅう）每周｜韩语参考：매주（每周，每星期）<br>
  例：父は毎週日曜日にゴルフをします。（父亲每周日打高尔夫。）
- **毎年**（まいねん）每年｜韩语参考：매년<br>
  例：毎年ここに来なきゃ。（每年都得来这儿。）
- **毎晩**（まいばん）每天晚上｜韩语参考：매일 밤<br>
  例：私は毎晩家にいます。（我每天晚上都在家。）
- **曲る**（まがる）拐弯；弯曲｜韩语参考：돌다 / 구부러지다<br>
  例：２ブロック先まで歩き、左へ曲がりなさい。（往前走两个街区，然后向左拐。）
- **まずい**（まずい）难吃；糟糕｜韩语参考：맛없다 / 곤란하다<br>
  例：あ！まずい！ガソリンが切れてきた。（啊！糟了！汽油快没了。）

## 语法

- **〜ではありません / 〜じゃない**：不是…
  接续：名词／な形容词 + ではありません（礼貌）／じゃない（普通）
  朝鲜语：아니다 / 아닙니다（韩语 아니다 是独立形容词，需接 이/가（학생이 아닙니다）；日语 ではありません 直接接名词，不用助词，这是常见差异。）
- **〜でした**：（过去）是…
  接续：名词／な形容词 + でした
  朝鲜语：이었습니다 / 였습니다（韩语过去礼貌体 이었습니다/였습니다 随收音变化，日语 でした 形式固定；い形容词过去用 かったです，韩语则用过去时制。）
