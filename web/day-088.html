今日语法 3 条

〜向き / 〜向け
발음〜무키 / 〜무케
适合…；面向…
名词 + 向き（だ／の／な）；名词 + 向け（だ／の／に）
「向き」表“适合某类人”，「向け」表“以某类人为对象制作”。
韩语对应…에 알맞다 / …용
초보자에게 알맞다 对照 初心者向き；초보자용 对照 初心者向け。前者评价适不适合，后者说明为谁设计，实际使用对象可能重合。
この料理は作り方が簡単なので、初心者向きだ。
这道菜做法简单，适合初学者。
この雑誌は、若い女性向けに作られている。
这本杂志是面向年轻女性制作的。
子ども向けの番組だが、大人が見ても十分楽しめる。
这是给孩子看的节目，大人看也很有趣。

易错点 これは初心者向きのな本です。 → これは初心者向きの本です。（名词前可用「向きの」或「向きな」，不叠用「のな」。）

〜がち
발음〜가치
容易…；动不动就…
动词ます形词干/名词 + がち
表示容易出现某种不太好的倾向，多含消极评价。
韩语对应-기 쉽다
韩语「-기 쉽다」中性，好坏都可用；日语「がち」几乎只用于消极倾向，且偏书面。
후유 니 나루토, 쓰이이에 니 코모리가치 니 나루.
冬になると、つい家にこもりがちになる。
一到冬天，就容易闷在家里。
무스메 와 치이사이코로뵤우키가치다따가, 이마 와 토테모겐키다.
娘は小さいころ病気がちだったが、今はとても元気だ。
女儿小时候常生病，现在很健康。
一人暮らしだと、野菜が不足しがちです。
一个人生活，容易蔬菜摄入不足。

易错点 冬になると、つい家にこもるがちになる。 → こもりがちになる（「がち」前接ます形词干「こもり」，不能接辞书形。）

〜気味
발음〜기미
有点…；稍有…迹象
名词/动词ます形词干 + 気味
表示已经出现某种轻微、不太好的迹象。
韩语对应약간 … 기운이 있다 / 조금 …한 편이다
감기 기운이 있다 很接近 風邪気味だ。疲れ気味 可译 요즘 조금 피곤한 편이다。気味 通常说眼下有一点某种迹象，がち 则说反复出现的倾向。
少し風邪気味なので、今日は早めに帰ります。
有点感冒，今天早点回去。
사이킨, 시고토 가 이소가시쿠테쓰카레키미다.
最近、仕事が忙しくて疲れ気味だ。
最近工作忙，有点累。
人手が足りず、工事は予定より遅れ気味だ。
人手不足，工程有点滞后。

易错点 少し風邪の気味なので、今日は早めに帰ります。 → 風邪気味なので（「気味」直接接名词或动词词干，不加「の」。）
