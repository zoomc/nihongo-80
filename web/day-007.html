今日语法 2 条

から ～ まで
발음카라 ～ 마데
从…到…
名詞（时/处） + から + 名詞 + まで
时间/空间的起点与终点，成对使用
쿠지카라고지마데벤쿄우시마스.
九時から五時まで勉強します。
从九点学习到五点。
에키카라가꼬우마데이키마스.
駅から学校まで行きます。
从车站走到学校。
朝鲜语：부터 ~ 까지
韩语起点用부터、终点까지，与日语基本对应；但韩语时间起点口语可用에，日语から不可省。
易错点

九時から五時に 勉強します。 → 九時から五時まで勉強します。（终点用 まで，に 是时点/归着；中文「到五点」误对应 に）

（场所）に ～ がある / いる
발음니 ～ 가아루 / 이루
（某地）有…
場所 + に + 物/人 + が + ある／いる
存在句：无生命用 ある，有生命用 いる；主体用 が
헤야니네코가이마스.
部屋に猫がいます。
房间里有猫。
에키노마에니미세가아리마스.
駅の前に店があります。
车站前有店。
朝鲜语：에 ~ 이/가 있다 / 계시다
韩语存在动词不分有无生命，一律있다，敬语用계시다；日语必须分ある/いる。
易错点

部屋に猫があります。 → 部屋に猫がいます。（猫是有生命，用 いる；中文「有」不分 animate，日语 ある/いる 必须分）
