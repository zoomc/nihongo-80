# Day 063 · 〜ば、〜たら

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜ば、〜たら」造两句自己的话，表达：如果…；如果…；…之后

## 新词 20

- **葉**（は）叶子<br>
  例：こちらには大きなハスの葉があります。（这里有巨大的荷叶。）
- **場合**（ばあい）场合；情况<br>
  例：システムが作動しない場合がある。（有时系统会不工作。）
- **パート**（パート）兼职；计时工<br>
  例：ごめんね。明日は朝からパートがあるのよ。（抱歉，明天一早我有兼职。）
- **倍**（ばい）倍｜朝鲜语：배<br>
  例：あの山はこの山の５倍の高さである。（那座山的高度是这座山的五倍。）
- **拝見**（はいけん）拜读；看<br>
  例：パスポートを拝見できますか。（能让我看一下您的护照吗？）
- **歯医者**（はいしゃ）牙医；牙科<br>
  例：今日歯医者へ行きました。（今天去看了牙医。）
- **場所**（ばしょ）地点；场所<br>
  例：このソファーは場所を取りすぎる。（这沙发太占地方了。）
- **はず**（はず）应该；理应<br>
  例：トムは今にもここに来るはずです。（汤姆应该马上就要到这里了。）
- **発音**（はつおん）发音｜朝鲜语：발음<br>
  例：あなたのお名前はどのように発音するのですか。（您的名字怎么念？）
- **はっきり**（はっきり）清楚；明确<br>
  例：私はまだはっきりとは知らない。（我还不太清楚。）
- **花見**（はなみ）赏花；赏樱<br>
  例：花見ができる春が待ち遠しい。（盼着能赏樱的春天快点来。）
- **林**（はやし）树林<br>
  例：林に竹が目立つ。（树林里竹子很显眼。）
- **払う**（はらう）支付；掸掉<br>
  例：ジャックはブラシで上着のほこりを払った。（杰克用刷子刷掉了外套上的灰。）
- **番組**（ばんぐみ）节目<br>
  例：今晩どんな番組がありますか。（今晚有什么节目？）
- **反対**（はんたい）反对；相反｜朝鲜语：반대<br>
  例：この考えには反対せざるをえない。（我不得不反对这个想法。）
- **ハンドバッグ**（ハンドバッグ）手提包<br>
  例：私のハンドバッグをどうしたの？（你把我的手提包怎么了？）
- **火**（ひ）火<br>
  例：いすをもっと火の近くに寄せなさい。（把椅子往火边再挪近些。）
- **日**（ひ）日子；太阳<br>
  例：冬が近づくにつれて日が短くなる。（随着冬天临近，白天越来越短。）
- **ピアノ**（ピアノ）钢琴<br>
  例：ナンシーはピアノを持っています。（南希有一架钢琴。）
- **冷える**（ひえる）变冷；冷却<br>
  例：冷えたビールがあればたまらないね。（要是有冰镇啤酒就太棒了。）

## 语法

- **〜ば**：如果…
  接续：五段动词词尾改え段+ば；一段动词去る+れば；い形容词去い+ければ；な形容词・名词+なら
  朝鲜语：-(으)면（韩语 -(으)면 与 ば 对应，但日语 ば 的后项一般不能是意志、命令；韩语 -(으)면 没有这个限制。）
- **〜たら**：如果…；…之后
  接续：动词た形 + ら；い形容词去い+かったら；な形容词・名词+だったら
  朝鲜语：-(으)면 / -았/었더니（韩语 -(으)면 表条件，-았/었더니 表前项完成后的发现；日语 たら 一个形式兼表两者，使用范围更广。）
