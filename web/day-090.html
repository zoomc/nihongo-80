今日语法 3 条

〜ようにする
발음〜요우니스루
尽量…；设法做到…
动词辞书形／动词ない形 + ようにする
表示有意识地努力维持某种做法或状态，常与「ている」表习惯。
韩语对应-도록 하다
늦지 않도록 하고 있다 对照 遅れないようにしている，表达有意识地维持。ようにする 也可以用于一次调整，如 明日は遅れないようにする。
毎日野菜を食べるようにしています。
我尽量每天都吃蔬菜。
코레카라 와 치코쿠시나이요우 니 시마스.
これからは遅刻しないようにします。
今后我会注意不再迟到。
네루마에 니 스마호 오 미나이요우 니 시테이루.
寝る前にスマホを見ないようにしている。
我尽量睡前不看手机。

易错点 毎日野菜を食べるようにしっています。 → 毎日野菜を食べるようにしています。（ようにする 的持续形是「ようにしている」，不是「しっている」）

〜はずだ
발음〜하즈다
应该…；按理说…
动词普通形／い形容词 + はずだ；な形容词+な／名词+の + はずだ
根据事实或逻辑推断理应如此，语气较有把握。
韩语对应-(으)ㄹ 것이다
韩语 -(으)ㄹ 것이다 既可表推测也可表意志，日语 はずだ 只表基于根据的推断，不含意志；两者不能完全对应。
荷物は明日届くはずです。
包裹应该明天到。
카레 와 주우넨 모 아메리카 니 슨데이타카라, 에이고 가 조우즈나하즈다.
彼は十年もアメリカに住んでいたから、英語が上手なはずだ。
他在美国住了十年，英语应该很好。
오카시이 나. 카기 와 코코 니 오이타하즈나노니.
おかしいな。かぎはここに置いたはずなのに。
奇怪，我明明把钥匙放在这里的。

易错点 彼は十年もアメリカに住んでいたから、英語が上手のはずだ。 → 彼は十年もアメリカに住んでいたから、英語が上手なはずだ。（な形容词接 はずだ 要用「な」，不是「の」）

〜はずがない
발음〜하즈가나이
不可能…；不会…
动词普通形／い形容词 + はずがない；な形容词+な／名词+の + はずがない
根据理由强烈否定某种可能性，语气比「ない」更主观。
韩语对应-(으)ㄹ 리가 없다
회사에 있을 리가 없다 对照 会社にいるはずがない。两句的判断都依赖已知情况，可以想成「按理说绝不可能」；若只转述消息，用 そうだ 更合适。
안나니마지메나히토 가 우소 오 쓰쿠하즈 가 나이.
あんなにまじめな人がうそをつくはずがない。
那么认真的人不可能说谎。
쿄우 와 니치요우비다카라, 긴코우 가 아이테이루하즈 가 나이.
今日は日曜日だから、銀行が開いているはずがない。
今天是星期天，银行不可能开门。
카기 와 찬토카케타카라, 도아 가 아이테이루하즈 가 나이.
かぎはちゃんとかけたから、ドアが開いているはずがない。
我明明锁好了，门不可能开着。

易错点 彼が来るはずがないません。 → 彼が来るはずがありません。（「ない」不与「ません」直接叠加。）
