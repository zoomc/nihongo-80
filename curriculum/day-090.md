# Day 090 · V辞書形 / Vない形 / い形 / な形な + うちに、Nの / Vている + 最中に（だ）

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「V辞書形 / Vない形 / い形 / な形な + うちに、Nの / Vている + 最中に（だ）」造两句自己的话，表达：趁着…；在…期间（不知不觉）…；正在…的时候（突然…）

## 新词 20

- **汚染**（おせん）污染｜韩语参考：오염（污染）<br>
  例：汚染が地球を傷つけている。（污染正在伤害地球。）
- **おそらく**（おそらく）恐怕；大概｜韩语参考：아마 / 어쩌면<br>
  例：首相はおそらく辞任するであろう。（首相恐怕会辞职。）
- **恐れる**（おそれる）害怕；担心｜韩语参考：겁나다（畏惧，害怕） / 겁내다（害怕，畏惧） / 겁먹다（受惊吓，害怕）<br>
  例：大人はしばしば変化を恐れる。（大人常常害怕变化。）
- **恐ろしい**（おそろしい）可怕；惊人｜韩语参考：무섭다（怕，害怕，可怕，恐惧）<br>
  例：その嵐の天候は恐ろしかった。（那场暴风雨的天气很可怕。）
- **お互い**（おたがい）互相；双方｜韩语参考：서로<br>
  例：お互い相性がいい。（彼此很合得来。）
- **穏やか**（おだやか）平静；温和｜韩语参考：평온（平稳，平静，安稳）<br>
  例：海は穏やかに、そしてなめらかに見える。（大海看上去平静而平滑。）
- **男の人**（おとこのひと）男人；男性｜韩语参考：남자<br>
  例：若い男の人がドアの前で歌っています。（一个年轻男人在门前唱歌。）
- **劣る**（おとる）劣于；不如｜韩语参考：못하다（不如，逊色） / 빠지다（不足，不及，不如）<br>
  例：彼女は、彼より、数学において劣っている。（她在数学方面不如他。）
- **鬼**（おに）鬼；妖怪｜韩语参考：도깨비 / 귀신<br>
  例：遅れたやつは鬼に食われろ。（迟到的人就让鬼吃掉吧。）
- **帯**（おび）腰带；地带｜韩语参考：띠（腰带） / 벨트（腰带）<br>
  例：彼女の着物と帯の取り合わせはおつだね。（她和服与腰带的搭配很有品味。）
- **お昼**（おひる）中午；午饭｜韩语参考：점심 / 정오<br>
  例：お昼をおごってくれたのを覚えてますか。（你还记得请我吃午饭的事吗？）
- **オフィス**（オフィス）办公室｜韩语参考：사무실<br>
  例：いつでも私のオフィスを訪ねなさい。（随时来我办公室找我。）
- **溺れる**（おぼれる）溺水；沉溺｜韩语参考：탐닉하다（沉湎，沉溺，迷恋）<br>
  例：彼女は危うく溺れるところだった。（她差点淹死。）
- **おまえ**（おまえ）你｜韩语参考：너<br>
  例：お前を娘の夫にしよう。（就让你做我女儿的丈夫吧。）
- **おめでとう**（おめでとう）恭喜｜韩语参考：축하해<br>
  例：クリスマスおめでとうございます。（圣诞快乐。）
- **お目に掛かる**（おめにかかる）拜见；见面｜韩语参考：뵙다（겸양）<br>
  例：家内もお目にかかることを楽しみにしておりますから。（我妻子也期待见到您。）
- **思い出**（おもいで）回忆｜韩语参考：추억（回忆）<br>
  例：この旅行はいい思い出になるでしょう。（这次旅行会成为美好的回忆。）
- **主に**（おもに）主要；大多｜韩语参考：주로（主要）<br>
  例：スペインの雨は主に平原に降る。（西班牙的雨主要下在平原上。）
- **思わず**（おもわず）不由得；禁不住｜韩语参考：무심코 / 저도 모르게<br>
  例：彼は思わず笑った。（他不由得笑了。）
- **泳ぎ**（およぎ）游泳｜韩语参考：헤엄（游泳，凫水，游水）<br>
  例：このごろは子供は学校で泳ぎを習う。（现在孩子在学校学游泳。）

## 语法

- **V辞書形 / Vない形 / い形 / な形な + うちに**：趁着…；在…期间（不知不觉）…
  接续：動詞辞書形 + うちに；動詞ない形 + ないうちに；い形 + うちに；な形 + なうちに；名詞 + のうちに
  朝鲜语：-는 동안에 / -기 전에（韩语는 동안表期间，기 전에表趁还没；日语うちに还含不知不觉变化，韩语须用는 사이에。）
- **Nの / Vている + 最中に（だ）**：正在…的时候（突然…）
  接续：名詞 + の + 最中に；動詞ている + 最中に；句末可 最中だ
  朝鲜语：-는 중에 / -는 도중에（韩语는 중表正在，도중에表途中；日语最中に强调正到一半被打断，语感更强。）
