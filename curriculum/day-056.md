# Day 056 · 〜中、〜つもり

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜中、〜つもり」造两句自己的话，表达：正在…中；整个…；全…；打算…；计划…

## 新词 19

- **すると**（すると）于是；那么｜韩语参考：그러자 / 그러면<br>
  例：するとあなたは幸せでしょう。（那样的话你就会幸福吧。）
- **生活**（せいかつ）生活｜韩语参考：생활（生活）<br>
  例：どのようにして生活していきますか。（你打算怎么生活下去？）
- **生産**（せいさん）生产｜韩语参考：생산（生产）<br>
  例：この工場はＣＤプレーヤーを生産している。（这家工厂生产CD播放机。）
- **政治**（せいじ）政治｜韩语参考：정치（政治）<br>
  例：政治については語りたくない。（我不想谈论政治。）
- **西洋**（せいよう）西方；西洋｜韩语参考：서양（西方，欧美，西洋）<br>
  例：それらは西洋の風呂よりずっといいです。（那些比西式的浴缸好得多。）
- **世界**（せかい）世界｜韩语参考：세계（世界）<br>
  例：愛の力は世界を動かす。（爱的力量能推动世界。）
- **席**（せき）座位｜韩语参考：자리（座位，席位）<br>
  例：この席を見ていてくれませんか。（能帮我看住这个座位吗？）
- **背中**（せなか）后背｜韩语参考：등<br>
  例：このブラウスはボタンが背中にある。（这件女衬衫的扣子在背上。）
- **ぜひ**（ぜひ）务必；一定｜韩语参考：꼭 / 부디<br>
  例：ぜひパーティーにおいでください。（请务必来参加聚会。）
- **線**（せん）线｜韩语参考：선（线） / 줄（线） / 라인（线，线条）<br>
  例：この線の終点はどこですか。（这条线的终点在哪里？）
- **ぜんぜん**（ぜんぜん）完全（不）｜韩语参考：전혀（부정과 함께）<br>
  例：私はビールはぜんぜん飲みません。（我完全不喝啤酒。）
- **戦争**（せんそう）战争｜韩语参考：전쟁（战争）<br>
  例：戦争が起こらなければいいと思う。（我希望不要发生战争。）
- **先輩**（せんぱい）前辈；学长｜韩语参考：선배（前辈）<br>
  例：彼は仕事の上では私の先輩だ。（在工作上他是我的前辈。）
- **そう**（そう）似乎；那样｜韩语参考：그렇게 / 그런 것 같다<br>
  例：まもなく雨が降りそうだ。（看样子马上就要下雨了。）
- **育てる**（そだてる）养育；培育｜韩语参考：기르다（养，养育，抚育） / 키우다（培育，培养）<br>
  例：クッキーはケイトによって育てられた。（库琪是凯特养大的。）
- **卒業**（そつぎょう）毕业｜韩语参考：졸업（毕业）<br>
  例：私はポップ・ミュージックはそろそろ卒業しようと思っているの。（我想我差不多该告别流行音乐了。）
- **祖父**（そふ）祖父；外祖父｜韩语参考：조부（祖父，外祖父）<br>
  例：祖父はステッキがないと歩けない。（祖父没有拐杖就走不了路。）
- **ソフト**（ソフト）柔软；温和｜韩语参考：부드럽다 / 온화하다<br>
  例：スミスさんはソフトな語り口の人物です。（史密斯先生说话语气温和。）
- **祖母**（そぼ）祖母；外祖母｜韩语参考：조모（祖母，外祖母）<br>
  例：私は祖母が大好きです。（我很爱我的祖母。）

## 语法

- **〜中**：正在…中；整个…；全…
  接续：名词 + 中（ちゅう／じゅう）
  朝鲜语：-중 / -내내（韩语 -중 对应 ちゅう（회의 중），-내내 对应 じゅう（하루 종일）；日语同一个汉字两种读法，韩语用不同词尾区分。）
- **〜つもり**：打算…；计划…
  接续：动词辞书形／动词ない形 + つもりだ
  朝鲜语：-(으)ㄹ 생각이다（韩语 -(으)ㄹ 생각이다 与 つもり 接近，但日语 つもり 可用于第二、三人称的确认；韩语 생각이다 多用于第一人称。）
