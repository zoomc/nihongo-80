# Day 024 · 〜と（and）、〜と（with）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜と（and）、〜と（with）」造两句自己的话，表达：…和…（全部列举）；和…一起

## 新词 19

- **誰**（だれ）谁｜韩语参考：누구（谁）<br>
  例：誰がこれをしたのかはわからない。（不知道这是谁干的。）
- **誕生日**（たんじょうび）生日｜韩语参考：생일（生日，生辰） / 생일날（生日，生日当天）<br>
  例：誕生日とは人が生まれた日のことだ。（生日就是人出生的那一天。）
- **だんだん**（だんだん）逐渐｜韩语参考：차차（渐渐，逐渐） / 차츰（渐渐，逐渐） / 차츰차츰（逐渐，渐渐）<br>
  例：日がだんだん長くなってきています。（白天渐渐变长了。）
- **小さな**（ちいさな）小的｜韩语参考：작은<br>
  例：小さなことでくよくよするな。（别为小事闷闷不乐。）
- **近い**（ちかい）近｜韩语参考：가깝다（近）<br>
  例：クリスマスが近くなってきた。（圣诞节快到了。）
- **違う**（ちがう）不同｜韩语参考：다르다（不同，不一致）<br>
  例：ライオンとヒョウの違いは何ですか。（狮子和豹有什么不同？）
- **近く**（ちかく）附近｜韩语参考：근처（附近，近处） / 부근（附近，周边） / 인근（邻近，附近）<br>
  例：７時近くだ。学校へ行かなくては。（快七点了，得去学校了。）
- **地下鉄**（ちかてつ）地铁｜韩语参考：지하철（地铁）<br>
  例：地下鉄で行きたいのです。（我想坐地铁去。）
- **茶色**（ちゃいろ）茶色；棕色｜韩语参考：갈색<br>
  例：その犬は茶色で小さくて、やせています。（那只狗是棕色的，又小又瘦。）
- **ちゃわん**（ちゃわん）碗｜韩语参考：밥그릇<br>
  例：この茶わんはなんとすばらしいのでしょう。（这个碗真不错啊。）
- **ちょうど**（ちょうど）正好｜韩语参考：꼭（正好，正合）<br>
  例：ちょうど食べたかったものでした。（那正是我想吃的。）
- **ちょっと**（ちょっと）一点；稍等｜韩语参考：조금 / 잠깐<br>
  例：ちょっと、そこのきみ！（喂，你站住！）
- **使う**（つかう）使用｜韩语参考：쓰다（用，使用） / 사용하다（使用，用，应用）<br>
  例：フラッシュを使ってもいいですか。（可以用闪光灯吗？）
- **疲れる**（つかれる）累｜韩语参考：피곤하다<br>
  例：とても疲れているように見えます。（你看起来很累。）
- **次**（つぎ）下一个｜韩语参考：담（下面，下一个） / 다음（下面，下一个）<br>
  例：次はいつ来ればいいのでしょうか。（下次什么时候来好呢？）
- **着く**（つく）到达｜韩语参考：닿다（到达，抵达） / 도달되다（到达，抵达，到） / 도달하다（到达）<br>
  例：シカゴに着いたらすぐ電話します。（一到芝加哥我就给你打电话。）
- **机**（つくえ）桌子｜韩语参考：책상<br>
  例：机の上にペンが一本もありません。（桌上连一支笔都没有。）
- **作る**（つくる）做｜韩语参考：짓다（做，造，建） / 만들다（制作，做，制造）<br>
  例：たまごを割らずにオムレツは作れない。（不打鸡蛋就做不成煎蛋卷。）
- **つける**（つける）打开（电器）｜韩语参考：켜다<br>
  例：テレビをつけて。（把电视打开。）

## 语法

- **〜と（and）**：…和…（全部列举）
  接续：名词 + と + 名词（全部列举）
  朝鲜语：와/과（韩语 와/과 与 と 对应，随收音换形；日语 と 还可表引用和共同对象，功能比韩语 와/과 更广。）
- **〜と（with）**：和…一起
  接续：名词（人）+ と（共同）
  朝鲜语：와/과 함께（韩语 와/과 可表共同，但口语更常用 하고；日语 と 后常可加 いっしょに，韩语 함께 的位置较固定。）
