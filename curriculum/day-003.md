# Day 003 · N も、これ / それ / あれ / どれ は N です

- 阶段：P0｜60 分钟｜常规日
- Can-do：用「N も、これ / それ / あれ / どれ は N です」各造一句自己的话，表达：…也…；这/那/那是…

## 新词 14

- **毎日**（まいにち）每天｜韩语参考：매일<br>
  例：毎日、学校へ行きます。（每天去学校。）
- **今週**（こんしゅう）本周｜韩语参考：금주（本周，这周，这星期）<br>
  例：今週は忙しいです。（这周很忙。）
- **月曜日**（げつようび）星期一｜韩语参考：월요일（星期一，周一，礼拜一）<br>
  例：月曜日に試験があります。（周一有考试。）
- **火曜日**（かようび）星期二｜韩语参考：화요일（星期二，周二，礼拜二）<br>
  例：火曜日に試験があります。（周二有考试。）
- **水曜日**（すいようび）星期三｜韩语参考：수（周三，星期三） / 수요일（星期三，周三，礼拜三）<br>
  例：水曜日は休みです。（周三休息。）
- **木曜日**（もくようび）星期四｜韩语参考：목요일（星期四，周四，礼拜四）<br>
  例：木曜日に映画を見ます。（周四看电影。）
- **金曜日**（きんようび）星期五｜韩语参考：금요일（星期五，周五，礼拜五）<br>
  例：金曜日は忙しいです。（周五很忙。）
- **土曜日**（どようび）星期六｜韩语参考：토（星期六，周六，礼拜六） / 토요일（星期六，周六，礼拜六）<br>
  例：土曜日に買い物します。（周六购物。）
- **日曜日**（にちようび）星期日｜韩语参考：일요일（星期日， 星期天，周日，礼拜天）<br>
  例：日曜日は休みです。（周日休息。）
- **家**（いえ）家；房子｜韩语参考：집（房子，窝，巢）<br>
  例：家に帰ります。（回家。）
- **学校**（がっこう）学校｜韩语参考：학교（学校） / 학원（学院，学校）<br>
  例：学校へ行きます。（去学校。）
- **会社**（かいしゃ）公司｜韩语参考：기업（企业，公司） / 회사（公司，企业，会社）<br>
  例：会社で働きます。（在公司工作。）
- **駅**（えき）车站｜韩语参考：역（기차역 등）<br>
  例：駅で電車に乗ります。（在车站上电车。）
- **店**（みせ）商店；店铺｜韩语参考：가게（店，店铺，商店） / 상점（商店） / 업소（小公司，营业所，店铺）<br>
  例：駅の前に店があります。（车站前有家店。）

## 语法

- **N も**：…也…
  接续：名詞 + も（替代 は/が/を）
  朝鲜语：도（韩语 도 和日语 も 都可表示追加，常替换主格或宾格助词；叠加其他助词须按具体语境判断。）
- **これ / それ / あれ / どれ は N です**：这/那/那是…
  接续：指示代名词 + は + 名詞 + です
  朝鲜语：이것 / 그것 / 저것 / 어느 것（韩语指示三分与日语相同，但修饰名词要用이/그/저且与것分写；日语可直接连体。）
