## 新词 19

- **会議室**（かいぎしつ）会议室｜韩语参考：회의실（会议室）<br>
  例：クラブの会員は会議室に集まった。（俱乐部成员在会议室集合了。）
- **会場**（かいじょう）会场｜韩语参考：회장（会场） / 대회장（大会场）<br>
  例：私たちは会場の後ろに座った。（我们坐在会场后面。）
- **会話**（かいわ）会话｜韩语参考：회화（会话）<br>
  例：その作家は会話を書くのがうまい。（那位作家很会写对话。）
- **帰り**（かえり）归途；回程｜韩语参考：돌아오는 길<br>
  例：どうして帰りがこんなに遅くなったの。（怎么回来得这么晚？）
- **科学**（かがく）科学｜韩语参考：과학（科学）<br>
  例：私は、ずっと科学を習っている。（我一直在学科学。）
- **鏡**（かがみ）镜子｜韩语参考：거울（镜子）<br>
  例：少女は立って鏡をのぞきこんだ。（少女站着照镜子。）
- **飾る**（かざる）装饰｜韩语参考：꾸미다（装饰，装扮） / 수식하다（修饰，装饰） / 장식하다（装饰，装扮，点缀）<br>
  例：その広間は日本画で飾られていた。（那个大厅用日本画装饰着。）
- **火事**（かじ）火灾｜韩语参考：불（火灾）<br>
  例：その火事はおととい発生した。（那场火灾发生在前天。）
- **ガス**（ガス）煤气；气体｜韩语参考：가스（气，气体）<br>
  例：料理の後でガスを止めました。（做完饭后关了煤气。）
- **ガソリン**（ガソリン）汽油｜韩语参考：가솔린（汽油） / 휘발유（汽油）<br>
  例：この車はあまりガソリンを食わない。（这辆车不太费油。）
- **ガソリンスタンド**（ガソリンスタンド）加油站｜韩语参考：주유소（加油站）<br>
  例：この辺にガソリンスタンドはありますか。（这附近有加油站吗？）
- **堅い**（かたい）硬｜韩语参考：단단하다<br>
  例：ダイヤモンドは本来堅いものだ。（钻石本来就很硬。）
- **形**（かたち）形状｜韩语参考：꼴（形，形状）<br>
  例：物質は温度によって形を変える。（物质会随温度改变形状。）
- **課長**（かちょう）科长｜韩语参考：과장（科长）<br>
  例：私は課長に任命された。（我被任命为科长。）
- **勝つ**（かつ）获胜｜韩语参考：이기다<br>
  例：この病気に勝てる人は少ない。（能战胜这种病的人很少。）
- **かっこう**（かっこう）样子；外表｜韩语参考：모습 / 차림<br>
  例：とても見られたかっこうじゃないよ。（这模样根本没法见人。）
- **家内**（かない）内人；妻子｜韩语参考：안（妻子，内人） / 처（妻子） / 아내（妻子，爱人，老婆）<br>
  例：家内は海外旅行中で、よく電話をかけてくる。（我妻子在国外旅行，常打电话来。）
- **必ず**（かならず）一定｜韩语参考：필시（一定，肯定，必定，无疑） / 필연（一定，肯定，必定，无疑） / 필히（一定要，必须）<br>
  例：あの歌は必ずヒットするよ。（那首歌一定会大热。）
- **壁**（かべ）墙壁｜韩语参考：벽（墙壁，墙壁） / 담벼락（墙壁）<br>
  例：壁はぬりかえなければなりませんか。（墙壁必须重新粉刷吗？）

## 语法

- **名詞/な形词干 + みたい(だ/な/に)**：好像…；像…一样（口语推量/比喻）
  接续：名詞 + みたい（不加 の）；な形 词干 + みたい；動詞/い形 普通形 + みたい；みたいな＋名／みたいに＋動
  朝鲜语：-(으)ㄴ 것 같다 / -처럼（韩语比喻和推测都用같다，口语最常用；日语みたい是ようだ口语版，韩语无正式口语两套。）
- **V ます形(去ます) + やすい / にくい**：容易…／难以…
  接续：動詞 ます形 去 ます + やすい・にくい；整体按 い形容詞 变形（読みやすくない／読みやすかった）
  朝鲜语：-기 쉽다 / -기 어렵다（韩语用기 쉽다/어렵다分析形，书面感强；日语やすい/にくい是一体化后缀，更口语。）
