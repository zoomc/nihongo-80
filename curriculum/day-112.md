# Day 112 · 〜ということだ、〜というのは

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜ということだ、〜というのは」造两句自己的话，表达：据说…；也就是说…；所谓…；是因为…

## 新词 25

- **適用**（てきよう）适用｜韩语参考：적용<br>
  例：この法律はすべての人に適用される。（这条法律适用于所有人。）
- **できれば**（できれば）如果可能的话｜韩语参考：가능하다면<br>
  例：出来れば明日までに帰ります。（可能的话，我明天之前回来。）
- **手品**（てじな）魔术；戏法｜韩语参考：마술（魔术） / 요술（妖术，魔术，妖法）<br>
  例：少年はたくさんの手品が使える。（那个少年会很多魔术。）
- **ですから**（ですから）所以｜韩语参考：그러므로<br>
  例：いいえ、結構です。お腹が一杯ですから。（不用了，谢谢。我已经吃饱了。）
- **鉄**（てつ）铁｜韩语参考：철（铁） / 쇠（铁）<br>
  例：鉄の原子番号は26です。（铁的原子序数是26。）
- **哲学**（てつがく）哲学｜韩语参考：철학（哲学）<br>
  例：哲学は難しいと見なされることが多い。（哲学常被认为是很难的。）
- **手伝い**（てつだい）帮忙；帮手｜韩语参考：도움 / 도우미<br>
  例：台所でお母さんの手伝いをしていたの。（我在厨房帮妈妈干活。）
- **徹底**（てってい）彻底｜韩语参考：철저（彻底，透彻，全面）<br>
  例：生産性はオートメーションの徹底によって向上する。（生产效率通过彻底自动化得到提高。）
- **鉄道**（てつどう）铁路｜韩语参考：철도（铁路，铁道） / 철로（铁路，铁道）<br>
  例：新しい鉄道はまだ完成していない。（新铁路还没有完工。）
- **徹夜**（てつや）通宵｜韩语参考：철야（彻夜，通宵，通宵达旦） / 밤샘（熬夜，通宵）<br>
  例：私はよく徹夜する。（我经常通宵。）
- **手間**（てま）工夫；劳力｜韩语参考：손（手，工夫） / 품（工，劲，工夫）<br>
  例：食べるのにどうしてそんなに手間がかかるのか。（吃个饭怎么这么费事？）
- **デモ**（デモ）游行；示威｜韩语参考：데모（示威，示威游行） / 시위（示威）<br>
  例：デモに参加しようと思う。（我想参加游行。）
- **典型**（てんけい）典型｜韩语参考：전형（典型）<br>
  例：彼女はあらゆる婦徳の典型である。（她是一切妇德的典范。）
- **天候**（てんこう）天气｜韩语参考：날（天气） / 날씨（天气） / 천기（天气；气象）<br>
  例：それはすべて天候に依存している。（那一切都取决于天气。）
- **電子**（でんし）电子｜韩语参考：전자（电子）<br>
  例：電子タイプライターはありますか。（有电子打字机吗？）
- **テント**（テント）帐篷｜韩语参考：천막（帐篷） / 텐트（帐篷）<br>
  例：私たちは暗くならないうちにテントを張った。（我们趁天还没黑搭起了帐篷。）
- **天然**（てんねん）天然｜韩语参考：천연（天然，自然） / 자연산（野生，天然）<br>
  例：この車は天然ガスで動く。（这辆车烧天然气。）
- **問い**（とい）问题；提问｜韩语参考：물음（提问，问题）<br>
  例：私はその問がたいへんやさしいことを発見した。（我发现那个问题很简单。）
- **党**（とう）党；派｜韩语参考：당（党）<br>
  例：彼女は根っからのコーヒー党です。（她是个地道的咖啡派。）
- **塔**（とう）塔；佛塔｜韩语参考：탑（塔）<br>
  例：家からその塔が見える。（从家里能看见那座塔。）
- **答案**（とうあん）答卷；答题纸｜韩语参考：답안（答案，答卷） / 답안지（答题卷，答卷，试卷）<br>
  例：時間です。答案を出して下さい。（时间到了。请把答卷交上来。）
- **同一**（どういつ）同一；相同｜韩语参考：동일（相同，同一，一致）<br>
  例：同一現象が観察された。（观察到了同一现象。）
- **どうか**（どうか）请；务必｜韩语参考：부디（千万，务必，切切）<br>
  例：どうか明朝６時に起こして下さい。（请明天早上6点叫醒我。）
- **当時**（とうじ）当时；那时｜韩语参考：당시（当时，那时）<br>
  例：その当時を回想すれば夢のようだ。（回想当年，恍如梦境。）
- **動詞**（どうし）动词｜韩语参考：동사（动词）<br>
  例：この動詞の変化を言えますか。（你能说出这个动词的活用吗？）

## 语法

- **〜ということだ**：据说…；也就是说…
  接续：普通形 + ということだ
  朝鲜语：-다는 것이다（韩语「-다는 것이다」与「ということだ」对应；但日语同一形式兼表传闻和“也就是说”，韩语要靠不同形式区分。）
- **〜というのは**：所谓…；是因为…
  接续：名词/句子 + というのは
  朝鲜语：-라는 것은（韩语「-라는 것은」表定义时与「というのは」对应；但日语还能在句末引出理由，韩语要用「왜냐하면」。）
