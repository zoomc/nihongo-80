今日语法 3 条

〜も〜ば〜も
발음〜모〜바〜모
既…又…；也…也…
名词 + も + ば形 + 名词 + も；名词 + も + い形容词ければ + 名词 + も
并举两个并存的事实，含“两者都有”的语气。
韩语对应-기도 하고 -기도 하다
韩语「-기도 하고 -기도 하다」只并列；日语「も〜ば〜も」用ば形连接，书面感更强，前半须是完整谓语。
카노조 와 우타 모 우타에바, 피아노 모 히쿠.
彼女は歌も歌えば、ピアノも弾く。
她既会唱歌，也会弹钢琴。
코노마치 니 와, 우미 모 아레바야마 모 아루.
この町には、海もあれば山もある。
这个镇子有海也有山。
진세이 니 와, 이이토키 모 아레바와루이토키 모 아루.
人生には、いいときもあれば悪いときもある。
人生既有好时候，也有坏时候。

易错点 彼女は歌も歌うば、ピアノも弾く。 → 歌も歌えば（前项必须用ば形「歌えば」，「歌うば」不合法。）

〜らしい（typical of）
발음〜라시이
像…样的；典型的…
名词 + らしい（らしくない 表“不像”）
表示某事物充分具备应有的特征，或“不愧为…”。
韩语对应-다운
韩语「-다운」同样表“符合其本色”；但日语「らしい」还有传闻用法，韩语传闻用「-라고 한다」，不会混淆。
쿄우 와 하루라시이아타타카이이치니치다따.
今日は春らしい暖かい一日だった。
今天是很有春意的一个暖和日子。
몬쿠 바카리 이우 난테, 키미라시쿠나이 네.
文句ばかり言うなんて、君らしくないね。
老是抱怨，真不像你。
もっと学生らしい服装で来てください。
请穿得更像个学生一点来。

易错点 もっと学生らしいの服装で来てください。 → 学生らしい服装（「らしい」直接修饰名词，不加「の」。）

〜っぽい
발음〜뽀이
有点…；容易…；带…色
名词/动词ます形词干/い形容词词干 + っぽい
口语中表“带有某种倾向或感觉”，多含轻微负面评价。
韩语对应…같다 / …기가 쉽다 / …빛이 돌다
子供っぽい 可译 아이 같다；忘れっぽい 是 자주 깜빡하다；白っぽい 是 희끄무레하다。っぽい 可表示印象、习性或近似色，需按前面的词理解。
코노후쿠 와 초또코도모뽀이카라, 베쓰노 니 시요우.
この服はちょっと子どもっぽいから、別のにしよう。
这件衣服有点孩子气，换一件吧。
最近忘れっぽくなって、困っている。
最近变得容易忘事，很苦恼。
あの白っぽいビルが、新しい市役所です。
那栋发白的楼就是新市政府。

易错点 この服はちょっと子どものっぽいから、別のにしよう。 → 子どもっぽい（「っぽい」直接接名词，不加「の」。）
