# Day 003 · これ / それ / あれ / どれ は N です、N の N

## 新词 25

- **会社**（かいしゃ）公司｜韩语参考：기업（企业，公司） / 회사（公司，企业，会社）<br>
  例：会社で働きます。（在公司工作。）
- **駅**（えき）车站｜韩语参考：역（기차역 등）<br>
  例：駅で電車に乗ります。（在车站上电车。）
- **店**（みせ）商店；店铺｜韩语参考：가게（店，店铺，商店） / 상점（商店） / 업소（小公司，营业所，店铺）<br>
  例：駅の前に店があります。（车站前有家店。）
- **病院**（びょういん）医院｜韩语参考：병원（医院）<br>
  例：病院に行きます。（去医院。）
- **図書館**（としょかん）图书馆｜韩语参考：도서관（图书馆）<br>
  例：図書館で本を読みます。（在图书馆读书。）
- **部屋**（へや）房间｜韩语参考：방（房间） / 집칸（房间）<br>
  例：部屋に猫がいます。（房间里有猫。）
- **上**（うえ）上面；上方｜韩语参考：위<br>
  例：机の上に本があります。（桌上有书。）
- **中**（なか）里面；中间｜韩语参考：속（里面，里头） / 안（里，里面） / 가운데（中间，正中，中央）<br>
  例：部屋の中にいます。（在房间里。）
- **前**（まえ）前面；之前｜韩语参考：앞（前，前面）<br>
  例：駅の前に店があります。（车站前有店。）
- **後**（あと）后面；之后｜韩语参考：담（之后） / 뒤（后，之后，后来） / 후（后，以后，之后）<br>
  例：授業の後で、図書館に行きます。（下课后，我去图书馆。）
- **ご飯**（ごはん）米饭；饭（餐）｜韩语参考：밥 / 식사<br>
  例：ご飯を食べます。（吃饭。）
- **朝ご飯**（あさごはん）早饭｜韩语参考：아침（早饭，早餐）<br>
  例：朝ご飯を食べます。（吃早饭。）
- **水**（みず）水（冷水／生水）｜韩语参考：물（水）<br>
  例：水を飲みます。（喝水。）
- **お茶**（おちゃ）茶｜韩语参考：차（茶，茶水）<br>
  例：お茶を飲みます。（喝茶。）
- **肉**（にく）肉｜韩语参考：살（肉） / 고기（肉）<br>
  例：肉を買います。（买肉。）
- **魚**（さかな）鱼｜韩语参考：물고기 / 생선（문맥에 따라）<br>
  例：魚が好きです。（喜欢鱼。）
- **野菜**（やさい）蔬菜｜韩语参考：야채（蔬菜） / 채소（菜，蔬菜）<br>
  例：野菜を買います。（买蔬菜。）
- **パン**（パン）面包｜韩语参考：빵（面包）<br>
  例：パンを食べます。（吃面包。）
- **料理**（りょうり）菜肴；烹饪｜韩语参考：요리（烹饪，烹调）<br>
  例：料理を作ります。（做菜。）
- **電車**（でんしゃ）电力驱动的列车；日常常泛指乘坐的普通列车｜韩语参考：전차（电车） / 전동차（电动车，电车）<br>
  例：電車で行きます。（坐电车去。）
- **バス**（バス）公交车｜韩语参考：버스（公共汽车，公交车）<br>
  例：バスに乗ります。（上公交。）
- **車**（くるま）汽车；车｜韩语参考：차（车，车辆） / 자동차（汽车）<br>
  例：車で会社へ行きます。（开车去公司。）
- **自転車**（じてんしゃ）自行车｜韩语参考：자전거（自行车）<br>
  例：自転車で学校へ行きます。（骑车去学校。）
- **飛行機**（ひこうき）飞机｜韩语参考：비행기（飞机）<br>
  例：飛行機で旅行します。（坐飞机旅行。）
- **父**（ちち）(我)父亲｜韩语参考：아버지（父亲，爸爸）<br>
  例：父は会社員です。（我父亲是公司职员。）

## 语法

- **これ / それ / あれ / どれ は N です**：这/那/那是…
  接续：指示代名词 + は + 名詞 + です
  朝鲜语：이것 / 그것 / 저것 / 어느 것（이것／그것／저것 可以单独作名词，对应 これ／それ／あれ。修饰名词时改用 이 책／그 책／저 책，对应 この本／その本／あの本；「哪本」是 どの本。）
- **N の N**：…的…；所属/修饰
  接续：名詞 + の + 名詞
  朝鲜语：N의 N（韩语의多表所属，口语常省略；修饰关系更常用名词直接并列，使用范围比日语の窄。）
