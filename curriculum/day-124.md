# Day 124 · 〜ないことはない、〜てしょうがない / 〜てしかたがない

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜ないことはない、〜てしょうがない / 〜てしかたがない」造两句自己的话，表达：并非不…；也不是不能…；…得不得了

## 新词 14

- **上等**（じょうとう）上等；高档｜韩语参考：고급 / 상등<br>
  例：どうしてこんな上等のぶどう酒を今まで取って置いたのか。（为什么把这么好的葡萄酒留到现在？）
- **衝突**（しょうとつ）冲突；碰撞｜韩语参考：충돌（冲突，碰撞，冲撞）<br>
  例：日米の利害がこの点で衝突した。（日美两国的利益在这一点上发生了冲突。）
- **商人**（しょうにん）商人｜韩语参考：장사꾼（商人，贩子，商贩）<br>
  例：商人は商品を売り買いする人だ。（商人是买卖商品的人。）
- **少年**（しょうねん）少年｜韩语参考：소년（少年，男孩）<br>
  例：少年は木に自分の名前を刻んだ。（少年把自己的名字刻在树上。）
- **商売**（しょうばい）生意；买卖｜韩语参考：장사（生意，经商）<br>
  例：彼は商売がうまくいったのを喜んだ。（他为生意顺利而高兴。）

  例：その車は多量の燃料を消費する。（那辆车消耗大量燃料。）
- **商品**（しょうひん）商品｜韩语参考：상품（商品） / 물건（商品，物品）<br>
  例：商人は商品を売り買いする人だ。（商人是买卖商品的人。）
- **消防**（しょうぼう）消防｜韩语参考：소방（消防）<br>
  例：彼が言うには、消防の仕事というのは大忙しか全く暇かのいずれかだそうだ。（据他说，消防工作不是忙得不可开交就是闲得没事。）
- **証明**（しょうめい）证明｜韩语参考：증명（证明）<br>

  例：婦人に開放されている職業は多い。（向女性开放的职业很多。）
- **食卓**（しょくたく）餐桌｜韩语参考：식탁（餐桌）<br>
  例：彼女は食卓に料理を並べた。（她把菜摆上了餐桌。）
- **食品**（しょくひん）食品｜韩语参考：식품（食品）<br>
  例：この食品は有毒である。（这种食品有毒。）

## 语法

- **〜ないことはない**：并非不…；也不是不能…
  接续：动词ない形/い形容词くない/ナ形容词でない + ことはない
  朝鲜语：-지 않은 것은 아니다（韩语「-지 않은 것은 아니다」与日语结构几乎一致；但日语常省略后半句留白，韩语一般要把话说完整。）
- **〜てしょうがない / 〜てしかたがない**：…得不得了
  接续：动词て形/い形容词くて/ナ形容词で + しょうがない（しかたがない）
  朝鲜语：-아서 견딜 수 없다（韩语「-아서 견딜 수 없다」偏“难以忍受”的强烈表达；日语「てしょうがない」也可用于轻微感受，程度可轻可重。）
