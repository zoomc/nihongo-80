## 新词 25

- **建てる**（たてる）建造｜韩语参考：짓다<br>
  例：この寺院は７８０年に建てられた。（这座寺院建于780年。）
- **立てる**（たてる）立起；发出｜韩语参考：세우다（立起，挺起）<br>
  例：図書館では物音を立ててはいけない。（在图书馆里不能弄出声响。）
- **例えば**（たとえば）例如｜韩语参考：예컨대（例如，比如） / 일테면（例如，比如） / 이를테면（例如，比如）<br>
  例：例えば、ロンドンは今は朝７時です。（比如，伦敦现在是早上7点。）
- **棚**（たな）架子；搁板｜韩语参考：선반（搁板）<br>
  例：その本はいちばん上の棚に置いてください。（请把那本书放在最上层的架子上。）
- **楽しみ**（たのしみ）期待；乐趣｜韩语参考：낙（乐，乐趣，快乐） / 즐거움（乐趣）<br>
  例：お便り楽しみにお待ちしております。（我期待着您的来信。）
- **楽しむ**（たのしむ）享受；欣赏｜韩语参考：즐기다（享受）<br>
  例：グレイ先生は仕事を楽しんでいませんでした。（格雷老师并不享受他的工作。）
- **たまに**（たまに）偶尔｜韩语参考：혹（偶尔） / 가끔（偶尔，有时，时而，间或） / 가다가（有时，偶尔）<br>
  例：たまには会いに来て下さい。（偶尔来看看我吧。）
- **ため**（ため）目的；缘故（〜ために 表示目的或原因）｜韩语参考：땜（因为，由于） / 때문（因为，由于）<br>
  例：忘れないように、そのためのメモを残した。（为了不忘记，我特意留了张便条。）
- **暖房**（だんぼう）暖气；取暖｜韩语参考：난방<br>
  例：お宅の暖房はどのようにしていますか。（您家的取暖是怎么弄的？）
- **血**（ち）血｜韩语参考：피（血，血液）<br>
  例：私たちは血がつながっている。（我们是有血缘关系的。）
- **チェックする**（チェックする）检查；核对｜韩语参考：체크하다（核对，核实，查对）<br>
  例：私は仕事を一つ終えるごとにリストの上でチェックする。（我每完成一项工作，就在清单上打勾。）
- **力**（ちから）力量；力气｜韩语参考：힘（力量，力气） / 파워（力量，势力，权威）<br>
  例：あなたは集中する力を失ってしまった。（你已经失去了集中注意力的能力。）
- **ちっとも**（ちっとも）一点也不｜韩语参考：조금도（부정과 함께）<br>
  例：最近エリザベスにちっともあってない。（最近完全没见到伊丽莎白。）
- **ちゃん**（ちゃん）小…（昵称）｜韩语参考：~짱（친근한 호칭）<br>
  例：あら、あなたのところの娘のはるちゃんはとても陽気ですね。（哎呀，你家女儿小春真开朗啊。）
- **注意**（ちゅうい）注意；提醒｜韩语参考：주의（注意，留意） / 주의하다（注意，留意）<br>
  例：彼に遅れないように注意した。（我提醒他别迟到。）
- **中学校**（ちゅうがっこう）初中｜韩语参考：중학교（初中）<br>
  例：この歌を聞くと私の中学校時代を思い出します。（听到这首歌就想起我的初中时代。）
- **注射**（ちゅうしゃ）打针；注射｜韩语参考：주사（注射）<br>
  例：注射をしましょう。（打一针吧。）
- **駐車場**（ちゅうしゃじょう）停车场｜韩语参考：주차장（停车场）<br>
  例：駐車場には人ひとり見えなかった。（停车场里一个人也看不见。）
- **地理**（ちり）地理｜韩语参考：지리（地理） / 지리학（地理学）<br>
  例：私はこの町の地理をよく知っている。（我很熟悉这个镇的地理。）
- **捕まえる**（つかまえる）抓住；逮住｜韩语参考：붙들다（抓住，逮住） / 붙잡다（抓住） / 포착하다（捕捉，抓住）<br>
  例：その男は少年の手をつかまえた。（那个男人抓住了男孩的手。）
- **月**（つき）月亮｜韩语参考：달<br>
  例：今夜は月がきれいです。（今晚的月亮很美。）
- **付く**（つく）附带；沾上｜韩语参考：묻다（沾上） / 붙다（附带，附加） / 달리다（附带，附加）<br>
  例：うちの車にはエアコンが付いている。（我们家的车装有空调。）
- **漬ける**（つける）浸泡；腌渍（食材等）｜韩语参考：재다（腌，喂） / 재우다（腌，喂） / 쟁이다（腌，喂）<br>
  例：きゅうりを塩に漬けます。（用盐腌黄瓜。）
- **都合**（つごう）方便；情况｜韩语参考：사정（处境，情况，原因，缘由）<br>
  例：何時がご都合よいでしょうか。（您几点方便？）
- **妻**（つま）妻子｜韩语参考：처（妻子） / 아내（妻子，爱人，老婆）<br>
  例：妻と一緒に旅行します。（和妻子一起旅行。）

## 语法

- **〜せる / 〜させる**：让…做；使…做
  接续：五段动词未然形+せる；一段动词未然形+させる；する→させる；来る→来させる
  朝鲜语：-게 하다（-게 하다 可先理解使役意思。日语要留意助词：让学生读课文用 学生に本を読ませる；「让孩子在外面玩」可说 子供を外で遊ばせる。）
- **〜せられる / 〜させられる**：被迫做…
  接续：五段词尾变あ段 + せられる（可缩为 される 的词很多，す结尾通常不缩）；一段去 る + させられる；する→させられる；来る→来させられる。
  朝鲜语：-도록 강요받다 / 억지로 …하게 되다（억지로 다시 쓰게 됐다 对照 書き直させられた。「書き直す」是 す 结尾，别按 読む→読まされる 的缩约方式造形。）
- **〜おう / 〜よう**：…吧；我要…
  接续：五段动词词尾改お段+う；一段动词去る+よう；する→しよう；来る→来よう
  朝鲜语：-자 / -(으)ㄹ게（韩语 -자 表提议，-(으)ㄹ게 表说话人意志；日语同一个意志形兼表两者，靠语境和语气区分。）
- **〜(よ)うと思う**：我想…；打算…
  接续：动词意志形 + と思う／と思っている
  朝鲜语：-(으)려고 하다（韩语 -(으)려고 하다 与 ようと思う 对应；但日语用「と思っている」可表持续的想法，韩语则靠现在时或 고 있다 区分。）
