## 新词 25

- **遅延**（ちえん）延误；晚点｜韩语参考：지연<br>
  例：電車に二十分の遅延が出ています。（电车晚点20分钟。）
- **運休**（うんきゅう）停运｜韩语参考：운휴（停运）<br>
  例：台風で電車が運休になりました。（台风导致电车停运。）
- **乗り換え**（のりかえ）换乘｜韩语参考：환승（换乘）<br>
  例：次の駅で乗り換えが必要です。（下一站需要换乘。）
- **到着**（とうちゃく）到达｜韩语参考：도착（到达）<br>
  例：電車は十時に到着します。（电车10点到达。）
- **出発**（しゅっぱつ）出发｜韩语参考：출발（出发）<br>
  例：バスは八時に出発します。（公交8点出发。）
- **混雑**（こんざつ）拥挤｜韩语参考：혼잡（混杂，纷杂，混乱，拥挤）<br>

- **経由**（けいゆ）经由；途经｜韩语参考：경유（经由，路过，途经） / 경유지（经由地，中转站） / 기착지（经由地，临时着陆地）<br>
  例：このバスは図書館を経由します。（这趟公交途经图书馆。）
- **運賃**（うんちん）车费；运费｜韩语参考：운임（运费） / 교통비（交通费，车费） / 운송료（运费，运输费）<br>
  例：運賃は二百円です。（车费200日元。）
- **経済**（けいざい）经济｜韩语参考：경제（经济）<br>
  例：経済のニュースを毎朝見ます。（每天早上看经济新闻。）
- **企業**（きぎょう）企业｜韩语参考：기업（企业，公司） / 업체（企业） / 기업체（企业，企业实体）<br>

- **物価**（ぶっか）物价｜韩语参考：물가（物价）<br>

  例：環境を守るために、ごみを減らします。（为保护环境减少垃圾。）
- **台風**（たいふう）台风｜韩语参考：태풍（台风）<br>
  例：台風で学校が休みになりました。（台风导致学校停课。）
- **避難**（ひなん）避难｜韩语参考：피난（避难，逃难，避乱） / 피란（避难，逃难，避乱）<br>
  例：地震のときは高い場所へ避難してください。（地震时请到高处避难。）
- **観光**（かんこう）观光；旅游｜韩语参考：관광（旅游，观光）<br>
  例：週末に京都へ観光に行きます。（周末去京都观光。）
- **伝統**（でんとう）传统｜韩语参考：전통（传统）<br>
  例：この町には古い伝統があります。（这个镇有古老传统。）
- **具体的**（ぐたいてき）具体的｜韩语参考：구체적（具体的，有形的）<br>
  例：具体的な例を教えてください。（请举具体例子。）
- **積極的**（せっきょくてき）积极的｜韩语参考：적극적（积极的）<br>
  例：彼は仕事に積極的です。（他对工作很积极。）
- **一般的**（いっぱんてき）一般的；普遍的｜韩语参考：일반적（一般的，普通的）<br>
  例：日本では、一般的にこの方法が使われます。（在日本，通常使用这种方法。）
- **定期的**（ていきてき）定期地；周期性的｜韩语参考：정기적으로<br>
  例：定期的に健康診断を受けています。（定期做健康检查。）
- **突然**（とつぜん）突然｜韩语参考：대뜸（马上，立即，突然） / 돌연（突然，突如其来，冷不防） / 돌연히（突然地，突如其来地，冷不防地，出乎意料地）<br>
  例：突然、雨が降り始めました。（突然开始下雨了。）
- **直ちに**（ただちに）立刻；立即｜韩语参考：곧장（马上，立即） / 금방（马上，立刻，立马） / 대뜸（马上，立即，突然）<br>
  例：危険を感じたら、直ちに避難してください。（感到危险请立即避难。）
- **次第に**（しだいに）逐渐｜韩语参考：차차（渐渐，逐渐） / 차츰（渐渐，逐渐） / 차츰차츰（逐渐，渐渐）<br>
  例：次第に日が長くなりました。（白天逐渐变长了。）
- **翌日**（よくじつ）次日；第二天｜韩语参考：뒷날（第二天） / 익일（翌日，明天，第二天） / 이튿날（第二天，翌日，次日）<br>
  例：注文した翌日に商品が届きました。（下单第二天商品就到了。）
- **途中**（とちゅう）途中；中途｜韩语参考：도중（途中，路上） / 중간（中途，中期）<br>
  例：駅へ行く途中で友達に会いました。（去车站的路上遇到了朋友。）

## 语法

- **Vて + いただけませんか / もらえませんか**：能否请您…（很礼貌的请求）
  接续：動詞 て形 + いただく（谦让）可能形 いただけませんか；或 もらう 可能形 もらえませんか
  朝鲜语：-아/어 주시겠어요?（韩语敬语请求用주시겠어요，比주세요客气；日语いただけませんか用否定疑问，韩语用肯定疑问加시겠。）
- **V辞書形 + ため(に) / 普通形・N の + ため(に)**：为了…（目的）／因为…、由于…（原因）
  接续：目的：意志动词 辞書形 + ため(に)；原因：普通形（多为 た形/ている/ない）或 名詞 + の + ため(に)
  朝鲜语：-기 위해(서) / -때문에（韩语目的用기 위해(서)，原因用때문에；日语ために两义同形，须靠后项判断。）
- **普通形 + のに（な形・名詞 は 〜な のに）**：明明…却…；…却（意外、不满、遗憾）
  接续：動詞・い形 普通形 + のに；な形・名詞 + な + のに；后项是与预期相反的结果
  朝鲜语：-는데도 / -(으)ㄴ데도（韩语逆接用는데도，带不满或意外；日语のに情绪更强，还能置于句末表遗憾。）
