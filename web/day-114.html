今日语法 2 条

韩语对应한 뒤에 / 하는 데에
韩语提示按整块理解。换成日语时先套接续「Verb-ta + 上で / 名词 + の + 上で / 动词辞书形 + 上で」，再看下面的例句。
〜上で
발음〜우에데
做完…后；在…过程中
Verb-ta + 上で / 名词 + の + 上で / 动词辞书形 + 上で
카조쿠토요쿠소우단시타우에데,오헨지이타시마스.
家族とよく相談した上で、お返事いたします。
I'll give you my answer after discussing it carefully with my family.
内容を確認した上で、契約書に署名してください。
Please sign the contract after checking its contents.
韩语对应한 이상
韩语提示按整块理解。换成日语时先套接续「动词普通形 / na-Adj + である / 名词 + である + 以上（は）」，再看下面的例句。
〜以上（は）
발음〜이조우
既然…就…
动词普通形 / na-Adj + である / 名词 + である + 以上（は）

引き受けた以上は、最後まで責任を持ってやり遂げるつもりだ。
Now that I've taken it on, I intend to see it through responsibly to the end.

As long as you're a professional, excuses aren't acceptable.
