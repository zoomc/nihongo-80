## 新词 14

- **代理**（だいり）代理；代理人｜韩语参考：대리（代理） / 서리（代理）<br>
  例：代理の方が来る場合は、委任状が必要です。（代理人来办时，需要委托书。）
- **家賃**（やちん）房租｜韩语参考：방세（房租） / 집세（房租）<br>
  例：家賃は毎月二十五日に払います。（房租每月25日支付。）
- **契約**（けいやく）合同；签约｜韩语参考：계약（合同，契约，合约）<br>
  例：来週、部屋の契約をします。（下周签房子的合同。）
- **退去**（たいきょ）搬出；退租｜韩语参考：퇴거<br>
  例：退去の一か月前に連絡してください。（请在搬出前一个月联系。）
- **引っ越し**（ひっこし）搬家｜韩语参考：이사<br>
  例：引っ越しの荷物をまとめています。（正在打包搬家的行李。）
- **不動産**（ふどうさん）房地产｜韩语参考：부동산（不动产，房地产）<br>
  例：不動産会社に部屋を紹介してもらいました。（请房产公司介绍了房子。）
- **敷金**（しききん）押金（房租押金）｜韩语参考：보증금<br>
  例：敷金は家賃の一か月分です。（押金是一个月房租。）
- **共益費**（きょうえきひ）公共区域费；物业公摊费｜韩语参考：공용 관리비<br>
  例：共益費は五千円です。（公共区域费是5000日元。）
- **設備**（せつび）设备；设施｜韩语参考：설비（设备）<br>
  例：この部屋には新しい設備があります。（这个房间有新设备。）
- **症状**（しょうじょう）症状｜韩语参考：증상（病情，症状） / 증후（症状）<br>
  例：症状が良くなりました。（症状好转了。）
- **診察**（しんさつ）诊察；看诊｜韩语参考：진찰（诊察）<br>
  例：午後から診察を受けます。（下午去看诊。）
- **処方**（しょほう）开处方｜韩语参考：처방（处方）<br>
  例：医者が薬を処方しました。（医生开了药。）
- **治療**（ちりょう）治疗｜韩语参考：치료<br>
  例：治療は一週間かかります。（治疗需要一周。）
- **予防**（よぼう）预防｜韩语参考：예방（预防）<br>
  例：風邪の予防に手を洗います。（为预防感冒洗手。）

## 语法

- **N / Vた形 / V辞書形 / Vて + ばかり**：刚…；净是…、只…；一味…
  接续：名詞 + ばかり；動詞 た形 + ばかり（刚做完）；辞書形 + ばかり（只等/只剩）；て形 + ばかり いる（光顾着做）
  朝鲜语：방금 / -만 / -기만 하다（韩语「刚」用방금、「只」用만、「一味」用기만 하다，三义分用；日语ばかり一形靠语境。）
- **V辞書形/Vている/Vた形 + ところ(だ/に/を/で)**：正要…／正在…／刚…；在…时候；…之际
  接续：辞書形 + ところだ（正要）；ている + ところだ（正在）；た形 + ところだ（刚做完）；ところに/を/で 后接外部动作或发现
  朝鲜语：-(으)려고 하다 / -고 있다 / -(으)ㄴ 참이다（韩语正要려고 하다、正在고 있다、刚ㄴ 참이다；日语ところだ按だ/に/を/で四形变化。）
