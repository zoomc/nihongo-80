# 100 天怎么学

打开首页点「开始或继续学习」。Day 001 保留原课，Day 002–100 每天 25 个新词。Day 1–26 为 N5，Day 27–50 为 N4，Day 51–100 为 N3，后段加入 10 条 N2 衔接语法。

1. 点「记忆曲线复习」里的「到期复习」，用单选更新当前浏览器的排期。
2. 学当天新词和语法，按需要用遮盖开关自查。
3. 做当天单选。每词两题、每条语法三题，答完可集中重练错题。
4. 点「完成」保存当天的云端自报记录。会话用 `python3 scripts/today.py` 查进度和 SQLite 到期卡。

[选学词库](../web/optional-vocab.html)收录主课之外的 211 个词。[原创听读资料](../web/library.html)和[真人听力](../web/listening.html)是独立资源入口。
