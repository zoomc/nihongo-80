# Day 130 · 〜場合（は）

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜場合（は）」造两句自己的话，表达：在…情况下

## 新词 20

- **袖**（そで）袖子｜韩语参考：소매（袖子） / 옷소매（衣袖，袖子） / 팔소매（衣袖，袖子）<br>
  例：父は袖に長い裂け目を作った。（父亲在袖子上划了一道长口子。）
- **備える**（そなえる）具备；准备｜韩语参考：갖추다（具备，备好） / 차리다（具备，讲究） / 예비하다（准备，预备）<br>
  例：このビルは非常階段を備えている。（这栋楼配有紧急楼梯。）
- **そのうち**（そのうち）不久；改天｜韩语参考：머지않아 / 다음에<br>
  例：そのうち一緒に仕事ができるといいなと思っています。（我想，希望不久能一起工作。）
- **そのまま**（そのまま）原样；就那样｜韩语参考：그냥（就那样） / 고대로（就那样，照旧） / 그대로（原原本本地，原封不动地，如实地，照原样）<br>
  例：ドアをそのままにしておいてはいけません。（不能就让门那样开着。）
- **ソファー**（ソファー）沙发｜韩语参考：소파（沙发）<br>
  例：少年はソファーに横になっていた。（少年躺在沙发上。）
- **粗末**（そまつ）粗糙；简慢｜韩语参考：허술하다 / 소홀하다<br>
  例：道具を粗末に使うな。（别把工具胡乱使。）
- **それぞれ**（それぞれ）各自；分别｜韩语参考：각각（各自，分别） / 각개（各个，各自） / 각기（各自）<br>
  例：人にはそれぞれ向き不向きがある。（人各有各的擅长和不擅长。）
- **それと**（それと）另外；还有｜韩语参考：그리고 / 또<br>
  例：それと俺がホモだとしたら、罪になるわけ？（还有，如果我是同性恋，就成罪了吗？）
- **損**（そん）亏损；吃亏｜韩语参考：손해<br>
  例：高望みをするとかえって損をする。（期望过高反而会吃亏。）
- **損害**（そんがい）损害；损失｜韩语参考：손해（损失）<br>
  例：その暴風雨は大損害をもたらした。（那场暴风雨带来了巨大损失。）
- **尊敬**（そんけい）尊敬｜韩语参考：존대（尊敬，恭敬，敬重）<br>
  例：あなたはだれからも尊敬されている。（你受到所有人的尊敬。）
- **存在**（そんざい）存在｜韩语参考：존재（存在）<br>
  例：神は存在すると思いますか。（你认为神存在吗？）
- **尊重**（そんちょう）尊重｜韩语参考：존중（尊重）<br>
  例：私は君の判断を尊重する。（我尊重你的判断。）
- **他**（た）其他；别的｜韩语参考：다른 / 그 밖의<br>
  例：彼女は彼を他の誰かとまちがえた。（她把他错认成了别人。）
- **田**（た）田地｜韩语参考：논 / 밭<br>
  例：彼女は田んぼの方に進んだ。（她朝稻田那边走去。）
- **対**（たい）对；比｜韩语参考：대（对）<br>
  例：試合は6対6で引き分けに終わった。（比赛以6比6打成平局。）
- **台**（だい）台；架子｜韩语参考：대（台） / 채（辆，台）<br>
  例：この台の上に花瓶を置いてはいけません。（不要在这个台子上放花瓶。）
- **大**（だい）大｜韩语参考：대（大）<br>
  例：彼女はハーバード大に入学した。（她考进了哈佛大学。）
- **題**（だい）题目；标题｜韩语参考：제목 / 문제<br>
  例：「友情」という題で作文を書きなさい。（请以《友情》为题写一篇作文。）
- **体育**（たいいく）体育｜韩语参考：체육（体育）<br>
  例：体育は必修科目ですか。（体育是必修科目吗？）

## 语法

- **〜場合（は）**：在…情况下
  接续：动词普通形/い形容词/ナ形容词な/名词の + 場合（は）
  朝鲜语：-는 경우（韩语「-는 경우」与「場合」对应；但日语「場合」偏书面、用于预设应对，日常口语多用「たら」。）
