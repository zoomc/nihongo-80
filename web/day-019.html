Day 019 · 〜や、〜も、〜の（possessive）

语法 3 条

〜や
발음〜야
…和…等（部分列举）
名词 + や + 名词（部分列举）
列举若干代表性事物，暗示还有其他，常与「など」呼应。
韩语对应나/이나
책이나 잡지 같은 것 对照 本や雑誌など，表示举些例子；要表达「书或杂志中选一个」，韩语还可用 이나，日语换成 本か雑誌。
쓰쿠에 노 우에 니 혼 야 자씨 가 아리마스.
机の上に本や雑誌があります。
桌子上有书、杂志等。
스파아 데 니쿠 야 야사이 오 카이마시타.
スーパーで肉や野菜を買いました。
我在超市买了肉、蔬菜等。
易错易混点
  • ✗ 机の上に本や雑誌とがあります。✓ 机の上に本や雑誌などがあります。部分列举不用 と 收尾，可用「など」
〜も
발음〜모
也…；（否定）也不…
名词 + も
表示同类追加，否定句中与前后 も 呼应表示「既不…也不…」。
韩语对应도
韩语 도 与 も 对应，且同样可叠用于否定并列（고기도 생선도）；日语 も 可顶替 は／が／を，韩语 도 也顶替主宾格助词。
와타시 모 가쿠세이데스.
私も学生です。
我也是学生。
아니 와 사까아 모 스키데스.
兄はサッカーも好きです。
哥哥也喜欢足球。
니쿠 모 사카나 모 타베마센.
肉も魚も食べません。
我既不吃肉也不吃鱼。
易错易混点
  • ✗ 私もは学生です。✓ 私も学生です。も 已含提示作用，不能与 は 叠用
〜の（possessive）
발음〜노
…的…
名词 + の + 名词
表示所属、属性、材料或同位关系，修饰名词时用 の。
韩语对应의
韩语 의 与 の 对应，但口语中 의 常省略；日语 の 不能省略，且还可代替名词（私の）。
코레 와 와타시 노 카사데스.
これは私のかさです。
这是我的伞。
니혼고 노 센세이 와 토테모야사시이데스.
日本語の先生はとてもやさしいです。
日语老师非常温柔。
에키 노 치카쿠 니 아타라시이미세 가 아리마스.
駅の近くに新しい店があります。
车站附近有一家新店。
易错易混点
  • ✗ これは私がかさです。✓ これは私のかさです。所属关系用 の，が 会变成主语标记
