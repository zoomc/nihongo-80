今日语法 3 条

韩语对应-도록 하다
韩语 -도록 하다 可表努力或指示；日语ようにする可用于自己的安排，也可用于要求他人注意。
V辞書形 / Vない形 + ように する
努力做到…／设法不…（有意识地做）
動詞 辞書形／ない形 + ように + する；する 按 サ変 变形（ようにしています／ようにした）
ようにする 表有意识地努力或安排；ようになる 常侧重变化结果，但变化也可能来自努力。
毎日野菜を食べるようにしています。
我尽量每天吃蔬菜。
네루마에니스마호오미나이요우니시테이마스.
寝る前にスマホを見ないようにしています。
睡前尽量不看手机。
易错点

毎日走るようになりました。 → 毎日走るようにしています。（想表达「我坚持每天跑步」应用 ようにする（意志努力）；ようになる 是自然变化，中文「坚持」直译易混）

韩语对应-기로 하다 / -게 되다
韩语自己决定用기로 하다，外部决定或结果用게 되다；与日语ことにする/なる对应整齐。
V辞書形/Vない形 + ことに する / なる
（自己）决定…／（结果）定为…、将要…
動詞 普通形 + ことに + する（主观决定）/ なる（客观决定、自然结果）；する・なる 可变形
ことにする 侧重决定，ことになる 侧重结果或安排；后者也可用于共同决定或自己的决定以客观方式叙述。
킨엔스루코토니시마시타.
禁煙することにしました。
我决定戒烟了。
来月から転勤することになりました。
定下下个月起调职了。
易错点

禁煙することになりました。（自己决定时） → 禁煙することにしました。（自己下的决定用 ことにする；ことになる 是外部/客观决定，中文「我决定」直译易错）

韩语对应-곤 하다 / -기도 하다
韩语곤 하다表过去反复习惯，기도 하다表有时；日语ことがある现在形表偶尔，时态限制不同。
V辞書形 / Vない形 + ことが ある
有时会…／有时不…（泛指倾向）
動詞 辞書形／ない形 + ことが ある；ある 可变形（ことがあります／あった）
表示偶尔发生、有时会那样；与 〜たことがある（G0042，曾经做过）时态语义都不同
이소가시쿠테,히루고한오와스레루코토가아리마스.
忙しくて、昼ご飯を忘れることがあります。
忙起来有时会忘了吃午饭。
카레와타마니치코쿠스루코토가아리마스.
彼はたまに遅刻することがあります。
他偶尔会迟到。
易错点

北海道へ行くことがあるです。 → 北海道へ行くことがあります。（「ことがある」结句接礼貌体应为「ことがあります」，「あるです」不合法；另「〜たことがある」表曾经做过（见 compare G0042），与表「有时会」的辞书形「〜ことがある」语义不同。）
