今日语法 2 条

韩语对应을 제외하고
韩语提示按整块理解。换成日语时先套接续「名词 + を除いて / 名词 + を除き / 名词 + を除く + 名词」，再看下面的例句。
〜を除いて
발음〜오노조이테
除…之外
名词 + を除いて / 名词 + を除き / 名词 + を除く + 名词
年末年始を除いて、図書館は毎日開いている。
The library is open every day except during the New Year holidays.
一部の地域を除き、明日は全国的に晴れるでしょう。
Except for some areas, it will be sunny nationwide tomorrow.
韩语对应인 것처럼
韩语提示按整块理解。换成日语时先套接续「动词普通形 / i-Adj + かのようだ / na-Adj + である + かのようだ / 名词 + である + かのようだ」，再看下面的例句。
〜かのようだ
발음〜카노요우다
仿佛…似的
动词普通形 / i-Adj + かのようだ / na-Adj + である + かのようだ / 名词 + である + かのようだ
彼はまるで何も知らないかのような顔をしていた。
He wore a look as if he knew nothing at all.
三月なのに、真冬に戻ったかのような寒さだ。
It's March, yet it's so cold it feels as if we'd gone back to midwinter.
