## 新词 25

- **写す**（うつす）抄写；拍照｜韩语参考：베끼다 / 촬영하다<br>
  例：その写真は空から写されたものである。（那张照片是从空中拍的。）
- **移る**（うつる）迁移；转移｜韩语参考：옮겨지다 / 옮다<br>
  例：もっとお金があれば大きな家に移れるのにな。（要是有更多钱，就能搬到更大的房子了。）
- **腕**（うで）胳膊；本事｜韩语参考：팔（臂，胳膊） / 팔뚝（小臂，小胳膊）<br>
  例：けがをした腕を見せて下さい。（请让我看看受伤的胳膊。）
- **うまい**（うまい）好吃；擅长｜韩语参考：맛있다 / 능숙하다<br>
  例：それはあまりにもうますぎる話だ。（这话也太美了，不像是真的。）
- **裏**（うら）背面；里面｜韩语参考：뒷면（后面，背面，反面）<br>
  例：靴の裏にガムがこびりついちゃった。（鞋底粘上了口香糖。）
- **売り場**（うりば）卖场；柜台｜韩语参考：매장 / 판매 코너<br>
  例：スナック売り場は、どこですか。（零食区在哪儿？）
- **うれしい**（うれしい）高兴；开心｜韩语参考：기쁘다<br>
  例：あなたに再会できてうれしい。（能再见到你我很高兴。）
- **うん**（うん）嗯；对｜韩语参考：음（嗯） / 으응（啊，嗯）<br>
  例：うん、休みが終わるまででいいの。（嗯，到假期结束就行。）
- **運転手**（うんてんしゅ）司机｜韩语参考：운전수（司机） / 기사（司机，驾驶员，操作员） / 운전사（驾驶员，司机）<br>
  例：運転手は車のスピードを上げた。（司机提高了车速。）
- **運動**（うんどう）运动；锻炼｜韩语参考：운동（运动）<br>
  例：週に一度でいいから運動しなさい。（一周一次也行，要运动。）
- **エスカレーター**（エスカレーター）自动扶梯｜韩语参考：에스컬레이터（扶梯）<br>
  例：上りのエスカレーターはどこですか？（上行的自动扶梯在哪里？）
- **枝**（えだ）树枝｜韩语参考：가지（树枝，枝） / 나뭇가지（树枝）<br>
  例：たくさんの鳥が枝にとまっている。（许多鸟停在树枝上。）
- **選ぶ**（えらぶ）选择｜韩语参考：택하다（选择） / 선택하다（选，选择）<br>
  例：これとあれの中から選んで下さい。（请从这和那里面选一个。）
- **おいでになる**（おいでになる）来；在（敬）｜韩语参考：오시다 / 계시다（높임）<br>
  例：いつ旅行においでになりますか。（您什么时候去旅行？）
- **お祝い**（おいわい）祝贺｜韩语参考：축하<br>
  例：心からお祝いを申し上げます。（衷心向您表示祝贺。）
- **オートバイ**（オートバイ）摩托车｜韩语参考：오토바이（摩托车）<br>
  例：オートバイに乗るのは楽しい。（骑摩托车很开心。）
- **おかげ**（おかげ）多亏；托福｜韩语参考：덕분<br>
  例：私が今日あるのは両親のおかげである。（我今天的成就多亏了父母。）
- **おかしい**（おかしい）奇怪；可笑｜韩语参考：우습다（可笑） / 이상하다（奇怪，古怪） / 이상스럽다（奇怪，古怪，可疑，怪异）<br>
  例：君のジョークは何度聞いてもおかしい。（你的笑话听多少次都好笑。）
- **お金持ち**（おかねもち）有钱人｜韩语参考：부자<br>
  例：どうしたらお金持ちになれるのかしら？（怎样才能变成有钱人呢？）
- **億**（おく）亿｜韩语参考：억（亿）<br>
  例：１０億人の人たちが英語を話しています。（有十亿人在说英语。）
- **屋上**（おくじょう）楼顶；屋顶｜韩语参考：옥상（屋顶，房顶，屋顶平台）<br>
  例：デパートの屋上にアドバルーンが上がっている。（百货商店的楼顶升起了广告气球。）
- **贈り物**（おくりもの）礼物｜韩语参考：선물（礼物）<br>
  例：ジェニーは贈り物をありがとうと言った。（珍妮说了声谢谢你的礼物。）
- **送る**（おくる）寄；送｜韩语参考：던지다（发，送，投） / 보내다（送，寄） / 부치다（寄，汇，邮）<br>
  例：この手紙を日本に送ってくれませんか。（能帮我把这封信寄到日本吗？）
- **起す**（おこす）扶起；唤醒｜韩语参考：일으키다（扶起）<br>
  例：病気の子供はベッドの上で体を起こした。（生病的孩子在床上坐了起来。）
- **行う**（おこなう）做；举行｜韩语参考：지내다（办，举行）<br>
  例：いう事と行う事はまったく別だ。（说的和做的完全是两回事。）

## 语法

- **受身形（～られる）**：被…／（迷惑）遭遇…
  接续：五段 う段→あ段+れる；一段 去る+られる；カ変 来られる；サ変 される
  朝鲜语：-이/히/리/기 피동（韩语可用被动词尾、被动词或其他构式表达被动；遇到不愉快的事也可改述，日语有雨に降られる等受害被动。）
- **使役形（～せる／させる）**：让／使…（做）
  接续：五段 う段→あ段+せる；一段 去る+させる；カ変 来させる；サ変 させる
  朝鲜语：-게 하다 / -시키다（韩语使役用게 하다或시키다，不区分自动他动的을/에게；日语せる/させる须分を/に。）
- **～てみる / ～てしまう / ～ておく**：试着…／…完了／事先…
  接续：動詞て形 + みる／しまう／おく
  朝鲜语：-아/어 보다 / -아·어 버리다 / -아·어 두다（韩语分别用보다(尝试)、버리다(完了/遗憾)、두다(预先)，与日语三形基本对应。）
