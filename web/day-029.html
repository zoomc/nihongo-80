今日语法 3 条

～たことが ある
발음～타코토가 아루
（曾经）做过…
動詞た形 + ことが + ある
表过去经验；与单纯过去 〜ました 不同，强调「有过这种经历」
코노혼오욘다코토가아리마스.
この本を読んだことがあります。
读过这本书。
朝鲜语：-(으)ㄴ 적이 있다
韩语经验用ㄴ 적이 있다，否定ㄴ 적이 없다；与单纯过去았/었的区分同日语。
易错点

京都に行くたことがあります。 → 京都に行ったことがあります。（表达经历用动词た形接ことがある。）

～そうです（样态／传闻）
발음～소우데스
看起来…／听说…
样态：ます形词干/い形去い/な形词干 + そう；传闻：普通形 + そうです
样态表肉眼推断，传闻表转述；两者接续不同，意义完全不同
아메가오리소우데스.
雨が降りそうです。
看起来要下雨。
아시타와아메다소우데스.
明日は雨だそうです。
听说明天有雨。
朝鲜语：-아/어 보이다 / -다고 하다
韩语样态用아/어 보이다，传闻用다고 하다，形态完全不同；日语そうだ须按接续分辨。
易错点

おいしいそうです（想表样态） → おいしそうです。（い形容词样态是 おいしそう（去 い）；おいしいそう 是传闻「听说好吃」）

～ようだ / ～らしい
발음～요우다 / ～라시이
好像…／似乎…（推测）
普通形 + ようだ／らしい（名 + の + ようだ）
ようだ 偏主观直感，らしい 偏传闻/典型特征；名词接 ようだ 要加 の
카레와이소가시이요우데스.
彼は忙しいようです。
他好像很忙。
아시타와아메라시이데스.
明日は雨らしいです。
明天好像有雨。
朝鲜语：-(으)ㄴ 것 같다 / -(으)ㄴ 모양이다
韩语推测最常用것 같다，传闻典型用다고 하다；日语ようだ主观、らしい客观传闻。
易错点

雨ようです。 → 雨のようです。（名词接 ようだ 要加 の：雨のようです）
