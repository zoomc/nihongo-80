# Day 042 · 〜ても / 〜でも、〜のに（although）、〜のに（purpose）、〜ので

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ても / 〜でも**：即使…也…
  接续：动词て形+も；い形容词去い+くても；な形容词・名词+でも
  朝鲜语：-아/어도（贵也买可说 비싸도 산다／高くても買う。名词「即便周末」则是 주말이어도／週末でも，韩语名词前后也有自己的接续。）
- **〜のに（although）**：明明…却…
  接续：动词普通形／い形容词 + のに；な形容词+な／名词+な + のに
  朝鲜语：-는데도（늦었는데도 안 졸리다 对照 遅いのに眠くない。日语把 のに 留在句末时可表达遗憾；韩语会用 …는데、…는데도! 等省略后文，语气看场合。）
- **〜のに（purpose）**：用于…；做…需要
  接续：动词辞书形 + のに（用途・所需）；名词 + に
  朝鲜语：-는 데（韩语 -는 데 与用途、所需的 のに 对应（걷는 데 20분 걸린다）；日语 のに 与转折的 のに 同形，韩语则用 데 区分。）
- **〜ので**：因为…；由于…
  接续：动词普通形／い形容词 + ので；な形容词+な／名词+な + ので
  朝鲜语：-아서/어서（韩语 -아서/어서 与 ので 都表客观原因，但日语 ので 可接意志、请求，韩语 -아서/어서 后项一般不能是命令、劝诱。）
