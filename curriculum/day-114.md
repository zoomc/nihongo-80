# Day 114 · 〜さえ、〜さえ〜ば

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜さえ、〜さえ〜ば」造两句自己的话，表达：连…都…；只要…就…

## 新词 20

- **覚める**（さめる）醒｜韩语参考：깨어나다<br>
  例：その音で彼女は眠りから覚めた。（那声音把她从睡梦中吵醒了。）
- **左右**（さゆう）左右｜韩语参考：좌우（左右）<br>
  例：彼は怒って首を左右に振った。（他生气地左右摇头。）
- **皿**（さら）盘子｜韩语参考：접시<br>
  例：彼女はテーブルの上に皿を置いた。（她把盘子放在桌上。）
- **更に**（さらに）更加；进一步｜韩语参考：더욱（更加，进一步，越来越，愈加） / 일층（更加，进一步） / 한층（更加，进一步）<br>
  例：その小説は彼の名声を更に高めた。（那部小说使他的名声更高了。）
- **猿**（さる）猴子｜韩语参考：원숭이（猴，猴子）<br>
  例：彼は猿のように木によじ登った。（他像猴子一样爬上了树。）
- **去る**（さる）离开；逝去｜韩语参考：뜨다（离开） / 떠나다（离开，离去） / 떠나오다（离开）<br>
  例：古き良き時代は去って、二度ともどってこない。（美好的旧时光已经逝去，再也不会回来。）
- **騒ぎ**（さわぎ）骚动；吵闹｜韩语参考：소동（骚动，动乱） / 소란（嘈杂，吵闹）<br>
  例：この騒ぎはどうしたの。（这么吵是怎么回事？）
- **参加**（さんか）参加｜韩语参考：참가（参加，参与） / 가담（参与，参加，加入）<br>
  例：あなたは競技に参加しましたか。（你参加比赛了吗？）
- **参考**（さんこう）参考｜韩语参考：참고（参考，参照，参酌）<br>
  例：参考のためにカタログをお送りください。（请寄一份目录供参考。）
- **賛成**（さんせい）赞成｜韩语参考：찬성（赞成，赞同）<br>
  例：私たちの計画に賛成してくれますか。（你赞成我们的计划吗？）
- **酸素**（さんそ）氧气｜韩语参考：산소（氧，氧气）<br>
  例：酸素が無ければ生きられない。（没有氧气就无法生存。）
- **氏**（し）氏；先生｜韩语参考：씨 / 성씨<br>
  例：亡くなったスミス氏は医者でした。（已故的史密斯先生是医生。）
- **詩**（し）诗｜韩语参考：시（诗）<br>
  例：この詩は誰が書いたのですか。（这首诗是谁写的？）
- **幸せ**（しあわせ）幸福｜韩语参考：행복（幸福）<br>
  例：金持ちが幸せとは限らない。（有钱人不一定幸福。）
- **ジーンズ**（ジーンズ）牛仔裤｜韩语参考：청바지（牛仔裤）<br>
  例：私は日曜日はたいていジーンズをはいている。（我星期天大多穿牛仔裤。）
- **ジェット機**（ジェットき）喷气式飞机｜韩语参考：제트기（喷气式飞机）<br>
  例：ジェット機は東京に着陸した。（喷气式飞机在东京降落了。）
- **直に**（じかに）直接｜韩语参考：직접<br>
  例：あなたとじかに会ってじっくり話したいことがあるのです。（我有事想跟你当面好好谈谈。）
- **しかも**（しかも）而且；并且｜韩语参考：게다가<br>
  例：彼は音もなくしかもすばやく動ける。（他能又无声又迅速地移动。）
- **叱る**（しかる）责备；训斥｜韩语参考：책하다（责备，训斥，斥责） / 혼내다（训斥，呵斥） / 꾸중하다（责骂，训斥）<br>
  例：ママに叱られますよ。（会被妈妈骂的哦。）
- **式**（しき）仪式；公式｜韩语参考：식（仪式）<br>
  例：彼は事故でその式に出席できなかった。（他因事故没能出席那个仪式。）

## 语法

- **〜さえ**：连…都…
  接续：名词 + さえ／でさえ／にさえ
  朝鲜语：-조차（韩语「-조차」多与否定呼应，这点与「さえ」相近；但日语「さえ」还能构成「さえ〜ば」条件句，韩语要用「-기만 하면」。）
- **〜さえ〜ば**：只要…就…
  接续：名词 + さえ + ば形；动词ます形词干 + さえ + すれば；动词て形 + さえ + いれば
  朝鲜语：-기만 하면（韩语「-기만 하면」与「さえ〜ば」对应；但日语「さえ」位置固定在各成分后，韩语统一贴在动词后，语序处理不同。）
