# Day 036 · ～ことが できる、～たことが ある

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～ことが できる、～たことが ある」造两句自己的话，表达：会／能…（可能迂说）；（曾经）做过…

## 新词 19

- **来週**（らいしゅう）下周｜韩语参考：내주（下周，下星期）<br>
  例：来週ヨーロッパへ行くつもりなんです。（我打算下周去欧洲。）
- **来年**（らいねん）明年｜韩语参考：내년（明年，来年） / 명년（明年）<br>
  例：あなたは来年この本を読むことが出来るでしょう。（你明年应该就能读这本书了。）
- **ラジオ**（ラジオ）收音机；广播｜韩语参考：라디오（电台广播）<br>
  例：そのニュースはラジオで聞いたよ。（那消息我是从收音机里听到的。）
- **ラジカセ**（ラジカセ）收录机｜韩语参考：라디오 카세트<br>
  例：確かに今の日本では、「ラジカセ」はもう古い言葉なのかもしれない。（确实，在今天的日本，「ラジカセ」也许已经是个过时的说法了。）
- **りっぱ**（りっぱ）出色；气派｜韩语参考：훌륭하다<br>
  例：どうもごりっぱな言いわけだよ。（这借口可真是冠冕堂皇。）
- **留学生**（りゅうがくせい）留学生｜韩语参考：유학생（留学生）<br>
  例：留学生も入れるのかしら。（留学生也能加入吗？）
- **両親**（りょうしん）父母；双亲｜韩语参考：부모（父母） / 양친（双亲） / 어버이（父母）<br>
  例：両親は二人ともまだ生きています。（父母双亲都还健在。）
- **零**（れい）零｜韩语参考：공（零） / 영（零） / 제로（零）<br>
  例：今朝の気温は零度でした。（今天早晨气温是零度。）
- **冷蔵庫**（れいぞうこ）冰箱｜韩语参考：냉장고（冰箱）<br>
  例：冷蔵庫の中にバターが２ポンドある。（冰箱里有两磅黄油。）
- **レコード**（レコード）唱片｜韩语参考：디스크（唱片） / 레코드（唱片） / 레코드판（唱片）<br>
  例：ステレオにレコードをかけてください。（请给音响放上唱片。）
- **レストラン**（レストラン）餐厅｜韩语参考：식당（饭店，餐厅） / 레스토랑（西餐厅）<br>
  例：あのレストランはサービスがよい。（那家餐厅服务很好。）
- **廊下**（ろうか）走廊｜韩语参考：복도（走廊，楼道）<br>
  例：廊下の突き当たりで火事が起きました。（走廊尽头起火了。）
- **ワイシャツ**（ワイシャツ）衬衫｜韩语参考：와이셔츠（衬衣，衬衫）<br>
  例：ワイシャツにボタンをつけて。（给衬衫钉个扣子。）
- **若い**（わかい）年轻｜韩语参考：젊다（年青，年轻）<br>
  例：「彼女は若いですか」「はい」（「她年轻吗？」「是的。」）
- **私**（わたくし）我｜韩语参考：저（我） / 제（我）<br>
  例：私は泳げません。（我不会游泳。）
- **渡す**（わたす）交给；递｜韩语参考：건네다（递，交） / 건네주다（递给，交给） / 넘겨주다（交，交给，移交）<br>
  例：わたしを川のむこうに渡してください。（请把我送到河对岸。）
- **渡る**（わたる）过；渡过｜韩语参考：건너다（过，跨过，渡过） / 건너가다（过，跨过，渡过） / 건너오다（跨过来，渡过来）<br>
  例：一行はアメリカへ渡った。（一行人渡海去了美国。）
- **悪い**（わるい）坏；不好｜韩语参考：세다（硬，不好） / 나쁘다（不良，坏） / 못되다（恶劣，坏）<br>
  例：これは悪い話ではないでしょう？（这不算什么坏消息吧？）
- **公園**（こうえん）公园｜韩语参考：공원（公园）<br>
  例：公園で遊びます。（在公园玩。）

## 语法

- **～ことが できる**：会／能…（可能迂说）
  接续：動詞辞書形 + ことが + できる
  朝鲜语：-(으)ㄹ 수 있다（韩语与可能形同一表达ㄹ 수 있다，无迂说与形态之分；日语二者可换但接续不同。）
- **～たことが ある**：（曾经）做过…
  接续：動詞た形 + ことが + ある
  朝鲜语：-(으)ㄴ 적이 있다（韩语经验用ㄴ 적이 있다，否定ㄴ 적이 없다；与单纯过去았/었的区分同日语。）
