今日语法 3 条

韩语对应-아/어도 / -더라도
韩语让步用아/어도，强调用더라도；日语ところで后项必为否定性结果，韩语无此限制。
Vた形 + ところで
발음V타카타치 + 토코로데
即使…也（不会有预期结果）
動詞た形 + ところで；后项多为否定或无意义的结果
表示即使前项成立，后项也不会改变；常与「無駄だ／変わらない／〜ない」呼应。
今更謝ったところで、間に合いません。
事到如今再道歉也来不及了。
何度説明したところで、彼は分からないでしょう。
即使说明多少次，他也不会明白吧。
易错点

何度説明するところで、彼は理解しないでしょう。 → 何度説明したところで、彼は理解しないでしょう。（ところで（即使）接た形，不接辞书形；中文“即使说明”直译用原形。）

韩语对应-는 바람에 / -기 때문에
韩语辩解多用는 바람에(多坏事)或기 때문에；日语ものだから带撒娇式辩解，韩语靠语调体现。
普通形 + ものだから / もので
因为…（所以…）；由于…
動詞・い形 普通形 + ものだから；な形・名詞 + な/だ + ものだから；もので 更书面
用于说明原因，常带辩解/道歉语气；后项多为自己的行为或请求，不用于客观叙述自然现象。
朝寝坊したものだから、電車に遅れました。
因为睡过头，所以没赶上电车。
니혼고가와카라나이모노데스카라,유꾸리하나시테쿠다사이.
日本語が分からないものですから、ゆっくり話してください。
因为我不懂日语，请说慢一点。
易错点

忙しいだものだから、行けません。 → 忙しいものだから、行けません。（い形「忙しい」后不能加 だ；ものだから 直接接普通形。中文“因为忙”直译容易保留“是”。）

韩语对应-니까 / -기 때문에야말로
韩语强调正因为用니까加야말로，或기 때문이다；无单一固定形，须组合表达。
普通形 + からこそ
正因为…才…
動詞・い形 普通形 + からこそ；な形・名詞 + だ + からこそ
强调前项是后项成立的关键原因，常与「〜のだ／〜のです」呼应。
스키다카라코소,키비시쿠이우노데스.
好きだからこそ、厳しく言うのです。
正因为喜欢，才严格地说。
이소가시이카라코소,지칸노쓰카이카타오칸가에루히쓰요우가아리마스.
忙しいからこそ、時間の使い方を考える必要があります。
正因为忙，才需要思考如何使用时间。
易错点

好きだからこそで、続けられます。 → 好きだからこそ、続けられます。（からこそ 后不接 で；中文“正因为喜欢”直译加 で。）
