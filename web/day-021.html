今日语法 3 条

〜か（question）
발음〜카
…吗？（疑问）
句子（礼貌体／普通体）+ か
在句末加か构成疑问，实际语调会随语境、句型和说话方式变化。
韩语对应-까? / -니?
역이에요? 可用语调问问题。日语礼貌体教材句常用 駅ですか；普通体常问 駅？ 或 駅なの？，直接用 か 会因语气而显得较硬。
코레 와 아나타 노 카반데스 카.
これはあなたのかばんですか。
这是你的包吗？
아사고한 오 타베마시타 카.
朝ご飯を食べましたか。
你吃早饭了吗？
토이레 와 도코데스 카.
トイレはどこですか。
洗手间在哪里？

易错点 朝ご飯を食べましたかです。 → 朝ご飯を食べましたか。（疑问助词 か 后不能再加 です）

〜ね
발음〜네
…吧；…啊（寻求认同）
句子 + ね
用于确认对方也有同感，或缓和语气、寻求同意。
韩语对应-죠? / -네요
따뜻하죠? 对照 暖かいですね；따뜻하네요 对照发现后感叹的 暖かいですね。ね 也可只缓和语气，需听实际语调。
쿄우 와 아쓰이데스 네.
今日は暑いですね。
今天真热啊。
코노케이키, 오이시이데스 네.
このケーキ、おいしいですね。
这个蛋糕很好吃吧。
아시타 노 테스토 와 주우지 카라 데스 네.
明日のテストは10時からですね。
明天的考试是十点开始吧？

易错点 明日のテストは10時からだねです。 → 明日のテストは10時からですね。（ね 接在句末，后不能再加 です）

〜よ
발음〜요
…哦；…呀（告知、强调）
句子 + よ
用于告诉对方不知道的信息，或强调自己的判断，语气较强。
韩语对应-요 / -거든요
韩语 -요 是礼貌尾，不专门表告知；日语 よ 明确提示新信息，韩语需靠 -거든요 或语调表达。
코노라아멘 와 토테모오이시이데스 요.
このラーメンはとてもおいしいですよ。
这拉面很好吃哦。
카사 오 와스레테이마스 요.
かさを忘れていますよ。
你忘了带伞哦。
아시타 와 테스토 가 아리마스 요.
明日はテストがありますよ。
明天有考试哦。

易错点 このラーメンはとてもおいしいよです。 → このラーメンはとてもおいしいですよ。（よ 接句末，后不能加 です）
