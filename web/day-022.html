今日语法 3 条

〜より
발음〜요리
比…
比较基准（名词或普通形）+ より；优胜的一项可用 は 或 の方が 表明。
表示比较的基准，常与「の方が」呼应。
韩语对应보다
배보다 사과가 싸다 对照 梨よりりんごの方が安い。两种语言都把比较标记放在基准后面；日语可先说主项 りんごは，再说 梨より。
쿄우 와 키노우 요리 사무이데스.
今日はきのうより寒いです。
今天比昨天冷。
덴샤 와 바스 요리 하야이데스.
電車はバスより速いです。
电车比公交车快。
아니 와 치치 요리 세 가 타카이데스.
兄は父より背が高いです。
哥哥比父亲高。

易错点 今日はきのうよりが寒いです。 → 今日はきのうより寒いです。（より 后不加 が）

〜の方が〜より
발음〜노호우가〜요리
…比…更…
名词 + の方が + 名词 + より + 形容词
明确指出两者中较优或程度更高的一方，より 引出比较基准。
韩语对应가/이 더 …
用 자전거가 더 빠르다 记优势侧，歩くより自転車の方が速い 中 方が 也放在优势侧。也可用 自転車は徒歩より速い 省去 方。
이누 노 카타 가 네코 요리 스키데스.
犬の方が猫より好きです。
我更喜欢狗，而不是猫。
토우쿄우 노 카타 가 오오사카 요리 히토 가 오오이데스.
東京の方が大阪より人が多いです。
东京比大阪人多。
나쓰 요리 후유 노 카타 가 스키데스.
夏より冬の方が好きです。
比起夏天，我更喜欢冬天。

易错点 犬が方が猫より好きです。 → 犬の方が猫より好きです。（需要用「の方が」，不是「が方が」）

〜と〜とどちらが
발음〜토〜토도치라가
…和…哪个更…？
名词 + と + 名词 + とどちらが + 形容词 + か
用于两者之间比较提问，回答用「〜の方が」。
韩语对应A와 B 중 어느 쪽이
韩语用 와/과 중 어느 쪽이，日语用 と〜とどちらが；韩语需加 중，日语靠 どちら 本身表两者。
코오히이 토 코우차 토 도치라 가 스키데스 카.
コーヒーと紅茶とどちらが好きですか。
咖啡和红茶你更喜欢哪个？
덴샤 토 바스 토 도치라 가 야스이데스 카.
電車とバスとどちらが安いですか。
电车和公交车哪个便宜？
「야마 토 우미 토 도치라 가 이이데스 카.」「우미 노 카타 가 이이데스.」
「山と海とどちらがいいですか。」「海の方がいいです。」
“山和海你更喜欢哪个？”“海更好。”

易错点 コーヒーと紅茶がどちらが好きですか。 → コーヒーと紅茶とどちらが好きですか。（比较的两个对象用 と 并列，疑问部分用 どちらが）
