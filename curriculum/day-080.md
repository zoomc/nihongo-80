# Day 080 · 〜たら〜た、〜たって / 〜だって、〜ないことはない

- 阶段：P4｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜たら〜た**：…了之后发现…
  接续：动词た形 + ら … た形
  朝鲜语：-았더니（韩语「-았더니」正好对应“做了之后发现”；但日语「たら」还兼表条件，需靠后半句的过去时和发现语气判断。）
- **〜たって / 〜だって**：即使…也…（口语）
  接续：动词た形 + って；い形容词词干 + くたって；ナ形容词/名词 + だって
  朝鲜语：-아도（韩语「-아도/어도」是标准形式，不分书面口语；日语「たって」带明显随意感，正式场合须换「ても」。）
- **〜ないことはない**：并非不…；也不是不能…
  接续：动词ない形/い形容词くない/ナ形容词でない + ことはない
  朝鲜语：-지 못하는 건 아니다 / -지 않는 건 아니다（갈 수 없는 건 아니야 对照 行けないことはない，委婉地保留「可以去」的余地。再加 けど 很适合接限制条件。）
