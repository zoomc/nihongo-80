# Day 120 · 〜につれて、〜とともに

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜につれて、〜とともに」造两句自己的话，表达：随着…；与…一起；随着…

## 新词 14

- **順**（じゅん）顺序；次序｜韩语参考：차례（次序）<br>
  例：用紙は順に番号が打ってある。（纸张上依次编了号。）
- **瞬間**（しゅんかん）瞬间｜韩语参考：순간（瞬间，刹那） / 삽시간（霎时，一瞬间）<br>
  例：彼女その瞬間にカッとなったんだね。（她就是在那一刻火了起来。）
- **順調**（じゅんちょう）顺利｜韩语参考：원활（顺利，顺畅，流畅） / 평탄（顺利，一帆风顺）<br>
  例：すべてが順調にいっている。（一切都很顺利。）
- **順番**（じゅんばん）顺序；轮次｜韩语参考：차례（顺序，次序）<br>
  例：私たちは彼の順番をわざと飛ばした。（我们故意跳过了他的顺序。）
- **小**（しょう）小；小号｜韩语参考：소（小）<br>
  例：大か、小か。（大的还是小的？）
- **章**（しょう）章；章节｜韩语参考：장（章）<br>
  例：先生は私に一番長い章を割り当てた。（老师把最长的一章分给了我。）
- **賞**（しょう）奖；奖项｜韩语参考：상（奖，奖赏）<br>
  例：期待されたとおり彼は賞を得た。（不出所料，他得了奖。）
- **使用**（しよう）使用｜韩语参考：사용（使用，用，应用）<br>
  例：体育館は式のために使用されます。（体育馆将用于举行仪式。）
- **障害**（しょうがい）障碍｜韩语参考：장애（障碍，阻力） / 장해（障碍，妨碍，防碍） / 거리낌（妨碍，障碍）<br>
  例：貧困は幸福への障害とはならない。（贫穷不会成为通往幸福的障碍。）
- **奨学金**（しょうがくきん）奖学金｜韩语参考：장학금（奖学金）<br>
  例：奨学金のおかげで彼女は留学した。（多亏了奖学金，她得以留学。）
- **乗客**（じょうきゃく）乘客｜韩语参考：승객（乘客） / 손님（乘客） / 탑승객（乘客）<br>
  例：乗客はどちらの側にも４人すわっていた。（乘客两侧各坐了四个人。）
- **上京**（じょうきょう）进京；去东京｜韩语参考：상경（进京，上京）<br>
  例：彼は商用で上京した。（他为做生意去了东京。）
- **正午**（しょうご）正午；中午｜韩语参考：정오（正午）<br>
  例：彼は正午までここにいるでしょう。（他会在这里待到中午吧。）
- **正直**（しょうじき）诚实；老实｜韩语参考：정직하다<br>
  例：彼は正直なので多くの友人がいる。（他为人诚实，所以朋友很多。）

## 语法

- **〜につれて**：随着…
  接续：动词辞书形/名词 + につれて
  朝鲜语：-에 따라（韩语「-에 따라」同时承担“依照”和“随着”；日语「につれて」只表随之变化，前后都须是变化性表达。）
- **〜とともに**：与…一起；随着…
  接续：名词 + とともに；动词辞书形 + とともに
  朝鲜语：-와 함께（韩语「-와 함께」只表“一起”；日语「とともに」还能表“随着、同时”，韩语后者要用「-에 따라」。）
