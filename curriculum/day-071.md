## 新词 25

- **気味**（きみ）感觉；苗头｜韩语参考：기미（苗头，迹象，征兆） / 기운（气势 ，迹象，征兆，苗头）<br>
  例：その事件には何となく気味の悪いところがあった。（那起事件总让人觉得有点瘆人。）
- **奇妙**（きみょう）奇怪｜韩语参考：기묘하다<br>
  例：これはとても奇妙な手紙です。（这是一封非常奇怪的信。）
- **義務**（ぎむ）义务｜韩语参考：의무（义务）<br>
  例：このような義務があるなんて知らなかった。（我不知道还有这样的义务。）
- **疑問**（ぎもん）疑问｜韩语参考：의문（疑问）<br>
  例：子供には疑問がたくさんあります。（孩子心里有很多疑问。）
- **逆**（ぎゃく）相反；反过来｜韩语参考：반대 / 거꾸로<br>

- **キャンプ**（キャンプ）露营｜韩语参考：야영（野营，露营） / 캠프（野营，露营地） / 캠핑（露营，野营）<br>

- **級**（きゅう）级；等级｜韩语参考：급（级）<br>
  例：彼は１０年級に在学中だ。（他在读十年级。）
- **旧**（きゅう）旧；前｜韩语参考：구（旧，老）<br>

- **休暇**（きゅうか）休假｜韩语参考：휴가（休假，度假，放假，假期）<br>
  例：私は休暇で出かけていました。（我休假出去了。）
- **休憩**（きゅうけい）休息｜韩语参考：휴게（休憩，休息）<br>
  例：休憩してコーヒーを飲もう。（休息一下喝杯咖啡吧。）
- **急激**（きゅうげき）急剧｜韩语参考：급격하다<br>
  例：その党は急激にのびた。（那个政党迅速壮大了起来。）
- **吸収**（きゅうしゅう）吸收｜韩语参考：흡수（吸收）<br>
  例：この布は水をよく吸収する。（这种布很吸水。）
- **救助**（きゅうじょ）救助｜韩语参考：구조（救助，营救，拯救）<br>
  例：彼はおぼれている少年を救助した。（他救起了溺水的少年。）
- **急速**（きゅうそく）迅速｜韩语参考：급속도（迅速，急速）<br>
  例：コンピューターは急速な進化を遂げた。（计算机经历了迅速的进化。）
- **急に**（きゅうに）突然｜韩语参考：갑자기（突然，忽然，猛地，一下子） / 급작스레（突然地，猝不及防地）<br>
  例：気苦労で彼は急にふけた。（操心让他一下子苍老了。）
- **器用**（きよう）手巧｜韩语参考：손재주가 좋다<br>
  例：マックスは手先が器用だ。（马克斯手很巧。）
- **教科書**（きょうかしょ）教科书｜韩语参考：교과서（教科书，教材）<br>
  例：教科書はどうしたらいいんでしょうか。（教科书该怎么办呢？）
- **競技**（きょうぎ）比赛｜韩语参考：경기（竞技，比赛，竞赛） / 게임（比赛）<br>
  例：あなたは競技に参加しましたか。（你参加比赛了吗？）
- **行儀**（ぎょうぎ）举止；礼貌｜韩语参考：버릇（礼貌）<br>
  例：彼女は行儀が極めて上品である。（她的举止非常文雅。）
- **供給**（きょうきゅう）供给｜韩语参考：공급（供应，供给） / 공여（供给）<br>
  例：水は外側から供給された。（水是从外部供给的。）
- **教師**（きょうし）教师｜韩语参考：교사（教师） / 선생（老师，教师）<br>
  例：私の兄は教師です。（我哥哥是教师。）
- **教授**（きょうじゅ）教授｜韩语参考：교수（教授，教学，讲授） / 정교수（正教授）<br>
  例：一人の教授がささやいた。（一位教授低声说。）
- **強調**（きょうちょう）强调｜韩语参考：강조（强调）<br>
  例：先生は毎日の練習の大切さを強調した。（老师强调了每天练习的重要性。）

## 语法

- **〜一方だ**：一直…；越来越…
  接续：动词辞书形 + 一方だ
  朝鲜语：-기만 한다（韩语「-기만 한다」偏“只做某事”；日语「一方だ」专指程度单向加剧，常带忧虑，韩语更常说「계속 -고 있다」。）
- **〜一方で**：一方面…；同时…
  接续：普通形 + 一方で；ナ形容词 + な + 一方で；名词 + である + 一方で
  朝鲜语：-는 반면에（韩语「-는 반면에」只表对比；日语「一方で」还能表“同时进行的两件事”，范围更宽。）
