# Day 039 · ～なくても いい、～ようになる / ～なくなる

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～なくても いい、～ようになる / ～なくなる」造两句自己的话，表达：不必…／不…也行；变得会…／变得不…了

## 新词 20

- **安心**（あんしん）放心；安心｜韩语参考：안도（安心） / 안심（安心，放心）<br>
  例：無事だと聞いて安心しました。（听说平安就放心了。）
- **興味**（きょうみ）兴趣；好奇｜韩语参考：관심（关注，关心，兴趣） / 재미（兴趣，趣味） / 취미（兴趣）<br>
  例：日本の歴史に興味があります。（我对日本历史感兴趣。）
- **上手**（じょうず）擅长；拿手｜韩语参考：잘하다 / 능숙하다<br>
  例：彼女は料理が上手です。（她做饭很拿手。）
- **下手**（へた）不擅长；笨拙｜韩语参考：서투르다 / 못하다<br>
  例：私は歌が下手です。（我唱歌不行。）
- **丈夫**（じょうぶ）结实；健壮｜韩语参考：튼튼하다<br>
  例：この鞄はとても丈夫です。（这个包很结实。）
- **大丈夫**（だいじょうぶ）没问题；不要紧；不用了｜韩语参考：괜찮다 / 문제없다 / 필요 없다（문맥에 따라）<br>
  例：「大丈夫ですか」「はい、大丈夫です」（「没事吧」「嗯，没事」）
- **簡単**（かんたん）简单；容易｜韩语参考：간단하다 / 쉽다<br>
  例：この問題は簡単です。（这道题很简单。）
- **危ない**（あぶない）危险｜韩语参考：위태롭다（危急，危险，惊险，悬） / 위험하다（危险）<br>
  例：ここで遊ぶのは危ないです。（在这里玩很危险。）
- **連絡**（れんらく）联络；联系｜韩语参考：연락（联络，联系）<br>
  例：先生に連絡してください。（请联系老师。）
- **予定**（よてい）预定；计划（日程）｜韩语参考：예정（预定）<br>
  例：明日は出張の予定です。（明天预定出差。）
- **予約**（よやく）预约；预订｜韩语参考：예약（预约，预订）<br>
  例：ホテルを予約しました。（订好了酒店。）
- **用意**（ようい）准备；备好（东西）｜韩语参考：마련（准备，备下，置备） / 준비（准备） / 채비（准备，筹备）<br>
  例：資料を用意してください。（请把资料准备好。）
- **世話**（せわ）照顾；照料｜韩语参考：건사（照看，照顾） / 치다꺼리（帮助，照顾，照料） / 뒤치다꺼리（收拾，照顾）<br>
  例：子供の世話をします。（照看孩子。）
- **そろそろ**（そろそろ）差不多该…；快要…｜韩语参考：슬슬 / 이제 곧<br>
  例：そろそろ帰りましょう。（差不多该回去了吧。）
- **あ**（あ）啊｜韩语参考：아<br>
  例：あ！まずい！ガソリンが切れてきた。（啊！糟了！汽油快没了。）
- **ああ**（ああ）那样；那种｜韩语参考：저렇게 / 저런<br>
  例：ある人はこうだと言い、またある人はああだと言う。（有人说这样，又有人说那样。）
- **あいさつする**（あいさつする）打招呼；问候｜韩语参考：인사하다<br>
  例：私にあいさつするような人はいない。（没有人会跟我打招呼。）
- **間**（あいだ）之间；期间｜韩语参考：새（之间，以来） / 사이（间，之间，……的时候）<br>
  例：二人の間がしっくり行かない。（两人之间处得不太融洽。）
- **合う**（あう）合适；相符｜韩语参考：맞다（合适，合乎，对） / 합하다（符合，相符） / 맞아떨어지다（完全相符，正好，一点不差）<br>
  例：このチョッキは前が合わない。（这件背心前面扣不上。）
- **あかちゃん**（あかちゃん）婴儿；宝宝｜韩语参考：아기<br>
  例：その赤ちゃんは歯が生えはじめている。（那个宝宝开始长牙了。）

## 语法

- **～なくても いい**：不必…／不…也行
  接续：動詞ない形（去ない） + くても + いい
  朝鲜语：-지 않아도 되다（韩语지 않아도 되다表不必，口语常안 해도 돼更随意；日语なくてもいい较中性。）
- **～ようになる / ～なくなる**：变得会…／变得不…了
  接续：辞书形/可能形 + ようになる；ない形去ない + なくなる（例：行かなくなる）
  朝鲜语：-게 되다 / -지 않게 되다（韩语变化结果统用게 되다，能力变化也用게 되다；日语ようになる与なくなる分开。）

- **別** 分别；另外；特别｜音：ベツ｜训：わか.れる、わ.ける
- **物** 东西；物品｜音：ブツ、モツ｜训：もの、もの-
- **使** 使用；派遣；使者｜音：シ｜训：つか.う、つか.い、-つか.い、-づか.い
