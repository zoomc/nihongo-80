# Day 041 · ～てみる / ～てしまう / ～ておく、あげる / くれる / もらう

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～てみる / ～てしまう / ～ておく、あげる / くれる / もらう」造两句自己的话，表达：试着…／…完了／事先…；给…；别人给我…；从…得到

## 新词 19

- **医学**（いがく）医学｜韩语参考：의학（医学）<br>
  例：二人の医者が医学の話をしていた。（两位医生在聊医学方面的事。）
- **生きる**（いきる）活；生存｜韩语参考：살다（活，活着，生存） / 살아가다（活命，生存，活下去）<br>
  例：生きるものはすべていつかは死ぬ。（所有活着的生物终有一死。）
- **意見**（いけん）意见；看法｜韩语参考：의견（意见）<br>
  例：ここではどんどん意見をおっしゃってかまいません。（在这里可以尽管提意见。）
- **石**（いし）石头｜韩语参考：돌（石，石头） / 바위（石头）<br>
  例：私にはこの石は持ち上がらない。（这块石头我举不起来。）
- **いじめる**（いじめる）欺负；捉弄｜韩语参考：괴롭히다<br>
  例：彼はよく友人をいじめたものだ。（他以前常欺负朋友。）
- **以上**（いじょう）以上；就这些｜韩语参考：이상（以上）<br>
  例：以上ですか？（就这些吗？）
- **急ぐ**（いそぐ）赶紧；着急｜韩语参考：서둘다（着急，操之过急） / 서두르다（着急，操之过急）<br>
  例：ニックはバスに間に合うように急いだ。（尼克为了赶上公交加快了脚步。）
- **致す**（いたす）做（谦让语）｜韩语参考：하다（겸양）<br>
  例：お取り寄せいたしましょうか。（要我帮您订购吗？）
- **一度**（いちど）一次；一遍｜韩语参考：한 번<br>
  例：人間はこの世に一度しか生きない。（人在这世上只能活一次。）
- **一生懸命**（いっしょうけんめい）拼命；努力｜韩语参考：열심히 / 필사적으로<br>
  例：もっと一生懸命勉強すべきだったのに。（本应该更拼命学习的。）
- **いっぱい**（いっぱい）满；很多｜韩语参考：가득 / 많이<br>
  例：このボトルに水をいっぱい入れてください。（请把这个瓶子装满水。）
- **糸**（いと）线；丝｜韩语参考：끈（绳子，绳索，线） / 실（线）<br>
  例：長い糸はからまりやすい。（长线容易缠在一起。）
- **以内**（いない）以内｜韩语参考：이내（以内）<br>
  例：１週間以内に電話します。（一周内给你打电话。）
- **田舎**（いなか）乡下；老家｜韩语参考：촌（老家） / 시골（乡下，农村，乡村）<br>
  例：去年の夏、父の田舎に行きました。（去年夏天去了父亲的老家。）
- **祈る**（いのる）祈祷；祝愿｜韩语参考：빌다（祈祷，祈求） / 기도하다（祈祷，祷告） / 축원하다（祝愿，祈祷，祷告）<br>
  例：早くよくなられるように祈っています。（盼望您早日康复。）
- **植える**（うえる）种植｜韩语参考：심다（种植，种，栽）<br>
  例：私は庭にバラを植えた。（我在院子里种了玫瑰。）
- **うかがう**（うかがう）拜访；请教｜韩语参考：방문하다 / 여쭙다（겸양）<br>
  例：体重をおうかがいしてもよろしいですか。（可以问一下您的体重吗？）
- **受ける**（うける）接受；参加（考试）｜韩语参考：받다（接受，遭受，经受，承蒙） / 보다（考，参加）<br>
  例：病気なので試験が受けられません。（因为生病，没法参加考试。）
- **動く**（うごく）动；运转｜韩语参考：가다（走，运转） / 돌다（运转） / 돌아가다（运转，运行）<br>
  例：まだ動くうちに売ってしまわなきゃ。（得趁它还能动赶紧卖掉。）

## 语法

- **～てみる / ～てしまう / ～ておく**：试着…／…完了／事先…
  接续：動詞て形 + みる／しまう／おく
  朝鲜语：-아/어 보다 / -아·어 버리다 / -아·어 두다（韩语分别用보다(尝试)、버리다(完了/遗憾)、두다(预先)，与日语三形基本对应。）
- **あげる / くれる / もらう**：给…；别人给我…；从…得到
  接续：给予者 は/が 接受者 に 物 を あげる；给予者 が 我方 に 物 を くれる；接受者 は 给予者 に/から 物 を もらう
  朝鲜语：주다 / 받다（韩语 주다 不分方向，日语必须按「谁给谁」区分 あげる／くれる；韩语 받다 对应 もらう，但日语 もらう 的来源可用 に 或 から。）
