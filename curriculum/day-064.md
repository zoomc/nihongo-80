## 新词 22

- **承認**（しょうにん）批准；认可｜韩语参考：승인（批准，同意）<br>
  例：部長が申請を承認しました。（部长批准了申请。）
- **提出**（ていしゅつ）提交；交出｜韩语参考：제출（提交，出具）<br>
  例：明日までに報告書を提出してください。（请在明天之前提交报告。）
- **締め切り**（しめきり）截止日期；截止｜韩语参考：마감（截至，截止日期）<br>
  例：応募の締め切りは今週の金曜日です。（报名截止日期是本周五。）
- **担当**（たんとう）负责；担任｜韩语参考：담당（负责，担任）<br>
  例：このお客様は田中さんが担当しています。（这位客户由田中负责。）
- **上司**（じょうし）上司｜韩语参考：상관（上司，上级） / 상사（上司）<br>
  例：上司に相談してから決めます。（和上司商量后再决定。）
- **部下**（ぶか）部下；下属｜韩语参考：부하（部下，下级，下属）<br>
  例：部下に仕事を頼みました。（把工作交给了下属。）
- **同僚**（どうりょう）同事｜韩语参考：동료（同事，同僚）<br>
  例：同僚と昼ご飯を食べました。（和同事一起吃了午饭。）
- **取引先**（とりひきさき）交易对象；客户公司｜韩语参考：거래처（客户）<br>
  例：取引先との会議は来週です。（和客户公司的会议在下周。）
- **打ち合わせ**（うちあわせ）碰头商量；事前协调｜韩语参考：사전 협의 / 회의<br>
  例：明日の打ち合わせは三時からです。（明天的碰头会三点开始。）
- **資料**（しりょう）资料；材料｜韩语参考：자료（资料）<br>
  例：会議の資料をコピーしました。（复印了会议资料。）
- **書類**（しょるい）文件；书面材料｜韩语参考：서류（文件，材料）<br>
  例：必要な書類を窓口に出してください。（请把必要文件交到窗口。）
- **宛先**（あてさき）收件地址；收件人｜韩语参考：수신인 / 수신 주소<br>
  例：メールの宛先を間違えました。（把邮件收件人弄错了。）
- **件名**（けんめい）（邮件）主题｜韩语参考：제목<br>
  例：件名には会議の名前を書いてください。（主题栏请写会议名称。）
- **添付**（てんぷ）附件；附加｜韩语参考：첨부（附加，附有，附上，添付）<br>
  例：見積書をメールに添付しました。（把报价单附在邮件里了。）
- **返信**（へんしん）回信；回复｜韩语参考：답신（回信，回复） / 답장（回信，回复） / 회신（回信，回电，回函，回电话，复函）<br>
  例：メールの返信を待っています。（在等邮件回复。）

  例：このメールを営業部に転送してください。（请把这封邮件转发给营业部。）

  例：提出の期限は明日の午後五時です。（提交期限是明天下午五点。）

- **印鑑**（いんかん）印章；图章｜韩语参考：인감도장（印鉴图章）<br>
  例：印鑑を持ってきてください。（请带上印章。）

## 语法

- **V意志形 + と 思う / と する**：打算…／正要…、试图…
  接续：動詞 意志形（五段 お段+う／一段 よう／する→しよう／来る→こよう）+ と 思う／と する
  朝鲜语：-(으)ㄹ 생각이다 / -(으)려고 하다（韩语打算用ㄹ 생각이다，正要或试图用려고 하다；日语と思う还含推测，韩语更明确表意志。）
- **N / Vた形 / V辞書形 / Vて + ばかり**：刚…；净是…、只…；一味…
  接续：名詞 + ばかり；動詞 た形 + ばかり（刚做完）；辞書形 + ばかり（只等/只剩）；て形 + ばかり いる（光顾着做）
  朝鲜语：방금 / -만 / -기만 하다（韩语「刚」用방금、「只」用만、「一味」用기만 하다，三义分用；日语ばかり一形靠语境。）
- **V辞書形/Vている/Vた形 + ところ(だ/に/を/で)**：正要…／正在…／刚…；在…时候；…之际
  接续：辞書形 + ところだ（正要）；ている + ところだ（正在）；た形 + ところだ（刚做完）；ところに/を/で 后接外部动作或发现
  朝鲜语：-(으)려고 하다 / -고 있다 / -(으)ㄴ 참이다（韩语正要려고 하다、正在고 있다、刚ㄴ 참이다；日语ところだ按だ/に/を/で四形变化。）
