今日语法 3 条

〜わけがない
발음〜와케가나이
不可能…；绝不会…
普通形 + わけがない；ナ形容词 + な + わけがない；名词 + の/な + わけがない
依据常理强烈否定某种可能性，语气比单纯否定更强。
韩语对应-(으)ㄹ 리가 없다
韩语「-ㄹ 리가 없다」与「わけがない」几乎一一对应；但韩语口语常说「-ㄹ 리가 없잖아」反驳，日语习惯前加「そんな」。
콘나니렌슈우시탄다카라, 마케루와케 가 나이.
こんなに練習したんだから、負けるわけがない。
练了这么多，不可能输。
안나니마지메나히토 가, 야쿠소쿠 오 와스레루와케 가 아리마센.
あんなにまじめな人が、約束を忘れるわけがありません。
那么认真的人，绝不可能忘记约定。
一日で漢字を百個覚えるなんて、できるわけがないよ。
一天记一百个汉字？不可能做到。

易错点 あんなにまじめな人が約束を忘れるわけがないだった。 → …忘れるわけがなかった。（「わけがない」的过去形是「わけがなかった」，不能再接「だった」。）

〜わけにはいかない
발음〜와케니하이카나이
不能…；不便…
动词辞书形 + わけにはいかない；动词ない形 + わけにはいかない
因社会常识、道义或立场而不能做某事，与能力无关。
韩语对应-ㄹ 수는 없다
韩语「-ㄹ 수는 없다」偏“能力或情况不允许”；日语「わけにはいかない」强调社会道义上的“不能”，含无奈。
아시타 와 다이지나카이기 가 아루카라, 야스무와케 니 와 이카나이.
明日は大事な会議があるから、休むわけにはいかない。
明天有重要会议，不能请假。
友達に頼まれたことだから、断るわけにはいかなかった。
是朋友托付的事，不好拒绝。
쇼우타이사레타노다카라, 파아티이 니 이카나이와케 니 와 이카나이.
招待されたのだから、パーティーに行かないわけにはいかない。
既然被邀请了，就不能不去参加。

易错点 明日は大事な会議があるから、休まわけにはいかない。 → 休むわけにはいかない（「わけにはいかない」前接辞书形「休む」或ない形「休まない」，「休ま」不是合法形式。）

〜ものだ
발음〜모노다
本来就…；应当…；过去常…
动词辞书形/た形 + ものだ；い形容词 + ものだ；ナ形容词 + な + ものだ
讲普遍规律或应当如此，也用「た形 + ものだ」回忆过去。
韩语对应-는 법이다
韩语「-는 법이다」只表“理应如此”；日语「ものだ」还能用た形表“过去常常”，对应韩语「-곤 했다」，分工不同。
코도모 노 코로 와, 코노카와데요쿠오요이다모노다.
子どものころは、この川でよく泳いだものだ。
小时候常在这条河里游泳。
아타라시이칸쿄우 니 나레루 니 와, 지칸 가 카카루모노다.
新しい環境に慣れるには、時間がかかるものだ。
适应新环境本来就需要时间。
메우에 노 히토 니 와 케이고 오 쓰카우모노다.
目上の人には敬語を使うものだ。
对长辈本来就该用敬语。

易错点 この辺りは、夜になると静かものだ。 → 静かなものだ（ナ形容词接「ものだ」要加「な」，「静かものだ」不合法。）
