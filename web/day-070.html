Day 070 · 〜気がする、〜ずに、〜まま

语法 3 条

〜気がする
발음〜키가스루
感觉…；总觉得…
普通形 + 気がする；ナ形容词 + な + 気がする；名词 + の + ような + 気がする
表达模糊的直觉或主观感觉，把握不大。
韩语对应-(으)ㄴ/는 것 같다 / …한 느낌이 들다
「好像在哪儿见过」可说 어디선가 본 것 같다，对照 どこかで会った気がする。気がする 常把它说成自己的隐约感觉。
코노히토 토 와, 도코 카 데 아따코토 가 아루키 가 스루.
この人とは、どこかで会ったことがある気がする。
总觉得在哪儿见过这个人。
쿄우 와 나니카, 이이코토 가 아리소우나키 가 스루.
今日は何か、いいことがありそうな気がする。
今天总觉得会有好事发生。
ドアの鍵をかけ忘れたような気がして、家に戻った。
觉得好像忘了锁门，就回家了一趟。
易错易混点
  • ✗ 今日は何か変気がする。✓ 変な気がするな形容词接 気がする 要加 な：変な気がする。
〜ずに
발음〜즈니
不…就…；没…而…
动词ない形词干 + ずに（する→せずに）
表示在不做某动作的状态下做另一动作，书面色彩强。
韩语对应-지 않고
-지 않고 对照 ないで／ずに。ずに 常见于较正式的叙述，普通会话也能用。する 是例外，写 せずに。
케사 와 아사고한 오 타베즈 니 이에 오 데타.
けさは朝ご飯を食べずに家を出た。
今天早上没吃早饭就出门了。
辞書を使わずに、この新聞記事が読めますか。
你能不用词典读懂这篇报道吗？
彼は誰にも相談せずに、会社を辞めてしまった。
他没跟任何人商量就辞职了。
易错易混点
  • ✗ 彼は誰にも相談しずに、会社を辞めてしまった。✓ 相談せずにする 的 ずに 形式是 せずに。
〜まま
발음〜마마
就那样…；保持着…
动词た形/ない形 + まま；い形容词 + まま；ナ形容词 + な + まま；名词 + の + まま
表示某状态保持不变地进行另一动作。
韩语对应-ㄴ 채로
韩语「-ㄴ 채로」与「まま」很接近；但日语可接名词「〜のまま」，韩语没有对应形式，要改说「그대로」。
에아콘 오 쓰케타마마네테시마이, 카제 오 히이타.
エアコンをつけたまま寝てしまい、風邪をひいた。
开着空调就睡着了，结果感冒了。
코노마치 와, 와타시 가 코도모다따코로 노 마마다.
この町は、私が子どもだったころのままだ。
这个镇子还和我小时候一样。
쿠쓰 노 마마헤야 니 하이라나이데쿠다사이.
靴のまま部屋に入らないでください。
请不要穿着鞋进房间。
易错易混点
  • ✗ エアコンをつけるまま寝てしまい、風邪をひいた。✓ つけたまま表示状态一直持续，要用 た形＋まま：つけたまま。
