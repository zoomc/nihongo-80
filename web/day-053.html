语法 3 条

V ば形 + 同一動詞 辞書形 + ほど
越…越…
动词 ば形 + 同一动词辞书形 + ほど；い形 〜ければ〜いほど；な形 〜なら〜なほど／〜であれば〜であるほど。
前后同词重复，表成正比变化；常与 ますます 呼应
韩语对应-(으)면 -(으)ㄹ수록
韩语用면…ㄹ수록前后同词，结构与日语ば…ほど对应；但韩语可省略前项只留수록。
렌슈우스레바스루 호도, 조우즈 니 나리마스.
練習すればするほど、上手になります。
越练越熟练。
네단 가 타카케레바타카이 호도, 우레니쿠쿠나리마스.
値段が高ければ高いほど、売れにくくなります。
价格越贵越难卖。
易错易混点
  • ✗ 練習すればするのほど上達します。✓ 練習すればするほど上達します。すればするほど 中间不加 の，する 直接接 ほど。
  • ✗ 高いば高いほど✓ 高ければ高いほど、…い形容词的ば形是 高ければ（い→ければ），不是 高い＋ば。
N(＋助詞) + さえ／こそ／すら；V ば形 前 + さえ…ば
발음N + 사에／코소／스라；V 바카타치 마에 + 사에…바
甚至…／只要…就／正是…／连…都
さえ/すら 取代 が・を 或接在助词后（にさえ／でさえ）；さえ…ば 用 条件形(ば)；こそ 强调主语/原因（〜からこそ）
さえ 举极端例表「连…都/甚至」；さえ…ば 表「只要满足这一项就够」；こそ 强调「正是」；すら 文言、更消极
韩语对应-조차 / -야말로 / -마저
韩语조차表连…都(多否定)、마저表连…也(消极)、야말로表正是，分工比日语さえ/すら细。
이소가시쿠테, 히루고한 오 타베루지칸 사에 아리마센.
忙しくて、昼ご飯を食べる時間さえありません。
忙得连吃午饭的时间都没有。
코레 사에 아레바, 다이조우부데스.
これさえあれば、大丈夫です。
只要有这个就没问题。
今こそ頑張るときです。
现在正是努力的时候。
易错易混点
  • ✗ 時間さえがありません。✓ 時間さえありません。さえ 已经取代 が／を，后面不再加。
  • ✗ 時間こそありません。✓ 時間さえありません。「连…都没有」用 さえ；こそ 是“正是…”，意思不同。
普通形 + くせに / ものの / とはいえ
明明…却（责备）／虽然…但是／虽说…然而
くせに：动词／い形普通形、な形容词 + な、名词 + の；ものの：普通形；とはいえ：名词或普通形 + とはいえ
くせに 带强烈责备/轻蔑（对人不满）；ものの 是中性书面让步；とはいえ 是「话虽如此」，常修正前句
韩语对应-(으)ㄴ/는 주제에 / -기는 하지만 / 그렇다고는 해도
くせに 接近 주제에，责备色彩强。ものの 可对照 -기는 하지만，承认事实后加保留。とはいえ 也可置于句首，像 그렇다고는 해도。
시떼이루쿠세 니, 오시에테쿠레마센데시타.
知っているくせに、教えてくれませんでした。
明明知道却不告诉我。
카따모노노, 쓰카떼이마센.
買ったものの、使っていません。
虽然买了却没在用。
타카이 토 와 이에, 힌시쓰 와 이이데스.
高いとはいえ、品質はいいです。
虽说贵，质量倒不错。
易错易混点
  • ✗ 先生は知っているくせに、教えてくれませんでした。✓ 先生はご存じなのに、教えてくださいませんでした。くせに 带责备口气，对老师用很失礼；换成 のに 或敬语说法。
  • ✗ 子供だくせに、…✓ 子供のくせに、…名词接 くせに 用 の：子供のくせに。
