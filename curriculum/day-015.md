# Day 015 · 〜を、〜に（time）、〜に（destination）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜を**：…是宾语；经过的场所
  接续：名词 + を（读作 o）
  朝鲜语：을/를（목적어）（밥을 먹다／ご飯を食べる 是对象；다리를 건너다／橋を渡る 是经过路线。日语这两个用法都写 を、读 o。）
- **〜に（time）**：在…（某时点）
  接续：名词（时间）+ に
  朝鲜语：에（시간）（韩语时点可用 에，日语具体时点常用 に；两种语言的相对时间词是否加助词都需看实际用法，不可机械对应。）
- **〜に（destination）**：去／来／回…（目的地）
  接续：名词（场所）+ に + 行く／来る／帰る
  朝鲜语：에（도착점）（韩语 에 与 に 对应；但韩语 가다 的目的地也可用 로，日语 へ 与之相近，に 更强调到达。）
