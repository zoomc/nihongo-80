Day 071 · 〜うちに、〜ところに / 〜ところへ / 〜ところを、〜ば〜ほど

语法 3 条

〜うちに
발음〜우치니
趁着…；在…过程中
动词辞书形/ている/ない形 + うちに；い形容词 + うちに；ナ形容词 + な + うちに；名词 + の + うちに
表示在某状态持续期间做某事，或期间不知不觉发生变化。
韩语对应…하는 동안에 / …하기 전에 / …할 때 얼른
韩语「-는 동안에」只表时间范围；日语「うちに」还含“趁还没变、赶在期限前”的语感。
와카이우치 니, 이로이로나쿠니 오 료코우시타호우 가 이이.
若いうちに、いろいろな国を旅行したほうがいい。
趁年轻多去几个国家旅行比较好。
스푸 가 사메나이우치 니, 도우조메시아가떼쿠다사이.
スープが冷めないうちに、どうぞ召し上がってください。
请趁汤还没凉快喝吧。
온가쿠 오 키이테이루우치 니, 이쓰노아이다니카네무떼시마따.
音楽を聞いているうちに、いつの間にか眠ってしまった。
听着音乐，不知不觉就睡着了。
易错易混点
  • ✗ 若いのうちに、いろいろな国を旅行したほうがいい。✓ 若いうちにい形容词直接接 うちに，不加 の。
〜ところに / 〜ところへ / 〜ところを
발음〜토코로니 / 〜토코로헤 / 〜토코로오
正当…的时候
动词辞书形/ている/た形 + ところに／ところへ／ところを
表示某动作正要发生或正在进行时，被另一事打断。
韩语对应…하려는 참에 / …하는 장면을
出かけるところに電話が来た 可对照 나가려는 참에 전화가 왔다。盗んでいるところを見られた 则是 훔치는 모습을 들켰다，由 を 标出被看见的场面。
데카케요우 토 시테이루토코로 니, 토모다치 카라 덴와 가 카카떼키타.
出かけようとしているところに、友達から電話がかかってきた。
正要出门时，朋友打来了电话。
민나 데 키미 노 하나시 오 시테이루토코로 에, 초우도키미 가 키타.
みんなで君の話をしているところへ、ちょうど君が来た。
我们正说你呢，你就来了。
주교우추우 니 스마호 오 미테이루토코로 오, 센세이 니 미라레테시마따.
授業中にスマホを見ているところを、先生に見られてしまった。
上课看手机被老师看见了。
易错易混点
  • ✗ 出かけるのところに、友達から電話がかかってきた。✓ 出かけるところにところ 前接动词不加 の；のところ 只接名词。
〜ば〜ほど
발음〜바〜호도
越…越…
动词ば形 + 同一动词辞书形 + ほど；い形容词ければ + い形容词 + ほど；ナ形容词なら + ナ形容词な + ほど
表示随着前项程度加深，后项程度也随之变化。
韩语对应-면 -ㄹ수록
-을수록 一次就能表达「越…越…」。日语可用 すればするほど，也可只用 するほど。前一种结构更便于看清同一动作反复套用。
日本語は、勉強すればするほど面白くなる。
日语越学越有意思。
스마호 노 가멘 와 오오키케레바오오키이 호도 미야스이가, 모치아루쿠노 와 타이헨다.
スマホの画面は大きければ大きいほど見やすいが、持ち歩くのは大変だ。
手机屏幕越大越容易看，但带着走很麻烦。
헤야 가 시즈카나라시즈카나 호도, 요쿠네무레루.
部屋が静かなら静かなほど、よく眠れる。
房间越安静，睡得越好。
易错易混点
  • ✗ 日本語は、勉強するすればするほど面白くなる。✓ 勉強すればするほど前项用ば形 すれば，するすれば 不成立。
