# Day 031 · 〜です、〜だ

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜です、〜だ」造两句自己的话，表达：是…（礼貌断定）；是…（普通断定）

## 新词 19

- **広い**（ひろい）宽；宽广｜韩语参考：넓다（宽敞，宽阔，宽广） / 크다（大，宽，广） / 너르다（宽，宽广）<br>
  例：この通りは広いが、あまり長くない。（这条街很宽，但不太长。）
- **フィルム**（フィルム）胶卷；胶片｜韩语参考：필름（胶卷）<br>
  例：カラーフィルムを一本ください。（请给我一卷彩色胶卷。）
- **封筒**（ふうとう）信封｜韩语参考：봉투（信封） / 겉봉（信封） / 편지봉투（信封）<br>
  例：だれがこの封筒を破って開けたのか。（是谁把这个信封撕开的？）
- **プール**（プール）游泳池｜韩语参考：풀（游泳场，游泳池，泳池）<br>
  例：サウナとプールがあります。（有桑拿和游泳池。）
- **フォーク**（フォーク）叉子｜韩语参考：포크（叉子，餐叉）<br>
  例：フォークでパスタを食べます。（用叉子吃意大利面。）
- **吹く**（ふく）吹；刮｜韩语参考：불다（刮，吹）<br>
  例：あの日は強い風が吹いていました。（那天刮着大风。）
- **服**（ふく）衣服｜韩语参考：옷（衣服，衣裳，服装）<br>
  例：この服はわたしにはもったいない。（这件衣服给我穿太可惜了。）
- **二つ**（ふたつ）两个｜韩语参考：두엇（两三，两个左右）<br>
  例：二つのうちでどちらが高いですか。（两个当中哪个更贵？）
- **豚肉**（ぶたにく）猪肉｜韩语参考：돼지고기（猪肉）<br>
  例：この豚肉は１キロいくらですか。（这种猪肉一公斤多少钱？）
- **二人**（ふたり）两个人｜韩语参考：두 사람<br>
  例：二人は何をしているところですか。（你们俩在做什么呢？）
- **二日**（ふつか）两天；二号｜韩语参考：이틀（两天）<br>
  例：それは１週間前、すなわち４月２日に行われた。（那是上周、也就是四月二号举行的。）
- **太い**（ふとい）粗；胖｜韩语参考：굵다（粗，粗大） / 굵다랗다（粗，粗大） / 굵직하다（粗，粗大）<br>
  例：彼は太い首をしている。（他脖子很粗。）
- **冬**（ふゆ）冬天｜韩语参考：겨울（冬天，冬季） / 한겨울（整个冬天）<br>
  例：まもなく冬だ。（冬天快到了。）
- **古い**（ふるい）旧；老｜韩语参考：헌（旧，陈旧，烂，破烂，破） / 오래되다（久，老）<br>
  例：時は金なりと古いことわざにもある。（老话说得好，时间就是金钱。）
- **ふろ**（ふろ）洗澡；浴室｜韩语参考：목욕 / 욕실<br>
  例：私は一日おきにふろに入ります。（我每隔一天洗一次澡。）
- **文章**（ぶんしょう）文章；文笔｜韩语参考：글（文章）<br>
  例：ヘミングウェイの文章は悪文だった。（海明威的文笔很糟糕。）
- **ページ**（ページ）页｜韩语参考：쪽（页） / 페이지（页）<br>
  例：もう３ページ残っている。（还剩三页。）
- **ベッド**（ベッド）床｜韩语参考：침대（床，床铺） / 침상（床，床铺）<br>
  例：どんなベッドでもないよりはよい。（再差的床也比没床强。）
- **ペット**（ペット）宠物｜韩语参考：반려견（宠物狗，伴侣犬） / 반려동물（宠物，伴侣动物） / 애완동물（宠物）<br>
  例：あなたはペットの世話ができない。（你照顾不了宠物。）

## 语法

- **〜です**：是…（礼貌断定）
  接续：名词／な形容词 + です；い形容词 + です
  朝鲜语：입니다（韩语正式礼貌判断常用 입니다，例如 학생입니다、의사입니다；日常礼貌体可用 이에요／예요，形式受词尾影响。日语名词与な形容词常接です。）
- **〜だ**：是…（普通断定）
  接续：名词／な形容词 + だ
  朝鲜语：이다（韩语 이다 是普通体断定，与 だ 对应；但韩语 이다 可随收音变为 이야/야，日语 だ 形式固定，且不能接 です。）

- **代** 代替；时代；费用｜音：ダイ、タイ｜训：か.わる、かわ.る、かわ.り、か.わり、-がわ.り、-が.わり、か.える、よ、しろ
- **明** 明亮；清楚；明智｜音：メイ、ミョウ、ミン｜训：あ.かり、あか.るい、あか.るむ、あか.らむ、あき.らか、あ.ける、-あ.け、あ.く、あ.くる、あ.かす
- **動** 动；移动｜音：ドウ｜训：うご.く、うご.かす
