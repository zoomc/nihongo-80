# Day 054 · 〜ようだ、〜みたい

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜ようだ、〜みたい」造两句自己的话，表达：好像…；似乎…；好像…；像…一样

## 新词 14

- **人口**（じんこう）人口｜朝鲜语：인구<br>
  例：インドの人口はどのくらいですか。（印度的人口有多少？）
- **神社**（じんじゃ）神社｜朝鲜语：신사<br>
  例：京都には多くの神社がある。（京都有很多神社。）
- **親切**（しんせつ）亲切；热心｜朝鲜语：친절<br>
  例：あなたの家族はきっと親切でしょう。（你的家人一定很热心吧。）
- **新聞社**（しんぶんしゃ）报社｜朝鲜语：신문사<br>
  例：どちらの新聞社にお勤めですか。（您在哪家报社工作？）
- **水泳**（すいえい）游泳｜朝鲜语：수영<br>
  例：水泳が私の楽しみの１つです。（游泳是我的乐趣之一。）
- **水道**（すいどう）自来水｜朝鲜语：수도<br>
  例：昨日水道を止められた。（昨天自来水被停了。）
- **ずいぶん**（ずいぶん）相当；很<br>
  例：私たちはもうずいぶん長くここにいます。（我们在这里已经待了很久了。）
- **数学**（すうがく）数学｜朝鲜语：수학<br>
  例：私にはこの数学の問題はわからない。（我解不出这道数学题。）
- **スーツ**（スーツ）西装<br>
  例：スーツを着て彼は目立っていた。（他穿着西装，很显眼。）
- **スーツケース**（スーツケース）行李箱<br>
  例：私は彼にスーツケースを運ばせた。（我让他搬了行李箱。）
- **過ぎる**（すぎる）超过；过度<br>
  例：このスープは、しょっぱ過ぎて飲めないよ。（这汤太咸了，喝不下去。）
- **すく**（すく）空；不挤<br>
  例：どの車両がすいていますか。（哪节车厢比较空？）
- **スクリーン**（スクリーン）屏幕<br>
  例：それらの単語は彼のコンピューター・スクリーンに現れたのだった。（那些词出现在他的电脑屏幕上。）
- **凄い**（すごい）厉害；非常<br>
  例：凄い明かりが野球場にあたっていた。（强烈的灯光照在棒球场上。）

## 语法

- **〜ようだ**：好像…；似乎…
  接续：动词普通形／い形容词 + ようだ；な形容词+な／名词+の + ようだ
  朝鲜语：-(으)ㄴ/는 것 같다（韩语 것 같다 与 ようだ 对应，但日语 ようだ 还常用于比喻和委婉断定；韩语 것 같다 的推测语气更单一。）
- **〜みたい**：好像…；像…一样
  接续：动词普通形／い形容词／な形容词词干／名词 + みたいだ（口语）
  朝鲜语：-(으)ㄴ/는 것 같다 / 처럼（韩语表比喻用 처럼，表推测用 것 같다；日语 みたい 一个形式兼表两者，且接续不随词性变化。）
