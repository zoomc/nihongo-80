# Day 139 · 〜くせに

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜くせに」造两句自己的话，表达：明明…却…

## 新词 22

- **出会う**（であう）遇见；邂逅｜韩语参考：만나다（遇到，遇见，碰见） / 마주치다（邂逅，偶遇）<br>
  例：きのう旧友の一人に出会った。（昨天遇见了一位老朋友。）
- **提案**（ていあん）提议；建议｜韩语参考：제안（提案，提议）<br>
  例：私の提案を承認していただけますか。（能批准我的提案吗？）
- **定期**（ていき）定期｜韩语参考：정기（定期） / 정기권（定期票，月票，季票） / 정기 예금（定期存款）<br>
  例：彼らは定期旅客船に乗り込んだ。（他们登上了定期客轮。）
- **抵抗**（ていこう）抵抗；阻力｜韩语参考：저항（抵抗）<br>
  例：困難に対してあくまでも抵抗した。（面对困难始终抵抗到底。）
- **程度**（ていど）程度｜韩语参考：정도（程度）<br>
  例：この程度のお金じゃ長くは持たないだろう。（这点钱撑不了多久吧。）
- **停留所**（ていりゅうじょ）车站；站点｜韩语参考：정거장（车站） / 정류소（车站） / 정류장（车站）<br>
  例：バスの停留所まで競争しよう。（我们比赛跑到公交站吧。）
- **デート**（デート）约会｜韩语参考：데이트（约会）<br>
  例：アンディはけっしてデートにおくれたことはない。（安迪约会从不迟到。）
- **敵**（てき）敌人；对手｜韩语参考：적（敌，敌人）<br>
  例：彼は敵に不意打ちを食わせた。（他偷袭了对手。）
- **出来事**（できごと）事件；事情｜韩语参考：사건 / 일<br>
  例：このようのしてその出来事は起こった。（那件事就是这样发生的。）
- **適する**（てきする）适合｜韩语参考：적합하다<br>
  例：その肉は全く食用に適さなかった。（那些肉完全不适合食用。）
- **適切**（てきせつ）恰当；合适｜韩语参考：적절하다<br>
  例：「行った」というのが適切な言葉だ。（「去了」才是恰当的词。）
- **適度**（てきど）适度｜韩语参考：적당한 정도<br>
  例：適度の運動は体に良い。（适度的运动对身体有好处。）
- **適用**（てきよう）适用｜韩语参考：적용<br>
  例：この法律はすべての人に適用される。（这条法律适用于所有人。）
- **できれば**（できれば）如果可能的话｜韩语参考：가능하다면<br>
  例：出来れば明日までに帰ります。（可能的话，我明天之前回来。）
- **手品**（てじな）魔术；戏法｜韩语参考：마술（魔术） / 요술（妖术，魔术，妖法）<br>
  例：少年はたくさんの手品が使える。（那个少年会很多魔术。）
- **ですから**（ですから）所以｜韩语参考：그러므로<br>
  例：いいえ、結構です。お腹が一杯ですから。（不用了，谢谢。我已经吃饱了。）
- **鉄**（てつ）铁｜韩语参考：철（铁） / 쇠（铁）<br>
  例：鉄の原子番号は26です。（铁的原子序数是26。）
- **哲学**（てつがく）哲学｜韩语参考：철학（哲学）<br>
  例：哲学は難しいと見なされることが多い。（哲学常被认为是很难的。）
- **手伝い**（てつだい）帮忙；帮手｜韩语参考：도움 / 도우미<br>
  例：台所でお母さんの手伝いをしていたの。（我在厨房帮妈妈干活。）
- **徹底**（てってい）彻底｜韩语参考：철저（彻底，透彻，全面）<br>
  例：生産性はオートメーションの徹底によって向上する。（生产效率通过彻底自动化得到提高。）
- **鉄道**（てつどう）铁路｜韩语参考：철도（铁路，铁道） / 철로（铁路，铁道）<br>
  例：新しい鉄道はまだ完成していない。（新铁路还没有完工。）
- **徹夜**（てつや）通宵｜韩语参考：철야（彻夜，通宵，通宵达旦） / 밤샘（熬夜，通宵）<br>
  例：私はよく徹夜する。（我经常通宵。）

## 语法

- **〜くせに**：明明…却…
  接续：动词普通形/い形容词/ナ形容词な/名词の + くせに
  朝鲜语：-ㄴ 주제에（韩语「-ㄴ 주제에」与「くせに」一样带强烈贬义，对应度很高；但日语语气更冲，正式场合须换「のに」。）
