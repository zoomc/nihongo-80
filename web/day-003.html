今日语法 2 条

韩语对应이것 / 그것 / 저것 / 어느 것
韩语指示三分与日语相同，但修饰名词要用이/그/저且与것分写；日语可直接连体。
これ / それ / あれ / どれ は N です
발음코레 / 소레 / 아레 / 도레 와 N 데스
这/那/那是…
指示代名词 + は + 名詞 + です
コソアド 指示词：近称/中称/远称/疑问
코레와혼데스.
これは本です。
这是书。
소레와이쿠라데스카.
それはいくらですか。
那个多少钱？
易错点

これ は 本です（分写） → これは本です。（指示词后主题助词 は 不能空格分开写）

韩语对应N의 N
韩语의多表所属，口语常省略；修饰关系更常用名词直接并列，使用范围比日语の窄。
N の N
발음N 노 N
…的…；所属/修饰
名詞 + の + 名詞
连体修饰、所属、同位；中文「的」的对应，但不可滥用
와타시노혼데스.
私の本です。
是我的书。
니혼고노센세이데스.
日本語の先生です。
是日语老师。
易错点

私は本です。 → 私の本です。（该用 の 表所属却用 は；中文「我的书」直译成「我 是 书」）
