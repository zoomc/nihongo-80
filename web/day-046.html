Day 046 · 〜んです / 〜のです、〜かどうか、〜か（embedded question）、〜と思う

语法 4 条

〜んです / 〜のです
발음〜ㄴ데스 / 〜노데스
（解释）是…的；因为…
动词普通形／い形容词 + んです；な形容词+な／名词+な + んです
用于说明原因、补充背景，或向对方寻求解释，口语色彩强。
韩语对应-ㄴ/는 것이다 / -거든요
韩语 -거든요 与 んです 的解释语气接近，但日语 んです 还可用于提问求解释；韩语 거든요 只用于陈述。
どうしたんですか。顔色が悪いですよ。
怎么了？你脸色不太好。
스미마센, 오쿠레마시타. 덴샤 가 토마떼이탄데스.
すみません、遅れました。電車が止まっていたんです。
对不起我迟到了，因为电车停运了。
니혼고 데 테가미 오 카키타인데스가, 테쓰다떼쿠레마센 카.
日本語で手紙を書きたいんですが、手伝ってくれませんか。
我想用日语写封信，你能帮我吗？
易错易混点
  • ✗ 電車が止まっていたのだです。✓ 電車が止まっていたんです。のだ 接礼貌体是「のです」，不能作「のだです」
〜かどうか
발음〜카도우카
是否…
动词、い形容词普通形 + かどうか；名词、な形容词非过去肯定词干直接接，或用 なのかどうか。
把是非疑问句嵌入句中，表示不确定或需要确认。
韩语对应-인지 아닌지
오는지 아닌지 对照 来るかどうか，장소가 맞는지 对照 場所が合っているかどうか。有 どこ、誰 等疑问词时，用单独的 か 嵌入问句。
明日行けるかどうか、まだ分かりません。
明天能不能去，我还不知道。
코노후쿠 가 니아우 카 도우 카, 초또키테미마스.
この服が似合うかどうか、ちょっと着てみます。
这件衣服合不合适，我试穿一下。
소노레스토란 가 오이시이 카 도우 카, 토모다치 니 키이테미요우.
そのレストランがおいしいかどうか、友達に聞いてみよう。
那家餐厅好不好吃，问问朋友吧。
易错易混点
  • ✗ 明日行けるかどうかを、まだ分かりません。✓ 明日行けるかどうか、まだ分かりません。分かる 的对象用 が 或直接提示，不用 を
〜か（embedded question）
발음〜카
（嵌入）什么…、哪里…
疑问词 + …普通形 + か
把含疑问词的问句嵌入句中作宾语或主语，句末不用疑问助词。
韩语对应-인지
어디서 열리는지 对照 どこで開かれるか。嵌入问句的 か 留在句内；外层句若也是问话，可另用 か，如 どこで開かれるか知っていますか。
카이기 가 난지 니 하지마루 카, 오시에테쿠다사이.
会議が何時に始まるか、教えてください。
请告诉我会议几点开始。
도코 데 사이후 오 나쿠시타 카, 오보에테이마센.
どこで財布をなくしたか、覚えていません。
我不记得在哪里丢了钱包。
誰が窓を割ったか、知っていますか。
你知道是谁打破了窗户吗？
易错易混点
  • ✗ 会議が何時に始まるかどうか、教えてください。✓ 会議が何時に始まるか、教えてください。何時 是疑问词，只能用「か」，不能再用「かどうか」
〜と思う
발음〜토오모우
我认为…
动词普通形／い形容词 + と思う；な形容词・名词 + だ + と思う
表示说话人的判断或意见，礼貌体用「と思います」缓和语气。
韩语对应-다고 생각하다
조용하다고 생각해요 对照 静かだと思います。日语 な形容词、名词肯定谓语在 と 前加 だ；动词和い形容词普通形直接接 と。
코노에이가 와 키또닌키 가 데루 토 오모우.
この映画はきっと人気が出ると思う。
我觉得这部电影一定会受欢迎。
카노조 와 쿄우 와 코나이 토 오모이마스.
彼女は今日は来ないと思います。
我想她今天不会来。
니뽄 노 덴샤 와 토테모벤리다 토 오모이마스.
日本の電車はとても便利だと思います。
我觉得日本的电车非常方便。
易错易混点
  • ✗ この映画はきっと人気が出るだと思う。✓ この映画はきっと人気が出ると思う。动词普通形直接接 と思う，不加 だ
