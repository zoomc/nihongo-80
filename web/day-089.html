③ 语法 6 分钟

V辞書形 / Nの + たびに
動詞辞書形 + たびに；名詞 + の + たびに（する名詞可直接 するたびに）
每当…就…；每次…都…

表示每次发生前项时，后项都随之发生；后项多为反复出现的习惯或自然结果，不用一次性的命令、请求。

大阪へ出張するたびに、この店に寄ります。
每次去大阪出差，都会来这家店。
会議のたびに、資料を準備します。
每次开会都准备资料。
朝鲜语：-(으)ㄹ 때마다
韩语때마다表每当，接名词或动词定语形；日语たびに只接辞书形或の，后项限制更严。

易错：大阪へ出張するのたびに、この店に寄ります。 → 大阪へ出張するたびに、この店に寄ります。（辞书形后接 たびに 不加 の；の 只能接名词。中文“每次去…”直译容易多写の。）

V辞書形 / Vた形 / Nの + ついでに
動詞辞書形/た形 + ついでに；名詞 + の + ついでに
顺便…；借…之便…

做主要事情时，顺便做另一件次要事情；次要动作通常耗时短、顺路。

駅へ行くついでに、切符を買いました。
去车站时顺便买了车票。
資料を届けるついでに、部長に挨拶しました。
送资料时顺便向部长打了招呼。
朝鲜语：-는 김에
韩语는 김에表顺便，隐含「既然…就」的语气；日语ついでに纯表顺便，不含既然义。

易错：駅へ行くのついでに、切符を買いました。 → 駅へ行くついでに、切符を買いました。（辞书形后接 ついでに 不加 の；の 只能接名词。）
