# Day 079 · 〜わけにはいかない、〜ものだ

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜わけにはいかない、〜ものだ」造两句自己的话，表达：不能…；不便…；本来就…；应当…；过去常…

  例：彼女は多くの学校の活動に参加する。（她参加很多学校活动。）

## 语法

- **〜わけにはいかない**：不能…；不便…
  接续：动词辞书形 + わけにはいかない；动词ない形 + わけにはいかない
  朝鲜语：-ㄹ 수는 없다（韩语「-ㄹ 수는 없다」偏“能力或情况不允许”；日语「わけにはいかない」强调社会道义上的“不能”，含无奈。）
- **〜ものだ**：本来就…；应当…；过去常…
  接续：动词辞书形/た形 + ものだ；い形容词 + ものだ；ナ形容词 + な + ものだ
  朝鲜语：-는 법이다（韩语「-는 법이다」只表“理应如此”；日语「ものだ」还能用た形表“过去常常”，对应韩语「-곤 했다」，分工不同。）
