# Day 007 · い形容词（～い です）、な形容词（～です）、ます形（丁寧体）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 新词 25

- **明るい**（あかるい）明亮；开朗｜韩语参考：밝다（明亮） / 환하다（明亮，亮，亮堂）<br>
  例：外はだんだん明るくなっていく。（外面渐渐亮了起来。）
- **秋**（あき）秋天｜韩语参考：가을（秋天，秋季） / 가을날（秋日，秋天） / 가을철（秋季，秋天）<br>
  例：秋はもうすぐそこまで来ている。（秋天马上就要到了。）
- **開く**（あく）（门窗等）打开；（店）开门（自动词）｜韩语参考：열리다（开）<br>
  例：九時に店が開きます。（店九点开门。）
- **開ける**（あける）打开｜韩语参考：열다（打开）<br>
  例：ドアはジムによって開けられます。（门被吉姆打开了。）
- **上げる**（あげる）举起；给｜韩语参考：주다（给予，给） / 쳐들다（举起，抬起，撑起） / 추켜들다（高举，举起）<br>
  例：左手を上げなさい。（把左手举起来。）
- **朝ごはん**（あさごはん）早饭｜韩语参考：아침밥<br>
  例：朝ごはんにはなにがよろしいですか。（早饭您想吃点什么？）
- **あさって**（あさって）后天｜韩语参考：모레<br>
  例：あさって彼にここへ来てもらうつもりです。（打算后天让他来这儿。）
- **足**（あし）脚；腿｜韩语参考：굽（底座，脚） / 발（足，脚） / 다리（腿，下肢）<br>
  例：また足がしびれた。（脚又麻了。）
- **あそこ**（あそこ）那里｜韩语参考：게（那儿，那里） / 거기（那儿，那里） / 고기（那儿，那里）<br>
  例：あそこにバス停があります。（那边有个公交站。）
- **遊ぶ**（あそぶ）玩；游玩｜韩语参考：놀이하다（玩耍，玩）<br>
  例：ビルはよく一人でおもちゃで遊ぶ。（比尔常一个人玩玩具。）
- **暑い**（あつい）热｜韩语参考：덥다（热，暑）<br>
  例：どうして、こんなに暑いのですか。（为什么这么热呢？）
- **熱い**（あつい）烫；热｜韩语参考：덥다（温，热，热乎乎） / 뜨겁다（烫，热）<br>
  例：熱いコーヒーを入れてあげましょう。（我给你冲杯热咖啡吧。）
- **あっち**（あっち）那边｜韩语参考：고쪽（那里，那边） / 그쪽（那里，那边）<br>
  例：こっちの本はあっちの本よりやさしい。（这边的书比那边的书容易。）
- **あの**（あの）那个｜韩语参考：그（那个） / 어（那个） / 조（那个）<br>
  例：あのおいしいワインをなぜ飲まないんだい。（为什么不喝喝那瓶好酒呢。）
- **アパート**（アパート）公寓｜韩语参考：아파트（公寓）<br>
  例：兄はアパートをさがしています。（哥哥在找公寓。）
- **あびる**（あびる）淋浴；沐浴｜韩语参考：씻다 / 뒤집어쓰다<br>
  例：朝、シャワーをあびます。（我早上淋浴。）
- **甘い**（あまい）甜；天真｜韩语参考：달다（甜，甘甜）<br>
  例：メアリーにはつい甘くなってしまう。（对玛丽我总是狠不下心。）
- **あまり**（あまり）不太｜韩语参考：별로（부정과 함께）<br>
  例：この手の本はあまり読まない。（这类书我不太读。）
- **飴**（あめ）糖果｜韩语参考：캔디（糖果，糖）<br>
  例：この飴はレモンの味がします。（这颗糖有柠檬味。）
- **洗う**（あらう）洗｜韩语参考：감다（洗） / 빨다（洗） / 씻다（洗，刷）<br>
  例：いつこの車は洗われましたか。（这辆车是什么时候洗的？）
- **ありがとう**（ありがとう）谢谢｜韩语参考：고마워<br>
  例：はるばる来てくれてありがとう。（谢谢你远道而来。）
- **歩く**（あるく）走；步行｜韩语参考：걷다（走，行走，步行）<br>
  例：歩いて行きますか？それともバスで行きますか？（你走路去还是坐公交去？）
- **あれ**（あれ）那个｜韩语参考：거（那个） / 그（那样，那个） / 거기（那个）<br>
  例：あれは学校です。（那是学校。）
- **いい**（いい）好；可以｜韩语参考：좋다 / 괜찮다<br>
  例：もう２、３ページ読みさえすればいい。（只要再读两三页就行了。）
- **いいえ**（いいえ）不；不是｜韩语参考：아뇨（不用，不是） / 아니요（不是，不用）<br>
  例：いいえ、学生ではありません。（不，我不是学生。）

## 语法

- **い形容词（～い です）**：…（い形容词谓语）
  接续：い形容詞 + です
  朝鲜语：형용사 어간 + 다 / -아·어요（비싸요 已在形容词内部变出礼貌词尾。日语 高い 自己承载活用，可直接结句；礼貌体 高いです 保留 い。）
- **な形容词（～です）**：…（な形容词谓语）
  接续：な形容詞語幹 + です／だ
  朝鲜语：조용하다 → 조용한 방（用 조용해요 对照 静かです，用 조용한 방 对照 静かな部屋。な 只在 静か 直接修饰名词时出现。）
- **ます形（丁寧体）**：动词礼貌形：ます／ません／ました／ませんでした
  接续：五段：う段→い段 + ます；一段：去 る + ます；する→します；来る（くる）→来ます（きます）
  朝鲜语：-습니다/ㅂ니다 / -아·어요（읽습니다／읽어요 都有礼貌，分属不同语体。日语动词礼貌体先掌握一套 ます 活用，遇到敬语动词再按对象选词。）
