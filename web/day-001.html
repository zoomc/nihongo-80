③ 语法 7 分钟

N は N です
名詞 + は + 名詞 + です
…是…

判断句，介绍身份/事物，礼貌体

私は学生です。
我是学生。
これは本です。
这是书。
朝鲜语：입니다 / 이에요
韩语敬语由终结词尾입니다/이에요承担，日语靠です；名词后还须按有无收音选은/는。

易错：私は学生だ。 → 私は学生です。（「私は学生だ。」本身是合法的普通体，不是错句；但本题要求礼貌体，所以句末要用 です。需要区分「语法错误」和「语体不匹配」。）

〜か（or）
名词 + か + 名词
…或…

表示两个以上选项中的选择，可用于陈述或疑问。

飲み物はコーヒーか紅茶がいいです。
饮料咖啡或红茶都行。
土曜日か日曜日に買い物に行きます。
我星期六或星期天去买东西。
駅までバスかタクシーで行きます。
坐公交车或出租车去车站。
朝鲜语：나/이나
韩语 나/이나 兼表选择和列举，日语 か 表选择、や 表列举，分工更明确。

易错：飲み物はコーヒーと紅茶かがいいです。 → 飲み物はコーヒーか紅茶がいいです。（表选择时用「AかB」，不能与 と 混用）
