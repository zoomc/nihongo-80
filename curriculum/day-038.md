# Day 038 · ～かもしれない / ～でしょう、～なければ ならない

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～かもしれない / ～でしょう、～なければ ならない」造两句自己的话，表达：也许…／大概…吧；必须…／不得不…

## 新词 19

- **調べる**（しらべる）调查；查阅｜韩语参考：조사하다 / 찾아보다<br>
  例：図書館で言葉を調べます。（在图书馆查词。）
- **比べる**（くらべる）比较｜韩语参考：견주다（比较，较量） / 비기다（比较，相提并论） / 비하다（比较）<br>
  例：二つの店の値段を比べます。（比较两家店的价格。）
- **慣れる**（なれる）习惯（自动）｜韩语参考：젖다（习惯） / 길들다（磨合，顺手，习惯） / 익숙하다（熟悉，习惯）<br>
  例：日本の生活に慣れました。（我习惯了日本的生活。）
- **遅れる**（おくれる）迟到；落后｜韩语参考：늦다（晚，迟到） / 뒤지다（落后，亚于） / 처지다（落下，落后，落伍）<br>
  例：会議に遅れてしまいました。（开会迟到了。）
- **間に合う**（まにあう）赶得上；来得及｜韩语参考：시간에 맞다 / 늦지 않다<br>
  例：急げば、始発に間に合います。（快点的话能赶上首班车。）
- **足りる**（たりる）够；足够｜韩语参考：족하다（足够，充足） / 충분하다（充分，充足，足够）<br>
  例：時間が足りません。（时间不够。）
- **挨拶**（あいさつ）寒暄；问候；致辞｜韩语参考：인사（问候，打招呼）<br>
  例：先生に挨拶をします。（向老师打招呼。）
- **お願い**（おねがい）请求；拜托｜韩语参考：부탁（拜托，请求，托付）<br>
  例：ちょっとお願いがあります。（有件事想拜托你。）
- **説明**（せつめい）说明；解释｜韩语参考：설명（说明）<br>
  例：使い方を説明してください。（请说明一下用法。）
- **準備**（じゅんび）准备（筹备）｜韩语参考：준비（准备） / 채비（准备，筹备）<br>
  例：旅行の準備をしています。（正在做旅行的准备。）
- **練習**（れんしゅう）练习｜韩语参考：연습（练习）<br>
  例：毎日ピアノを練習します。（每天练习钢琴。）
- **掃除**（そうじ）打扫；扫除｜韩语参考：소제（打扫，清扫） / 청소（打扫，清扫，扫除）<br>
  例：部屋を掃除します。（打扫房间。）
- **洗濯**（せんたく）洗衣服；洗涤｜韩语参考：빨래（洗衣，洗衣服） / 세탁（洗衣）<br>
  例：週末に洗濯をします。（周末洗衣服。）
- **約束**（やくそく）约定；约会｜韩语参考：약속（约定，约好，承诺）<br>
  例：友達と映画の約束をしました。（和朋友约好了看电影。）
- **心配**（しんぱい）担心｜韩语参考：걱정（担心，忧虑，担忧） / 근심（担心，担忧） / 염려（顾虑，惦记，担心，挂念）<br>
  例：母は私のことを心配しています。（妈妈在担心我。）
- **安心**（あんしん）放心；安心｜韩语参考：안도（安心） / 안심（安心，放心）<br>
  例：無事だと聞いて安心しました。（听说平安就放心了。）
- **興味**（きょうみ）兴趣；好奇｜韩语参考：관심（关注，关心，兴趣） / 재미（兴趣，趣味） / 취미（兴趣）<br>
  例：日本の歴史に興味があります。（我对日本历史感兴趣。）
- **上手**（じょうず）擅长；拿手｜韩语参考：잘하다 / 능숙하다<br>
  例：彼女は料理が上手です。（她做饭很拿手。）
- **下手**（へた）不擅长；笨拙｜韩语参考：서투르다 / 못하다<br>
  例：私は歌が下手です。（我唱歌不行。）

## 语法

- **～かもしれない / ～でしょう**：也许…／大概…吧
  接续：普通形 + かもしれない；普通形 + でしょう
  朝鲜语：-(으)ㄹ지도 모르다 / -겠다（韩语不确定用ㄹ지도 모르다，较强推量用겠다或ㄹ 것이다；でしょう无对应敬语分层。）
- **～なければ ならない**：必须…／不得不…
  接续：動詞ない形（去ない） + ければ + ならない
  朝鲜语：-아/어야 하다 / -지 않으면 안 되다（韩语义务用아/어야 하다，更强用아/어야만 하다；敬语하셔야 합니다，日语无此分层。）
