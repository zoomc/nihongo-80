九 九

音读：キュウ、ク
训读：ここの、ここのつ
韩语字音：구

中文读 jiǔ；日语「九時」くじ、「九日」ここのか 训读；两音读 キュウ/ク 并存，「九」不可一律读 きゅう。

十 十

音读：ジュウ、ジッ
训读：とお
韩语字音：십

中文读 shí；日语「十日」とおか 训读，「十」音读 じゅう；「十分」じゅっぷん/じっぷん 促音便，ジッ 音读在复合中出现。

百 百

音读：ヒャク
训读：无常用训读
韩语字音：백

中文读 bǎi；日语「百」基本只用音读 ひゃく，「百円」ひゃくえん；「三百」さんびゃく 浊音便；训读 もも 极罕见。

円 日元；圆

音读：エン
训读：无常用训读
韩语字音：원
日语货币单位在韩语通常称 엔；圓 的汉字音是 원。
中文「元/圆」；日语「円」是货币单位 えん，旧字体「圓」；不可望文生义写成「元」，也不可理解成「圆形」（圆形是 円形 えんけい 但义不同）。

時 时；时刻

音读：ジ
训读：とき
韩语字音：시

中文读 shí；日语「時」音读 じ（三時 さんじ）、训读 とき（时候）；「時計」とけい、「時間」じかん 全音读，一词两读。

③ 语法 6 分钟

N の N
名詞 + の + 名詞
…的…；所属/修饰

连体修饰、所属、同位；中文「的」的对应，但不可滥用

私の本です。
是我的书。
日本語の先生です。
是日语老师。
朝鲜语：N의 N
韩语의多表所属，口语常省略；修饰关系更常用名词直接并列，使用范围比日语の窄。

易错：私は本です。 → 私の本です。（该用 の 表所属却用 は；中文「我的书」直译成「我 是 书」）

が（主语／新信息／存在主体）
名詞 + が + 動詞／形容詞
…（主语/新信息/存在主体/能力对象）

表主语、新信息、疑问词主语、存在主体、能力/好恶对象

猫がいます。
有猫。
誰が来ますか。
谁来？
朝鲜语：이/가
韩语主格助词按收音选이/가，口语가常被는替换表对比；日语が还表能力对象。

易错：私がは学生です。 → 私は学生です。（が 与 は 不能叠加；自我介绍用 は 提示主题，が 标记新信息焦点（如「誰が学生ですか」→「私が学生です」），两者分工不同。）
