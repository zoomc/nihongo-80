## 语法

- **〜にしても**：即使…；就算是…
  接续：动词普通形／名词 + にしても；名词化的 の + にしても 也可用
  朝鲜语：-다고 해도（韩语「-다고 해도」与「にしても」对应；但日语常隐含责备，韩语语气更中性，需靠上下文补出不满。）
- **〜に関して / 〜に関する**：关于…；就…
  接续：名词 + に関して；名词 + に関する／に関しての + 名词
  朝鲜语：-에 관해서（韩语「-에 관해서」表示关于；修饰名词时日语可用「に関する」或「に関しての」，韩语可用「-에 관한」。）
- **〜に比べて**：与…相比
  接续：名词 + に比べて；动词辞书形 + のに比べて
  朝鲜语：-에 비해서（韩语「-에 비해서」与「に比べて」完全对应；但日语还可用「のに比べて」接动词小句，韩语需名词化。）
