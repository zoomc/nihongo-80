# Day 115 · 〜にしては、〜にしても

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜にしては、〜にしても」造两句自己的话，表达：照…来说；以…而言；即使…；就算是…

## 新词 14

- **作業**（さぎょう）作业；工作｜韩语参考：작업（工作，作业 ，劳动）<br>
  例：私がいない間も作業を続けなさい。（我不在的时候也继续干活。）
- **昨**（さく）昨｜韩语参考：지난 / 어제<br>
  例：彼は昨シーズンで野球をやめました。（他上个赛季退出了棒球。）
- **作品**（さくひん）作品｜韩语参考：작품（作品，制品）<br>
  例：これは母の作品の一つです。（这是我妈妈的作品之一。）
- **作物**（さくもつ）农作物｜韩语参考：작물（作物） / 농작물（农作物）<br>
  例：日本の主要作物は米である。（日本的主要作物是水稻。）
- **桜**（さくら）樱花｜韩语参考：벚꽃（樱花） / 벚나무（樱花树）<br>
  例：桜もそろそろじゃないでしょうか。（樱花是不是快开了？）
- **酒**（さけ）酒｜韩语参考：술（酒）<br>
  例：僕は酒も煙草もやらないんだ。（我既不喝酒也不抽烟。）
- **叫ぶ**（さけぶ）喊叫｜韩语参考：치다（喊叫，呼喊） / 지르다（喊叫）<br>
  例：彼女は子供たちに静かにと叫んだ。（她冲孩子们喊「安静」。）
- **避ける**（さける）避开｜韩语参考：피하다<br>
  例：あなたはいやな経験を避けるかもしれない。（你也许能避开不愉快的经历。）
- **支える**（ささえる）支撑；支持｜韩语参考：받치다（支援，支持） / 이기다（支撑） / 떠받치다（支撑，维系）<br>
  例：なんとかそこで支えよ。入市を許すな。（想办法在那里顶住，别让他们进城。）
- **指す**（さす）指；指向｜韩语参考：짚다（指） / 가리키다（指，指着，指出）<br>
  例：＆という記号は、ａｎｄを指す。（「＆」这个符号指的是 and。）
- **座席**（ざせき）座位｜韩语参考：좌석（坐席，座位） / 자리（座位，席位）<br>
  例：鞄を座席の下に置いてください。（请把包放在座位下面。）
- **誘う**（さそう）邀请；引诱｜韩语参考：권하다 / 유혹하다<br>
  例：ウラウラとした日差しに誘われて、眠りに落ちた。（暖洋洋的阳光让人犯困，我不知不觉睡着了。）
- **札**（さつ）纸币｜韩语参考：지폐<br>
  例：１０００円札をくずしていただけませんか。（能帮我把一千日元换开吗？）
- **作家**（さっか）作家｜韩语参考：작가（作家）<br>
  例：その作家は私たちによく知られています。（那位作家我们很熟悉。）

## 语法

- **〜にしては**：照…来说；以…而言
  接续：动词普通形／名词 + にしては；名词化的 の + にしては 也可用
  朝鲜语：-치고는（韩语「-치고는」与「にしては」几乎一一对应，都含“出乎预料”；但日语多接身份、时间名词。）
- **〜にしても**：即使…；就算是…
  接续：动词普通形／名词 + にしても；名词化的 の + にしても 也可用
  朝鲜语：-다고 해도（韩语「-다고 해도」与「にしても」对应；但日语常隐含责备，韩语语气更中性，需靠上下文补出不满。）
