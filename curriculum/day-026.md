# Day 026 · 〜の（possessive）、〜から（from）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜の（possessive）、〜から（from）」造两句自己的话，表达：…的…；从…（起点）

  例：もう手が冷たくって。（我的手都冻僵了。）

  例：日本の生活はどうですか。（在日本的生活怎么样？）
- **どうして**（どうして）为什么<br>
  例：どうしてあなたは一人になったの？（你怎么会变成一个人了？）

## 语法

- **〜の（possessive）**：…的…
  接续：名词 + の + 名词
  朝鲜语：의（韩语 의 与 の 对应，但口语中 의 常省略；日语 の 不能省略，且还可代替名词（私の）。）
- **〜から（from）**：从…（起点）
  接续：名词 + から（起点）
  朝鲜语：부터 / 에서（韩语时间起点用 부터，场所起点用 에서；日语 から 两者通用，范围更宽。）
