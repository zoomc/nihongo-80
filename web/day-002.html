Day 002 · N は N ではありません / じゃない、N は N でした、N も

语法 3 条

N は N ではありません / じゃない
발음N 와 N 데와아리마센 / 자나이
…不是…
名词 + ではありません／じゃありません（礼貌体）；名词 + ではない／じゃない（普通体）
名词谓语的非过去否定，按场合选礼貌体或普通体。
韩语对应이/가 아닙니다
학생이 아닙니다、의사가 아닙니다 按收音选 이/가。日语名词后直接接 ではありません，熟人间常说 じゃない。
와타시 와 센세이 데 와 아리마센.
私は先生ではありません。
我不是老师。
易错易混点
  • ✗ 私は先生ないです。✓ 私は先生ではありません。“不是”要用 ではありません（口语 じゃない），不能只留 ない。少了 では，听起来像“老师＋没有”。
N は N でした
발음N 와 N 데시타
…（过去）是…
名詞 + は + 名詞 + でした
判断句过去式，礼貌体
韩语对应이었습니다 / 였습니다
韩语过去按有无收音选이었/였，且分层级；日语でした只有一形，无收音条件。
키노우 와 니치요우비데시타.
昨日は日曜日でした。
昨天是周日。
易错易混点
  • ✗ 昨日は日曜日だったです。✓ 昨日は日曜日でした。名词句的客气过去是 でした；だった 是它的简体形，两个不能叠在一起。
N も
발음N 모
…也…
名詞 + も（替代 は/が/を）
表同类追加；替代格助词，不与 は 叠加
韩语对应도
韩语 도 和日语 も 都可表示追加，常替换主格或宾格助词；叠加其他助词须按具体语境判断。
와타시 모 가쿠세이데스.
私も学生です。
我也是学生。
易错易混点
  • ✗ 私はも学生です。✓ 私も学生です。「も」本身就含“也”，要把 は 换掉，不能写成 は＋も。
  • ✗ 私を学生です。✓ 私も学生です。「も」不是宾格助词，写不成 を。“我也…”就是 私も。
