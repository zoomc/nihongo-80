# Day 008 · 租房与邻居｜（场所）に ～ がある / いる、い形容词（～い です）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在「租房与邻居」场景里，用 （场所）に ～ がある / いる 说清一件事

## 新词 19

- **いる**（いる）有；在（有生命）  
  例：部屋に猫がいます。（房间里有猫。）
- **なる**（なる）变成；成为  
  例：医者になりました。（当上医生了。）
- **書く**（かく）写  
  例：名前を書いてください。（请写名字。）
- **読む**（よむ）读；念  
  例：本を読みます。（读书。）
- **話す**（はなす）说；讲  
  例：日本語を話します。（说日语。）
- **聞く**（きく）听；问  
  例：音楽を聞きます。（听音乐。）
- **待つ**（まつ）等；等待  
  例：駅で友達を待ちます。（在车站等朋友。）
- **乗る**（のる）乘；坐（车船）  
  例：電車に乗ります。（上电车。）
- **降る**（ふる）下（雨、雪等）  
  例：雨が降っています。（正在下雨。）
- **起きる**（おきる）起床；起来  
  例：七時に起きます。（七点起床。）
- **借りる**（かりる）借（入）；向人借  
  例：図書館で本を借ります。（在图书馆借书。）
- **教える**（おしえる）教；告诉  
  例：日本語を教えます。（教日语。）
- **帰る**（かえる）回；回家  
  例：家に帰ります。（回家。）
- **休む**（やすむ）休息；请假；睡  
  例：会社を休みます。（向公司请假。）
- **分かる**（わかる）懂；明白  
  例：日本語が分かります。（懂日语。）
- **高い**（たかい）贵；高  
  例：この本は高いです。（这本书贵。）
- **安い**（やすい）便宜  
  例：電車よりバスのほうが安いです。（公交比电车便宜。）
- **大きい**（おおきい）大  
  例：大きい家です。（大房子。）
- **小さい**（ちいさい）小  
  例：小さい部屋です。（小房间。）

## 语法

- **（场所）に ～ がある / いる**：（某地）有…
  接续：場所 + に + 物/人 + が + ある／いる
  朝鲜语：에 ~ 이/가 있다 / 계시다（韩语存在动词不分有无生命，一律있다，敬语用계시다；日语必须分ある/いる。）
- **い形容词（～い です）**：…（い形容词谓语）
  接续：い形容詞 + です
  朝鲜语：형용사 어간 + 다 / -아·어요（韩语形容词作谓语要加终结词尾，敬语靠어요/습니다；日语い形直接加です。）
