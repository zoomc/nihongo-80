今日语法 2 条

V辞書形 + ため(に) / 普通形・N の + ため(に)
目的：意志动词 辞書形 + ため(に)；原因：普通形（多为 た形/ている/ない）或 名詞 + の + ため(に)
V辞書形 + ため(に) / 普通形・N の + ため(に)
为了…（目的）／因为…、由于…（原因）
目的句后项须是意志动作；原因句多接客观、非意志结果（事故・遅刻等），偏书面/正式，に 可省
日本語を勉強するために、日本に来ました。
为了学日语来了日本。
渋滞のために、会議に遅れました。
因为堵车，开会迟到了。
朝鲜语：-기 위해(서) / -때문에
韩语目的用기 위해(서)，原因用때문에；日语ために两义同形，须靠后项判断。
易错点

日本語を勉強したために、来ました。 → 日本語を勉強するために来ました。（目的用 辞书形 勉強する；た形 变成「因为学了日语」原因义，中文「为了」直译用过去式错）

普通形 + のに（な形・名詞 は 〜な のに）
動詞・い形 普通形 + のに；な形・名詞 + な + のに；后项是与预期相反的结果
普通形 + のに（な形・名詞 は 〜な のに）
明明…却…；…却（意外、不满、遗憾）
逆接，带说话人意外/责备/遗憾情绪；比 が/けど 情绪强
たくさん勉強したのに、合格できませんでした。
明明学了很多却没考上。
今日は日曜日なのに、仕事に行きます。
明明是周日却要去上班。
朝鲜语：-는데도 / -(으)ㄴ데도
韩语逆接用는데도，带不满或意外；日语のに情绪更强，还能置于句末表遗憾。
易错点

高いのにを買いました。 → 高いのに買いました。（「のに」后不再接 を 等格助词提示前项；中文「虽然贵」直译叠加助词错）
