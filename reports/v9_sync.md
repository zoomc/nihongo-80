# v9 私人复习同步

`nh80 study-sync` 调用 `scripts/study_sync.py::run(root, base, key, push_only=False)`。密钥由 CLI 提供，模块不读取凭据文件、不输出密钥。每个站点的作答和自评游标分别保存在 SQLite meta；拉取每页 500 条、每类最多 20000 条，并检查顺序和结构。作答经现有 cloud_sync 组装和 CLI 本地重判；相同会话按 40 条分批，保证跨页不会丢失。自评按事件 ID 幂等，只调整 FSRS 排期，不判掌握。拉取或导入失败不推进任一游标；已导入部分可安全重试。

同步生成私有 `data/review/context.json` 和 `data/review/CONTEXT.md`，以实际 FSRS 到期卡为先，并附历史错误、自评遗忘/不熟及待处理任务。投影只发送到期知识 ID、时间、阶段和优先级；同一知识点的能力卡取最早到期项。发布失败保留本地结果，返回 `published: false`，可重试；`push_only` 只生成并发布本地状态。上下文需会话显式读取，不代表平台自动传递。

验证：用 SQLite 只读备份的临时隔离副本和本地假 HTTP 服务，检查 501 条跨页、伪造正确结果被本地判错、自评重复同步不重复排期、未知题失败不推进游标、发布失败仍生成本地文件。没有写真实库、访问线上服务或部署。验证不等同生产 Worker 与真实浏览器端到端验收。

补传自评按本机导入时刻进入 FSRS，服务端原始时间记入审计；已有卡时间异常地晚于导入时刻时拒绝并保持游标。回归测试先复现旧自评将 `last_review` 从 11 月 7 日回拨到 11 月 5 日，再验证修复后用 11 月 8 日导入时刻且保留原始时间。
