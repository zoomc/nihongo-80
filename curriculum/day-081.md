# Day 081 · 〜てしょうがない / 〜てしかたがない、〜てたまらない、〜てはじめて

- 阶段：P4｜60 分钟｜听力日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 新词 25

- **他人**（たにん）别人；外人｜韩语参考：남（别人，他人，人家） / 외인（外人）<br>
  例：彼女はもっと他人の言うことを聞くべきだ。（她应该多听听别人的话。）
- **種**（たね）种子；起因｜韩语参考：씨（种子，籽） / 불씨（导火线，起因，诱因） / 씨앗（种子）<br>
  例：そんなことをすれば笑いものの種なるよ。（做那种事会被人当成笑柄的。）
- **束**（たば）把；捆｜韩语参考：꼭지（把） / 묶음（捆，束） / 뭉치（团，捆，束）<br>
  例：彼は古い手紙を束にした。（他把旧信捆成了一捆。）
- **度**（たび）次；回（〜度に＝每当…）｜韩语参考：번 / 차례<br>
  例：この曲を聞く度に故郷を思い出す。（每次听到这首曲子，我都会想起故乡。）
- **旅**（たび）旅行｜韩语参考：여행（旅行，旅游，游行）<br>
  例：旅はよりよい教育法の一つである。（旅行是较好的教育方式之一。）
- **たびたび**（たびたび）屡次；多次｜韩语参考：자주 / 여러 번<br>
  例：私はたびたび彼から手紙をもらう。（我常收到他的来信。）
- **玉**（たま）球；硬币｜韩语参考：공 / 구슬 / 동전<br>
  例：ニッケルは５セント玉です。（镍币是五美分的硬币。）
- **たまに**（たまに）偶尔｜韩语参考：가끔<br>
  例：たまに近所のカフェで本を読む。（我偶尔在附近的咖啡馆看书。）
- **弾**（たま）子弹｜韩语参考：탄환<br>
  例：弾が彼の頬をかすめた。（子弹擦过他的脸颊。）
- **たまたま**（たまたま）偶然；碰巧｜韩语参考：우연히（偶然地）<br>
  例：通りを歩いていたとき、私はたまたま旧友に出会った。（走在街上时，我碰巧遇见了老朋友。）
- **たまらない**（たまらない）受不了；极其｜韩语参考：견딜 수 없다 / 몹시<br>
  例：あのカメラが欲しくてたまらない。（我特别想要那台相机。）
- **黙る**（だまる）沉默；不说话｜韩语参考：침묵하다（沉默，旁观，袖手旁观）<br>
  例：もうこれ以上、黙ってられないわ。（我再也不能保持沉默了。）
- **試し**（ためし）尝试｜韩语参考：시도（试图，尝试） / 맛보기（尝试，体验）<br>
  例：私は試しにその山に登ってみた。（我试着爬了那座山。）
- **試す**（ためす）试；测试｜韩语参考：시험하다<br>
  例：もう一度試したが失敗しただけだった。（我又试了一次，结果还是失败。）
- **単位**（たんい）单位；学分｜韩语参考：단위（单位） / 학점（学分）<br>
  例：この科目は何単位ですか。（这门课有几个学分？）
- **単語**（たんご）单词｜韩语参考：단어（单词，词汇） / 낱말（单词，词语）<br>
  例：これらの単語を一つずつ覚えなさい。（把这些单词一个一个记住。）
- **男子**（だんし）男子；男生｜韩语参考：남자（男子，男人）<br>
  例：このクラスは女子が男子より多いです。（这个班女生比男生多。）
- **単純**（たんじゅん）单纯；简单｜韩语参考：단순（单纯，单一）<br>
  例：彼の話は単純そのものだった。（他的话简单得不能再简单。）
- **誕生**（たんじょう）诞生；出生｜韩语参考：탄생（诞生）<br>
  例：生命はいつ誕生したのですか。（生命是什么时候诞生的？）
- **ダンス**（ダンス）舞蹈｜韩语参考：춤（舞蹈）<br>
  例：ダンスはスタイルをよくするのにいい。（跳舞对保持身材有好处。）
- **団体**（だんたい）团体｜韩语参考：단체（团体，集体，团伙）<br>
  例：彼女はこの団体の会員である。（她是这个团体的会员。）
- **単なる**（たんなる）仅仅的；单纯的｜韩语参考：단순한 / 단지<br>
  例：それは単なる偶然だと思う。（我想那只是偶然。）
- **単に**（たんに）仅仅；只是｜韩语参考：한갓（区区，只是，只不过是）<br>
  例：彼は単に好奇心からそれをしただけだ。（他那么做只是出于好奇。）
- **地**（ち）地；大地｜韩语参考：땅 / 대지<br>
  例：彼は地に足がついていない。（他做事不脚踏实地。）
- **地位**（ちい）地位｜韩语参考：지위（地位）<br>
  例：彼は会社で高い地位にあります。（他在公司地位很高。）

## 语法

- **〜てしょうがない / 〜てしかたがない**：…得不得了
  接续：动词て形/い形容词くて/ナ形容词で + しょうがない（しかたがない）
  朝鲜语：-아서 견딜 수 없다（韩语「-아서 견딜 수 없다」偏“难以忍受”的强烈表达；日语「てしょうがない」也可用于轻微感受，程度可轻可重。）
- **〜てたまらない**：…得受不了；非常…
  接续：动词て形/い形容词くて/ナ形容词で + たまらない
  朝鲜语：-아서 못 견디다（韩语表达强烈感受常用「정말 -다」或「-아서 못 견디다」；日语「てたまらない」是固定句型，不能自由替换。）
- **〜てはじめて**：只有…之后才…
  接续：动词て形 + はじめて
  朝鲜语：-고 나서야（-고 나서야 与 てはじめて 都表示「经历前项以后才发生后项」。后项常见 分かった，也可以是 做得到、开始做 等新变化。）
