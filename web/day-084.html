③ 语法 6 分钟

N(＋助詞) + さえ／こそ／すら；V ば形 前 + さえ…ば
さえ/すら 取代 が・を 或接在助词后（にさえ／でさえ）；さえ…ば 用 条件形(ば)；こそ 强调主语/原因（〜からこそ）
甚至…／只要…就／正是…／连…都

さえ 举极端例表「连…都/甚至」；さえ…ば 表「只要满足这一项就够」；こそ 强调「正是」；すら 文言、更消极

忙しくて、昼ご飯を食べる時間さえありません。
忙得连吃午饭的时间都没有。
これさえあれば、大丈夫です。
只要有这个就没问题。
今こそ頑張るときです。
现在正是努力的时候。
朝鲜语：-조차 / -야말로 / -마저
韩语조차表连…都(多否定)、마저表连…也(消极)、야말로表正是，分工比日语さえ/すら细。

易错：時間さえがありません。 → 時間さえありません。（さえ 已取代 が/を，不再叠 が；中文「连时间都没有」直译保留 が 错）

普通形 + くせに / ものの / とはいえ
くせに：动词／い形普通形、な形容词 + な、名词 + の；ものの：普通形；とはいえ：名词或普通形 + とはいえ
明明…却（责备）／虽然…但是／虽说…然而

くせに 带强烈责备/轻蔑（对人不满）；ものの 是中性书面让步；とはいえ 是「话虽如此」，常修正前句

知っているくせに、教えてくれませんでした。
明明知道却不告诉我。
買ったものの、使っていません。
虽然买了却没在用。
高いとはいえ、品質はいいです。
虽说贵，质量倒不错。
朝鲜语：-는데도 / -지만 / -라고는 해도
韩语责备用는데도，中性让步用지만，话虽如此用라고는 해도；くせに的轻蔑靠语调。

易错：先生は知っているくせに、教えてくれませんでした。 → 先生はご存じなのに、教えてくださいませんでした。（くせに 带责备/轻蔑，对老师用极失礼；中文「明明…却」直译不看对象错）
