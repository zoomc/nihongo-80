# Day 107 · 〜ないことはない、〜てしょうがない / 〜てしかたがない

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜ないことはない、〜てしょうがない / 〜てしかたがない」各造一句自己的话，表达：并非不…；也不是不能…；…得不得了

## 新词 24

- **経つ**（たつ）时间流逝｜韩语参考：흐르다（流，流淌，流逝）<br>
  例：時が経つうちに彼は心変わりした。（随着时间流逝，他变了心。）
- **達する**（たっする）达到｜韩语参考：달하다（达到） / 오르다（达到） / 이르다（达到）<br>
  例：彼らはそれで合意に達するだろう。（他们会就此达成协议吧。）
- **だって**（だって）因为；就连｜韩语参考：왜냐하면 / ~조차<br>
  例：子供にだってそんな事は分かるよ。（那种事连小孩都懂。）
- **たっぷり**（たっぷり）充足；足够｜韩语参考：듬뿍（足够地，充分地） / 넉넉히（足够地，充足地，充分地） / 충분히（充分地，充足地）<br>
  例：まだ時間はたっぷりある。（时间还很充裕。）
- **たとえ**（たとえ）纵然；假设｜韩语参考：설령 / 가령<br>
  例：たとえどんなことがあってもあきらめません。（无论发生什么，我都不会放弃。）
- **谷**（たに）山谷｜韩语参考：골짜기（山沟，山谷） / 산골짝（山谷，山沟）<br>
  例：谷は彼の呼び声でこだました。（山谷回荡着他的喊声。）
- **他人**（たにん）别人；外人｜韩语参考：남（别人，他人，人家） / 외인（外人）<br>
  例：彼女はもっと他人の言うことを聞くべきだ。（她应该多听听别人的话。）
- **種**（たね）种子；起因｜韩语参考：씨（种子，籽） / 불씨（导火线，起因，诱因） / 씨앗（种子）<br>
  例：そんなことをすれば笑いものの種なるよ。（做那种事会被人当成笑柄的。）
- **束**（たば）把；捆｜韩语参考：꼭지（把） / 묶음（捆，束） / 뭉치（团，捆，束）<br>
  例：彼は古い手紙を束にした。（他把旧信捆成了一捆。）
- **度**（たび）次；回｜韩语参考：번 / 차례<br>
  例：彼は東京へ来るたび私を訪ねてきた。（他每次来东京都来看我。）
- **旅**（たび）旅行｜韩语参考：여행（旅行，旅游，游行）<br>
  例：旅はよりよい教育法の一つである。（旅行是较好的教育方式之一。）
- **たびたび**（たびたび）屡次；多次｜韩语参考：자주 / 여러 번<br>
  例：私はたびたび彼から手紙をもらう。（我常收到他的来信。）
- **玉**（たま）球；硬币｜韩语参考：공 / 구슬 / 동전<br>
  例：ニッケルは５セント玉です。（镍币是五美分的硬币。）
- **偶**（たま）偶尔｜韩语参考：가끔<br>
  例：友理子はたまの逢瀬を心行くまで楽しんでしまいました。（友理子尽情享受着难得的幽会。）
- **弾**（たま）子弹｜韩语参考：탄환<br>
  例：弾が彼の頬をかすめた。（子弹擦过他的脸颊。）
- **たまたま**（たまたま）偶然；碰巧｜韩语参考：우연히（偶然地）<br>
  例：通りを歩いていたとき、私はたまたま旧友に出会った。（走在街上时，我碰巧遇见了老朋友。）
- **たまらない**（たまらない）受不了；极其｜韩语参考：견딜 수 없다 / 몹시<br>
  例：あのカメラが欲しくてたまらない。（我特别想要那台相机。）
- **黙る**（だまる）沉默；不说话｜韩语参考：침묵하다（沉默，旁观，袖手旁观）<br>
  例：もうこれ以上、黙ってられないわ。（我再也不能保持沉默了。）
- **試し**（ためし）尝试｜韩语参考：시도（试图，尝试） / 맛보기（尝试，体验）<br>
  例：私は試しにその山に登ってみた。（我试着爬了那座山。）
- **試す**（ためす）试；测试｜韩语参考：시험하다<br>
  例：もう一度試したが失敗しただけだった。（我又试了一次，结果还是失败。）
- **便り**（たより）音信；信｜韩语参考：서신（信，书信）<br>
  例：それ以来、彼からは何の便りもありません。（那以后他一直没有音信。）
- **頼る**（たよる）依靠；依赖｜韩语参考：기대다（依靠，依，靠） / 비비다（靠，依靠） / 의존되다（依赖，依存，依靠）<br>
  例：あまり人に頼ってはいけない。（不要太依赖别人。）
- **誰か**（だれか）某人；谁｜韩语参考：누군가<br>
  例：「誰か車の中にいるのですか」「トムがいます」（“车里有人吗？”“有汤姆。”）
- **段**（だん）段；台阶｜韩语参考：단（段）<br>
  例：彼は階段を一度に三段ずつかけあがった。（他一次三级地跑上了楼梯。）

## 语法

- **〜ないことはない**：并非不…；也不是不能…
  接续：动词ない形/い形容词くない/ナ形容词でない + ことはない
  朝鲜语：-지 않은 것은 아니다（韩语「-지 않은 것은 아니다」与日语结构几乎一致；但日语常省略后半句留白，韩语一般要把话说完整。）
- **〜てしょうがない / 〜てしかたがない**：…得不得了
  接续：动词て形/い形容词くて/ナ形容词で + しょうがない（しかたがない）
  朝鲜语：-아서 견딜 수 없다（韩语「-아서 견딜 수 없다」偏“难以忍受”的强烈表达；日语「てしょうがない」也可用于轻微感受，程度可轻可重。）
