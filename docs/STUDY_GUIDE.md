# 每天怎么学

打开线上首页，点“开始或继续学习”。网页是资源，会话负责反馈；不用管理仪表盘或多套任务系统。

## 网页 42 分钟

1. 复习：默认列表，也可切卡片。用“显示／遮中文／遮日语”背诵，点击遮盖处临时查看；遮中文会同时遮住韩语提示，避免泄题。课页提供课程复习词，私人会话根据 SQLite 的真实到期队列补充当天复习，不把公开静态页冒充实时 FSRS。
2. 新词：用列表快速通览，或用卡片逐词记忆。例句与韩语参考可展开；加粗是当天学习重点。只完成必学词。常规最多16个、听力日最多11个。韩语提示用来理解意义，不意味着日语与韩语在所有语境可互换。还有余力再勾选拓展。
3. 语法：始终显示，不参与遮盖。红色加粗标出今日词句，蓝色区分句型与接续；先看例句及韩语区别，再做语法选择题。
4. 听力日：先听完整音频，再答三题，最后看脚本。播放器可暂停、拖动；设备无法播放时使用设备朗读备用。
   听力块底部有 3 个按阶段推荐的**免费真人听力外链**（跳转到官方原站收听），另可打开
   [真人听力页](listening.html)：那里有 4 条开放许可音频可在本页直接播放，以及官方样题、播客、
   Irodori、Erin 等分阶段清单。本站每日精听仍是原创文本合成语音，真人材料是补充，不在本站托管。
5. 选句：全是四选一，三题必做、七题拓展，不用自己写。选错后直接查看正确项和原文。
6. 练习：完成六题。周测和阶段日把部分释义题换成阅读信息提取、语境语法，不额外堆题。

每日另有24–36道词汇、语法翻页选做题，可切换词汇／语法，上一题会保留对错。每逢Day 5、10、15等，从当天链接进入五日复习：五天全部词汇与语法都列出，可遮中文或日语，另配20题抽样巩固。选做不增加每日达标门槛。

“忘了／不熟”及错题进入[个人复习集](review.html)，按到期、曾错、忘了／不熟筛选；历史标记答对后仍保留，自评只调整排期。每次点击会先在本机记录，填写口令后自动批量同步，断网或超额会保留待同步记录。

点保存即可保留本次必做作答。首次云端保存需输入个人学习口令，本机在 `deploy/.sync-key`；只保留在当前标签页。口令不要贴进仓库、报告或外部网站。也可以直接“导出作答”，交给会话导入，断网或达到云端预算仍能继续学习。

## 会话 18 分钟

教师或能读本项目文件的 agent 执行：

```sh
python3 scripts/session_v5.py daily --sync
# 拉取作答和自评，输出下一未完成课的 brief 和链接；本机密钥不回显。
python3 scripts/nh80.py start-day N
```

显式读取 `data/review/CONTEXT.md` 和 `data/review/context.json`，结合 SQLite 的真实到期卡与错题安排复习。同步失败时说明原因；如果结果显示 `published: false`，本地结果仍保留，可重试发布。自评只用于调整复习，不代表掌握。

网页导出方式：

```sh
python3 scripts/nh80.py import-file --file /path/to/nihongo-day-N.json
```

练习页面导出的待同步队列也使用同一命令，将路径替换为导出的 JSON 文件。导入前会检查整份队列，题目在本地重新判分，自评和云端使用相同事件标识去重；导入后运行 `python3 scripts/nh80.py study-sync --push-only` 更新复习建议。

会话解释错题、复习薄弱项；可按需要口头造句或复述，不要求提交手写。网页choice模式作答拉取或导入后，CLI自动核对当天必做题是否答齐、正确率是否至少70%，达标即完成；拓展题不影响门槛，选择题不等同独立产出或掌握。

会话结束时运行 `python3 scripts/nh80.py study-sync --push-only`，生成并发布最新本地复习建议，并检查输出的 `published`。新会话须再次执行同步并读取文件，不依赖平台自动记忆或自动传递状态。

已保存后可点“再练一轮”，新一轮会使用独立会话标识，不覆盖此前记录。新会话从SQLite和文件读取；默认下一课取第一个未完成日，显式daily --day N只打开指定课。

## N3 检验

周阅读用于检查是否抓住事实；阶段短测用于发现薄弱项。第148课之后，从资源页打开官方N3练习集，按官网说明完成文字词汇、语法阅读与听力，可分多个学习时段，再核对官方答案。本站原创建议题不冒充官方卷，也不换算官方标准分。薄弱项回到对应词句、错题和FSRS复习，不因赶进度降低题目标准。
