## 新词 25

- **信頼**（しんらい）信赖｜韩语参考：신뢰（信赖，信任）<br>
  例：確かに彼は信頼できます。（他确实值得信赖。）
- **心理**（しんり）心理｜韩语参考：심리（心理）<br>
  例：私には青少年の心理がわからない。（我不懂青少年的心理。）
- **人類**（じんるい）人类｜韩语参考：인류（人类） / 인간（人，人类）<br>
  例：人類だけが火の使い方を知っている。（只有人类懂得用火。）
- **巣**（す）巢；窝｜韩语参考：집（房子，窝，巢） / 보금자리（巢，鸟巢）<br>

- **図**（ず）图；图表｜韩语参考：그림 / 도표<br>

- **筋**（すじ）筋；情节｜韩语参考：힘줄（筋，腱）<br>

  例：すなわち彼はそれをしたくないのだ。（也就是说，他不想做那件事。）

  例：私たちは彼にスピーチを頼んだ。（我们请他做演讲。）

## 语法

- **〜たびに**：每当…就…
  接续：动词辞书形 + たびに；名词 + の + たびに
  朝鲜语：-ㄹ 때마다（韩语「-ㄹ 때마다」与「たびに」基本对应；但日语「たびに」偏书面，口语常说「〜ときはいつも」。）
- **〜ごとに**：每…；每隔…
  接续：名词 + ごとに；动词辞书形 + ごとに
  朝鲜语：-마다（韩语「-마다」兼表“每”和“每隔”；日语要区分「ごとに」（每）与「おきに」（每隔）。）
- **〜最中に**：正当…的时候
  接续：动词ている + 最中に；名词 + の + 最中に
  朝鲜语：-는 중에（韩语「-는 중에」只表“进行中”；日语「最中に」还隐含“被打断、扫兴”的语感。）
- **〜をめぐって**：围绕…展开争论或讨论
  接续：名词 + をめぐって
  朝鲜语：을 둘러싸고（常接讨论、对立等表示多方立场的动作。）
