# Day 030 · 〜と〜とどちらが、〜の中で〜が一番

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜と〜とどちらが、〜の中で〜が一番」造两句自己的话，表达：…和…哪个更…？；在…中最…

## 新词 19

- **半**（はん）半；一半｜韩语参考：반（一半，半）<br>
  例：半時間したら彼はここに来るでしょう。（过半个小时他就会来吧。）
- **晩**（ばん）晚上；晚间｜韩语参考：저녁 / 밤<br>
  例：晩までにはおそらく雨になるだろう。（到晚上大概会下雨吧。）
- **ハンカチ**（ハンカチ）手帕｜韩语参考：손수건（手帕，手绢）<br>
  例：このハンカチはいくらですか。（这条手帕多少钱？）
- **番号**（ばんごう）号码；编号｜韩语参考：번호（号码）<br>
  例：番号をまちがえじゃありませんか。（您是不是弄错号码了？）
- **晩御飯**（ばんごはん）晚饭｜韩语参考：석식（晚餐，晚饭）<br>
  例：晩ご飯ですよ、お父さん。（爸爸，晚饭好了。）
- **半分**（はんぶん）一半；半个｜韩语参考：반（一半，半） / 반쪽（一半，半）<br>
  例：ケーキのどちらの半分でもとりなさい。（蛋糕两半你随便拿哪一半。）
- **東**（ひがし）东；东方｜韩语参考：동（东方，东边） / 동녘（东方，东边） / 동쪽（东边，东方）<br>
  例：その市はロンドンの東にある。（那座城市位于伦敦以东。）
- **引く**（ひく）拉；查（词典）｜韩语参考：끌다（引，拉） / 당기다（拉，拖，拽）<br>
  例：カーテンがゆっくり引かれた。（窗帘被慢慢地拉上了。）
- **弾く**（ひく）弹奏（乐器）｜韩语参考：치다（弹，弹奏，打） / 타다（弹，弹奏，演奏）<br>
  例：ギターをひくのはおもしろい。（弹吉他很有意思。）
- **低い**（ひくい）低；矮｜韩语参考：낮다（低，矮，低洼） / 얕다（浅，低，矮） / 옅다（矮）<br>
  例：ラジオの音を低くして下さい。（请把收音机的声音调小。）
- **左**（ひだり）左；左边｜韩语参考：좌（左）<br>
  例：アラビア語は右から左へ書きます。（阿拉伯语是从右往左写的。）
- **一つ**（ひとつ）一个；一样｜韩语参考：하나 / 한 개<br>
  例：車にはハンドルが一つある。（汽车有一个方向盘。）
- **一月**（ひとつき）一个月｜韩语参考：한 달<br>
  例：金がなくなる頃にはもうひと月ある。（到钱花完的时候还有一个月。）
- **一人**（ひとり）一个人；独自｜韩语参考：한 사람 / 혼자<br>
  例：どうしてあなたは一人になったの？（你怎么变成一个人了？）
- **暇**（ひま）空闲；余暇｜韩语参考：짬（空，空闲） / 틈（暇，余暇） / 사이（空儿，空闲）<br>
  例：ジョンはひどく急いでいたので話をする暇もなかった。（约翰急得连说话的空都没有。）
- **百**（ひゃく）百｜韩语参考：백（百）<br>
  例：百年後にはみな同じになる。（一百年后大家都一样了。）
- **病気**（びょうき）生病；疾病｜韩语参考：우환（疾病） / 질병（疾病）<br>
  例：ボブはいったい病気なのだろうか。（鲍勃到底是不是病了？）
- **昼**（ひる）中午；白天｜韩语参考：낮（白天，白日，日间） / 점심（中午） / 점심때（中午，晌午，午饭时间）<br>
  例：昼はホットドッグを食べたんだ。（中午吃了个热狗。）
- **昼御飯**（ひるごはん）午饭｜韩语参考：점심밥<br>
  例：昼ご飯を食べに外に出ませんか。（要不要出去吃午饭？）

## 语法

- **〜と〜とどちらが**：…和…哪个更…？
  接续：名词 + と + 名词 + とどちらが + 形容词 + か
  朝鲜语：A와 B 중 어느 쪽이（韩语用 와/과 중 어느 쪽이，日语用 と〜とどちらが；韩语需加 중，日语靠 どちら 本身表两者。）
- **〜の中で〜が一番**：在…中最…
  接续：名词（范围）+ の中で + 名词 + が一番 + 形容词
  朝鲜语：… 중에서 …이 가장（韩语 중에서 与 の中で 对应，가장/제일 与 一番 对应；语序上韩语 가장 在形容词前，日语 一番 也在形容词前，较接近。）
