## 新词 20

- **斬る**（きる）用刀刃（刀、砍刀、小刀等）杀死（人）；切断；砍掉；割掉<br>
- **片付く**（かたづく）收拾妥当；事情处理完（自动词）<br>
  例：部屋が片付いたら出かけよう。（等屋里收拾好了再出门吧。）
- **まぶた**（まぶた）眼睑；眼皮<br>
- **凸凹**（でこぼこ）凹凸不平（也常写成假名「でこぼこ」）<br>
  例：道がでこぼこで走りにくい。（路凹凸不平，不好跑。）

- **蘇る**（よみがえる）复活；苏醒；恢复；重现；恢复精神；得到恢复；被回忆起；被唤回<br>
- **部首**（ぶしゅ）部首<br>
- **話中**（はなしちゅう）（电话）占线中；正在通话中；洽谈中；讨论中<br>
- **威張る**（いばる）摆架子；逞威风；趾高气扬；傲慢自大<br>
- **帰す**（かえす）遣回；送回；让…回家<br>
- **隙間**（すきま）缝隙；空隙<br>
  例：ドアの隙間から冷たい風が入る。（冷风从门缝里吹进来。）
- **四捨五入**（ししゃごにゅう）四舍五入；观点趋同；达成共识<br>
- **重なる**（かさなる）重叠；冲突（日期等）；接连发生<br>
  例：会議の時間が重なった。（会议时间撞在一起了。）
- **甚だしい**（はなはだしい）极端的；过度的；可怕的；强烈的；严重的；巨大的；惨重的（损害）<br>
- **生意気**（なまいき）自以为是；不懂分寸（多为责备）<br>
  例：生意気なことを言ってしまった。（说了句不知分寸的话。）
- **たんす**（たんす）抽屉柜；五斗柜；衣柜；储物柜<br>
- **勇ましい**（いさましい）勇敢；英勇；无畏；振奋；雄壮；激励人心<br>
- **燃やす**（もやす）燃烧；点燃；激昂<br>

  例：長い文章をいくつかの段落に区切った。（把长文章分成了几段。）
- **付き合う**（つきあう）来往；交往；陪同（「〜に付き合う」）<br>
  例：買い物に付き合ってくれない？（能陪我去买东西吗？）

## 语法

- **〜のもとで / 〜のもとに**：在…指导或条件下
  接续：名词 + のもとで / 名词 + のもとに
  朝鲜语：…의 지도 아래 / …라는 조건 아래（导师指导常说「指導のもとで」。规则或共同目标作条件时也可说「合意のもとに」。）
- **〜抜きで / 〜抜きに**：省去…；撇开…
  接续：名词 + 抜きで / 名词 + 抜きに / 名词 + 抜きの + 名词
  朝鲜语：…을/를 빼고 / …없이는（「話抜きで」是主动略去，「協力抜きには」是少了某项就难以完成。修饰名词用「抜きの」。）
