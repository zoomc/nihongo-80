## 新词 25

- **母**（はは）(我)母亲｜韩语参考：어머니（母亲，妈妈）<br>
  例：母は医者です。（我母亲是医生。）
- **兄**（あに）(我)哥哥｜韩语参考：형（哥，哥哥） / 오빠（哥哥） / 오라비（哥哥）<br>
  例：兄は東京にいます。（我哥哥在东京。）
- **姉**（あね）(我)姐姐｜韩语参考：누나（姐姐） / 언니（姐姐）<br>
  例：姉は学生です。（我姐姐是学生。）
- **弟**（おとうと）(我)弟弟｜韩语参考：동생（弟弟；妹妹） / 아우（弟弟） / 남동생（弟弟）<br>
  例：弟に本を貸します。（借书给弟弟。）
- **妹**（いもうと）(我)妹妹｜韩语参考：동생（弟弟；妹妹） / 여동생（妹妹） / 누이동생（妹妹）<br>
  例：妹は元気です。（我妹妹很精神。）
- **家族**（かぞく）家人；家庭｜韩语参考：가족（家庭，家人） / 식구（家人）<br>
  例：家族と旅行します。（和家人旅行。）
- **子供**（こども）孩子；小孩｜韩语参考：애（孩子，小孩） / 아이（小孩，孩子） / 어린애（小孩）<br>
  例：子供が公園にいます。（孩子在公园。）
- **彼**（かれ）他；男朋友｜韩语参考：그（他）<br>
  例：彼は学生です。（他是学生。）
- **彼女**（かのじょ）她；女朋友｜韩语参考：그녀（她） / 여자 친구（女朋友）<br>
  例：彼女は元気です。（她很精神。）
- **友達**（ともだち）朋友｜韩语参考：벗（朋友，友人） / 친구（朋友，好友， 友人，故旧）<br>
  例：友達と映画を見ます。（和朋友看电影。）
- **人**（ひと）人｜韩语参考：사람（人） / 인간（人，人类）<br>
  例：あの人は先生です。（那位是老师。）
- **学生**（がくせい）学生｜韩语参考：학생（学生） / 대학생（大学生）<br>
  例：私は学生です。（我是学生。）
- **先生**（せんせい）老师；也用来称呼医生、律师等｜韩语参考：샘（老师） / 선생（老师，教师） / 선생님（老师，教师）<br>
  例：田中さんは先生です。（田中是老师。）
- **本**（ほん）书｜韩语参考：책（书，书籍，画册） / 서적（书籍，书）<br>
  例：本を読みます。（读书。）
- **日本語**（にほんご）日语｜韩语参考：일본어（日语，日本语）<br>
  例：日本語を勉強します。（学日语。）
- **勉強**（べんきょう）学习；用功｜韩语参考：공부（学习，读书）<br>
  例：図書館で勉強します。（在图书馆学习。）
- **宿題**（しゅくだい）作业｜韩语参考：숙제（作业） / 과제물（作业）<br>
  例：宿題をします。（做作业。）
- **名前**（なまえ）名字；姓名｜韩语参考：이름（名字，名称）<br>
  例：ここに名前を書いてください。（请在这里写名字。）
- **仕事**（しごと）工作；活儿｜韩语参考：일（事情，工作） / 일감（活儿，工作） / 직장（职业，职场，工作）<br>
  例：仕事が忙しいです。（工作很忙。）
- **会社員**（かいしゃいん）公司职员｜韩语参考：회사원（公司职员，公司员工）<br>
  例：彼は会社員です。（他是公司职员。）
- **医者**（いしゃ）医生｜韩语参考：의사（医生）<br>
  例：医者になりたいです。（想当医生。）
- **電話**（でんわ）电话｜韩语参考：전화（电话） / 전화기（电话机）<br>
  例：友達に電話します。（给朋友打电话。）
- **旅行**（りょこう）旅行｜韩语参考：여행（旅行，旅游，游行）<br>
  例：家族と旅行します。（和家人旅行。）
- **ホテル**（ホテル）宾馆；酒店｜韩语参考：호텔（酒店，饭店，宾馆）<br>
  例：ホテルに泊まります。（住宾馆。）
- **頭**（あたま）头；脑袋｜韩语参考：골치（脑袋） / 골통（脑袋） / 머리（头）<br>
  例：朝から頭が痛いです。（从早上开始就头疼。）

## 语法

- **が（主语／新信息／存在主体）**：…（主语/新信息/存在主体/能力对象）
  接续：名詞 + が + 動詞／形容詞
  朝鲜语：이/가（이/가 与 が 都能聚焦是谁、是什么，也能标存在主体。自我介绍通常先定话题，用 저는／私は；回应「谁是学生」时可用 제가／私が。）
- **を（宾语／移动经过）**：把…（标宾语）
  接续：名词 + を + 他动词（对象）；场所 + を + 移动动词（路线或离开的起点）
  朝鲜语：을/를（ご飯を食べる 对应 밥을 먹다，公園を通る 对应 공원을 지나가다。公園で遊ぶ 对应 공원에서 놀다，此时公园是动作发生的场所。）
- **に（时点／归着点／存在场所／对象）**：在／于／向…
  接续：名詞 + に
  朝鲜语：에 / 에게（七時に起きる 对应 일곱 시에 일어나다；部屋にいる 对应 방에 있다；友達に送る 对应 친구에게 보낸다。日语多用同一个 に。）
