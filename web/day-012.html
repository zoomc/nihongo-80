Day 012 · ～たい / ～たがる、～ましょう / ～ませんか、～が ほしい

语法 3 条

～たい / ～たがる
발음～타이 / ～타가루
想（做）…／（第三人称）想…
动词ます形去 ます + たい／たがる；描述眼前持续表现出来的愿望常用 たがっている
たい 通常用于说话人愿望或询问对方；叙述他人外显愿望常用 たがる，也可通过引用、传闻等交代他人愿望。
韩语对应-고 싶다 / -고 싶어 하다
韩语常用 -고 싶다 表自己愿望、询问对方或转述内容；观察他人的愿望常用 -고 싶어 하다。日语也须按叙述视角选择。
미즈 가 노미타이데스.
水が飲みたいです。
想喝水。
에이가 가 미타이데스.
映画が見たいです。
想看电影。
易错易混点
  • ✗ 飲みたいだ。✓ 飲みたいです。たい 按い形容词变化，结句用 です（飲みたいです），不能加 だ。
～ましょう / ～ませんか
발음～마쇼우 / ～마센카
（一起）…吧／要不要…？
動詞ます形（去ます） + ましょう／ませんか
ましょう 表提议/意志；ませんか 是委婉邀约
韩语对应-(으)ㅂ시다 / -(으)ㄹ까요? / 같이 …하지 않을래요?
같이 갈까요? 可对照 一緒に行きませんか。ましょう 是提出一起做，ませんか 把决定留给对方。单说 行きませんか 在合适语境里是邀请。
이쑈 니 에이가 오 미마센 카.
一緒に映画を見ませんか。
一起看电影好吗？
소로소로카에리마쇼우.
そろそろ帰りましょう。
差不多回去吧。
易错易混点
  • ✗ 映画を見るましょう。✓ 映画を見ましょう。ましょう 接ます形词干（見ましょう），不接辞书形 見る。
～が ほしい
발음～가 호시이
想要（某物）
名詞 + が + ほしい（です）
表说话人想要某物；对象用 が，不是 を；第三人称用 ほしがる
韩语对应N을/를 갖고 싶다 / N이/가 필요하다
우산을 갖고 싶어요 用 을/를，日语 傘がほしいです 用 が。也能问对方想要什么：何がほしいですか。
아타라시이파소콘 가 호시이데스.
新しいパソコンがほしいです。
想要新电脑。
易错易混点
  • ✗ パソコンを ほしいです。✓ パソコンがほしいです。ほしい 的对象用 が（パソコンがほしい），不用 を。
  • ✗ ほしいだ。✓ ほしいです。ほしい 是い形容词型，结句加 です，不加 だ。
