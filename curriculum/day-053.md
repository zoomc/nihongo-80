# Day 053 · 〜そうだ（hearsay）、〜らしい（hearsay/conjecture）

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜そうだ（hearsay）、〜らしい（hearsay/conjecture）」造两句自己的话，表达：听说…；据说…；好像…；据说…

## 新词 19

  例：私はいつも辞典を３冊手元に置いています。（我手边总放着三本辞典。）
- **品物**（しなもの）物品｜韩语参考：물건（商品，物品）<br>

- **しばらく**（しばらく）暂时｜韩语参考：당분간（暂时，暂且）<br>
  例：ここしばらく彼にまるで会わない。（最近一直没见到他。）
- **島**（しま）岛｜韩语参考：섬（岛，岛屿）<br>

  例：私のおじはこの事務所で働いている。（我叔叔在这家事务所工作。）
- **社会**（しゃかい）社会｜韩语参考：사회（社会）<br>
  例：彼の一生は社会の下積みで終わった。（他一生在社会底层度过。）
- **社長**（しゃちょう）社长｜韩语参考：사장<br>

- **ジャム**（ジャム）果酱｜韩语参考：잼（果酱）<br>
  例：イチゴはジャムに作られる。（草莓被做成了果酱。）
- **自由**（じゆう）自由｜韩语参考：자유（自由）<br>

- **習慣**（しゅうかん）习惯｜韩语参考：습관（习惯）<br>
  例：その習慣は中国で始まった。（那个习惯起源于中国。）
- **住所**（じゅうしょ）住址｜韩语参考：주소（地址，住址）<br>
  例：あなたの名前と住所を記入しなさい。（请填写你的姓名和住址。）
- **柔道**（じゅうどう）柔道｜韩语参考：유도（柔道）<br>
  例：柔道では力より技のほうが大切である。（柔道里技巧比力气更重要。）
- **十分**（じゅうぶん）充分；足够｜韩语参考：십분（十分，充分） / 백분（完全，充分） / 함빡（足足地，充分地）<br>

- **出席**（しゅっせき）出席；参加｜韩语参考：출석（出勤，出席，到场） / 참석（参加，出席）<br>
  例：出席できないんですか。どうして？（你不能出席吗？为什么？）
- **趣味**（しゅみ）爱好；兴趣｜韩语参考：취미（爱好，嗜好，趣味，兴趣）<br>
  例：趣味については話しましたか？（谈过兴趣爱好方面的事了吗？）
- **紹介**（しょうかい）介绍｜韩语参考：소개（介绍，推荐）<br>
  例：あなたを私の両親に紹介したい。（我想把你介绍给我的父母。）
- **小学校**（しょうがっこう）小学｜韩语参考：소학교（小学） / 국민학교（小学） / 초등학교（小学）<br>
  例：あなたは小学校に通っているの？（你在上小学吗？）

## 语法

- **〜そうだ（hearsay）**：听说…；据说…
  接续：动词普通形／い形容词 + そうだ；な形容词・名词 + だ + そうだ
  朝鲜语：-다고 하다（韩语 -다고 하다 是间接引语，与传闻 そうだ 对应；但日语 そうだ 前接名词要加 だ，韩语则用 -(이)라고 하다。）
- **〜らしい（hearsay/conjecture）**：好像…；据说…
  接续：动词普通形／い形容词／な形容词词干／名词 + らしい
  朝鲜语：-(으)ㄴ/는 모양이다（韩语 모양이다 偏重迹象推断，传言则用 -다고 하다；日语 らしい 兼有传闻与推断两种用法，范围更宽。）
