# Day 058 · 〜たがる、〜がる

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜たがる、〜がる」各造一句自己的话，表达：（第三人称）想做…；（第三人称）显得…；表现出…

## 新词 20

- **湖**（みずうみ）湖｜韩语参考：호（湖） / 호수（湖，湖泊）<br>
  例：湖の深さはどのくらいですか。（湖水有多深。）
- **味噌**（みそ）味噌；妙处｜韩语参考：된장 / 요점<br>
  例：この電子辞書は携帯しやすいところが味噌です。（这本电子词典的好处是方便携带。）
- **皆**（みな）大家；都｜韩语参考：다（全，都） / 모두（都，全）<br>
  例：私の親族は皆この町に住んでいる。（我的亲戚都住在这个镇上。）
- **港**（みなと）港口｜韩语参考：항구（港口）<br>
  例：その船はいま港にある。（那艘船现在在港口。）
- **向かう**（むかう）前往；朝向｜韩语参考：향하다<br>
  例：あなたは何処へ向かっているのですか。（你要去哪儿。）
- **迎える**（むかえる）迎接；接｜韩语参考：맞다（迎接，接待） / 받다（接待，迎接，接受，录用） / 맞이하다（迎接，迎）<br>
  例：６時にホテルに車で迎えて下さい。（六点请开车来酒店接我。）
- **昔**（むかし）从前｜韩语参考：과거（过去，从前）<br>
  例：この本を読むたびに昔を思い出す。（每次读这本书都会想起从前。）
- **虫**（むし）虫子｜韩语参考：벌레（虫子）<br>
  例：鳥は虫を探していた。（鸟在找虫子。）
- **息子**（むすこ）儿子｜韩语参考：아들（儿子） / 아들자식（儿子）<br>
  例：母親は息子にやかましく言って聞かせた。（母亲狠狠训了儿子一顿。）
- **娘**（むすめ）女儿｜韩语参考：딸（女儿） / 딸애（小女儿） / 여식（女儿）<br>
  例：私はヘレンカートライトの娘です。（我是海伦·卡特赖特的女儿。）
- **無理**（むり）不可能；勉强｜韩语参考：무리（过分，不合适，勉强，强人所难） / 억지（牵强，勉强）<br>
  例：それは無理な注文だ。（这个要求太过分了。）
- **召し上がる**（めしあがる）吃；喝（尊敬）｜韩语参考：잡수다（吃） / 잡숫다（吃） / 잡수시다（吃）<br>
  例：ここで召し上がりますか、それともお持ち帰りですか。（您在这儿吃还是带走。）
- **珍しい**（めずらしい）少见；稀奇｜韩语参考：희한하다（稀罕，稀奇）<br>
  例：これは珍しい種類の魚です。（这是很稀奇的一种鱼。）
- **申し上げる**（もうしあげる）说（自谦）｜韩语参考：말씀드리다（说，告知）<br>
  例：お礼の申し上げようもありません。（实在不知怎么感谢您才好。）
- **もうすぐ**（もうすぐ）马上｜韩语参考：곧<br>
  例：明るくなってきた。もうすぐ朝だ。（天亮了，马上就要早晨了。）
- **もし**（もし）如果｜韩语参考：만약（如果，假如，要是）<br>
  例：もし電話がなったら出てくれますか。（要是电话响了，你能接一下吗。）
- **もちろん**（もちろん）当然｜韩语参考：그럼（可不是，就是，当然）<br>
  例：「ご一緒してもいいですか」「もちろんです」（「我可以一起去吗？」「当然。」。）
- **もっとも**（もっとも）最｜韩语参考：가장<br>
  例：ケンは三人のなかでもっとも速く走ります。（健在三跑得最快。）
- **戻る**（もどる）返回｜韩语参考：돌아가다（返回） / 되돌아가다（回去，返回）<br>
  例：やってしまったことは元に戻らない。（做过的事回不到原样。）
- **木綿**（もめん）棉；棉布｜韩语参考：면（棉，棉布） / 무명（棉布）<br>
  例：このブラウスは木綿製です。（这件衬衫是棉的。）

## 语法

- **〜たがる**：（第三人称）想做…
  接续：动词ます形去ます + たがる
  朝鲜语：-고 싶어 하다（韩语常用 -고 싶어 하다 描述他人表现出的愿望；日语たがる同样关注外显表现，人称选择需结合语境。）
- **〜がる**：（第三人称）显得…；表现出…
  接续：い形容词去い／な形容词词干 + がる
  朝鲜语：-아/어 하다（韩语可用 -아/어 하다 描述他人表现出的情绪，如 무서워하다；日语がる通常描述外显表现，也可客观回顾自己的倾向。）
