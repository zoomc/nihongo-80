# Day 058 · 〜ことになる、〜える / 〜られる（potential）

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜ことになる、〜える / 〜られる（potential）」造两句自己的话，表达：决定…；结果变成…；能…；会…

## 新词 19

- **足す**（たす）加；添｜韩语参考：더하다（加，加上） / 플러스하다（加）<br>
  例：６０にするためには１７に何を足せばよいの。（要凑成60，17还得加上多少？）
- **尋ねる**（たずねる）询问｜韩语参考：묻다<br>
  例：お尋ねしてもよろしいでしょうか。（可以请教您一下吗？）
- **訪ねる**（たずねる）拜访｜韩语参考：찾다（拜访，寻访，探访） / 찾아보다（去找，去见，拜访，走访）<br>
  例：いつでも私のオフィスを訪ねなさい。（随时来我的办公室找我。）
- **正しい**（ただしい）正确｜韩语参考：맞다（正确，对） / 옳다（对，正确） / 바르다（正确，属实）<br>
  例：これが正しいかどうか自信がないんだ。（我不确定这是否正确。）
- **畳**（たたみ）榻榻米｜韩语参考：다다미<br>
  例：彼は畳の上に大の字になった。（他四肢摊开躺在榻榻米上。）
- **建てる**（たてる）建造｜韩语参考：짓다<br>
  例：この寺院は７８０年に建てられた。（这座寺院建于780年。）
- **立てる**（たてる）立起；发出｜韩语参考：세우다（立起，挺起）<br>
  例：図書館では物音を立ててはいけない。（在图书馆里不能弄出声响。）
- **例えば**（たとえば）例如｜韩语参考：예컨대（例如，比如） / 일테면（例如，比如） / 이를테면（例如，比如）<br>
  例：例えば、ロンドンは今は朝７時です。（比如，伦敦现在是早上7点。）
- **棚**（たな）架子；搁板｜韩语参考：선반（搁板）<br>
  例：その本はいちばん上の棚に置いてください。（请把那本书放在最上层的架子上。）
- **楽しみ**（たのしみ）期待；乐趣｜韩语参考：낙（乐，乐趣，快乐） / 즐거움（乐趣）<br>
  例：お便り楽しみにお待ちしております。（我期待着您的来信。）
- **楽しむ**（たのしむ）享受；欣赏｜韩语参考：즐기다（享受）<br>
  例：グレイ先生は仕事を楽しんでいませんでした。（格雷老师并不享受他的工作。）
- **たまに**（たまに）偶尔｜韩语参考：혹（偶尔） / 가끔（偶尔，有时，时而，间或） / 가다가（有时，偶尔）<br>
  例：たまには会いに来て下さい。（偶尔来看看我吧。）
- **為**（ため）为了；因为｜韩语参考：땜（因为，由于） / 때문（因为，由于）<br>
  例：それは、おまえの声をよく聞くためだよ。（那是为了好好听你的声音。）
- **だめ**（だめ）不行；没用｜韩语参考：안 되다 / 소용없다<br>
  例：もうだめだ。（已经不行了。）
- **男性**（だんせい）男性｜韩语参考：남성（男性）<br>
  例：男性の方は上着を着用してください。（男士请穿上外套。）
- **暖房**（だんぼう）暖气；取暖｜韩语参考：난방<br>
  例：お宅の暖房はどのようにしていますか。（您家的取暖是怎么弄的？）
- **血**（ち）血｜韩语参考：피（血，血液）<br>
  例：私たちは血がつながっている。（我们是有血缘关系的。）
- **チェックする**（チェックする）检查；核对｜韩语参考：체크하다（核对，核实，查对）<br>
  例：私は仕事を一つ終えるごとにリストの上でチェックする。（我每完成一项工作，就在清单上打勾。）
- **力**（ちから）力量；力气｜韩语参考：힘（力量，力气） / 파워（力量，势力，权威）<br>
  例：あなたは集中する力を失ってしまった。（你已经失去了集中注意力的能力。）

## 语法

- **〜ことになる**：决定…；结果变成…
  接续：动词辞书形／动词ない形 + ことになる
  朝鲜语：-게 되다（韩语 -게 되다 也与 ことになる 对应，但日语 ことになる 强调「被决定」的过程，韩语 게 되다 还可表能力或状态的自然变化。）
- **〜える / 〜られる（potential）**：能…；会…
  接续：五段动词词尾改え段+る；一段动词去る+られる；する→できる；来る→来られる
  朝鲜语：-(으)ㄹ 수 있다（韩语用 -(으)ㄹ 수 있다 表能力，与日语可能形对应；但日语可能形是动词活用，韩语是句尾构式，且日语宾语常改用 が。）
