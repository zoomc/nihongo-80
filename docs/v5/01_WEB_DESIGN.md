# 网页设计：一天一页，5 块，42 分钟

## 1. 设计目标

| 指标 | 目标 |
|---|---|
| 打开到开始学 | ≤ 10 秒 |
| 手机完成一页 | 4 屏内（375×812） |
| 首屏加载 | ≤ 1.5 秒（4G） |
| 每天操作 | 复习 3 档、词卡 16 张、语法 2 条、句子 10 句、练习 6 题 |
| 不需要的东西 | 一个都不出现 |

## 2. 信息架构

```
/day-061.html
├── header（sticky）  Day 061 · 今日目标 · 42 分钟 · 进度 2/6
├── ① 复习        12 min   到期卡 ≤80 张，三档自评
├── ② 新词        14 min   16 个（听力日 11 个）
├── ③ 语法         6 min   1–2 条 + 韩语对应 + 即时题
├── ④ 句子输出     6 min   10 句（7 韩→日，3 中→日）
├── ⑤ 练习         4 min   6 题，即时判分
└── ⑥ 今日完成            正确率 / 错题 / 同步状态 / 明日预告
```

手机线框：

```

│ │      （点击翻面）         │ │
```

## 3. 每一块的规格

### ① 复习（12 分钟）

- 数据源：`state.db` 里 `due <= now` 的能力卡，上限 80 张，按逾期天数降序。
- 交互：正面日语（词/句/语法例句）→ 点击翻面 → 三档。
  - 记住了：`good`，推进 FSRS。
  - 模糊：`hard`，当天再出现一次。
  - 忘了：`again`，当天再出现两次，并进错题。
- 键盘：`1/2/3` 对应三档，`空格` 翻面。
- 显示剩余张数，不显示百分比圆环。
- 没有到期卡时：一行「今天没有到期项」，不编造任务。

### ② 新词（14 分钟）

- 16 个（听力日 11 个），横向卡片，一次一张。
- 正面：词形 + 假名 + 发音按钮；背面：中文 + **朝鲜语汉字词对照**（有则显示，无则写「无直接对应」）+ 1 个例句（带中文）。
- 两个按钮：`记住了`（进 FSRS，间隔长）/ `再练一次`（当天再来）。
- 底部显示 `3 / 16`，不做进度条动画。
- 发音：优先真人音频字段 `audio_url`，没有则浏览器 TTS（标 `tts`，不冒充真人）。

### ③ 语法（6 分钟）

每条语法一张卡，固定 6 段：

1. 句型（大字）
2. 接续（一行，例：`V辞書形 + ために`）
3. 3 个例句（日语 + 中文 + 发音按钮）
4. **朝鲜语对应**：`ko_equiv` + `ko_diff`（差异），标注「不完全等价」
5. 中国学习者易错点 1 条（`common_errors[0]`，必须是真的不合法）
6. 即时题 1 道（选择题，答错展开解析）

### ④ 句子输出（6 分钟）

- 10 句：7 句韩→日，3 句中→日。
- 网页只给题干 + 文本框，**不判对错**（避免虚假正确）。草稿自动存 localStorage。
- 提交后进入「待老师批改」，会话里逐句改。
- 每题下方给 1 个提示词（不是答案），如「注意授受方向」。

### ⑤ 练习（4 分钟）

- 6 题，混合：选择 3、填空 1、排序 1、翻译 1。
- 即时判分 + 一句解析（≤60 字）。
- 答错标 `error_type`（助词/时态/语体/词义/语序），进错题本。
- 不显示总分大动画，只在底部显示 `4/6`。

### ⑥ 今日完成

- 一行正确率、一行错题数、一行「已同步 / 未联网，稍后自动重试」。
- 明日预告一句：`明天：N3 前半 · ～うちに / ～最中に`。
- 一个次要按钮「导出今日记录」，只在同步失败时出现。

## 5. 删除清单（v4 有、v5 必须没有）

- 80 天热力图、能力雷达、诊断标签
- 时间块明细表、系统术语、来源编号
- 教师区 / 系统信息折叠面板
- 回传码大面板（改为「自动同步 + 一行状态」）
- PWA 安装提示、离线提示横幅
- 韩语对照只在语法卡和词卡内出现，不做独立页面
- 任何「本页不承诺…」以外的免责声明堆叠（整站只留页尾一句）

## 6. 保留但降级

| 功能 | v4 | v5 |
|---|---|---|
| 韩语对照 | 独立区块 | 词卡一行 + 语法卡一段 |
| 发音 | 多处按钮 | 词卡、例句、听力各一个 |
| 回传码 | 大面板 + 分享/下载 | 默认自动同步，失败才显示「复制」 |
| 模考 | 每日页入口 | 独立 `mock.html`，不占每日页 |
| PWA | 提示安装 | 静默缓存，不提示 |

## 7. 交互与技术约束

- 纯静态 + 原生 JS，不引入框架；单文件 `app.js` ≤ 60KB。
- 分步展开：完成一块自动展开下一块，也可点 header 跳转。
- 发音：`speechSynthesis`（ja-JP），外部音频用 `<audio preload="none">`。
- 答案不进页面：`day-NNN.json` 不含 `answer` 字段，判分走后端 `/api/grade` 或本地 CLI 预生成 hash；离线时用本地加密答案包（简单异或 + 日号），不追求强安全。
- 离线：Service Worker 缓存当天页与音频元数据；音频不缓存（版权 + 体积）。
- 可访问性：对比度 ≥ 4.5:1，字号可调（根 `font-size` 三档），`prefers-reduced-motion` 关闭动画。

## 8. 验收标准

- [ ] 375×812 真机从打开到做完 ≤ 4 屏滚动。
- [ ] 冷启动（清缓存）首屏 ≤ 1.5 秒。
- [ ] 无 JS 报错；断网后当天页仍可打开，复习/词卡可用。
- [ ] 复习卡不超过 80 张；超过时显示「今天先做 80 张，其余顺延」。
- [ ] 语法卡 6 段齐全，韩语对照不为空。
- [ ] 句子输出草稿刷新不丢。
- [ ] 页面源码里搜不到 `heatmap`、`radar`、`diagnostic`、`timeblock`。

## 9. 遮盖背诵（核心交互，v5.1 追加）

目标：同一张卡，既能「看日忆中」，也能「看中忆日」，还能双向自测。

### 三种遮盖模式

| 模式 | 日语 | 中文 | 用途 |
|---|---|---|---|
| 全显 | 显示 | 显示 | 首次学习 |
| 遮中文 | 显示 | 模糊块 | 读解、回忆意思 |
| 遮日语 | 模糊块 | 显示 | 产出、翻译训练 |
| 双向 | 模糊块 | 模糊块 | 考前自测 |

### 交互

- 每张词卡/例句右上角一个「眼睛」按钮，循环切换：全显 → 遮中文 → 遮日语 → 双向。
- 点模糊块本身也能揭开（单次），3 秒后自动盖回；长按固定揭开。
- 页面顶部一个全局开关，作用于当天所有卡；默认「遮中文」。
- 偏好写 `localStorage`，跨天记住；不同块可不同模式（词卡遮中文、例句遮日语）。
- PC 快捷键：`C` 遮/显中文，`J` 遮/显日语，`空格` 揭开当前焦点卡，`1/2/3` 复习评分。
- 手机：点击卡片空白处切换，眼睛按钮切换模式；不做长按菜单，避免和滚动冲突。
- 遮盖用 CSS `filter: blur(6px)` + 透明文字色，不用 `display:none`，避免布局跳动。
- 揭开时朗读按钮仍可用（听音回忆 → 再揭开核对）。

### 数据与状态

- 遮盖状态只存本地，不进 `state.db`，不影响 FSRS。
- 但「双向模式下 3 秒内揭开」记为 `peeked`，随作答一起上报，用于判断是否真的回忆出来（不直接改掌握，只进审计）。

### 响应式（手机 + PC）

| 断点 | 布局 |
|---|---|
| < 640px | 单列；卡片全宽；底部固定「上一张/评分/下一张」；字号 16px 起 |
| 640–1024px | 单列居中，最大 720px；侧边留白 |
| > 1024px | 两栏：左侧当天目录（5 块锚点），右侧内容；卡片最大 760px |
| 打印 | 隐藏按钮与模糊，输出「日语 + 中文」对照表，A4 两栏 |

PC 端不放大留白凑数：内容区固定 760px，两侧放目录与快捷键提示。手机端禁止横向滚动，长单词用 `overflow-wrap:anywhere`。
