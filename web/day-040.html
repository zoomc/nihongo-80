今日语法 3 条

〜方
발음〜카타
…的方法；…的方式
动词ます形去ます + 方（かた）
把动作名词化，表示做某事的方法，常与「使い方／読み方」搭配。
코노키카이노쓰카이카타오오시에테쿠다사이.
この機械の使い方を教えてください。
请告诉我这台机器的使用方法。
코노칸지노요미카타가와카리마센.
この漢字の読み方が分かりません。
我不知道这个汉字怎么读。
소보니오이시이미소시루노쓰쿠리카타오나라따.
祖母においしいみそ汁の作り方を習った。
我跟奶奶学了做味噌汤的方法。
朝鲜语：-는 방법
韩语 -는 방법 与 方 对应；但日语 方 直接接ます形去ます构成复合名词，韩语则用定语形加方法。
易错点

この機械を使い方を教えてください。 → この機械の使い方を教えてください。（「使い方」是名词短语，前面的名词要用 の 连接，不能同时保留 を）

〜中
발음〜추우／주우
正在…中；整个…；全…
名词 + 中（ちゅう／じゅう）
读 ちゅう 表示正在进行的活动，读 じゅう 表示整个范围或期间。
치치와이마,덴와추우데스.
父は今、電話中です。
父亲现在正在打电话。
키노우와이치니치주우아메가후떼이타.
昨日は一日中雨が降っていた。
昨天一整天都在下雨。
코노우타와세카이주우데시라레테이루.
この歌は世界中で知られている。
这首歌全世界都知道。
朝鲜语：-중 / -내내
韩语 -중 对应 ちゅう（회의 중），-내내 对应 じゅう（하루 종일）；日语同一个汉字两种读法，韩语用不同词尾区分。
易错点

父は今、電話の中です。 → 父は今、電話中です。（表示正在打电话用「電話中」，不是「電話の中」）

〜つもり
발음〜쓰모리
打算…；计划…
动词辞书形／动词ない形 + つもりだ
表示说话人已形成的意图，否定形表示不打算做。
나쓰야스미와호까이도우오료코우스루쓰모리데스.
夏休みは北海道を旅行するつもりです。
暑假我打算去北海道旅行。
쿄우와오사케오노마나이쓰모리데스.
今日はお酒を飲まないつもりです。
今天我不打算喝酒。
다이가쿠오데타라,도우스루쓰모리데스카.
大学を出たら、どうするつもりですか。
大学毕业后你打算做什么？
朝鲜语：-(으)ㄹ 생각이다
韩语 -(으)ㄹ 생각이다 与 つもり 接近，但日语 つもり 可用于第二、三人称的确认；韩语 생각이다 多用于第一人称。
易错点

夏休みは北海道を旅行しつもりです。 → 夏休みは北海道を旅行するつもりです。（つもり 前接辞书形，不是ます形去ます）
