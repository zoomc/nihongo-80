# Day 034 · ～そうです（样态／传闻）、～ようだ / ～らしい、～かもしれない / ～でしょう

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「～そうです（样态／传闻）、～ようだ / ～らしい、～かもしれない / ～でしょう」各造一句自己的话，表达：看起来…／听说…；好像…／似乎…（推测）；也许…／大概…吧

## 语法

- **～そうです（样态／传闻）**：看起来…／听说…
  接续：样态：ます形词干/い形去い/な形词干 + そう；传闻：普通形 + そうです
  朝鲜语：-아/어 보이다 / -다고 하다（韩语样态用아/어 보이다，传闻用다고 하다，形态完全不同；日语そうだ须按接续分辨。）
- **～ようだ / ～らしい**：好像…／似乎…（推测）
  接续：普通形 + ようだ／らしい（名 + の + ようだ）
  朝鲜语：-(으)ㄴ 것 같다 / -(으)ㄴ 모양이다（韩语推测最常用것 같다，传闻典型用다고 하다；日语ようだ主观、らしい客观传闻。）
- **～かもしれない / ～でしょう**：也许…／大概…吧
  接续：普通形 + かもしれない；普通形 + でしょう
  朝鲜语：-(으)ㄹ지도 모르다 / -겠다（韩语不确定用ㄹ지도 모르다，较强推量用겠다或ㄹ 것이다；でしょう无对应敬语分层。）
