③ 语法 6 分钟

加粗的是今日重点。先看句型与接续，再读例句。

Vます形(去ます) + ようがない / ようもない
動詞ます形去ます + ようがない；する→しようがない；句末 ようがありません
无法…；没有办法…

表示想做但客观上没有手段/方法，不是能力不足；常与「〜たくても」呼应。

名前も住所も分からないので、連絡しようがありません。
姓名和住址都不知道，所以没法联系。
電源が入らないので、直しようがありません。
电源打不开，所以没法修。
朝鲜语：-(으)ㄹ 방법이 없다
韩语ㄹ 방법이 없다表无手段，与能力不足的ㄹ 수 없다区分；同日语ようがない与できない之别。
用法提醒

名前も分からないので、連絡するようがありません。 → 連絡しようがありません。（ようがない 接ます形去ます（し），不接辞书形；中文“没有办法联系”直译错。）

N / Vます形(去ます) + がちだ
名詞 + がちだ；動詞ます形去ます + がちだ；がちな + 名詞
容易…；往往…（多指不好的倾向）

表示某种（多负面）倾向容易发生；常用「〜がちです／がちな人」。

朝は電車が遅れがちです。
早上电车容易晚点。
忙しい時期は、食事が不規則になりがちです。
忙碌时期，饮食容易不规律。
朝鲜语：-기 쉽다 / -는 경향이 있다
韩语기 쉽다表容易(中性)，负面倾向用는 경향이 있다；日语がちだ多负面，语感更窄。
用法提醒

彼は病気がちなです。 → 彼は病気がちです。（がち 是な形容詞型，接です 用「がちです」，不用「がちなです」；中文“容易生病”直译。）
