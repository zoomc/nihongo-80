# Day 088 · 〜向き / 〜向け、〜がち、〜気味

- 阶段：P4｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜向き / 〜向け**：适合…；面向…
  接续：名词 + 向き（だ／の／な）；名词 + 向け（だ／の／に）
  朝鲜语：…에 알맞다 / …용（초보자에게 알맞다 对照 初心者向き；초보자용 对照 初心者向け。前者评价适不适合，后者说明为谁设计，实际使用对象可能重合。）
- **〜がち**：容易…；动不动就…
  接续：动词ます形词干/名词 + がち
  朝鲜语：-기 쉽다（韩语「-기 쉽다」中性，好坏都可用；日语「がち」几乎只用于消极倾向，且偏书面。）
- **〜気味**：有点…；稍有…迹象
  接续：名词/动词ます形词干 + 気味
  朝鲜语：약간 … 기운이 있다 / 조금 …한 편이다（감기 기운이 있다 很接近 風邪気味だ。疲れ気味 可译 요즘 조금 피곤한 편이다。気味 通常说眼下有一点某种迹象，がち 则说反复出现的倾向。）
