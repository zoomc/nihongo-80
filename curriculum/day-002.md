# Day 002 · N は N ではありません / じゃない、N は N でした

- 阶段：P0｜60 分钟｜常规日
- Can-do：用「N は N ではありません / じゃない、N は N でした」造两句自己的话，表达：…不是…；…（过去）是…

## 新词 14

- **七**（なな）七（なな／しち）｜韩语参考：칠 / 일곱<br>
  例：七時に起きます。（七点起床。）
- **八**（はち）八｜韩语参考：팔（八） / 여덟（八）<br>
  例：八日から休みます。（从八号开始休息。）
- **九**（きゅう）九（きゅう／く）｜韩语参考：구（九）<br>
  例：九時です。（九点。）
- **十**（じゅう）十｜韩语参考：십（十）<br>
  例：十人います。（有十个人。）
- **何**（なん）什么｜韩语参考：무엇 / 뭐<br>
  例：これは何ですか。（这是什么？）
- **いくら**（いくら）多少钱｜韩语参考：얼마<br>
  例：これはいくらですか。（这个多少钱？）
- **円**（えん）日元（货币单位）｜韩语参考：엔（일본 화폐 단위）<br>
  例：百円です。（一百日元。）
- **今**（いま）现在｜韩语参考：시방（刚刚，现在） / 이제（现在） / 인제（现在，到现在）<br>
  例：今、何時ですか。（现在几点？）
- **今日**（きょう）今天｜韩语参考：금일（今日，今天） / 오늘（今天，今日）<br>
  例：今日は月曜日です。（今天是周一。）
- **明日**（あした）明天｜韩语参考：내일（明天）<br>
  例：明日、学校へ行きます。（明天去学校。）
- **昨日**（きのう）昨天｜韩语参考：어제（昨天，昨日） / 어저께（在昨天，在昨日）<br>
  例：昨日は日曜日でした。（昨天是周日。）
- **朝**（あさ）早晨｜韩语参考：아침（早上，早晨）<br>
  例：朝ご飯を食べます。（吃早饭。）
- **時間**（じかん）时间；小时｜韩语参考：시간（时间）<br>
  例：時間がありません。（没时间。）
- **時計**（とけい）钟表；手表｜韩语参考：시계<br>
  例：時計を見ます。（看表。）

## 语法

- **N は N ではありません / じゃない**：…不是…
  接续：名詞 + は + 名詞 + ではありません（口语 じゃない）
  朝鲜语：이/가 아닙니다（韩语否定用이/가 아니다，助词随收音变化；日语では可缩成じゃ，韩语无对应缩略。）
- **N は N でした**：…（过去）是…
  接续：名詞 + は + 名詞 + でした
  朝鲜语：이었습니다 / 였습니다（韩语过去按有无收音选이었/였，且分层级；日语でした只有一形，无收音条件。）

- **木** 树；木头；星期四｜音：ボク、モク｜训：き
