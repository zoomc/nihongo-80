Day 001 · N は N です、〜か（or）

语法 2 条

N は N です
발음N 와 N 데스
…是…
名詞 + は + 名詞 + です
判断句，介绍身份/事物，礼貌体
韩语对应입니다 / 이에요
은/는 标主题。학생입니다、의사입니다 在正式礼貌体同用 입니다；日常礼貌体按有无收音选 이에요／예요。日语句末统一用 です。
와타시 와 가쿠세이데스.
私は学生です。
我是学生。
코레 와 혼데스.
これは本です。
这是书。
易错易混点
  • ✗ 私は学生だです。✓ 私は学生です。「だ」和「です」都表示“是”，一句话只留一个。中文没有这层变化，容易两个都写。
  • ✗ 私は 学生 です（は 读 ha）✓ 私は学生です。（は 读 wa）「は」当助词用时读 wa，不读 ha。中文母语者容易照字面读成 ha。
〜か（or）
발음〜카
…或…
名词 + か + 名词
表示两个以上选项中的选择，可用于陈述或疑问。
韩语对应나/이나
韩语 나/이나 兼表选择和列举，日语 か 表选择、や 表列举，分工更明确。
노미모노 와 코오히이 카 코우차 가 이이데스.
飲み物はコーヒーか紅茶がいいです。
饮料咖啡或红茶都行。
도요우비 카 니치요우비 니 카이모노 니 이키마스.
土曜日か日曜日に買い物に行きます。
我星期六或星期天去买东西。
에키 마데 바스 카 타쿠시이 데 이키마스.
駅までバスかタクシーで行きます。
坐公交车或出租车去车站。
易错易混点
  • ✗ 飲み物はコーヒーと紅茶かがいいです。✓ 飲み物はコーヒーか紅茶がいいです。表选择时用「AかB」，不能与 と 混用

2. 请选择「〜か（or）」所用句型的主要含义。
3. 请选择「これは本です。」的中文意思。
4. 请选择「土曜日か日曜日に買い物に行きます。」的中文意思。
5. 「坐公交车或出租车去车站。」选出连接两个备选项的助词。 駅までバス（　）タクシーで行きます。
6. 「这是书。」选出礼貌体句末。 これは本（　）。
