# Day 051 · 〜てある、〜とき

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜てある、〜とき」造两句自己的话，表达：…着（有意为之的结果状态）；…的时候

## 新词 20

- **坂**（さか）坡道｜韩语参考：비탈길<br>
  例：私は何度も転びながら、坂を下っていった。（我摔了好几次，一路走下了坡。）
- **探す**（さがす）寻找｜韩语参考：찾다（寻，觅，访，寻找，查）<br>
  例：私は貸間を探しているところです。（我正在找出租的房子。）
- **下がる**（さがる）下降｜韩语参考：내리다（下降，下跌） / 내려가다（降，下降） / 하락하다（下落，下降）<br>
  例：ロープから下がっていなさい。（抓住绳子往下退。）
- **盛ん**（さかん）兴盛｜韩语参考：활발하다 / 번성하다<br>
  例：日本では英語教育が盛んである。（日本英语教育很兴盛。）
- **下げる**（さげる）降低；放下｜韩语参考：낮추다（压低，降低，放低） / 떨구다（降低） / 떨어뜨리다（降低）<br>
  例：ラジオの音を下げてくれませんか。（能把收音机声音调小吗？）
- **差し上げる**（さしあげる）给（敬）｜韩语参考：드리다<br>
  例：飲み物を差し上げましょうか。（给您来点饮料吧？）
- **さっき**（さっき）刚才｜韩语参考：방금（刚才，方才） / 아까（刚才，方才，刚刚）<br>
  例：さっきなぜかマイクが入らなかった。（刚才不知为什么麦克风没声音。）
- **寂しい**（さびしい）寂寞｜韩语参考：적적하다（寂寞，孤寂，无聊）<br>
  例：それで、彼女はとてもさびしく思っています。（所以她觉得很寂寞。）
- **再来月**（さらいげつ）下下个月｜韩语参考：다다음 달<br>
  例：再来月は１２月だ。（下下个月是十二月。）
- **再来週**（さらいしゅう）下下周｜韩语参考：다다음 주<br>
  例：再来週の木曜日はどう？（下下周四怎么样？）
- **サラダ**（サラダ）沙拉｜韩语参考：샐러드（沙拉，色拉）<br>
  例：もう少しサラダはいかがですか。（再来点沙拉怎么样？）
- **騒ぐ**（さわぐ）吵闹｜韩语参考：떠들다<br>
  例：どうかそんなに騒がないで下さい。（请别那么吵。）
- **触る**（さわる）触摸｜韩语参考：만지다（触摸，抚摸） / 손대다（触摸）<br>
  例：触らずそのままにしておきなさい。（别碰，就那样放着。）
- **産業**（さんぎょう）产业｜韩语参考：산업（产业）<br>
  例：日本は産業国である。（日本是工业国。）
- **サンダル**（サンダル）凉鞋｜韩语参考：샌들（凉鞋）<br>
  例：あんな底の厚いサンダル履いてたら、転んで捻挫しちゃうぞ。（穿那么厚的凉鞋会摔倒扭伤的。）
- **サンドイッチ**（サンドイッチ）三明治｜韩语参考：샌드위치（三明治）<br>
  例：サンドイッチだったらどれくらいかかりますか。（三明治的话要多少钱？）
- **市**（し）市｜韩语参考：시（市）<br>
  例：その町は大きくなって市となった。（那个镇发展壮大成了市。）
- **字**（じ）字｜韩语参考：자（字） / 글（字，文字） / 글씨（字，字样）<br>
  例：君は字がうまいね。（你字写得真好。）
- **試合**（しあい）比赛｜韩语参考：시합（比赛） / 게임（比赛）<br>
  例：その試合は何時に始まりますか。（那场比赛几点开始？）
- **仕方**（しかた）方法｜韩语参考：수（手段，办法，方法）<br>
  例：あなたはチェスの仕方を知っていますか。（你知道国际象棋怎么下吗？）

## 语法

- **〜てある**：…着（有意为之的结果状态）
  接续：他动词て形 + ある；结果状态常用 が，已完成的准备可用 を。
  朝鲜语：-아/어 있다（韩语 -아/어 있다 可表状态持续，但不像日语 てある 那样明确区分他动词与自动词；日语用 が 提示结果主体，韩语用 이/가。）
- **〜とき**：…的时候
  接续：动词普通形／い形容词／な形容词+な／名词+の + とき
  朝鲜语：-(으)ㄹ 때（韩语 -(으)ㄹ 때 与 とき 对应，但日语要注意 な形容词加 な、名词加 の；韩语统一用 -(으)ㄹ 때，无词性变化。）
