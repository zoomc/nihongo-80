# Day 016 · ～ましょう / ～ませんか、～が ほしい

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～ましょう / ～ませんか、～が ほしい」造两句自己的话，表达：（一起）…吧／要不要…？；想要（某物）

## 新词 19

- **かける**（かける）打电话；挂｜韩语参考：전화하다 / 걸다<br>
  例：１０円で電話がかけられますか。（十日元能打个电话吗？）
- **傘**（かさ）伞｜韩语参考：우산<br>
  例：タクシーに傘を忘れてしまった。（我把伞落在出租车上了。）
- **貸す**（かす）借出｜韩语参考：빌려주다<br>
  例：ホッチキスを貸してくれませんか。（能借我订书机用一下吗？）
- **風**（かぜ）风｜韩语参考：바람（风） / 바람결（风，随风）<br>
  例：カーテンが風になびいた。（窗帘随风飘动。）
- **風邪**（かぜ）感冒｜韩语参考：감기（感冒）<br>
  例：ただの風邪でしょう。（大概只是感冒吧。）
- **方**（かた）人；方法｜韩语参考：분 / 방법<br>
  例：こちらはあなたがお話しになるお方です。（这位就是您要谈的那位。）
- **カップ**（カップ）杯子｜韩语参考：컵（杯子）<br>
  例：テーブルの上にカップがある。（桌上有个杯子。）
- **家庭**（かてい）家庭｜韩语参考：가정（家庭，家园）<br>
  例：食事は家庭で食べますか、外食ですか。（饭在家吃还是在外吃？）
- **角**（かど）角；拐角｜韩语参考：각（角，棱角） / 모（角，棱） / 코너（拐角）<br>
  例：角のテーブルがいいのですが。（我想要角落的那张桌子。）
- **かばん**（かばん）包｜韩语参考：가방（包，背包，提包）<br>
  例：これはジェーンさんのかばんです。（这是简的包。）
- **花瓶**（かびん）花瓶｜韩语参考：화병（花瓶） / 꽃병（花瓶）<br>
  例：花びんに水を入れなさい。（往花瓶里装点水。）
- **紙**（かみ）纸｜韩语参考：종이（纸，纸片）<br>
  例：紙は木から作られる。（纸是用木头做的。）
- **カメラ**（カメラ）相机｜韩语参考：사진기（照相机，相机） / 카메라（照相机）<br>
  例：おじさんがぼくにカメラをくれました。（叔叔给了我一部相机。）
- **辛い**（からい）辣｜韩语参考：맵다（辣）<br>
  例：このカレーは辛すぎて食べられない。（这咖喱太辣了，吃不下。）
- **体**（からだ）身体｜韩语参考：몸（身体，身子）<br>
  例：とりわけ体に気をつけなさい。（尤其要注意身体。）
- **軽い**（かるい）轻｜韩语参考：가볍다（轻） / 경하다（轻，轻微） / 가뿐하다（轻，轻便）<br>
  例：軽く食べましょう。（我们随便吃点吧。）
- **カレー**（カレー）咖喱｜韩语参考：카레（咖喱，咖喱粉）<br>
  例：このレストランのカレーはうまいよ。（这家店的咖喱很好吃。）
- **カレンダー**（カレンダー）日历｜韩语参考：달력（日历）<br>
  例：このカレンダーはどこにかけましょうか。（这本日历挂在哪儿好呢？）
- **川**（かわ）河｜韩语参考：강（江，河）<br>
  例：その川はあまりきれいではなかった。（那条河不太干净。）

## 语法

- **～ましょう / ～ませんか**：（一起）…吧／要不要…？
  接续：動詞ます形（去ます） + ましょう／ませんか
  朝鲜语：-(으)ㅂ시다 / -(으)ㄹ래요?（韩语提议用ㅂ시다，邀约用ㄹ래요；对长辈ㅂ시다不礼貌，须换ㄹ까요。）
- **～が ほしい**：想要（某物）
  接续：名詞 + が + ほしい（です）
  朝鲜语：이/가 갖고 싶다 / 원하다（韩语갖고 싶다限第一人称，第三人称用갖고 싶어 하다；원하다偏书面。）

## 汉字 5

- **外** 外面；以外；其他｜音：ガイ、ゲ｜训：そと、ほか、はず.す、はず.れる、と-
- **山** 山；山岳｜音：サン、セン｜训：やま
- **北** 北；北方｜音：ホク｜训：きた
- **午** 正午；午时；干支马｜音：ゴ｜训：うま
- **名** 名字；名称；有名｜音：メイ、ミョウ｜训：な、-な
