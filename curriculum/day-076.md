# Day 076 · N / 普通形 + ばかりか、Vます形(去ます) + ようがない / ようもない

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「N / 普通形 + ばかりか、Vます形(去ます) + ようがない / ようもない」各造一句自己的话，表达：不仅…而且…；无法…；没有办法…

## 新词 24

- **温暖**（おんだん）温暖｜韩语参考：온난（温暖）<br>
  例：島の天候はとても温暖です。（岛上的气候非常温暖。）
- **温度**（おんど）温度｜韩语参考：온도（温度）<br>
  例：物質は温度によって形を変える。（物质会随温度改变形态。）
- **可**（か）可；可以｜韩语参考：가（可，赞成）<br>
  例：この試験は辞書持ち込み可です。（这场考试可以带词典。）
- **課**（か）课｜韩语参考：과（课）<br>
  例：１０課から始めましょう。（从第十课开始吧。）
- **カー**（カー）汽车｜韩语参考：자동차（汽车）<br>
  例：あいつはカーマニアだから、車のことならなんでも知ってるよ。（那家伙是个车迷，车的事他什么都知道。）
- **カード**（カード）卡片｜韩语参考：카드（卡，卡片）<br>
  例：この店ではカードが使えます。（这家店可以刷卡。）
- **会**（かい）会；团体｜韩语参考：모임（协会，组织，团体）<br>
  例：この会の名称はＥ．Ｓ．Ｓ．とする。（本会名称为E.S.S.。）
- **回**（かい）次；回｜韩语参考：회（次 ，场 ，回 ，期） / 번（次，遍） / 탕（次，回）<br>
  例：彼女は毎週１回映画を見に行く。（她每周去看一次电影。）
- **害**（がい）害处｜韩语参考：해 / 해로움<br>
  例：ワインは本来害にならない。（葡萄酒本来并无害处。）
- **会員**（かいいん）会员｜韩语参考：회원（会员）<br>
  例：クラブの会員は会議室に集まった。（俱乐部会员聚集在会议室。）
- **絵画**（かいが）绘画｜韩语参考：회화（绘画，画） / 그림（画儿，绘画，画作，图画） / 그리기（绘画）<br>
  例：その絵画を見たらおもしろかった。（那幅画看着挺有意思。）
- **海外**（かいがい）海外；国外｜韩语参考：해외（海外，国外）<br>
  例：君はどれくらいよく海外に行きますか。（你多久出国一次？）
- **会計**（かいけい）结账；会计｜韩语参考：회계（会计，核算，统计） / 경리（财会，会计）<br>
  例：チェックアウトしたいので、会計をおねがいします。（我想退房，请结账。）
- **解決**（かいけつ）解决｜韩语参考：해결（解决）<br>
  例：その問題はまだ解決されていない。（那个问题还没有解决。）
- **会合**（かいごう）聚会；会议｜韩语参考：회합（会合，会聚，相聚，聚会，集会） / 모임（聚会）<br>
  例：これはとても大切な会合だ。（这是一次非常重要的聚会。）
- **外交**（がいこう）外交｜韩语参考：외교（外交）<br>
  例：英語は外交や観光事業に有効である。（英语在外交和旅游业中很有用。）
- **開始**（かいし）开始｜韩语参考：개시（开始） / 시작（开始，开端，开头，起始，起头）<br>
  例：天候のためレースの開始は遅れるだろう。（因天气原因，比赛可能推迟开始。）
- **解釈**（かいしゃく）解释；理解｜韩语参考：해석（解释） / 풀이（解释，解答）<br>
  例：それは２通りに解釈できる。（那可以有两种理解。）
- **外出**（がいしゅつ）外出｜韩语参考：외출（外出，出行，出门） / 출타（外出，出门，出行） / 바깥출입（外出，出门，出行）<br>
  例：ヒーターをつけたまま外出した。（我开着暖气就出门了。）
- **改善**（かいぜん）改善｜韩语参考：개선（改善）<br>
  例：改善の余地は大いに残されている。（还有很大的改善余地。）
- **快適**（かいてき）舒适｜韩语参考：쾌적하다<br>
  例：この家は住むのにとても快適だ。（这房子住起来很舒适。）
- **飼う**（かう）饲养｜韩语参考：치다（饲养，喂） / 기르다（养，喂养，饲养，栽培） / 사육하다（饲养）<br>
  例：ナンシーは犬を飼いたがっていますか。（南希想养狗吗？）
- **換える**（かえる）交换；兑换｜韩语参考：바꾸다 / 교환하다<br>
  例：銀行に行けばその５０ドルの小切手を現金に換えてくれる。（去银行就能把那张五十美元支票换成现金。）
- **替える**（かえる）更换；替换｜韩语参考：갈다（换，替换） / 바꾸다（换，更换，调换）<br>
  例：お花の水を替えましょう。（我来给花换水吧。）

## 语法

- **N / 普通形 + ばかりか**：不仅…而且…
  接续：名詞 + ばかりか；動詞・い形 普通形 + ばかりか；な形・名詞 + な/である + ばかりか
  朝鲜语：-(으)ㄹ 뿐만 아니라（韩语뿐만 아니라表不仅而且，后项可同程度；日语ばかりか后项常程度更高，还可接まで/も。）
- **Vます形(去ます) + ようがない / ようもない**：无法…；没有办法…
  接续：動詞ます形去ます + ようがない；する→しようがない；句末 ようがありません
  朝鲜语：-(으)ㄹ 방법이 없다（韩语ㄹ 방법이 없다表无手段，与能力不足的ㄹ 수 없다区分；同日语ようがない与できない之别。）
