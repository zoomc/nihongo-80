Day 014 · ～たり ～たり する、〜は、〜が（subject）

语法 3 条

～たり ～たり する
발음～타리 ～타리 스루
又…又…／时而…时而…
動詞た形 + り + 動詞た形 + り + する
列举代表性动作或状态，完整的基本句式常用 たりする 收尾；口语中也会省略或以列举形式结束。
韩语对应-기도 하고 -기도 하다
주말에는 영화를 보기도 하고 산책을 하기도 해요 对照 週末は映画を見たり散歩したりします，列举平时会做的几件事。た 是 たり 的接续，整句时态看最后的 する。
야스미 노 히 와, 혼 오 욘 다리 온가쿠 오 키이 타리 시마스.
休みの日は、本を読んだり音楽を聞いたりします。
休息日看看书、听听音乐。
易错易混点
  • ✗ 本を読みたり 音楽を聞いたり✓ 本を読んだり音楽を聞いたりします。たり 接た形（読んだり），不是ます形词干 読み。
〜は
발음〜와
…是主题；至于…
名词 + は（读作 wa）
提示句子的主题，后面对主题加以说明或判断。
韩语对应은/는（주제 조사）
은/는、は 都可以提示主题或拉出对比。日语 は 写作 ha 所对应的假名、这里读 wa。复习「茶喝，咖啡不喝」这种对比时可以说 お茶は飲むが、コーヒーは飲まない。
와타시 와 가쿠세이데스.
私は学生です。
我是学生。
쿄우 와 텐키 가 이이데스.
今日は天気がいいです。
今天天气很好。
코노혼 와 오모시로이데스.
この本はおもしろいです。
这本书很有意思。
易错易混点
  • ✗ 私を学生です。✓ 私は学生です。判断句的主题要用 は；を 标记宾语，不能与 です 搭配
〜が（subject）
발음〜가
…是主语；提示新信息
名词 + が
指出动作主体或新信息，疑问词作主语时必须用 が。
韩语对应이/가（주어·신정보）
누가 왔어요? 对照 誰が来ましたか。日语用 が 来标「谁」这一询问焦点。回答也可用 田中さんが来ました；韩语口语中偶尔会省略其他类型的主语助词。
아메 가 후떼이마스.
雨が降っています。
下雨了。
다레 가 마도 오 아케마시타 카.
だれが窓を開けましたか。
谁打开了窗户？
와타시 가 이키마스.
私が行きます。
我去。
易错易混点
  • ✗ だれは窓を開けましたか。✓ だれが窓を開けましたか。疑问词作主语必须用 が，不能用 は
