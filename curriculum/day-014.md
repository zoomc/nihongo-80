# Day 014 · ～て も いい / ～て は いけない、～ながら

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～て も いい / ～て は いけない、～ながら」各造一句自己的话，表达：可以…／不许…；一边…一边…

## 新词 23

- **木**（き）树；木头｜韩语参考：나무（树，树木）<br>
  例：その木には実がたわわになっていた。（那棵树上结满了果实。）
- **黄色**（きいろ）黄色｜韩语参考：노란색（黄色，鹅黄色，嫩黄色）<br>
  例：木の葉は秋には黄色になる。（树叶秋天会变黄。）
- **黄色い**（きいろい）黄色的｜韩语参考：노랗다（黄色的）<br>
  例：その黄色いのをいただきましょう。（我要那个黄色的吧。）
- **消える**（きえる）消失；熄灭｜韩语参考：들어가다（消失） / 사라지다（消失） / 스러지다（消失）<br>
  例：火が消えないようにしてください。（请别让火灭了。）
- **北**（きた）北｜韩语参考：북（北）<br>
  例：その町はロンドンのすぐ北にある。（那座小镇就在伦敦北边。）
- **ギター**（ギター）吉他｜韩语参考：기타（吉他）<br>
  例：どちらがあなたのギターですか。（哪一把是你的吉他？）
- **汚い**（きたない）脏｜韩语参考：더럽다（脏，污浊）<br>
  例：ジャックは私に汚いいたずらをした。（杰克对我搞了个卑鄙的恶作剧。）
- **喫茶店**（きっさてん）咖啡馆｜韩语参考：다방（茶馆，咖啡馆） / 카페（咖啡店，咖啡馆） / 커피숍（咖啡店，咖啡馆，咖啡厅）<br>
  例：私たちは喫茶店で昼食をとった。（我们在咖啡馆吃了午饭。）
- **切手**（きって）邮票｜韩语参考：우표（邮票）<br>
  例：切手の上からサインをしてください。（请在邮票上签名。）
- **牛肉**（ぎゅうにく）牛肉｜韩语参考：소고기（牛肉） / 쇠고기（牛肉）<br>
  例：日本人はイギリス人より牛肉を食べる。（日本人吃的牛肉比英国人多。）
- **牛乳**（ぎゅうにゅう）牛奶｜韩语参考：우유（牛奶）<br>
  例：牛乳はバターやチーズになります。（牛奶可以做成黄油和奶酪。）
- **教室**（きょうしつ）教室｜韩语参考：교실（教室）<br>
  例：ＬＬ教室を使ってもよいですか。（可以用语音教室吗？）
- **兄弟**（きょうだい）兄弟姐妹｜韩语参考：형제（兄弟） / 오라비（兄弟）<br>
  例：あなたは何人兄弟がいますか。（你有几个兄弟姐妹？）

  例：ビルは去年の秋に私に会いに来た。（比尔去年秋天来看过我。）

  例：ジムくんは行き過ぎの嫌いがある。（吉姆有点做事过头的毛病。）
- **切る**（きる）切；剪｜韩语参考：썰다（切，锯） / 째다（割，切） / 자르다（切断，剪，砍断）<br>
  例：トランプをよく切ってください。（请把牌好好洗一下。）

- **口**（くち）嘴；口子｜韩语参考：입（嘴，口） / 주둥이（嘴）<br>
  例：口にものをほおばってしゃべるな。（嘴里塞满东西时别说话。）
- **靴**（くつ）鞋｜韩语参考：신발<br>
  例：靴のほこりをはけではらいなさい。（把鞋上的灰刷掉。）

## 语法

- **～て も いい / ～て は いけない**：可以…／不许…
  接续：動詞て形 + も いい（です）／+ は いけない
  朝鲜语：-아/어도 되다 / -(으)면 안 되다（韩语许可用도 되다、禁止用면 안 되다；敬语疑问되어요更委婉，日语靠语调。）
- **～ながら**：一边…一边…
  接续：動詞ます形（去ます） + ながら
  朝鲜语：-(으)면서（韩语면서要求同一主语且前后动作同时；日语ながら前项多为附带动作，主句在后。）
