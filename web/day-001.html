今日语法 2 条

N は N です
발음N 와 N 데스
…是…
名詞 + は + 名詞 + です
判断句，介绍身份/事物，礼貌体
와타시와가쿠세이데스.
私は学生です。
我是学生。
코레와혼데스.
これは本です。
这是书。
朝鲜语：입니다 / 이에요
韩语敬语由终结词尾입니다/이에요承担，日语靠です；名词后还须按有无收音选은/는。
易错点

私は学生だ。 → 私は学生です。（「私は学生だ。」本身是合法的普通体，不是错句；但本题要求礼貌体，所以句末要用 です。需要区分「语法错误」和「语体不匹配」。）

〜か（or）
발음〜카
…或…
名词 + か + 名词
表示两个以上选项中的选择，可用于陈述或疑问。
노미모노와코오히이카코우차가이이데스.
飲み物はコーヒーか紅茶がいいです。
饮料咖啡或红茶都行。
도요우비카니치요우비니카이모노니이키마스.
土曜日か日曜日に買い物に行きます。
我星期六或星期天去买东西。
에키마데바스카타쿠시이데이키마스.
駅までバスかタクシーで行きます。
坐公交车或出租车去车站。
朝鲜语：나/이나
韩语 나/이나 兼表选择和列举，日语 か 表选择、や 表列举，分工更明确。
易错点

飲み物はコーヒーと紅茶かがいいです。 → 飲み物はコーヒーか紅茶がいいです。（表选择时用「AかB」，不能与 と 混用）
