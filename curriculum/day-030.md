# Day 030 · 普通形 + か どうか、普通形 + んです / のだ、N に Vて ほしい / Vないで ほしい、名詞/な形词干 + みたい(だ/な/に)

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **普通形 + か どうか**：是否…；…还是不…
  接续：動詞/い形 普通形 + かどうか；名詞・な形 词干 + かどうか（不加 だ/な）；疑问词问句不用 かどうか
  朝鲜语：-는지 / -(으)ㄴ지（오는지 对照 来るかどうか，학생인지 对照 学生かどうか。名词可直接接 かどうか；问谁、哪里时用疑问词 + か。）
- **普通形 + んです / のだ**：（是）因为…；其实是…（说明/强调语气）
  接续：動詞・い形 普通形 + んです；な形・名詞 + な + んです；礼貌体 んです，简体 のだ／んだ
  朝鲜语：-거든요 / -는데요 / -잖아요（韩语说明语气由거든요、는데요、잖아요等分担；日语んです一形统合，须按语境选择。）
- **N に Vて ほしい / Vないで ほしい**：希望（别人）做…／希望别…
  接续：動詞 て形 + ほしい；否定 ない形 + で + ほしい；动作主体用 に（或 が）
  朝鲜语：-아/어 주기를 바라다（韩语希望别人做用주기를 바라다，对长辈须加시；日语てほしい不宜直接对长辈说。）
- **名詞/な形词干 + みたい(だ/な/に)**：好像…；像…一样（口语推量/比喻）
  接续：名詞 + みたい（不加 の）；な形 词干 + みたい；動詞/い形 普通形 + みたい；みたいな＋名／みたいに＋動
  朝鲜语：-(으)ㄴ 것 같다 / -처럼（船みたいだ 可对照 배 같아，船のようだ 可对照 배와 같다。みたい 常见于会话；名词前用 みたいな、动作前用 みたいに。）
