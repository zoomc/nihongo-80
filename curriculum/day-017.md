# Day 017 · 比较（より／ほうが／ほど）、～に 行く / 来る（移动目的）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「比较（より／ほうが／ほど）、～に 行く / 来る（移动目的）」造两句自己的话，表达：比…／不如…；去／来做…

## 语法

- **比较（より／ほうが／ほど）**：比…／不如…
  接续：A は B より ～；A より B の ほうが ～；A は B ほど ～ない
  朝鲜语：A가 B보다 + 형용사（韩语可用 보다 表比较基准；「没昨天冷」可说 어제보다 춥지 않다，也可用 만큼 与否定表达。）
- **～に 行く / 来る（移动目的）**：去／来做…
  接续：動詞ます形（去ます）／名詞 + に + 移動動詞 行く/来る
  朝鲜语：-(으)러 가다/오다（韩语目的用(으)러接动作动词，名词目的用에；日语に接ます干或サ変名词。）
