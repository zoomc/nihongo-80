## 语法

- **N + に 対して / に 関して**：对…（针对对象/对比）／关于…（书面）
  接续：名詞 + に対して（动作/态度的对象，或「与此相对」的对比）；名詞 + に関して（＝について 的书面语）
  朝鲜语：-에 대해 / -에 관해（韩语에 대해表针对，에 관해表关于，二者都可书面；日语に対して还表对比，韩语须用에 비해。）
- **N / V辞書形 + に 伴って / に つれて / に 従って**：随着…（前项变化，后项也跟着变化）
  接续：名詞 + に／動詞 辞書形 + に + 伴って・つれて・従って；后项须是变化动词（増える／変わる／高くなる 等）
  朝鲜语：-에 따라 / -(으)면서（韩语伴随变化用에 따라或면서，比例变化多用ㄹ수록；日语三形语感细分更多。）
