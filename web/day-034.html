③ 语法 7 分钟

～に なる / ～く なる / ～に する
名詞/な形 + に + なる；い形 + く + なる；他动词 〜に/く する
变成…／使…变得…

なる 自动词表自然变化，する 他动词表人为改变

彼は医者になりました。
他当上医生了。
部屋が静かになりました。
房间变安静了。
朝鲜语：-아/어지다 / -게 하다
韩语变化用아/어지다，人为改变用게 하다；无日语なる/する的自动他动对立。

易错：部屋を静かになりました。 → 部屋が静かになりました。／部屋を静かにしました。（「なる」是自动词，主体用 が；人为改变才用 を+する）

～と 思う / ～と 言う
普通形从句 + と + 思う／言う
觉得…／说「…」

引用助词 と；从句用普通形，不用 です/ます

明日は雨だと思います。
我觉得明天会下雨。
彼は行きたくないと言いました。
他说不想去。
朝鲜语：-다고 생각하다 / -라고 말하다
韩语引用按句类选다고/라고/냐고，动词要变化；日语と引用保留原形即可。

易错：明日は雨です と思います。 → 明日は雨だと思います。（「です」不能直接接「と思います」（引用从句要用普通体）。应说「明日は雨だと思います」。这不是 です 本身错，而是嵌在引用从句里的语体不对。）
