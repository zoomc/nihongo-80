今日语法 3 条

名詞/な形词干 + みたい(だ/な/に)
好像…；像…一样（口语推量/比喻）
名詞 + みたい（不加 の）；な形 词干 + みたい；動詞/い形 普通形 + みたい；みたいな＋名／みたいに＋動
口语版 〜ようだ（G0044）；比 らしい/そう 更随意；比喻用 まるで…みたい
카레와겐키자나이미타이데스.
彼は元気じゃないみたいです。
他好像不太精神。
쿄우와하루미타이니아타타카이데스.
今日は春みたいに暖かいです。
今天暖和得像春天。
朝鲜语：-(으)ㄴ 것 같다 / -처럼
韩语比喻和推测都用같다，口语最常用；日语みたい是ようだ口语版，韩语无正式口语两套。
易错点

彼は学生のみたいです。 → 彼は学生みたいです。（名词接 みたい 不加 の（ようだ 才要 の）；中文「像是学生」直译加 の 错）

V ます形(去ます) + やすい / にくい
발음V 마스카타치 + 야스이 / 니쿠이
容易…／难以…
動詞 ます形 去 ます + やすい・にくい；整体按 い形容詞 变形（読みやすくない／読みやすかった）
表示做该动作的难易程度（不是能力），主语多用 が；偏客观属性
코노혼와요미야스이데스.
この本は読みやすいです。
这本书好读。
코노펜와카키니쿠이데스.
このペンは書きにくいです。
这支笔不好写。
朝鲜语：-기 쉽다 / -기 어렵다
韩语用기 쉽다/어렵다分析形，书面感强；日语やすい/にくい是一体化后缀，更口语。
易错点

この本は読むやすいです。 → この本は読みやすいです。（必须接 ます形去ます（読み），不能用辞书形 読む；中文「容易读」直译错）

Vます形(去ます)/い形(去い)/な形词干 + すぎる
过于…；…得过头
動詞ます形去ます、い形容词去 い、な形容词/名词 词干 + すぎる；すぎる 按一段动词变形
超过适度；な形/名词直接接（静かすぎる／甘すぎる），不加 な；食べすぎる 是复合动词
타베스기테오하라가이타이데스.
食べすぎてお腹が痛いです。
吃多了肚子疼。
코노쿠쓰와타카스기마스.
この靴は高すぎます。
这鞋太贵了。
朝鲜语：너무 / -기에는 너무
韩语너무是副词，直接修饰谓语；日语すぎる是后缀，须接词干，且可单独作谓语。
易错点

食べるすぎます。 → 食べすぎます。（必须接 ます形去ます（食べ），不能用辞书形；中文「吃太多」直译错）
