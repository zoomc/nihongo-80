今日语法 2 条

N + に 基づいて / を もとに / どおり(に)
名詞 + に基づいて（依据资料/规则/数据）；名詞 + をもとに（以…为素材/基础）；名詞 + どおり(に)（照原样、按预定）
N + に 基づいて / を もとに / どおり(に)
基于…／以…为依据／按照…
书面；に基づいて 偏「依据权威来源」，をもとに 偏「以…为材料加工」，どおり 偏「不改动地照做」
調査結果に基づいて、報告書を作成しました。
依据调查结果写成了报告。
予定どおりに、会議を始めます。
按预定开始会议。
朝鲜语：-에 근거해 / -을 바탕으로 / -대로
韩语에 근거해表依据、을 바탕으로表以…为基础、대로表按照，与日语三形基本对应。
易错点

資料に基づいてに書きました。 → 資料に基づいて書きました。（に基づいて 已含 に，不再叠 に；中文「基于资料」直译叠加助词错）

V ば形 + 同一動詞 辞書形 + ほど
動詞 条件形(ば) + 同じ動詞 辞書形 + ほど；い形 ければ＋い形＋ほど；な形 なら＋な形＋ほど
V ば形 + 同一動詞 辞書形 + ほど
越…越…
前后同词重复，表成正比变化；常与 ますます 呼应
練習すればするほど、上手になります。
越练越熟练。
値段が高ければ高いほど、売れにくくなります。
价格越贵越难卖。
朝鲜语：-(으)면 -(으)ㄹ수록
韩语用면…ㄹ수록前后同词，结构与日语ば…ほど对应；但韩语可省略前项只留수록。
易错点

練習すれば、上手になります。 → 練習すればするほど上手になります。（这是普通条件句，不含「越…越…」；中文「越练越好」直译丢 ほど 错）
