# Day 003 · N も、これ / それ / あれ / どれ は N です

- 阶段：P0｜60 分钟｜常规日
- Can-do：用「N も、これ / それ / あれ / どれ は N です」造两句自己的话，表达：…也…；这/那/那是…

## 新词 9

- **何**（なん）什么｜韩语参考：무엇 / 뭐<br>
  例：これは何ですか。（这是什么？）
- **いくら**（いくら）多少钱｜韩语参考：얼마<br>
  例：これはいくらですか。（这个多少钱？）
- **円**（えん）日元（货币单位）｜韩语参考：엔（일본 화폐 단위）<br>
  例：百円です。（一百日元。）
- **今**（いま）现在｜韩语参考：시방（刚刚，现在） / 이제（现在） / 인제（现在，到现在）<br>
  例：今、何時ですか。（现在几点？）
- **今日**（きょう）今天｜韩语参考：금일（今日，今天） / 오늘（今天，今日）<br>
  例：今日は月曜日です。（今天是周一。）
- **明日**（あした）明天｜韩语参考：내일（明天）<br>
  例：明日、学校へ行きます。（明天去学校。）
- **昨日**（きのう）昨天｜韩语参考：어제（昨天，昨日） / 어저께（在昨天，在昨日）<br>
  例：昨日は日曜日でした。（昨天是周日。）
- **朝**（あさ）早晨｜韩语参考：아침（早上，早晨）<br>
  例：朝ご飯を食べます。（吃早饭。）
- **時間**（じかん）时间；小时｜韩语参考：시간（时间）<br>
  例：時間がありません。（没时间。）

## 语法

- **N も**：…也…
  接续：名詞 + も（替代 は/が/を）
  朝鲜语：도（韩语 도 和日语 も 都可表示追加，常替换主格或宾格助词；叠加其他助词须按具体语境判断。）
- **これ / それ / あれ / どれ は N です**：这/那/那是…
  接续：指示代名词 + は + 名詞 + です
  朝鲜语：이것 / 그것 / 저것 / 어느 것（韩语指示三分与日语相同，但修饰名词要用이/그/저且与것分写；日语可直接连体。）
