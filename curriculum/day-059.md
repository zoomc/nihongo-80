## 新词 25

- **香り**（かおり）香味；香气｜韩语参考：향（香味） / 향기（香气，香味） / 향내（香味，香气）<br>
  例：そのバラはよい香りを発散した。（那朵玫瑰散发出好闻的香味。）
- **画家**（がか）画家｜韩语参考：화가（画家）<br>
  例：その画家は、いわば永遠の少年だ。（那位画家可以说是永远的少年。）
- **抱える**（かかえる）抱着；背负｜韩语参考：안다 / 떠안다<br>
  例：彼は両手に大きな箱を抱えていた。（他双手抱着一个大箱子。）
- **価格**（かかく）价格｜韩语参考：가격（价格，价钱） / 값（价格，价钱）<br>
  例：最も良い価格で見積もって下さい。（请报最好的价格。）
- **化学**（かがく）化学｜韩语参考：화학（化学）<br>
  例：貴方は、化学を勉強しますか。（你学化学吗？）

- **限る**（かぎる）限于；限定｜韩语参考：한하다（限于，仅限） / 제한하다（限制，限定） / 한정하다（限定）<br>

- **家具**（かぐ）家具｜韩语参考：가구（家具）<br>

  例：彼は非常に学がある。（他非常有学问。）
- **額**（がく）金额；额头｜韩语参考：금액（金额）<br>
  例：この額は税込みです。（这个金额含税。）
- **覚悟**（かくご）思想准备；决心｜韩语参考：각오（心理准备，思想准备）<br>
  例：私はすでに覚悟はできています。（我已经做好准备了。）
- **確実**（かくじつ）确实；可靠｜韩语参考：확실하다<br>
  例：これは遅いけど確実な方法だ。（这方法虽慢但可靠。）
- **学者**（がくしゃ）学者｜韩语参考：학자（学者） / 학사（学者）<br>
  例：その学者はライフワークを続けた。（那位学者继续着他毕生的事业。）
- **学習**（がくしゅう）学习｜韩语参考：학습（学习） / 공부（学习，读书）<br>
  例：これは生物の学習法としてはあまりよくないと思う。（我觉得这作为生物的学习方法不太好。）
- **欠ける**（かける）缺少；欠缺｜韩语参考：결하다（缺，缺乏，欠缺） / 부재하다（不在，不力，欠缺）<br>
  例：メアリーは思いやりに欠けている。（玛丽缺乏体贴。）
- **加減**（かげん）程度；分寸（如盐量、火候）｜韩语参考：정도 / 불 조절<br>
  例：味見をして、塩加減を調整する。（先尝一下，再调整咸淡。）
- **過去**（かこ）过去｜韩语参考：과거（过去，从前） / 어제（过去，往日）<br>
  例：私はいつまでも過去にこだわらないようにと心がけている。（我一直提醒自己不要总纠结于过去。）
- **籠**（かご）篮子｜韩语参考：바구니（篮子，篮，筐）<br>

- **囲む**（かこむ）围住；包围｜韩语参考：싸다（围，围住） / 둘러싸다（包围）<br>
  例：庭は木のフェンスで囲まれていた。（院子被木栅栏围着。）
- **火災**（かさい）火灾｜韩语参考：화재（火灾） / 불（火灾）<br>
  例：火災の理由は何か。（火灾的原因是什么？）
- **菓子**（かし）点心；糕点｜韩语参考：과자<br>
  例：この菓子を自由にお取り下さい。（请随便拿这些点心。）
- **貸し**（かし）借出；人情｜韩语参考：빌려줌 / 빚진 것<br>
  例：でも、これで１つ貸しだね。（不过这样一来你就欠我一个人情了。）
- **家事**（かじ）家务｜韩语参考：가사（家务） / 집일（家务） / 가정일（家务）<br>
  例：私は両親が家事をするのを手伝った。（我帮父母做了家务。）

## 语法

- **普通形 + はずがない**：不可能…；理应不会…
  接续：動詞・い形普通形 + はずがない；な形容詞 + な／名詞 + の + はずがない
  朝鲜语：-(으)ㄹ 리가 없다（韩语ㄹ 리가 없다表绝不可能，推断依据强；与单纯否定안不同，同日语はずがない。）
- **〜わけだ**：难怪…；也就是说…
  接续：普通形 + わけだ；ナ形容词 + な + わけだ；名词 + という + わけだ
  朝鲜语：어쩐지 …더라 / 그러니까 …라는 말이다（「暖气没开，难怪冷」可想成 어쩐지 춥더라。做逻辑推算时可说 그러니까 …라는 말이다。わけだ 比单纯的 -는 셈이다 涵盖的语境更广。）
- **〜わけではない**：并不是…；并非…
  接续：普通形 + わけではない；ナ形容词 + な + わけではない；名词 + という + わけではない
  朝鲜语：-는 것은 아니다（韩语「-는 것은 아니다」也表部分否定，但常缩成「-는 게 아니다」；日语「わけではない」更明确针对“由此推出的结论”。）
