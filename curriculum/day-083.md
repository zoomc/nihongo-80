# Day 083 · V辞書形 + ため(に) / 普通形・N の + ため(に)、普通形 + のに（な形・名詞 は 〜な のに）

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「V辞書形 + ため(に) / 普通形・N の + ため(に)、普通形 + のに（な形・名詞 は 〜な のに）」造两句自己的话，表达：为了…（目的）／因为…、由于…（原因）；明明…却…；…却（意外、不满、遗憾）

## 新词 20

- **息**（いき）呼吸｜韩语参考：숨（呼吸）<br>
  例：おぼれかけた人は息を吹き返した。（快淹死的人缓过气来了。）
- **勢い**（いきおい）势头｜韩语参考：세（势头）<br>
  例：勢いに流されているんですよ。（你是被势头推着走。）
- **生き物**（いきもの）生物；活物｜韩语参考：생물체（生物体，生物）<br>
  例：人は意識のある生き物だ。（人是有意识的生物。）
- **いけない**（いけない）不行；必须｜韩语参考：안 된다 / 반드시 ~해야 한다<br>
  例：友人は助け合わなければいけない。（朋友之间必须互相帮助。）
- **意志**（いし）意志｜韩语参考：의지（意志） / 심지（意志，心志）<br>
  例：私は辞職する意志はまったくない。（我完全没有辞职的意思。）
- **意思**（いし）意思；意图｜韩语参考：용의（用意，意思）<br>
  例：人間は互いに言葉で意思を通じ合う。（人通过语言互相沟通意思。）
- **医師**（いし）医生｜韩语参考：의사（医生）<br>
  例：彼は医師になるために勉強している。（他为了当医生在学习。）
- **維持**（いじ）维持｜韩语参考：유지（维持，维护）<br>
  例：この車の維持は高くつく。（养这辆车很费钱。）
- **意識**（いしき）意识；顾及｜韩语参考：의식（意识）<br>
  例：このお料理は、パリのエスプリを意識して、味付けしてみました。（这道菜是顾及巴黎风味调味的。）
- **異常**（いじょう）异常｜韩语参考：이상（异常，反常，不正常）<br>
  例：そんなにたくさん食べるのは異常だ。（吃那么多是不正常的。）
- **泉**（いずみ）泉；喷泉｜韩语参考：샘（泉，泉水）<br>
  例：泉はおよそ１７０フィートの高さまで温水を吹き出す。（喷泉把温水喷到约一百七十英尺高。）
- **いずれ**（いずれ）早晚；哪个｜韩语参考：언젠가 / 어느 쪽<br>
  例：人間はいずれ死ぬのだ。（人早晚都会死。）
- **以前**（いぜん）以前｜韩语参考：이전（以前，之前） / 앞（前，以前） / 예（以前）<br>
  例：彼女はもはや以前の彼女ではない。（她已经不是从前的她了。）
- **板**（いた）板｜韩语参考：판 / 널빤지<br>
  例：この鉄の板はすずでメッキしてある。（这块铁板镀了锡。）
- **偉大**（いだい）伟大｜韩语参考：위대하다<br>
  例：リンカーンは偉大な政治家であった。（林肯是伟大的政治家。）
- **抱く**（いだく）怀抱；怀有｜韩语参考：안다（抱着，怀有）<br>
  例：母への感謝の気持ちを抱いています。（怀着对母亲的感激之情。）
- **いたずら**（いたずら）恶作剧；淘气｜韩语参考：장난 / 개구쟁이짓<br>
  例：私はいたずらな子供を大目に見る事ができない。（我没法容忍淘气的孩子。）
- **痛み**（いたみ）疼痛｜韩语参考：통증（疼痛）<br>
  例：ここにしつこい痛みがあります。（我这里一直疼。）
- **至る**（いたる）达到｜韩语参考：이르다（达到） / 다다르다（达到）<br>
  例：その語は広い意味を持つに至った。（那个词有了很广的含义。）
- **いち**（いち）集市｜韩语参考：시장<br>
  例：市は月曜ごとに立つ。（集市每周一开。）

## 语法

- **V辞書形 + ため(に) / 普通形・N の + ため(に)**：为了…（目的）／因为…、由于…（原因）
  接续：目的：意志动词 辞書形 + ため(に)；原因：普通形（多为 た形/ている/ない）或 名詞 + の + ため(に)
  朝鲜语：-기 위해(서) / -때문에（韩语目的用기 위해(서)，原因用때문에；日语ために两义同形，须靠后项判断。）
- **普通形 + のに（な形・名詞 は 〜な のに）**：明明…却…；…却（意外、不满、遗憾）
  接续：動詞・い形 普通形 + のに；な形・名詞 + な + のに；后项是与预期相反的结果
  朝鲜语：-는데도 / -(으)ㄴ데도（韩语逆接用는데도，带不满或意外；日语のに情绪更强，还能置于句末表遗憾。）
