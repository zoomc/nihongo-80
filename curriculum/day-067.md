# Day 067 · V辞書形 + ため(に) / 普通形・N の + ため(に)、普通形 + のに（な形・名詞 は 〜な のに）

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「V辞書形 + ため(に) / 普通形・N の + ため(に)、普通形 + のに（な形・名詞 は 〜な のに）」造两句自己的话，表达：为了…（目的）／因为…、由于…（原因）；明明…却…；…却（意外、不满、遗憾）

## 新词 24

- **具体的**（ぐたいてき）具体的｜韩语参考：구체적（具体的，有形的）<br>
  例：具体的な例を教えてください。（请举具体例子。）
- **積極的**（せっきょくてき）积极的｜韩语参考：적극적（积极的）<br>
  例：彼は仕事に積極的です。（他对工作很积极。）
- **一般的**（いっぱんてき）一般的；普遍的｜韩语参考：일반적（一般的，普通的）<br>
  例：日本では、一般的にこの方法が使われます。（在日本，通常使用这种方法。）
- **定期的**（ていきてき）定期地；周期性的｜韩语参考：정기적으로<br>
  例：定期的に健康診断を受けています。（定期做健康检查。）
- **突然**（とつぜん）突然｜韩语参考：대뜸（马上，立即，突然） / 돌연（突然，突如其来，冷不防） / 돌연히（突然地，突如其来地，冷不防地，出乎意料地）<br>
  例：突然、雨が降り始めました。（突然开始下雨了。）
- **直ちに**（ただちに）立刻；立即｜韩语参考：곧장（马上，立即） / 금방（马上，立刻，立马） / 대뜸（马上，立即，突然）<br>
  例：危険を感じたら、直ちに避難してください。（感到危险请立即避难。）
- **次第に**（しだいに）逐渐｜韩语参考：차차（渐渐，逐渐） / 차츰（渐渐，逐渐） / 차츰차츰（逐渐，渐渐）<br>
  例：次第に日が長くなりました。（白天逐渐变长了。）
- **翌日**（よくじつ）次日；第二天｜韩语参考：뒷날（第二天） / 익일（翌日，明天，第二天） / 이튿날（第二天，翌日，次日）<br>
  例：注文した翌日に商品が届きました。（下单第二天商品就到了。）
- **途中**（とちゅう）途中；中途｜韩语参考：도중（途中，路上） / 중간（中途，中期）<br>
  例：駅へ行く途中で友達に会いました。（去车站的路上遇到了朋友。）
- **愛**（あい）爱｜韩语参考：사랑（爱，爱情，恋情）<br>
  例：愛とは夢にまで彼女を見ることだ。（爱就是连梦里都见到她。）
- **愛情**（あいじょう）爱；关爱｜韩语参考：애정（爱，爱心） / 사랑（爱，爱情，恋情）<br>
  例：とりわけ子供たちは愛情を必要とする。（孩子尤其需要关爱。）
- **合図**（あいず）信号；示意｜韩语参考：신호（信号） / 시그널（信号） / 신호탄（开端，信号弹）<br>
  例：すぐにゴーの合図をしてください。（请马上给出开始的信号。）
- **アイスクリーム**（アイスクリーム）冰淇淋｜韩语参考：아이스크림（冰淇淋）<br>
  例：アイスクリームを３つください。（请给我三个冰淇淋。）
- **愛する**（あいする）爱｜韩语参考：사랑하다（爱）<br>
  例：ロメオはジュリエットが愛している男だ。（罗密欧是朱丽叶爱着的男人。）
- **相手**（あいて）对方；对象｜韩语参考：상대（相对，对象） / 상대방（对方）<br>
  例：あなたのダンスの相手はだれですか。（你的舞伴是谁。）
- **あいにく**（あいにく）不凑巧｜韩语参考：공교롭게도<br>
  例：あいにく私はお金を持っていない。（不凑巧，我身上没带钱。）
- **アイロン**（アイロン）熨斗｜韩语参考：다리미（熨斗）<br>
  例：アイロンで手をやけどしました。（我用熨斗把手烫伤了。）
- **アウト**（アウト）出局｜韩语参考：아웃（出局）<br>
  例：最初の打者はアウトになった。（第一个击球手出局了。）
- **明かり**（あかり）灯光｜韩语参考：불빛（灯光） / 전깃불（电灯，灯光） / 전등불（灯光）<br>
  例：どうか明かりをつけて下さい。（请把灯打开。）
- **空き**（あき）空隙；空位｜韩语参考：빈자리 / 틈<br>
  例：字と字の間の空きをもっと広くしなさい。（把字与字之间的空隙留大一些。）
- **明らか**（あきらか）明显｜韩语参考：명백하다<br>
  例：その船が沈んだのは明らかだ。（那艘船沉了，这是明摆着的。）
- **諦める**（あきらめる）放弃｜韩语参考：버리다（放弃，舍弃，放手） / 체념하다（死心，放弃，断念） / 포기하다（放弃）<br>
  例：その少年は死んだものとしてあきらめられた。（那个少年被当作死了而放弃了。）
- **飽きる**（あきる）腻；厌倦｜韩语参考：물리다（腻，厌烦） / 질리다（腻，厌烦）<br>
  例：息子はハンバーガーにあきています。（儿子吃腻了汉堡。）
- **握手**（あくしゅ）握手｜韩语参考：악수（握手）<br>
  例：彼は友人と握手した。（他和朋友握了手。）

## 语法

- **V辞書形 + ため(に) / 普通形・N の + ため(に)**：为了…（目的）／因为…、由于…（原因）
  接续：目的：意志动词 辞書形 + ため(に)；原因：普通形（多为 た形/ている/ない）或 名詞 + の + ため(に)
  朝鲜语：-기 위해(서) / -때문에（韩语目的用기 위해(서)，原因用때문에；日语ために两义同形，须靠后项判断。）
- **普通形 + のに（な形・名詞 は 〜な のに）**：明明…却…；…却（意外、不满、遗憾）
  接续：動詞・い形 普通形 + のに；な形・名詞 + な + のに；后项是与预期相反的结果
  朝鲜语：-는데도 / -(으)ㄴ데도（韩语逆接用는데도，带不满或意外；日语のに情绪更强，还能置于句末表遗憾。）

## 汉字 6

- **連** 连接；带领；连续｜音：レン｜训：つら.なる、つら.ねる、つ.れる、-づ.れ
- **対** 对；相对；对抗｜音：タイ、ツイ｜训：あいて、こた.える、そろ.い、つれあ.い、なら.ぶ、むか.う

- **市** 城市；市场｜音：シ｜训：いち
- **内** 内部；里面｜音：ナイ、ダイ｜训：うち
- **定** 决定；规定｜音：テイ、ジョウ｜训：さだ.める、さだ.まる、さだ.か
