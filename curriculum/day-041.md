# Day 041 · 授受 ～てあげる／てくれる／てもらう、〜てもらう

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「授受 ～てあげる／てくれる／てもらう、〜てもらう」造两句自己的话，表达：给（别人）做…／给（我）做…／请（人）做…；请别人为我做…；得到…

## 新词 19

- **草**（くさ）草｜韩语参考：풀（草）<br>
  例：月には草が生えて無い。（月球上没长草。）
- **首**（くび）脖子｜韩语参考：목（脖子，颈）<br>
  例：あなたの首は風前のともし火だ。（你的脖子岌岌可危。）
- **雲**（くも）云｜韩语参考：구름（云，云彩）<br>
  例：雲がだんだん黒くなっています。（云渐渐变黑了。）
- **くれる**（くれる）给（我）｜韩语参考：주다（나에게）<br>
  例：友達がはがきをくれるように私に頼んだ。（朋友托我给他寄明信片。）
- **暮れる**（くれる）天黑；日暮｜韩语参考：저물다（日落，天黑）<br>
  例：知らぬ間に日はとっぷりと暮れていた。（不知不觉天已经全黑了。）
- **毛**（け）毛｜韩语参考：털（毛，毛发）<br>
  例：犬の毛はいわばセーターだ。（狗的毛好比一件毛衣。）
- **計画**（けいかく）计划｜韩语参考：계획（计划，筹划） / 작정（打算，计划）<br>
  例：その計画では彼に同調できました。（那个计划我倒是赞同他。）
- **警察**（けいさつ）警察｜韩语参考：경찰（警方，警察当局）<br>
  例：その場合には警察を呼びなさい。（那种情况下就叫警察。）
- **ケーキ**（ケーキ）蛋糕｜韩语参考：케이크（蛋糕）<br>
  例：ケイトはケーキの作り方を知っています。（凯特会做蛋糕。）
- **けがする**（けがする）受伤｜韩语参考：다치다<br>
  例：特定の食べ物を食べた後に、胸やけがするのですか？（吃了某些食物后会烧心吗？）
- **景色**（けしき）景色｜韩语参考：경관（景观，景色） / 경치（风景，景色） / 풍경（风景，风光，景色，景致）<br>
  例：それは私が見たことのない景色だ。（那是我从没见过的景色。）
- **消しゴム**（けしゴム）橡皮｜韩语参考：지우개（橡皮擦）<br>
  例：ちょっと消しゴムをかしてくれませんか。（能借我一下橡皮吗？）
- **下宿**（げしゅく）寄宿｜韩语参考：하숙（寄宿，下宿，借宿） / 하숙집（寄宿处）<br>
  例：彼女は学生を下宿させている。（她让学生住在自己家里。）
- **決して**（けっして）决不｜韩语参考：결코（부정과 함께）<br>
  例：これは決して小さなことではない。（这绝不是小事。）
- **けれど**（けれど）但是｜韩语参考：그러나<br>
  例：ちょっと会いたいのだけれど。（我有点想见你。）
- **けんかする**（けんかする）吵架｜韩语参考：싸우다<br>
  例：ケンとけんかしたのか。（你跟健吵架了？）
- **研究**（けんきゅう）研究｜韩语参考：연구（研究）<br>
  例：あなたのご研究は、いかがですか。（您的研究进展如何？）
- **研究室**（けんきゅうしつ）研究室｜韩语参考：연구실（研究室）<br>
  例：私たちはその研究室を利用した。（我们使用了那间研究室。）
- **見物**（けんぶつ）参观；游览｜韩语参考：구경（赏，观看，游览）<br>
  例：どこを見物すればいいでしょうか。（去哪儿游览比较好呢？）

## 语法

- **授受 ～てあげる／てくれる／てもらう**：给（别人）做…／给（我）做…／请（人）做…
  接续：動詞て形 + あげる／くれる／もらう
  朝鲜语：-아/어 주다 / -아·어 받다（韩语只用주다(给)与받다(受)，无あげる/くれる/もらう的方向三分；敬语用드리다/주시다。）
- **〜てもらう**：请别人为我做…；得到…
  接续：动词て形 + もらう（施益者用 に/から 标记）
  朝鲜语：-아/어 받다（韩语常用 -아/어 받다 或 -해 주시다；日语 てもらう 强调接受者视角，施益者用 に，韩语则多用 에게/한테。）
