# Day 049 · 〜てくる、〜てしまう / 〜ちゃう

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜てくる、〜てしまう / 〜ちゃう」造两句自己的话，表达：…来；一直…到现在；开始…；…完了；不小心…；结果…

## 新词 19

- **子**（こ）孩子｜韩语参考：애（孩子，小孩） / 아이（小孩，孩子）<br>
  例：彼はきっすいのロンドン子です。（他是地道的伦敦人。）
- **こう**（こう）这样｜韩语参考：이렇게<br>
  例：紙をこう折ってください。（请这样折纸。）
- **郊外**（こうがい）郊外｜韩语参考：교외（郊外） / 야외（野外，郊外）<br>
  例：私は東京の郊外に住んでいる。（我住在东京郊外。）
- **講義**（こうぎ）讲课｜韩语参考：강의（讲课，授课，讲授）<br>
  例：その講義へ来た人はほとんどいなかった。（来听那堂课的人几乎没有。）
- **工業**（こうぎょう）工业｜韩语参考：공업（工业）<br>
  例：７月の工業生産は急増した。（七月的工业生产激增。）
- **高校**（こうこう）高中｜韩语参考：고교（高中） / 고등학교（高中）<br>
  例：私の息子は、高校に入学した。（我儿子上了高中。）
- **高校生**（こうこうせい）高中生｜韩语参考：고교생（高中生） / 고등학생（高中生）<br>
  例：私はアメリカの高校生と文通をしている。（我在和美国的高中生通信。）
- **工場**（こうじょう）工厂｜韩语参考：공장（厂，工厂）<br>
  例：その工場は来月から作業を中止する。（那家工厂下个月起停工。）
- **校長**（こうちょう）校长｜韩语参考：교장（校长） / 학교장（校长）<br>
  例：校長が先生の後ろから入ってきた。（校长从老师身后走了进来。）
- **交通**（こうつう）交通｜韩语参考：교통（交通）<br>
  例：交通に注意しなければいけない。（必须注意交通安全。）
- **講堂**（こうどう）礼堂｜韩语参考：강당（礼堂，大礼堂）<br>
  例：その教師は講堂に学生を集めた。（那位老师把学生集合到礼堂。）
- **高等学校**（こうとうがっこう）高级中学｜韩语参考：고등학교<br>
  例：彼は高等学校の生徒ではありません。（他不是高中的学生。）
- **公務員**（こうむいん）公务员｜韩语参考：공무원（公务员） / 공복（公仆，公务员） / 공직자（公职人员，公务员）<br>
  例：私は公務員です。（我是公务员。）
- **国際**（こくさい）国际｜韩语参考：국제（国际）<br>
  例：英語は国際言語である。（英语是国际语言。）

- **御主人**（ごしゅじん）您丈夫｜韩语参考：남편（상대방의）<br>
  例：あなたのご主人は食事にうるさいのかな？（你丈夫对吃的是不是很挑剔？）
- **ご存じ**（ごぞんじ）知道｜韩语参考：알고 계시다<br>

  例：なんとすばらしいごちそうでしょう。（多么丰盛的一桌菜啊。）

## 语法

- **〜てくる**：…来；一直…到现在；开始…
  接续：动词て形 + くる（てくる）
  朝鲜语：-아/어 오다（韩语 -아/어 오다 表靠近或持续至今，与 てくる 相近；但日语 てくる 还可表「顺路做某事再回来」，韩语需用 다녀오다 等动词。）
- **〜てしまう / 〜ちゃう**：…完了；不小心…；结果…
  接续：动词て形 + しまう（口语缩约 ちゃう／じゃう）
  朝鲜语：-아/어 버리다（韩语 -아/어 버리다 同样表完成或遗憾，语气很接近；但日语 しまう 还可中性表「全部做完」，韩语 버리다 的懊悔色彩更强。）
