# Day 118 · 〜だらけ、〜切る / 〜切れない

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜だらけ、〜切る / 〜切れない」各造一句自己的话，表达：满是…；净是…；…完；…不了

## 新词 25

- **軒**（のき）屋檐｜韩语参考：처마（屋檐，房檐）<br>
  例：彼女は鳥かごを軒からつるした。（她把鸟笼挂在屋檐下。）
- **残す**（のこす）留下；剩下｜韩语参考：끼치다（留下，引起） / 남기다（剩，剩下） / 뒤로하다（留下）<br>
  例：これは父が私に残してくれたものが一つある。（这是父亲留给我的一件东西。）
- **残り**（のこり）剩余；剩下的｜韩语参考：나머지（剩下的，其余的）<br>
  例：私たちの内残りの者はあとに残ることになっている。（我们其余的人要留下来。）
- **乗せる**（のせる）让…乘坐；放上｜韩语参考：태우다 / 올려놓다<br>
  例：車に乗せてください。（请让我搭一下车。）
- **除く**（のぞく）除去；除外｜韩语参考：제외하다（除外，排除）<br>
  例：医者は彼の苦痛を除いてやった。（医生解除了他的痛苦。）
- **望み**（のぞみ）希望；愿望｜韩语参考：가망（指望，希望） / 바람（希望，期望，期待） / 소망（心愿，愿望）<br>
  例：あなたの望みが実現するといいですね。（希望你的愿望能实现。）
- **望む**（のぞむ）希望；期望｜韩语参考：원하다（希望，想要） / 기대하다（期待，期望）<br>
  例：全国民が平和を望んでいる。（全国人民都希望和平。）
- **後**（のち）之后；以后｜韩语参考：나중 / 이후<br>
  例：晴れ後曇りでした。（晴转多云。）
- **ノック**（ノック）敲门｜韩语参考：노크（敲门，叩门）<br>
  例：入る前にドアをノックして下さい。（进去前请先敲门。）
- **伸ばす**（のばす）伸展；拉长｜韩语参考：벋다（伸展，舒展） / 뻗다（伸展，舒展） / 늘이다（拉长，加长）<br>
  例：右腕を伸ばせません。（我的右臂伸不直。）
- **伸びる**（のびる）伸长；增长｜韩语参考：늘다（增大，增长，增加） / 늘어지다（拉长，伸长，变长，变松）<br>
  例：消費は心持ち伸びる程度でしょう。（消费大概只会略微增长。）
- **述べる**（のべる）陈述；叙述｜韩语参考：말하다 / 서술하다<br>
  例：私は客に別れのあいさつを述べた。（我向客人致了告别辞。）
- **昇る**（のぼる）上升；升起｜韩语参考：돋다（(日、月等)升起） / 솟다（升，升起） / 돋아나다（升起）<br>
  例：そのとき太陽がのぼるところだった。（那时太阳正要升起。）
- **のんびり**（のんびり）悠闲；从容｜韩语参考：느긋하게<br>
  例：日曜日はのんびりしています。（星期天我们过得很悠闲。）
- **場**（ば）场合；场所｜韩语参考：터（地点、场所、痕迹） / 판（局，场，场合） / 자리（场合）<br>
  例：このネクタイはこのような場にふさわしくありません。（这条领带不适合这种场合。）
- **はあ**（はあ）唉；嗯｜韩语参考：아 / 하아<br>
  例：・・・はぁ、どう状況を受け止めればいいのかしら。（……唉，这种情况我该怎么接受呢。）
- **パーセント**（パーセント）百分比｜韩语参考：프로（百分率, 百分比）<br>
  例：現金払いには１０パーセント割引いたします。（现金付款可打九折。）
- **灰**（はい）灰；灰烬｜韩语参考：재<br>

  例：彼女はバイオリンが大変上手です。（她小提琴拉得非常好。）
- **ハイキング**（ハイキング）徒步；远足｜韩语参考：하이킹（徒步旅行）<br>
  例：ハイキングは中止にしたほうがいいわね。（远足还是取消为好。）

- **パイプ**（パイプ）管子；烟斗｜韩语参考：파이프（烟斗）<br>

- **俳優**（はいゆう）演员｜韩语参考：배우（演员） / 연기자（演员） / 탤런트（演员）<br>
  例：彼は俳優になるべきだった。（他本来该当演员的。）
- **パイロット**（パイロット）飞行员｜韩语参考：파일럿（飞行员）<br>
  例：私の夢はパイロットになることです。（我的梦想是当飞行员。）
- **墓**（はか）坟墓｜韩语参考：무덤（坟墓）<br>
  例：私は彼の墓を立ち去り難かった。（我舍不得离开他的墓。）

## 语法

- **〜だらけ**：满是…；净是…
  接续：名词 + だらけ
  朝鲜语：-투성이（韩语「-투성이」常带负面色彩；日语「だらけ」也常用于负面事物，并可接抽象名词，如「間違いだらけ」。）
- **〜切る / 〜切れない**：…完；…不了
  接续：动词ます形词干 + 切る／切れない
  朝鲜语：-아/어 내다（韩语完成用「-아/어 내다」，日常更常说「다 -다」；日语「切る」强调“彻底做到最后”，还引申出“断然”的语感。）
