# Day 077 · 家人与朋友｜〜と思う、～おかげで / ～せいで

- 阶段：P2｜60 分钟｜常规日
- Can-do：在「家人与朋友」场景里，用 〜と思う 说清一件事

## 新词 20

- **契約**（けいやく）合同；签约  
  例：来週、部屋の契約をします。（下周签房子的合同。）
- **退去**（たいきょ）搬出；退租  
  例：退去の一か月前に連絡してください。（请在搬出前一个月联系。）
- **引っ越し**（ひっこし）搬家  
  例：引っ越しの荷物をまとめています。（正在打包搬家的行李。）
- **不動産**（ふどうさん）房地产  
  例：不動産会社に部屋を紹介してもらいました。（请房产公司介绍了房子。）
- **敷金**（しききん）押金（房租押金）  
  例：敷金は家賃の一か月分です。（押金是一个月房租。）
- **共益費**（きょうえきひ）公共区域费；物业公摊费  
  例：共益費は五千円です。（公共区域费是5000日元。）
- **設備**（せつび）设备；设施  
  例：この部屋には新しい設備があります。（这个房间有新设备。）
- **症状**（しょうじょう）症状  
  例：症状が良くなりました。（症状好转了。）
- **診察**（しんさつ）诊察；看诊  
  例：午後から診察を受けます。（下午去看诊。）
- **処方**（しょほう）开处方  
  例：医者が薬を処方しました。（医生开了药。）
- **治療**（ちりょう）治疗  
  例：治療は一週間かかります。（治疗需要一周。）
- **予防**（よぼう）预防  
  例：風邪の予防に手を洗います。（为预防感冒洗手。）
- **栄養**（えいよう）营养  
  例：野菜には栄養がたくさんあります。（蔬菜有很多营养。）
- **睡眠**（すいみん）睡眠  
  例：睡眠を十分に取ることが大切です。（充足睡眠很重要。）
- **回復**（かいふく）恢复；康复  
  例：病状が回復しました。（病情恢复了。）
- **遅延**（ちえん）延误；晚点  
  例：電車に二十分の遅延が出ています。（电车晚点20分钟。）
- **運休**（うんきゅう）停运  
  例：台風で電車が運休になりました。（台风导致电车停运。）
- **乗り換え**（のりかえ）换乘  
  例：次の駅で乗り換えが必要です。（下一站需要换乘。）
- **到着**（とうちゃく）到达  
  例：電車は十時に到着します。（电车10点到达。）
- **出発**（しゅっぱつ）出发  
  例：バスは八時に出発します。（公交8点出发。）

## 语法

- **〜と思う**：我认为…
  接续：动词普通形／い形容词 + と思う；な形容词・名词 + だ + と思う
  朝鲜语：-다고 생각하다（韩语 -다고 생각하다 与 と思う 对应，但日语 と思う 常省略主语，韩语则常出现 저는；日语疑问句用 と思いますか 更委婉。）
- **～おかげで / ～せいで**：多亏…／都怪…
  接续：名/な形 + の/な + おかげで／せいで；普通形 + おかげで／せいで
  朝鲜语：-덕분에 / -때문에（韩语积极原因用덕분에，消极原因用때문에(中性)；日语せいで专表负面，色彩更固定。）
