# Day 097 · 〜さえ〜ば、〜こそ、〜として

- 阶段：P4｜60 分钟｜听力日
- Can-do：用「〜さえ〜ば、〜こそ、〜として」造两句自己的话，表达：只要…就…；正是…；才是…；作为…；以…身份

## 新词 22

- **出身**（しゅっしん）出身；毕业｜韩语参考：출신（出身，身份）<br>
  例：彼女は神戸大学の出身です。（她毕业于神户大学。）
- **出版**（しゅっぱん）出版｜韩语参考：출판（出版，出刊，刊行） / 출간（出刊，出版）<br>
  例：ついにその本を出版した。（那本书终于出版了。）
- **首都**（しゅと）首都｜韩语参考：수도（首都） / 서울（首都）<br>
  例：東京は日本の首都です。（东京是日本的首都。）
- **主婦**（しゅふ）家庭主妇｜韩语参考：주부（主妇，家庭主妇）<br>
  例：主婦は節約に努めるべきである。（家庭主妇应当努力节约。）
- **主要**（しゅよう）主要｜韩语参考：주요（主要）<br>
  例：日本の主要作物は米である。（日本的主要作物是水稻。）
- **需要**（じゅよう）需求｜韩语参考：수요（需要，需求）<br>
  例：これらの品物の需要は多いですか。（这些商品的需求量大吗？）
- **種類**（しゅるい）种类｜韩语参考：종류（种类）<br>
  例：動物園にはたくさんの種類の動物がいる。（动物园里有很多种动物。）
- **順**（じゅん）顺序；次序｜韩语参考：차례（次序）<br>
  例：用紙は順に番号が打ってある。（纸张上依次编了号。）
- **瞬間**（しゅんかん）瞬间｜韩语参考：순간（瞬间，刹那） / 삽시간（霎时，一瞬间）<br>
  例：彼女その瞬間にカッとなったんだね。（她就是在那一刻火了起来。）
- **順調**（じゅんちょう）顺利｜韩语参考：원활（顺利，顺畅，流畅） / 평탄（顺利，一帆风顺）<br>
  例：すべてが順調にいっている。（一切都很顺利。）
- **順番**（じゅんばん）顺序；轮次｜韩语参考：차례（顺序，次序）<br>
  例：私たちは彼の順番をわざと飛ばした。（我们故意跳过了他的顺序。）
- **小**（しょう）小；小号｜韩语参考：소（小）<br>
  例：大か、小か。（大的还是小的？）
- **章**（しょう）章；章节｜韩语参考：장（章）<br>
  例：先生は私に一番長い章を割り当てた。（老师把最长的一章分给了我。）
- **賞**（しょう）奖；奖项｜韩语参考：상（奖，奖赏）<br>
  例：期待されたとおり彼は賞を得た。（不出所料，他得了奖。）
- **使用**（しよう）使用｜韩语参考：사용（使用，用，应用）<br>
  例：体育館は式のために使用されます。（体育馆将用于举行仪式。）
- **障害**（しょうがい）障碍｜韩语参考：장애（障碍，阻力） / 장해（障碍，妨碍，防碍） / 거리낌（妨碍，障碍）<br>
  例：貧困は幸福への障害とはならない。（贫穷不会成为通往幸福的障碍。）
- **奨学金**（しょうがくきん）奖学金｜韩语参考：장학금（奖学金）<br>
  例：奨学金のおかげで彼女は留学した。（多亏了奖学金，她得以留学。）
- **乗客**（じょうきゃく）乘客｜韩语参考：승객（乘客） / 손님（乘客） / 탑승객（乘客）<br>
  例：乗客はどちらの側にも４人すわっていた。（乘客两侧各坐了四个人。）
- **上京**（じょうきょう）进京；去东京｜韩语参考：상경（进京，上京）<br>
  例：彼は商用で上京した。（他为做生意去了东京。）
- **正午**（しょうご）正午；中午｜韩语参考：정오（正午）<br>
  例：彼は正午までここにいるでしょう。（他会在这里待到中午吧。）
- **正直**（しょうじき）诚实；老实｜韩语参考：정직하다<br>
  例：彼は正直なので多くの友人がいる。（他为人诚实，所以朋友很多。）
- **常識**（じょうしき）常识｜韩语参考：상식（常识）<br>
  例：彼女には常識が欠けている。（她缺乏常识。）

## 语法

- **〜さえ〜ば**：只要…就…
  接续：名词 + さえ + ば形；动词ます形词干 + さえ + すれば；动词て形 + さえ + いれば
  朝鲜语：-기만 하면（韩语「-기만 하면」与「さえ〜ば」对应；但日语「さえ」位置固定在各成分后，韩语统一贴在动词后，语序处理不同。）
- **〜こそ**：正是…；才是…
  接续：名词 + こそ（可加「が」成「こそが」）
  朝鲜语：-야말로（韩语「-야말로」与「こそ」几乎一致；但日语「こちらこそ」已成固定寒暄，韩语对应「저야말로」，礼貌度需注意。）
- **〜として**：作为…；以…身份
  接续：名词 + として；名词 + としての + 名词
  朝鲜语：-로서（韩语「-로서」表资格，与「として」对应；但韩语另有「-로써」表手段，日语「として」不表手段，切勿混用。）
