今日语法 3 条

韩语对应-(으)ㄹ 리가 없다
韩语ㄹ 리가 없다表绝不可能，推断依据强；与单纯否定안不同，同日语はずがない。
普通形 + はずがない
不可能…；理应不会…
動詞・い形普通形 + はずがない；な形容詞 + な／名詞 + の + はずがない
根据事实/常识强烈否定某可能性；比单纯「ない」更有推断依据。
카레가야쿠소쿠오와스레루하즈가아리마센.
彼が約束を忘れるはずがありません。
他不可能忘记约定。
電車が止まっているので、今到着するはずがありません。
电车停了，现在不可能到达。
易错点

彼が来るはずがないでした。 → 彼が来るはずがありませんでした。（はずがない 是现在否定，过去用「はずがありませんでした／はずがなかったです」；ないでした 不合法。）

韩语对应-는 셈이다
韩语「-는 셈이다」侧重“算作某种结果”；日语「わけだ」更强调说话人由事实推导的过程，常带“原来如此”的领悟语气。
〜わけだ
발음〜와케다
难怪…；也就是说…
普通形 + わけだ；ナ形容词 + な + わけだ；名词 + という + わけだ
由已知事实推出结论，常与「どうりで」呼应。
산넴모추우고쿠니슨데이탄데스카.다카라추우고쿠고가조우즈나와케데스네.
三年も中国に住んでいたんですか。だから中国語が上手なわけですね。
在中国住了三年啊。难怪你中文这么好。
窓が全部開いている。どうりで寒いわけだ。
窗户全开着。难怪这么冷。
この本は三百ページだから、一日に二十ページ読めば、十五日で読み終わるわけだ。
这本书三百页，一天读二十页的话，也就是十五天读完。
易错点

窓が全部開いている。どうりで寒いわけだです。 → …寒いわけですね。（「わけだ」本身已是普通体断定，礼貌说法整体变成「わけです」，不能再叠「です」。）

韩语对应-는 것은 아니다
韩语「-는 것은 아니다」也表部分否定，但常缩成「-는 게 아니다」；日语「わけではない」更明确针对“由此推出的结论”。
〜わけではない
발음〜와케데와나이
并不是…；并非…
普通形 + わけではない；ナ形容词 + な + わけではない；名词 + という + わけではない
部分否定对方的整体判断，常与「別に」「必ずしも」呼应。
料理が嫌いなわけではないが、毎日作る時間がない。
我不是讨厌做饭，只是每天没时间做。
네단가타카케레바오이시이토이우와케데와나이.
値段が高ければおいしいというわけではない。
贵并不等于好吃。
全然分からないわけではありませんが、もう少しゆっくり話していただけますか。
也不是完全听不懂，能请您再说慢一点吗？
易错点

この店は便利わけではないが、駅から近い。 → 便利なわけではない（ナ形容词接「わけではない」必须加「な」，「便利わけではない」不合法。）
