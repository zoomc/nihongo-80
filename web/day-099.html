今日语法 3 条

〜切る / 〜切れない
발음〜키루 / 〜키레나이
…完；…不了
动词ます形词干 + 切る／切れない
表把动作彻底做完，或“多到做不完、做不到”。
산지칸카케테,나가이쇼우세쓰오사이고마데요미키따.
三時間かけて、長い小説を最後まで読み切った。
花了三个小时，把那本长篇小说读完了。
추우몬시스기테,료우리오타베키레나카따.
注文しすぎて、料理を食べ切れなかった。
点得太多，菜没能吃完。
야마노우에데와,카조에키레나이호도노호시가미에타.
山の上では、数え切れないほどの星が見えた。
山顶上看得见数不清的星星。
朝鲜语：-아/어 내다
韩语完成用「-아/어 내다」，日常更常说「다 -다」；日语「切る」强调“彻底做到最后”，还引申出“断然”的语感。
易错点

注文しすぎて、料理を食べ切りなかった。 → 食べ切れなかった（表“吃不完”要用可能形「切れない」；「切りない」不是合法形式，也不能表无法完成。）

〜かける
발음〜카케루
…了一半；刚要…
动词ます形词干 + かける；动词ます形词干 + かけの + 名词
表动作做到一半或刚开始就中断。
요미카케노혼가,쓰쿠에노우에니오이테아루.
読みかけの本が、机の上に置いてある。
桌上放着一本读到一半的书。
카노조와나니카이이카케타가,소노마마다마떼시마따.
彼女は何か言いかけたが、そのまま黙ってしまった。
她话说到一半，又沉默了。
この花は枯れかけていたが、水をやったら元気になった。
这花本来有点枯萎，浇了水就精神了。
朝鲜语：-다 말다
韩语「-다 말다」表“做到一半就停”，与「かける」对应；但日语还能表“刚开始、眼看要”，韩语要用「-려다」，含义更宽。
易错点

読みかけるの本が、机の上に置いてある。 → 読みかけの本（修饰名词要用「〜かけの」，「かけるの」不合法。）

〜に際して
발음〜니사이시테
值…之际；在…时
名词／动词辞书形 + に際して
用于值得注意的正式时点或事项。
申し込みに際して、注意事項をご確認ください。
申请时请确认注意事项。
新店舗を開くに際して、近隣の方々に挨拶した。
开新店时拜访了附近居民。
朝鲜语：에 즈음하여
常用于手续、公告等正式语境。
易错点

申し込みを際して → 申し込みに際して（这个句型固定写作「に際して」。）
