# Day 112 · 打工与职场｜〜ところに / 〜ところへ / 〜ところを、〜ば〜ほど

- 阶段：P3｜60 分钟｜常规日
- Can-do：在「打工与职场」场景里，用 〜ところに / 〜ところへ / 〜ところを 说清一件事

## 新词 20

- **最終**（さいしゅう）最终；最后｜朝鲜语：최종  
  例：最終電車はいつ出ますか。（末班电车几点开？）
- **最中**（さいちゅう）正在…之中  
  例：彼はスピーチの最中に気を失った。（他在演讲当中昏了过去。）
- **最低**（さいてい）最低；最差｜朝鲜语：최저  
  例：私は最低２マイルは歩ける。（我至少能走两英里。）
- **才能**（さいのう）才能｜朝鲜语：재능  
  例：君には音楽の才能がある。（你有音乐才能。）
- **裁判**（さいばん）审判；官司｜朝鲜语：재판  
  例：裁判は公明正大であることが要求される。（审判要求公正无私。）
- **材料**（ざいりょう）材料｜朝鲜语：재료  
  例：すぐれた材料で作られた家具は、売れ行きがよい。（用好材料做的家具很畅销。）
- **幸い**（さいわい）幸运；幸好  
  例：あなたがここに居たのは幸いでした。（幸好你当时在这儿。）
- **サイン**（サイン）签名  
- **境**（さかい）边界；交界  
  例：彼は生死の境をさ迷った。（他在生死之间徘徊。）
- **逆らう**（さからう）违抗；逆着  
  例：彼は世の風潮に逆らう。（他逆时代潮流而行。）
- **盛り**（さかり）鼎盛期；正当时  
  例：彼は今男盛りだ。（他正处在男人的壮年。）
- **作業**（さぎょう）作业；工作｜朝鲜语：작업  
  例：私がいない間も作業を続けなさい。（我不在的时候也继续干活。）
- **昨**（さく）昨｜朝鲜语：작  
  例：彼は昨シーズンで野球をやめました。（他上个赛季退出了棒球。）
- **作品**（さくひん）作品｜朝鲜语：작품  
  例：これは母の作品の一つです。（这是我妈妈的作品之一。）
- **作物**（さくもつ）农作物｜朝鲜语：작물  
  例：日本の主要作物は米である。（日本的主要作物是水稻。）
- **桜**（さくら）樱花  
  例：桜もそろそろじゃないでしょうか。（樱花是不是快开了？）
- **酒**（さけ）酒｜朝鲜语：주  
  例：僕は酒も煙草もやらないんだ。（我既不喝酒也不抽烟。）
- **叫ぶ**（さけぶ）喊叫  
  例：彼女は子供たちに静かにと叫んだ。（她冲孩子们喊「安静」。）
- **避ける**（さける）避开  
  例：あなたはいやな経験を避けるかもしれない。（你也许能避开不愉快的经历。）
- **支える**（ささえる）支撑；支持  
  例：なんとかそこで支えよ。入市を許すな。（想办法在那里顶住，别让他们进城。）

## 语法

- **〜ところに / 〜ところへ / 〜ところを**：正当…的时候
  接续：动词辞书形/ている/た形 + ところに／ところへ／ところを
  朝鲜语：-려는 참에（韩语常用「-려는 참에」表“正要做时”；日语按「に/へ/を」区分打断方式，韩语没有这种分工。）
- **〜ば〜ほど**：越…越…
  接续：动词ば形 + 同一动词辞书形 + ほど；い形容词ければ + い形容词 + ほど；ナ形容词なら + ナ形容词な + ほど
  朝鲜语：-면 -ㄹ수록（韩语「-ㄹ수록」一个形式即可；日语要把同一词重复两次（すればするほど），形式负担更重。）
