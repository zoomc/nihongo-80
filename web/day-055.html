今日语法 3 条

普通形 + わけが ない / V辞書形 + わけには いかない
不可能…／不能…（わけにはいかない）
普通形 + わけがない（强烈否定可能性）；辞書形 + わけにはいかない（因情理/规则不能做）
わけがない 是「绝无可能」；わけにはいかない 是「（道理上）不能这么做」，两形意义不同勿混
카레가손나코토오이우와케가아리마센.
彼がそんなことを言うわけがありません。
他不可能说那种话。
明日試験があるので、遊びに行くわけにはいきません。
明天有考试，不能去玩。
朝鲜语：-(으)ㄹ 리가 없다 / -(으)ㄹ 수는 없다
韩语ㄹ 리가 없다表绝无可能，ㄹ 수는 없다表情理上不能；两形区分与日语相近。
易错点

彼が来るわけがないでした。 → 彼が来るわけがありませんでした。（过去礼貌形可用「わけがありませんでした」，不能说「ないでした」。）

普通形 + と は 限らない
未必…；不一定…；不见得…
動詞・い形 普通形 / 名詞・な形（＋だ 常省）+ とは 限らない；常与 必ずしも／すべて／〜からといって 呼应
否定「一概如此」，修正以偏概全；礼貌体 とは 限りません
타카이모노가카나라즈시모요이토와카기리마센.
高いものが必ずしも良いとは限りません。
贵的东西未必就好。
센세이다카라토이떼,난데모시떼이루토와카기리마센.
先生だからといって、何でも知っているとは限りません。
虽说是老师，也未必什么都懂。
朝鲜语：-다고 해서 다 …는 것은 아니다
韩语用「다고 해서 다…는 아니다」表未必，比日语とは限らない冗长，口语常说꼭 그런 건 아니다。
易错点

高いとは限らないません。 → 高いとは限りません。（否定礼貌形可说限りません，不叠加ない和ません。）

Vて + いただけませんか / もらえませんか
발음V테 + 이타다케마센카 / 모라에마센카
能否请您…（很礼貌的请求）
動詞 て形 + いただく（谦让）可能形 いただけませんか；或 もらう 可能形 もらえませんか
对长辈/不熟的人请求，比 〜てください（G0026）礼貌；用否定疑问表委婉
스코시마떼이타다케마센카.
少し待っていただけませんか。
能请您稍等一下吗？
쓰카이카타오오시에테이타다케마센카.
使い方を教えていただけませんか。
能教我一下用法吗？
朝鲜语：-아/어 주시겠어요?
韩语敬语请求用주시겠어요，比주세요客气；日语いただけませんか用否定疑问，韩语用肯定疑问加시겠。
易错点

この漢字を教えるいただけませんか。 → この漢字を教えていただけませんか。（いただけませんか前接动词て形。）
