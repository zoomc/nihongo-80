# Day 121 · 问候与自我介绍｜〜たびに、〜ごとに

- 阶段：P3｜60 分钟｜常规日

- **商人**（しょうにん）商人｜朝鲜语：상인  
  例：商人は商品を売り買いする人だ。（商人是买卖商品的人。）
- **少年**（しょうねん）少年｜朝鲜语：소년

- **商売**（しょうばい）生意；买卖

- **消費**（しょうひ）消费｜朝鲜语：소비  
  例：その車は多量の燃料を消費する。（那辆车消耗大量燃料。）
- **商品**（しょうひん）商品｜朝鲜语：상품  
  例：商人は商品を売り買いする人だ。（商人是买卖商品的人。）

  例：彼女は食卓に料理を並べた。（她把菜摆上了餐桌。）
- **食品**（しょくひん）食品｜朝鲜语：식품  
  例：この食品は有毒である。（这种食品有毒。）

## 语法

- **〜たびに**：每当…就…
  接续：动词辞书形 + たびに；名词 + の + たびに
  朝鲜语：-ㄹ 때마다（韩语「-ㄹ 때마다」与「たびに」基本对应；但日语「たびに」偏书面，口语常说「〜ときはいつも」。）
- **〜ごとに**：每…；每隔…
  接续：名词 + ごとに；动词辞书形 + ごとに
  朝鲜语：-마다（韩语「-마다」兼表“每”和“每隔”；日语要区分「ごとに」（每）与「おきに」（每隔）。）
