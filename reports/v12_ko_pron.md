# v12 · 韩语读音标注 + 页面去重复（2026-11-12）

## 用户要求（原话）

1. 「我会韩语，所以你给单词和语法和句子学习的时候，在适当的地方加上韩语发音标注。然后再遮挡中文的时候隐藏。」
2. 「ありがとうございますありがとうございます / ありがとうございます / 谢谢（敬体）/ 韩语参考：감사합니다 /
   ありがとうございますありがとうございます。/ 读音提示：ありがとうございます（ありがとうございます）/ 谢谢。/
   朗读例句 —— 就比如这个，有非常多的重复。你把一个重复的地方替换成韩语发音，然后保留一个日语，然后剩余重复的去掉。」
3. 「平假 / 正常日语单词 / 韩语发音 / 例句读音标注 / 例句 / 朗读，新词部分大概这样就行。」
4. 「每个新词或者语法旁边加个显示按钮，就是当遮住一种语言的时候，按下这个按钮，当前项目临时三种语言都显示 10 秒。」

## 做了什么

### 1. 读音层 `scripts/ko_pron.py`

| 能力 | 说明 |
|---|---|
| `to_hangul(kana)` | 假名逐拍转写：清/浊/半浊/拗音/外来音；促音紧音（がっこう→가꼬우）；拨音同化（しんぶん→심분）；长音按拍不压缩（とう→토우、コーヒー→코오히이） |
| `counter_kana(num, unit)` | 時/分/月/日/年/人/歳/円/回/週間/か月/階/枚/本/冊/台/杯/匹/軒/個/番/つ；汉字数字、阿拉伯、全角、「何」都支持 |
| `ReadingIndex.reading/hangul` | 用词汇种子的 (surface, kana) 做最长匹配还原整句读音；词干只切「词干里还有汉字、词尾是假名」的词；不许停在汉字串中间；助词 は/へ/を 只在夹在两个已识别词之间时改读 わ/え/お |

**宁缺勿错**：整句只要有一个汉字解析不出来就返回 `None`，页面不显示韩语读音行，不猜。

补充词表：`knowledge/ko_reading_supplement.json`（160 条：东京/大阪/田中/値段/本当/週末/列車…），
`review_status=self_reviewed`，只收多字词；单字词一律不收（否则 火事 → ひこと 这种错误读音会被页面当真）。

### 2. 版式（新词 / 复习 / 语法）

```
わたし              ← 平假读音（只在词形≠假名时出现）
私                  ← 日语单词（不再 ruby 自注）
발음 와타시          ← 韩语发音
我                  ← 中文
韩语参考：나 / 저     ← 韩语释义
와타시와가쿠세이데스。 ← 例句韩语读音（能整句解析时）
私は学生です。        ← 例句
我是学生。            ← 例句中文
朗读                 ← 朗读按钮
忘了 / 不熟 / 记得    ← 自评
```

删掉的重复：假名词的 ruby 自注、单词下方那条重复的假名行、例句的「读音提示：词（词）」整行。
语法卡同构：`pattern → 발음 → 中文 → 接续 → 用法 → 例句 → 朝鲜语对照 → 易错点`。

### 3. 遮蔽与临时全显

- 所有韩语元素一律 `data-role="zh"`：**遮中文时韩语一起隐藏**（沿用 v8 约定，避免泄题）。
- 每项右上角一个「显示」按钮（`data-show-all`）：点击后该项三种语言一起显示 **10 秒**，
  按钮显示倒计时，结束自动回遮；同一时间只允许一项全显；该 section 处于「显示」模式时按钮隐藏。

## 已知限制（不藏）

1. 读音是**逐拍音译**，不是韩语借词写法：とう→토우（不是 도）、コーヒー→코오히이（不是 커피）、
   さん→산（韩语习惯写 상）。这是刻意的：压缩长音会让 思う→오모 这类词尾丢失。
2. 中文译文的「韩语字音」与日语读音是两层（人：字音 인 / 音读 진），页面分开列，不混为一谈。
3. N3 例句约三成没有韩语读音行——是因为解析不出来，不是渲染 bug；补词表可以继续抬，
   但**单字词不进表**，否则会出现听着像对的错读音。
4. 同形异读（着/出/何）的单字词干一律不收，代价是这类例句整句不标——这是刻意的取舍：
   猜错读音比不标更糟。词表外的活用形靠 `ko_reading_supplement.json` 逐条补。
5. 五日复习单元页（`unit-*.html`）与错题复习集沿用旧卡片，本轮没加韩语读音（改动集中在每日页）。
6. 读音层是机器推导（kana 部分 100% 确定，整句解析部分依赖词表覆盖），未做人工逐条审校，
   与内容一样按 `ai_draft` 口径对待。
