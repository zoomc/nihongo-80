# Day 053 · 〜たら、〜なら、〜と（conditional）

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜たら、〜なら、〜と（conditional）」各造一句自己的话，表达：如果…；…之后；如果是…的话；一…就…；如果…就…

## 新词 19

- **なるほど**（なるほど）原来如此｜韩语参考：그렇군요<br>
  例：ああ、なるほど！（啊，原来如此！）
- **におい**（におい）气味｜韩语参考：냄새<br>
  例：あの花はにおいが強いな。（那花的气味真冲。）
- **苦い**（にがい）苦｜韩语参考：쓰다（苦）<br>
  例：このコーヒーは苦い味がする。（这咖啡有苦味。）
- **二階建て**（にかいだて）二层楼｜韩语参考：이층집<br>
  例：私は２階建ての家に住んでいる。（我住在两层楼的房子里。）
- **逃げる**（にげる）逃跑；逃避｜韩语参考：뛰다（逃跑，逃窜，逃亡） / 빼다（逃避，避开） / 달아나다（逃跑，逃走，逃亡）<br>
  例：現実から逃げることはできない。（人无法逃避现实。）
- **日記**（にっき）日记｜韩语参考：일기（日记）<br>
  例：彼女はそのことを日記に書いた。（她把那件事写进了日记。）
- **入学**（にゅうがく）入学｜韩语参考：입학（入学）<br>
  例：私はこの学校に２年前に入学した。（我两年前进入这所学校。）
- **似る**（にる）像；相似｜韩语参考：닮다（像，随）<br>
  例：私も似た話を聞いたことがある。（我也听过类似的事。）
- **人形**（にんぎょう）人偶；娃娃｜韩语参考：인형（娃娃）<br>
  例：メアリーは私にアメリカの人形をくれた。（玛丽送给我一个美国人偶。）
- **盗む**（ぬすむ）偷；盗窃｜韩语参考：훔치다（偷，盗，盗取） / 도둑질하다（偷窃，盗窃）<br>
  例：盗まれたお金があきらめられない。（被偷的钱我放不下。）
- **塗る**（ぬる）涂；抹｜韩语参考：바르다（涂，抹）<br>
  例：ジョンがドアにペンキを塗っていた。（约翰在给门刷漆。）
- **ぬれる**（ぬれる）淋湿；湿｜韩语参考：젖다<br>
  例：木のおかげで雨にぬれずにすんだ。（多亏那些树，我才没被雨淋湿。）
- **ねだん**（ねだん）价格｜韩语参考：가격<br>
  例：このラジオの値段はいくらですか。（这台收音机多少钱？）
- **熱**（ねつ）发烧；热度｜韩语参考：신열（发烧，发热）<br>
  例：１０２゜Ｆの熱があります。（烧到华氏102度。）
- **ねっしん**（ねっしん）热心；勤奋｜韩语参考：열심이다<br>
  例：彼女は熱心に小鳥にえさをやった。（她热心地给小鸟喂食。）
- **寝坊**（ねぼう）睡懒觉；睡过头｜韩语参考：늦잠（懒觉）<br>
  例：彼はときどき寝坊する。（他有时会睡过头。）
- **眠い**（ねむい）困；发困｜韩语参考：졸리다（困）<br>
  例：テレビを見ているとすぐ眠くなる。（一看电视就容易犯困。）
- **眠る**（ねむる）睡；睡眠｜韩语参考：자다（睡，睡觉） / 잠자다（睡觉，睡眠）<br>
  例：もし眠るといけないので目覚し時計をセットしなさい。（免得睡着，把闹钟设好。）
- **残る**（のこる）剩下；留下｜韩语参考：남다（剩，剩下）<br>
  例：もう３ページ残っている。（还剩三页。）

## 语法

- **〜たら**：如果…；…之后
  接续：动词た形 + ら；い形容词去い+かったら；な形容词・名词+だったら
  朝鲜语：-(으)면 / -았/었더니（韩语 -(으)면 表条件，-았/었더니 表前项完成后的发现；日语 たら 一个形式兼表两者，使用范围更广。）
- **〜なら**：如果是…的话
  接续：动词普通形／い形容词／な形容词／名词 + なら
  朝鲜语：-(이)라면 / -다면（韩语 -(이)라면 与名词搭配，-다면 与动词、形容词搭配；日语 なら 前接形式不随词性变化，接续更简单。）
- **〜と（conditional）**：一…就…；如果…就…
  接续：动词辞书形／ない形／い形容词 + と；な形容词・名词 + だ + と
  朝鲜语：-(으)면（韩语 -(으)면 可表条件，也可接请求；日语 と 的后项必须是自然结果，不能是命令、请求，这一点需特别注意。）
