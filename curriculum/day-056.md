## 3. 新语法（含先修）
- `G0092` **普通形 + からこそ** — 正因为…才…｜接续：動詞・い形 普通形 + からこそ；な形・名詞 + だ + からこそ
- `G0082` **普通形 + わりに(は) / N + に しては** — （相较…）却…；按…来说倒是…｜接续：動詞・い形 普通形 / 名詞＋の + わりに；名詞 + にしては；后项是与前项预期不符的评价

## 4. 新汉字（中日差异）
- `K0120` **技** 音:ギ 训:わざ｜中文「技」jì；日语 技 音读 ギ（技術 ぎじゅつ）、训读 わざ（技）；「技術」是「技术」，与中文义近但读音完全不同，须按 ギ 验证，不能按中文 jì 推。
- `K0121` **術** 音:ジュツ 训:｜中文「术」shù；日语 術 音读 ジュツ（技術 ぎじゅつ、手術 しゅじゅつ，入声 -ツ）；简体「术」与「術」字形差异大，不可按中文形推，此字无常用训读。
