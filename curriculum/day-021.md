# Day 021 · 〜か（question）、〜ね、〜よ

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜か（question）**：…吗？（疑问）
  接续：句子（礼貌体／普通体）+ か
  朝鲜语：-까? / -니?（역이에요? 可用语调问问题。日语礼貌体教材句常用 駅ですか；普通体常问 駅？ 或 駅なの？，直接用 か 会因语气而显得较硬。）
- **〜ね**：…吧；…啊（寻求认同）
  接续：句子 + ね
  朝鲜语：-죠? / -네요（따뜻하죠? 对照 暖かいですね；따뜻하네요 对照发现后感叹的 暖かいですね。ね 也可只缓和语气，需听实际语调。）
- **〜よ**：…哦；…呀（告知、强调）
  接续：句子 + よ
  朝鲜语：-요 / -거든요（韩语 -요 是礼貌尾，不专门表告知；日语 よ 明确提示新信息，韩语需靠 -거든요 或语调表达。）
