③ 语法 7 分钟

（场所）に ～ がある / いる
場所 + に + 物/人 + が + ある／いる
（某地）有…

存在句：无生命用 ある，有生命用 いる；主体用 が

部屋に猫がいます。
房间里有猫。
駅の前に店があります。
车站前有店。
朝鲜语：에 ~ 이/가 있다 / 계시다
韩语存在动词不分有无生命，一律있다，敬语用계시다；日语必须分ある/いる。

易错：部屋に猫があります。 → 部屋に猫がいます。（猫是有生命，用 いる；中文「有」不分 animate，日语 ある/いる 必须分）

い形容词（～い です）
い形容詞 + です
…（い形容词谓语）

い形容词作谓语，礼貌体直接加 です，不再加 だ

この本は高いです。
这本书贵。
朝鲜语：형용사 어간 + 다 / -아·어요
韩语形容词作谓语要加终结词尾，敬语靠어요/습니다；日语い形直接加です。

易错：本は高いだ。 → 本は高いです。（い形容词后不能接 だ；「です」已是礼貌体，中文「是」诱发了 だ）
