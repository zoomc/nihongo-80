今日语法 2 条

Nの / Vている + 最中に（だ）
名詞 + の + 最中に；動詞ている + 最中に；句末可 最中だ
Nの / Vている + 最中に（だ）
正在…的时候（突然…）
强调某动作/状态正进行到一半时，发生了另一件事，后项常是打扰或意外。
会議の最中に、電話が鳴りました。
正在开会时电话响了。
ご飯の最中に、突然停電しました。
正吃饭时突然停电了。
朝鲜语：-는 중에 / -는 도중에
韩语는 중表正在，도중에表途中；日语最中に强调正到一半被打断，语感更强。
易错点

会議の最中を、電話が鳴りました。 → 会議の最中に、電話が鳴りました。（最中 后接时间点用 に，不用 を；中文“在会议中”直译成 を。）

Vた形 + ところで
動詞た形 + ところで；后项多为否定或无意义的结果
Vた形 + ところで
即使…也（不会有预期结果）
表示即使前项成立，后项也不会改变；常与「無駄だ／変わらない／〜ない」呼应。
今更謝ったところで、間に合いません。
事到如今再道歉也来不及了。
何度説明したところで、彼は分からないでしょう。
即使说明多少次，他也不会明白吧。
朝鲜语：-아/어도 / -더라도
韩语让步用아/어도，强调用더라도；日语ところで后项必为否定性结果，韩语无此限制。
易错点

何度説明するところで、彼は理解しないでしょう。 → 何度説明したところで、彼は理解しないでしょう。（ところで（即使）接た形，不接辞书形；中文“即使说明”直译用原形。）
