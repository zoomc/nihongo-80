今日语法 3 条

〜や
발음〜야
…和…等（部分列举）
名词 + や + 名词（部分列举）
列举若干代表性事物，暗示还有其他，常与「など」呼应。
韩语对应나/이나
韩语 나/이나 表选择或部分列举，与 や 接近；但韩语还可表示「或者」，日语 や 只表列举，不表选择。
쓰쿠에노우에니혼야자씨가아리마스.
机の上に本や雑誌があります。
桌子上有书、杂志等。
스파아데니쿠야야사이오카이마시타.
スーパーで肉や野菜を買いました。
我在超市买了肉、蔬菜等。

易错点 机の上に本や雑誌とがあります。 → 机の上に本や雑誌などがあります。（部分列举不用 と 收尾，可用「など」）

〜も
발음〜모
也…；（否定）也不…
名词 + も
表示同类追加，否定句中与前后 も 呼应表示「既不…也不…」。
韩语对应도
韩语 도 与 も 对应，且同样可叠用于否定并列（고기도 생선도）；日语 も 可顶替 は／が／を，韩语 도 也顶替主宾格助词。
와타시모가쿠세이데스.
私も学生です。
我也是学生。
아니와사까아모스키데스.
兄はサッカーも好きです。
哥哥也喜欢足球。
니쿠모사카나모타베마센.
肉も魚も食べません。
我既不吃肉也不吃鱼。

易错点 私もは学生です。 → 私も学生です。（も 已含提示作用，不能与 は 叠用）

〜の（possessive）
발음〜노
…的…
名词 + の + 名词
表示所属、属性、材料或同位关系，修饰名词时用 の。
韩语对应의
韩语 의 与 の 对应，但口语中 의 常省略；日语 の 不能省略，且还可代替名词（私の）。
코레와와타시노카사데스.
これは私のかさです。
这是我的伞。
니혼고노센세이와토테모야사시이데스.
日本語の先生はとてもやさしいです。
日语老师非常温柔。
에키노치카쿠니아타라시이미세가아리마스.
駅の近くに新しい店があります。
车站附近有一家新店。

易错点 これは私がかさです。 → これは私のかさです。（所属关系用 の，が 会变成主语标记）
