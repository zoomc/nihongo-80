# Day 087 · 新闻与天气｜普通形 + わりに(は) / N + に しては、V ます形(去ます) + かねない / かねる

- 阶段：P2｜60 分钟｜听力日
- Can-do：在「新闻与天气」场景里，用 普通形 + わりに(は) / N + に しては 说清一件事

## 新词 14

- **うなる**（うなる）低吼；呻吟  
  例：その犬は小さな男の子に向かって唸った。（那条狗冲着小男孩低吼。）
- **奪う**（うばう）夺取；抢走  
  例：彼女は若い男にバッグを奪われた。（她的包被一个年轻男子抢走了。）
- **馬**（うま）马  
  例：馬に乗ることができますか？（你会骑马吗？）
- **生まれ**（うまれ）出生；出身  
  例：私は生まれも育ちも東京だ。（我出生和成长都在东京。）
- **梅**（うめ）梅；梅子  
  例：梅の花は今週が見頃です。（梅花这周开得最好。）
- **裏切る**（うらぎる）背叛  
  例：私が信じていた人が私を裏切った。（我信任的人背叛了我。）
- **売れる**（うれる）畅销；卖出  
  例：この本は最近よく売れている。（这本书最近卖得很好。）
- **上**（うわ）上面；表面  
- **噂**（うわさ）传闻；谣言  
  例：うわさは四方八方に広がった。（传闻传到了四面八方。）
- **運**（うん）运气｜朝鲜语：운  
  例：そうすればやがて運が開けるでしょう。（那样的话，运气迟早会好起来。）
- **柄**（え）柄；把手  
- **永遠**（えいえん）永远｜朝鲜语：영원  
  例：その画家は、いわば永遠の少年だ。（那位画家可以说是永远的少年。）
- **永久**（えいきゅう）永久｜朝鲜语：영구  
  例：彼は永久に日本を離れた。（他永远离开了日本。）
- **営業**（えいぎょう）营业；销售｜朝鲜语：영업  
  例：営業の者と話をしてみました。（我和营业部门的人谈过了。）

## 语法

- **普通形 + わりに(は) / N + に しては**：（相较…）却…；按…来说倒是…
  接续：動詞・い形 普通形 / 名詞＋の + わりに；名詞 + にしては；后项是与前项预期不符的评价
  朝鲜语：-에 비해 / -치고는（韩语에 비해表相较，치고는表按…来说；日语わりに偏不匹配，にしては偏身份标准。）
- **V ます形(去ます) + かねない / かねる**：难保不会…、恐怕会…／难以…、不便…
  接续：動詞 ます形 去 ます + かねない／かねる；かねる 按一段动词变形（かねます／かねた）
  朝鲜语：-(으)ㄹ 수도 있다 / -기 어렵다（韩语ㄹ 수도 있다表恐怕会(坏结果)，委婉拒绝用하기 어렵습니다；かねる的立场限制韩语须另加说明。）

## 汉字 4

- **勝** 胜；赢｜音：ショウ｜训：か.つ、-が.ち、まさ.る、すぐ.れる、かつ
- **面** 脸；表面；方面｜音：メン、ベン｜训：おも、おもて、つら
- **反** 反；相反；反叛｜音：ハン、ホン、タン、ホ｜训：そ.る、そ.らす、かえ.す、かえ.る、-かえ.る
