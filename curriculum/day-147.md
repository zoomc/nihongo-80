# Day 147 · 〜かける

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜かける」造两句自己的话，表达：…了一半；刚要…

## 新词 21

- **熱中**（ねっちゅう）热衷；着迷｜韩语参考：열중（热衷）<br>
  例：この頃は彼女はテニスに熱中している。（最近她迷上了网球。）
- **年間**（ねんかん）一年间；年度｜韩语参考：연간（年，年间）<br>
  例：私はここで１０年間働いている。（我在这里工作了十年。）
- **年中**（ねんじゅう）全年；一年到头｜韩语参考：일 년 내내<br>
  例：私は１年中テニスをします。（我一年到头都打网球。）
- **年代**（ねんだい）年代｜韩语参考：연대（年代） / 년대（年代）<br>
  例：１９９０年代は湾岸戦争で始まった。（20世纪90年代以海湾战争开始。）
- **年齢**（ねんれい）年龄｜韩语参考：연령（年龄） / 나이（年龄，年纪，岁数）<br>
  例：彼女は私と同じくらいの年齢です。（她和我年纪差不多。）
- **野**（の）野地；田野｜韩语参考：들판<br>
  例：この野バラは甘い香りを放つ。（这株野玫瑰散发着甜香。）
- **能**（のう）能乐｜韩语参考：노가쿠（일본 전통극）<br>
  例：私は能に興味を持つアメリカ人に会いました。（我遇到了一位对能乐感兴趣的美国人。）
- **農家**（のうか）农户；农家｜韩语参考：농가（农家） / 농삿집（农家）<br>
  例：農家の子になりたいかね。（你想当农家子弟吗？）
- **農業**（のうぎょう）农业｜韩语参考：농업（农业）<br>
  例：農業はその国の経済のもとである。（农业是那个国家经济的基础。）
- **農民**（のうみん）农民｜韩语参考：농민（农民）<br>
  例：私は貧しい農民に過ぎない。（我不过是个贫穷的农民。）
- **能力**（のうりょく）能力｜韩语参考：능력（能力，才能） / 실력（实力，能力）<br>
  例：彼はすぐれた能力をもっていた。（他有出众的能力。）
- **ノー**（ノー）不；不行｜韩语参考：아니요 / 안 됨<br>
  例：うちの母はノーと言うに決まっている。（我妈肯定会说不。）
- **軒**（のき）屋檐｜韩语参考：처마（屋檐，房檐）<br>
  例：彼女は鳥かごを軒からつるした。（她把鸟笼挂在屋檐下。）
- **残す**（のこす）留下；剩下｜韩语参考：끼치다（留下，引起） / 남기다（剩，剩下） / 뒤로하다（留下）<br>
  例：これは父が私に残してくれたものが一つある。（这是父亲留给我的一件东西。）
- **残り**（のこり）剩余；剩下的｜韩语参考：나머지（剩下的，其余的）<br>
  例：私たちの内残りの者はあとに残ることになっている。（我们其余的人要留下来。）
- **乗せる**（のせる）让…乘坐；放上｜韩语参考：태우다 / 올려놓다<br>
  例：車に乗せてください。（请让我搭一下车。）
- **除く**（のぞく）除去；除外｜韩语参考：제외하다（除外，排除）<br>
  例：医者は彼の苦痛を除いてやった。（医生解除了他的痛苦。）
- **望み**（のぞみ）希望；愿望｜韩语参考：가망（指望，希望） / 바람（希望，期望，期待） / 소망（心愿，愿望）<br>
  例：あなたの望みが実現するといいですね。（希望你的愿望能实现。）
- **望む**（のぞむ）希望；期望｜韩语参考：원하다（希望，想要） / 기대하다（期待，期望）<br>
  例：全国民が平和を望んでいる。（全国人民都希望和平。）
- **後**（のち）之后；以后｜韩语参考：나중 / 이후<br>
  例：晴れ後曇りでした。（晴转多云。）
- **ノック**（ノック）敲门｜韩语参考：노크（敲门，叩门）<br>
  例：入る前にドアをノックして下さい。（进去前请先敲门。）

## 语法

- **〜かける**：…了一半；刚要…
  接续：动词ます形词干 + かける；动词ます形词干 + かけの + 名词
  朝鲜语：-다 말다（韩语「-다 말다」表“做到一半就停”，与「かける」对应；但日语还能表“刚开始、眼看要”，韩语要用「-려다」，含义更宽。）
