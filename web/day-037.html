③ 语法 6 分钟

～そうです（样态／传闻）
样态：ます形词干/い形去い/な形词干 + そう；传闻：普通形 + そうです
看起来…／听说…

样态表肉眼推断，传闻表转述；两者接续不同，意义完全不同

雨が降りそうです。
看起来要下雨。
明日は雨だそうです。
听说明天有雨。
朝鲜语：-아/어 보이다 / -다고 하다
韩语样态用아/어 보이다，传闻用다고 하다，形态完全不同；日语そうだ须按接续分辨。

易错：おいしいそうです（想表样态） → おいしそうです。（い形容词样态是 おいしそう（去 い）；おいしいそう 是传闻「听说好吃」）

～ようだ / ～らしい
普通形 + ようだ／らしい（名 + の + ようだ）
好像…／似乎…（推测）

ようだ 偏主观直感，らしい 偏传闻/典型特征；名词接 ようだ 要加 の

彼は忙しいようです。
他好像很忙。
明日は雨らしいです。
明天好像有雨。
朝鲜语：-(으)ㄴ 것 같다 / -(으)ㄴ 모양이다
韩语推测最常用것 같다，传闻典型用다고 하다；日语ようだ主观、らしい客观传闻。

易错：雨ようです。 → 雨のようです。（名词接 ようだ 要加 の：雨のようです）
