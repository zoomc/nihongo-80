③ 语法 6 分钟

加粗的是今日重点。先看句型与接续，再读例句。

～てみる / ～てしまう / ～ておく
動詞て形 + みる／しまう／おく
试着…／…完了／事先…

补助动词：てみる 尝试、てしまう 完了/遗憾、ておく 事先准备

この料理を食べてみます。
尝尝这道菜。
本を読んでしまいました。
把书看完了。
朝鲜语：-아/어 보다 / -아·어 버리다 / -아·어 두다
韩语分别用보다(尝试)、버리다(完了/遗憾)、두다(预先)，与日语三形基本对应。
用法提醒

食べてみる（写成 食べみる） → 食べてみます。（补助动词前必须 て形，漏 て 错）

あげる / くれる / もらう
给予者 は/が 接受者 に 物 を あげる；给予者 が 我方 に 物 を くれる；接受者 は 给予者 に/から 物 を もらう
给…；别人给我…；从…得到

按给与方向和视角选择：我给别人用あげる，别人给我用くれる，我收到用もらう。

私は弟に古いゲームをあげた。
我把旧的游戏机给了弟弟。
姉が誕生日にかわいいかばんをくれました。
姐姐在我生日时送了我一个可爱的包。
友達から旅行のおみやげをもらった。
我收到了朋友旅行带回来的特产。
朝鲜语：주다 / 받다
韩语 주다 不分方向，日语必须按「谁给谁」区分 あげる／くれる；韩语 받다 对应 もらう，但日语 もらう 的来源可用 に 或 から。
用法提醒

私は弟に古いゲームをくれた。 → 私は弟に古いゲームをあげた。（くれる 的给予者必须是他人，不能是「私」；我给别人要用 あげる）
