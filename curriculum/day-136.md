## 语法

- **〜に越したことはない**：最好还是…
  接续：动词辞书形 / Verb-nai / i-Adj / na-Adj / 名词 + に越したことはない
  朝鲜语：하는 것이 가장 좋다（韩语提示按整块理解。换成日语时先套接续「动词辞书形 / Verb-nai / i-Adj / na-Adj / 名词 + に越したことはない」，再看下面的例句。）
- **〜にもかかわらず**：尽管…仍然…
  接续：动词普通形 / i-Adj / na-Adj + である / 名词 + にもかかわらず
  朝鲜语：에도 불구하고（韩语 에도 불구하고 和日语都可表逆接。日语可接名词或普通形，常见于说明和书面语。）
