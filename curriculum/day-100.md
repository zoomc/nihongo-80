# Day 100 · 〜そうにない / 〜そうもない、〜一方だ

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜そうにない / 〜そうもない、〜一方だ」造两句自己的话，表达：看样子不会…；不像会…；一直…；越来越…

## 新词 19

- **議員**（ぎいん）议员｜韩语参考：의원（议员）<br>
  例：私もまた、議員の一人です。（我也是议员之一。）
- **記憶**（きおく）记忆｜韩语参考：생각（回想，记忆）<br>
  例：私はその日の記憶を呼び覚まそうとした。（我试图唤起那天的记忆。）
- **気温**（きおん）气温｜韩语参考：기온（气温）<br>
  例：気温が下がると関節が痛むんだ。（气温一降，关节就疼。）
- **機械**（きかい）机器｜韩语参考：기계（机械，机器） / 기기（机器）<br>
  例：彼はその新しい機械を試してみた。（他试了试那台新机器。）
- **議会**（ぎかい）议会｜韩语参考：의회（议会）<br>
  例：議会はさいごにけんかになった。（议会最后吵了起来。）
- **期間**（きかん）期间｜韩语参考：기간（期间，时期）<br>
  例：治るのにどのくらいの期間がかかりますか。（治好需要多长时间？）
- **機関**（きかん）机构；机关｜韩语参考：기관（机关）<br>
  例：その機関は１９６０年代後半に設立された。（那个机构成立于六十年代后期。）
- **効く**（きく）有效；见效｜韩语参考：듣다（见效，有效） / 먹혀들다（见效，起效，听进去）<br>
  例：よくもまあ私にそんな口がきけるね。（你居然敢这么跟我说话。）
- **機嫌**（きげん）心情；情绪｜韩语参考：비위（想法，心情，情绪）<br>
  例：彼は他人の機嫌を損ねないように気をつけている。（他注意不去惹别人不高兴。）
- **気候**（きこう）气候｜韩语参考：기후（气候）<br>
  例：その国は気候が温和だ。（那个国家气候温和。）
- **岸**（きし）岸｜韩语参考：기슭 / 물가<br>
  例：彼らはその船を岸にあげた。（他们把船拖上了岸。）
- **生地**（きじ）布料；面料｜韩语参考：감（布料，料子） / 옷감（衣料，布料）<br>
  例：生地を預ければドレスを仕立ててくれますか。（把布料交给你们，能给我做条连衣裙吗？）
- **技師**（ぎし）工程师｜韩语参考：엔지니어（工程师）<br>
  例：トムは電気技師です。（汤姆是电气工程师。）
- **記者**（きしゃ）记者｜韩语参考：기자（记者）<br>
  例：記者は話されたことはすべて書き留めた。（记者把说过的话全都记了下来。）
- **傷**（きず）伤；瑕疵｜韩语参考：티（瑕疵，疵点 ，疵瑕） / 흠（瑕疵，缺损） / 상처（伤口，伤）<br>
  例：ここに傷があるので安くしてください。（这里有瑕疵，请便宜一点。）
- **期待**（きたい）期待｜韩语参考：기대（期待，期望） / 기대치（期望值，期待值）<br>
  例：とにかく万事うまくいくように期待しよう。（总之就指望一切顺利吧。）
- **帰宅**（きたく）回家｜韩语参考：귀가（回家）<br>
  例：何が彼を帰宅する気にさせたのか。（是什么让他想回家的呢？）
- **貴重**（きちょう）宝贵｜韩语参考：귀중하다<br>
  例：あれは貴重な経験だった。（那是一次宝贵的经历。）
- **議長**（ぎちょう）议长｜韩语参考：의장（议长）<br>
  例：彼らはスミスさんを議長に任命した。（他们任命史密斯先生为议长。）

## 语法

- **〜そうにない / 〜そうもない**：看样子不会…；不像会…
  接续：动词ます形词干 + そうにない／そうもない
  朝鲜语：-ㄹ 것 같지 않다（韩语没有专门对应，常说「-ㄹ 것 같지 않다」；日语「そうにない」依据眼前迹象，主观判断色彩更强。）
- **〜一方だ**：一直…；越来越…
  接续：动词辞书形 + 一方だ
  朝鲜语：-기만 한다（韩语「-기만 한다」偏“只做某事”；日语「一方だ」专指程度单向加剧，常带忧虑，韩语更常说「계속 -고 있다」。）
