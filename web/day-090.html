今日语法 2 条

〜的
발음〜테키
…上的；…式的
名词 + 的（てき）；修饰名词可用 的な，也有直接连接的词组，如経済的理由
把名词转成形容词性，表性质、领域或立场。
日本の伝統的な料理を食べてみたい。
我想尝尝日本传统式的料理。
この問題は、経済的な理由で解決が難しい。
这个问题因经济上的原因难以解决。
個人的には、この案に賛成です。
个人而言，我赞成这个方案。
朝鲜语：-적
韩语「-적」来自同一汉字词，用法高度相似；但韩语接「으로/인」，日语换成「に/な」，词形对应不齐。
易错点

具体的にの説明をお願いします。 → 具体的な説明をお願いします。（修饰名词可说「具体的な説明」，不能叠加「にの」。）

〜ような / 〜ように（like）
발음〜요우나 / 〜요우니
像…一样；如同…
名词 + の + ような/ように；普通形 + ような/ように
举出相似例子、比喻，或表示“按照…的方式”。
私も、あなたのような優しい看護師になりたいです。
我也想成为像你这样温柔的护士。
센세이가이따요우니,코노붐포우와테스토니요쿠데루.
先生が言ったように、この文法はテストによく出る。
正如老师所说，这个语法考试常考。
토우쿄우노요우나오오키나토시데와,야친가토테모타카이.
東京のような大きな都市では、家賃がとても高い。
在东京这样的大城市，房租很贵。
朝鲜语：-같은
韩语「-같은」修饰名词、「-같이」修饰动词，分工与日语相似；但日语名词前必须加「の」，韩语不加。
易错点

東京のよう大きな都市では、家賃がとても高い。 → 東京のような大きな都市（名词后接「ような」须保留「な」，「よう大きな」不合法。）
