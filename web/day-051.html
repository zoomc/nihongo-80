Day 051 · Vて + いただけませんか / もらえませんか、V辞書形 + ため(に) / 普通形・N の + ため(に)、普通形 + のに（な形・名詞 は 〜な のに）

语法 3 条

Vて + いただけませんか / もらえませんか
발음V테 + 이타다케마센카 / 모라에마센카
能否请您…（很礼貌的请求）
動詞 て形 + いただく（谦让）可能形 いただけませんか；或 もらう 可能形 もらえませんか
对长辈/不熟的人请求，比 〜てください（G0026）礼貌；用否定疑问表委婉
韩语对应-아/어 주시겠어요?
韩语敬语请求用주시겠어요，比주세요客气；日语いただけませんか用否定疑问，韩语用肯定疑问加시겠。
스코시마떼이타 다케 마센 카.
少し待っていただけませんか。
能请您稍等一下吗？
쓰카이카타 오 오시에테이타 다케 마센 카.
使い方を教えていただけませんか。
能教我一下用法吗？
易错易混点
  • ✗ この漢字を教えるいただけませんか。✓ この漢字を教えていただけませんか。いただけませんか 前接て形：教えていただけませんか。
V辞書形 + ため(に) / 普通形・N の + ため(に)
为了…（目的）／因为…、由于…（原因）
目的：动词辞书形／名词 + の + ために。原因：动词、い形容词普通形／な形 + な／名词 + の + ために。
目的句后项须是意志动作；原因句多接客观、非意志结果（事故・遅刻等），偏书面/正式，に 可省
韩语对应-기 위해(서) / -때문에
韩语目的用기 위해(서)，原因用때문에；日语ために两义同形，须靠后项判断。
니혼고 오 벤쿄우스루타메 니, 니뽄 니 키마시타.
日本語を勉強するために、日本に来ました。
为了学日语来了日本。
주우타이 노 타메 니, 카이기 니 오쿠레마시타.
渋滞のために、会議に遅れました。
因为堵车，开会迟到了。
易错易混点
  • ✗ 日本語を勉強したために、来ました。✓ 日本語を勉強するために来ました。目的用辞书形（勉強するために）；た形 变成“因为学了”。
  • ✗ 事故ため、電車が止まりました。✓ 事故のため、電車が止まりました。名词接 ため 要加 の：事故のため。
普通形 + のに（な形・名詞 は 〜な のに）
明明…却…；…却（意外、不满、遗憾）
動詞・い形 普通形 + のに；な形・名詞 + な + のに；后项是与预期相反的结果
逆接，带说话人意外/责备/遗憾情绪；比 が/けど 情绪强
韩语对应-는데도 / -(으)ㄴ데도
韩语逆接用는데도，带不满或意外；日语のに情绪更强，还能置于句末表遗憾。
타쿠삼벤쿄우시타노니, 고우카쿠데키마센데시타.
たくさん勉強したのに、合格できませんでした。
明明学了很多却没考上。
쿄우 와 니치요우비나노니, 시고토 니 이키마스.
今日は日曜日なのに、仕事に行きます。
明明是周日却要去上班。
易错易混点
  • ✗ 高いのにを買いました。✓ 高いのに買いました。のに 后面直接接主句，不再加 を。
  • ✗ 日曜日だのに、働きます。✓ 日曜日なのに、働きます。名词、な形容词接 のに 用 な：日曜日なのに。
