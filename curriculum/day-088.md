## 新词 25

- **日曜**（にちよう）星期日｜韩语参考：일요일<br>
  例：銀行は日曜にはやってません。（银行星期天不营业。）
- **日光**（にっこう）日光；阳光｜韩语参考：일광（日光） / 햇발（阳光，日光） / 햇볕（阳光，日光）<br>
  例：この部屋はあまり日光が当たらない。（这个房间晒不到多少太阳。）
- **にっこり**（にっこり）笑眯眯｜韩语参考：빙글（笑眯眯地，微微地） / 빙그레（笑眯眯地，微微地） / 해죽해죽（笑眯眯地）<br>
  例：彼女はにっこり笑ってそういった。（她笑眯眯地这样说了。）
- **人間**（にんげん）人；人类｜韩语参考：인간（人，人类） / 사람（人）<br>
  例：彼は人間としてよくできた人です。（他为人很有修养。）
- **抜く**（ぬく）拔出；胜过｜韩语参考：빼내다（抽出，拔出）<br>
  例：最後まで戦い抜こう。（战斗到最后吧。）
- **抜ける**（ぬける）脱落；漏掉｜韩语参考：빠지다（脱落，掉）<br>
  例：歯が１本抜けた。（我掉了一颗牙。）
- **布**（ぬの）布｜韩语参考：천（布）<br>
  例：この布は値段の割に品質が良い。（这块布价格虽低，质量却好。）
- **ね**（ね）价值；价钱｜韩语参考：값 / 가격<br>
  例：彼はその絵にたいへん高い値をつけた。（他给那幅画定了很高的价。）
- **根**（ね）根；根性｜韩语参考：뿌리（根）<br>
  例：彼は根はやさしい男だった。（他骨子里是个善良的人。）
- **願い**（ねがい）愿望；请求｜韩语参考：원（愿，愿望，心愿） / 청（请求，委托，嘱托） / 소원（心愿，愿望）<br>
  例：市長は私達の願いを聞き入れてくれた。（市长接受了我们的请求。）
- **願う**（ねがう）希望；请求｜韩语参考：원하다（希望，想要）<br>
  例：足元に御用心願います。（请注意脚下。）
- **鼠**（ねずみ）老鼠｜韩语参考：쥐（老鼠，耗子）<br>
  例：猫がいなくなるとネズミたちが遊びだす。（猫一走，老鼠就闹起来了。）
- **熱帯**（ねったい）热带｜韩语参考：열대（热带）<br>
  例：あの島は熱帯性気候です。（那座岛是热带气候。）
- **熱中**（ねっちゅう）热衷；着迷｜韩语参考：열중（热衷）<br>
  例：この頃は彼女はテニスに熱中している。（最近她迷上了网球。）
- **年間**（ねんかん）一年间；年度｜韩语参考：연간（年，年间）<br>
  例：私はここで１０年間働いている。（我在这里工作了十年。）
- **年中**（ねんじゅう）全年；一年到头｜韩语参考：일 년 내내<br>
  例：私は１年中テニスをします。（我一年到头都打网球。）
- **年代**（ねんだい）年代｜韩语参考：연대（年代） / 년대（年代）<br>
  例：１９９０年代は湾岸戦争で始まった。（20世纪90年代以海湾战争开始。）
- **年齢**（ねんれい）年龄｜韩语参考：연령（年龄） / 나이（年龄，年纪，岁数）<br>
  例：彼女は私と同じくらいの年齢です。（她和我年纪差不多。）
- **野**（の）野地；田野｜韩语参考：들판<br>
  例：この野バラは甘い香りを放つ。（这株野玫瑰散发着甜香。）
- **軒**（のき）屋檐｜韩语参考：처마（屋檐，房檐）<br>
  例：彼女は鳥かごを軒からつるした。（她把鸟笼挂在屋檐下。）
- **残す**（のこす）留下；剩下｜韩语参考：끼치다（留下，引起） / 남기다（剩，剩下） / 뒤로하다（留下）<br>
  例：これは父が私に残してくれたものが一つある。（这是父亲留给我的一件东西。）
- **残り**（のこり）剩余；剩下的｜韩语参考：나머지（剩下的，其余的）<br>
  例：私たちの内残りの者はあとに残ることになっている。（我们其余的人要留下来。）
- **乗せる**（のせる）让…乘坐；放上｜韩语参考：태우다 / 올려놓다<br>
  例：車に乗せてください。（请让我搭一下车。）
- **除く**（のぞく）除去；除外｜韩语参考：제외하다（除外，排除）<br>
  例：医者は彼の苦痛を除いてやった。（医生解除了他的痛苦。）
- **望み**（のぞみ）希望；愿望｜韩语参考：가망（指望，希望） / 바람（希望，期望，期待） / 소망（心愿，愿望）<br>
  例：あなたの望みが実現するといいですね。（希望你的愿望能实现。）

## 语法

- **〜向き / 〜向け**：适合…；面向…
  接续：名词 + 向き（だ／の／な）；名词 + 向け（だ／の／に）
  朝鲜语：-용（韩语「-용」只对应「向け」（面向）；「向き」（适合）要用「-에 맞는」，日语两个词形近义远，最易混。）
- **〜がち**：容易…；动不动就…
  接续：动词ます形词干/名词 + がち
  朝鲜语：-기 쉽다（韩语「-기 쉽다」中性，好坏都可用；日语「がち」几乎只用于消极倾向，且偏书面。）
- **〜気味**：有点…；稍有…迹象
  接续：名词/动词ます形词干 + 気味
  朝鲜语：-기가 있다（韩语没有简洁对应，常说「좀 -은 편이다」；日语「気味」专指轻微不良迹象，程度更轻、更具体。）
