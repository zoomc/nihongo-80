# Day 123 · 〜おかげで、〜せいで

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜おかげで、〜せいで」造两句自己的话，表达：多亏…；托…的福；都怪…；因为…

## 新词 20

- **印**（しるし）记号；标志｜韩语参考：표（标记，记号，符号，标志） / 마크（商标，标志，徽章）<br>
  例：発音できない語に印をつけなさい。（在不会发音的词上做个记号。）
- **城**（しろ）城堡｜韩语参考：성 / 성곽<br>
  例：その城は１６１０年に建てられた。（那座城堡建于1610年。）
- **進学**（しんがく）升学｜韩语参考：진학（升学）<br>
  例：彼は大学院に進学しないだろう。（他大概不会读研究生吧。）
- **神経**（しんけい）神经｜韩语参考：신경（神经）<br>
  例：彼はそのことで神経をとがらせている。（他因为那件事神经紧绷。）
- **真剣**（しんけん）认真；严肃｜韩语参考：진지하다<br>
  例：ジョージは勉強に真剣でない。（乔治对学习不认真。）
- **信仰**（しんこう）信仰｜韩语参考：신앙（信仰，崇拜） / 믿음（信仰）<br>
  例：キリスト教を信仰していますか。（你信仰基督教吗？）
- **信号**（しんごう）信号；红绿灯｜韩语参考：신호（信号） / 시그널（信号）<br>
  例：信号が青に変わったわよ。（信号灯变绿了哦。）
- **人工**（じんこう）人工｜韩语参考：인공（人工）<br>
  例：この庭の美しさは自然より人工のおかげだ。（这庭院的美更多归功于人工而非自然。）
- **深刻**（しんこく）严重；深刻｜韩语参考：심각하다<br>
  例：事態は非常に深刻である。（事态非常严重。）
- **人種**（じんしゅ）人种；种族｜韩语参考：인종（人种）<br>
  例：世界にはいろいろな人種がいる。（世界上有各种各样的人种。）
- **信じる**（しんじる）相信｜韩语参考：믿다（信，相信）<br>
  例：きっと彼はあなたを信じると思いますよ。（我想他一定会相信你的。）
- **人生**（じんせい）人生｜韩语参考：인생（人生）<br>
  例：できるあいだに人生を楽しみなさい。（趁着还能享受，好好享受人生吧。）
- **親戚**（しんせき）亲戚｜韩语参考：친척（亲戚）<br>
  例：フィリップとトムは親戚である。（菲利普和汤姆是亲戚。）
- **新鮮**（しんせん）新鲜｜韩语参考：신선하다<br>
  例：どうやって新鮮な魚をえらぶのですか。（怎样才能挑到新鲜的鱼呢？）
- **心臓**（しんぞう）心脏｜韩语参考：심장（心脏） / 염통（心脏）<br>
  例：煙は彼の心臓によくないかもしれない。（烟可能对他的心脏不好。）
- **身体**（しんたい）身体｜韩语参考：신체（身体） / 몸（身体，身子）<br>
  例：身体を大事にしなければならない。（必须爱惜身体。）
- **慎重**（しんちょう）慎重；谨慎｜韩语参考：신중（慎重）<br>
  例：彼女は何をするにも慎重であった。（她做什么都很谨慎。）
- **身長**（しんちょう）身高｜韩语参考：신장（身高，身长） / 키（身高，身长，个子，个儿，个头儿）<br>
  例：息子はもう私と同じ身長だ。（儿子已经和我一样高了。）
- **審判**（しんぱん）裁判；审判｜韩语参考：심판（审判）<br>
  例：彼一人だけ余る、だから審判させよう。（只剩他一个人了，就让他当裁判吧。）
- **人物**（じんぶつ）人物｜韩语参考：인물（人物）<br>
  例：あの人はどんな人物か教えて下さい？（请告诉我他是个什么样的人？）

## 语法

- **〜おかげで**：多亏…；托…的福
  接续：动词普通形/い形容词/ナ形容词な/名词の + おかげで
  朝鲜语：-덕분에（韩语「-덕분에」与「おかげで」对应；但日语还能用于讽刺（「おかげで遅れた」），韩语同样可以，需靠上下文判断。）
- **〜せいで**：都怪…；因为…
  接续：动词普通形/い形容词/ナ形容词な/名词の + せいで
  朝鲜语：-때문에（韩语「-때문에」中性，好坏结果都可用；日语「せいで」专用于坏结果并带责难，不能随便替换「おかげで」。）
