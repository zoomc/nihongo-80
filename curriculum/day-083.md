## 新词 25

- **直接**（ちょくせつ）直接｜韩语参考：직접（直接）<br>
  例：彼女に直接言ったらどうですか。（你直接跟她说怎么样？）
- **著者**（ちょしゃ）作者｜韩语参考：저자（著者，作者） / 필자（笔者，作者） / 글쓴이（作者）<br>
  例：この本の著者は誰ですか。（这本书的作者是谁？）
- **塵**（ちり）尘土｜韩语参考：티（尘土，尘粒 ，尘埃）<br>
  例：１年が過ぎ、彼の死体は塵と化した。（一年过去，他的尸体化为了尘土。）
- **遂に**（ついに）终于｜韩语参考：종내（终于，终究）<br>
  例：彼はついに大学の学長を辞任した。（他终于辞去了大学校长职务。）
- **通過**（つうか）通过｜韩语参考：통과（通过）<br>
  例：通過する車に気をつけなさい。（注意过往的车辆。）
- **通学**（つうがく）上学；走读｜韩语参考：통학（走读）<br>
  例：いつもバス通学です。（我平时坐公交上学。）
- **通行**（つうこう）通行｜韩语参考：통행（通行）<br>
  例：ここは大型車の通行は禁止されている。（这里禁止大型车辆通行。）
- **通じる**（つうじる）通；通晓｜韩语参考：통하다（通，通过，流经）<br>
  例：彼女は電話が通じるとすぐ話し始めた。（电话一接通，她就说了起来。）
- **通信**（つうしん）通信｜韩语参考：통신（通信，通讯）<br>
  例：彼は、無電で通信を送った。（他用无线电发了报。）
- **捕まる**（つかまる）被抓；被捉｜韩语参考：잡히다（被抓） / 붙들리다（被抓住，被逮住） / 붙잡히다（(人、动物等)被抓住）<br>
  例：ロープにしっかり捕まりなさい。（抓紧绳子。）
- **掴む**（つかむ）抓住；掌握｜韩语参考：잡다（掌握） / 붙들다（抓住，揪住） / 붙잡다（抓住）<br>
  例：ジムはジュリーの腕をぐいと掴んだ。（吉姆一把抓住朱莉的手臂。）
- **疲れ**（つかれ）疲劳｜韩语参考：피곤（疲惫，疲劳，疲倦） / 피로（疲劳，疲倦，疲乏，劳累）<br>
  例：彼女はいくぶん疲れを感じていた。（她感到有些疲倦。）
- **付き合い**（つきあい）交往；应酬｜韩语参考：교제（交往）<br>
  例：彼は知事と長年の付き合いです。（他和知事有多年的交情。）
- **次々**（つぎつぎ）接连不断｜韩语参考：차례차례<br>
  例：彼らは次々と出発した。（他们一个接一个地出发了。）
- **就く**（つく）就职；就位｜韩语参考：취임하다 / 자리에 앉다<br>
  例：友人の好意で職に就くことができた。（承蒙朋友帮忙，我找到了工作。）
- **付ける**（つける）安上；附加｜韩语参考：붙이다（加，附加）<br>
  例：彼女は昔、日記を付けていたが今はつけていない。（她以前写日记，现在不写了。）
- **土**（つち）土；土壤｜韩语参考：땅（土，土地，土层） / 흙（土，土壤） / 토양（泥土，土壤）<br>
  例：種の上に少し土をかぶせなさい。（在种子上盖一点土。）
- **続き**（つづき）继续；续篇｜韩语参考：속편（续集，续篇）<br>
  例：日照り続きでその池は干上がった。（因为持续干旱，那个池塘干涸了。）
- **包み**（つつみ）包裹；包｜韩语参考：꾸러미（包，卷，捆，串） / 보따리（包，包袱）<br>
  例：行商人は大きな包みを背負って運んだ。（货郎背着一个大包裹赶路。）
- **勤め**（つとめ）工作；职务｜韩语参考：근무 / 직무<br>
  例：お勤めはどちらですか。（您在哪工作？）
- **つまり**（つまり）也就是说｜韩语参考：곧（也就是，换言之） / 즉（也就是）<br>
  例：つまり彼女は下手な踊り子だ。（也就是说，她是个蹩脚的舞者。）
- **罪**（つみ）罪；过错｜韩语参考：죄（罪，罪孽）<br>
  例：ビルはその罪を犯していなかった。（比尔没有犯那项罪。）
- **詰める**（つめる）装入；塞满；缩短｜韩语参考：놓다（填充，塞，装）<br>
  例：荷物をスーツケースに詰めました。（我把行李塞进了旅行箱。）
- **積もる**（つもる）积；堆积｜韩语参考：쌓이다（堆，叠放，堆积）<br>
  例：雪はあたり一面に積もっていた。（雪积得满地都是。）
- **梅雨**（つゆ）梅雨｜韩语参考：장마（梅雨）<br>
  例：天気予報によれば、まもなく梅雨に入るそうだ。（据天气预报，马上就要入梅了。）

## 语法

- **〜とすれば / 〜としたら**：假设…的话
  接续：动词普通形／い形容词 + とすれば・としたら；名词及な形容词可视表达使用 だとしたら 或 としたら
  朝鲜语：-라고 한다면（韩语「-라고 한다면」偏传闻假设；日语「としたら」只是单纯设想，不含传闻，语气更轻。）
- **〜としても**：即使…也…
  接续：动词普通形／い形容词 + としても；名词及な形容词可视表达使用 だとしても 或 としても
  朝鲜语：-다고 해도（韩语 -다고 해도 可表达让步假设；日语名词或な形容词的形式需结合具体结构，如「本当だとしても」或「本当としても」。）
