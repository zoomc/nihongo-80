# Day 097 · 〜ことはない、〜ことにしている

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜ことはない、〜ことにしている」造两句自己的话，表达：不必…；用不着…；习惯上…；坚持…

## 新词 19

- **刀**（かたな）刀｜韩语参考：칼（刀）<br>
  例：その刀は王子にふさわしい。（那把刀配得上王子。）
- **語る**（かたる）讲述；谈论｜韩语参考：말하다 / 이야기하다<br>
  例：行動は言葉よりも声高く語る。（行动比语言更响亮。）
- **価値**（かち）价值｜韩语参考：가치（价，价值） / 값（价值） / 값어치（价格，价值）<br>
  例：この本にはある程度の価値はあります。（这本书有一定价值。）
- **勝ち**（かち）胜利｜韩语参考：승리<br>
  例：試合は彼の勝ちに終わった。（比赛以他获胜告终。）
- **がっかり**（がっかり）失望；沮丧｜韩语参考：실망하다<br>
  例：その知らせにはがっかりだ。（听到那个消息很失望。）
- **活気**（かっき）活力；生气｜韩语参考：활기（朝气，活力，生气，生机） / 생기（朝气，活力）<br>
  例：その街は活気にあふれていた。（那条街充满活力。）
- **学期**（がっき）学期｜韩语参考：학기（学期）<br>
  例：前学期は成績がよかった。（上学期成绩很好。）
- **活動**（かつどう）活动｜韩语参考：활동（活动）<br>
  例：彼女は多くの学校の活動に参加する。（她参加很多学校活动。）
- **活用**（かつよう）活用；利用｜韩语参考：활용（充分利用，灵活运用，活用，应用）<br>
  例：彼はその機会を最大限に活用した。（他最大限度地利用了那次机会。）
- **悲しむ**（かなしむ）悲伤；难过｜韩语参考：슬퍼하다（悲伤，伤心） / 서러워하다（悲伤，悲哀，伤心）<br>
  例：悲しんでいる彼女をそっとしておきなさい。（别去打扰正伤心的她。）
- **必ずしも**（かならずしも）未必｜韩语参考：반드시 ~는 아니다<br>
  例：金持ちが必ずしも幸福とは限らない。（有钱人未必幸福。）
- **金**（かね）钱｜韩语参考：돈（钱，金钱，钱币）<br>
  例：母は子供たちに金をわけてやった。（母亲把钱分给了孩子们。）
- **金持ち**（かねもち）有钱人｜韩语参考：부잣집（富人家，有钱人家）<br>
  例：金持ちが必ずしも幸福とは限らない。（有钱人未必幸福。）
- **可能**（かのう）可能｜韩语参考：가능（可能）<br>
  例：男の子へのしつけは可能である。（对男孩的管教是可能的。）
- **株**（かぶ）股票；股份｜韩语参考：주（股票）<br>
  例：彼は大金を株に投資した。（他把一大笔钱投资到股票上。）
- **被る**（かぶる）戴（头）；蒙受｜韩语参考：쓰다（戴）<br>
  例：その機械はほこりをかぶっていた。（那台机器上蒙了一层灰。）
- **我慢**（がまん）忍耐｜韩语参考：참다 / 인내<br>
  例：この寒さは我慢出来ないな。（这么冷真受不了啊。）
- **神**（かみ）神｜韩语参考：신（上帝，神）<br>
  例：人間は神ほど万能ではない。（人并非像神那样无所不能。）
- **雷**（かみなり）雷｜韩语参考：우레（雷）<br>
  例：子供達は雷におびえた。（孩子们被雷声吓坏了。）

## 语法

- **〜ことはない**：不必…；用不着…
  接续：动词辞书形 + ことはない
  朝鲜语：-ㄹ 필요는 없다（韩语「-ㄹ 필요는 없다」直译“没有必要”；日语「ことはない」还隐含“你想多了”的安慰，语气更主观。）
- **〜ことにしている**：习惯上…；坚持…
  接续：动词辞书形/ない形 + ことにしている
  朝鲜语：-기로 하고 있다（韩语「-기로 하다」多指一次性决定；日语「ことにしている」用「ている」表长期坚持，韩语要靠「-곤 한다」才接近。）
