# Day 031 · V ます形(去ます) + やすい / にくい、Vます形(去ます)/い形(去い)/な形词干 + すぎる、あげる / くれる / もらう

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **V ます形(去ます) + やすい / にくい**：容易…／难以…
  接续：動詞 ます形 去 ます + やすい・にくい；整体按 い形容詞 变形（読みやすくない／読みやすかった）
  朝鲜语：-기 쉽다 / -기 어렵다（쓰기 쉽다／쓰기 어렵다 对照 書きやすい／書きにくい。韩语用 -기 把动作名词化；日语先找 ます形，再去 ます。）
- **Vます形(去ます)/い形(去い)/な形词干 + すぎる**：过于…；…得过头
  接续：动词ます形去 ます、い形容词去 い、な形容词用词干 + すぎる；如 食べすぎる／熱すぎる／静かすぎる。
  朝鲜语：너무 / -기에는 너무（韩语너무是副词，直接修饰谓语；日语すぎる是后缀，须接词干，且可单独作谓语。）
- **あげる / くれる / もらう**：给…；别人给我…；从…得到
  接续：给予者 は/が 接受者 に 物 を あげる；给予者 が 我方 に 物 を くれる；接受者 は 给予者 に/から 物 を もらう
  朝鲜语：주다 / 받다（韩语 주다 不分方向，日语必须按「谁给谁」区分 あげる／くれる；韩语 받다 对应 もらう，但日语 もらう 的来源可用 に 或 から。）
