# Day 096 · 〜くらい / 〜ぐらい（extent）、〜さえ

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜くらい / 〜ぐらい（extent）、〜さえ」造两句自己的话，表达：到…地步；至少…；连…都…

## 新词 24

- **州**（しゅう）州｜韩语参考：주<br>
  例：南部の州へ冬期に旅行すると、今旅行するよりも料金が高くなります。（冬天去南部各州旅行，费用会比现在高。）
- **週**（しゅう）周；星期｜韩语参考：주（一周，一星期） / 주일（周，星期）<br>
  例：それはその前の週に買ったものでした。（那是前一周买的。）
- **銃**（じゅう）枪；枪支｜韩语参考：총（枪）<br>
  例：警察は簡単に銃を使ってはいけない。（警察不能轻易动用枪支。）
- **周囲**（しゅうい）周围；四周｜韩语参考：주위（周围）<br>
  例：この木は周囲３メートルある。（这棵树周长有三米。）
- **収穫**（しゅうかく）收获；收成｜韩语参考：수확（收获，收成，产量） / 소출（收成，产量）<br>
  例：私たちはみな収穫の手伝いをした。（我们都帮忙做了收割的活儿。）
- **週間**（しゅうかん）周；星期｜韩语参考：주간（周，星期） / 주일（周，星期）<br>
  例：もう２週間たったら帰ります。（再过两周我就回来。）
- **宗教**（しゅうきょう）宗教｜韩语参考：종교（宗教）<br>
  例：その両国は宗教と文化が違っている。（那两个国家的宗教和文化不同。）
- **重視**（じゅうし）重视｜韩语参考：중시（重视）<br>
  例：人生においてお金を重視する人もいる。（也有人看重人生中的金钱。）
- **ジュース**（ジュース）果汁；饮料｜韩语参考：주스（汁，果汁） / 과실음료（果汁饮料）<br>
  例：私はニワトコジュースが好きだ。（我喜欢接骨木果汁。）
- **修正**（しゅうせい）修正；订正｜韩语参考：수정（修正，修改）<br>
  例：彼は自説を修正した。（他修正了自己的主张。）
- **重大**（じゅうだい）重大；严重｜韩语参考：중대（重大）<br>
  例：彼は重大な発見をした。（他有了重大发现。）
- **住宅**（じゅうたく）住宅；住房｜韩语参考：주택（住宅，住房）<br>
  例：どちらかといえば木造住宅に住みたい。（真要说的话，我想住木结构住宅。）
- **集団**（しゅうだん）集体；群体｜韩语参考：집단（集团，团队，团伙，集体） / 단체（团体，集体）<br>
  例：君はいまやエリート集団の一員だ。（你现在已经是精英团体的一员了。）
- **集中**（しゅうちゅう）集中｜韩语参考：집중（集中）<br>
  例：私は読書に集中していた。（我正专心读书。）
- **収入**（しゅうにゅう）收入｜韩语参考：수입（收入）<br>
  例：収入以上の生活をするな。（不要过超出收入的生活。）
- **住民**（じゅうみん）居民｜韩语参考：주민（居民） / 거주민（居民）<br>
  例：住民の半数以上はその計画に反対だ。（半数以上的居民反对那个计划。）
- **重要**（じゅうよう）重要｜韩语参考：중요（重要）<br>
  例：彼女はすぐに出発する事が重要だ。（她必须马上出发，这一点很重要。）
- **修理**（しゅうり）修理｜韩语参考：수리（修理，维修）<br>
  例：その車は修理する価値がない。（那辆车不值得修。）
- **主義**（しゅぎ）主义；原则｜韩语参考：주의（主义）<br>

- **宿泊**（しゅくはく）住宿｜韩语参考：숙박（住宿，投宿）<br>
  例：６人宿泊させて欲しい。（希望让我们六个人住下。）
- **手術**（しゅじゅつ）手术｜韩语参考：수술（手术）<br>
  例：手術をしなければなりません。（必须做手术。）
- **首相**（しゅしょう）首相；总理｜韩语参考：수상（首相） / 국무총리（国务总理）<br>
  例：首相の留守中は外務大臣が代理を務める。（首相不在期间由外务大臣代理。）
- **手段**（しゅだん）手段；方法｜韩语参考：수（手段，办法，方法）<br>
  例：全ての手段が試みられたわけではない。（并不是所有办法都试过了。）
- **主張**（しゅちょう）主张｜韩语参考：주장（主张）<br>
  例：私たちはその重要性を主張した。（我们强调了它的重要性。）

## 语法

- **〜くらい / 〜ぐらい（extent）**：到…地步；至少…
  接续：普通形 + くらい／ぐらい；名词 + くらい
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」对应程度用法；“至少”韩语要说「적어도」，日语用「くらい」一并承担，范围更宽。）
- **〜さえ**：连…都…
  接续：名词 + さえ／でさえ／にさえ
  朝鲜语：-조차（韩语「-조차」多与否定呼应，这点与「さえ」相近；但日语「さえ」还能构成「さえ〜ば」条件句，韩语要用「-기만 하면」。）
