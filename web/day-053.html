今日语法 3 条

韩语对应-(으)면 -(으)ㄹ수록
韩语用면…ㄹ수록前后同词，结构与日语ば…ほど对应；但韩语可省略前项只留수록。
V ば形 + 同一動詞 辞書形 + ほど
越…越…
動詞 条件形(ば) + 同じ動詞 辞書形 + ほど；い形 ければ＋い形＋ほど；な形 なら＋な形＋ほど
前后同词重复，表成正比变化；常与 ますます 呼应
렌슈우스레바스루호도,조우즈니나리마스.
練習すればするほど、上手になります。
越练越熟练。
네단가타카케레바타카이호도,우레니쿠쿠나리마스.
値段が高ければ高いほど、売れにくくなります。
价格越贵越难卖。
易错点

練習すれば、上手になります。 → 練習すればするほど上手になります。（这是普通条件句，不含「越…越…」；中文「越练越好」直译丢 ほど 错）

韩语对应-조차 / -야말로 / -마저
韩语조차表连…都(多否定)、마저表连…也(消极)、야말로表正是，分工比日语さえ/すら细。
N(＋助詞) + さえ／こそ／すら；V ば形 前 + さえ…ば
발음N + 사에／코소／스라；V 바카타치 마에 + 사에…바
甚至…／只要…就／正是…／连…都
さえ/すら 取代 が・を 或接在助词后（にさえ／でさえ）；さえ…ば 用 条件形(ば)；こそ 强调主语/原因（〜からこそ）
さえ 举极端例表「连…都/甚至」；さえ…ば 表「只要满足这一项就够」；こそ 强调「正是」；すら 文言、更消极
이소가시쿠테,히루고한오타베루지칸사에아리마센.
忙しくて、昼ご飯を食べる時間さえありません。
忙得连吃午饭的时间都没有。
코레사에아레바,다이조우부데스.
これさえあれば、大丈夫です。
只要有这个就没问题。
今こそ頑張るときです。
现在正是努力的时候。
易错点

時間さえがありません。 → 時間さえありません。（さえ 已取代 が/を，不再叠 が；中文「连时间都没有」直译保留 が 错）

韩语对应-는데도 / -지만 / -라고는 해도
韩语责备用는데도，中性让步用지만，话虽如此用라고는 해도；くせに的轻蔑靠语调。
普通形 + くせに / ものの / とはいえ
明明…却（责备）／虽然…但是／虽说…然而
くせに：动词／い形普通形、な形容词 + な、名词 + の；ものの：普通形；とはいえ：名词或普通形 + とはいえ
くせに 带强烈责备/轻蔑（对人不满）；ものの 是中性书面让步；とはいえ 是「话虽如此」，常修正前句
시떼이루쿠세니,오시에테쿠레마센데시타.
知っているくせに、教えてくれませんでした。
明明知道却不告诉我。
카따모노노,쓰카떼이마센.
買ったものの、使っていません。
虽然买了却没在用。
타카이토와이에,힌시쓰와이이데스.
高いとはいえ、品質はいいです。
虽说贵，质量倒不错。
易错点

先生は知っているくせに、教えてくれませんでした。 → 先生はご存じなのに、教えてくださいませんでした。（くせに 带责备/轻蔑，对老师用极失礼；中文「明明…却」直译不看对象错）
