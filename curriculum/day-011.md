# Day 011 · て形、た形（普通过去）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「て形、た形（普通过去）」造两句自己的话，表达：动词て形（连接/中顿/请求基础）；动词た形（简体过去）

## 新词 23

- **ええ**（ええ）是；嗯｜韩语参考：네（是，行） / 응（是，行）<br>
  例：「テニスをしましょうか」「ええ」（“我们打网球吧？”“好啊。”）
- **エレベーター**（エレベーター）电梯｜韩语参考：엘리베이터（电梯，升降梯）<br>
  例：エレベーターはどこですか。（电梯在哪儿？）
- **鉛筆**（えんぴつ）铅笔｜韩语参考：연필（铅笔）<br>
  例：えんぴつであなたの名前を書きなさい。（用铅笔写下你的名字。）
- **おいしい**（おいしい）好吃｜韩语参考：맛있다<br>
  例：おいしい食事をありがとう。（谢谢这顿美味的饭。）
- **多い**（おおい）多｜韩语参考：많다（多，丰富，强）<br>
  例：この学校は男子よりも女子が多い。（这所学校女生比男生多。）
- **大きな**（おおきな）大的｜韩语参考：큰<br>
  例：それらはとても大きなりんごです。（那些是很大的苹果。）
- **大勢**（おおぜい）很多人｜韩语参考：많은 사람<br>
  例：大ぜいの人たちがいた。（人很多。）
- **お母さん**（おかあさん）母亲；妈妈｜韩语参考：엄마（妈妈） / 어머니（母亲，妈妈）<br>
  例：お母さんに口答えしてはいけませんよ。（不许跟妈妈顶嘴。）
- **お菓子**（おかし）点心；零食｜韩语参考：과자 / 간식<br>
  例：もうすこしお菓子を食べませんか。（再吃点零食吗？）
- **お金**（おかね）钱｜韩语参考：돈（钱，金钱，钱币）<br>
  例：どうやってそのお金を手に入れたんですか。（你是怎么弄到那笔钱的？）
- **置く**（おく）放；放置｜韩语参考：놓다（放，放置） / 두다（搁，放置，摆放）<br>
  例：それをテーブルの上に置きなさい。（把它放在桌上。）
- **奥さん**（おくさん）夫人；太太｜韩语参考：사모님（令夫人，尊夫人）<br>
  例：奥さんがどこかに出かけているらしいから。（他太太好像出门去哪儿了。）
- **お酒**（おさけ）酒｜韩语参考：술<br>
  例：マイクはお酒をやめたの？（迈克戒酒了吗？）
- **お皿**（おさら）盘子｜韩语参考：접시<br>
  例：スープを入れるくぼんだお皿がありますか。（有盛汤用的深盘吗？）
- **お祖父さん**（おじいさん）祖父；老爷爷｜韩语参考：할아버지<br>
  例：おじいさんはとてもゆっくりと話す。（爷爷说话非常慢。）
- **押す**（おす）推；按｜韩语参考：밀다（推） / 누르다（按，压，摁） / 떠밀다（推，推动）<br>
  例：シャッターを押してくれますか。（能帮我按一下快门吗？）
- **遅い**（おそい）慢；晚｜韩语参考：늦다（晚，迟） / 뜨다（慢，缓慢） / 느리다（慢，缓慢，迟缓）<br>
  例：遅くなっても何もないよりはまし。（晚做总比不做好。）
- **お手洗い**（おてあらい）洗手间｜韩语参考：화장실（洗手间，卫生间）<br>
  例：お手洗いはどこですか。（洗手间在哪儿？）
- **お父さん**（おとうさん）父亲；爸爸｜韩语参考：아빠（爸爸）<br>
  例：お父さんからことづけがあります。（你父亲托我带个话。）
- **男**（おとこ）男人｜韩语参考：남자（男子，男人） / 사내（男人，老爷们）<br>
  例：その男とつきあってはいけないよ。（别跟那个男人来往。）
- **男の子**（おとこのこ）男孩｜韩语参考：사내애（男孩儿） / 사내아이（男孩儿）<br>
  例：あのハンサムな男の子を見て。（看那个帅气的男孩。）
- **一昨日**（おととい）前天｜韩语参考：그제（前天） / 그저께（前天）<br>
  例：一昨日、彼は学校を休んだかもしれない。（前天他可能没去上学。）
- **一昨年**（おととし）前年｜韩语参考：재작년（前年）<br>
  例：彼女は、一昨年よりもはるかに暮らし向きがよい。（她的日子比前年好过多了。）

## 语法

- **て形**：动词て形（连接/中顿/请求基础）
  接续：五段音便（って/んで/いて/いで/して）；一段 去る+て；カ変 来て；サ変 して
  朝鲜语：-고 / -아·어서（韩语连接词尾按语义分고(并列)、서(顺序/原因)，不能一词尾通吃；日语て形用途更广。）
- **た形（普通过去）**：动词た形（简体过去）
  接续：て形 的 て/で → た/だ
  朝鲜语：-았/었-（韩语过去词尾附于词干且受元音和谐影响；日语た形有音便，还能表完成、发现。）
