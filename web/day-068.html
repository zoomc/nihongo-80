今日语法 2 条

N + に 対して / に 関して
발음〜니타이시테 / 〜니칸시테
对…（针对对象/对比）／关于…（书面）
名詞 + に対して（动作/态度的对象，或「与此相对」的对比）；名詞 + に関して（＝について 的书面语）
に対して 后接对人/物的动作、态度或对比；に関して 多用于正式文书、新闻
先生に対して失礼なことを言いました。
对老师说了失礼的话。
この問題に関して、後ほど報告します。
关于这个问题稍后汇报。
朝鲜语：-에 대해 / -에 관해
韩语에 대해表针对，에 관해表关于，二者都可书面；日语に対して还表对比，韩语须用에 비해。
易错点

先生に対してに失礼しました。 → 先生に対して失礼しました。（に対して 已含 に，不再叠 に；中文「对老师」直译叠加助词错）

N / V辞書形 + に 伴って / に つれて / に 従って
발음〜니토모나떼
随着…（前项变化，后项也跟着变化）
名詞 + に／動詞 辞書形 + に + 伴って・つれて・従って；后项须是变化动词（増える／変わる／高くなる 等）
书面，表伴随变化；につれて/に従って 偏比例变化，に伴って 偏伴随发生（常带同时性）
気温が上がるにつれて、売上が増えます。
随着气温升高，销量增加。
技術の進歩に伴って、仕事のやり方が変わりました。
随着技术进步，工作方式变了。
朝鲜语：-에 따라 / -(으)면서
韩语伴随变化用에 따라或면서，比例变化多用ㄹ수록；日语三形语感细分更多。
易错点

気温が上がるにつれて、ビールがおいしいです。 → 気温が上がるにつれて、ビールが売れるようになります。（后项须是变化（増える／高くなる），静态形容词 おいしい 不接；中文「随着…很…」直译错）
