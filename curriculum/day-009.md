## 新词 25

- **入口**（いりぐち）入口｜韩语参考：입구<br>
  例：１台の車が入り口に止まった。（一辆车停在了入口处。）
- **要る**（いる）需要｜韩语参考：필요하다<br>
  例：今のところお金はいらない。（现在不需要钱。）
- **入れる**（いれる）放进；装入｜韩语参考：넣다（放进，装进） / 집어넣다（放进去）<br>
  例：それは引き出しに入れておきました。（那个我放进抽屉里了。）
- **色**（いろ）颜色｜韩语参考：색깔（颜色，色彩）<br>
  例：カメレオンはどんな色にでもなれる。（变色龙能变成任何颜色。）
- **いろいろ**（いろいろ）各种各样｜韩语参考：여러 가지<br>
  例：先生といってもいろいろある。（老师也分各种各样的。）
- **後ろ**（うしろ）后面｜韩语参考：뒤（后，后面） / 뒤쪽（后面，后头，后部） / 뒷면（后面，背面，反面）<br>
  例：校長が先生の後ろから入ってきた。（校长从老师身后走了进来。）
- **薄い**（うすい）薄；淡｜韩语参考：묽다（稀，薄） / 얇다（薄） / 엷다（薄）<br>
  例：コーヒーは薄いのが好きです。（我喜欢淡一点的咖啡。）
- **歌**（うた）歌｜韩语参考：노래（歌，歌曲，唱歌）<br>
  例：歌がうまければいいのになあ。（我要是唱歌好听就好了。）
- **歌う**（うたう）唱｜韩语参考：뽑다（唱） / 부르다（唱） / 뽑아내다（唱）<br>
  例：ジョンはステージで何を歌いましたか。（约翰在台上唱了什么？）
- **生まれる**（うまれる）出生｜韩语参考：나다（生，出生） / 출생되다（出生，出世） / 출생하다（出生，出世）<br>
  例：どんぐりからオークが生まれる。（橡树由橡子长成。）
- **海**（うみ）海｜韩语参考：바다（海，大海，海洋）<br>
  例：何としても海をひと目みたいものだ。（我真想看一眼大海。）
- **売る**（うる）卖｜韩语参考：팔다（卖，出售） / 팔아먹다（卖）<br>
  例：トムはメアリーにバイクを売った。（汤姆把摩托车卖给了玛丽。）
- **煩い**（うるさい）吵；烦人｜韩语参考：시끄럽다 / 귀찮다<br>
  例：あの子はなんてうるさい子だろう。（那孩子真够闹的。）
- **上着**（うわぎ）上衣；外套｜韩语参考：겉옷（外衣，外套） / 상의（上衣，上装） / 웃옷（上衣，上装）<br>
  例：ドアのそばのかぎに上着をかけなさい。（把外套挂在门边的钩子上。）
- **絵**（え）画｜韩语参考：그림<br>
  例：絵がテーブルの上にかかっている。（画挂在桌子上方。）
- **映画館**（えいがかん）电影院｜韩语参考：영화관（电影院） / 상영관（电影院，影厅）<br>
  例：その映画館は人々でいっぱいだった。（电影院里挤满了人。）
- **英語**（えいご）英语｜韩语参考：영어（英语）<br>
  例：アメリカでは英語を話します。（在美国人们说英语。）
- **ええ**（ええ）是；嗯｜韩语参考：네（是，行） / 응（是，行）<br>
  例：「テニスをしましょうか」「ええ」（“我们打网球吧？”“好啊。”）
- **エレベーター**（エレベーター）电梯｜韩语参考：엘리베이터（电梯，升降梯）<br>
  例：エレベーターはどこですか。（电梯在哪儿？）
- **鉛筆**（えんぴつ）铅笔｜韩语参考：연필（铅笔）<br>
  例：えんぴつであなたの名前を書きなさい。（用铅笔写下你的名字。）
- **おいしい**（おいしい）好吃｜韩语参考：맛있다<br>
  例：おいしい食事をありがとう。（谢谢这顿美味的饭。）
- **多い**（おおい）多｜韩语参考：많다（多，丰富，强）<br>
  例：この学校は男子よりも女子が多い。（这所学校女生比男生多。）
- **大きな**（おおきな）大的｜韩语参考：큰<br>
  例：それらはとても大きなりんごです。（那些是很大的苹果。）
- **大勢**（おおぜい）很多人｜韩语参考：많은 사람<br>
  例：大ぜいの人たちがいた。（人很多。）
- **お母さん**（おかあさん）母亲；妈妈｜韩语参考：엄마（妈妈） / 어머니（母亲，妈妈）<br>
  例：お母さんに口答えしてはいけませんよ。（不许跟妈妈顶嘴。）

## 语法

- **ます形（丁寧体）**：动词礼貌形：ます／ません／ました／ませんでした
  接续：動詞 + ます（う段→い段+ます；一段去る+ます）
  朝鲜语：-습니다/ㅂ니다 / -아·어요（韩语敬语分합쇼체与해요체，随听者选择；日语ます体一套即可，无此分层。）
- **～が ほしい**：想要（某物）
  接续：名詞 + が + ほしい（です）
  朝鲜语：이/가 갖고 싶다 / 원하다（韩语갖고 싶다限第一人称，第三人称用갖고 싶어 하다；원하다偏书面。）
- **比较（より／ほうが／ほど）**：比…／不如…
  接续：A は B より ～；A より B の ほうが ～；A は B ほど ～ない
  朝鲜语：A가 B보다 + 형용사（韩语可用 보다 表比较基准；「没昨天冷」可说 어제보다 춥지 않다，也可用 만큼 与否定表达。）
