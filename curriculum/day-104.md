# Day 104 · 〜も〜ば〜も、〜らしい（typical of）

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜も〜ば〜も、〜らしい（typical of）」造两句自己的话，表达：既…又…；也…也…；像…样的；典型的…

## 新词 19

- **切れる**（きれる）断；用完｜韩语参考：되다（用完，没有） / 끊기다（断，绝） / 끊어지다（断，被切断）<br>
  例：ガソリンが切れかかっている。（汽油快用完了。）
- **記録**（きろく）记录｜韩语参考：기록（记录） / 기재（记录，记载，填写）<br>
  例：無言が記録されたためしはない。（还从没有过沉默被记录下来的先例。）
- **議論**（ぎろん）讨论；争论｜韩语参考：의논（商议，讨论，商量）<br>
  例：彼らは議論をやめることに決めた。（他们决定停止争论。）
- **銀**（ぎん）银｜韩语参考：은（银）<br>
  例：金より銀の指輪の方が好きです。（比起金戒指，我更喜欢银的。）
- **禁煙**（きんえん）禁烟｜韩语参考：금연（禁烟）<br>
  例：いつ禁煙のサインを消すのでしょうね。（不知什么时候才会把禁烟的牌子撤掉呢。）
- **金額**（きんがく）金额｜韩语参考：금액（金额） / 액수（数额，金额）<br>
  例：彼は彼女にかなりの金額を与えた。（他给了她一大笔钱。）
- **金庫**（きんこ）保险箱｜韩语参考：금고（保险柜，保险箱，金库）<br>
  例：貴重品は金庫にしまっておきなさい。（贵重物品要收进保险箱。）
- **禁止**（きんし）禁止｜韩语参考：금지（禁止）<br>
  例：ここでは煙草は禁止されています。（这里禁止吸烟。）
- **金銭**（きんせん）金钱｜韩语参考：금전（金钱，钱） / 돈（钱，金钱，钱币）<br>
  例：金銭のことで彼と争いになった。（因为钱的事跟他起了争执。）
- **金属**（きんぞく）金属｜韩语参考：금속（金属） / 쇠（金属）<br>
  例：鉄は最も有用な金属です。（铁是最有用的金属。）
- **近代**（きんだい）近代｜韩语参考：근대（近代）<br>
  例：近代医学の進歩は長い道程を歩んだ。（近代医学的进步走过了漫长的历程。）
- **緊張**（きんちょう）紧张｜韩语参考：긴장（紧张）<br>
  例：冷戦の緊張が高まった。（冷战紧张局势加剧了。）
- **筋肉**（きんにく）肌肉｜韩语参考：근육（肌肉）<br>
  例：水泳は筋肉を発達させる。（游泳能使肌肉发达。）
- **金融**（きんゆう）金融｜韩语参考：금융（金融）<br>
  例：工業よりも金融に関心のある学生のほうが多い。（关心金融的学生比关心工业的还多。）
- **金曜**（きんよう）星期五｜韩语参考：금요일<br>
  例：彼は月曜から金曜まで働く。（他从周一到周五工作。）
- **句**（く）句；俳句｜韩语参考：구（句）<br>
  例：彼はその句の文字どおりの意味を説明した。（他解释了那句话的字面意思。）
- **食う**（くう）吃｜韩语参考：먹다（吃）<br>
  例：この事業は金を食う。（这项事业很费钱。）
- **偶然**（ぐうぜん）偶然｜韩语参考：우연（偶然） / 우연히（偶然地）<br>
  例：私は道で古い友人と偶然出会った。（我在路上偶然遇到了老朋友。）
- **臭い**（くさい）臭｜韩语参考：구리다（臭，难闻） / 쿠리다（臭，难闻） / 고리타분하다（臭，腐臭）<br>
  例：あいつが臭い。（那家伙身上有股味儿。）

## 语法

- **〜も〜ば〜も**：既…又…；也…也…
  接续：名词 + も + ば形 + 名词 + も；名词 + も + い形容词ければ + 名词 + も
  朝鲜语：-기도 하고 -기도 하다（韩语「-기도 하고 -기도 하다」只并列；日语「も〜ば〜も」用ば形连接，书面感更强，前半须是完整谓语。）
- **〜らしい（typical of）**：像…样的；典型的…
  接续：名词 + らしい（らしくない 表“不像”）
  朝鲜语：-다운（韩语「-다운」同样表“符合其本色”；但日语「らしい」还有传闻用法，韩语传闻用「-라고 한다」，不会混淆。）
