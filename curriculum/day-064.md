# Day 064 · 〜ようとする、〜そうにない / 〜そうもない、〜一方だ

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ようとする**：想要…；正要…
  接续：动词意志形 + とする（否定形：ようとしない）
  朝鲜语：-(으)려고 하다 / -(으)려던 참이다（韩语「-려고 하다」也表意图，但“正要…的瞬间”日语说「ようとしたとき」，韩语多用「-려던 참에」，形式不同。）
- **〜そうにない / 〜そうもない**：看样子不会…；不像会…
  接续：动词ます形词干 + そうにない／そうもない
  朝鲜语：-(으)ㄹ 것 같지 않다（韩语没有专门对应，常说「-ㄹ 것 같지 않다」；日语「そうにない」依据眼前迹象，主观判断色彩更强。）
- **〜一方だ**：一直…；越来越…
  接续：动词辞书形 + 一方だ
  朝鲜语：계속 …하다 / 점점 더 …해지다（물가가 계속 오르다 可对照 物価は上がる一方だ，后者强调走势只向上涨一侧。-기만 하다 常说一个人只做某事，适合对照 てばかりいる。）
