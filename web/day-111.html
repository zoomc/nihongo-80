③ 语法 6 分钟

〜まま
动词た形/ない形 + まま；い形容词 + まま；ナ形容词 + な + まま；名词 + の + まま
就那样…；保持着…

表示某状态保持不变地进行另一动作。

エアコンをつけたまま寝てしまい、風邪をひいた。
开着空调就睡着了，结果感冒了。
この町は、私が子どもだったころのままだ。
这个镇子还和我小时候一样。
靴のまま部屋に入らないでください。
请不要穿着鞋进房间。
朝鲜语：-ㄴ 채로
韩语「-ㄴ 채로」与「まま」很接近；但日语可接名词「〜のまま」，韩语没有对应形式，要改说「그대로」。

易错：エアコンをつけるまま寝てしまい、風邪をひいた。 → つけたまま（表示状态持续要用「た形 + まま」，「つけるまま」不合法。）

〜うちに
动词辞书形/ている/ない形 + うちに；い形容词 + うちに；ナ形容词 + な + うちに；名词 + の + うちに
趁着…；在…过程中

表示在某状态持续期间做某事，或期间不知不觉发生变化。

若いうちに、いろいろな国を旅行したほうがいい。
趁年轻多去几个国家旅行比较好。
スープが冷めないうちに、どうぞ召し上がってください。
请趁汤还没凉快喝吧。
音楽を聞いているうちに、いつの間にか眠ってしまった。
听着音乐，不知不觉就睡着了。
朝鲜语：-는 동안에
韩语「-는 동안에」只表时间范围；日语「うちに」还含“趁还没变、赶在期限前”的语感。

易错：若いのうちに、いろいろな国を旅行したほうがいい。 → 若いうちに（い形容词直接接「うちに」，不加「の」。）
