# Day 006 · で（动作场所／手段／材料／原因）、へ（移动方向）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「で（动作场所／手段／材料／原因）、へ（移动方向）」造两句自己的话，表达：在…／用…／因为…；往／向…

## 新词 20

- **友達**（ともだち）朋友｜韩语参考：벗（朋友，友人） / 친구（朋友，好友， 友人，故旧）<br>
  例：友達と映画を見ます。（和朋友看电影。）
- **人**（ひと）人｜韩语参考：사람（人） / 인간（人，人类）<br>
  例：あの人は先生です。（那位是老师。）
- **学生**（がくせい）学生｜韩语参考：학생（学生） / 대학생（大学生）<br>
  例：私は学生です。（我是学生。）
- **先生**（せんせい）老师；医生/律师等｜韩语参考：샘（老师） / 선생（老师，教师） / 선생님（老师，教师）<br>
  例：田中さんは先生です。（田中是老师。）
- **本**（ほん）书｜韩语参考：책（书，书籍，画册） / 서적（书籍，书）<br>
  例：本を読みます。（读书。）
- **日本語**（にほんご）日语｜韩语参考：일본어（日语，日本语）<br>
  例：日本語を勉強します。（学日语。）
- **勉強**（べんきょう）学习；用功｜韩语参考：공부（学习，读书）<br>
  例：図書館で勉強します。（在图书馆学习。）
- **宿題**（しゅくだい）作业｜韩语参考：숙제（作业） / 과제물（作业）<br>
  例：宿題をします。（做作业。）
- **名前**（なまえ）名字；姓名｜韩语参考：이름（名字，名称）<br>
  例：ここに名前を書いてください。（请在这里写名字。）
- **仕事**（しごと）工作；活儿｜韩语参考：일（事情，工作） / 일감（活儿，工作） / 직장（职业，职场，工作）<br>
  例：仕事が忙しいです。（工作很忙。）
- **会社員**（かいしゃいん）公司职员｜韩语参考：회사원（公司职员，公司员工）<br>
  例：彼は会社員です。（他是公司职员。）
- **医者**（いしゃ）医生｜韩语参考：의사（医生）<br>
  例：医者になりたいです。（想当医生。）
- **電話**（でんわ）电话｜韩语参考：전화（电话） / 전화기（电话机）<br>
  例：友達に電話します。（给朋友打电话。）
- **旅行**（りょこう）旅行｜韩语参考：여행（旅行，旅游，游行）<br>
  例：家族と旅行します。（和家人旅行。）
- **ホテル**（ホテル）宾馆；酒店｜韩语参考：호텔（酒店，饭店，宾馆）<br>
  例：ホテルに泊まります。（住宾馆。）
- **頭**（あたま）头；脑袋｜韩语参考：골치（脑袋） / 골통（脑袋） / 머리（头）<br>
  例：頭が痛いです。（头疼。）
- **薬**（くすり）药｜韩语参考：약（药）<br>
  例：薬を飲みます。（吃药。）
- **雨**（あめ）雨｜韩语参考：비（雨）<br>
  例：雨が降っています。（正在下雨。）
- **天気**（てんき）天气｜韩语参考：날씨（天气） / 일기（天气） / 천기（天气；气象）<br>
  例：今日はいい天気です。（今天天气好。）
- **猫**（ねこ）猫｜韩语参考：고양이（猫）<br>
  例：部屋に猫がいます。（房间里有猫。）

## 语法

- **で（动作场所／手段／材料／原因）**：在…／用…／因为…
  接续：名詞 + で
  朝鲜语：에서 / (으)로（韩语动作场所用에서，手段材料用(으)로；日语で一形统合，学习者易混。）
- **へ（移动方向）**：往／向…
  接续：名詞 + へ + 移動動詞
  朝鲜语：(으)로（韩语方向用(으)로，常可与에互换；日语へ读e、只表方向不含到达点。）

## 汉字 5

- **上** 上；上面｜音：ジョウ、ショウ｜训：うえ、あ、のぼ
- **下** 下；下面｜音：カ、ゲ｜训：した、さ、お
- **中** 中；里面；中国｜音：チュウ｜训：なか
- **前** 前；前面；之前｜音：ゼン｜训：まえ
- **後** 后；后面；之后｜音：ゴ、コウ｜训：あと、うし、のち
