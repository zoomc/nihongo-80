今日语法 4 条

〜て（reason）
발음〜테
因为…（造成某种状态）
动词て形／い形容词去い+くて／な形容词・名词+で
用て形连接原因与结果，后项多为感情、状态或不能控制的结果。
韩语对应-아서/어서
韩语 -아서/어서 与 て 的原因用法对应，但日语 て 形还可表并列、先后，功能更多；韩语需靠上下文或另加连接词。
뉴우스 오 키이테, 비꾸리시마시타.
ニュースを聞いて、びっくりしました。
听到那个消息，我吓了一跳。
코노스푸 와 네쓰쿠테, 노메마센.
このスープは熱くて、飲めません。
这汤太烫了，喝不了。
카제 데 가꼬우 오 야스미마시타.
かぜで学校を休みました。
因为感冒，我请假没去学校。

易错点 このスープは熱いで、飲めません。 → このスープは熱くて、飲めません。（い形容词用「くて」，不是「いで」）

〜し
발음〜시
既…又…；而且…
动词普通形／い形容词 + し；な形容词・名词 + だ + し
列举两个以上理由或特征，暗示还有其他，后项多为综合判断。
韩语对应-고
韩语 -고 可并列理由，但语气中性；日语 し 暗示「还有别的理由」，主观色彩更强，韩语常需加 -기도 하고 才接近。
코노헤야 와 히로이시, 에키 카라 치카이시, 토테모키니이떼이마스.
この部屋は広いし、駅から近いし、とても気に入っています。
这个房间又宽敞，离车站又近，我很喜欢。
쿄우 와 아메다시, 쓰카레테이루시, 도코 니 모 이키타쿠나이.
今日は雨だし、疲れているし、どこにも行きたくない。
今天又下雨，人又累，哪儿都不想去。
모우오소이시, 소로소로카에로우 카.
もう遅いし、そろそろ帰ろうか。
时间也不早了，我们差不多回去吧。

易错点 この部屋は広いだし、駅から近いだし、とても気に入っています。 → この部屋は広いし、駅から近いし、とても気に入っています。（い形容词直接接 し，不加 だ）

〜けど / 〜けれども
발음〜케도 / 〜케레도모
但是…；虽然…
句子普通形 + けど／けれども（礼貌体可直接接）
表示转折，或用来缓和语气、引出请求与铺垫。
韩语对应-지만
韩语 -지만 与 けど 对应，但日语 けど 还可放在句末缓和语气、引出下文；韩语 -지만 一般不能这样独立使用。
코노미세 와 타카이케도, 오이시이.
この店は高いけど、おいしい。
这家店贵，但很好吃。
스미마센, 에키 니 이키타인데스케도, 도우이케바이이데스 카.
すみません、駅に行きたいんですけど、どう行けばいいですか。
不好意思，我想去车站，请问怎么走？
何度も電話したけれども、誰も出なかった。
我打了好几次电话，但没人接。

易错点 この店は高いだけど、おいしい。 → この店は高いけど、おいしい。（い形容词接 けど 不加 だ）

〜ために
발음〜타메니
为了…；因为…
动词辞书形／动词た形 + ために；名词 + の + ために
前接意志动词表目的，前接名词或过去形表原因，后者较书面。
韩语对应-기 위해(서) / 때문에
韩语 -기 위해(서) 表目的，때문에 表原因，两者形式不同；日语 ために 一个形式兼表目的与原因，需靠前接成分判断。
日本の大学に入るために、毎日勉強しています。
为了考进日本的大学，我每天学习。
家族のために、一生懸命働いている。
我为了家人拼命工作。
오오유키 노 타메 니, 덴샤 가 토마리마시타.
大雪のために、電車が止まりました。
因为大雪，电车停运了。

易错点 大雪のためで、電車が止まりました。 → 大雪のために、電車が止まりました。（名词接 ために 用「の」，不是「で」）
