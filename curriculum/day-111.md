# Day 111 · 〜とか（hearsay）、〜って

- 阶段：P4｜60 分钟｜听力日
- Can-do：用「〜とか（hearsay）、〜って」各造一句自己的话，表达：听说…；好像说…；说是…；所谓…

## 新词 22

- **つまり**（つまり）也就是说｜韩语参考：곧（也就是，换言之） / 즉（也就是）<br>
  例：つまり彼女は下手な踊り子だ。（也就是说，她是个蹩脚的舞者。）
- **罪**（つみ）罪；过错｜韩语参考：죄（罪，罪孽）<br>
  例：ビルはその罪を犯していなかった。（比尔没有犯那项罪。）
- **詰める**（つめる）塞；改短｜韩语参考：놓다（填充，塞，装）<br>
  例：このブラウスをつめていただけますか。（这件衬衫能帮我改小一点吗？）
- **積もる**（つもる）积；堆积｜韩语参考：쌓이다（堆，叠放，堆积）<br>
  例：雪はあたり一面に積もっていた。（雪积得满地都是。）
- **梅雨**（つゆ）梅雨｜韩语参考：장마（梅雨）<br>
  例：天気予報によれば、まもなく梅雨に入るそうだ。（据天气预报，马上就要入梅了。）
- **辛い**（つらい）难受；痛苦｜韩语参考：괴롭다（痛苦，难过） / 아프다（难受，难过） / 쓰라리다（痛苦）<br>
  例：流産はとても辛い経験です。（流产是非常痛苦的经历。）
- **釣り**（つり）钓鱼｜韩语参考：낚시<br>
  例：あなたは釣りに行きたがっている。（你很想去钓鱼。）
- **連れ**（つれ）同伴；同行者（〜連れ＝带着…同行）｜韩语参考：동행 / 데리고 감<br>
  例：駅までお連れいたしましょう。（我送您到车站吧。）
- **で**（で）出；出自｜韩语参考：나옴 / 출신<br>
  例：そこは風景が美しいことで有名だ。（那里以风景优美而闻名。）
- **出会い**（であい）相遇；邂逅｜韩语参考：만남<br>
  例：私たちの出会いはまったくの偶然でした。（我们的相遇完全是偶然。）
- **出会う**（であう）遇见；邂逅｜韩语参考：만나다（遇到，遇见，碰见） / 마주치다（邂逅，偶遇）<br>
  例：きのう旧友の一人に出会った。（昨天遇见了一位老朋友。）
- **提案**（ていあん）提议；建议｜韩语参考：제안（提案，提议）<br>
  例：私の提案を承認していただけますか。（能批准我的提案吗？）
- **定期**（ていき）定期｜韩语参考：정기（定期） / 정기권（定期票，月票，季票） / 정기 예금（定期存款）<br>
  例：彼らは定期旅客船に乗り込んだ。（他们登上了定期客轮。）
- **抵抗**（ていこう）抵抗；阻力｜韩语参考：저항（抵抗）<br>
  例：困難に対してあくまでも抵抗した。（面对困难始终抵抗到底。）
- **程度**（ていど）程度｜韩语参考：정도（程度）<br>
  例：この程度のお金じゃ長くは持たないだろう。（这点钱撑不了多久吧。）
- **停留所**（ていりゅうじょ）车站；站点｜韩语参考：정거장（车站） / 정류소（车站） / 정류장（车站）<br>
  例：バスの停留所まで競争しよう。（我们比赛跑到公交站吧。）
- **デート**（デート）约会｜韩语参考：데이트（约会）<br>
  例：アンディはけっしてデートにおくれたことはない。（安迪约会从不迟到。）
- **敵**（てき）敌人；对手｜韩语参考：적（敌，敌人）<br>
  例：彼は敵に不意打ちを食わせた。（他偷袭了对手。）
- **出来事**（できごと）事件；事情｜韩语参考：사건 / 일<br>
  例：このようのしてその出来事は起こった。（那件事就是这样发生的。）
- **適する**（てきする）适合｜韩语参考：적합하다<br>
  例：その肉は全く食用に適さなかった。（那些肉完全不适合食用。）
- **適切**（てきせつ）恰当；合适｜韩语参考：적절하다<br>
  例：「行った」というのが適切な言葉だ。（「去了」才是恰当的词。）
- **適度**（てきど）适度｜韩语参考：적당한 정도<br>
  例：適度の運動は体に良い。（适度的运动对身体有好处。）

## 语法

- **〜とか（hearsay）**：听说…；好像说…
  接续：普通形 + とか（句末，或用「とかで」表原因）
  朝鲜语：-다고 하던데（韩语「-다고 하던데」带“听说…”的转述感；日语「とか」还可单纯列举，需靠位置和语调区分。）
- **〜って**：说是…；所谓…
  接续：普通形 + って；名词 + って（表话题）
  朝鲜语：-대（韩语「-대」是口语转述缩略，与「って」很像；但日语「って」还能当话题助词（「〜って何？」），韩语要用「-는」。）
