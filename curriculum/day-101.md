# Day 101 · 〜ようとする、〜そうにない / 〜そうもない

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜ようとする、〜そうにない / 〜そうもない」造两句自己的话，表达：想要…；正要…；看样子不会…；不像会…

## 新词 14

- **教授**（きょうじゅ）教授｜韩语参考：교수（教授，教学，讲授） / 정교수（正教授）<br>
  例：一人の教授がささやいた。（一位教授低声说。）
- **強調**（きょうちょう）强调｜韩语参考：강조（强调）<br>
  例：先生は毎日の練習の大切さを強調した。（老师强调了每天练习的重要性。）
- **共通**（きょうつう）共同；共通｜韩语参考：공통（共通，共同）<br>
  例：私と彼は共通することが多い。（我和他有很多共同点。）
- **共同**（きょうどう）共同｜韩语参考：공동（共同，联合） / 합동（共同，联合）<br>
  例：私は妹と共同で部屋を使っている。（我和妹妹合用一间房。）
- **恐怖**（きょうふ）恐惧｜韩语参考：두려움（恐惧，畏惧） / 무서움（害怕，恐惧）<br>
  例：私は恐怖で気も狂わんばかりだった。（我吓得几乎要发疯。）
- **協力**（きょうりょく）合作｜韩语参考：협력（协力，协作，合作）<br>
  例：彼らは協力してその絵を仕上げた。（他们合作完成了那幅画。）
- **強力**（きょうりょく）强大；强力｜韩语参考：강력（强力）<br>
  例：日本の軍隊は非常に強力だった。（日本军队当时非常强大。）
- **局**（きょく）局；台｜韩语参考：판（盘，局）<br>
  例：この地区では三局受信できます。（这个地区能收到三个台。）
- **巨大**（きょだい）巨大｜韩语参考：거대（巨大，庞大）<br>
  例：巨大なタンカーがついに今し方出港した。（巨型油轮刚刚终于出港了。）
- **嫌う**（きらう）讨厌｜韩语参考：밉보다（讨厌，不喜欢） / 싫어하다（讨厌，不愿意）<br>
  例：彼女は人前で話をするのを嫌う。（她讨厌在人前讲话。）
- **霧**（きり）雾｜韩语参考：안개（雾，雾气）<br>
  例：濃い霧のために私たちの飛行機は遅れた。（因为大雾，我们的飞机延误了。）
- **切れ**（きれ）片；块｜韩语参考：점（块） / 도막（段，根，块） / 조각（片）<br>
  例：肉は何切れにしましょうか。（肉切成几片呢？）
- **切れる**（きれる）断；用完｜韩语参考：되다（用完，没有） / 끊기다（断，绝） / 끊어지다（断，被切断）<br>
  例：ガソリンが切れかかっている。（汽油快用完了。）
- **記録**（きろく）记录｜韩语参考：기록（记录） / 기재（记录，记载，填写）<br>
  例：無言が記録されたためしはない。（还从没有过沉默被记录下来的先例。）

## 语法

- **〜ようとする**：想要…；正要…
  接续：动词意志形 + とする（否定形：ようとしない）
  朝鲜语：-려고 하다（韩语「-려고 하다」也表意图，但“正要…的瞬间”日语说「ようとしたとき」，韩语多用「-려던 참에」，形式不同。）
- **〜そうにない / 〜そうもない**：看样子不会…；不像会…
  接续：动词ます形词干 + そうにない／そうもない
  朝鲜语：-ㄹ 것 같지 않다（韩语没有专门对应，常说「-ㄹ 것 같지 않다」；日语「そうにない」依据眼前迹象，主观判断色彩更强。）

- **助** 帮助；救助｜音：ジョ｜训：たす.ける、たす.かる、す.ける、すけ
