## 新词 25

- **切れる**（きれる）断；用完｜韩语参考：되다（用完，没有） / 끊기다（断，绝） / 끊어지다（断，被切断）<br>
  例：ガソリンが切れかかっている。（汽油快用完了。）
- **記録**（きろく）记录｜韩语参考：기록（记录） / 기재（记录，记载，填写）<br>
  例：無言が記録されたためしはない。（还从没有过沉默被记录下来的先例。）
- **議論**（ぎろん）讨论；争论｜韩语参考：의논（商议，讨论，商量）<br>
  例：彼らは議論をやめることに決めた。（他们决定停止争论。）
- **金銭**（きんせん）金钱｜韩语参考：금전（金钱，钱） / 돈（钱，金钱，钱币）<br>
  例：金銭のことで彼と争いになった。（因为钱的事跟他起了争执。）
- **金属**（きんぞく）金属｜韩语参考：금속（金属） / 쇠（金属）<br>
  例：鉄は最も有用な金属です。（铁是最有用的金属。）
- **近代**（きんだい）近代｜韩语参考：근대（近代）<br>
  例：近代医学の進歩は長い道程を歩んだ。（近代医学的进步走过了漫长的历程。）
- **緊張**（きんちょう）紧张｜韩语参考：긴장（紧张）<br>
  例：冷戦の緊張が高まった。（冷战紧张局势加剧了。）
- **筋肉**（きんにく）肌肉｜韩语参考：근육（肌肉）<br>
  例：水泳は筋肉を発達させる。（游泳能使肌肉发达。）
- **金融**（きんゆう）金融｜韩语参考：금융（金融）<br>
  例：工業よりも金融に関心のある学生のほうが多い。（关心金融的学生比关心工业的还多。）
- **金曜**（きんよう）星期五｜韩语参考：금요일<br>
  例：彼は月曜から金曜まで働く。（他从周一到周五工作。）
- **句**（く）句；俳句｜韩语参考：구（句）<br>
  例：彼はその句の文字どおりの意味を説明した。（他解释了那句话的字面意思。）
- **食う**（くう）吃｜韩语参考：먹다（吃）<br>
  例：この事業は金を食う。（这项事业很费钱。）
- **偶然**（ぐうぜん）偶然｜韩语参考：우연（偶然） / 우연히（偶然地）<br>
  例：私は道で古い友人と偶然出会った。（我在路上偶然遇到了老朋友。）
- **臭い**（くさい）臭｜韩语参考：구리다（臭，难闻） / 쿠리다（臭，难闻） / 고리타분하다（臭，腐臭）<br>
  例：あいつが臭い。（那家伙身上有股味儿。）
- **鎖**（くさり）锁链｜韩语参考：사슬 / 쇠사슬<br>
  例：ジョージはその犬に鎖をつけた。（乔治给那条狗拴上了链子。）
- **腐る**（くさる）腐烂｜韩语参考：곯다（坏，腐烂） / 썩다（腐败，腐烂） / 상하다（损坏，腐烂，变质）<br>
  例：これらのオレンジは腐っている。（这些橙子烂了。）
- **癖**（くせ）习惯；癖好｜韩语参考：버릇（习惯，习性）<br>
  例：その子は悪い癖が直った。（那孩子改掉了坏习惯。）
- **管**（くだ）管子｜韩语参考：대롱（管子，竹管，竹筒）<br>
  例：この管の中を水が流れます。（水从这根管子里流过。）
- **具体**（ぐたい）具体｜韩语参考：구체적<br>
  例：計画を具体的に説明してください。（请具体说明计划。）
- **組合**（くみあい）工会；组合｜韩语参考：조합（组合）<br>
  例：組合はデモに参加しましたか。（工会参加游行了吗？）
- **組む**（くむ）组合；交叉｜韩语参考：짜다 / 엮다 / 꼬다<br>
  例：私は彼らが腕を組んで歩いているのを見た。（我看见他们挽着手臂走路。）
- **位**（くらい）位；左右｜韩语参考：자리（位） / 언저리（左右）<br>
  例：５８１４を千の位に四捨五入すれば何になりますか。（5814四舍五入到千位是多少？）
- **暮らし**（くらし）生活｜韩语参考：삶（生活） / 살림（生活，日子，持家） / 살림살이（生活，过日子，持家）<br>
  例：もっと良い暮らしができますように。（希望能过上更好的生活。）
- **クラシック**（クラシック）古典乐｜韩语参考：클래식 음악<br>
  例：クラシックはありません。（没有古典乐。）
- **暮らす**（くらす）生活；度日｜韩语参考：살다（生活，过活，过日子） / 지내다（度日，生活） / 생활하다（生活，居住）<br>
  例：彼女が一人で暮らすのはよくない。（她一个人生活不太好。）

## 语法

- **〜ようとする**：想要…；正要…
  接续：动词意志形 + とする（否定形：ようとしない）
  朝鲜语：-려고 하다（韩语「-려고 하다」也表意图，但“正要…的瞬间”日语说「ようとしたとき」，韩语多用「-려던 참에」，形式不同。）
- **〜そうにない / 〜そうもない**：看样子不会…；不像会…
  接续：动词ます形词干 + そうにない／そうもない
  朝鲜语：-ㄹ 것 같지 않다（韩语没有专门对应，常说「-ㄹ 것 같지 않다」；日语「そうにない」依据眼前迹象，主观判断色彩更强。）
- **〜一方だ**：一直…；越来越…
  接续：动词辞书形 + 一方だ
  朝鲜语：-기만 한다（韩语「-기만 한다」偏“只做某事”；日语「一方だ」专指程度单向加剧，常带忧虑，韩语更常说「계속 -고 있다」。）
