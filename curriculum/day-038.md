# Day 038 · 普通形 + か どうか、普通形 + んです / のだ、N に Vて ほしい / Vないで ほしい

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「普通形 + か どうか、普通形 + んです / のだ、N に Vて ほしい / Vないで ほしい」各造一句自己的话，表达：是否…；…还是不…；（是）因为…；其实是…（说明/强调语气）；希望（别人）做…／希望别…

## 新词 19

- **親**（おや）父母｜韩语参考：부모（父母） / 어버이（父母）<br>
  例：私たちは親をあてにしてはいけない。（我们不能依赖父母。）
- **泳ぎ方**（およぎかた）游法｜韩语参考：수영하는 방법<br>
  例：君に泳ぎ方を教えよう。（我来教你游泳的方法。）
- **下りる**（おりる）下来；下车｜韩语参考：나오다（下来，出来） / 내려서다（下，下来） / 내려오다（下来）<br>
  例：一行は、歩いてその山を下りた。（一行人步行下了那座山。）
- **折る**（おる）折断；折叠｜韩语参考：꺾다（折，折断） / 포개다（叠，折叠） / 분지르다（折断，掰断）<br>
  例：その紙を四つ折りにしなさい。（把那张纸折成四折。）
- **お礼**（おれい）道谢｜韩语参考：감사 / 사례<br>
  例：息子に成り代わってお礼を申し上げます。（我代表儿子向您道谢。）
- **折れる**（おれる）断；折｜韩语参考：부러지다（折，折断）<br>
  例：医者は彼の折れた足をついだ。（医生给他接好了断腿。）
- **終わり**（おわり）结束｜韩语参考：종말（结局，结束，下场）<br>
  例：さぁ、一日を終わりとしましょう。（好了，今天就到此结束吧。）
- **カーテン**（カーテン）窗帘｜韩语参考：커튼（窗帘）<br>
  例：カーテンが風になびいた。（窗帘随风飘动。）
- **海岸**（かいがん）海岸｜韩语参考：해안（海岸，海边） / 해변가（海岸，海滨，海边） / 해안가（海岸，海边）<br>
  例：このバスは、海岸に行きますか。（这趟公交去海岸吗？）
- **会議室**（かいぎしつ）会议室｜韩语参考：회의실（会议室）<br>
  例：クラブの会員は会議室に集まった。（俱乐部成员在会议室集合了。）
- **会場**（かいじょう）会场｜韩语参考：회장（会场） / 대회장（大会场）<br>
  例：私たちは会場の後ろに座った。（我们坐在会场后面。）
- **会話**（かいわ）会话｜韩语参考：회화（会话）<br>
  例：その作家は会話を書くのがうまい。（那位作家很会写对话。）
- **帰り**（かえり）归途；回程｜韩语参考：돌아오는 길<br>
  例：どうして帰りがこんなに遅くなったの。（怎么回来得这么晚？）
- **科学**（かがく）科学｜韩语参考：과학（科学）<br>
  例：私は、ずっと科学を習っている。（我一直在学科学。）
- **鏡**（かがみ）镜子｜韩语参考：거울（镜子）<br>
  例：少女は立って鏡をのぞきこんだ。（少女站着照镜子。）
- **飾る**（かざる）装饰｜韩语参考：꾸미다（装饰，装扮） / 수식하다（修饰，装饰） / 장식하다（装饰，装扮，点缀）<br>
  例：その広間は日本画で飾られていた。（那个大厅用日本画装饰着。）
- **火事**（かじ）火灾｜韩语参考：불（火灾）<br>
  例：その火事はおととい発生した。（那场火灾发生在前天。）
- **ガス**（ガス）煤气；气体｜韩语参考：가스（气，气体）<br>
  例：料理の後でガスを止めました。（做完饭后关了煤气。）
- **ガソリン**（ガソリン）汽油｜韩语参考：가솔린（汽油） / 휘발유（汽油）<br>
  例：この車はあまりガソリンを食わない。（这辆车不太费油。）

## 语法

- **普通形 + か どうか**：是否…；…还是不…
  接续：動詞/い形 普通形 + かどうか；名詞・な形 词干 + かどうか（不加 だ/な）；疑问词问句不用 かどうか
  朝鲜语：-는지 / -(으)ㄴ지（韩语嵌入疑问用는지，按词性变인지；日语かどうか固定，且不能直接接名词。）
- **普通形 + んです / のだ**：（是）因为…；其实是…（说明/强调语气）
  接续：動詞・い形 普通形 + んです；な形・名詞 + な + んです；礼貌体 んです，简体 のだ／んだ
  朝鲜语：-거든요 / -는데요 / -잖아요（韩语说明语气由거든요、는데요、잖아요等分担；日语んです一形统合，须按语境选择。）
- **N に Vて ほしい / Vないで ほしい**：希望（别人）做…／希望别…
  接续：動詞 て形 + ほしい；否定 ない形 + で + ほしい；动作主体用 に（或 が）
  朝鲜语：-아/어 주기를 바라다（韩语希望别人做用주기를 바라다，对长辈须加시；日语てほしい不宜直接对长辈说。）
