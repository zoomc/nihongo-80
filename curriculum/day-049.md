## 3. 新语法（含先修）
- `G0093` **N / 普通形 + ばかりか** — 不仅…而且…｜接续：名詞 + ばかりか；動詞・い形 普通形 + ばかりか；な形・名詞 + な/である + ばかりか
- `G0080` **N(＋助詞) + さえ／こそ／すら；V ば形 前 + さえ…ば** — 甚至…／只要…就／正是…／连…都｜接续：さえ/すら 取代 が・を 或接在助词后（にさえ／でさえ）；さえ…ば 用 条件形(ば)；こそ 强调主语/原因（〜からこそ）

## 4. 新汉字（中日差异）
- `K0134` **味** 音:ミ 训:あじ｜中文「味」wèi；日语 味 音读 ミ（意味 いみ）、训读 あじ（味道）；「意味」是「意思」，与「味道」无关，中文易按「味」猜成「滋味」，典型陷阱，不能靠汉字猜。
- `K0108` **議** 音:ギ 训:｜中文「议」yì；日语 議 音读 ギ，「会議」かいぎ「議論」ぎろん；简体「议」与「議」字形不同，须按 ギ 验证，此字无常用训读。
