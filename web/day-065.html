Day 065 · 〜一方で、〜に対して、〜について

语法 3 条

〜一方で
발음〜이뽀우데
一方面…；同时…
普通形 + 一方で；ナ形容词 + な + 一方で；名词 + である + 一方で
并列同一事物的两个侧面，或表两件事同时进行。
韩语对应-는 반면에
韩语「-는 반면에」只表对比；日语「一方で」还能表“同时进行的两件事”，范围更宽。
インターネットは便利な一方で、危険な面もある。
互联网很方便，另一方面也有危险的一面。
코노카이샤 와 큐우료우 가 타카이이뽀우 데, 야스미 가 토테모스쿠나이.
この会社は給料が高い一方で、休みがとても少ない。
这家公司工资高，但休假很少。
카노조 와 카이샤 데 하타라쿠이뽀우 데, 요루 와 다이가쿠인 니 카요떼이루.
彼女は会社で働く一方で、夜は大学院に通っている。
她一边在公司上班，晚上一边读研究生。
易错易混点
  • ✗ インターネットは便利だ一方で、危険な面もある。✓ 便利な一方でな形容词接 一方で 用 な：便利な一方で。
〜に対して
발음〜니타이시테
对…；与…相对
名词 + に対して（针对、相对）；对比两个判断时，动词、い形普通形 + のに対して，な形 + なのに対して，名词 + なのに対して／であるのに対して。
表动作或态度的对象，也用于前后对比。
韩语对应…에게 / …에 대해 / 반면에
人に対して失礼だ 可对应 사람에게 무례하다。要对比前后情况时，用 のに対して，对照 -는 반면에。
오캬쿠사마 니타이시테, 손나이이카타 오 시테 와 이케나이.
お客様に対して、そんな言い方をしてはいけない。
对客人不能那么说话。
아타라시이제이킨 니타이스루 한타이 노 코에 가 타카마떼이루.
新しい税金に対する反対の声が高まっている。
反对新税的声音越来越大。
토우쿄우 와 하레테이루노 니타이시테, 오오사카 와 아사 카라 오오아메다.
東京は晴れているのに対して、大阪は朝から大雨だ。
东京是晴天，而大阪从早上就下大雨。
易错易混点
  • ✗ 東京は晴れているに対して、大阪は朝から大雨だ。✓ 晴れているのに対して动词小句后接对比的 に対して，要用 のに対して。
〜について
발음〜니쓰이테
关于…
名词 + について；名词 + についての + 名词
指出谈话、思考或调查的主题。
韩语对应-에 대해서
회의에 대해 이야기하다 对照 会議について話す；회의에 관한 자료 对照 会議についての資料。修饰日语名词时，について 后要接 の。
今日の授業では、日本の食文化について話し合いました。
今天的课上我们讨论了日本饮食文化。
아타라시이쇼우힌 니쓰이테 노 시쓰몬 와, 코치라 노 메이루아도레스 마데 오오쿠리쿠다사이.
新しい商品についての質問は、こちらのメールアドレスまでお送りください。
关于新产品的疑问请发到这个邮箱。
소노지켄 니쓰이테, 케이사쓰 와 마다나니모 하뾰우시테이나이.
その事件について、警察はまだ何も発表していない。
关于那起事件，警方还没有任何发布。
易错易混点
  • ✗ 今日の授業では、日本の食文化をについて話し合いました。✓ 食文化についてについて 本身已含助词作用，不能再叠 を。
