# Day 035 · ～から / ～ので（原因）、条件形 使い分け（たら／ば／なら／と）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～から / ～ので（原因）、条件形 使い分け（たら／ば／なら／と）」造两句自己的话，表达：因为…所以…；如果／要是／一…就（四条件辨析）

## 新词 19

- **やる**（やる）做；给｜韩语参考：하다 / 주다<br>
  例：５ドルをやる。（给你五美元。）
- **夕方**（ゆうがた）傍晚｜韩语参考：저녁（傍晚） / 저녁때（傍晚） / 저녁나절（晚上，傍晚）<br>
  例：ひょっとすると夕方前に雨になるかもしれない。（说不定傍晚前会下雨。）
- **夕飯**（ゆうはん）晚饭｜韩语参考：저녁（晚饭，晚餐） / 저녁밥（晚饭，晚餐）<br>
  例：夕飯はもう食べましたか。（晚饭吃过了吗？）
- **郵便局**（ゆうびんきょく）邮局｜韩语参考：우체국（邮局）<br>
  例：あの～郵便局はどちらでしょうか。（那个……邮局在哪儿呢？）
- **昨夜**（ゆうべ）昨晚｜韩语参考：어젯밤<br>
  例：昨夜はよく眠れましたか。（昨晚睡得好吗？）
- **有名**（ゆうめい）有名；著名｜韩语参考：유명（有名，知名，著名）<br>
  例：そのホテルは食事で有名である。（那家酒店以餐饮闻名。）
- **雪**（ゆき）雪｜韩语参考：눈（雪）<br>
  例：ひどい雪のため外出できなかった。（因为大雪，没能出门。）
- **ゆっくりと**（ゆっくりと）慢慢地｜韩语参考：천천히<br>
  例：おじいさんはとてもゆっくりと話す。（爷爷说话很慢。）
- **八日**（ようか）八天；八号｜韩语参考：여드레（八天）<br>
  例：学校は４月８日から始まります。（学校四月八号开学。）
- **洋服**（ようふく）西服；洋装｜韩语参考：양복 / 서양식 옷<br>
  例：お前に新しい洋服を作ってあげよう。（我给你做身新衣服吧。）
- **よく**（よく）经常；好好地｜韩语参考：잘（经常）<br>
  例：ジャック、よく来てくれたね。（杰克，你能来太好了。）
- **横**（よこ）旁边；横向｜韩语参考：옆（旁，旁边） / 옆쪽（旁边）<br>
  例：母親は赤ん坊をベッドに横にした。（母亲把婴儿放倒在床上。）
- **四日**（よっか）四天；四号｜韩语参考：나흘（四天）<br>
  例：長くても４日しか待てませんよ。（最多只能等四天。）
- **四つ**（よっつ）四个｜韩语参考：네 개<br>
  例：その紙を四つ折りにしなさい。（把那张纸折成四折。）
- **呼ぶ**（よぶ）叫；邀请｜韩语参考：부르다（叫） / 초대하다（邀请，招待）<br>
  例：あなたをケパと呼ぶことにします。（我们就叫你凯法吧。）
- **より**（より）比；与…相比｜韩语参考：보다（比）<br>
  例：もうこれよりほかに手はない。（除此之外已经没有别的办法了。）
- **夜**（よる）夜晚｜韩语参考：야간（夜间，夜晚）<br>
  例：あなたは夜よく寝れませんか。（你晚上睡不好吗？）
- **弱い**（よわい）弱；薄弱｜韩语参考：약하다（弱，小）<br>
  例：それを言われると弱いなあ。（被这么一说我就没辙了。）
- **来月**（らいげつ）下个月｜韩语参考：내달（下月，下个月）<br>
  例：来月タクシー料金があがります。（下个月出租车费要涨。）

## 语法

- **～から / ～ので（原因）**：因为…所以…
  接续：普通形/丁寧形 + から；普通形 + ので（名/な形 + なので）
  朝鲜语：-아/어서 / -(으)니까（韩语아/어서后不接命令请求，니까可接；日语から可接命令，ので语气较柔。）
- **条件形 使い分け（たら／ば／なら／と）**：如果／要是／一…就（四条件辨析）
  接续：たら 既定/假定通用；ば 假定；なら 承接话题；と 自然/必然结果
  朝鲜语：-(으)면 / -다면 / -자마자（韩语条件主要靠면，假设用다면，一…就用자마자；无日语と/なら的意志限制。）
