## 新词 25

- **応じる**（おうじる）响应；根据｜韩语参考：응하다 / 따르다<br>
  例：彼は収入に応じた生活をしている。（他过着与收入相称的生活。）
- **横断**（おうだん）横穿；横渡｜韩语参考：횡단（横穿，横过，横渡）<br>
  例：彼はヨットで太平洋を横断した。（他乘帆船横渡了太平洋。）
- **終える**（おえる）结束；完成｜韩语参考：맺다（结尾，结束） / 끝내다（结束，完成） / 끝맺다（结束，完结）<br>
  例：その仕事をもう終えましたか。（那份工作已经做完了吗？）
- **大いに**（おおいに）大大地；非常｜韩语参考：크게 / 대단히<br>
  例：私は彼を大いに尊敬しています。（我非常尊敬他。）

- **オーバー**（オーバー）大衣；超过｜韩语参考：외투 / 초과<br>

- **大家**（おおや）房东｜韩语参考：주인집（房东，房东家） / 집주인（房主，房东）<br>

- **丘**（おか）小山；丘陵｜韩语参考：둔덕（坎，岗，堤，丘陵） / 언덕（坡，丘陵，山坡，山丘）<br>

- **鬼**（おに）鬼；妖怪｜韩语参考：도깨비 / 귀신<br>

- **お昼**（おひる）中午；午饭｜韩语参考：점심 / 정오<br>

- **オフィス**（オフィス）办公室｜韩语参考：사무실<br>
  例：いつでも私のオフィスを訪ねなさい。（随时来我办公室找我。）

  例：彼女は危うく溺れるところだった。（她差点淹死。）

  例：「おまえも来るか」と兄が聞いた。（哥哥问道：“你也来吗？”）

## 语法

- **Vた形 + ところで**：即使…也（不会有预期结果）
  接续：動詞た形 + ところで；后项多为否定或无意义的结果
  朝鲜语：-아/어도 / -더라도（-아/어도 或 -더라도 都可让步。日语 たところで 特别常说「做了也改变不了结果」，如 今さら聞いたところで、答えは変わらない。）
- **普通形 + ものだから / もので**：因为…（所以…）；由于…
  接续：动词、い形普通形 + ものだから／もので；名词、な形容词的非过去肯定用 な + ものだから／もので。
  朝鲜语：-는 바람에 / -기 때문에（为迟到解释「道が混んでいたもので」时，可译成 길이 막혀서요。もので 常用来委婉交代原因，ものだから 的解释、辩解感更明显。）
- **普通形 + からこそ**：正因为…才…
  接续：動詞・い形 普通形 + からこそ；な形・名詞 + だ + からこそ
  朝鲜语：바로 …이기 때문에 / …니까 가능한 것이다（「正因为是朋友，才能这么说」可说 바로 친구니까 이런 말을 할 수 있다。日语在因果的 から 后放 こそ，把原因凸显出来。）
