今日语法 3 条

ます形（丁寧体）
발음마스카타치
动词礼貌形：ます／ません／ました／ませんでした
動詞 + ます（う段→い段+ます；一段去る+ます）
礼貌体现在/否定/过去/过去否定；是て/た/ない形的基础
마이니치,가꼬우에이키마스.
毎日、学校へ行きます。
每天去学校。
고한오타베마스.
ご飯を食べます。
吃饭。
朝鲜语：-습니다/ㅂ니다 / -아·어요
韩语敬语分합쇼체与해요체，随听者选择；日语ます体一套即可，无此分层。
易错点

食べります。 → 食べます。（把一段动词「食べる」误当五段，加 り；一段去 る 直接 ます）

～が ほしい
발음～가 호시이
想要（某物）
名詞 + が + ほしい（です）
表说话人想要某物；对象用 が，不是 を；第三人称用 ほしがる
아타라시이파소콘가호시이데스.
新しいパソコンがほしいです。
想要新电脑。
朝鲜语：이/가 갖고 싶다 / 원하다
韩语갖고 싶다限第一人称，第三人称用갖고 싶어 하다；원하다偏书面。
易错点

パソコンを ほしいです。 → パソコンがほしいです。（「ほしい」对象格用 が；中文「想要(某物)」是动宾，直译成 を 错）

比较（より／ほうが／ほど）
比…／不如…
A は B より ～；A より B の ほうが ～；A は B ほど ～ない
比较句三式；「ほど＋否定」表「不如…那么」
덴샤요리바스노호우가야스이데스.
電車よりバスのほうが安いです。
公交比电车便宜。
쿄우와키노우호도사무쿠나이데스.
今日は昨日ほど寒くないです。
今天没昨天冷。
朝鲜语：A가 B보다 + 형용사
韩语可用 보다 表比较基准；「没昨天冷」可说 어제보다 춥지 않다，也可用 만큼 与否定表达。
易错点

電車はバスのほうが安いです。 → 電車よりバスのほうが安いです。（比较句式杂糅：用 ほうが 时基准用 より，不能 は…ほうが 并用）
