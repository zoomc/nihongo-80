③ 语法 6 分钟

N に Vて ほしい / Vないで ほしい
動詞 て形 + ほしい；否定 ない形 + で + ほしい；动作主体用 に（或 が）
希望（别人）做…／希望别…

对他人的愿望；不能用于自己（自己用 〜たい G0031）；也不直接对长辈说 てほしい（改用 G0073）

もう少し待ってほしいです。
希望（你）再等一下。
大きな声で話さないでほしいです。
希望别大声说话。
朝鲜语：-아/어 주기를 바라다
韩语希望别人做用주기를 바라다，对长辈须加시；日语てほしい不宜直接对长辈说。

易错：私は映画を見てほしいです。 → 映画が見たいです。（「我想看」应用 見たい；てほしい 是希望别人做，中文「想」不分主体易错）

名詞/な形词干 + みたい(だ/な/に)
名詞 + みたい（不加 の）；な形 词干 + みたい；動詞/い形 普通形 + みたい；みたいな＋名／みたいに＋動
好像…；像…一样（口语推量/比喻）

口语版 〜ようだ（G0044）；比 らしい/そう 更随意；比喻用 まるで…みたい

彼は元気じゃないみたいです。
他好像不太精神。
今日は春みたいに暖かいです。
今天暖和得像春天。
朝鲜语：-(으)ㄴ 것 같다 / -처럼
韩语比喻和推测都用같다，口语最常用；日语みたい是ようだ口语版，韩语无正式口语两套。

易错：彼は学生のみたいです。 → 彼は学生みたいです。（名词接 みたい 不加 の（ようだ 才要 の）；中文「像是学生」直译加 の 错）
