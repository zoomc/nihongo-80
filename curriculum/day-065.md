## 语法

- **〜一方で**：一方面…；同时…
  接续：普通形 + 一方で；ナ形容词 + な + 一方で；名词 + である + 一方で
  朝鲜语：-는 반면에（韩语「-는 반면에」只表对比；日语「一方で」还能表“同时进行的两件事”，范围更宽。）
- **〜に対して**：对…；与…相对
  接续：名词 + に対して（针对、相对）；对比两个判断时，动词、い形普通形 + のに対して，な形 + なのに対して，名词 + なのに対して／であるのに対して。
  朝鲜语：…에게 / …에 대해 / 반면에（人に対して失礼だ 可对应 사람에게 무례하다。要对比前后情况时，用 のに対して，对照 -는 반면에。）
- **〜について**：关于…
  接续：名词 + について；名词 + についての + 名词
  朝鲜语：-에 대해서（회의에 대해 이야기하다 对照 会議について話す；회의에 관한 자료 对照 会議についての資料。修饰日语名词时，について 后要接 の。）
