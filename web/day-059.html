今日语法 3 条

〜かもしれない
발음〜카모시레나이
也许…；可能…
动词普通形／い形容词／な形容词／名词 + かもしれない
表示不确定的推测，可能性低于だろう。
고고카라아메가후루카모시레마센.
午後から雨が降るかもしれません。
下午可能会下雨。
카기가나이.덴샤노나카데오토시타카모시레나이.
かぎがない。電車の中で落としたかもしれない。
钥匙不见了，可能掉在电车上了。
소노하나시와혼토우카모시레나이.
その話は本当かもしれない。
那个说法可能是真的。
朝鲜语：-(으)ㄹ지도 모르다
韩语 -(으)ㄹ지도 모르다 与 かもしれない 对应，但韩语字面含「不知道」，语气更不确定；日语 かもしれない 可直接表推测。
易错点

午後から雨が降るかもません。 → 午後から雨が降るかもしれません。（かもしれない 的礼貌形是「かもしれません」）

〜だろう
발음〜다로우
大概…吧
动词普通形／い形容词／な形容词／名词 + だろう
表示说话人的推测，把握较大，口语常用。
아시타와타분하레루다로우.
明日はたぶん晴れるだろう。
明天大概会晴吧。
카노조와모우이에니쓰이타다로우.
彼女はもう家に着いただろう。
她大概已经到家了吧。
코노몬다이와코도모니와무즈카시이다로우토오모이마스.
この問題は子どもには難しいだろうと思います。
我觉得这个问题对孩子来说大概太难了。
朝鲜语：-(으)ㄹ 것이다 / -겠다
韩语 -(으)ㄹ 것이다 与 だろう 对应，-겠다 更偏主观意志或推测；日语 だろう 只表推测，不表意志。
易错点

明日はたぶん晴れるでしょうだ。 → 明日はたぶん晴れるでしょう。（でしょう 已是礼貌断定，不能再加 だ）

〜んです / 〜のです
발음〜ㄴ데스 / 〜노데스
（解释）是…的；因为…
动词普通形／い形容词 + んです；な形容词+な／名词+な + んです
用于说明原因、补充背景，或向对方寻求解释，口语色彩强。
どうしたんですか。顔色が悪いですよ。
怎么了？你脸色不太好。
스미마센,오쿠레마시타.덴샤가토마떼이탄데스.
すみません、遅れました。電車が止まっていたんです。
对不起我迟到了，因为电车停运了。
니혼고데테가미오카키타인데스가,테쓰다떼쿠레마센카.
日本語で手紙を書きたいんですが、手伝ってくれませんか。
我想用日语写封信，你能帮我吗？
朝鲜语：-ㄴ/는 것이다 / -거든요
韩语 -거든요 与 んです 的解释语气接近，但日语 んです 还可用于提问求解释；韩语 거든요 只用于陈述。
易错点

電車が止まっていたのだです。 → 電車が止まっていたんです。（のだ 接礼貌体是「のです」，不能作「のだです」）
