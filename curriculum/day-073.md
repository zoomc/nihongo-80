## 新词 25

- **句**（く）句；俳句｜韩语参考：구（句）<br>
  例：彼はその句の文字どおりの意味を説明した。（他解释了那句话的字面意思。）
- **食う**（くう）吃｜韩语参考：먹다（吃）<br>
  例：この事業は金を食う。（这项事业很费钱。）
- **偶然**（ぐうぜん）偶然｜韩语参考：우연（偶然） / 우연히（偶然地）<br>
  例：私は道で古い友人と偶然出会った。（我在路上偶然遇到了老朋友。）
- **臭い**（くさい）臭｜韩语参考：구리다（臭，难闻） / 쿠리다（臭，难闻） / 고리타분하다（臭，腐臭）<br>
  例：あいつが臭い。（那家伙身上有股味儿。）
- **鎖**（くさり）锁链｜韩语参考：사슬 / 쇠사슬<br>
  例：ジョージはその犬に鎖をつけた。（乔治给那条狗拴上了链子。）
- **腐る**（くさる）腐烂｜韩语参考：곯다（坏，腐烂） / 썩다（腐败，腐烂） / 상하다（损坏，腐烂，变质）<br>
  例：これらのオレンジは腐っている。（这些橙子烂了。）
- **癖**（くせ）习惯；癖好｜韩语参考：버릇（习惯，习性）<br>
  例：その子は悪い癖が直った。（那孩子改掉了坏习惯。）
- **管**（くだ）管子｜韩语参考：대롱（管子，竹管，竹筒）<br>
  例：この管の中を水が流れます。（水从这根管子里流过。）
- **具体**（ぐたい）具体｜韩语参考：구체적<br>
  例：計画を具体的に説明してください。（请具体说明计划。）
- **下す**（くだす）下达；作出｜韩语参考：내리다（下达）<br>
  例：問題は誰が決定を下すかということだ。（问题是谁来做出决定。）
- **下り**（くだり）下行；下坡｜韩语参考：하행（下行）<br>
  例：ここの下りも手掛かりがないので危険だ。（这里的下坡也没有可抓的地方，很危险。）
- **苦痛**（くつう）痛苦｜韩语参考：고통（痛苦） / 고초（痛苦，苦楚） / 괴롬（痛苦，煎熬，伤痛）<br>
  例：苦痛で彼の顔が歪んでいる。（他痛苦得脸都歪了。）
- **ぐっすり**（ぐっすり）熟睡｜韩语参考：푹（잠들다）<br>
  例：昨夜はぐっすり眠れなかった。（昨晚没能睡个好觉。）
- **区別**（くべつ）区别｜韩语参考：구별（区别，区分，分辨）<br>
  例：私は彼女と妹を区別できなかった。（我分不清她和她妹妹。）
- **組**（くみ）组；套｜韩语参考：조（组，小组） / 팀（组，小组，团队）<br>
  例：もうひと組の観光客が到着した。（又一批游客到了。）
- **組合**（くみあい）工会；组合｜韩语参考：조합（组合）<br>
  例：組合はデモに参加しましたか。（工会参加游行了吗？）
- **組む**（くむ）组合；交叉｜韩语参考：짜다 / 엮다 / 꼬다<br>
  例：私は彼らが腕を組んで歩いているのを見た。（我看见他们挽着手臂走路。）
- **位**（くらい）位；左右｜韩语参考：자리（位） / 언저리（左右）<br>
  例：５８１４を千の位に四捨五入すれば何になりますか。（5814四舍五入到千位是多少？）
- **暮らし**（くらし）生活｜韩语参考：삶（生活） / 살림（生活，日子，持家） / 살림살이（生活，过日子，持家）<br>
  例：もっと良い暮らしができますように。（希望能过上更好的生活。）
- **クラシック**（クラシック）古典乐｜韩语参考：클래식 음악<br>
  例：クラシックはありません。（没有古典乐。）
- **暮らす**（くらす）生活；度日｜韩语参考：살다（生活，过活，过日子） / 지내다（度日，生活） / 생활하다（生活，居住）<br>
  例：彼女が一人で暮らすのはよくない。（她一个人生活不太好。）
- **グラス**（グラス）玻璃杯｜韩语参考：글라스（玻璃杯，酒杯） / 유리잔（玻璃杯） / 유리컵（玻璃杯）<br>
  例：グラスは粉々に割れてしまった。（玻璃杯摔得粉碎。）
- **グランド**（グランド）场地；运动场｜韩语参考：운동장 / 경기장<br>
  例：イングランドはその試合に勝つだろう。（英格兰大概会赢下那场比赛。）
- **クリーム**（クリーム）奶油｜韩语参考：크림（奶油）<br>
  例：彼女はデザート用にクリームを泡立てた。（她为做甜点打了奶油。）
- **繰り返す**（くりかえす）重复｜韩语参考：반복하다（反复，重复）<br>
  例：「いいえ」とイギリス人は繰り返しました。（那个英国人又说了一遍「不」。）

## 语法

- **〜によると / 〜によれば**：据…说
  接续：名词 + によると／によれば（句末须有传闻表达）
  朝鲜语：-에 따르면（韩语「-에 따르면」同样要求句末有传闻标记；日语「によると」必须与「そうだ/らしい」呼应，韩语可与多种转述形式搭配。）
- **〜ばかりでなく**：不仅…而且…
  接续：普通形 + ばかりでなく；ナ形容词 + な + ばかりでなく；名词 + ばかりでなく
  朝鲜语：-뿐만 아니라（韩语「-뿐만 아니라」与日语几乎完全对应；但日语后项习惯加「も」，韩语可省，容易漏掉「も」。）
