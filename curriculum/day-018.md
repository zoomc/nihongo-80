# Day 018 · ～たり ～たり する、〜は

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～たり ～たり する、〜は」造两句自己的话，表达：又…又…／时而…时而…；…是主题；至于…

## 新词 19

- **交差点**（こうさてん）十字路口｜韩语参考：네거리（十字路口）<br>
  例：あの交差点で何が起こったのか。（那个十字路口发生了什么？）
- **紅茶**（こうちゃ）红茶｜韩语参考：홍차（红茶）<br>
  例：紅茶かコーヒーはいかがですか。（您要红茶还是咖啡？）
- **交番**（こうばん）派出所｜韩语参考：파출소（派出所）<br>
  例：向こうの交番で聞いてください。（请到对面的派出所问一下。）
- **声**（こえ）声音；嗓音｜韩语参考：목（嗓音） / 목청（嗓音） / 소리（嗓音，嗓子，嗓门）<br>
  例：あなたの声が聞けてうれしいわ。（能听到你的声音真高兴。）
- **コート**（コート）大衣；球场｜韩语参考：코트（大衣）<br>
  例：このコートいいですね。試着してもいいですか。（这件大衣不错。可以试穿吗？）
- **コーヒー**（コーヒー）咖啡｜韩语参考：커피（咖啡）<br>
  例：そのコーヒーはいいにおいがする。（那咖啡闻着真香。）
- **ここ**（ここ）这里｜韩语参考：예（这里，这儿） / 여기（这里，这儿） / 요기（这里，这儿）<br>
  例：ここで待ってください。（请在这里等。）
- **午後**（ごご）下午｜韩语参考：오후（下午，午后） / 하오（下午）<br>
  例：午後何時ごろうかがいましょうか。（下午几点去拜访您？）
- **九日**（ここのか）九天；九号｜韩语参考：아흐레（九天）<br>
  例：スピーチコンテストは１１月９日に行われた。（演讲比赛在11月9日举行。）
- **九つ**（ここのつ）九个｜韩语参考：아홉 개<br>
  例：私たちの学校にはクラスが９つある。（我们学校有九个班。）
- **午前**（ごぜん）上午｜韩语参考：오전（上午） / 아침나절（上午）<br>
  例：その電車は午前９時にここを出発します。（那趟电车上午9点从这里发车。）
- **答える**（こたえる）回答｜韩语参考：답하다（回答，答话） / 대답하다（回答，解答） / 응답하다（应答，回答）<br>
  例：「はい、ありません」とジョーダンさんは答えた。（“是的，没有。”乔丹先生答道。）
- **ごちそうさま**（ごちそうさま）多谢款待｜韩语参考：잘 먹었습니다<br>
  例：コーヒー、ごちそうさまでした。（谢谢您的咖啡。）
- **こちら**（こちら）这边；这位｜韩语参考：요쪽（这边）<br>
  例：今のところこちらだけになります。（目前只有这一种。）
- **こっち**（こっち）这边｜韩语参考：요쪽（这边） / 요리요리（往这边）<br>
  例：こっちへ来い、ぐずぐずしないで。（到这儿来，别磨蹭。）
- **コップ**（コップ）杯子｜韩语参考：잔（杯，杯子） / 컵（杯子）<br>
  例：コップに水を入れます。（往杯子里倒水。）
- **今年**（ことし）今年｜韩语参考：금년（今年） / 올（今年）<br>
  例：今年もよい年でありますように。（愿今年也是好年。）
- **言葉**（ことば）语言；话语｜韩语参考：말（话，语言）<br>
  例：言葉が出てこなかった。（我说不出话来。）
- **この**（この）这个｜韩语参考：요（这个） / 이（这，这个）<br>
  例：このコップをミルクで満たした。（我把这个杯子倒满了牛奶。）

## 语法

- **～たり ～たり する**：又…又…／时而…时而…
  接续：動詞た形 + り + 動詞た形 + り + する
  朝鲜语：-기도 하고 -기도 하다（韩语用기도 하고…기도 하다列举，句末必须하다；거나表选择，语义不同。）
- **〜は**：…是主题；至于…
  接续：名词 + は（读作 wa）
  朝鲜语：은/는（주제 조사）（韩语 은/는 也分主题与对比，但日语 は 读作 wa，且可顶替 を／が 的位置；韩语助词随收音换形，日语不随音变。）
