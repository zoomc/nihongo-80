# Day 031 · 可能形、条件形（ば／たら／なら／と）、～に なる / ～く なる / ～に する

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「可能形、条件形（ば／たら／なら／と）、～に なる / ～く なる / ～に する」各造一句自己的话，表达：能／会…（动词可能形）；如果…／一…就…（条件形总览）；变成…／使…变得…

- **公園**（こうえん）公园｜韩语参考：공원（公园）<br>
  例：公園で遊びます。（在公园玩。）
- **切符**（きっぷ）车票；票｜韩语参考：표（票，券） / 차표（车票） / 기차표（火车票）<br>
  例：切符を買います。（买车票。）

  例：メールを送ります。（发邮件。）

  例：日本語ができます。（会日语。）

  例：日本語は難しいです。（日语很难。）
- **きれい**（きれい）漂亮；干净｜韩语参考：예쁘다 / 깨끗하다<br>

  例：安いです。しかし、美味しくないです。（便宜，但是不好吃。）
- **手伝う**（てつだう）帮忙；搭把手｜韩语参考：곁들다（帮忙，插话） / 도와주다（帮忙，帮助）<br>
  例：母の仕事を手伝います。（我帮妈妈干活。）
- **忘れる**（わすれる）忘记；忘带｜韩语参考：잊다（忘，忘记，忘却）<br>

- **覚える**（おぼえる）记住；学会｜韩语参考：기억하다（记着，记住）<br>

- **無くす**（なくす）弄丢；丢失｜韩语参考：잃다（丢，丢失，遗失） / 분실하다（遗失，丢失） / 잃어버리다（丢，丢失，遗失）<br>
  例：切符を無くしてしまいました。（我把车票弄丢了。）
- **落とす**（おとす）使落下；遗失｜韩语参考：잃다（丢，丢失，遗失） / 흘리다（落下，丢掉） / 빠뜨리다（落掉，遗忘，落下）<br>
  例：財布を落としてしまいました。（我把钱包弄掉了。）
- **運ぶ**（はこぶ）搬运；运送｜韩语参考：나르다（搬，搬运） / 운송하다（运送，运输）<br>
  例：荷物を部屋まで運びます。（把行李搬到房间。）
- **片付ける**（かたづける）整理；收拾；解决｜韩语参考：치우다（清理，收拾）<br>
  例：部屋を片付けてください。（请把房间收拾好。）
- **直す**（なおす）修理；改正｜韩语参考：고치다（改正，纠正） / 바로잡다（纠正，改正） / 수리하다（修理）<br>
  例：間違いを直します。（我把错误改过来。）
- **続ける**（つづける）继续（他动）｜韩语参考：계속하다（继续，持续）<br>
  例：日本語の勉強を続けています。（我一直在继续学日语。）
- **始める**（はじめる）开始（他动）｜韩语参考：비롯하다（开始） / 시작하다（开始）<br>
  例：新しい仕事を始めます。（我开始新工作。）
- **決める**（きめる）决定（他动）｜韩语参考：가르다（区分，决定）<br>
  例：旅行の日を決めました。（定好了旅行的日子。）

## 语法

- **可能形**：能／会…（动词可能形）
  接续：五段 う段→え段+る；一段 去る+られる；カ変 来られる；サ変 できる
  朝鲜语：-(으)ㄹ 수 있다（韩语可能用ㄹ 수 있다短语，不改动词形态；日语靠一段/五段变形，宾语可を→が。）
- **条件形（ば／たら／なら／と）**：如果…／一…就…（条件形总览）
  接续：ば えば/ければ；たら た形+ら；なら 名词/普通形+なら；と 辞书形+と
  朝鲜语：-(으)면（韩语条件基本用면一形，语用限制少；日语ば/たら/なら/と四分，と后不接意志。）
- **～に なる / ～く なる / ～に する**：变成…／使…变得…
  接续：名詞/な形 + に + なる；い形 + く + なる；他动词 〜に/く する
  朝鲜语：-아/어지다 / -게 하다（韩语变化用아/어지다，人为改变用게 하다；无日语なる/する的自动他动对立。）
