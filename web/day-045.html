今日语法 4 条

〜なら
발음〜나라
如果是…的话
动词普通形／い形容词／な形容词／名词 + なら
承接对方已知或提到的话题，就此事给出判断、建议或条件。
쿄우토에이쿠나라,아키가이이데스요.
京都へ行くなら、秋がいいですよ。
如果你要去京都，秋天最合适。
파소콘노코토나라,아니니키쿠토이이요.
パソコンのことなら、兄に聞くといいよ。
电脑方面的事，问我哥哥就好。
손나니네무이나라,쿄우와하야쿠네타라?
そんなに眠いなら、今日は早く寝たら？
那么困的话，今天早点睡怎么样？
朝鲜语：-(이)라면 / -다면
韩语 -(이)라면 与名词搭配，-다면 与动词、形容词搭配；日语 なら 前接形式不随词性变化，接续更简单。
易错点

京都へ行くなれば、秋がいいですよ。 → 京都へ行くなら、秋がいいですよ。（なら 前接普通形，动词不用「なれば」）

〜と（conditional）
발음〜토
一…就…；如果…就…
动词辞书形／ない形／い形容词 + と；な形容词・名词 + だ + と
表示反复出现的自然结果、必然条件或机械性反应，后项不能是意志、请求。
코노보탄오오스토,오차가데마스.
このボタンを押すと、お茶が出ます。
按下这个按钮，茶就会出来。
하루니나루토,사쿠라가사키마스.
春になると、桜が咲きます。
一到春天，樱花就开了。
코노미치오미기니마가루토,히다리니유우빈쿄쿠가아리마스.
この道を右に曲がると、左に郵便局があります。
沿这条路向右转，左边有一家邮局。
朝鲜语：-(으)면
韩语 -(으)면 可表条件，也可接请求；日语 と 的后项必须是自然结果，不能是命令、请求，这一点需特别注意。
易错点

このボタンを押すと、お茶を出してください。 → このボタンを押すと、お茶が出ます。（と 的后项不能是请求、意志表达）

〜ても / 〜でも
발음〜테모 / 〜데모
即使…也…
动词て形+も；い形容词去い+くても；な形容词・名词+でも
表示让步条件，前项成立也不影响后项结论。
아메가후떼모,시아이와아리마스.
雨が降っても、試合はあります。
即使下雨，比赛也照常进行。
이쿠라렌슈우시테모,나카나카조우즈니나리마센.
いくら練習しても、なかなか上手になりません。
无论怎么练习，就是不见进步。
니치요우비데모,코노미세와아이테이마스.
日曜日でも、この店は開いています。
即使是星期天，这家店也开着。
朝鲜语：-아/어도
韩语 -아/어도 与 ても 对应，但日语名词和な形容词用 でも，接续随词性变化；韩语则统一接词干。
易错点

日曜日ても、この店は開いています。 → 日曜日でも、この店は開いています。（名词要用「でも」，不能直接接 ても）

〜のに（although）
발음〜노니
明明…却…
动词普通形／い形容词 + のに；な形容词+な／名词+な + のに
表示与预期相反，带有意外、不满或惋惜的语气。
一生懸命勉強したのに、試験に落ちてしまった。
我明明拼命学习了，考试却没通过。
日曜日なのに、会社に行かなければならない。
明明是星期天，却必须去公司。
約束したのに、彼は来なかった。
他明明答应了，却没有来。
朝鲜语：-는데도
韩语 -는데도 与 のに 对应，同样带不满；但日语 のに 还可用于句末表遗憾，韩语 -는데도 不能单独结句。
易错点

日曜日ののに、会社に行かなければならない。 → 日曜日なのに、会社に行かなければならない。（名词接 のに 直接加 な，不用 の）
