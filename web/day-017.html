今日语法 3 条

韩语对应에（빈도）
韩语 주에 두 번 与「一週間に二回」对应；但韩语「하루에 두 번」的 에 不可省略，日语 に 在口语中有时可省略。
〜に（frequency）
발음〜니
每…（几次）
数量词 + に + 数量词（回数）
表示在一段时间内做某事的频率，如「一日に二回」。
이쓔우칸니니카이,푸우루데오요기마스.
一週間に二回、プールで泳ぎます。
我一周在游泳池游两次。
하하와이치니치니니카이,이누노삼포오시마스.
母は一日に二回、犬の散歩をします。
母亲一天遛两次狗。
이치넨니이치도,카조쿠데료코우시마스.
一年に一度、家族で旅行します。
我们一年全家旅行一次。
易错点

一週間で二回に、プールで泳ぎます。 → 一週間に二回、プールで泳ぎます。（频率基准用「一週間に二回」，に 跟在基准期间后）

韩语对应로/으로（방향）
韩语 로/으로 与 へ 对应，随收音换形；日语 へ 读作 e，写法固定，不随名词变化。
〜へ
발음〜에
往…；朝…
名词（场所／方向）+ へ（读作 e）
表示移动的方向，常与行く、来る、帰る等搭配。
나쓰야스미니호까이도우에이키마스.
夏休みに北海道へ行きます。
暑假我要去北海道。
라이슈우,쿠니에카에리마스.
来週、国へ帰ります。
下周回国。
도코에이키마스카.
どこへ行きますか。
你去哪里？
易错点

夏休みに北海道へを行きます。 → 夏休みに北海道へ行きます。（へ 后不能再加 を）

韩语对应에서（동작 장소）
韩语 에서 与 で 对应，에 表存在；日语 で 与 に 的分工和韩语 에서 与 에 基本一致，较易迁移。
〜で（place of action）
발음〜데
在…（做某事）
名词（场所）+ で
表示动作发生的场所，与存在场所的 に 相对。
토쇼칸데혼오요미마스.
図書館で本を読みます。
我在图书馆看书。
키노우,데파아토데쿠쓰오카이마시타.
きのう、デパートでくつを買いました。
昨天在百货商店买了鞋。
에키노마에데토모다치오마치마시타.
駅の前で友達を待ちました。
我在车站前等朋友。
易错点

図書館に本を読みます。 → 図書館で本を読みます。（动作发生场所用 で，に 表存在或到达）
