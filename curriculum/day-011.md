# Day 011 · ～て から、～て も いい / ～て は いけない、～ながら

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **～て から**：…之后（再）…
  接续：動詞て形 + から
  朝鲜语：-고 나서 / -(으)ㄴ 후에（韩语고 나서强调先后，후에偏「之后」；日语てから强调先做这个再，语气更强。）
- **～て も いい / ～て は いけない**：可以…／不许…
  接续：動詞て形 + も いい（です）／+ は いけない
  朝鲜语：-아/어도 되다 / -(으)면 안 되다（찍어도 돼요 对应 撮ってもいいです，찍으면 안 돼요 对应 撮ってはいけません。想问「可以吗」时说 撮ってもいいですか。）
- **～ながら**：一边…一边…
  接续：動詞ます形（去ます） + ながら
  朝鲜语：-(으)면서（韩语면서要求同一主语且前后动作同时；日语ながら前项多为附带动作，主句在后。）
