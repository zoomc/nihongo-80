# Day 004 · N の N、が（主语／新信息／存在主体）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「N の N、が（主语／新信息／存在主体）」造两句自己的话，表达：…的…；所属/修饰；…（主语/新信息/存在主体/能力对象）

## 新词 20

- **木曜日**（もくようび）星期四｜韩语参考：목요일（星期四，周四，礼拜四）<br>
  例：木曜日に映画を見ます。（周四看电影。）
- **金曜日**（きんようび）星期五｜韩语参考：금요일（星期五，周五，礼拜五）<br>
  例：金曜日は忙しいです。（周五很忙。）
- **土曜日**（どようび）星期六｜韩语参考：토（星期六，周六，礼拜六） / 토요일（星期六，周六，礼拜六）<br>
  例：土曜日に買い物します。（周六购物。）
- **日曜日**（にちようび）星期日｜韩语参考：일요일（星期日， 星期天，周日，礼拜天）<br>
  例：日曜日は休みです。（周日休息。）
- **家**（いえ）家；房子｜韩语参考：집（房子，窝，巢）<br>
  例：家に帰ります。（回家。）
- **学校**（がっこう）学校｜韩语参考：학교（学校） / 학원（学院，学校）<br>
  例：学校へ行きます。（去学校。）
- **会社**（かいしゃ）公司｜韩语参考：기업（企业，公司） / 회사（公司，企业，会社）<br>
  例：会社で働きます。（在公司工作。）
- **駅**（えき）车站｜韩语参考：역（기차역 등）<br>
  例：駅で電車に乗ります。（在车站上电车。）
- **店**（みせ）商店；店铺｜韩语参考：가게（店，店铺，商店） / 상점（商店） / 업소（小公司，营业所，店铺）<br>
  例：駅の前に店があります。（车站前有家店。）
- **病院**（びょういん）医院｜韩语参考：병원（医院）<br>
  例：病院に行きます。（去医院。）
- **図書館**（としょかん）图书馆｜韩语参考：도서관（图书馆）<br>
  例：図書館で本を読みます。（在图书馆读书。）
- **部屋**（へや）房间｜韩语参考：방（房间） / 집칸（房间）<br>
  例：部屋に猫がいます。（房间里有猫。）
- **上**（うえ）上面；上方｜韩语参考：위<br>
  例：机の上に本があります。（桌上有书。）
- **中**（なか）里面；中间｜韩语参考：속（里面，里头） / 안（里，里面） / 가운데（中间，正中，中央）<br>
  例：部屋の中にいます。（在房间里。）
- **前**（まえ）前面；之前｜韩语参考：앞（前，前面）<br>
  例：駅の前に店があります。（车站前有店。）
- **後**（あと）后面；之后｜韩语参考：담（之后） / 뒤（后，之后，后来） / 후（后，以后，之后）<br>
  例：食事の後に、薬を飲みます。（饭后吃药。）
- **ご飯**（ごはん）米饭；饭（餐）｜韩语参考：밥 / 식사<br>
  例：ご飯を食べます。（吃饭。）
- **朝ご飯**（あさごはん）早饭｜韩语参考：아침（早饭，早餐）<br>
  例：朝ご飯を食べます。（吃早饭。）
- **水**（みず）水（冷水／生水）｜韩语参考：물（水）<br>
  例：水を飲みます。（喝水。）
- **お茶**（おちゃ）茶｜韩语参考：차（茶，茶水）<br>
  例：お茶を飲みます。（喝茶。）

## 语法

- **N の N**：…的…；所属/修饰
  接续：名詞 + の + 名詞
  朝鲜语：N의 N（韩语의多表所属，口语常省略；修饰关系更常用名词直接并列，使用范围比日语の窄。）
- **が（主语／新信息／存在主体）**：…（主语/新信息/存在主体/能力对象）
  接续：名詞 + が + 動詞／形容詞
  朝鲜语：이/가（韩语主格助词按收音选이/가，口语가常被는替换表对比；日语が还表能力对象。）
