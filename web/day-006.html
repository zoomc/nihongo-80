今日语法 2 条

へ（移动方向）
名詞 + へ + 移動動詞
へ（移动方向）
往／向…
表移动方向，读 e 不读 he；侧重方向，に 侧重到达点
明日、学校へ行きます。
明天去学校。
朝鲜语：(으)로
韩语方向用(으)로，常可与에互换；日语へ读e、只表方向不含到达点。
易错点

学校へ 行きます（へ 读 he） → 学校へ行きます。（へ 读 e）（助词「へ」在此读 e，不读罗马字 he；中文无此音便）

と（并列／共同／引用）
名詞 + と + 名詞／動詞；引用从句 + と + 思う/言う
と（并列／共同／引用）
和…／与…（一起）；「…」地
完全并列、共同动作对象、引用内容
友達と映画を見ます。
和朋友看电影。
朝鲜语：와/과 / 하고 / (이)라고
韩语并列用와/과、口语하고，引用用라고且随词性变；日语と一形通用。
易错点

友達も映画を見ます。 → 友達と映画を見ます。（「も」是追加「也」，共同动作用 と；中文「和/也」易混）
