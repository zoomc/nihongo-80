今日语法 3 条

〜も
발음〜모
也…；（否定）也不…
名词 + も
表示同类追加，否定句中与前后 も 呼应表示「既不…也不…」。
와타시모가쿠세이데스.
私も学生です。
我也是学生。
아니와사까아모스키데스.
兄はサッカーも好きです。
哥哥也喜欢足球。
니쿠모사카나모타베마센.
肉も魚も食べません。
我既不吃肉也不吃鱼。
朝鲜语：도
韩语 도 与 も 对应，且同样可叠用于否定并列（고기도 생선도）；日语 も 可顶替 は／が／を，韩语 도 也顶替主宾格助词。
易错点

私もは学生です。 → 私も学生です。（も 已含提示作用，不能与 は 叠用）

〜の（possessive）
발음〜노
…的…
名词 + の + 名词
表示所属、属性、材料或同位关系，修饰名词时用 の。
코레와와타시노카사데스.
これは私のかさです。
这是我的伞。
니혼고노센세이와토테모야사시이데스.
日本語の先生はとてもやさしいです。
日语老师非常温柔。
에키노치카쿠니아타라시이미세가아리마스.
駅の近くに新しい店があります。
车站附近有一家新店。
朝鲜语：의
韩语 의 与 の 对应，但口语中 의 常省略；日语 の 不能省略，且还可代替名词（私の）。
易错点

これは私がかさです。 → これは私のかさです。（所属关系用 の，が 会变成主语标记）

〜から（from）
발음〜카라
从…（起点）
名词 + から（起点）
表示时间或场所的起点，常与「まで」呼应。
주교우와쿠지카라데스.
授業は9時からです。
课从九点开始。
가꼬우카라에키마데아루키마스.
学校から駅まで歩きます。
我从学校走到车站。
와타시와부라지루카라키마시타.
私はブラジルから来ました。
我来自巴西。
朝鲜语：부터 / 에서
韩语时间起点用 부터，场所起点用 에서；日语 から 两者通用，范围更宽。
易错点

学校から駅までに歩きます。 → 学校から駅まで歩きます。（まで 表终点，后接动词时不再加 に）
