# Day 028 · ～なければ ならない、～なくても いい、～ようになる / ～なくなる、受身形（～られる）

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **～なければ ならない**：必须…／不得不…
  接续：動詞ない形（去ない） + ければ + ならない
  朝鲜语：-아/어야 하다 / -지 않으면 안 되다（韩语义务用아/어야 하다，更强用아/어야만 하다；敬语하셔야 합니다，日语无此分层。）
- **～なくても いい**：不必…／不…也行
  接续：動詞ない形（去ない） + くても + いい
  朝鲜语：-지 않아도 되다（韩语지 않아도 되다表不必，口语常안 해도 돼更随意；日语なくてもいい较中性。）
- **～ようになる / ～なくなる**：变得会…／变得不…了
  接续：辞书形/可能形 + ようになる；ない形去ない + なくなる（例：行かなくなる）
  朝鲜语：-게 되다 / -지 않게 되다（韩语变化结果统用게 되다，能力变化也用게 되다；日语ようになる与なくなる分开。）
- **受身形（～られる）**：被…／（迷惑）遭遇…
  接续：五段 う段→あ段+れる；一段 去る+られる；カ変 来られる；サ変 される
  朝鲜语：-이/히/리/기 피동（韩语可用被动词尾、被动词或其他构式表达被动；遇到不愉快的事也可改述，日语有雨に降られる等受害被动。）
