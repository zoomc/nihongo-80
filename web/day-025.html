今日语法 4 条

韩语对应-(으)ㄹ 수 있다
韩语可能用ㄹ 수 있다短语，不改动词形态；日语靠一段/五段变形，宾语可を→が。
可能形
能／会…（动词可能形）
五段 う段→え段+る；一段 去る+られる；カ変 来られる；サ変 できる
表能力/可能；对象助词常由 を 变 が（日本語が話せる）
니혼고가하나시세마스.
日本語が話せます。
会说日语。
易错点

話せできます。 → 話せます。（可能形后不能再叠加 できる（双重可能））

韩语对应-(으)면
韩语条件基本用면一形，语用限制少；日语ば/たら/なら/と四分，と后不接意志。
条件形（ば／たら／なら／と）
如果…／一…就…（条件形总览）
ば えば/ければ；たら た形+ら；なら 名词/普通形+なら；と 辞书形+と
四大条件形的变形总览；各自语用限制见 G0038
야스케레바카이마스.
安ければ買います。
便宜就买。
아메가후따라이키마센.
雨が降ったら行きません。
下雨就不去。
易错点

雨が降るたら、家にいます。 → 雨が降ったら、家にいます。（たら接动词た形，不接辞书形加たら。）

韩语对应-아/어지다 / -게 하다
韩语变化用아/어지다，人为改变用게 하다；无日语なる/する的自动他动对立。
～に なる / ～く なる / ～に する
발음～니 나루 / ～쿠 나루 / ～니 스루
变成…／使…变得…
名詞/な形 + に + なる；い形 + く + なる；他动词 〜に/く する
なる 自动词表自然变化，する 他动词表人为改变
카레와이샤니나리마시타.
彼は医者になりました。
他当上医生了。
헤야가시즈카니나리마시타.
部屋が静かになりました。
房间变安静了。
易错点

部屋を静かになりました。 → 部屋が静かになりました。／部屋を静かにしました。（「なる」是自动词，主体用 が；人为改变才用 を+する）

韩语对应-다고 생각하다 / -라고 말하다
韩语引用按句类选다고/라고/냐고，动词要变化；日语と引用保留原形即可。
～と 思う / ～と 言う
발음～토 오모우 / ～토 이우
觉得…／说「…」
普通形从句 + と + 思う／言う
引用助词 と；从句用普通形，不用 です/ます
아시타와아메다토오모이마스.
明日は雨だと思います。
我觉得明天会下雨。
카레와이키타쿠나이토이이마시타.
彼は行きたくないと言いました。
他说不想去。
易错点

明日は雨です と思います。 → 明日は雨だと思います。（「です」不能直接接「と思います」（引用从句要用普通体）。应说「明日は雨だと思います」。这不是 です 本身错，而是嵌在引用从句里的语体不对。）
