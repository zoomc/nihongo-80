# Day 033 · ～ことが できる、～たことが ある

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「～ことが できる、～たことが ある」造两句自己的话，表达：会／能…（可能迂说）；（曾经）做过…

## 新词 20

- **簡単**（かんたん）简单；容易｜韩语参考：간단하다 / 쉽다<br>
  例：この問題は簡単です。（这道题很简单。）
- **危ない**（あぶない）危险｜韩语参考：위태롭다（危急，危险，惊险，悬） / 위험하다（危险）<br>
  例：ここで遊ぶのは危ないです。（在这里玩很危险。）
- **連絡**（れんらく）联络；联系｜韩语参考：연락（联络，联系）<br>
  例：先生に連絡してください。（请联系老师。）
- **予定**（よてい）预定；计划（日程）｜韩语参考：예정（预定）<br>
  例：明日は出張の予定です。（明天预定出差。）
- **予約**（よやく）预约；预订｜韩语参考：예약（预约，预订）<br>
  例：ホテルを予約しました。（订好了酒店。）
- **用意**（ようい）准备；备好（东西）｜韩语参考：마련（准备，备下，置备） / 준비（准备） / 채비（准备，筹备）<br>
  例：資料を用意してください。（请把资料准备好。）
- **世話**（せわ）照顾；照料｜韩语参考：건사（照看，照顾） / 치다꺼리（帮助，照顾，照料） / 뒤치다꺼리（收拾，照顾）<br>
  例：子供の世話をします。（照看孩子。）
- **そろそろ**（そろそろ）差不多该…；快要…｜韩语参考：슬슬 / 이제 곧<br>
  例：そろそろ帰りましょう。（差不多该回去了吧。）
- **あ**（あ）啊｜韩语参考：아<br>
  例：あ！まずい！ガソリンが切れてきた。（啊！糟了！汽油快没了。）
- **ああ**（ああ）那样；那种｜韩语参考：저렇게 / 저런<br>
  例：ある人はこうだと言い、またある人はああだと言う。（有人说这样，又有人说那样。）
- **あいさつする**（あいさつする）打招呼；问候｜韩语参考：인사하다<br>
  例：私にあいさつするような人はいない。（没有人会跟我打招呼。）
- **間**（あいだ）之间；期间｜韩语参考：새（之间，以来） / 사이（间，之间，……的时候）<br>
  例：二人の間がしっくり行かない。（两人之间处得不太融洽。）
- **合う**（あう）合适；相符｜韩语参考：맞다（合适，合乎，对） / 합하다（符合，相符） / 맞아떨어지다（完全相符，正好，一点不差）<br>
  例：このチョッキは前が合わない。（这件背心前面扣不上。）
- **あかちゃん**（あかちゃん）婴儿；宝宝｜韩语参考：아기<br>
  例：その赤ちゃんは歯が生えはじめている。（那个宝宝开始长牙了。）
- **上がる**（あがる）上升；提高；（电池）耗尽/亏电｜韩语参考：오르다（上升，上涨） / 상승하다（上升） / 올라가다（上升，提高）<br>
  例：車のバッテリーが上がってるよ。（车电瓶没电了。）
- **赤ん坊**（あかんぼう）婴儿｜韩语参考：아기（小孩，婴儿）<br>
  例：うちの赤ん坊は口をきくようになってきました。（我家宝宝开始会说话了。）
- **空く**（あく）空；有空｜韩语参考：비다（空）<br>
  例：放課後は空いてますか？（放学后有空吗？）
- **アクセサリー**（アクセサリー）首饰；配饰｜韩语参考：패물（首饰） / 장신구（首饰，装饰品） / 액세서리（饰品，首饰）<br>
  例：この服にはどんなアクセサリーを付けるの？（这身衣服配什么首饰？）
- **浅い**（あさい）浅；浅薄｜韩语参考：얇다（浅，淡） / 얕다（浅，低，矮） / 엷다（浅，薄）<br>
  例：この川はあそこで浅くなっている。（这条河在那里变浅了。）
- **味**（あじ）味道；口味｜韩语参考：맛（味，味道）<br>
  例：このチーズはピリッとした味がする。（这奶酪味道有点冲。）

## 语法

- **～ことが できる**：会／能…（可能迂说）
  接续：動詞辞書形 + ことが + できる
  朝鲜语：-(으)ㄹ 수 있다（韩语与可能形同一表达ㄹ 수 있다，无迂说与形态之分；日语二者可换但接续不同。）
- **～たことが ある**：（曾经）做过…
  接续：動詞た形 + ことが + ある
  朝鲜语：-(으)ㄴ 적이 있다（韩语经验用ㄴ 적이 있다，否定ㄴ 적이 없다；与单纯过去았/었的区分同日语。）
