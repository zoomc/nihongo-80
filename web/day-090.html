③ 语法 6 分钟

V辞書形 / Vない形 / い形 / な形な + うちに
動詞辞書形 + うちに；動詞ない形 + ないうちに；い形 + うちに；な形 + なうちに；名詞 + のうちに
趁着…；在…期间（不知不觉）…

表示在前项状态持续期间做后项；「〜ないうちに」=趁还没…；也可表示不知不觉发生变化。

若いうちに、いろいろな経験をしたほうがいいです。
趁年轻应该多积累各种经验。
忘れないうちに、メモしてください。
趁还没忘，请记下来。
朝鲜语：-는 동안에 / -기 전에
韩语는 동안表期间，기 전에表趁还没；日语うちに还含不知不觉变化，韩语须用는 사이에。

易错：暗いないうちに、帰りましょう。 → 暗くならないうちに、帰りましょう。（い形「暗い」的否定是「暗くない」，不能直接加 ない；中文“还没黑”直译错。）

Nの / Vている + 最中に（だ）
名詞 + の + 最中に；動詞ている + 最中に；句末可 最中だ
正在…的时候（突然…）

强调某动作/状态正进行到一半时，发生了另一件事，后项常是打扰或意外。

会議の最中に、電話が鳴りました。
正在开会时电话响了。
ご飯の最中に、突然停電しました。
正吃饭时突然停电了。
朝鲜语：-는 중에 / -는 도중에
韩语는 중表正在，도중에表途中；日语最中に强调正到一半被打断，语感更强。

易错：会議の最中を、電話が鳴りました。 → 会議の最中に、電話が鳴りました。（最中 后接时间点用 に，不用 を；中文“在会议中”直译成 を。）
