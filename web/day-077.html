③ 语法 6 分钟

V辞書形 / Vない形 + ことが ある
動詞 辞書形／ない形 + ことが ある；ある 可变形（ことがあります／あった）
有时会…／有时不…（泛指倾向）

表示偶尔发生、有时会那样；与 〜たことがある（G0042，曾经做过）时态语义都不同

忙しくて、昼ご飯を忘れることがあります。
忙起来有时会忘了吃午饭。
彼はたまに遅刻することがあります。
他偶尔会迟到。
朝鲜语：-곤 하다 / -기도 하다
韩语곤 하다表过去反复习惯，기도 하다表有时；日语ことがある现在形表偶尔，时态限制不同。

易错：北海道へ行くことがあるです。 → 北海道へ行くことがあります。（「ことがある」结句接礼貌体应为「ことがあります」，「あるです」不合法；另「〜たことがある」表曾经做过（见 compare G0042），与表「有时会」的辞书形「〜ことがある」语义不同。）

V意志形 + と 思う / と する
動詞 意志形（五段 お段+う／一段 よう／する→しよう／来る→こよう）+ と 思う／と する
打算…／正要…、试图…

(よ)うと思う 表说话人打算（现在/将来）；(よ)うとする 表正要开始做或尝试做

日曜日は映画を見ようと思っています。
周日打算看电影。
出かけようとしたら、雨が降ってきました。
正要出门时下起雨来了。
朝鲜语：-(으)ㄹ 생각이다 / -(으)려고 하다
韩语打算用ㄹ 생각이다，正要或试图用려고 하다；日语と思う还含推测，韩语更明确表意志。

易错：映画を見ると思います。 → 映画を見ようと思います。（「打算看」须用意志形 見よう；用辞书形 見る 变成「觉得会看」，中文「想看」直译错）
