# Day 078 · 〜ごとに、〜最中に、〜ついでに

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ごとに**：每…；每隔…
  接续：名词 + ごとに；动词辞书形 + ごとに
  朝鲜语：-마다（십 분마다 对照 十分ごとに；一人ごとに 则可对照 한 사람마다。名词后直接加 ごとに；重复动作也可以用 たびに。）
- **〜最中に**：正当…的时候
  接续：动词ている + 最中に；名词 + の + 最中に
  朝鲜语：-는 중에（회의 중에 전화가 왔다 对照 会議の最中に電話が来た。最中 特别强调「正当中」，常接意外插进来的事，但也可平静叙述正在发生什么。）
- **〜ついでに**：顺便…
  接续：动词辞书形/た形 + ついでに；名词 + の + ついでに
  朝鲜语：-는 김에（韩语「-는 김에」同样表“顺便”，与「ついでに」对应；但日语可接名词+の，韩语只接动词。）
