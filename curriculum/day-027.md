# Day 027 · 〜よ、〜より、〜の方が〜より

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜よ、〜より、〜の方が〜より」造两句自己的话，表达：…哦；…呀（告知、强调）；比…；…比…更…

## 新词 23

- **ペン**（ペン）笔；钢笔｜韩语参考：펜（笔）<br>

## 语法

- **〜よ**：…哦；…呀（告知、强调）
  接续：句子 + よ
  朝鲜语：-요 / -거든요（韩语 -요 是礼貌尾，不专门表告知；日语 よ 明确提示新信息，韩语需靠 -거든요 或语调表达。）
- **〜より**：比…
  接续：名词 + より
  朝鲜语：보다（韩语 보다 与 より 对应，位置在比较对象后；日语 より 后直接接形容词，韩语 보다 后也直接接，语序相近。）
- **〜の方が〜より**：…比…更…
  接续：名词 + の方が + 名词 + より + 形容词
  朝鲜语：가/이 더 …（韩语用 이/가 더 表胜出项，보다 表基准；日语「の方が」是固定形式，不能换成 が。）
