今日语法 3 条

～はずだ / ～わけではない
발음～하즈다 / ～와케데와나이
应该…／并不是…
普通形 + はずだ；普通形 + わけではない
はずだ 表基于依据的推断「理应」；わけではない 表部分否定「并非」
韩语对应-(으)ㄹ 것이다 / -는 것은 아니다
韩语理应推断用ㄹ 것이다或ㄹ 텐데，部分否定用는 것은 아니다；はずだ依据性更强。
카레와모우카에따하즈데스.
彼はもう帰ったはずです。
他应该已经回去了。
타카이카라토이떼,오이시이와케데와아리마센.
高いからといって、美味しいわけではありません。
贵并不一定就好吃。

易错点 彼は帰った はず だ です → 彼は帰ったはずです。（「はずだ」礼貌形是 はずです，不叠加 だ+です）

～おかげで / ～せいで
발음～오카게데 / ～세이데
多亏…／都怪…
名/な形 + の/な + おかげで／せいで；普通形 + おかげで／せいで
おかげで 通常表达对好结果的感谢，也可反讽；せいで 常用于不理想结果，不应脱离语境机械判定。
韩语对应-덕분에 / -때문에
韩语 덕분에 通常表示多亏，也可反讽；때문에 可用于中性原因。日语 せいで 常带不满或归因。
센세이노오카게데,니혼고가조우즈니나리마시타.
先生のおかげで、日本語が上手になりました。
多亏老师，日语变好了。
아메노세이데,이케마센데시타.
雨のせいで、行けませんでした。
都怪下雨，没能去成。

易错点 先生のおかげで（漏 の） → 先生のおかげで…（名词后接 おかげで 要加 の：先生のおかげで）

～によって / ～について / ～にとって
발음～니요떼 / ～니쓰이테 / ～니토떼
因…而异／关于…／对…来说
名詞 + によって／について／にとって
によって 表「因…而不同/依据/手段被动」、について「关于」、にとって「对…而言（评价）」
韩语对应-에 따라 / -에 대해 / -에게
韩语에 따라表依据或随…而异，에 대해关于，에게表评价对象，三者分工比日语清楚。
히토니요떼이켄가치가이마스.
人によって意見が違います。
意见因人而异。
니혼고니쓰이테하나시마스.
日本語について話します。
谈谈日语。
와타시니토떼,니혼고와무즈카시이데스.
私にとって、日本語は難しいです。
对我来说日语很难。

易错点 私について、日本語は難しいです → 私にとって、日本語は難しいです。（「对…来说」用 にとって，について 是「关于」，中文「对」易混）
