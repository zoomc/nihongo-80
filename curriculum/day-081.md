## 新词 25

- **直に**（じかに）直接｜韩语参考：직접<br>
  例：あなたとじかに会ってじっくり話したいことがあるのです。（我有事想跟你当面好好谈谈。）
- **しかも**（しかも）而且；并且｜韩语参考：게다가<br>
  例：彼は音もなくしかもすばやく動ける。（他能又无声又迅速地移动。）
- **叱る**（しかる）责备；训斥｜韩语参考：책하다（责备，训斥，斥责） / 혼내다（训斥，呵斥） / 꾸중하다（责骂，训斥）<br>
  例：ママに叱られますよ。（会被妈妈骂的哦。）
- **式**（しき）仪式；公式｜韩语参考：식（仪式）<br>
  例：彼は事故でその式に出席できなかった。（他因事故没能出席那个仪式。）
- **時期**（じき）时期｜韩语参考：시기（时期，时节，季节）<br>
  例：１年のこの時期は天候がよく変わる。（每年这个时期天气变化很大。）
- **直**（じき）马上｜韩语参考：곧 / 즉시<br>
  例：彼女はじきよくなるだろう。（她很快就会好起来。）
- **支給**（しきゅう）发放；支付｜韩语参考：지급（支付，付给，颁发）<br>
  例：私たちは制服を支給された。（我们被发放了制服。）
- **しきりに**（しきりに）频频；一个劲儿｜韩语参考：자꾸 / 빈번하게<br>
  例：トムはしきりに新車を買いたがっている。（汤姆一个劲儿地想买新车。）
- **支出**（ししゅつ）支出｜韩语参考：지출（支出）<br>
  例：収入につりあった支出をしなければなりません。（支出必须与收入相称。）
- **事情**（じじょう）情况；缘由｜韩语参考：사정（处境，情况，原因，缘由） / 사유（事由，事因，缘由，缘故，情由） / 연고（缘故，缘由）<br>
  例：彼女はすべての事情を利用する。（她会利用一切情况。）
- **詩人**（しじん）诗人｜韩语参考：시인（诗人）<br>
  例：彼女は大した詩人ではありません。（她算不上什么了不起的诗人。）
- **自身**（じしん）自身；本人｜韩语参考：자신 / 본인<br>
  例：ジェーン自身がこの手紙を書いた。（这封信是简本人写的。）
- **沈む**（しずむ）下沉；消沉｜韩语参考：가라앉다 / 침울해지다<br>
  例：まるで、沈む船から逃げるネズミみたいね。（简直就像从沉船上逃走的老鼠。）
- **自然**（しぜん）自然｜韩语参考：자연（自然） / 자연적（自然而然的）<br>
  例：夫婦が愛し合うのは全く自然である。（夫妻相爱是很自然的。）
- **思想**（しそう）思想｜韩语参考：사상（思想） / 메시지（寓意，宗旨，思想，启示）<br>
  例：彼には思想の理想がかけている。（他缺少思想上的追求。）
- **舌**（した）舌头｜韩语参考：혀（舌头）<br>
  例：コーヒーは舌が焼けるほど熱かった。（咖啡烫得几乎烫伤舌头。）
- **次第**（しだい）取决于；一…就｜韩语参考：~에 달려 있다 / ~하자마자<br>
  例：空港に着き次第、電話します。（我一到机场就给你打电话。）
- **事態**（じたい）事态｜韩语参考：사태（事态，事件）<br>
  例：事態はかなり切迫している。（事态相当紧迫。）
- **従う**（したがう）遵从；跟随｜韩语参考：뒤좇다（遵从） / 따르다（跟随，尾随） / 뒤따르다（跟随）<br>
  例：本能に従うと道を誤ることが多い。（依本能行事往往会走错路。）
- **したがって**（したがって）因此；按照｜韩语参考：따라서 / ~에 따라<br>
  例：君は能力にしたがって上達する。（你会按能力逐步提高。）
- **親しい**（したしい）亲密｜韩语参考：정답다（亲切，亲密，温情） / 친하다（亲近，要好，亲密） / 친근하다（亲近，亲密）<br>
  例：犬は人間の最も親しい友達である。（狗是人类最亲密的朋友。）
- **質**（しつ）质量；质地｜韩语参考：질（质，质量）<br>
  例：お茶の質は下がりつつある。（茶叶的质量正在下降。）
- **失業**（しつぎょう）失业｜韩语参考：실업（失业） / 실직（失业）<br>
  例：この地域の失業はほぼないに等しい。（这个地区的失业几乎等于没有。）
- **実験**（じっけん）实验｜韩语参考：실험（实验）<br>
  例：この実験では不注意は許されない。（这个实验不允许有半点疏忽。）
- **実現**（じつげん）实现｜韩语参考：실현（实现） / 구현（体现，实现，贯彻）<br>
  例：あなたの夢がみんな実現されますように。（愿你的梦想都能实现。）

## 语法

- **〜さえ〜ば**：只要…就…
  接续：名词 + さえ + ば形；动词ます形词干 + さえ + すれば；动词て形 + さえ + いれば
  朝鲜语：-기만 하면（韩语「-기만 하면」与「さえ〜ば」对应；但日语「さえ」位置固定在各成分后，韩语统一贴在动词后，语序处理不同。）
- **〜こそ**：正是…；才是…
  接续：名词 + こそ（可加「が」成「こそが」）
  朝鲜语：-야말로（韩语「-야말로」与「こそ」几乎一致；但日语「こちらこそ」已成固定寒暄，韩语对应「저야말로」，礼貌度需注意。）
- **〜として**：作为…；以…身份
  接续：名词 + として；名词 + としての + 名词
  朝鲜语：-로서（韩语「-로서」表资格，与「として」对应；但韩语另有「-로써」表手段，日语「として」不表手段，切勿混用。）
