今日语法 4 条

〜たびに
발음〜타비니
每当…就…
动词辞书形 + たびに；名词 + の + たびに
表示每次发生前项，后项也随之发生。
この写真を見るたびに、大学時代を思い出す。
每次看到这张照片，就想起大学时代。
아네와슈쪼우노타비니,오미야게오카떼키테쿠레루.
姉は出張のたびに、お土産を買ってきてくれる。
姐姐每次出差都会给我带特产。
この川は、大雨が降るたびにあふれて、道が通れなくなる。
这条河每次下大雨都会泛滥，路都过不去。
朝鲜语：-ㄹ 때마다
韩语「-ㄹ 때마다」与「たびに」基本对应；但日语「たびに」偏书面，口语常说「〜ときはいつも」。
易错点

この写真を見たたびに、大学時代を思い出す。 → 見るたびに（「たびに」前接辞书形（或名词+の），不接た形。）

〜ごとに
발음〜고토니
每…；每隔…
名词 + ごとに；动词辞书形 + ごとに
表示以某单位等间隔重复，或“每一个都各自不同”。
코노바스와주우고훈고토니데테이마스.
このバスは十五分ごとに出ています。
这趟公交每十五分钟一班。
키세쓰고토니,미세노카자리가카와루.
季節ごとに、店の飾りが変わる。
每个季节店里的装饰都会变。
一回使うごとにポイントがたまるカードです。
这是每用一次就积分的卡。
朝鲜语：-마다
韩语「-마다」兼表“每”和“每隔”；日语要区分「ごとに」（每）与「おきに」（每隔）。
易错点

このバスは十五分おきごとに出ています。 → 十五分ごとに（「おき」与「ごと」都表间隔，不能叠加，二者择一。）

〜最中に
발음〜사이추우니
正当…的时候
动词ている + 最中に；名词 + の + 最中に
表示某动作正值高潮时另一事突然发生，多含妨碍意味。
大事な会議の最中に、携帯電話が鳴ってしまった。
正开重要会议时，手机响了。
料理をしている最中に、停電になった。
正做饭时停电了。
이마,시켄노사이추우다카라,로우카데와시즈카니시테쿠다사이.
今、試験の最中だから、廊下では静かにしてください。
现在正在考试，请在走廊保持安静。
朝鲜语：-는 중에
韩语「-는 중에」只表“进行中”；日语「最中に」还隐含“被打断、扫兴”的语感。
易错点

大事な会議最中に、携帯電話が鳴ってしまった。 → 会議の最中に（「最中」是名词，接名词要加「の」，说「会議の最中に」。）

〜をめぐって
발음〜오메구떼
围绕…展开争论或讨论
名词 + をめぐって
用在有不同立场的问题或议题上。
学校の移転をめぐって、意見が分かれています。
围绕学校搬迁，大家意见不一。
予算の使い方をめぐって、話し合いが続いています。
围绕预算用法的讨论还在继续。
朝鲜语：을 둘러싸고
常接讨论、对立等表示多方立场的动作。
易错点

移転にめぐって → 移転をめぐって（这个句型固定写作「をめぐって」。）
