# Day 122 · 〜せいで、〜たとたん / 〜たとたんに

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜せいで、〜たとたん / 〜たとたんに」造两句自己的话，表达：都怪…；因为…；刚一…就…

## 新词 14

- **主義**（しゅぎ）主义；原则｜韩语参考：주의（主义）<br>
  例：それは私の主義に反する。（那违背我的原则。）
- **宿泊**（しゅくはく）住宿｜韩语参考：숙박（住宿，投宿）<br>
  例：６人宿泊させて欲しい。（希望让我们六个人住下。）
- **手術**（しゅじゅつ）手术｜韩语参考：수술（手术）<br>
  例：手術をしなければなりません。（必须做手术。）
- **首相**（しゅしょう）首相；总理｜韩语参考：수상（首相） / 국무총리（国务总理）<br>
  例：首相の留守中は外務大臣が代理を務める。（首相不在期间由外务大臣代理。）
- **手段**（しゅだん）手段；方法｜韩语参考：수（手段，办法，方法）<br>
  例：全ての手段が試みられたわけではない。（并不是所有办法都试过了。）
- **主張**（しゅちょう）主张｜韩语参考：주장（主张）<br>
  例：私たちはその重要性を主張した。（我们强调了它的重要性。）
- **出身**（しゅっしん）出身；毕业｜韩语参考：출신（出身，身份）<br>
  例：彼女は神戸大学の出身です。（她毕业于神户大学。）
- **出版**（しゅっぱん）出版｜韩语参考：출판（出版，出刊，刊行） / 출간（出刊，出版）<br>
  例：ついにその本を出版した。（那本书终于出版了。）
- **首都**（しゅと）首都｜韩语参考：수도（首都） / 서울（首都）<br>
  例：東京は日本の首都です。（东京是日本的首都。）
- **主婦**（しゅふ）家庭主妇｜韩语参考：주부（主妇，家庭主妇）<br>
  例：主婦は節約に努めるべきである。（家庭主妇应当努力节约。）
- **主要**（しゅよう）主要｜韩语参考：주요（主要）<br>
  例：日本の主要作物は米である。（日本的主要作物是水稻。）
- **需要**（じゅよう）需求｜韩语参考：수요（需要，需求）<br>
  例：これらの品物の需要は多いですか。（这些商品的需求量大吗？）
- **種類**（しゅるい）种类｜韩语参考：종류（种类）<br>
  例：動物園にはたくさんの種類の動物がいる。（动物园里有很多种动物。）
- **順**（じゅん）顺序；次序｜韩语参考：차례（次序）<br>
  例：用紙は順に番号が打ってある。（纸张上依次编了号。）

## 语法

- **〜せいで**：都怪…；因为…
  接续：动词普通形/い形容词/ナ形容词な/名词の + せいで
  朝鲜语：-때문에（韩语「-때문에」中性，好坏结果都可用；日语「せいで」专用于坏结果并带责难，不能随便替换「おかげで」。）
- **〜たとたん / 〜たとたんに**：刚一…就…
  接续：动词た形 + とたん（に）
  朝鲜语：-자마자（韩语「-자마자」只表紧接发生；日语「とたん」还要求后项是意外、非意志的事，不能接自己的有意动作。）
