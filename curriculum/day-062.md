# Day 062 · 〜な（prohibition）、〜なさい

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜な（prohibition）、〜なさい」造两句自己的话，表达：不许…；别…；（长辈指示）做…

## 新词 19

- **どんどん**（どんどん）不断；一个劲｜韩语参考：계속 / 점점<br>
  例：だれかがドアをどんどんたたいている。（有人在不停地敲门。）
- **治る**（なおる）痊愈；治好｜韩语参考：낫다（痊愈）<br>
  例：２週間もすれば自然に治ります。（过两周就会自然痊愈。）
- **直る**（なおる）修好；改正｜韩语参考：고쳐지다 / 낫다<br>
  例：いったい、いつになったらそのケチは直るの？（到底什么时候你才能改掉那小气的毛病？）
- **中々**（なかなか）相当；怎么也（不）｜韩语参考：상당히 / 좀처럼（부정과 함께）<br>
  例：試験中はなかなか大変だった。（考试期间相当辛苦。）
- **泣く**（なく）哭｜韩语参考：울다（哭，哭泣）<br>
  例：ビルは何時間も泣き続けた。（比尔哭了好几个小时。）
- **亡くなる**（なくなる）去世｜韩语参考：가다（去世） / 돌아가다（去世，逝世）<br>
  例：父が亡くなってから３年になります。（父亲去世已经三年了。）
- **無くなる**（なくなる）不见；用完｜韩语参考：없어지다（没有了，不见了）<br>
  例：あなたの青いペンがなくなってしまいました。（你的蓝笔不见了。）
- **投げる**（なげる）扔；投｜韩语参考：던지다（投，掷，扔）<br>
  例：その子は犬に石を投げた。（那个孩子朝狗扔石头。）
- **鳴る**（なる）响；鸣｜韩语参考：울다（响，鸣） / 치다（敲，响） / 울리다（响，鸣）<br>
  例：電話が鳴ったらただちに出なさい。（电话一响就马上接。）
- **なるべく**（なるべく）尽量｜韩语参考：되도록（尽量） / 될 수 있는 대로（尽量）<br>
  例：なるべく安いほうがいいです。（尽量便宜一点的好。）
- **なるほど**（なるほど）原来如此｜韩语参考：그렇군요<br>
  例：ああ、なるほど！（啊，原来如此！）
- **におい**（におい）气味｜韩语参考：냄새<br>
  例：あの花はにおいが強いな。（那花的气味真冲。）
- **苦い**（にがい）苦｜韩语参考：쓰다（苦）<br>
  例：このコーヒーは苦い味がする。（这咖啡有苦味。）
- **二階建て**（にかいだて）二层楼｜韩语参考：이층집<br>
  例：私は２階建ての家に住んでいる。（我住在两层楼的房子里。）
- **逃げる**（にげる）逃跑；逃避｜韩语参考：뛰다（逃跑，逃窜，逃亡） / 빼다（逃避，避开） / 달아나다（逃跑，逃走，逃亡）<br>
  例：現実から逃げることはできない。（人无法逃避现实。）
- **日記**（にっき）日记｜韩语参考：일기（日记）<br>
  例：彼女はそのことを日記に書いた。（她把那件事写进了日记。）
- **入学**（にゅうがく）入学｜韩语参考：입학（入学）<br>
  例：私はこの学校に２年前に入学した。（我两年前进入这所学校。）
- **似る**（にる）像；相似｜韩语参考：닮다（像，随）<br>
  例：私も似た話を聞いたことがある。（我也听过类似的事。）
- **人形**（にんぎょう）人偶；娃娃｜韩语参考：인형（娃娃）<br>
  例：メアリーは私にアメリカの人形をくれた。（玛丽送给我一个美国人偶。）

## 语法

- **〜な（prohibition）**：不许…；别…
  接续：动词辞书形 + な
  朝鲜语：-지 마라（韩语 -지 마라 与禁止形对应，语气同样强硬；日语禁止形只接辞书形，韩语则接词干，接续方式不同。）
- **〜なさい**：（长辈指示）做…
  接续：动词ます形去ます + なさい
  朝鲜语：-아/어라（韩语 -(으)세요 是礼貌命令，-아/어라 是强硬命令；日语 なさい 介于两者之间，专用于上对下，韩语没有完全对应的专用形式。）
