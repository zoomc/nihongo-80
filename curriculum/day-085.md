## 新词 25

- **電子**（でんし）电子｜韩语参考：전자（电子）<br>
  例：電子タイプライターはありますか。（有电子打字机吗？）
- **テント**（テント）帐篷｜韩语参考：천막（帐篷） / 텐트（帐篷）<br>
  例：私たちは暗くならないうちにテントを張った。（我们趁天还没黑搭起了帐篷。）
- **天然**（てんねん）天然｜韩语参考：천연（天然，自然） / 자연산（野生，天然）<br>
  例：この車は天然ガスで動く。（这辆车烧天然气。）
- **問い**（とい）问题；提问｜韩语参考：물음（提问，问题）<br>
  例：私はその問がたいへんやさしいことを発見した。（我发现那个问题很简单。）
- **党**（とう）党；派｜韩语参考：당（党）<br>
  例：彼女は根っからのコーヒー党です。（她是个地道的咖啡派。）
- **塔**（とう）塔；佛塔｜韩语参考：탑（塔）<br>
  例：家からその塔が見える。（从家里能看见那座塔。）
- **同時**（どうじ）同时｜韩语参考：동시（同时） / 일시（同时） / 한때（同时）<br>
  例：二つのことを同時にするのは難しいです。（同时做两件事很难。）
- **どうしても**（どうしても）无论如何；一定｜韩语参考：어떻게 해도 / 반드시<br>
  例：残念ですが、あなたの名前をどうしても覚えられない。（很遗憾，我怎么也记不住你的名字。）
- **道徳**（どうとく）道德｜韩语参考：도덕（道德）<br>
  例：彼は道徳力に欠けていた。（他缺少道德感。）
- **投票**（とうひょう）投票｜韩语参考：투표（投票）<br>
  例：２０歳になっていれば、投票できるのに。（要是满20岁就能投票了。）
- **同様**（どうよう）同样；一样｜韩语参考：마찬가지（相同，一样）<br>
  例：この車は新車同様だ。（这辆车跟新车一样。）
- **道路**（どうろ）道路；公路｜韩语参考：도로（道路，公路） / 길（路，道，道路） / 행로（大路，道路）<br>
  例：その崖は道路の上に突き出ている。（那道悬崖突出在道路上方。）
- **通す**（とおす）让…通过；领进｜韩语参考：통하다（通过，利用，使用）<br>
  例：彼はその訪問者を居間に通した。（他把那位访客领进了客厅。）
- **通り**（とおり）街道；经过；照样（如 予定通り）｜韩语参考：거리（大街，街头，马路） / 길거리（大街，街头，马路）<br>
  例：駅前の通りをまっすぐ進んでください。（请沿着车站前那条路一直走。）
- **通り過ぎる**（とおりすぎる）走过；经过｜韩语参考：지나가다（途径，经过） / 지나치다（走过，路过） / 지나다니다（经过，路过）<br>
  例：私はその暗い道を通り過ぎた。（我走过了那条昏暗的路。）
- **都会**（とかい）城市；都市｜韩语参考：도회（城市，都市）<br>
  例：あの人達は都会の生活にあこがれている。（那些人向往城市生活。）
- **時**（とき）时候；时间｜韩语参考：날（时候） / 때（时，时候） / 시（时，时候）<br>
  例：１２才の時彼は声変わりした。（他十二岁时变了声。）
- **解く**（とく）解开；解除｜韩语参考：풀다（解开，解答） / 끄르다（解开） / 풀어내다（化解，解开）<br>
  例：彼は重責を解かれた。（他被免去了重任。）
- **毒**（どく）毒｜韩语参考：독（毒）<br>
  例：この魚は毒がない。（这种鱼没有毒。）
- **得意**（とくい）擅长；得意｜韩语参考：득의（得意）<br>
  例：あなたは数学が得意ですか。（你擅长数学吗？）
- **読書**（どくしょ）读书｜韩语参考：독서（读书）<br>
  例：母はメガネなしでは読書できない。（母亲不戴眼镜就没法看书。）
- **独身**（どくしん）单身；未婚｜韩语参考：독신（单身） / 단신（独身，单身）<br>
  例：彼は一生独身で過ごした。（他一生独身。）
- **登山**（とざん）登山｜韩语参考：등산（登山）<br>
  例：その靴は登山には向かないよ。（那双鞋不适合登山。）
- **都市**（とし）城市；都市｜韩语参考：도시（都市，城市）<br>
  例：この都市の面積はどれくらいか。（这座城市面积有多大？）
- **年月**（としつき）岁月；年月｜韩语参考：세월 / 연월<br>
  例：あれだけのコインを収集するのにどれだけの年月がかかりましたか。（收集那么多硬币花了多少年月。）

## 语法

- **〜というのは**：所谓…；是因为…
  接续：名词/句子 + というのは
  朝鲜语：-라는 것은（韩语「-라는 것은」表定义时与「というのは」对应；但日语还能在句末引出理由，韩语要用「왜냐하면」。）
- **〜というより**：与其说…不如说…
  接续：动词普通形/い形容词/ナ形容词/名词 + というより
  朝鲜语：-라기보다（韩语「-라기보다」与「というより」对应；但日语名词后不加「だ」，韩语要按有无收音变形，形式更复杂。）
- **〜わりに / 〜わりには**：照…来说；相对…而言
  接续：动词普通形/い形容词/ナ形容词な/名词の + わりに（は）
  朝鲜语：-에 비해서（韩语没有与「わりに」完全对应的形式，常译成「-에 비해서」或「-치고는」；日语专表“比例上不符预期”。）
