## 语法

- **〜つつ / 〜つつも**：一边…；虽…仍…
  接续：ます词干 + つつ / ます词干 + つつも
  朝鲜语：하면서 / 하면서도（韩语提示按整块理解。换成日语时先套接续「ます词干 + つつ / ます词干 + つつも」，再看下面的例句。）
- **〜つつある**：正在逐渐…
  接续：ます词干 + つつある
  朝鲜语：해 가고 있다（韩语 해 가고 있다 可表达变化过程。日语用ます词干接 つつある，偏书面。）
