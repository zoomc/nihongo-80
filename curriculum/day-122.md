# Day 122 · 〜最中に、〜ついでに

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜最中に、〜ついでに」造两句自己的话，表达：正当…的时候；顺便…

## 新词 14

- **植物**（しょくぶつ）植物｜韩语参考：식물（植物）<br>
  例：植物や生き物は持っていませんね？（你没有养植物和动物吧？）
- **食物**（しょくもつ）食物｜韩语参考：음식 / 식품<br>
  例：私はたくさんの食物を持って帰ろう。（我要带很多食物回去。）
- **食欲**（しょくよく）食欲｜韩语参考：식욕（食欲） / 밥맛（胃口，食欲） / 입맛（口味，胃口，食欲）<br>
  例：最近食欲がないんです。（最近没什么食欲。）
- **食料**（しょくりょう）食物；粮食｜韩语参考：식량 / 식품<br>
  例：彼らはじゅうぶんな食料を手に入れられなかった。（他们没能弄到足够的食物。）
- **食糧**（しょくりょう）粮食｜韩语参考：식량（粮食，食粮） / 양식（粮食）<br>
  例：食糧が不足している。（粮食短缺。）
- **書斎**（しょさい）书房｜韩语参考：서재（书斋，书室，书房，书屋） / 서실（书房，写字间）<br>
  例：このドアは書斎に通じている。（这扇门通向书房。）
- **女子**（じょし）女子；女生｜韩语参考：여자（女子，女人） / 여인（女人，女子）<br>
  例：この学校は男子よりも女子が多い。（这所学校女生比男生多。）
- **助手**（じょしゅ）助手｜韩语参考：조수（助手）<br>
  例：私は助手を探している。（我正在找助手。）
- **徐々に**（じょじょに）逐渐｜韩语参考：서서히<br>
  例：単語は徐々に増えますので、こまめにチェックしてください。（单词会逐渐增加，请经常查看。）
- **書物**（しょもつ）书籍｜韩语参考：서적（书籍，书） / 서책（书籍）<br>
  例：私たちは、書物から楽しみを得ることができる。（我们能从书籍中获得乐趣。）
- **女優**（じょゆう）女演员｜韩语参考：여우（女演员） / 여배우（女演员）<br>
  例：その女優はせりふを台なしにした。（那个女演员把台词念砸了。）
- **処理**（しょり）处理｜韩语参考：처리（处理，办理）<br>
  例：あなたはあの車をどう処理したのですか？（那辆车你是怎么处理的？）
- **知らせ**（しらせ）通知；消息｜韩语参考：기별（送信儿，消息，信儿）<br>
  例：その悪い知らせは残念ながら本当だ。（遗憾的是，那个坏消息是真的。）
- **尻**（しり）屁股｜韩语参考：볼기（臀部，屁股） / 꽁무니（屁股） / 엉덩이（屁股，臀部）<br>
  例：彼は女の子の尻ばかり追いかけている。（他老是追着女孩子跑。）

## 语法

- **〜最中に**：正当…的时候
  接续：动词ている + 最中に；名词 + の + 最中に
  朝鲜语：-는 중에（韩语「-는 중에」只表“进行中”；日语「最中に」还隐含“被打断、扫兴”的语感。）
- **〜ついでに**：顺便…
  接续：动词辞书形/た形 + ついでに；名词 + の + ついでに
  朝鲜语：-는 김에（韩语「-는 김에」同样表“顺便”，与「ついでに」对应；但日语可接名词+の，韩语只接动词。）
