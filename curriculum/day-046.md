## 新词 25

- **パート**（パート）兼职；计时工｜韩语参考：시간제 일 / 아르바이트<br>
  例：ごめんね。明日は朝からパートがあるのよ。（抱歉，明天一早我有兼职。）
- **倍**（ばい）倍｜韩语参考：배（倍） / 곱（倍） / 곱절（倍）<br>
  例：あの山はこの山の５倍の高さである。（那座山的高度是这座山的五倍。）
- **拝見**（はいけん）拜读；看｜韩语参考：뵙다 / 보다（겸양）<br>
  例：パスポートを拝見できますか。（能让我看一下您的护照吗？）
- **歯医者**（はいしゃ）牙医；牙科｜韩语参考：치과 의사 / 치과<br>
  例：今日歯医者へ行きました。（今天去看了牙医。）
- **場所**（ばしょ）地点；场所｜韩语参考：장소（场所，地点） / 처소（处所，场所）<br>
  例：このソファーは場所を取りすぎる。（这沙发太占地方了。）
- **はず**（はず）应该；理应｜韩语参考：~일 것이다 / ~해야 한다<br>
  例：トムは今にもここに来るはずです。（汤姆应该马上就要到这里了。）
- **発音**（はつおん）发音｜韩语参考：발음（发音）<br>
  例：あなたのお名前はどのように発音するのですか。（您的名字怎么念？）
- **はっきり**（はっきり）清楚；明确｜韩语参考：쏙（清楚地） / 뻔히（清楚，明显） / 또렷이（清晰地，明确地）<br>
  例：私はまだはっきりとは知らない。（我还不太清楚。）
- **花見**（はなみ）赏花；赏樱｜韩语参考：꽃구경（赏花，看花） / 꽃놀이（赏花）<br>
  例：花見ができる春が待ち遠しい。（盼着能赏樱的春天快点来。）
- **林**（はやし）树林｜韩语参考：숲（树林） / 수풀（树林，树丛）<br>
  例：林に竹が目立つ。（树林里竹子很显眼。）
- **払う**（はらう）支付；掸掉｜韩语参考：지불하다 / 털다<br>
  例：ジャックはブラシで上着のほこりを払った。（杰克用刷子刷掉了外套上的灰。）
- **番組**（ばんぐみ）节目｜韩语参考：프로（节目，节目单） / 프로그램（节目，节目单）<br>
  例：今晩どんな番組がありますか。（今晚有什么节目？）
- **反対**（はんたい）反对；相反｜韩语参考：반대（反，相反）<br>
  例：この考えには反対せざるをえない。（我不得不反对这个想法。）
- **ハンドバッグ**（ハンドバッグ）手提包｜韩语参考：손가방（手提包） / 핸드백（手提包，手包）<br>
  例：私のハンドバッグをどうしたの？（你把我的手提包怎么了？）
- **火**（ひ）火｜韩语参考：불（火）<br>
  例：いすをもっと火の近くに寄せなさい。（把椅子往火边再挪近些。）
- **日**（ひ）日子；太阳｜韩语参考：해（太阳）<br>
  例：冬が近づくにつれて日が短くなる。（随着冬天临近，白天越来越短。）
- **ピアノ**（ピアノ）钢琴｜韩语参考：피아노（钢琴）<br>
  例：ナンシーはピアノを持っています。（南希有一架钢琴。）
- **冷える**（ひえる）变冷；冷却｜韩语参考：추워지다（变冷，冷起来）<br>
  例：冷えたビールがあればたまらないね。（要是有冰镇啤酒就太棒了。）
- **光**（ひかり）光；光线｜韩语参考：빛（光，光线）<br>
  例：光が世にやって来た。（光来到了世上。）
- **光る**（ひかる）发光；闪耀｜韩语参考：빛나다（发光，照射）<br>
  例：上部前方で何かが光っている。（前方上方有什么东西在发光。）
- **引き出し**（ひきだし）抽屉｜韩语参考：서랍（抽屉）<br>
  例：きれいなタオルは引き出しにありますよ。（干净的毛巾在抽屉里。）
- **引き出す**（ひきだす）取出；提取｜韩语参考：인출하다（支取，提取） / 찾아가다（取，取回，领取，提取）<br>
  例：彼のいいところを引き出すようにしなさい。（要设法把他好的一面引导出来。）
- **ひげ**（ひげ）胡子｜韩语参考：수염<br>
  例：お父さんがバスルームでひげを剃っている。（爸爸在浴室里刮胡子。）
- **飛行場**（ひこうじょう）机场｜韩语参考：비행장（机场）<br>
  例：その島の飛行場は、今では草がぼうぼうだ。（那个岛上的机场如今杂草丛生。）
- **久しぶり**（ひさしぶり）好久不见｜韩语参考：오랜만（好久，久违） / 오래간만（好久，久违）<br>
  例：彼女から久しぶりに電話があった。（好久没联系的她打来了电话。）

## 语法

- **〜のに（purpose）**：用于…；做…需要
  接续：动词辞书形 + のに（用途・所需）；名词 + に
  朝鲜语：-는 데（韩语 -는 데 与用途、所需的 のに 对应（걷는 데 20분 걸린다）；日语 のに 与转折的 のに 同形，韩语则用 데 区分。）
- **〜ので**：因为…；由于…
  接续：动词普通形／い形容词 + ので；な形容词+な／名词+な + ので
  朝鲜语：-아서/어서（韩语 -아서/어서 与 ので 都表客观原因，但日语 ので 可接意志、请求，韩语 -아서/어서 后项一般不能是命令、劝诱。）
- **〜て（reason）**：因为…（造成某种状态）
  接续：动词て形／い形容词去い+くて／な形容词・名词+で
  朝鲜语：-아서/어서（韩语 -아서/어서 与 て 的原因用法对应，但日语 て 形还可表并列、先后，功能更多；韩语需靠上下文或另加连接词。）
