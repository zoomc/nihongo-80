今日语法 2 条

普通形 + はずがない
動詞・い形普通形 + はずがない；な形容詞 + な／名詞 + の + はずがない
普通形 + はずがない
不可能…；理应不会…
根据事实/常识强烈否定某可能性；比单纯「ない」更有推断依据。
彼が約束を忘れるはずがありません。
他不可能忘记约定。
電車が止まっているので、今到着するはずがありません。
电车停了，现在不可能到达。
朝鲜语：-(으)ㄹ 리가 없다
韩语ㄹ 리가 없다表绝不可能，推断依据强；与单纯否定안不同，同日语はずがない。
易错点

彼が来るはずがないでした。 → 彼が来るはずがありませんでした。（はずがない 是现在否定，过去用「はずがありませんでした／はずがなかったです」；ないでした 不合法。）

〜わけだ
普通形 + わけだ；ナ形容词 + な + わけだ；名词 + という + わけだ
〜わけだ
难怪…；也就是说…
由已知事实推出结论，常与「どうりで」呼应。
三年も中国に住んでいたんですか。だから中国語が上手なわけですね。
在中国住了三年啊。难怪你中文这么好。
窓が全部開いている。どうりで寒いわけだ。
窗户全开着。难怪这么冷。
この本は三百ページだから、一日に二十ページ読めば、十五日で読み終わるわけだ。
这本书三百页，一天读二十页的话，也就是十五天读完。
朝鲜语：-는 셈이다
韩语「-는 셈이다」侧重“算作某种结果”；日语「わけだ」更强调说话人由事实推导的过程，常带“原来如此”的领悟语气。
易错点

窓が全部開いている。どうりで寒いわけだです。 → …寒いわけですね。（「わけだ」本身已是普通体断定，礼貌说法整体变成「わけです」，不能再叠「です」。）
