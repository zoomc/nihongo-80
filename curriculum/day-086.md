# Day 086 · 〜くせに、〜から〜にかけて、〜ぶり

- 阶段：P4｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜くせに**：明明…却…
  接续：动词普通形/い形容词/ナ形容词な/名词の + くせに
  朝鲜语：-(으)ㄴ/는 주제에（알면서도 모르는 척한다 较中性；说 知っているくせに 则明确带责备，可对照 아는 주제에。客观写作或向不熟的人说话时常用 のに 等较中性的表达。）
- **〜から〜にかけて**：从…到…期间
  接续：名词 + から + 名词 + にかけて
  朝鲜语：-에서 -에 걸쳐（韩语「-에서 -에 걸쳐」与「から〜にかけて」对应，都偏书面；日语中间不能插「まで」。）
- **〜ぶり**：隔了…才；…的样子
  接续：表示时间间隔：期间名词 + ぶり，如 五年ぶり；表示做事的样子：名词或动词词干 + ぶり，如 仕事ぶり、話しぶり。
  朝鲜语：-만에（韩语「-만에」与「ぶりに」对应；但日语「ぶり」还能接动词词干表“…的样子」（仕事ぶり），韩语不能直译。）
