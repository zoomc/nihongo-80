今日语法 3 条

V意志形 + と 思う / と する
打算…／正要…、试图…
動詞 意志形（五段 お段+う／一段 よう／する→しよう／来る→こよう）+ と 思う／と する
(よ)うと思う 表说话人打算（现在/将来）；(よ)うとする 表正要开始做或尝试做
니치요우비와에이가오미요우토오모떼이마스.
日曜日は映画を見ようと思っています。
周日打算看电影。
데카케요우토시타라,아메가후떼키마시타.
出かけようとしたら、雨が降ってきました。
正要出门时下起雨来了。
朝鲜语：-(으)ㄹ 생각이다 / -(으)려고 하다
韩语打算用ㄹ 생각이다，正要或试图用려고 하다；日语と思う还含推测，韩语更明确表意志。
易错点

映画を見ると思います。 → 映画を見ようと思います。（「打算看」须用意志形 見よう；用辞书形 見る 变成「觉得会看」，中文「想看」直译错）

N / Vた形 / V辞書形 / Vて + ばかり
刚…；净是…、只…；一味…
名詞 + ばかり；動詞 た形 + ばかり（刚做完）；辞書形 + ばかり（只等/只剩）；て形 + ばかり いる（光顾着做）
多义：①刚…②净/只③一味做；数量或程度超出预期，常带负面语感
니뽄니키타바카리데스.
日本に来たばかりです。
刚来日本不久。
카레와게이무바카리시테이마스.
彼はゲームばかりしています。
他光打游戏。
코노미세와네담바카리타카쿠테,아지와후쓰우데스.
この店は値段ばかり高くて、味は普通です。
这家店光价格贵，味道一般。
朝鲜语：방금 / -만 / -기만 하다
韩语「刚」用방금、「只」用만、「一味」用기만 하다，三义分用；日语ばかり一形靠语境。
易错点

日本に来るばかりです。 → 日本に来たばかりです。（「刚来」用 た形 来たばかり，不能用辞书形；中文「刚」直译不体现 た 易错）

V辞書形/Vている/Vた形 + ところ(だ/に/を/で)
正要…／正在…／刚…；在…时候；…之际
辞書形 + ところだ（正要）；ている + ところだ（正在）；た形 + ところだ（刚做完）；ところに/を/で 后接外部动作或发现
把动作切成「即将/进行/刚完」的时间点；ところを 多用于被看见/被打断（含被动、抱歉语气）
이마카라데카케루토코로데스.
今から出かけるところです。
正要出门。
고한오타베테이루토코로니덴와가카카떼키마시타.
ご飯を食べているところに電話がかかってきました。
正吃饭时来了电话。
에키니쓰이타토코로데스.
駅に着いたところです。
刚到车站。
朝鲜语：-(으)려고 하다 / -고 있다 / -(으)ㄴ 참이다
韩语正要려고 하다、正在고 있다、刚ㄴ 참이다；日语ところだ按だ/に/を/で四形变化。
易错点

今から出かけたところです。 → 今から出かけるところです。（「正要出门」用 辞书形 出かけるところ；た形 变成「刚出去」，中文「正要」直译错）
