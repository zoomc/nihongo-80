Day 058 · N / 普通形 + ばかりか、Vます形(去ます) + ようがない / ようもない、N / Vます形(去ます) + がちだ

语法 3 条

N / 普通形 + ばかりか
不仅…而且…
名詞 + ばかりか；動詞・い形 普通形 + ばかりか；な形・名詞 + な/である + ばかりか
前项已成立，后项进一步追加，常与「も／まで」呼应；后项多比前项程度更高。
韩语对应-(으)ㄹ 뿐만 아니라
韩语뿐만 아니라表不仅而且，后项可同程度；日语ばかりか后项常程度更高，还可接まで/も。
코노미세 와 야스이 바카리 카, 아지 모 오이시이데스.
この店は安いばかりか、味も美味しいです。
这家店不仅便宜，味道也好。
카레 와 시고토 바카리 카, 카지 모 요쿠테쓰다이마스.
彼は仕事ばかりか、家事もよく手伝います。
他不仅工作，还经常帮忙做家务。
易错易混点
  • ✗ 英語のばかりか、中国語も話せます。✓ 英語ばかりか、中国語も話せます。名词接 ばかりか 不加 の。
  • ✗ この店は安いばかりかで、味もいいです。✓ この店は安いばかりか、味もいいです。ばかりか 后面不接 で，直接接后项。
Vます形(去ます) + ようがない / ようもない
발음V마스카타치 + 요우가나이 / 요우모나이
无法…；没有办法…
動詞ます形去ます + ようがない；する→しようがない；句末 ようがありません
表示想做但客观上没有手段/方法，不是能力不足；常与「〜たくても」呼应。
韩语对应-(으)ㄹ 방법이 없다
韩语ㄹ 방법이 없다表无手段，与能力不足的ㄹ 수 없다区分；同日语ようがない与できない之别。
나마에 모 주우쇼 모 와카라나이노데, 렌라쿠시요우 가 아리마센.
名前も住所も分からないので、連絡しようがありません。
姓名和住址都不知道，所以没法联系。
덴겐 가 하이라나이노데, 나오시요우 가 아리마센.
電源が入らないので、直しようがありません。
电源打不开，所以没法修。
易错易混点
  • ✗ 名前も分からないので、連絡するようがありません。✓ 連絡しようがありません。ようがない 接ます形词干（し），不接辞书形。
  • ✗ 電源が入らないので、直すようがないです。✓ 直しようがありません。ようがない 接ます形词干（直し），不接辞书形 直す。
N / Vます形(去ます) + がちだ
발음N / V마스카타치 + 가치다
容易…；往往…（多指不好的倾向）
名詞 + がちだ；動詞ます形去ます + がちだ；がちな + 名詞
表示某种（多负面）倾向容易发生；常用「〜がちです／がちな人」。
韩语对应-기 쉽다 / -는 경향이 있다
韩语기 쉽다表容易(中性)，负面倾向用는 경향이 있다；日语がちだ多负面，语感更窄。
아사 와 덴샤 가 오쿠레가치데스.
朝は電車が遅れがちです。
早上电车容易晚点。
이소가시이지키 와, 쇼쿠지 가 후키소쿠 니 나리가치데스.
忙しい時期は、食事が不規則になりがちです。
忙碌时期，饮食容易不规律。
易错易混点
  • ✗ 彼は病気がちなです。✓ 彼は病気がちです。がち 按な形容词变化，接 です 就说 がちです，不能说 がちなです。
  • ✗ 朝は電車が遅れがちな。✓ 朝は電車が遅れがちです。がちな 后面必须跟名词；一句话结尾用 がちだ／がちです。
