今日语法 4 条

〜おう / 〜よう
발음〜오우 / 〜요우
…吧；我要…
五段动词词尾改お段+う；一段动词去る+よう；する→しよう；来る→来よう
表示提议、劝诱或说话人自己的意志，口语中常用于自言自语。
쓰카레타네.스코시야스모우.
疲れたね。少し休もう。
累了吧，稍微休息一下吧。
슈우마쓰,이쑈니에이가오미요우요.
週末、一緒に映画を見ようよ。
周末一起去看电影吧。
よし、今日から毎日日記を書こう。
好，从今天起我每天写日记。
朝鲜语：-자 / -(으)ㄹ게
韩语 -자 表提议，-(으)ㄹ게 表说话人意志；日语同一个意志形兼表两者，靠语境和语气区分。
易错点

週末、一緒に映画を見ろうよ。 → 週末、一緒に映画を見ようよ。（見る 是上一段动词，意志形是「見よう」，不是「見ろう」）

〜(よ)うと思う
발음〜우토오모우
我想…；打算…
动词意志形 + と思う／と思っている
表示说话人正在考虑或已下的决心，持续想法用「と思っている」。
코토시노나쓰와우미니이코우토오모떼이마스.
今年の夏は海に行こうと思っています。
今年夏天我想去海边。
아시타와하야쿠오키테,코우엔오하시로우토오모우.
明日は早く起きて、公園を走ろうと思う。
我打算明天早起去公园跑步。
아타라시이파소콘오카오우토오모따케도,야메마시타.
新しいパソコンを買おうと思ったけど、やめました。
我本来想买台新电脑，后来放弃了。
朝鲜语：-(으)려고 하다
韩语 -(으)려고 하다 与 ようと思う 对应；但日语用「と思っている」可表持续的想法，韩语则靠现在时或 고 있다 区分。
易错点

今年の夏は海に行きようと思っています。 → 今年の夏は海に行こうと思っています。（行く 是五段动词，意志形是「行こう」，不是「行きよう」）

〜え / 〜ろ
발음〜에 / 〜로
（命令）做！
五段动词词尾改え段；一段动词去る+ろ；する→しろ；来る→来い
表示强烈的命令，语气粗鲁，多用于男性或紧急场合。
하야쿠오키로!치코쿠스루조.
早く起きろ！遅刻するぞ。
快起来！要迟到了！
아부나이!토마레!
危ない！止まれ！
危险！停下！
감바레!아토스코시다!
がんばれ！あと少しだ！
加油！就差一点了！
朝鲜语：-아/어라
韩语 -아/어라 与命令形对应，但韩语还有 -(으)세요 等礼貌命令；日语命令形语气更硬，且来る 的命令形是特殊形「来い」。
易错点

危ない！止まりろ！ → 危ない！止まれ！（止まる 的命令形是「止まれ」，不是「止まりろ」）

〜な（prohibition）
발음〜나
不许…；别…
动词辞书形 + な
表示强烈的禁止，多用于告示、男性口语或紧急提醒。
아부나이카라,코노카와데와오요구나.
危ないから、この川では泳ぐな。
这里很危险，不要在这条河里游泳。
모우나쿠나.다이조우부다요.
もう泣くな。大丈夫だよ。
别哭了，没事的。
카베니「코코니고미오스테루나」토카이테아루.
壁に「ここにごみを捨てるな」と書いてある。
墙上写着“请勿在此倒垃圾”。
朝鲜语：-지 마라
韩语 -지 마라 与禁止形对应，语气同样强硬；日语禁止形只接辞书形，韩语则接词干，接续方式不同。
易错点

危ないから、この川では泳がないな。 → 危ないから、この川では泳ぐな。（禁止形是辞书形+な，不是ない形+な）
