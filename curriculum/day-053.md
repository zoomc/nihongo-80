## 3. 新语法（含先修）
- `G0076` **N + に 対して / に 関して** — 对…（针对对象/对比）／关于…（书面）｜接续：名詞 + に対して（动作/态度的对象，或「与此相对」的对比）；名詞 + に関して（＝について 的书面语）
- `G0077` **N / V辞書形 + に 伴って / に つれて / に 従って** — 随着…（前项变化，后项也跟着变化）｜接续：名詞 + に／動詞 辞書形 + に + 伴って・つれて・従って；后项须是变化动词（増える／変わる／高くなる 等）

## 4. 新汉字（中日差异）
- `K0111` **給** 音:キュウ 训:｜中文「给」gěi/jǐ；日语 給 音读 キュウ，「給料」きゅうりょう 是「工资」；简体「给」与「給」不同，中文「给料」易误解为「发放材料」，不能靠汉字猜词。
- `K0112` **報** 音:ホウ 训:むくいる｜中文「报」bào；日语 報 音读 ホウ，「報告」ほうこく 汇报、「情報」じょうほう 信息（≠中文「情报」多指间谍情报）；简体「报」与「報」不同，不能按中文义域推。
