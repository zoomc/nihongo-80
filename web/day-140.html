今日语法 1 条

〜をはじめ
발음〜오하지메
以…为代表，包括…
名词 + をはじめ / 名词 + をはじめとして / 名词 + をはじめとする + 名词
韩语对应을 비롯해
韩语提示按整块理解。换成日语时先套接续「名词 + をはじめ / 名词 + をはじめとして / 名词 + をはじめとする + 名词」，再看下面的例句。
京都には、金閣寺をはじめ、多くの有名な寺がある。
Kyoto has many famous temples, including Kinkakuji.
社長をはじめとして、社員全員がこの計画に賛成した。
Everyone in the company, starting with the president, agreed to this plan.
