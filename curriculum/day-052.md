# Day 052 · 〜な（prohibition）、〜なさい、〜ば

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜な（prohibition）、〜なさい、〜ば」造两句自己的话，表达：不许…；别…；（长辈指示）做…；如果…

## 新词 22

- **動物園**（どうぶつえん）动物园｜韩语参考：동물원（动物园）<br>
  例：コンドルは動物園では決して育たない。（神鹫在动物园里从不繁殖。）
- **遠く**（とおく）远处｜韩语参考：멀리（远处，远方）<br>
  例：遠くにぼんやりした明かりが見えた。（远处隐约看见一点灯光。）
- **通る**（とおる）通过；经过｜韩语参考：통하다（通，通过，流经） / 지나가다（通过，路过） / 통과되다（通过，许可，合格）<br>
  例：私は毎日その教会の前を通る。（我每天从那座教堂前经过。）
- **特に**（とくに）特别；尤其｜韩语参考：특히（特别，尤其，尤为）<br>
  例：私は音楽、特にロックが大好きだ。（我喜欢音乐，尤其是摇滚。）
- **特別**（とくべつ）特别｜韩语参考：특별（特别）<br>
  例：特別料理がございますが。（我们有特别料理。）
- **とこや**（とこや）理发店｜韩语参考：이발소<br>
  例：おや、床屋へ行ってきたのだね。（哎，你去理发店了吧。）
- **特急**（とっきゅう）特快列车｜韩语参考：특급（特快）<br>
  例：時計がおくれていたので、私は特急にのりそこねた。（因为表慢了，我没赶上特快列车。）
- **届ける**（とどける）送达；申报｜韩语参考：전달하다 / 신고하다<br>
  例：家に届けていただけますか。（能送到我家吗？）
- **泊まる**（とまる）住宿；投宿｜韩语参考：투숙하다（投宿，住店）<br>
  例：私は先週おじの家に泊まりました。（我上周住在叔叔家。）
- **止める**（とめる）停下；阻止｜韩语参考：세우다（使停下）<br>
  例：急にジムは銀行の前で車を止めた。（吉姆突然把车停在银行前。）
- **取り替える**（とりかえる）更换；调换｜韩语参考：갈다（换，更换） / 바꾸다（更换，互换，对调）<br>
  例：これを青いのと取り替えてください。（请把这个换成蓝色的。）
- **泥棒**（どろぼう）小偷｜韩语参考：도둑（小偷，盗贼，窃贼）<br>
  例：そこの乞食が泥棒である事がわかった。（那个乞丐原来是小偷。）
- **どんどん**（どんどん）不断；一个劲｜韩语参考：계속 / 점점<br>
  例：だれかがドアをどんどんたたいている。（有人在不停地敲门。）
- **治る**（なおる）痊愈；治好｜韩语参考：낫다（痊愈）<br>
  例：２週間もすれば自然に治ります。（过两周就会自然痊愈。）
- **直る**（なおる）修好；改正｜韩语参考：고쳐지다 / 낫다<br>
  例：いったい、いつになったらそのケチは直るの？（到底什么时候你才能改掉那小气的毛病？）
- **中々**（なかなか）相当；怎么也（不）｜韩语参考：상당히 / 좀처럼（부정과 함께）<br>
  例：試験中はなかなか大変だった。（考试期间相当辛苦。）
- **泣く**（なく）哭｜韩语参考：울다（哭，哭泣）<br>
  例：ビルは何時間も泣き続けた。（比尔哭了好几个小时。）
- **亡くなる**（なくなる）去世｜韩语参考：가다（去世） / 돌아가다（去世，逝世）<br>
  例：父が亡くなってから３年になります。（父亲去世已经三年了。）
- **無くなる**（なくなる）不见；用完｜韩语参考：없어지다（没有了，不见了）<br>
  例：あなたの青いペンがなくなってしまいました。（你的蓝笔不见了。）
- **投げる**（なげる）扔；投｜韩语参考：던지다（投，掷，扔）<br>
  例：その子は犬に石を投げた。（那个孩子朝狗扔石头。）
- **鳴る**（なる）响；鸣｜韩语参考：울다（响，鸣） / 치다（敲，响） / 울리다（响，鸣）<br>
  例：電話が鳴ったらただちに出なさい。（电话一响就马上接。）
- **なるべく**（なるべく）尽量｜韩语参考：되도록（尽量） / 될 수 있는 대로（尽量）<br>
  例：なるべく安いほうがいいです。（尽量便宜一点的好。）

## 语法

- **〜な（prohibition）**：不许…；别…
  接续：动词辞书形 + な
  朝鲜语：-지 마라（韩语 -지 마라 与禁止形对应，语气同样强硬；日语禁止形只接辞书形，韩语则接词干，接续方式不同。）
- **〜なさい**：（长辈指示）做…
  接续：动词ます形去ます + なさい
  朝鲜语：-아/어라（韩语 -(으)세요 是礼貌命令，-아/어라 是强硬命令；日语 なさい 介于两者之间，专用于上对下，韩语没有完全对应的专用形式。）
- **〜ば**：如果…
  接续：五段动词词尾改え段+ば；一段动词去る+れば；い形容词去い+ければ；な形容词・名词+なら
  朝鲜语：-(으)면（韩语 -(으)면 与 ば 对应，但日语 ば 的后项一般不能是意志、命令；韩语 -(으)면 没有这个限制。）
