今日语法 2 条

普通形 + 一方(で) / 反面 / 代わりに
動詞・い形普通形／な形容词 + な／名词 + である + 一方(で)・反面；名詞 + の／普通形 + 代わりに
普通形 + 一方(で) / 反面 / 代わりに
一方面…另一方面…／…但另一方面／取而代之、作为交换
一方で 并列同一事物的两面（可同褒贬）；反面 强调「反面/弊端」；代わりに 是替代或交换条件
この仕事は給料が高い一方で、残業も多いです。
这工作工资高，另一方面加班也多。
便利な反面、費用がかかります。
方便是方便，反面花费也高。
朝鲜语：-는 한편 / -반면에 / -대신에
韩语는 한편表一方面、반면에表相反、대신에表代替，与日语三形对应整齐，반면对比更强。
易错点

便利だ一方で、費用がかかります。 → 便利な一方で、費用がかかります。（な形/名词 接 一方で 用 便利な／である，不用 だ；中文「方便一方面」直译保留 だ 错）

V辞書形 / Nの + たびに
動詞辞書形 + たびに；名詞 + の + たびに（する名詞可直接 するたびに）
V辞書形 / Nの + たびに
每当…就…；每次…都…
表示每次发生前项时，后项都随之发生；后项多为反复出现的习惯或自然结果，不用一次性的命令、请求。
大阪へ出張するたびに、この店に寄ります。
每次去大阪出差，都会来这家店。
会議のたびに、資料を準備します。
每次开会都准备资料。
朝鲜语：-(으)ㄹ 때마다
韩语때마다表每当，接名词或动词定语形；日语たびに只接辞书形或の，后项限制更严。
易错点

大阪へ出張するのたびに、この店に寄ります。 → 大阪へ出張するたびに、この店に寄ります。（辞书形后接 たびに 不加 の；の 只能接名词。中文“每次去…”直译容易多写の。）
