# Day 018 · 〜で（means）、〜と（and）、〜と（with）

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜で（means）**：用…；靠…；以…
  接续：名词（工具／手段／语言／材料）+ で
  朝鲜语：로/으로（수단）（연필로 쓰다／鉛筆で書く，일본어로 말하다／日本語で話す，都是用同一个助词表示工具或手段。）
- **〜と（and）**：…和…（全部列举）
  接续：名词 + と + 名词（全部列举）
  朝鲜语：와/과（韩语 와/과 与 と 对应，随收音换形；日语 と 还可表引用和共同对象，功能比韩语 와/과 更广。）
- **〜と（with）**：和…一起
  接续：名词（人）+ と（共同）
  朝鲜语：와/과 함께（韩语 와/과 可表共同，但口语更常用 하고；日语 と 后常可加 いっしょに，韩语 함께 的位置较固定。）
