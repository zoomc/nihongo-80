# Day 055 · 〜すぎる、〜方

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜すぎる、〜方」造两句自己的话，表达：过于…；…过头；…的方法；…的方式

## 新词 20

- **進む**（すすむ）前进；有进展｜韩语参考：나가다（进行，进展） / 나아가다（前进） / 진행되다（前行，前进）<br>
  例：英語の勉強は進んでいますか？（英语学习进展顺利吗？）
- **すっと**（すっと）一下子；顺畅地｜韩语参考：쑥 / 순조롭게<br>
  例：カタツムリがすっと角を出した。（蜗牛一下子伸出了触角。）
- **ステーキ**（ステーキ）牛排｜韩语参考：스테이크（牛排）<br>
  例：ステーキの焼き方はどうなさいますか。（牛排您要几分熟？）
- **捨てる**（すてる）扔掉；抛弃｜韩语参考：버리다（抛弃，遗弃） / 내다버리다（扔出，扔掉）<br>
  例：そんな計画は捨ててしまいなさい。（那种计划就扔掉吧。）
- **ステレオ**（ステレオ）音响｜韩语参考：스테레오（立体声，立体音响，立体声装置）<br>
  例：私はあの店で新しいステレオを買った。（我在那家店买了新的音响。）
- **砂**（すな）沙子｜韩语参考：모래<br>
  例：後ろ足で砂をかけるようなことをした。（他干出了忘恩负义的事。）
- **すばらしい**（すばらしい）极好；出色｜韩语参考：훌륭하다<br>
  例：その日は実にすばらしい日だった。（那天真是美好的一天。）
- **滑る**（すべる）滑；打滑｜韩语参考：타다（溜，滑） / 미끄러지다（滑倒，滑）<br>
  例：来年はうまく滑れるようになるでしょう。（明年你应该就能滑得很好吧。）
- **隅**（すみ）角落｜韩语参考：모（角落） / 구석（角，角落）<br>
  例：隅のテーブルがいいのですが。（我想要角落的那张桌子。）
- **済む**（すむ）结束；了事｜韩语参考：끝나다（结束，完成） / 끝장나다（结束，收场）<br>
  例：１０時ちょっと前に仕事が済んだ。（快到十点时工作结束了。）
- **すり**（すり）扒手｜韩语参考：소매치기<br>
  例：すりは人ごみの中に消えた。（扒手消失在人群里。）
- **すると**（すると）于是；那么｜韩语参考：그러자 / 그러면<br>
  例：するとあなたは幸せでしょう。（那样的话你就会幸福吧。）
- **生活**（せいかつ）生活｜韩语参考：생활（生活）<br>
  例：どのようにして生活していきますか。（你打算怎么生活下去？）
- **生産**（せいさん）生产｜韩语参考：생산（生产）<br>
  例：この工場はＣＤプレーヤーを生産している。（这家工厂生产CD播放机。）

## 语法

- **〜すぎる**：过于…；…过头
  接续：动词ます形去ます／い形容词去い／な形容词词干 + すぎる
  朝鲜语：너무 …하다（韩语用「너무」+形容词，位置在词前；日语 すぎる 是后缀，接在词干后，且可用于动词（食べすぎる），韩语需说 너무 많이 먹다。）
- **〜方**：…的方法；…的方式
  接续：动词ます形去ます + 方（かた）
  朝鲜语：-는 방법（韩语 -는 방법 与 方 对应；但日语 方 直接接ます形去ます构成复合名词，韩语则用定语形加方法。）
