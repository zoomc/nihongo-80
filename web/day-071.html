今日语法 3 条

〜うちに
발음〜우치니
趁着…；在…过程中
动词辞书形/ている/ない形 + うちに；い形容词 + うちに；ナ形容词 + な + うちに；名词 + の + うちに
表示在某状态持续期间做某事，或期间不知不觉发生变化。
韩语对应-는 동안에
韩语「-는 동안에」只表时间范围；日语「うちに」还含“趁还没变、赶在期限前”的语感。
와카이우치니,이로이로나쿠니오료코우시타호우가이이.
若いうちに、いろいろな国を旅行したほうがいい。
趁年轻多去几个国家旅行比较好。
스푸가사메나이우치니,도우조메시아가떼쿠다사이.
スープが冷めないうちに、どうぞ召し上がってください。
请趁汤还没凉快喝吧。
온가쿠오키이테이루우치니,이쓰노아이다니카네무떼시마따.
音楽を聞いているうちに、いつの間にか眠ってしまった。
听着音乐，不知不觉就睡着了。

易错点 若いのうちに、いろいろな国を旅行したほうがいい。 → 若いうちに（い形容词直接接「うちに」，不加「の」。）

〜ところに / 〜ところへ / 〜ところを
발음〜토코로니 / 〜토코로헤 / 〜토코로오
正当…的时候
动词辞书形/ている/た形 + ところに／ところへ／ところを
表示某动作正要发生或正在进行时，被另一事打断。
韩语对应-려는 참에
韩语常用「-려는 참에」表“正要做时”；日语按「に/へ/を」区分打断方式，韩语没有这种分工。
데카케요우토시테이루토코로니,토모다치카라덴와가카카떼키타.
出かけようとしているところに、友達から電話がかかってきた。
正要出门时，朋友打来了电话。
민나데키미노하나시오시테이루토코로헤,초우도키미가키타.
みんなで君の話をしているところへ、ちょうど君が来た。
我们正说你呢，你就来了。
주교우추우니스마호오미테이루토코로오,센세이니미라레테시마따.
授業中にスマホを見ているところを、先生に見られてしまった。
上课看手机被老师看见了。

易错点 出かけるのところに、友達から電話がかかってきた。 → 出かけるところに（「ところ」前接动词时不能加「の」，「のところ」只接名词。）

〜ば〜ほど
발음〜바〜호도
越…越…
动词ば形 + 同一动词辞书形 + ほど；い形容词ければ + い形容词 + ほど；ナ形容词なら + ナ形容词な + ほど
表示随着前项程度加深，后项程度也随之变化。
韩语对应-면 -ㄹ수록
韩语「-ㄹ수록」一个形式即可；日语要把同一词重复两次（すればするほど），形式负担更重。
日本語は、勉強すればするほど面白くなる。
日语越学越有意思。
스마호노가멘와오오키케레바오오키이호도미야스이가,모치아루쿠노와타이헨다.
スマホの画面は大きければ大きいほど見やすいが、持ち歩くのは大変だ。
手机屏幕越大越容易看，但带着走很麻烦。
헤야가시즈카나라시즈카나호도,요쿠네무레루.
部屋が静かなら静かなほど、よく眠れる。
房间越安静，睡得越好。

易错点 日本語は、勉強するすればするほど面白くなる。 → 勉強すればするほど（前项必须用ば形「すれば」，「するすれば」不合法。）
