# Day 090 · 〜的、〜ような / 〜ように（like）

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜的、〜ような / 〜ように（like）」各造一句自己的话，表达：…上的；…式的；像…一样；如同…

## 新词 25

- **国会**（こっかい）国会｜韩语参考：국회（国会）<br>
  例：火曜日に国会が開かれる。（国会将在周二召开。）
- **国境**（こっきょう）国境｜韩语参考：국경（国境，边境）<br>
  例：明日中には国境を越えます。（明天之内就会越过国境。）
- **骨折**（こっせつ）骨折｜韩语参考：골절（骨折）<br>
  例：右腕を骨折したようです。（我的右臂好像骨折了。）
- **小包**（こづつみ）包裹｜韩语参考：소포（包裹）<br>
  例：この小包を船便で送ってください。（请把这个包裹寄海运。）
- **異なる**（ことなる）不同｜韩语参考：다르다（不同，不一致）<br>
  例：彼らの意見は私のとは異なっている。（他们的意见和我的不同。）
- **諺**（ことわざ）谚语｜韩语参考：속담（俗语，谚语）<br>
  例：このことわざが使われるのを聞いた事があります。（我听过有人用这句谚语。）
- **断る**（ことわる）拒绝｜韩语参考：거부하다（拒绝，反对） / 거절하다（拒绝，谢绝）<br>
  例：なぜ彼の申し出を断ったのですか。（你为什么拒绝了他的提议？）
- **粉**（こな）粉；面粉｜韩语参考：분（粉，粉末）<br>
  例：この小麦は粉にされる。（这些小麦被磨成面粉。）
- **好み**（このみ）喜好｜韩语参考：기호（嗜好，喜好，爱好） / 입맛（口味，喜好）<br>
  例：特にお好みの色とかおありですか。（您有特别喜欢的颜色吗？）
- **好む**（このむ）喜好｜韩语参考：좋아하다<br>
  例：彼は飛行機での海外旅行を好む。（他喜欢坐飞机出国旅行。）
- **コピー**（コピー）复印；副本｜韩语参考：복사（复印） / 카피（复制，复印） / 복사본（复印件，副本）<br>
  例：このページをコピーして下さい。（请把这一页复印一下。）
- **小麦**（こむぎ）小麦｜韩语参考：밀（小麦）<br>
  例：この小麦は粉にされる。（这些小麦被磨成面粉。）
- **小屋**（こや）小屋｜韩语参考：작은 집 / 오두막<br>
  例：遠くに小屋が見えた。（远处能看到一间小屋。）
- **これら**（これら）这些｜韩语参考：이것들<br>
  例：これらのクッキーは星の形をしている。（这些饼干是星星形状的。）
- **頃**（ころ）时候；左右｜韩语参考：녘（时候） / 무렵（时候，时分） / 언저리（左右）<br>
  例：おひる頃やっと太陽が顔を出した。（快到中午时太阳才露出来。）
- **殺す**（ころす）杀｜韩语参考：죽이다（杀，消弱）<br>
  例：おまえはオレを殺そうとしている。（你想杀了我。）
- **転ぶ**（ころぶ）摔倒｜韩语参考：넘어지다（跌倒，倒下，摔倒）<br>
  例：転んで手首を痛めました。（我摔倒伤了手腕。）
- **今回**（こんかい）这次｜韩语参考：이번（这次，这回）<br>
  例：今回はしくじれないぞ。（这次可不能失手。）
- **今後**（こんご）今后｜韩语参考：차후（此后，以后，今后，日后） / 향후（往后，此后，今后，从今以后）<br>
  例：今後気をつけなくてはなりません。（今后必须多加小心。）
- **こんなに**（こんなに）这么｜韩语参考：이리（这么，如此） / 이다지（如此，这么） / 이리도（如此，这么）<br>
  例：どうして帰りがこんなに遅くなったの。（怎么回来得这么晚？）
- **困難**（こんなん）困难｜韩语参考：곤란（困难，窘迫） / 어려움（困难）<br>
  例：彼の言ってる事を理解するのは困難だ。（要理解他说的话很困难。）
- **今日**（こんにち）今日；如今｜韩语参考：오늘 / 오늘날<br>
  例：彼は宿題を今日終えねばならない。（他今天必须把作业做完。）
- **コンピューター**（コンピューター）电脑｜韩语参考：컴퓨터（电脑）<br>
  例：そのコンピューターは新しいです。（那台电脑是新的。）
- **婚約**（こんやく）婚约；订婚｜韩语参考：약혼（订婚） / 정혼（订婚） / 혼약（婚约，订婚）<br>
  例：とうとう私の姉は婚約した。（我姐姐终于订婚了。）
- **混乱**（こんらん）混乱｜韩语参考：혼란（混乱，杂乱）<br>
  例：国会は混乱のうちに散会した。（国会在混乱中散会了。）

## 语法

- **〜的**：…上的；…式的
  接续：名词 + 的（てき）；修饰名词可用 的な，也有直接连接的词组，如経済的理由
  朝鲜语：-적（韩语「-적」来自同一汉字词，用法高度相似；但韩语接「으로/인」，日语换成「に/な」，词形对应不齐。）
- **〜ような / 〜ように（like）**：像…一样；如同…
  接续：名词 + の + ような/ように；普通形 + ような/ように
  朝鲜语：-같은（韩语「-같은」修饰名词、「-같이」修饰动词，分工与日语相似；但日语名词前必须加「の」，韩语不加。）
