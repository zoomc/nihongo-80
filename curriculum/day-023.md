# Day 023 · 〜の中で〜が一番、〜です

## 新词 25

- **緑**（みどり）绿色；绿｜韩语参考：초록（草绿，草绿色） / 초록색（草绿色）<br>
  例：東京ミッドタウンは緑がいっぱい！（东京中城绿意盎然！）
- **皆さん**（みなさん）大家；各位｜韩语参考：여러분（诸位，各位，大家）<br>
  例：皆さんじっとしていてください。（请大家别动。）
- **南**（みなみ）南；南方｜韩语参考：남쪽（南侧，南边，南方） / 남측（南侧，南边，南方）<br>
  例：フランスは英国の南にある。（法国在英国南边。）
- **耳**（みみ）耳朵｜韩语参考：귀（耳，耳朵） / 가는귀（灵敏的耳朵）<br>
  例：なぜ、あなたの耳はそんなに大きいの？（你的耳朵怎么这么大？）
- **みんな**（みんな）大家；全部｜韩语参考：말끔（干净地，利落地，全部） / 몽땅（都，全部）<br>
  例：女の子はほとんどみんなやさしい。（女孩子几乎都很温柔。）
- **六日**（むいか）六天；六号｜韩语参考：엿새 / 육 일<br>
  例：六日に病院へ行きます。（我六号去医院。）
- **向こう**（むこう）对面；那边｜韩语参考：건너（对面） / 고쪽（那边） / 그쪽（那边）<br>
  例：その男の子は向こうにいます。（那个男孩在对面。）
- **六つ**（むっつ）六个｜韩语参考：여섯 개<br>
  例：パンを六つ買いました。（我买了六个面包。）
- **村**（むら）村庄｜韩语参考：촌（村子，村庄，乡村） / 동네（小区，社区，村庄） / 마을（村子，村庄）<br>
  例：町は村よりも大きい。（镇比村大。）
- **目**（め）眼睛｜韩语参考：눈（眼睛）<br>
  例：彼女はきれいな目をしている。（她有一双漂亮的眼睛。）
- **持つ**（もつ）拿；持有｜韩语参考：갖다（持有，有） / 집다（握，拿） / 가지다（持有，有）<br>
  例：コートを持ちましょうか。（我来帮你拿外套吧？）
- **もっと**（もっと）更；更加｜韩语参考：더（更，更加） / 더욱（更加，进一步，越来越，愈加）<br>
  例：父がもっと長生きしていたらなあ。（父亲要是能多活几年就好了。）
- **物**（もの）东西；物品｜韩语参考：것（东西，事，的） / 물건（东西，物品，物件）<br>
  例：どちらのかばんがあなたの物ですか。（哪个包是你的？）
- **門**（もん）门；大门｜韩语参考：문（路，门，渠道，途径）<br>
  例：ジョンは門のところまで出てきた。（约翰一直走到门口。）
- **問題**（もんだい）问题；题目｜韩语参考：문제（题，问题）<br>
  例：問題はお金がないということです。（问题是我们没钱。）
- **八百屋**（やおや）蔬菜店｜韩语参考：채소 가게<br>
  例：その八百屋は客にとても親切だ。（那家菜店对客人很热情。）
- **易しい**（やさしい）容易；简单｜韩语参考：쉽다<br>
  例：もっと易しい事を聞いて下さい。（请问点简单些的。）
- **休み**（やすみ）休息；休假｜韩语参考：참（中间休息时间）<br>
  例：学校はクリスマスで休みになった。（学校因圣诞节放假了。）
- **八つ**（やっつ）八个｜韩语参考：여덟 개<br>
  例：そこに八つの小石があった。（那里有八颗小石子。）
- **山**（やま）山｜韩语参考：산（山）<br>
  例：その山はどれくらいの高さですか。（那座山有多高？）
- **やる**（やる）做；给｜韩语参考：하다 / 주다<br>
  例：５ドルをやる。（给你五美元。）
- **夕方**（ゆうがた）傍晚｜韩语参考：저녁（傍晚） / 저녁때（傍晚） / 저녁나절（晚上，傍晚）<br>
  例：ひょっとすると夕方前に雨になるかもしれない。（说不定傍晚前会下雨。）
- **夕飯**（ゆうはん）晚饭｜韩语参考：저녁（晚饭，晚餐） / 저녁밥（晚饭，晚餐）<br>
  例：夕飯はもう食べましたか。（晚饭吃过了吗？）
- **郵便局**（ゆうびんきょく）邮局｜韩语参考：우체국（邮局）<br>
  例：あの～郵便局はどちらでしょうか。（那个……邮局在哪儿呢？）
- **昨夜**（ゆうべ）昨晚｜韩语参考：어젯밤<br>
  例：昨夜はよく眠れましたか。（昨晚睡得好吗？）

## 语法

- **〜の中で〜が一番**：在…中最…
  接续：名词（范围）+ の中で + 名词 + が一番 + 形容词
  朝鲜语：… 중에서 …이 가장（韩语 중에서 与 の中で 对应，가장/제일 与 一番 对应；语序上韩语 가장 在形容词前，日语 一番 也在形容词前，较接近。）
- **〜です**：是…（礼貌断定）
  接续：名词／な形容词 + です；い形容词 + です
  朝鲜语：입니다（韩语正式礼貌判断常用 입니다，例如 학생입니다、의사입니다；日常礼貌体可用 이에요／예요，形式受词尾影响。日语名词与な形容词常接です。）
