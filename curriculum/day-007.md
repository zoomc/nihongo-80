# Day 007 · と（并列／共同／引用）、から ～ まで

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「と（并列／共同／引用）、から ～ まで」造两句自己的话，表达：和…／与…（一起）；「…」地；从…到…

## 新词 20

- **映画**（えいが）电影｜韩语参考：영화（电影）<br>
  例：映画を見ます。（看电影。）
- **音楽**（おんがく）音乐｜韩语参考：음악（音乐）<br>
  例：音楽を聞きます。（听音乐。）
- **食べる**（たべる）吃｜韩语参考：먹다（吃）<br>
  例：ご飯を食べます。（吃饭。）
- **飲む**（のむ）喝；吞（药）｜韩语参考：먹다（喝） / 마시다（喝，饮） / 들이마시다（喝）<br>
  例：水を飲みます。（喝水。）
- **行く**（いく）去｜韩语参考：가다<br>
  例：学校へ行きます。（去学校。）
- **来る**（くる）来｜韩语参考：오다（来，来到） / 나오다（来，出来）<br>
  例：友達が来ます。（朋友要来。）
- **見る**（みる）看；观看｜韩语参考：보다（看）<br>
  例：映画を見ます。（看电影。）
- **買う**（かう）买｜韩语参考：끊다（买） / 받다（买，沽） / 뽑다（买，购买）<br>
  例：本を買います。（买书。）
- **する**（する）做；干｜韩语参考：들다（做，服侍，伺侯）<br>
  例：宿題をします。（做作业。）
- **ある**（ある）有；存在（无生命）｜韩语参考：있다（사물）<br>
  例：机の上に本があります。（桌上有书。）
- **いる**（いる）有；在（有生命）｜韩语参考：있다（사람·동물）<br>
  例：部屋に猫がいます。（房间里有猫。）
- **なる**（なる）变成；成为｜韩语参考：되다（成为，变为）<br>
  例：医者になりました。（当上医生了。）
- **書く**（かく）写｜韩语参考：쓰다（写） / 적다（写）<br>
  例：名前を書いてください。（请写名字。）
- **読む**（よむ）读；念｜韩语参考：읽다（读，朗读）<br>
  例：本を読みます。（读书。）
- **話す**（はなす）说；讲｜韩语参考：말하다（说，讲） / 얘기하다（说，讲）<br>
  例：日本語を話します。（说日语。）
- **聞く**（きく）听；问｜韩语参考：듣다（听） / 묻다（问） / 질문하다（提问，问）<br>
  例：音楽を聞きます。（听音乐。）
- **待つ**（まつ）等；等待｜韩语参考：참다（忍耐，等待） / 기다리다（等，等待）<br>
  例：駅で友達を待ちます。（在车站等朋友。）
- **乗る**（のる）乘；坐（车船）｜韩语参考：타다（乘，乘坐） / 오르다（上，乘，骑） / 올라타다（乘，搭）<br>
  例：電車に乗ります。（上电车。）
- **降る**（ふる）下（雨、雪等）｜韩语参考：오다（下，来） / 내리다（下，落）<br>
  例：雨が降っています。（正在下雨。）
- **起きる**（おきる）起床；起来｜韩语参考：일어나다（起，起来）<br>
  例：七時に起きます。（七点起床。）

## 语法

- **と（并列／共同／引用）**：和…／与…（一起）；「…」地
  接续：名詞 + と + 名詞／動詞；引用从句 + と + 思う/言う
  朝鲜语：와/과 / 하고 / (이)라고（韩语并列用와/과、口语하고，引用用라고且随词性变；日语と一形通用。）
- **から ～ まで**：从…到…
  接续：名詞（时/处） + から + 名詞 + まで
  朝鲜语：부터 ~ 까지（韩语起点用부터、终点까지，与日语基本对应；但韩语时间起点口语可用에，日语から不可省。）
