## 新词 25

- **共通**（きょうつう）共同；共通｜韩语参考：공통（共通，共同）<br>
  例：私と彼は共通することが多い。（我和他有很多共同点。）
- **共同**（きょうどう）共同｜韩语参考：공동（共同，联合） / 합동（共同，联合）<br>
  例：私は妹と共同で部屋を使っている。（我和妹妹合用一间房。）
- **恐怖**（きょうふ）恐惧｜韩语参考：두려움（恐惧，畏惧） / 무서움（害怕，恐惧）<br>
  例：私は恐怖で気も狂わんばかりだった。（我吓得几乎要发疯。）
- **協力**（きょうりょく）合作｜韩语参考：협력（协力，协作，合作）<br>
  例：彼らは協力してその絵を仕上げた。（他们合作完成了那幅画。）
- **強力**（きょうりょく）强大；强力｜韩语参考：강력（强力）<br>
  例：日本の軍隊は非常に強力だった。（日本军队当时非常强大。）
- **局**（きょく）局；台｜韩语参考：판（盘，局）<br>
  例：この地区では三局受信できます。（这个地区能收到三个台。）
- **巨大**（きょだい）巨大｜韩语参考：거대（巨大，庞大）<br>
  例：巨大なタンカーがついに今し方出港した。（巨型油轮刚刚终于出港了。）
- **嫌う**（きらう）讨厌｜韩语参考：밉보다（讨厌，不喜欢） / 싫어하다（讨厌，不愿意）<br>
  例：彼女は人前で話をするのを嫌う。（她讨厌在人前讲话。）
- **霧**（きり）雾｜韩语参考：안개（雾，雾气）<br>
  例：濃い霧のために私たちの飛行機は遅れた。（因为大雾，我们的飞机延误了。）
- **切れ**（きれ）片；块｜韩语参考：점（块） / 도막（段，根，块） / 조각（片）<br>
  例：肉は何切れにしましょうか。（肉切成几片呢？）
- **切れる**（きれる）断；用完｜韩语参考：되다（用完，没有） / 끊기다（断，绝） / 끊어지다（断，被切断）<br>
  例：ガソリンが切れかかっている。（汽油快用完了。）
- **記録**（きろく）记录｜韩语参考：기록（记录） / 기재（记录，记载，填写）<br>
  例：無言が記録されたためしはない。（还从没有过沉默被记录下来的先例。）
- **議論**（ぎろん）讨论；争论｜韩语参考：의논（商议，讨论，商量）<br>
  例：彼らは議論をやめることに決めた。（他们决定停止争论。）
- **銀**（ぎん）银｜韩语参考：은（银）<br>
  例：金より銀の指輪の方が好きです。（比起金戒指，我更喜欢银的。）
- **禁煙**（きんえん）禁烟｜韩语参考：금연（禁烟）<br>
  例：いつ禁煙のサインを消すのでしょうね。（不知什么时候才会把禁烟的牌子撤掉呢。）
- **金額**（きんがく）金额｜韩语参考：금액（金额） / 액수（数额，金额）<br>
  例：彼は彼女にかなりの金額を与えた。（他给了她一大笔钱。）
- **金庫**（きんこ）保险箱｜韩语参考：금고（保险柜，保险箱，金库）<br>
  例：貴重品は金庫にしまっておきなさい。（贵重物品要收进保险箱。）
- **禁止**（きんし）禁止｜韩语参考：금지（禁止）<br>
  例：ここでは煙草は禁止されています。（这里禁止吸烟。）
- **金銭**（きんせん）金钱｜韩语参考：금전（金钱，钱） / 돈（钱，金钱，钱币）<br>
  例：金銭のことで彼と争いになった。（因为钱的事跟他起了争执。）
- **金属**（きんぞく）金属｜韩语参考：금속（金属） / 쇠（金属）<br>
  例：鉄は最も有用な金属です。（铁是最有用的金属。）
- **近代**（きんだい）近代｜韩语参考：근대（近代）<br>
  例：近代医学の進歩は長い道程を歩んだ。（近代医学的进步走过了漫长的历程。）
- **緊張**（きんちょう）紧张｜韩语参考：긴장（紧张）<br>
  例：冷戦の緊張が高まった。（冷战紧张局势加剧了。）
- **筋肉**（きんにく）肌肉｜韩语参考：근육（肌肉）<br>
  例：水泳は筋肉を発達させる。（游泳能使肌肉发达。）
- **金融**（きんゆう）金融｜韩语参考：금융（金融）<br>
  例：工業よりも金融に関心のある学生のほうが多い。（关心金融的学生比关心工业的还多。）
- **金曜**（きんよう）星期五｜韩语参考：금요일<br>
  例：彼は月曜から金曜まで働く。（他从周一到周五工作。）

## 语法

- **〜に対して**：对…；与…相对
  接续：名词 + に対して；动词/い形容词/ナ形容词 + な + のに対して
  朝鲜语：-에 대해서（韩语「-에 대해서」只表对象；日语「に対して」还常用于前后对比，相当于韩语「-는 반면」，用法更广。）
- **〜について**：关于…
  接续：名词 + について；名词 + についての + 名词
  朝鲜语：-에 대해서（韩语「-에 대해서」与「について」基本对应；但日语修饰名词须用「についての」，韩语无此变化，容易漏写「の」。）
- **〜によって / 〜による**：由…；由于…；因…而异
  接续：名词 + によって；名词 + による + 名词
  朝鲜语：-에 의해서（韩语「-에 의해서」主要用于被动主体；日语还能表原因和“因…而异”，韩语后者要用「-에 따라」。）
