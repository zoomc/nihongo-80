# Day 079 · 〜おかげで、〜せいで、〜たとたん / 〜たとたんに

- 阶段：P4｜60 分钟｜听力日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜おかげで**：多亏…；托…的福
  接续：动词普通形/い形容词/ナ形容词な/名词の + おかげで
  朝鲜语：-덕분에（덕분에 和 おかげで 通常都表示受益，如 덕분에 무사히 도착했어요／おかげで無事に着きました。语境明确时两者也能反讽。）
- **〜せいで**：都怪…；因为…
  接续：动词普通形/い形容词/ナ形容词な/名词の + せいで
  朝鲜语：-때문에（韩语「-때문에」中性，好坏结果都可用；日语「せいで」专用于坏结果并带责难，不能随便替换「おかげで」。）
- **〜たとたん / 〜たとたんに**：刚一…就…
  接续：动词た形 + とたん（に）
  朝鲜语：-자마자（韩语「-자마자」只表紧接发生；日语「とたん」还要求后项是意外、非意志的事，不能接自己的有意动作。）
