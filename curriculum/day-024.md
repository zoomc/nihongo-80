# Day 024 · 〜だ、〜ではありません / 〜じゃない、〜でした

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜だ**：是…（普通断定）
  接续：名词／な形容词 + だ
  朝鲜语：이다（이다 与 だ 都可作普通体判断，韩语终结时还可选 학생이야／의사야 等熟人语体。日语名词、な形容词常用 だ，动词、い形容词不再接 だ。）
- **〜ではありません / 〜じゃない**：不是…
  接续：名词／な形容词 + ではありません（礼貌）／じゃない（普通）
  朝鲜语：아니다 / 아닙니다（학생이 아닙니다／의사가 아닙니다 取决于有无收音，日语统一把 ではありません 接在名词后。では 的会话缩约为 じゃ，礼貌度仍由 ありません／ない 等句末决定。）
- **〜でした**：（过去）是…
  接续：名词／な形容词 + でした
  朝鲜语：이었습니다 / 였습니다（韩语过去礼貌体 이었습니다/였습니다 随收音变化，日语 でした 形式固定；い形容词过去用 かったです，韩语则用过去时制。）
