# Day 027 · 〜まで（until）、〜か（question）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜まで（until）、〜か（question）」造两句自己的话，表达：到…为止；直到…；…吗？（疑问）

## 新词 19

- **鳥**（とり）鸟｜韩语参考：새（鸟）<br>
  例：なんてきれいな鳥なんだろう。（多漂亮的鸟啊。）
- **鶏肉**（とりにく）鸡肉｜韩语参考：닭고기<br>
  例：鶏肉を３ポンド分ください。（请给我三磅鸡肉。）
- **撮る**（とる）拍摄｜韩语参考：찍다（拍，拍摄） / 촬영하다（摄影，摄制，拍摄）<br>
  例：外からなら撮ってもかまいません。（从外面拍的话没关系。）
- **取る**（とる）拿；取｜韩语参考：먹다（得， 取） / 취하다（取，拿，获得，获取，摄取）<br>
  例：そのお金はいざというときのために取っておくよ。（那笔钱我留着以备不时之需。）
- **どれ**（どれ）哪个｜韩语参考：어느 것<br>
  例：あなたのかばんはどれですか。（哪个是你的包？）
- **ナイフ**（ナイフ）刀｜韩语参考：칼（刀）<br>
  例：それはあなたのナイフではない。（那不是你的刀。）
- **長い**（ながい）长｜韩语参考：길다（长）<br>
  例：だんだん日が長くなっています。（白天渐渐变长了。）
- **鳴く**（なく）（动物）叫｜韩语参考：（동물이）울다<br>
  例：カエルが鳴いたら帰ろう。（青蛙叫了就回去吧。）
- **なぜ**（なぜ）为什么｜韩语参考：왜<br>
  例：あなたはなぜ働いているの。（你为什么在工作？）
- **夏**（なつ）夏天｜韩语参考：여름（夏，夏天，夏季）<br>
  例：アリは夏じゅうせっせとはたらく。（蚂蚁整个夏天都勤快地干活。）
- **夏休み**（なつやすみ）暑假｜韩语参考：여름휴가（暑假，暑期休假）<br>
  例：この夏休みはどこかへ行くのですか。（这个暑假你要去哪里吗？）
- **など**（など）等等｜韩语参考：등 / 따위<br>
  例：ぬくもりなどどこにも見つからない。（哪里都找不到温暖。）
- **七つ**（ななつ）七个｜韩语参考：일곱 개<br>
  例：７つの海って何ですか。（七大洋是什么？）
- **七日**（なのか）七天；七号｜韩语参考：이레（七天）<br>
  例：一週間は七日です。（一周有七天。）
- **習う**（ならう）学｜韩语参考：배우다（学，学习）<br>
  例：車の運転を習っています。（我在学开车。）
- **並ぶ**（ならぶ）排队｜韩语参考：줄짓다（排队，站队）<br>
  例：あんた、なぜに並んでいるのだい。（你排队做什么？）
- **並べる**（ならべる）排列｜韩语参考：늘어놓다<br>
  例：メイドはテーブルにナイフとフォークを並べた。（女仆把刀叉摆在桌上。）
- **賑やか**（にぎやか）热闹｜韩语参考：번화하다 / 떠들썩하다<br>
  例：この通りは賑やかだ。（这条街很热闹。）
- **西**（にし）西｜韩语参考：서（西）<br>
  例：列車は西へ走っていた。（列车一直向西行驶。）

## 语法

- **〜まで（until）**：到…为止；直到…
  接续：名词 + まで（终点）
  朝鲜语：까지（韩语 까지 与 まで 对应，时间和空间都可用；日语 まで 还可表程度界限（駅まで歩く），韩语 까지 同样可延伸。）
- **〜か（question）**：…吗？（疑问）
  接续：句子（礼貌体／普通体）+ か
  朝鲜语：-까? / -니?（韩语可用疑问词尾或语调构成疑问；日语礼貌体常加か，语调也会随交际语境变化。）
