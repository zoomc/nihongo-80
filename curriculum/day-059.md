# Day 059 · 〜れる / 〜られる（passive）、〜せる / 〜させる

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜れる / 〜られる（passive）、〜せる / 〜させる」造两句自己的话，表达：被…；遭受…；让…做；使…做

## 新词 14

- **都合**（つごう）方便；情况<br>
  例：何時がご都合よいでしょうか。（您几点方便？）
- **伝える**（つたえる）传达；转告<br>
  例：その話は親から子へと伝えられた。（那个故事从父母传给了孩子。）
- **続く**（つづく）持续；继续<br>
  例：どれくらいこの寒い天気は続きますか。（这种冷天还要持续多久？）
- **包む**（つつむ）包；包裹<br>
  例：プレゼント用に包んでもらえますか。（能帮我包成礼物吗？）
- **妻**（つま）妻子<br>
  例：妻と一緒に旅行します。（和妻子一起旅行。）
- **つもり**（つもり）打算<br>
  例：私は来年留学するつもりです。（我打算明年去留学。）
- **釣る**（つる）钓；钓鱼<br>
  例：思っていたほど魚は釣れなかった。（鱼没有预想的那么好钓。）
- **連れる**（つれる）带（人）<br>
  例：でもさ、母を連れて行かなくてはいけないんだ。（可是啊，我必须带母亲一起去。）
- **丁寧**（ていねい）礼貌；仔细<br>
  例：漢字を書くときは点やはらいに気をつけて、なるべく早くていねいに書きましょう。（写汉字时要注意点和撇捺，尽量又快又工整地书写。）
- **テキスト**（テキスト）教材；课本<br>
  例：このテキストは初心者向きにできている。（这本教材是为初学者编写的。）
- **適当**（てきとう）适当；随便｜朝鲜语：적당<br>
  例：あなたが適当だと思う本なら何でも読みなさい。（只要你觉得合适的书，什么都可以读。）
- **できるだけ**（できるだけ）尽量<br>
  例：できるだけ多くの本を読みなさい。（尽量多读书。）
- **テニス**（テニス）网球<br>
  例：１日中テニスをしていたのだから。（因为他一整天都在打网球。）
- **手袋**（てぶくろ）手套<br>
  例：この手袋は両方がそろっていない。（这副手套不成双。）

## 语法

- **〜れる / 〜られる（passive）**：被…；遭受…
  接续：五段动词未然形+れる；一段动词未然形+られる；する→される；来る→来られる
  朝鲜语：피동 (-이/히/리/기-)（韩语用被动词尾或 -에 의해，日语用助动词 れる／られる；日语受害被动（足を踏まれた）在韩语中常改用主动句或 -당하다。）
- **〜せる / 〜させる**：让…做；使…做
  接续：五段动词未然形+せる；一段动词未然形+させる；する→させる；来る→来させる
  朝鲜语：-게 하다（韩语 -게 하다 与使役对应，但日语使役对象用 に 还是 を 取决于动词；韩语统一用 을/를 或 에게，需按语义判断。）
