# Day 071 · V ます形(去ます) + かねない / かねる、V ます形(去ます) + 得る / V ない形(去ない) + ざるを 得ない

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「V ます形(去ます) + かねない / かねる、V ます形(去ます) + 得る / V ない形(去ない) + ざるを 得ない」各造一句自己的话，表达：难保不会…、恐怕会…／难以…、不便…；可能…、会有…／不得不…

## 新词 22

- **いつでも**（いつでも）随时；总是｜韩语参考：무시로（无时无刻，随时）<br>
  例：私はいつでも喜んでお手伝いします。（我随时都乐意帮忙。）
- **一般**（いっぱん）一般；普通｜韩语参考：일반（普通）<br>
  例：その理論はまだ一般に認められていない。（那个理论还没有被普遍接受。）
- **一方**（いっぽう）一方面；另一方面｜韩语参考：일방（一边，一方，单方） / 일편（一方面，既……又……） / 한쪽（一边，一方，一面，一头，一端）<br>
  例：一方は赤で、また一方は白である。（一个是红的，另一个是白的。）
- **いつまでも**（いつまでも）永远；一直｜韩语参考：영영（永远地，完全）<br>
  例：私はいつまでも彼の名を覚えている。（我会永远记得他的名字。）
- **移動**（いどう）移动｜韩语参考：이동（移动）<br>
  例：彼らはあちこちへと移動してきます。（他们到处迁移。）
- **従兄弟**（いとこ）堂兄弟；表兄弟｜韩语参考：사촌（堂表亲，堂表兄弟姐妹） / 고종사촌（姑表亲，姑表兄弟，姑表姐妹）<br>
  例：彼は私の兄ではなくて、いとこである。（他不是我哥哥，是我表兄弟。）
- **稲**（いね）稻子｜韩语参考：나락（稻子）<br>
  例：稲は雨の多い地域で作られる。（稻子种在雨水多的地区。）
- **居眠り**（いねむり）打瞌睡｜韩语参考：졸기<br>
  例：授業中に居眠りすることは許しません。（不许上课时打瞌睡。）
- **命**（いのち）生命；命｜韩语参考：명（命） / 목숨（命，生命，性命） / 생명（命，性命，生命）<br>
  例：その犬は少女の命を救った。（那条狗救了女孩的命。）
- **違反**（いはん）违反｜韩语参考：위반（违反，违背） / 위배（违背，违反）<br>
  例：それはルール違反です。（那是违反规则的。）
- **衣服**（いふく）衣服｜韩语参考：의복（衣服） / 옷（衣服，衣裳，服装） / 피복（衣服，衣物，衣裳）<br>
  例：彼らは衣服をほとんど着用しない。（他们几乎不穿衣服。）
- **居間**（いま）起居室；客厅｜韩语参考：거실（客厅）<br>
  例：彼らは居間でお茶を飲んでいます。（他们在客厅喝茶。）
- **今に**（いまに）不久；早晚｜韩语参考：곧 / 머지않아<br>
  例：今にバチがあたるぞ。（早晚会遭报应的。）
- **今にも**（いまにも）眼看就要｜韩语参考：금방이라도<br>
  例：トムは今にもここに来るはずです。（汤姆应该马上就要来了。）
- **否**（いや）不；不是｜韩语参考：아니 / 아니다<br>
  例：いや、当初の考えはそうでした。（不，最初的想法是这样的。）
- **以来**（いらい）以来｜韩语参考：이래（以来，之后）<br>
  例：１９８８年以来トムに会っていません。（自1988年以来就没见过汤姆。）
- **依頼**（いらい）委托；请求｜韩语参考：의뢰（委托） / 부탁（拜托，请求，托付）<br>
  例：彼女は彼に資金を集めるように依頼した。（她委托他去筹集资金。）
- **いらいら**（いらいら）焦躁；烦躁｜韩语参考：초조히（焦躁地，焦虑地） / 지글거리다（焦躁，烦躁）<br>
  例：ビルは試験のことでいらいらしている。（比尔因为考试的事心烦。）
- **いらっしゃい**（いらっしゃい）欢迎；请进｜韩语参考：어서 오세요<br>
  例：いるだけ持っていらっしゃい。（你要多少就拿多少吧。）
- **医療**（いりょう）医疗｜韩语参考：의료（医疗）<br>
  例：彼は医療に一生を捧げた。（他把一生献给了医疗事业。）
- **岩**（いわ）岩石｜韩语参考：바위（岩石） / 바윗돌（岩石，大石头）<br>
  例：この岩は何に似ていますか。（这块岩石像什么？）
- **祝い**（いわい）祝贺；庆祝｜韩语参考：축하（祝贺，庆贺，道贺）<br>
  例：私は彼の卒業祝いに電報を打った。（我发了电报祝贺他毕业。）

## 语法

- **V ます形(去ます) + かねない / かねる**：难保不会…、恐怕会…／难以…、不便…
  接续：動詞 ます形 去 ます + かねない／かねる；かねる 按一段动词变形（かねます／かねた）
  朝鲜语：-(으)ㄹ 수도 있다 / -기 어렵다（韩语ㄹ 수도 있다表恐怕会(坏结果)，委婉拒绝用하기 어렵습니다；かねる的立场限制韩语须另加说明。）
- **V ます形(去ます) + 得る / V ない形(去ない) + ざるを 得ない**：可能…、会有…／不得不…
  接续：動詞 ます形 去 ます + 得る（读 うる／える，否定 得ない えない）；動詞 ない形 去 ない + ざるを得ない（する→せざるを得ない 例外）
  朝鲜语：-(으)ㄹ 수 있다 / -지 않을 수 없다（韩语可能用ㄹ 수 있다，不得不的用지 않을 수 없다或해야 한다；ざるを得ない更书面。）
