今日语法 3 条

〜れる / 〜られる（passive）
발음〜레루 / 〜라레루
被…；遭受…
五段动词未然形+れる；一段动词未然形+られる；する→される；来る→来られる
表示被他人施加动作，或事物被处理；受害被动常带困扰语气。
센세이니사쿠분오호메라레마시타.
先生に作文をほめられました。
我的作文受到了老师表扬。
덴샤노나카데아시오후마레타.
電車の中で足を踏まれた。
我在电车里被踩了脚。
この寺は六百年前に建てられました。
这座寺庙建于六百年前。
朝鲜语：피동 (-이/히/리/기-)
韩语用被动词尾或 -에 의해，日语用助动词 れる／られる；日语受害被动（足を踏まれた）在韩语中常改用主动句或 -당하다。
易错点

この寺は六百年前に建てらました。 → この寺は六百年前に建てられました。（建てる 的受身是「建てられ」，不是「建てら」）

〜せる / 〜させる
발음〜세루 / 〜사세루
让…做；使…做
五段动词未然形+せる；一段动词未然形+させる；する→させる；来る→来させる
表示使役，可指命令、允许或放任，视上下文而定。
母は毎日弟に野菜を食べさせる。
母亲每天让弟弟吃蔬菜。
코오치와마이니치,센슈타치오하시라세타.
コーチは毎日、選手たちを走らせた。
教练每天让选手们跑步。
息子が行きたいと言ったので、一人で旅行に行かせました。
儿子说想去，我就让他一个人去旅行了。
朝鲜语：-게 하다
韩语 -게 하다 与使役对应，但日语使役对象用 に 还是 を 取决于动词；韩语统一用 을/를 或 에게，需按语义判断。
易错点

母は毎日弟を野菜を食べさせる。 → 母は毎日弟に野菜を食べさせる。（使役对象用 に，不能再用 を 标记同一成分）

〜せられる / 〜させられる
발음〜세라레루 / 〜사세라레루
被迫做…
五段动词未然形 + せられる（部分动词常缩约为 される）；一段动词未然形 + させられる
表示不情愿地被迫做某事，含有受害或无奈的语气。
코도모노코로,하하니마이니치피아노오렌슈우사세라레타.
子どものころ、母に毎日ピアノを練習させられた。
小时候母亲每天逼我练钢琴。
에키데산주뿜모마타사레마시타.
駅で三十分も待たされました。
我在车站被迫等了三十分钟。
카이샤노노미카이데우타오우타와사레타.
会社の飲み会で歌を歌わされた。
公司聚会上我被逼着唱了歌。
朝鲜语：-게 시킴을 당하다
韩语没有专门的使役被动词尾，通常说 -하도록 강요받다 或 -게 되다；日语有固定的使役受身活用，语气更强调被迫。
易错点

母に野菜を食べさせられますた。 → 母に野菜を食べさせられました。（礼貌过去形为「食べさせられました」。）
