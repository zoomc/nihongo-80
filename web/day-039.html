今日语法 2 条

～なくても いい
動詞ない形（去ない） + くても + いい
～なくても いい
不必…／不…也行
表许可不做；与 〜てはいけない（禁止）相对
明日は来なくてもいいです。
明天不来也行。
朝鲜语：-지 않아도 되다
韩语지 않아도 되다表不必，口语常안 해도 돼更随意；日语なくてもいい较中性。
易错点

来なくては いい → 来なくてもいいです。（「なくては」是「必须/不…不行」，与许可义相反）

～ようになる / ～なくなる
辞书形/可能形 + ようになる；ない形去ない + なくなる（例：行かなくなる）
～ようになる / ～なくなる
变得会…／变得不…了
表状态/能力的变化；能力变化多用可能形 + ようになる
日本語が話せるようになりました。
变得会说日语了。
雨が降らなくなりました。
雨停了（不再下了）。
朝鲜语：-게 되다 / -지 않게 되다
韩语变化结果统用게 되다，能力变化也用게 되다；日语ようになる与なくなる分开。
易错点

話すようになりました（想表能力） → 話せるようになりました。（能力变化用 可能形 + ようになる：話せる）
