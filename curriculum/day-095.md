# Day 095 · 〜わけがない、〜わけにはいかない

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜わけがない、〜わけにはいかない」造两句自己的话，表达：不可能…；绝不会…；不能…；不便…

- **活気**（かっき）活力；生气｜韩语参考：활기（朝气，活力，生气，生机） / 생기（朝气，活力）<br>

  例：金持ちが必ずしも幸福とは限らない。（有钱人未必幸福。）
- **金**（かね）钱｜韩语参考：돈（钱，金钱，钱币）<br>
  例：母は子供たちに金をわけてやった。（母亲把钱分给了孩子们。）

- **神**（かみ）神｜韩语参考：신（上帝，神）<br>
  例：人間は神ほど万能ではない。（人并非像神那样无所不能。）

## 语法

- **〜わけがない**：不可能…；绝不会…
  接续：普通形 + わけがない；ナ形容词 + な + わけがない；名词 + の/な + わけがない
  朝鲜语：-ㄹ 리가 없다（韩语「-ㄹ 리가 없다」与「わけがない」几乎一一对应；但韩语口语常说「-ㄹ 리가 없잖아」反驳，日语习惯前加「そんな」。）
- **〜わけにはいかない**：不能…；不便…
  接续：动词辞书形 + わけにはいかない；动词ない形 + わけにはいかない
  朝鲜语：-ㄹ 수는 없다（韩语「-ㄹ 수는 없다」偏“能力或情况不允许”；日语「わけにはいかない」强调社会道义上的“不能”，含无奈。）
