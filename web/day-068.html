Day 068 · 〜的、〜ような / 〜ように（like）

语法 2 条

〜的
발음〜테키
…上的；…式的
名词 + 的（てき）；修饰名词可用 的な，也有直接连接的词组，如経済的理由
把名词转成形容词性，表性质、领域或立场。
韩语对应-적
韩语「-적」来自同一汉字词，用法高度相似；但韩语接「으로/인」，日语换成「に/な」，词形对应不齐。
日本の伝統的な料理を食べてみたい。
我想尝尝日本的传统菜肴。
この問題は、経済的な理由で解決が難しい。
这个问题因经济上的原因难以解决。
個人的には、この案に賛成です。
个人而言，我赞成这个方案。
易错易混点
  • ✗ 具体的にの説明をお願いします。✓ 具体的な説明をお願いします。说 具体的な説明，不能叠成 にの。
〜ような / 〜ように（like）
발음〜요우나 / 〜요우니
像…一样；如同…
名词 + の + ような/ように；普通形 + ような/ように
举出相似例子、比喻，或表示“按照…的方式”。
韩语对应…같은 / …같이 / …처럼
先生のような人 可对照 선생님 같은 사람，先生のように読む 对照 선생님처럼 읽다。日语名词接 よう 前加 の，句中再根据修饰对象选 な／に。
私も、あなたのような優しい看護師になりたいです。
我也想成为像你这样温柔的护士。
센세이 가 이따요우 니, 코노붐포우 와 테스토 니 요쿠데루.
先生が言ったように、この文法はテストによく出る。
正如老师所说，这个语法考试常考。
토우쿄우 노 요우나오오키나토시 데 와, 야친 가 토테모타카이.
東京のような大きな都市では、家賃がとても高い。
在东京这样的大城市，房租很贵。
易错易混点
  • ✗ 東京のよう大きな都市では、家賃がとても高い。✓ 東京のような大きな都市名词接 ような 要保留 な：東京のような大きな都市。
