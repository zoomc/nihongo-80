## 语法

- **〜上で**：做完…后；在…过程中
  接续：Verb-ta + 上で / 名词 + の + 上で / 动词辞书形 + 上で
  朝鲜语：한 뒤에 / 하는 데에（韩语提示按整块理解。换成日语时先套接续「Verb-ta + 上で / 名词 + の + 上で / 动词辞书形 + 上で」，再看下面的例句。）
- **〜以上（は）**：既然…就…
  接续：动词普通形 / na-Adj + である / 名词 + である + 以上（は）
  朝鲜语：한 이상（韩语提示按整块理解。换成日语时先套接续「动词普通形 / na-Adj + である / 名词 + である + 以上（は）」，再看下面的例句。）
