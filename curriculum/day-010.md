# Day 010 · な形容词 否定／过去／で、ます形（丁寧体）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「な形容词 否定／过去／で、ます形（丁寧体）」造两句自己的话，表达：不…／曾…／而…（な形变形）；动词礼貌形：ます／ません／ました／ませんでした

## 语法

- **な形容词 否定／过去／で**：不…／曾…／而…（な形变形）
  接续：静か→静かではない／静かだった／静かで
  朝鲜语：-지 않다 / -았·었- / -고（韩语形容词否定与过去共用一套词尾，不分な形い形；中顿고不表原因。）
- **ます形（丁寧体）**：动词礼貌形：ます／ません／ました／ませんでした
  接续：動詞 + ます（う段→い段+ます；一段去る+ます）
  朝鲜语：-습니다/ㅂ니다 / -아·어요（韩语敬语分합쇼체与해요체，随听者选择；日语ます体一套即可，无此分层。）
