# Day 005 · を（宾语／移动经过）、に（时点／归着点／存在场所／对象）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「を（宾语／移动经过）、に（时点／归着点／存在场所／对象）」造两句自己的话，表达：把…（标宾语）；在／于／向…

## 新词 19

- **中**（なか）里面；中间｜韩语参考：속（里面，里头） / 안（里，里面） / 가운데（中间，正中，中央）<br>
  例：部屋の中にいます。（在房间里。）
- **前**（まえ）前面；之前｜韩语参考：앞（前，前面）<br>
  例：駅の前に店があります。（车站前有店。）
- **後**（あと）后面；之后｜韩语参考：담（之后） / 뒤（后，之后，后来） / 후（后，以后，之后）<br>
  例：食事の後に、薬を飲みます。（饭后吃药。）
- **ご飯**（ごはん）米饭；饭（餐）｜韩语参考：밥 / 식사<br>
  例：ご飯を食べます。（吃饭。）
- **朝ご飯**（あさごはん）早饭｜韩语参考：아침（早饭，早餐）<br>
  例：朝ご飯を食べます。（吃早饭。）
- **水**（みず）水（冷水／生水）｜韩语参考：물（水）<br>
  例：水を飲みます。（喝水。）
- **お茶**（おちゃ）茶｜韩语参考：차（茶，茶水）<br>
  例：お茶を飲みます。（喝茶。）
- **肉**（にく）肉｜韩语参考：살（肉） / 고기（肉）<br>
  例：肉を買います。（买肉。）
- **魚**（さかな）鱼｜韩语参考：물고기 / 생선（문맥에 따라）<br>
  例：魚が好きです。（喜欢鱼。）
- **野菜**（やさい）蔬菜｜韩语参考：야채（蔬菜） / 채소（菜，蔬菜）<br>
  例：野菜を買います。（买蔬菜。）
- **パン**（パン）面包｜韩语参考：빵（面包）<br>
  例：パンを食べます。（吃面包。）
- **料理**（りょうり）菜肴；烹饪｜韩语参考：요리（烹饪，烹调）<br>
  例：料理を作ります。（做菜。）
- **電車**（でんしゃ）电车（轨道交通）｜韩语参考：전차（电车） / 전동차（电动车，电车）<br>
  例：電車で行きます。（坐电车去。）
- **バス**（バス）公交车｜韩语参考：버스（公共汽车，公交车）<br>
  例：バスに乗ります。（上公交。）
- **車**（くるま）汽车；车｜韩语参考：차（车，车辆） / 자동차（汽车）<br>
  例：車で会社へ行きます。（开车去公司。）
- **自転車**（じてんしゃ）自行车｜韩语参考：자전거（自行车）<br>
  例：自転車で学校へ行きます。（骑车去学校。）
- **飛行機**（ひこうき）飞机｜韩语参考：비행기（飞机）<br>
  例：飛行機で旅行します。（坐飞机旅行。）
- **父**（ちち）(我)父亲｜韩语参考：아버지（父亲，爸爸）<br>
  例：父は会社員です。（我父亲是公司职员。）
- **母**（はは）(我)母亲｜韩语参考：어머니（母亲，妈妈）<br>
  例：母は医者です。（我母亲是医生。）

## 语法

- **を（宾语／移动经过）**：把…（标宾语）
  接续：名詞 + を + 他動詞
  朝鲜语：을/를（韩语宾格助词按收音选을/를，口语可省略；日语を还能表移动经过，韩语该义也用를。）
- **に（时点／归着点／存在场所／对象）**：在／于／向…
  接续：名詞 + に
  朝鲜语：에 / 에게（韩语存在场所用에，人的对象用에게/한테；日语に一形多义，韩语须按对象分开。）
