今日语法 2 条

N は N ではありません / じゃない
名詞 + は + 名詞 + ではありません（口语 じゃない）
N は N ではありません / じゃない
…不是…
判断句否定，礼貌体
私は先生ではありません。
我不是老师。
朝鲜语：이/가 아닙니다
韩语否定用이/가 아니다，助词随收音变化；日语では可缩成じゃ，韩语无对应缩略。
易错点

私は先生ないです。 → 私は先生ではありません。（把「ではありません」拆成「ない＋です」，中文「不是」直译导致词类错误；「じゃありません」是合法的口语礼貌否定，不在纠错范围。）

N は N でした
名詞 + は + 名詞 + でした
N は N でした
…（过去）是…
判断句过去式，礼貌体
昨日は日曜日でした。
昨天是周日。
朝鲜语：이었습니다 / 였습니다
韩语过去按有无收音选이었/였，且分层级；日语でした只有一形，无收音条件。
易错点

昨日は日曜日です。 → 昨日は日曜日でした。（时间词「昨日」要求过去，中文「是」无时态变化易漏 でした）
