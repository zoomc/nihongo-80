## 3. 新语法（含先修）
- `G0086` **V辞書形 / Nの + たびに** — 每当…就…；每次…都…｜接续：動詞辞書形 + たびに；名詞 + の + たびに（する名詞可直接 するたびに）
- `G0078` **N + に 基づいて / を もとに / どおり(に)** — 基于…／以…为依据／按照…｜接续：名詞 + に基づいて（依据资料/规则/数据）；名詞 + をもとに（以…为素材/基础）；名詞 + どおり(に)（照原样、按预定）

## 4. 新汉字（中日差异）
- `K0116` **就** 音:シュウ 训:つく｜中文「就」jiù 多作副词；日语 就 音读 シュウ，「就職」しゅうしょく 是「就业/就职」（名词/サ変）；中文「就」的词性与日语完全不同，不能按中文直译。
- `K0113` **告** 音:コク 训:つげる｜中文「告」gào；日语 告 音读 コク（入声 -ク）、训读 つげる（告げる），「報告」ほうこく「広告」こうこく；不可按中文 gào 推成 ゴウ/カオ。
