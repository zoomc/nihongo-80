# Day 132 · 〜ということだ

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜ということだ」造两句自己的话，表达：据说…；也就是说…

## 新词 21

- **相続**（そうぞく）继承｜韩语参考：상속（继承）<br>
  例：彼は父親の大きな土地を相続した。（他继承了父亲的大片土地。）
- **装置**（そうち）装置；设备｜韩语参考：장치（装置，装备，设备）<br>
  例：みんな、その装置にとても感心した。（大家都对那个装置很佩服。）
- **相当**（そうとう）相当；合适｜韩语参考：상당（相当于，合） / 상당히（相当多地）<br>
  例：その場所は今は相当建て込んでいる。（那个地方现在建得相当密集。）
- **速度**（そくど）速度｜韩语参考：속도（速度）<br>
  例：その男は一定の速度で車を運転した。（那个男人以稳定的速度开车。）
- **底**（そこ）底部；底｜韩语参考：밑（底，底下） / 밑창（底，底部） / 바닥（底）<br>
  例：靴の底がすり減ってしまった。（鞋底磨薄了。）
- **そこで**（そこで）于是；因此｜韩语参考：그래서 / 그리하여<br>
  例：そこで他人との相互作用が大切になる。（因此，与他人的互动就变得重要了。）
- **組織**（そしき）组织｜韩语参考：조직（组织） / 짜임（组织，结构）<br>
  例：彼らは労働組合を組織するだろう。（他们会组织工会吧。）
- **注ぐ**（そそぐ）注入；倾注｜韩语参考：쏟다（倾注） / 퍼붓다（倾注）<br>
  例：彼は友人を助けることに全力を注いだ。（他把全力倾注在帮助朋友上。）
- **育つ**（そだつ）成长；长大｜韩语参考：크다（长，成长，生长） / 자라다（生长，成长） / 자라나다（长大）<br>
  例：子供は放っておいても育つものだ。（孩子放着不管也会长大。）
- **そっくり**（そっくり）一模一样；完全｜韩语参考：똑같이（一模一样，很相似）<br>
  例：あなたはお母さんにそっくりね。（你和你妈妈长得一模一样呢。）
- **そっと**（そっと）轻轻地；悄悄地｜韩语参考：벙싯（微微地，轻轻地） / 사르르（轻轻地） / 살며시（悄悄地，轻轻地）<br>
  例：彼女は子供をそっと寝かせた。（她轻轻地把孩子放下哄睡了。）
- **袖**（そで）袖子｜韩语参考：소매（袖子） / 옷소매（衣袖，袖子） / 팔소매（衣袖，袖子）<br>
  例：父は袖に長い裂け目を作った。（父亲在袖子上划了一道长口子。）
- **備える**（そなえる）具备；准备｜韩语参考：갖추다（具备，备好） / 차리다（具备，讲究） / 예비하다（准备，预备）<br>
  例：このビルは非常階段を備えている。（这栋楼配有紧急楼梯。）
- **そのうち**（そのうち）不久；改天｜韩语参考：머지않아 / 다음에<br>
  例：そのうち一緒に仕事ができるといいなと思っています。（我想，希望不久能一起工作。）
- **そのまま**（そのまま）原样；就那样｜韩语参考：그냥（就那样） / 고대로（就那样，照旧） / 그대로（原原本本地，原封不动地，如实地，照原样）<br>
  例：ドアをそのままにしておいてはいけません。（不能就让门那样开着。）
- **ソファー**（ソファー）沙发｜韩语参考：소파（沙发）<br>
  例：少年はソファーに横になっていた。（少年躺在沙发上。）
- **粗末**（そまつ）粗糙；简慢｜韩语参考：허술하다 / 소홀하다<br>
  例：道具を粗末に使うな。（别把工具胡乱使。）
- **それぞれ**（それぞれ）各自；分别｜韩语参考：각각（各自，分别） / 각개（各个，各自） / 각기（各自）<br>
  例：人にはそれぞれ向き不向きがある。（人各有各的擅长和不擅长。）
- **それと**（それと）另外；还有｜韩语参考：그리고 / 또<br>
  例：それと俺がホモだとしたら、罪になるわけ？（还有，如果我是同性恋，就成罪了吗？）
- **損**（そん）亏损；吃亏｜韩语参考：손해<br>
  例：高望みをするとかえって損をする。（期望过高反而会吃亏。）
- **損害**（そんがい）损害；损失｜韩语参考：손해（损失）<br>
  例：その暴風雨は大損害をもたらした。（那场暴风雨带来了巨大损失。）

## 语法

- **〜ということだ**：据说…；也就是说…
  接续：普通形 + ということだ
  朝鲜语：-다는 것이다（韩语「-다는 것이다」与「ということだ」对应；但日语同一形式兼表传闻和“也就是说”，韩语要靠不同形式区分。）
