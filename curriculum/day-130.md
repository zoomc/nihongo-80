## 语法

- **〜てからでないと**：不先…就不能…
  接续：Verb-te + からでないと / Verb-te + からでなければ
  朝鲜语：하고 나서야（韩语提示按整块理解。换成日语时先套接续「Verb-te + からでないと / Verb-te + からでなければ」，再看下面的例句。）
- **〜て以来**：自…以来
  接续：Verb-te + 以来 / 名词 + 以来
  朝鲜语：한 이래로（韩语提示按整块理解。换成日语时先套接续「Verb-te + 以来 / 名词 + 以来」，再看下面的例句。）
