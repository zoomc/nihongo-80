# Day 041 · 〜ば、〜たら、〜なら、〜と（conditional）

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ば**：如果…
  接续：五段词尾改え段 + ば；一段去 る + れば；い形容词去 い + ければ；な形容词／名词用 なら 或 であれば。
  朝鲜语：-(으)면（싸면 사겠다 对照 安ければ買う。形容词状态作条件时，后项完全可以是意志；若是同一人先完成动作再接受指令，常用 着いたら電話して。）
- **〜たら**：如果…；…之后
  接续：动词た形 + ら；い形容词去い+かったら；な形容词・名词+だったら
  朝鲜语：-(으)면 / -았/었더니（韩语 -(으)면 表条件，-았/었더니 表前项完成后的发现；日语 たら 一个形式兼表两者，使用范围更广。）
- **〜なら**：如果是…的话
  接续：动词普通形／い形容词／な形容词／名词 + なら
  朝鲜语：-(이)라면 / -다면（韩语 -(이)라면 与名词搭配，-다면 与动词、形容词搭配；日语 なら 前接形式不随词性变化，接续更简单。）
- **〜と（conditional）**：一…就…；如果…就…
  接续：动词辞书形／ない形／い形容词 + と；な形容词・名词 + だ + と
  朝鲜语：-(으)면（버튼을 누르면 불이 켜진다 对照 ボタンを押すと電気がつく。と 适合规律、自动反应和叙事中的发现；若后句要对听者发请求，通常换成 たら。）
