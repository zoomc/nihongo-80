## 新词 25

- **しばらく**（しばらく）暂时｜韩语参考：당분간（暂时，暂且）<br>
  例：ここしばらく彼にまるで会わない。（最近一直没见到他。）
- **島**（しま）岛｜韩语参考：섬（岛，岛屿）<br>
  例：その島にはとても近づきやすい。（那座岛很容易靠近。）
- **市民**（しみん）市民｜韩语参考：시민（市民）<br>
  例：私は千葉市民ですが、東京で勤めています。（我是千叶市民，在东京上班。）
- **事務所**（じむしょ）事务所｜韩语参考：사무소（事务所，办事处）<br>
  例：私のおじはこの事務所で働いている。（我叔叔在这家事务所工作。）
- **社会**（しゃかい）社会｜韩语参考：사회（社会）<br>
  例：彼の一生は社会の下積みで終わった。（他一生在社会底层度过。）

  例：この会社の社長は誰ですか。（这家公司的社长是谁？）

  例：その車がじゃまです。動かしてください。（那辆车挡路了，请挪开。）
- **ジャム**（ジャム）果酱｜韩语参考：잼（果酱）<br>
  例：イチゴはジャムに作られる。（草莓被做成了果酱。）
- **自由**（じゆう）自由｜韩语参考：자유（自由）<br>

- **習慣**（しゅうかん）习惯｜韩语参考：습관（习惯）<br>
  例：その習慣は中国で始まった。（那个习惯起源于中国。）
- **住所**（じゅうしょ）住址｜韩语参考：주소（地址，住址）<br>

  例：あなたを私の両親に紹介したい。（我想把你介绍给我的父母。）
- **小学校**（しょうがっこう）小学｜韩语参考：소학교（小学） / 국민학교（小学） / 초등학교（小学）<br>
  例：あなたは小学校に通っているの？（你在上小学吗？）
- **小説**（しょうせつ）小说｜韩语参考：소설（小说）<br>
  例：トムは小説を読んでいる。（汤姆正在读小说。）
- **招待**（しょうたい）邀请；招待｜韩语参考：초대（邀请；招待） / 초청（邀请）<br>
  例：ご招待をありがとうございます。（感谢您的邀请。）
- **承知**（しょうち）知道；同意｜韩语参考：알다 / 승낙<br>
  例：人はすべて死すべきものと承知している。（我明白人终有一死。）
- **将来**（しょうらい）将来；前途｜韩语参考：장래（将来，未来） / 뒷길（前程，前途） / 미래（未来，将来）<br>
  例：将来の事を考えずにはいられない。（不由得不去想将来的事。）
- **食事**（しょくじ）吃饭；用餐｜韩语参考：식사（用餐，就餐，餐）<br>
  例：食事は母に作ってもらっています。（饭菜是让母亲给我做的。）
- **食料品**（しょくりょうひん）食品｜韩语参考：식료품（食品原料）<br>

- **女性**（じょせい）女性｜韩语参考：여성（女性）<br>
  例：その少女は大きくなってすらりとした女性になった。（那个女孩长大后成了身材苗条的女性。）
- **知らせる**（しらせる）通知；告知｜韩语参考：알리다（告知） / 기별하다（送信，传信，通知）<br>
  例：彼女はそれをどのようにして知らせたのですか。（她是怎么把这件事通知出去的？）
- **人口**（じんこう）人口｜韩语参考：인구（人口）<br>
  例：インドの人口はどのくらいですか。（印度的人口有多少？）
- **神社**（じんじゃ）神社｜韩语参考：신사（일본의 신을 모신 곳）<br>
  例：京都には多くの神社がある。（京都有很多神社。）
- **親切**（しんせつ）亲切；热心｜韩语参考：친절（亲切，关切，热情）<br>
  例：あなたの家族はきっと親切でしょう。（你的家人一定很热心吧。）
- **新聞社**（しんぶんしゃ）报社｜韩语参考：신문사（报社）<br>
  例：どちらの新聞社にお勤めですか。（您在哪家报社工作？）

## 语法

- **〜ようだ**：好像…；似乎…
  接续：动词普通形／い形容词 + ようだ；な形容词+な／名词+の + ようだ
  朝鲜语：-(으)ㄴ/는 것 같다（韩语 것 같다 与 ようだ 对应，但日语 ようだ 还常用于比喻和委婉断定；韩语 것 같다 的推测语气更单一。）
- **〜みたい**：好像…；像…一样
  接续：动词普通形／い形容词／な形容词词干／名词 + みたいだ（口语）
  朝鲜语：-(으)ㄴ/는 것 같다 / 처럼（韩语表比喻用 처럼，表推测用 것 같다；日语 みたい 一个形式兼表两者，且接续不随词性变化。）
- **〜すぎる**：过于…；…过头
  接续：动词ます形去ます／い形容词去い／な形容词词干 + すぎる
  朝鲜语：너무 …하다（韩语用「너무」+形容词，位置在词前；日语 すぎる 是后缀，接在词干后，且可用于动词（食べすぎる），韩语需说 너무 많이 먹다。）
