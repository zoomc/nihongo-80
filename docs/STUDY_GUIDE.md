# 每天怎么学

打开线上首页，点“开始或继续学习”。网页是资源，会话负责反馈；不用管理仪表盘或多套任务系统。

## 网页 42 分钟

1. 复习：先想再翻。课页提供课程复习词，私人会话根据 SQLite 的真实到期队列补充当天复习，不把公开静态页冒充实时 FSRS。
2. 新词：只完成必学卡。常规最多16个、听力日最多11个。韩语提示用来理解意义，不意味着日语与韩语在所有语境可互换。还有余力再勾选拓展。
3. 语法：看接续、例句及韩语区别，用自己的经历想句子。
4. 听力日：先听完整音频，再答三题，最后看脚本。播放器可暂停、拖动；设备无法播放时使用设备朗读备用。真人听力和官方样题在“官方资源”页。
5. 句子：先写三句必做。其余七句是拓展，不挤占必学预算。
6. 练习：完成六题。周测和阶段日把部分释义题换成阅读信息提取、语境语法，不额外堆题。

点保存即可保留作答。首次云端保存需输入个人学习口令，本机在 `deploy/.sync-key`；只保留在当前标签页。口令不要贴进仓库、报告或外部网站。也可以直接“导出作答”，交给会话导入，断网或达到云端预算仍能继续学习。

## 会话 18 分钟

教师或能读本项目文件的 agent 执行：

```sh
python3 scripts/session_v5.py daily --sync
# 输出下一未完成课的 brief 和链接；云端密钥自动从本机读取，不回显。
python3 scripts/nh80.py start-day N
```

网页导出方式：

```sh
python3 scripts/nh80.py import-file --file /path/to/nihongo-day-N.json
```

答疑、抽三词主动回忆、独立造两句、逐句批改三句翻译。教师把真实原文、反馈和语法评分填进脚本生成的 `days/day-NNN/output-review.json`，然后：

```sh
python3 scripts/nh80.py confirm-output --day N --file days/day-NNN/output-review.json
python3 scripts/nh80.py finish-day N
```

选择题必须全做且正确率至少70%，自主造句须通过教师评分，才计当天完成。错了就先改再重试，原始作答和批改保留；完成不等于掌握。新会话从 SQLite 和文件读取，不靠记忆。默认下一课取第一个未完成日；显式 `daily --day N` 只是打开指定课，不会伪造此前完成。

## N3 检验

周阅读用于检查是否抓住事实；阶段短测用于发现薄弱项。第148课之后，从资源页打开官方N3练习集，按官网说明完成文字词汇、语法阅读与听力，可分多个学习时段，再核对官方答案。本站原创建议题不冒充官方卷，也不换算官方标准分。薄弱项回到对应词句、错题和FSRS复习，不因赶进度降低题目标准。
