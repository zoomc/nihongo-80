# Day 024 · 〜と（and）、〜と（with）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜と（and）、〜と（with）」造两句自己的话，表达：…和…（全部列举）；和…一起

## 新词 20

- **それでは**（それでは）那么｜韩语参考：그러면<br>
  例：それでは、あなたは来ないということですか。（那么，你是说不来了吗？）
- **大学**（だいがく）大学｜韩语参考：대학（大学） / 대학교（大学）<br>
  例：大学で何をするつもりですか。（你打算在大学做什么？）
- **大使館**（たいしかん）大使馆｜韩语参考：대사관（大使馆）<br>
  例：日本大使館はどこにありますか。（日本大使馆在哪里？）
- **大好き**（だいすき）很喜欢｜韩语参考：매우 좋아하다<br>
  例：ロジャーはパーティーが大好きだ。（罗杰特别喜欢聚会。）
- **大切**（たいせつ）重要｜韩语参考：소중하다 / 중요하다<br>
  例：本を読むことは大切です。（读书很重要。）
- **台所**（だいどころ）厨房｜韩语参考：부엌（厨房） / 주방（厨房）<br>
  例：ルーシーは今台所にいるでしょう。（露西现在应该在厨房吧。）
- **たいへん**（たいへん）非常；辛苦｜韩语参考：매우 / 힘들다<br>
  例：それはたいへんなショックでした。（那真是巨大的打击。）
- **たくさん**（たくさん）很多｜韩语参考：많이<br>
  例：なすべきことがまだたくさんある。（还有很多事该做。）
- **タクシー**（タクシー）出租车｜韩语参考：택시（出租车）<br>
  例：そのタクシーはいきなり左に曲がった。（那辆出租车突然向左拐了。）
- **出す**（だす）拿出；寄出｜韩语参考：내다（拿出） / 꺼내다（拿出，掏出，取出） / 내놓다（拿出来）<br>
  例：ここではおいしい食べ物が出されます。（这里会端出好吃的饭菜。）
- **立つ**（たつ）站｜韩语参考：서다（站，站立）<br>
  例：立っているのは、みんな男だった。（站着的全是男人。）
- **たて**（たて）竖；长度｜韩语参考：세로 / 길이<br>
  例：テーブルを縦一列に並べなさい。（把桌子竖着排成一列。）
- **建物**（たてもの）建筑物｜韩语参考：건물（建筑，建筑物） / 건조물（建造物，建筑物）<br>
  例：建物がとっても小さく見えるよ。（那些建筑看起来好小啊。）
- **楽しい**（たのしい）快乐｜韩语参考：즐겁다<br>
  例：あなたと一緒にいて楽しかった。（和你在一起很开心。）
- **頼む**（たのむ）请求；点（菜）｜韩语参考：청하다（请求，委托，嘱托）<br>
  例：あなたに頼んでもよろしいですか。（能拜托你一件事吗？）
- **たばこ**（たばこ）香烟｜韩语参考：담배<br>
  例：男はライターでたばこに火をつけた。（那个男人用打火机点着了烟。）
- **たぶん**（たぶん）大概｜韩语参考：아마<br>
  例：君にはたぶんみんなわかっていることでしょう。（这些你大概都明白吧。）
- **食べ物**（たべもの）食物｜韩语参考：음식（食物，食品） / 먹을거리（食物，食品）<br>
  例：食べ物はすべてなくなってしまった。（食物全都吃光了。）
- **卵**（たまご）蛋｜韩语参考：알（蛋，卵）<br>
  例：卵を一ダースづつつめなさい。（请把鸡蛋按每打装好。）
- **誰**（だれ）谁｜韩语参考：누구（谁）<br>
  例：誰がこれをしたのかはわからない。（不知道这是谁干的。）

## 语法

- **〜と（and）**：…和…（全部列举）
  接续：名词 + と + 名词（全部列举）
  朝鲜语：와/과（韩语 와/과 与 と 对应，随收音换形；日语 と 还可表引用和共同对象，功能比韩语 와/과 更广。）
- **〜と（with）**：和…一起
  接续：名词（人）+ と（共同）
  朝鲜语：와/과 함께（韩语 와/과 可表共同，但口语更常用 하고；日语 と 后常可加 いっしょに，韩语 함께 的位置较固定。）

## 汉字 4

- **音** 音；声音；音乐｜音：オン｜训：おと
- **楽** 音乐；快乐；轻松｜音：ガク、ラク｜训：たのしい
- **料** 料；材料；费用；工资｜音：リョウ｜训：
- **理** 理；理由；条理；料理｜音：リ｜训：
