# Day 113 · 〜ほど、〜くらい / 〜ぐらい（extent）

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜ほど、〜くらい / 〜ぐらい（extent）」造两句自己的话，表达：到了…的程度；到…地步；至少…

## 新词 14

- **指す**（さす）指；指向｜韩语参考：짚다（指） / 가리키다（指，指着，指出）<br>
  例：＆という記号は、ａｎｄを指す。（「＆」这个符号指的是 and。）
- **座席**（ざせき）座位｜韩语参考：좌석（坐席，座位） / 자리（座位，席位）<br>
  例：鞄を座席の下に置いてください。（请把包放在座位下面。）
- **誘う**（さそう）邀请；引诱｜韩语参考：권하다 / 유혹하다<br>
  例：ウラウラとした日差しに誘われて、眠りに落ちた。（暖洋洋的阳光让人犯困，我不知不觉睡着了。）
- **札**（さつ）纸币｜韩语参考：지폐<br>
  例：１０００円札をくずしていただけませんか。（能帮我把一千日元换开吗？）
- **作家**（さっか）作家｜韩语参考：작가（作家）<br>
  例：その作家は私たちによく知られています。（那位作家我们很熟悉。）
- **作曲**（さっきょく）作曲｜韩语参考：작곡（作曲，谱曲）<br>
  例：この音楽はバッハによって作曲された。（这首曲子是巴赫作的。）
- **ざっと**（ざっと）大致；粗略｜韩语参考：대충（大概，大致，大体） / 슬쩍（草草地，大致地） / 슬쩍슬쩍（大致地，草草地）<br>
  例：私はパンフレットにざっと目をとおした。（我大致浏览了一遍小册子。）
- **さっぱり**（さっぱり）清爽；完全（不）｜韩语参考：상쾌하다 / 전혀（부정과 함께）<br>
  例：私はこの手のことにはさっぱりだ。（这类事我完全不懂。）
- **さて**（さて）那么｜韩语参考：자 / 그런데<br>
  例：さて、次の問題を考えましょう。（那么，来想想下一道题吧。）
- **砂漠**（さばく）沙漠｜韩语参考：사막（沙漠）<br>
  例：サハラは広大な砂漠です。（撒哈拉是一片广阔的沙漠。）
- **差別**（さべつ）歧视；区别｜韩语参考：차별（差别，不平等，歧视）<br>
  例：その週間は差別とは関係がなかった。（那一周和歧视问题没有关系。）
- **作法**（さほう）礼节；礼法｜韩语参考：예법（礼法） / 예절（礼节，礼貌，礼仪）<br>
  例：彼は作法がぎこちない。（他的礼节举止很生硬。）
- **様々**（さまざま）各种各样｜韩语参考：여러 가지<br>
  例：庭には様々な花が咲き乱れていた。（院子里各种花开得繁盛。）
- **覚ます**（さます）弄醒；醒｜韩语参考：깨우다<br>
  例：その物音が私を眠りから覚まさせた。（那声响把我从睡梦中弄醒了。）

## 语法

- **〜ほど**：到了…的程度
  接续：普通形 + ほど；名词 + ほど
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」与「ほど」基本对应；但日语「ほど」还用于「〜ほど〜ない」比较句，韩语要用「-만큼」。）
- **〜くらい / 〜ぐらい（extent）**：到…地步；至少…
  接续：普通形 + くらい／ぐらい；名词 + くらい
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」对应程度用法；“至少”韩语要说「적어도」，日语用「くらい」一并承担，范围更宽。）
