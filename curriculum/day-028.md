# Day 028 · 〜と〜とどちらが、〜の中で〜が一番

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜と〜とどちらが、〜の中で〜が一番」造两句自己的话，表达：…和…哪个更…？；在…中最…

## 新词 23

- **丸い**（まるい）圆的｜韩语参考：동글다（圆圆的） / 둥글다（圆，圆圆的） / 둥그렇다（圆圆的）<br>
  例：ボールは丸い。（球是圆的。）
- **万**（まん）万｜韩语参考：만（万）<br>
  例：このテープレコーダーは４万円しました。（这台录音机花了我四万日元。）
- **万年筆**（まんねんひつ）钢笔｜韩语参考：만년필（钢笔）<br>
  例：新しい万年筆をなくしてしまった。（我把新买的钢笔弄丢了。）
- **磨く**（みがく）擦；刷；磨练｜韩语参考：닦다（刷，擦） / 연마하다（磨练，锻炼，钻研）<br>
  例：そのなべを磨いていただけませんか。（能不能把那口锅擦一擦？）
- **右**（みぎ）右；右边｜韩语参考：우（右） / 오른쪽（右侧，右边） / 오른편（右边，右侧）<br>
  例：アラビア語は右から左へ書きます。（阿拉伯语是从右往左写的。）
- **短い**（みじかい）短｜韩语参考：짧다（短）<br>
  例：日がだんだん短くなっている。（白天渐渐变短了。）
- **見せる**（みせる）给…看；展示｜韩语参考：보여 주다<br>
  例：パスポートを見せてくれませんか。（能给我看看护照吗？）
- **道**（みち）道路；路｜韩语参考：길（路，道，道路）<br>
  例：二本の道はそこでクロスしている。（两条路在那里交叉。）
- **三日**（みっか）三天；三号｜韩语参考：사흘 / 삼 일<br>
  例：１０月３日です。（是十月三号。）
- **三つ**（みっつ）三个｜韩语参考：세 개<br>
  例：コーヒー三つおねがいします。（请来三杯咖啡。）
- **緑**（みどり）绿色；绿｜韩语参考：초록（草绿，草绿色） / 초록색（草绿色）<br>
  例：東京ミッドタウンは緑がいっぱい！（东京中城绿意盎然！）
- **皆さん**（みなさん）大家；各位｜韩语参考：여러분（诸位，各位，大家）<br>
  例：皆さんじっとしていてください。（请大家别动。）
- **南**（みなみ）南；南方｜韩语参考：남쪽（南侧，南边，南方） / 남측（南侧，南边，南方）<br>
  例：フランスは英国の南にある。（法国在英国南边。）
- **耳**（みみ）耳朵｜韩语参考：귀（耳，耳朵） / 가는귀（灵敏的耳朵）<br>
  例：なぜ、あなたの耳はそんなに大きいの？（你的耳朵怎么这么大？）
- **みんな**（みんな）大家；全部｜韩语参考：말끔（干净地，利落地，全部） / 몽땅（都，全部）<br>
  例：女の子はほとんどみんなやさしい。（女孩子几乎都很温柔。）
- **六日**（むいか）六天；六号｜韩语参考：엿새 / 육 일<br>
  例：４月５日か６日に会っていただけませんか。（能不能在四月五号或六号见一面？）
- **向こう**（むこう）对面；那边｜韩语参考：건너（对面） / 고쪽（那边） / 그쪽（那边）<br>
  例：その男の子は向こうにいます。（那个男孩在对面。）
- **六つ**（むっつ）六个｜韩语参考：여섯 개<br>
  例：彼は６行のうちに６つまちがいをした。（他在六行里出了六处错。）
- **村**（むら）村庄｜韩语参考：촌（村子，村庄，乡村） / 동네（小区，社区，村庄） / 마을（村子，村庄）<br>
  例：町は村よりも大きい。（镇比村大。）
- **目**（め）眼睛｜韩语参考：눈（眼睛）<br>
  例：彼女はきれいな目をしている。（她有一双漂亮的眼睛。）
- **メートル**（メートル）米；公尺｜韩语参考：미터（米）<br>
  例：前の人から1メートル離れて並んでください。（请和前面的人隔开一米排队。）
- **眼鏡**（めがね）眼镜｜韩语参考：안경<br>
  例：私はメガネがなくては読めない。（我不戴眼镜就看不了书。）
- **もう一度**（もういちど）再一次｜韩语参考：한 번 더<br>
  例：もう一度ゆっくりお話しください。（请再慢慢说一遍。）

## 语法

- **〜と〜とどちらが**：…和…哪个更…？
  接续：名词 + と + 名词 + とどちらが + 形容词 + か
  朝鲜语：A와 B 중 어느 쪽이（韩语用 와/과 중 어느 쪽이，日语用 と〜とどちらが；韩语需加 중，日语靠 どちら 本身表两者。）
- **〜の中で〜が一番**：在…中最…
  接续：名词（范围）+ の中で + 名词 + が一番 + 形容词
  朝鲜语：… 중에서 …이 가장（韩语 중에서 与 の中で 对应，가장/제일 与 一番 对应；语序上韩语 가장 在形容词前，日语 一番 也在形容词前，较接近。）
