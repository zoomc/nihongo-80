词卡与语法保持原来的暖色纸张视觉。375 手机单列，1280 桌面目录与正文两栏。全局/单卡均有全显、遮中文、遮日语、双向四态，点遮盖文字临时揭开三秒。没有到期项就显示暂无，不捏造复习记录。

词汇保持 150 天全覆盖 2700 个，实际 9–22 个/天；旧设计 16/11 与全覆盖不能同时实现（只有 2175 个容量）。该取舍待用户决定，不能声称已经减量。韩语对应未知显示“未标注对应（待核对）”，不把未知冒充“无直接对应”。例句新增仍是 AI 草稿。

句子保持每天十题：7 中→日、3 日→中。浏览器只显示题干和提示，草稿自动存本机；提交同时送云端，CLI 拉取至 `days/day-NNN/web-drafts.json`，供会话批改，不能据此自动算完成。

练习六题基于当天新词/语法/汉字生成，听力额外三题。共享生成器 `quiz_v5.py` 同时给 CLI 登记标准答案、给网页输出哈希、给 Worker 打包答案。网页不下发独立的答案字段、解析或参考译文；选项哈希可被枚举，不是防作弊或加密。词卡和语法教学例句仍按产品用途显示。

听力为 45 个原创 TTS 版本，来自九类情境各五个事实变体，逐日不复用素材 ID。每篇三个理解题。播放朗读全文；脚本在折叠区，提交前展开即计提示。每篇约 300–400 日文字符，时长按每秒五字估计；未测浏览器实际播放时长，没有真人录音，也未证明 N3 真题难度或 90% 已知词率。

提交按钮仅在 API 确认 `ok:true` 后提示保存成功，失败保留本机载荷并可重试。每次会话有独立 ID，云端与本地均以 session+qid 去重；客户端不提交 correct。作答保存不等于整天完成，完成仍由 CLI 检查全部当天题号与正确率。

Service Worker 使用构建摘要做缓存版本；GET 优先网络，断网才读已访问页面缓存，`/api/` 不缓存。未访问页面不承诺离线可用。

验收实测记录见 `reports/v5_review_codex.md`；教材目标和真实学习用时仍须真人试学验证。
