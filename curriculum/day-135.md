# Day 135 · 〜わりに / 〜わりには

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜わりに / 〜わりには」造两句自己的话，表达：照…来说；相对…而言

## 新词 21

- **ただ**（ただ）只；免费｜韩语参考：단（只，单单） / 무료（免费）<br>
  例：君はただ皿を洗いさえすればいい。（你只要洗碗就行了。）
- **戦い**（たたかい）战斗；斗争｜韩语参考：싸움（争斗，打架，战斗） / 전투（战斗）<br>
  例：戦いは人間の獣性をよびおこす。（战争会唤起人的兽性。）
- **戦う**（たたかう）战斗；斗争｜韩语参考：싸우다（斗争，抗争） / 투쟁하다（斗争，战斗，交锋）<br>
  例：おまえも決して戦う拳を忘れるな。（你也绝不要忘记战斗的拳头。）
- **叩く**（たたく）敲；打｜韩语参考：치다（打，敲，击） / 때리다（打，揍，抽） / 두드리다（敲，拍打）<br>
  例：口答えしたら父は私を叩いた。（我一顶嘴，父亲就打了我。）
- **立ち上がる**（たちあがる）站起来｜韩语参考：일어나다（起，起来） / 일어서다（起身，站起来）<br>
  例：突然若い女性が立ち上がった。（一位年轻女子突然站了起来。）
- **立場**（たちば）立场；处境｜韩语参考：입장（立场） / 처지（处境）<br>
  例：お答えできる立場にありません。（我不便回答。）
- **経つ**（たつ）时间流逝｜韩语参考：흐르다（流，流淌，流逝）<br>
  例：時が経つうちに彼は心変わりした。（随着时间流逝，他变了心。）
- **達する**（たっする）达到｜韩语参考：달하다（达到） / 오르다（达到） / 이르다（达到）<br>
  例：彼らはそれで合意に達するだろう。（他们会就此达成协议吧。）
- **だって**（だって）因为；就连｜韩语参考：왜냐하면 / ~조차<br>
  例：子供にだってそんな事は分かるよ。（那种事连小孩都懂。）
- **たっぷり**（たっぷり）充足；足够｜韩语参考：듬뿍（足够地，充分地） / 넉넉히（足够地，充足地，充分地） / 충분히（充分地，充足地）<br>
  例：まだ時間はたっぷりある。（时间还很充裕。）
- **たとえ**（たとえ）纵然；假设｜韩语参考：설령 / 가령<br>
  例：たとえどんなことがあってもあきらめません。（无论发生什么，我都不会放弃。）
- **谷**（たに）山谷｜韩语参考：골짜기（山沟，山谷） / 산골짝（山谷，山沟）<br>
  例：谷は彼の呼び声でこだました。（山谷回荡着他的喊声。）
- **他人**（たにん）别人；外人｜韩语参考：남（别人，他人，人家） / 외인（外人）<br>
  例：彼女はもっと他人の言うことを聞くべきだ。（她应该多听听别人的话。）
- **種**（たね）种子；起因｜韩语参考：씨（种子，籽） / 불씨（导火线，起因，诱因） / 씨앗（种子）<br>
  例：そんなことをすれば笑いものの種なるよ。（做那种事会被人当成笑柄的。）
- **束**（たば）把；捆｜韩语参考：꼭지（把） / 묶음（捆，束） / 뭉치（团，捆，束）<br>
  例：彼は古い手紙を束にした。（他把旧信捆成了一捆。）
- **度**（たび）次；回｜韩语参考：번 / 차례<br>
  例：彼は東京へ来るたび私を訪ねてきた。（他每次来东京都来看我。）
- **旅**（たび）旅行｜韩语参考：여행（旅行，旅游，游行）<br>
  例：旅はよりよい教育法の一つである。（旅行是较好的教育方式之一。）
- **たびたび**（たびたび）屡次；多次｜韩语参考：자주 / 여러 번<br>
  例：私はたびたび彼から手紙をもらう。（我常收到他的来信。）
- **玉**（たま）球；硬币｜韩语参考：공 / 구슬 / 동전<br>
  例：ニッケルは５セント玉です。（镍币是五美分的硬币。）
- **偶**（たま）偶尔｜韩语参考：가끔<br>
  例：友理子はたまの逢瀬を心行くまで楽しんでしまいました。（友理子尽情享受着难得的幽会。）
- **弾**（たま）子弹｜韩语参考：탄환<br>
  例：弾が彼の頬をかすめた。（子弹擦过他的脸颊。）

## 语法

- **〜わりに / 〜わりには**：照…来说；相对…而言
  接续：动词普通形/い形容词/ナ形容词な/名词の + わりに（は）
  朝鲜语：-에 비해서（韩语没有与「わりに」完全对应的形式，常译成「-에 비해서」或「-치고는」；日语专表“比例上不符预期”。）
