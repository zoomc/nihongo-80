# Day 075 · ～おかげで / ～せいで、～によって / ～について / ～にとって

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「～おかげで / ～せいで、～によって / ～について / ～にとって」造两句自己的话，表达：多亏…／都怪…；因…而异／关于…／对…来说

## 新词 14

- **見つける**（みつける）找到（他动）｜韩语参考：찾다 / 발견하다（타동사）<br>
  例：鍵を見つけました。（找到钥匙了。）
- **見つかる**（みつかる）被找到；（东西）找到了（自动）｜韩语参考：찾아지다 / 발견되다（자동사）<br>
  例：無くした時計が見つかりました。（丢的表找到了。）
- **変える**（かえる）改变（他动）｜韩语参考：바꾸다（改变，转变，更改）<br>
  例：予定を変えました。（改了计划。）
- **職場**（しょくば）职场；工作岗位｜韩语参考：일터（工作岗位） / 자리（职，岗位） / 직장（工作单位，职场）<br>
  例：職場の人と相談します。（和同事（职场的人）商量。）
- **会議**（かいぎ）会议｜韩语参考：회의（会，会议）<br>
  例：午後から会議があります。（下午开始有会议。）
- **残業**（ざんぎょう）加班｜韩语参考：야근（加班） / 잔업（加班）<br>
  例：今日は残業しなければなりません。（今天不得不加班。）
- **給料**（きゅうりょう）工资；薪水｜韩语参考：급료（工资，薪金） / 급여（报酬，薪水，工资） / 봉급（薪资，薪酬，工资）<br>
  例：給料が上がりました。（工资涨了。）
- **報告**（ほうこく）报告；汇报｜韩语参考：보고（报告）<br>
  例：上司に結果を報告します。（向上司汇报结果。）
- **相談**（そうだん）商量；咨询｜韩语参考：상담（咨询） / 상의（商量，商议，讨论） / 의논（商议，讨论，商量）<br>
  例：先生に進路を相談します。（找老师商量升学去向。）
- **就職**（しゅうしょく）就职；就业｜韩语参考：취업（就业） / 취직（就业，就职）<br>
  例：大学を卒業して、就職しました。（大学毕业后就业了。）
- **手続き**（てつづき）手续；程序｜韩语参考：수속（手续） / 절차（手续，步骤，程序）<br>
  例：入学の手続きをします。（办理入学手续。）
- **申請**（しんせい）申请（书面）｜韩语参考：신청（申请）<br>
  例：ビザを申請しました。（申请了签证。）
- **技術**（ぎじゅつ）技术｜韩语参考：기술（技术）<br>
  例：新しい技術を開発します。（开发新技术。）
- **故障**（こしょう）故障；出毛病｜韩语参考：탈（故障） / 고장（故障）<br>
  例：パソコンが故障しました。（电脑出故障了。）

## 语法

- **～おかげで / ～せいで**：多亏…／都怪…
  接续：名/な形 + の/な + おかげで／せいで；普通形 + おかげで／せいで
  朝鲜语：-덕분에 / -때문에（韩语 덕분에 通常表示多亏，也可反讽；때문에 可用于中性原因。日语 せいで 常带不满或归因。）
- **～によって / ～について / ～にとって**：因…而异／关于…／对…来说
  接续：名詞 + によって／について／にとって
  朝鲜语：-에 따라 / -에 대해 / -에게（韩语에 따라表依据或随…而异，에 대해关于，에게表评价对象，三者分工比日语清楚。）
