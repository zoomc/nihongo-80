## 新词 25

- **分かる**（わかる）懂；明白｜韩语参考：알다（知道，明白）<br>
  例：日本語が分かります。（懂日语。）
- **高い**（たかい）贵；高｜韩语参考：높다（高） / 크다（大，高，长，壮阔） / 비싸다（贵）<br>
  例：この本は高いです。（这本书贵。）
- **安い**（やすい）便宜｜韩语参考：싸다（便宜，贱） / 헐하다（廉价，贱，便宜）<br>
  例：電車よりバスのほうが安いです。（公交比电车便宜。）
- **大きい**（おおきい）大｜韩语参考：크다（大，高，长，壮阔）<br>
  例：大きい家です。（大房子。）
- **小さい**（ちいさい）小｜韩语参考：작다（小， 矮）<br>
  例：小さい部屋です。（小房间。）
- **新しい**（あたらしい）新｜韩语参考：새롭다（新）<br>
  例：新しいパソコンがほしいです。（想要新电脑。）
- **美味しい**（おいしい）好吃；美味｜韩语参考：맛나다（好吃，可口） / 맛있다（好吃，可口，香） / 맛깔나다（可口，美味）<br>
  例：この料理は美味しいです。（这道菜好吃。）
- **忙しい**（いそがしい）忙｜韩语参考：바쁘다（忙，忙碌，紧张）<br>
  例：今週は忙しいです。（这周很忙。）
- **寒い**（さむい）冷（天气/体感）｜韩语参考：춥다（冷）<br>
  例：今日は昨日ほど寒くないです。（今天没昨天冷。）
- **好き**（すき）喜欢｜韩语参考：좋아하다<br>
  例：魚が好きです。（喜欢鱼。）
- **元気**（げんき）精神；健康；有活力｜韩语参考：건강하다 / 활기차다<br>
  例：彼女は元気です。（她很精神。）
- **静か**（しずか）安静；宁静｜韩语参考：조용하다<br>
  例：この部屋は静かです。（这个房间安静。）
- **便利**（べんり）方便；便利｜韩语参考：편리（便利，方便）<br>
  例：駅が近いので、通勤に便利です。（因为离车站近，上下班很方便。）
- **とても**（とても）非常；很｜韩语参考：된통（很，厉害） / 매우（非常，极其，很） / 몹시（十分，非常，太）<br>
  例：この本はとても高いです。（这本书很贵。）
- **少し**（すこし）稍微；一点｜韩语参考：좀（一点点，有一点） / 살짝（稍微） / 슬쩍（稍微）<br>
  例：少し休みます。（稍微休息一下。）
- **そして**（そして）然后；而且｜韩语参考：그리고（而且，并且，况且）<br>
  例：本を読んで、そして寝ます。（读书，然后睡觉。）
- **だから**（だから）所以；因此｜韩语参考：그러므로（因此，所以）<br>
  例：雨です。だから、行きません。（下雨，所以不去。）
- **でも**（でも）不过；但是（句首连词）｜韩语参考：그런데（可是，但是）<br>
  例：この店は小さいです。でも、料理がおいしいです。（这家店很小，不过菜很好吃。）
- **すぐ**（すぐ）马上；立刻；就近｜韩语参考：곧（马上，就） / 금방（马上，立刻，立马） / 당장（当前，立刻）<br>
  例：すぐ行きます。（马上就去。）
- **ゆっくり**（ゆっくり）慢慢地；好好地｜韩语参考：천천히（慢慢地，缓慢地） / 슬렁슬렁（慢慢地，轻轻地）<br>
  例：ゆっくり話してください。（请慢慢说。）
- **会う**（あう）见面｜韩语参考：보다（看，见，见面） / 만나다（见面，相逢）<br>
  例：もうスミスさんに会われましたね。（您已经见过史密斯先生了吧。）
- **青**（あお）蓝色；青色｜韩语参考：파랑 / 푸른색<br>
  例：信号が青に変わったわよ。（信号灯变绿了。）
- **青い**（あおい）蓝色的；不成熟｜韩语参考：파랗다 / 미숙하다<br>
  例：お前はまだ「青い」な。（你还嫩着呢。）
- **赤**（あか）红色｜韩语参考：빨강（红色，红色染料） / 붉은색（红色） / 빨간색（红色）<br>
  例：赤インクで書いてはいけない。（不能用红墨水写。）
- **赤い**（あかい）红色的｜韩语参考：빨갛다<br>
  例：彼女は赤いスカートをはいていた。（她穿着一条红裙子。）

## 语法

- **から ～ まで**：从…到…
  接续：名詞（时/处） + から + 名詞 + まで
  朝鲜语：부터 ~ 까지（时间起点常用 부터，空间起点常用 에서，两者在日语都用 から。まで 对应 까지，表示持续或范围终点；截止前做完用 までに。）
- **（场所）に ～ がある / いる**：（某地）有…
  接续：場所 + に + 物/人 + が + ある／いる
  朝鲜语：에 ~ 이/가 있다 / 계시다（한국어 있다 多数既可说人和动物，也可说物品。日语通常人、动物用 いる，物品、植物等用 ある；「老师在」也可用尊敬语 いらっしゃる。）
