## 新词 25

- **実行**（じっこう）实行；执行｜韩语参考：실행（实行，执行，实施）<br>
  例：彼は計画を立てれば必ず実行する。（他一旦订了计划就一定执行。）
- **実際**（じっさい）实际｜韩语参考：실제（实际） / 기실（其实，实际上） / 실상（实际上，其实）<br>
  例：人間は実際自然のなすがままである。（人类实际上只能听任自然摆布。）
- **実施**（じっし）实施｜韩语参考：실시（实施，实行）<br>
  例：その計画は実施された。（那个计划已经实施了。）
- **支店**（してん）分店｜韩语参考：지점（分店）<br>
  例：新しい支店が来月シカゴに開店する。（新分店下个月在芝加哥开业。）
- **指導**（しどう）指导｜韩语参考：지도（指导）<br>
  例：彼は指導されなくても学ぶことができた。（即使没人指导，他也能学。）
- **自動**（じどう）自动｜韩语参考：자동（自动）<br>
  例：彼女は自動式の洗濯機をもっている。（她有一台自动洗衣机。）
- **品**（しな）商品；物品｜韩语参考：물건（商品，物品）<br>
  例：ここでお買い上げの品は無料で配達します。（在本店购买的商品免费送货。）
- **支配**（しはい）支配；统治｜韩语参考：지배（统治）<br>
  例：静けさが森を支配していた。（寂静笼罩着森林。）
- **芝居**（しばい）戏剧｜韩语参考：연극（话剧，戏剧）<br>
  例：どの芝居がいいですか。（哪出戏好呢？）
- **しばしば**（しばしば）屡次；常常｜韩语参考：누차（屡次）<br>
  例：貧困はしばしば犯罪の原因となる。（贫困常常成为犯罪的原因。）
- **芝生**（しばふ）草坪｜韩语参考：잔디<br>
  例：彼らは芝生の上に横になっていた。（他们躺在草坪上。）
- **支払**（しはらい）支付｜韩语参考：지불<br>
  例：どのような支払方法がありますか。（有哪些支付方式？）
- **支払う**（しはらう）支付｜韩语参考：치르다（支付，付，付出） / 지불하다（支付，付给，付款）<br>
  例：私はその本に３ドル支払った。（我为那本书付了三美元。）
- **死亡**（しぼう）死亡｜韩语参考：사망（死亡） / 운명（去世，死亡） / 죽음（死亡）<br>
  例：彼は母親が死亡したという電報を受け取った。（他收到一封电报，说他母亲去世了。）
- **資本**（しほん）资本｜韩语参考：자본（资本，资金）<br>
  例：彼らには次の工場を建設するだけの資本がある。（他们有足够的资本再建一座工厂。）
- **しまい**（しまい）姐妹｜韩语参考：자매<br>
  例：彼の姉妹は二人とも美人です。（他的两个姐妹都是美女。）
- **しまう**（しまう）收拾；做完｜韩语参考：치우다 / ~해 버리다<br>
  例：本とノートをしまいなさい。（把书和笔记本收起来。）
- **しまった**（しまった）糟糕｜韩语参考：아차（糟糕） / 아뿔싸（糟糕，坏了）<br>
  例：しまった！ウッカリして、携帯電話をお店に忘れてきちゃった。（糟糕！我一不小心把手机忘在店里了。）
- **自慢**（じまん）自豪；自夸｜韩语参考：자랑 / 자랑하다<br>
  例：われわれは体力を自慢した。（我们对自己的体力很自豪。）
- **州**（しゅう）州｜韩语参考：주<br>
  例：南部の州へ冬期に旅行すると、今旅行するよりも料金が高くなります。（冬天去南部各州旅行，费用会比现在高。）
- **週**（しゅう）周；星期｜韩语参考：주（一周，一星期） / 주일（周，星期）<br>
  例：それはその前の週に買ったものでした。（那是前一周买的。）
- **銃**（じゅう）枪；枪支｜韩语参考：총（枪）<br>
  例：警察は簡単に銃を使ってはいけない。（警察不能轻易动用枪支。）
- **周囲**（しゅうい）周围；四周｜韩语参考：주위（周围）<br>
  例：この木は周囲３メートルある。（这棵树周长有三米。）
- **収穫**（しゅうかく）收获；收成｜韩语参考：수확（收获，收成，产量） / 소출（收成，产量）<br>
  例：私たちはみな収穫の手伝いをした。（我们都帮忙做了收割的活儿。）
- **週間**（しゅうかん）周；星期｜韩语参考：주간（周，星期） / 주일（周，星期）<br>
  例：もう２週間たったら帰ります。（再过两周我就回来。）

## 语法

- **〜にとって**：对…来说
  接续：名词 + にとって；名词 + にとっての + 名词
  朝鲜语：-에게 있어서（韩语「-에게 있어서」同样表立场，但较长、偏书面；日语「にとって」口语也常用，后项多接评价性表达。）
- **〜にしては**：照…来说；以…而言
  接续：动词普通形／名词 + にしては；名词化的 の + にしては 也可用
  朝鲜语：-치고는（韩语「-치고는」与「にしては」几乎一一对应，都含“出乎预料”；但日语多接身份、时间名词。）
- **〜にしても**：即使…；就算是…
  接续：动词普通形／名词 + にしても；名词化的 の + にしても 也可用
  朝鲜语：-다고 해도（韩语「-다고 해도」与「にしても」对应；但日语常隐含责备，韩语语气更中性，需靠上下文补出不满。）
