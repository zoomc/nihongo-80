Day 030 · 普通形 + か どうか、普通形 + んです / のだ、N に Vて ほしい / Vないで ほしい、名詞/な形词干 + みたい(だ/な/に)

语法 4 条

普通形 + か どうか
是否…；…还是不…
動詞/い形 普通形 + かどうか；名詞・な形 词干 + かどうか（不加 だ/な）；疑问词问句不用 かどうか
把是非疑问嵌入句中，作 分かる／調べる／決める／聞く 等的内容；整体可当名词用（が／を／は）
韩语对应-는지 / -(으)ㄴ지
오는지 对照 来るかどうか，학생인지 对照 学生かどうか。名词可直接接 かどうか；问谁、哪里时用疑问词 + か。
이케루 카 도우 카, 마다와카리마센.
行けるかどうか、まだ分かりません。
还不知道能不能去。
카레 가 쿠루 카 도우 카, 키이테미마스.
彼が来るかどうか、聞いてみます。
我去问问他来不来。
易错易混点
  • ✗ 行くかどうかを分かりません。✓ 行くかどうか分かりません。分かる 的对象用 が（分かりません），不用 を。
  • ✗ 便利だかどうか調べます。✓ 便利かどうか調べます。名词、な形容词接 かどうか 要去掉 だ：便利かどうか。
普通形 + んです / のだ
（是）因为…；其实是…（说明/强调语气）
動詞・い形 普通形 + んです；な形・名詞 + な + んです；礼貌体 んです，简体 のだ／んだ
解释原因、背景或强调；回答 どうして 时用；口语用 んです，书面/简体用 のだ
韩语对应-거든요 / -는데요 / -잖아요
韩语说明语气由거든요、는데요、잖아요等分担；日语んです一形统合，须按语境选择。
오소쿠나떼스미마센. 덴샤 가 오쿠레탄데스.
遅くなってすみません。電車が遅れたんです。
抱歉迟到了，是电车晚点了。
코노미세 와 타카인데스 카.
この店は高いんですか。
这家店（是）很贵吗？
易错易混点
  • ✗ 電車が遅れたです。✓ 電車が遅れたんです。「遅れた」是普通形，正好接 んです；不能直接接 です。
  • ✗ 彼は学生んです。✓ 彼は学生なんです。名词接 んです 要加 な：学生なんです。
N に Vて ほしい / Vないで ほしい
발음N 니 V테 호시이 / V나이데 호시이
希望（别人）做…／希望别…
動詞 て形 + ほしい；否定 ない形 + で + ほしい；动作主体用 に（或 が）
てほしい 表说话人希望某事发生，动作主体可以是他人或自然事物；对人直接提出要求时要考虑关系与礼貌程度。
韩语对应-아/어 주기를 바라다
韩语希望别人做用주기를 바라다，对长辈须加시；日语てほしい不宜直接对长辈说。
모우스코시마떼호시이데스.
もう少し待ってほしいです。
希望（你）再等一下。
오오키나코에 데 하나시사나이데호시이데스.
大きな声で話さないでほしいです。
希望别大声说话。
易错易混点
  • ✗ 希望对方别吸烟：たばこを吸わなくてほしいです。✓ たばこを吸わないでほしいです。希望别人别做，用 ないでほしい；なくてほしい 不成立。
  • ✗ 先生に待ってほしいです。✓ 先生に少しお待ちいただけませんか。对长辈直接说 てほしい 很失礼，要换成 お待ちいただけませんか。
名詞/な形词干 + みたい(だ/な/に)
好像…；像…一样（口语推量/比喻）
名詞 + みたい（不加 の）；な形 词干 + みたい；動詞/い形 普通形 + みたい；みたいな＋名／みたいに＋動
口语版 〜ようだ（G0044）；比 らしい/そう 更随意；比喻用 まるで…みたい
韩语对应-(으)ㄴ 것 같다 / -처럼
船みたいだ 可对照 배 같아，船のようだ 可对照 배와 같다。みたい 常见于会话；名词前用 みたいな、动作前用 みたいに。
카레 와 겐키 자 나이미타이데스.
彼は元気じゃないみたいです。
他好像不太精神。
쿄우 와 하루미타이 니 아타타카이데스.
今日は春みたいに暖かいです。
今天暖和得像春天。
易错易混点
  • ✗ 彼は学生のみたいです。✓ 彼は学生みたいです。名词接 みたい 不加 の；ようだ 才需要 の。
  • ✗ 彼女はモデルみたいなきれいです。✓ 彼女はモデルみたいにきれいです。修饰名词用 みたいな，修饰形容词或动词用 みたいに。
