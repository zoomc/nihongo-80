Day 024 · 〜だ、〜ではありません / 〜じゃない、〜でした

语法 3 条

〜だ
발음〜다
是…（普通断定）
名词／な形容词 + だ
普通体判断句，用于朋友间会话、日记或报道。
韩语对应이다
이다 与 だ 都可作普通体判断，韩语终结时还可选 학생이야／의사야 等熟人语体。日语名词、な形容词常用 だ，动词、い形容词不再接 だ。
쿄우 와 니치요우비다.
今日は日曜日だ。
今天是星期天。
아노히토 와 와타시 노 아니다.
あの人は私の兄だ。
那个人是我哥哥。
아시타 와 야스미다카라, 유꾸리네루.
明日は休みだから、ゆっくり寝る。
明天休息，所以我要睡个懒觉。
易错易混点
  • ✗ 今日は日曜日だです。✓ 今日は日曜日です。だ 与 です 不能并用
〜ではありません / 〜じゃない
발음〜데와아리마센 / 〜자나이
不是…
名词／な形容词 + ではありません（礼貌）／じゃない（普通）
否定判断句，礼貌体用 ではありません，口语用 じゃない。
韩语对应아니다 / 아닙니다
학생이 아닙니다／의사가 아닙니다 取决于有无收音，日语统一把 ではありません 接在名词后。では 的会话缩约为 じゃ，礼貌度仍由 ありません／ない 等句末决定。
와타시 와 센세이 데 와 아리마센. 가쿠세이데스.
私は先生ではありません。学生です。
我不是老师，是学生。
쿄우 와 야스미 자 나이.
今日は休みじゃない。
今天不是休息日。
코노마치 와 아마리니기야카데와아리마센.
この町はあまりにぎやかではありません。
这个镇不太热闹。
易错易混点
  • ✗ 私は先生ではありませんだ。✓ 私は先生ではありません。ではありません 已是完整否定，不能再加 だ
〜でした
발음〜데시타
（过去）是…
名词／な形容词 + でした
礼貌体的过去判断，表示过去的状态或身份。
韩语对应이었습니다 / 였습니다
韩语过去礼貌体 이었습니다/였습니다 随收音变化，日语 でした 形式固定；い形容词过去用 かったです，韩语则用过去时制。
키노우 와 와타시 노 탄조우비데시타.
きのうは私の誕生日でした。
昨天是我的生日。
코도모 노 코로, 야사이 가 키라이데시타.
子どものころ、野菜がきらいでした。
我小时候讨厌蔬菜。
테스토 와 칸탄데시타.
テストはかんたんでした。
考试很简单。
易错易混点
  • ✗ きのうは私の誕生日ですでした。✓ きのうは私の誕生日でした。です 与 でした 不能叠用
