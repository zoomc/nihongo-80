## 新词 25

- **辛い**（つらい）难受；痛苦｜韩语参考：괴롭다（痛苦，难过） / 아프다（难受，难过） / 쓰라리다（痛苦）<br>
  例：流産はとても辛い経験です。（流产是非常痛苦的经历。）
- **釣り**（つり）钓鱼｜韩语参考：낚시<br>
  例：あなたは釣りに行きたがっている。（你很想去钓鱼。）
- **連れ**（つれ）同伴；同行者（〜連れ＝带着…同行）｜韩语参考：동행 / 데리고 감<br>
  例：駅までお連れいたしましょう。（我送您到车站吧。）
- **で**（で）出；出自｜韩语参考：나옴 / 출신<br>

- **出会い**（であい）相遇；邂逅｜韩语参考：만남<br>

- **出会う**（であう）遇见；邂逅｜韩语参考：만나다（遇到，遇见，碰见） / 마주치다（邂逅，偶遇）<br>

  例：バスの停留所まで競争しよう。（我们比赛跑到公交站吧。）

  例：この法律はすべての人に適用される。（这条法律适用于所有人。）

  例：出来れば明日までに帰ります。（可能的话，我明天之前回来。）
- **手品**（てじな）魔术；戏法｜韩语参考：마술（魔术） / 요술（妖术，魔术，妖法）<br>
  例：少年はたくさんの手品が使える。（那个少年会很多魔术。）

- **鉄**（てつ）铁｜韩语参考：철（铁） / 쇠（铁）<br>

- **哲学**（てつがく）哲学｜韩语参考：철학（哲学）<br>

- **手伝い**（てつだい）帮忙；帮手｜韩语参考：도움 / 도우미<br>

- **鉄道**（てつどう）铁路｜韩语参考：철도（铁路，铁道） / 철로（铁路，铁道）<br>

- **徹夜**（てつや）通宵｜韩语参考：철야（彻夜，通宵，通宵达旦） / 밤샘（熬夜，通宵）<br>
  例：私はよく徹夜する。（我经常通宵。）

  例：食べるのにどうしてそんなに手間がかかるのか。（吃个饭怎么这么费事？）
- **デモ**（デモ）游行；示威｜韩语参考：데모（示威，示威游行） / 시위（示威）<br>
  例：デモに参加しようと思う。（我想参加游行。）
- **典型**（てんけい）典型｜韩语参考：전형（典型）<br>
  例：彼女はあらゆる婦徳の典型である。（她是一切妇德的典范。）
- **天候**（てんこう）天气｜韩语参考：날（天气） / 날씨（天气） / 천기（天气；气象）<br>
  例：それはすべて天候に依存している。（那一切都取决于天气。）

## 语法

- **〜とか（hearsay）**：听说…；好像说…
  接续：普通形 + とか（句末，或用「とかで」表原因）
  朝鲜语：-다고 하던데（韩语「-다고 하던데」带“听说…”的转述感；日语「とか」还可单纯列举，需靠位置和语调区分。）
- **〜って**：说是…；所谓…
  接续：普通形 + って；名词 + って（表话题）
  朝鲜语：-대（韩语「-대」是口语转述缩略，与「って」很像；但日语「って」还能当话题助词（「〜って何？」），韩语要用「-는」。）
- **〜ということだ**：据说…；也就是说…
  接续：普通形 + ということだ
  朝鲜语：-다는 것이다（韩语「-다는 것이다」与「ということだ」对应；但日语同一形式兼表传闻和“也就是说”，韩语要靠不同形式区分。）
