## 语法

- **〜ないことには**：如果不…就无法…
  接续：Verb-nai / i-Adj-ku + ない / na-Adj + でない / 名词 + でない + ことには
  朝鲜语：하지 않으면 …할 수 없다（韩语提示按整块理解。换成日语时先套接续「Verb-nai / i-Adj-ku + ない / na-Adj + でない / 名词 + でない + ことには」，再看下面的例句。）
- **〜ことは〜が**：…倒是…，不过…
  接续：动词普通形 + ことは + 动词普通形 + が / i-Adj + ことは + i-Adj + が / na-Adj + な + ことは + na-Adj + だ + が
  朝鲜语：하기는 하지만（韩语提示按整块理解。换成日语时先套接续「动词普通形 + ことは + 动词普通形 + が / i-Adj + ことは + i-Adj + が / na-Adj + な + ことは + na-Adj + だ + が」，再看下面的例句。）
