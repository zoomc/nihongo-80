Day 048 · V辞書形 / Vない形 + ように する、V辞書形/Vない形 + ことに する / なる、V辞書形 / Vない形 + ことが ある

语法 3 条

V辞書形 / Vない形 + ように する
努力做到…／设法不…（有意识地做）
動詞 辞書形／ない形 + ように + する；する 按 サ変 变形（ようにしています／ようにした）
ようにする 表有意识地努力或安排；ようになる 常侧重变化结果，但变化也可能来自努力。
韩语对应-도록 하다
韩语 -도록 하다 可表努力或指示；日语ようにする可用于自己的安排，也可用于要求他人注意。
毎日野菜を食べるようにしています。
我尽量每天吃蔬菜。
네루마에 니 스마호 오 미나이요우 니 시테이마스.
寝る前にスマホを見ないようにしています。
睡前尽量不看手机。
易错易混点
  • ✗ 有意保持每天跑步：毎日走るようになりました。✓ 毎日走るようにしています。ようにしている 是“自己留心保持这个习惯”；ようになる 是“变得会、开始”。
  • ✗ 遅刻するようにしてください。✓ 遅刻しないようにしてください。「请别迟到」要用否定：遅刻しないようにしてください。
V辞書形/Vない形 + ことに する / なる
（自己）决定…／（结果）定为…、将要…
动词辞书形／ない形 + ことにする（决定）／ことになる（安排、结果）。
ことにする 侧重决定，ことになる 侧重结果或安排；后者也可用于共同决定或自己的决定以客观方式叙述。
韩语对应-기로 하다 / -게 되다
韩语自己决定用기로 하다，外部决定或结果用게 되다；与日语ことにする/なる对应整齐。
킨엔스루코토 니 시마시타.
禁煙することにしました。
我决定戒烟了。
来月から転勤することになりました。
定下下个月起调职了。
易错易混点
  • ✗ 禁煙することになりました。（自己决定时）✓ 禁煙することにしました。自己做的决定用 ことにする；ことになる 是外部或客观决定。
  • ✗ 来月転勤することにします。（公司已决定时）✓ 来月から転勤することになりました。公司已经定好的事，用 ことになる 说结果。
V辞書形 / Vない形 + ことが ある
有时会…／有时不…（泛指倾向）
動詞 辞書形／ない形 + ことが ある；ある 可变形（ことがあります／あった）
表示偶尔发生、有时会那样；与 〜たことがある（G0042，曾经做过）时态语义都不同
韩语对应-곤 하다 / -기도 하다
偶发可用 -는 때가 있다 或 -기도 하다；持续一段时期的习惯才适合 -곤 하다。日语 凍ることがある 是有时结冰，凍ったことがある 指结过冰。
이소가시쿠테, 히루고한 오 와스레루코토 가 아리마스.
忙しくて、昼ご飯を忘れることがあります。
忙起来有时会忘了吃午饭。
카레 와 타마니치코쿠스루코토 가 아리마스.
彼はたまに遅刻することがあります。
他偶尔会迟到。
易错易混点
  • ✗ 北海道へ行くことがあるです。✓ 北海道へ行くことがあります。结句要接 あります，没有「あるです」这种说法。
  • ✗ 忘れることがありますでした。✓ 忘れることがありました。あります 已经含客气形，后面不能再加 でした；过去说 ありました。
