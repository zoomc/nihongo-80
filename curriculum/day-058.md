## 3. 新语法（含先修）
- `G0076` **N + に 対して / に 関して** — 对…（针对对象/对比）／关于…（书面）｜接续：名詞 + に対して（动作/态度的对象，或「与此相对」的对比）；名詞 + に関して（＝について 的书面语）
- `G0077` **N / V辞書形 + に 伴って / に つれて / に 従って** — 随着…（前项变化，后项也跟着变化）｜接续：名詞 + に／動詞 辞書形 + に + 伴って・つれて・従って；后项须是变化动词（増える／変わる／高くなる 等）

## 4. 新汉字（中日差异）
- `K0127` **滞** 音:タイ 训:とどこおる｜中文「滞」zhì；日语 滞 音读 タイ（渋滞 じゅうたい、滞在 たいざい）、训读 とどこおる（滞る）；「渋滞」堵车，不能按中文「停滞」字面套到交通场景。
- `K0128` **運** 音:ウン 训:はこぶ｜中文「运」yùn；日语 運 音读 ウン（運転 うんてん、運動 うんどう）、训读 はこぶ（運ぶ）；「運転」是「驾驶」，中文「运转/运输」≠日语「運転」，不能按中文猜。
