# Day 021 · 〜へ、〜で（place of action）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜へ、〜で（place of action）」各造一句自己的话，表达：往…；朝…；在…（做某事）

## 新词 24

- **使う**（つかう）使用｜韩语参考：쓰다（用，使用） / 사용하다（使用，用，应用）<br>
  例：フラッシュを使ってもいいですか。（可以用闪光灯吗？）
- **疲れる**（つかれる）累｜韩语参考：피곤하다<br>
  例：とても疲れているように見えます。（你看起来很累。）
- **次**（つぎ）下一个｜韩语参考：담（下面，下一个） / 다음（下面，下一个）<br>
  例：次はいつ来ればいいのでしょうか。（下次什么时候来好呢？）
- **着く**（つく）到达｜韩语参考：닿다（到达，抵达） / 도달되다（到达，抵达，到） / 도달하다（到达）<br>
  例：シカゴに着いたらすぐ電話します。（一到芝加哥我就给你打电话。）
- **机**（つくえ）桌子｜韩语参考：책상<br>
  例：机の上にペンが一本もありません。（桌上连一支笔都没有。）
- **作る**（つくる）做｜韩语参考：짓다（做，造，建） / 만들다（制作，做，制造）<br>
  例：たまごを割らずにオムレツは作れない。（不打鸡蛋就做不成煎蛋卷。）
- **つける**（つける）打开（电器）｜韩语参考：켜다<br>
  例：テレビをつけて。（把电视打开。）
- **勤める**（つとめる）任职｜韩语参考：근무하다<br>
  例：父は銀行に勤めています。（父亲在银行工作。）
- **つまらない**（つまらない）无聊｜韩语参考：맹맹하다（无聊，乏味）<br>
  例：このビデオはつまらないよ。（这录像很无聊。）
- **冷たい**（つめたい）冷；冷淡｜韩语参考：차다（冷，寒冷，凉，冰凉） / 차갑다（冷淡，冰冷，冷漠）<br>
  例：もう手が冷たくって。（我的手都冻僵了。）
- **強い**（つよい）强｜韩语参考：세다（强，猛） / 강하다（强，猛，强大）<br>
  例：トラとライオンとどちらが強いか。（老虎和狮子哪个更强？）
- **手**（て）手｜韩语参考：손（手） / 수（手，招数）<br>
  例：ここに手のないナベがある。（这里有一口没把手的锅。）
- **テープ**（テープ）磁带；胶带｜韩语参考：테이프（绝缘胶带）<br>
  例：君はそのコンサートをテープにとったか。（你把那场音乐会录下来了吗？）
- **テーブル**（テーブル）桌子｜韩语参考：탁자（桌子，台子） / 테이블（桌子，台子，平台）<br>
  例：このテーブルを頼んだのではない。（我点的不是这张桌子。）
- **テープレコーダー**（テープレコーダー）录音机｜韩语参考：녹음기（录音机） / 카세트（盒式磁带录音机，卡式录音机）<br>
  例：このテープレコーダーは新しくない。（这台录音机不是新的。）
- **出かける**（でかける）外出｜韩语参考：외출하다<br>
  例：出かけるよりもじっとしていたい。（与其出门，我更想待着不动。）
- **手紙**（てがみ）信｜韩语参考：서신（信，书信） / 편지（信，书信，信件）<br>
  例：書かねばならない手紙があります。（我有一封信必须写。）
- **出口**（でぐち）出口｜韩语参考：출구（出口）<br>
  例：B2出口から地上に出てください。（请从B2出口上到地面。）
- **テスト**（テスト）考试｜韩语参考：고사（考试，考核） / 시험（考试） / 테스트（测验，考试，试验，检查，测试）<br>
  例：そのテストはむずかしかった。（那场考试很难。）
- **では**（では）那么｜韩语参考：그럼（那么，既然那样）<br>
  例：では今晩またね、さようなら。（那今晚见，再见。）
- **デパート**（デパート）百货商店｜韩语参考：백화점（百货商店）<br>
  例：あのデパートで新しいコートを買いたい。（我想在那家百货商店买件新大衣。）
- **出る**（でる）出去；出现｜韩语参考：나다（出现，达成） / 나가다（出，出去） / 나서다（出去，上前）<br>
  例：電話には出なかったからメールしておきました。（他没接电话，所以我发了邮件。）
- **テレビ**（テレビ）电视｜韩语参考：티브이（电视，电视机） / 텔레비전（电视，电视机）<br>
  例：あなたはどこでテレビを見ますか。（你在哪里看电视？）
- **電気**（でんき）电；电灯｜韩语参考：전기（电，电气） / 전등（电灯） / 전깃불（电灯，灯光）<br>
  例：電気シェーバーから火が出ました。（电动剃须刀冒火了。）

## 语法

- **〜へ**：往…；朝…
  接续：名词（场所／方向）+ へ（读作 e）
  朝鲜语：로/으로（방향）（韩语 로/으로 与 へ 对应，随收音换形；日语 へ 读作 e，写法固定，不随名词变化。）
- **〜で（place of action）**：在…（做某事）
  接续：名词（场所）+ で
  朝鲜语：에서（동작 장소）（韩语 에서 与 で 对应，에 表存在；日语 で 与 に 的分工和韩语 에서 与 에 基本一致，较易迁移。）
