# Day 042 · 新闻与天气｜N が V(他動詞)て ある、Vて + いく / くる

- 阶段：P1｜60 分钟｜常规日
- Can-do：在「新闻与天气」场景里，用 N が V(他動詞)て ある 说清一件事

## 新词 20

- **動く**（うごく）动；运转  
  例：まだ動くうちに売ってしまわなきゃ。（得趁它还能动赶紧卖掉。）
- **うそ**（うそ）谎话；假的  
  例：えっ嘘でしょ。（咦，骗人的吧。）
- **うち**（うち）里面；家里  
  例：教会は私の家とあなたの家の中にあります。（教堂在我家和你家之间。）
- **打つ**（うつ）打；敲

- **美しい**（うつくしい）美丽；美好

- **写す**（うつす）抄写；拍照

- **移る**（うつる）迁移；转移  
  例：もっとお金があれば大きな家に移れるのにな。（要是有更多钱，就能搬到更大的房子了。）

- **うまい**（うまい）好吃；擅长

- **裏**（うら）背面；里面

- **売り場**（うりば）卖场；柜台  
  例：スナック売り場は、どこですか。（零食区在哪儿？）
- **うれしい**（うれしい）高兴；开心  
  例：あなたに再会できてうれしい。（能再见到你我很高兴。）
- **うん**（うん）嗯；对  
  例：うん、休みが終わるまででいいの。（嗯，到假期结束就行。）

  例：運転手は車のスピードを上げた。（司机提高了车速。）
- **運動**（うんどう）运动；锻炼｜朝鲜语：운동  
  例：週に一度でいいから運動しなさい。（一周一次也行，要运动。）

  例：上りのエスカレーターはどこですか？（上行的自动扶梯在哪里？）

  例：心からお祝いを申し上げます。（衷心向您表示祝贺。）

## 语法

- **N が V(他動詞)て ある**：（人为地）已经…着；事先做好了…
  接续：他動詞 て形 + ある；原来的 を 宾语改由 が 提示（N が …てある）
  朝鲜语：-아/어 있다（韩语结果状态用아/어 있다，不强调人为施事；日语てある暗示某人有意为之，语感不同。）
- **Vて + いく / くる**：…下去／…起来（趋势）；去…再来／…过来（移动）
  接续：動詞 て形 + いく／くる；いく・くる 按五段/カ変变形（ていきます／てきました）
  朝鲜语：-아/어 가다 / -아·어 오다（韩语가다/오다补助同样表时间趋势，以说话人为基准；与日语いく/くる方向基准相近。）

- **重** 重；重要；重叠｜音：ジュウ、チョウ｜训：え、おも.い、おも.り、おも.なう、かさ.ねる、かさ.なる、おも
- **近** 近；接近｜音：キン、コン｜训：ちか.い
- **考** 思考；考虑｜音：コウ｜训：かんが.える、かんが.え
