# Day 149 · 〜はずだ

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜はずだ」造两句自己的话，表达：应该…；按理说…

## 新词 21

- **莫大**（ばくだい）巨大；巨额｜韩语参考：막대하다<br>
  例：ジョンは莫大な財産を相続した。（约翰继承了一大笔财产。）
- **爆発**（ばくはつ）爆炸｜韩语参考：폭발（爆炸）<br>
  例：そのニュースは彼の怒りを爆発させた。（那条消息让他怒火爆发。）
- **博物館**（はくぶつかん）博物馆｜韩语参考：박물관（博物馆）<br>
  例：あの博物館はくるに値する。（那座博物馆值得一去。）
- **激しい**（はげしい）激烈；猛烈｜韩语参考：세차다（强劲，猛烈） / 가열차다（强烈，激烈，热烈） / 가열하다（激烈，狂热）<br>
  例：その２チームは激しく戦った。（那两支队伍打得非常激烈。）
- **はさみ**（はさみ）剪刀｜韩语参考：가위（剪刀）<br>
  例：ジェイはその古いはさみを拾い上げた。（杰伊捡起了那把旧剪刀。）
- **破産**（はさん）破产｜韩语参考：파산（破产）<br>
  例：かけごとのために彼は破産した。（他因赌博破了产。）
- **端**（はし）边缘；端｜韩语参考：끝（头，尖，端） / 가장자리（边，边缘）<br>
  例：こっちの端を持っててくれる？（你能帮我拿着这一头吗？）
- **始まり**（はじまり）开始；开端｜韩语参考：머리（开始，开头） / 시발（开端，开头） / 시작（开始，开端，开头，起始，起头）<br>
  例：始まりがうまければ半ばうまくいったもおなじ。（开头好就等于成功了一半。）
- **パス**（パス）通行证；传球｜韩语参考：패스（传球）<br>
  例：隣の選手にパスを出しました。（把球传给了旁边的队员。）
- **外す**（はずす）取下；除去｜韩语参考：떼다 / 벗기다<br>
  例：私は野球チームから外された。（我被棒球队除名了。）
- **パスポート**（パスポート）护照｜韩语参考：여권（护照） / 패스（护照） / 패스포트（护照）<br>
  例：パスポートを拝見できますか。（可以看一下您的护照吗？）
- **旗**（はた）旗子｜韩语参考：깃발（旗，旗帜，旗子）<br>
  例：彼は旗を上下に動かした。（他把旗子上下挥动。）
- **肌**（はだ）皮肤；性子｜韩语参考：살（皮肤） / 피부（皮肤）<br>
  例：中国の音楽はどうも僕の肌に合わない。（中国音乐总不合我的口味。）
- **裸**（はだか）裸体；光着｜韩语参考：나신（裸体） / 나체（裸体） / 누드（裸体）<br>
  例：子供たちは裸で泳いでいた。（孩子们光着身子游泳。）
- **畑**（はたけ）旱田；田地｜韩语参考：밭（旱田）<br>
  例：春になると畑をほりかえして種をまきます。（一到春天就翻地播种。）
- **働き**（はたらき）工作；作用｜韩语参考：일 / 작용<br>
  例：働きすぎると体によくないだろう。（工作过度对身体不好。）
- **バッグ**（バッグ）包；手提包｜韩语参考：백（袋，皮包，手提包） / 가방（包，背包，提包）<br>
  例：バッグはどこに置けばいいですか。（包放在哪里好？）
- **発見**（はっけん）发现｜韩语参考：발견（发现）<br>
  例：だれがそれを発見したのかと思う。（我想知道是谁发现了它。）
- **発行**（はっこう）发行；出版｜韩语参考：발행（发行）<br>
  例：この地方新聞は週に１回発行される。（这份地方报纸每周发行一次。）
- **発車**（はっしゃ）发车｜韩语参考：발차（发车）<br>
  例：バスは五分後に発車します。（公交车五分钟后发车。）
- **罰する**（ばっする）惩罚｜韩语参考：벌주다（罚，惩罚） / 벌하다（罚，惩罚） / 벌세우다（罚，惩罚）<br>
  例：どうしてあなたは彼らを罰しているのですか。（你为什么惩罚他们？）

## 语法

- **〜はずだ**：应该…；按理说…
  接续：动词普通形／い形容词 + はずだ；な形容词+な／名词+の + はずだ
  朝鲜语：-(으)ㄹ 것이다（韩语 -(으)ㄹ 것이다 既可表推测也可表意志，日语 はずだ 只表基于根据的推断，不含意志；两者不能完全对应。）
