# Day 071 · 〜うちに、〜ところに / 〜ところへ / 〜ところを、〜ば〜ほど

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜うちに**：趁着…；在…过程中
  接续：动词辞书形/ている/ない形 + うちに；い形容词 + うちに；ナ形容词 + な + うちに；名词 + の + うちに
  朝鲜语：…하는 동안에 / …하기 전에 / …할 때 얼른（韩语「-는 동안에」只表时间范围；日语「うちに」还含“趁还没变、赶在期限前”的语感。）
- **〜ところに / 〜ところへ / 〜ところを**：正当…的时候
  接续：动词辞书形/ている/た形 + ところに／ところへ／ところを
  朝鲜语：…하려는 참에 / …하는 장면을（出かけるところに電話が来た 可对照 나가려는 참에 전화가 왔다。盗んでいるところを見られた 则是 훔치는 모습을 들켰다，由 を 标出被看见的场面。）
- **〜ば〜ほど**：越…越…
  接续：动词ば形 + 同一动词辞书形 + ほど；い形容词ければ + い形容词 + ほど；ナ形容词なら + ナ形容词な + ほど
  朝鲜语：-면 -ㄹ수록（-을수록 一次就能表达「越…越…」。日语可用 すればするほど，也可只用 するほど。前一种结构更便于看清同一动作反复套用。）
