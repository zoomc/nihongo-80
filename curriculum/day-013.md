## 新词 25

- **九つ**（ここのつ）九个｜韩语参考：아홉 개<br>
  例：箱の中にみかんが九つあります。（箱里有九个橘子。）
- **午前**（ごぜん）上午｜韩语参考：오전（上午） / 아침나절（上午）<br>
  例：その電車は午前９時にここを出発します。（那趟电车上午9点从这里发车。）
- **答える**（こたえる）回答｜韩语参考：답하다（回答，答话） / 대답하다（回答，解答） / 응답하다（应答，回答）<br>
  例：「はい、ありません」とジョーダンさんは答えた。（“是的，没有。”乔丹先生答道。）
- **ごちそうさま**（ごちそうさま）多谢款待｜韩语参考：잘 먹었습니다<br>
  例：コーヒー、ごちそうさまでした。（谢谢您的咖啡。）
- **こちら**（こちら）这边；这位｜韩语参考：요쪽（这边）<br>
  例：今のところこちらだけになります。（目前只有这一种。）
- **こっち**（こっち）这边｜韩语参考：요쪽（这边） / 요리요리（往这边）<br>
  例：こっちへ来い、ぐずぐずしないで。（到这儿来，别磨蹭。）
- **コップ**（コップ）杯子｜韩语参考：잔（杯，杯子） / 컵（杯子）<br>
  例：コップに水を入れます。（往杯子里倒水。）
- **今年**（ことし）今年｜韩语参考：금년（今年） / 올（今年）<br>
  例：今年もよい年でありますように。（愿今年也是好年。）
- **言葉**（ことば）语言；话语｜韩语参考：말（话，语言）<br>
  例：言葉が出てこなかった。（我说不出话来。）
- **この**（この）这个｜韩语参考：요（这个） / 이（这，这个）<br>
  例：このコップをミルクで満たした。（我把这个杯子倒满了牛奶。）
- **御飯**（ごはん）米饭；饭｜韩语参考：밥<br>
  例：御飯をもう一杯ください。（请再给我一碗米饭。）
- **コピーする**（コピーする）复印｜韩语参考：복사하다（复印）<br>
  例：コピーするページに付箋をつけておいてください。（请在要复印的那几页贴上标签。）
- **困る**（こまる）为难；困扰｜韩语参考：딱하다（为难，难堪，尴尬） / 난처하다（为难，不好办）<br>
  例：時間がなくてたいへん困っている。（时间不够，我很为难。）
- **ごめんなさい**（ごめんなさい）对不起｜韩语参考：미안합니다<br>
  例：お話し中、ごめんなさい。（打扰您说话了，对不起。）
- **これ**（これ）这个｜韩语参考：요（这个） / 이것（这个）<br>
  例：これは兄です。かっこいいですね。（这是我哥哥。很帅吧。）
- **今月**（こんげつ）这个月｜韩语参考：이번 달 / 금월<br>
  例：今月の売り上げはよくない。（这个月销售额不好。）
- **こんな**（こんな）这样的｜韩语参考：이런（这样的）<br>
  例：こんな本を読んで何になるのか。（读这种书有什么用呢。）
- **今晩**（こんばん）今晚｜韩语参考：오늘 밤<br>
  例：今晩はパーティーがあるのかなあ。（今晚是有聚会吗？）
- **さあ**（さあ）来吧；这个嘛｜韩语参考：자 / 글쎄<br>
  例：さあ、パーティーをおしまいにしよう。（好了，聚会就到此结束吧。）
- **財布**（さいふ）钱包｜韩语参考：지갑（钱包，钱夹，钱袋） / 손지갑（小钱包）<br>
  例：財布を家に忘れました。（我把钱包忘在家了。）
- **雑誌**（ざっし）杂志｜韩语参考：잡지（杂志） / 잡지책（杂志）<br>
  例：その雑誌はどこで買えますか。（那本杂志在哪里能买到？）
- **砂糖**（さとう）糖｜韩语参考：설탕（糖，砂糖）<br>
  例：ポットにはあまり砂糖がなかった。（壶里没剩多少糖。）
- **さようなら**（さようなら）再见｜韩语参考：안녕히 가세요 / 안녕히 계세요<br>
  例：では今晩またね、さようなら。（那今晚见，再见。）
- **再来年**（さらいねん）后年｜韩语参考：후년（后年） / 내후년（大后年）<br>
  例：祖父は、再来年引退する予定です。（祖父打算后年退休。）
- **散歩**（さんぽ）散步｜韩语参考：산보（散步） / 산책（散步）<br>
  例：散歩に出かけてもよろしいですか。（我可以出去散散步吗？）

## 语法

- **比较（より／ほうが／ほど）**：比…／不如…
  接续：A は B より ～；A より B の ほうが ～；A は B ほど ～ない
  朝鲜语：A가 B보다 + 형용사（韩语可用 보다 表比较基准；「没昨天冷」可说 어제보다 춥지 않다，也可用 만큼 与否定表达。）
- **～に 行く / 来る（移动目的）**：去／来做…
  接续：動詞ます形（去ます）／名詞 + に + 移動動詞 行く/来る
  朝鲜语：-(으)러 가다/오다（보러 가다 对应 見に行く；쇼핑하러 가다 对应 買い物に行く。日语动词用ます词干，常见动作名词可直接接 に。）
