今日语法 2 条

〜次第
발음〜시다이
一…就立即…
ます词干 + 次第 / 名词 + 次第
韩语对应…하는 대로 / …하자마자
常用于联络安排，前项尚未发生，发生后立刻执行后项。接ます词干「届き次第」，也有较正式的「到着次第」。
詳しい日程が決まり次第、皆様にご連絡いたします。
详细日程一确定，我们就通知各位。
시료우 가 토도키시다이, 나이요우 오 카쿠닌시테오헨지시마스.
資料が届き次第、内容を確認してお返事します。
材料一送到，我就核对内容并回复。

易错点 資料が届く次第、連絡する → 資料が届き次第、連絡する（「すぐに」这一义项接ます词干。）

〜次第だ / 〜次第で
발음〜시다이다 / 〜시다이데
取决于…
名词 + 次第だ / 名词 + 次第で / 名词 + 次第では
韩语对应…에 달려 있다 / …에 따라
「努力次第だ」说结果取决于某因素，「努力次第で」说明该因素会怎样影响后项。「決まり次第」才是“一确定就”。
合格できるかどうかは、これからの努力次第だ。
能否通过考试，取决于接下来的努力。
天気次第で、明日の予定を変えるかもしれない。
明天的安排可能会视天气而调整。

易错点 予算を次第で、内容を決める → 予算次第で、内容を決める（决定因素紧贴「次第で」，无需宾格助词。）
