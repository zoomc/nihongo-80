③ 语法 7 分钟

〜の（possessive）
名词 + の + 名词
…的…

表示所属、属性、材料或同位关系，修饰名词时用 の。

これは私のかさです。
这是我的伞。
日本語の先生はとてもやさしいです。
日语老师非常温柔。
駅の近くに新しい店があります。
车站附近有一家新店。
朝鲜语：의
韩语 의 与 の 对应，但口语中 의 常省略；日语 の 不能省略，且还可代替名词（私の）。

易错：これは私がかさです。 → これは私のかさです。（所属关系用 の，が 会变成主语标记）

〜から（from）
名词 + から（起点）
从…（起点）

表示时间或场所的起点，常与「まで」呼应。

授業は9時からです。
课从九点开始。
学校から駅まで歩きます。
我从学校走到车站。
私はブラジルから来ました。
我来自巴西。
朝鲜语：부터 / 에서
韩语时间起点用 부터，场所起点用 에서；日语 から 两者通用，范围更宽。

易错：学校から駅までに歩きます。 → 学校から駅まで歩きます。（まで 表终点，后接动词时不再加 に）
