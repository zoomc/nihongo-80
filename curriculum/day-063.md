# Day 063 · V辞書形/Vない形 + ことに する / なる、V辞書形 / Vない形 + ことが ある

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「V辞書形/Vない形 + ことに する / なる、V辞書形 / Vない形 + ことが ある」造两句自己的话，表达：（自己）决定…／（结果）定为…、将要…；有时会…／有时不…（泛指倾向）

## 新词 25

- **申す**（もうす）说；叫做（谦让语）｜韩语参考：말씀드리다 / ~라고 하다（겸양）<br>
  例：田中と申します。よろしくお願いします。（我姓田中，请多关照。）
- **遠慮**（えんりょ）客气；顾虑；谢绝｜韩语参考：거절（拒绝，谢绝） / 격의（顾虑，隔阂，芥蒂） / 사양（谢绝，客气）<br>
  例：どうぞ遠慮なく召し上がってください。（请别客气，尽管吃。）
- **見つける**（みつける）找到（他动）｜韩语参考：찾다 / 발견하다（타동사）<br>
  例：鍵を見つけました。（找到钥匙了。）
- **見つかる**（みつかる）被找到；（东西）找到了（自动）｜韩语参考：찾아지다 / 발견되다（자동사）<br>
  例：無くした時計が見つかりました。（丢的表找到了。）
- **変える**（かえる）改变（他动）｜韩语参考：바꾸다（改变，转变，更改）<br>
  例：予定を変えました。（改了计划。）
- **職場**（しょくば）职场；工作岗位｜韩语参考：일터（工作岗位） / 자리（职，岗位） / 직장（工作单位，职场）<br>
  例：職場の人と相談します。（和同事（职场的人）商量。）
- **会議**（かいぎ）会议｜韩语参考：회의（会，会议）<br>
  例：午後から会議があります。（下午开始有会议。）
- **残業**（ざんぎょう）加班｜韩语参考：야근（加班） / 잔업（加班）<br>
  例：今日は残業しなければなりません。（今天不得不加班。）
- **給料**（きゅうりょう）工资；薪水｜韩语参考：급료（工资，薪金） / 급여（报酬，薪水，工资） / 봉급（薪资，薪酬，工资）<br>
  例：給料が上がりました。（工资涨了。）
- **報告**（ほうこく）报告；汇报｜韩语参考：보고（报告）<br>
  例：上司に結果を報告します。（向上司汇报结果。）
- **相談**（そうだん）商量；咨询｜韩语参考：상담（咨询） / 상의（商量，商议，讨论） / 의논（商议，讨论，商量）<br>
  例：先生に進路を相談します。（找老师商量升学去向。）
- **就職**（しゅうしょく）就职；就业｜韩语参考：취업（就业） / 취직（就业，就职）<br>
  例：大学を卒業して、就職しました。（大学毕业后就业了。）
- **手続き**（てつづき）手续；程序｜韩语参考：수속（手续） / 절차（手续，步骤，程序）<br>
  例：入学の手続きをします。（办理入学手续。）
- **申請**（しんせい）申请（书面）｜韩语参考：신청（申请）<br>
  例：ビザを申請しました。（申请了签证。）
- **技術**（ぎじゅつ）技术｜韩语参考：기술（技术）<br>
  例：新しい技術を開発します。（开发新技术。）
- **故障**（こしょう）故障；出毛病｜韩语参考：탈（故障） / 고장（故障）<br>
  例：パソコンが故障しました。（电脑出故障了。）
- **操作**（そうさ）操作（机器/界面）｜韩语参考：조작（操作）<br>
  例：この機械は操作が簡単です。（这台机器操作很简单。）
- **渋滞**（じゅうたい）堵车；拥堵｜韩语参考：정체（拥堵，堵车） / 교통 체증（交通堵塞，堵车）<br>
  例：朝は道が渋滞しています。（早上路上堵车。）
- **事故**（じこ）事故；意外事件｜韩语参考：탈（意外，变故） / 사고（事故）<br>
  例：高速道路で事故がありました。（高速上发生了事故。）
- **運転**（うんてん）驾驶；开车｜韩语参考：운전（驾驶，操纵，开）<br>
  例：父は毎日車を運転します。（爸爸每天开车。）
- **入院**（にゅういん）住院｜韩语参考：입원（住院）<br>
  例：祖母が入院しました。（奶奶住院了。）
- **看病**（かんびょう）护理；照料病人｜韩语参考：병간호（看护病人，护理病人） / 병구완（护理病人，伺候病人）<br>
  例：母が入院して、看病しています。（妈妈住院了，我在护理她。）
- **記事**（きじ）报道；文章；条目｜韩语参考：기사（报道，新闻） / 기사문（报道，纪实文）<br>
  例：新聞の記事を読みました。（读了报上的报道。）
- **確認**（かくにん）确认；核实｜韩语参考：확인（确认）<br>
  例：資料の内容を確認してください。（请确认资料内容。）
- **検討**（けんとう）探讨；研究；考虑｜韩语参考：검토（研究，考虑）<br>
  例：この案を検討することにしました。（决定研究这个方案。）

## 语法

- **V辞書形/Vない形 + ことに する / なる**：（自己）决定…／（结果）定为…、将要…
  接续：動詞 普通形 + ことに + する（主观决定）/ なる（客观决定、自然结果）；する・なる 可变形
  朝鲜语：-기로 하다 / -게 되다（韩语自己决定用기로 하다，外部决定或结果用게 되다；与日语ことにする/なる对应整齐。）
- **V辞書形 / Vない形 + ことが ある**：有时会…／有时不…（泛指倾向）
  接续：動詞 辞書形／ない形 + ことが ある；ある 可变形（ことがあります／あった）
  朝鲜语：-곤 하다 / -기도 하다（韩语곤 하다表过去反复习惯，기도 하다表有时；日语ことがある现在形表偶尔，时态限制不同。）
