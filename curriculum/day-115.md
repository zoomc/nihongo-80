# Day 115 · 〜ぶり、〜っけ

- 阶段：P4｜60 分钟｜听力日
- Can-do：用「〜ぶり、〜っけ」造两句自己的话，表达：隔了…才；…的样子；…来着？（回忆确认）

## 新词 23

- **ドレス**（ドレス）连衣裙；礼服｜韩语参考：드레스（(连衣裙式)礼服）<br>
  例：あのドレスは彼女によく似合う。（那条连衣裙很适合她。）
- **取れる**（とれる）脱落；能取到｜韩语参考：떨어지다 / 얻을 수 있다<br>
  例：オリーブの実から油が取れます。（橄榄果能榨出油。）
- **泥**（どろ）泥｜韩语参考：진흙<br>
  例：彼はブーツの泥をこすり落とした。（他刮掉了靴子上的泥。）
- **トン**（トン）吨｜韩语参考：톤（吨）<br>
  例：この荷物は一トンあります。（这批货重一吨。）
- **とんでもない**（とんでもない）岂有此理；哪里的话｜韩语参考：천만에요 / 터무니없다<br>
  例：彼女が歌手だなんてとんでもない。（说她是歌手，简直荒唐。）
- **どんな**（どんな）什么样的｜韩语参考：뭔（什么） / 무슨（什么） / 아무（任何，什么）<br>
  例：私はどんな戦争にも反対だ。（我反对任何形式的战争。）
- **どんなに**（どんなに）多么｜韩语参考：좀（多么） / 암만（多么） / 오죽（多么，多）<br>
  例：君は私がどんなに心配しているかを知らない。（你不知道我有多担心。）
- **トンネル**（トンネル）隧道｜韩语参考：굴（隧道） / 터널（隧道）<br>
  例：汽車はトンネルを通り抜けた。（火车穿过了隧道。）
- **名**（な）名字；名声｜韩语参考：이름（名字，名称）<br>
  例：私はいつまでも彼の名を覚えている。（我会永远记得他的名字。）
- **なお**（なお）仍然；另外｜韩语参考：여전히 / 또한<br>
  例：あとで起こったことはなお悪かった。（后来发生的事更糟。）
- **仲**（なか）关系；交情｜韩语参考：사이（关系）<br>
  例：私は彼とは訪問し合う仲だ。（我和他是互相串门的交情。）
- **流す**（ながす）冲；流（泪）｜韩语参考：쏟다（流，淌）<br>
  例：あんな恐ろしい男のために流す涙はない。（不值得为那种可怕的男人流泪。）
- **半ば**（なかば）一半；中途｜韩语参考：반（一半，半） / 중턱（一半）<br>
  例：彼女は４０代半ばで再婚した。（她四十多岁中期再婚了。）
- **仲間**（なかま）伙伴；同伴｜韩语参考：동료<br>
  例：田中さんは父のつり仲間の一人だ。（田中是我父亲的钓友之一。）
- **眺め**（ながめ）景色；眺望｜韩语参考：경치（风景，景色）<br>
  例：眺めのよい部屋をお願いします。（请给我一间视野好的房间。）
- **眺める**（ながめる）眺望；凝视｜韩语参考：내다보다（眺望，远望） / 바라다보다（注视，凝视）<br>
  例：何時間も海を眺めた。（我望着大海看了好几个小时。）
- **流れ**（ながれ）水流；潮流｜韩语参考：흐름（潮流，长河，进程，流程）<br>
  例：流れは池に注いでいる。（溪水流进池塘。）
- **流れる**（ながれる）流动；漂流｜韩语参考：흐르다<br>
  例：当時はきれいな水がこの川にも流れていた。（当时这条河里也流着干净的水。）
- **無し**（なし）没有｜韩语参考：없음<br>
  例：ようやくその男と貸し借り無しになった。（我终于和那个男人两清了。）
- **なぜなら**（なぜなら）因为｜韩语参考：왜냐하면<br>
  例：なぜなら新聞記者だったからです。（因为当时我是报社记者。）
- **謎**（なぞ）谜；谜团｜韩语参考：수수께끼（谜）<br>
  例：彼がなぜ仕事をやめたのかは謎だ。（他为什么辞职是个谜。）
- **納得**（なっとく）理解；认可｜韩语参考：납득（接受，理解）<br>
  例：「そっか」ウィリーはようやく納得した。（「原来如此。」威利终于接受了。）
- **何**（なに）什么｜韩语参考：머（什么） / 뭐（什么） / 뭣（什么）<br>
  例：今のアナウンスは何だったのですか。（刚才的广播说了什么？）

## 语法

- **〜ぶり**：隔了…才；…的样子
  接续：期间名词 + ぶり；动词ます形词干 + ぶり
  朝鲜语：-만에（韩语「-만에」与「ぶりに」对应；但日语「ぶり」还能接动词词干表“…的样子」（仕事ぶり），韩语不能直译。）
- **〜っけ**：…来着？（回忆确认）
  接续：动词普通形、名词或句末表达等 + っけ；「だっけ／だったっけ」也常用。口语では「何時からっけ」等の省略もある。
  朝鲜语：-였지?（韩语没有专门的回忆确认句尾，常用「-였지?」；日语「っけ」还可用た形回忆过去，韩语要靠「-곤 했지」补足。）
