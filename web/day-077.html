今日语法 3 条

〜気がする
발음〜키가스루
感觉…；总觉得…
普通形 + 気がする；ナ形容词 + な + 気がする；名词 + の + ような + 気がする
表达模糊的直觉或主观感觉，把握不大。
코노히토토와,도코카데아따코토가아루키가스루.
この人とは、どこかで会ったことがある気がする。
总觉得在哪儿见过这个人。
쿄우와나니카,이이코토가아리소우나키가스루.
今日は何か、いいことがありそうな気がする。
今天总觉得会有好事发生。
ドアの鍵をかけ忘れたような気がして、家に戻った。
觉得好像忘了锁门，就回家了一趟。
朝鲜语：-ㄴ 기분이 들다
韩语「-ㄴ 기분이 들다」偏情绪感受；日语「気がする」还能用于记忆和判断的模糊确信，范围更广。
易错点

今日は何か変気がする。 → 変な気がする（ナ形容词接「気がする」要加「な」，「変気がする」不合法。）

〜ずに
발음〜즈니
不…就…；没…而…
动词ない形词干 + ずに（する→せずに）
表示在不做某动作的状态下做另一动作，书面色彩强。
케사와아사고한오타베즈니이에오데타.
けさは朝ご飯を食べずに家を出た。
今天早上没吃早饭就出门了。
辞書を使わずに、この新聞記事が読めますか。
你能不用词典读懂这篇报道吗？
彼は誰にも相談せずに、会社を辞めてしまった。
他没跟任何人商量就辞职了。
朝鲜语：-지 않고
韩语「-지 않고」不分书面口语；日语「ずに」限书面正式，「ないで」才是口语，需按文体选择。
易错点

彼は誰にも相談しずに、会社を辞めてしまった。 → 相談せずに（「する」的「ずに」形式是「せずに」，「しずに」不合法。）

〜まま
발음〜마마
就那样…；保持着…
动词た形/ない形 + まま；い形容词 + まま；ナ形容词 + な + まま；名词 + の + まま
表示某状态保持不变地进行另一动作。
에아콘오쓰케타마마네테시마이,카제오히이타.
エアコンをつけたまま寝てしまい、風邪をひいた。
开着空调就睡着了，结果感冒了。
코노마치와,와타시가코도모다따코로노마마다.
この町は、私が子どもだったころのままだ。
这个镇子还和我小时候一样。
쿠쓰노마마헤야니하이라나이데쿠다사이.
靴のまま部屋に入らないでください。
请不要穿着鞋进房间。
朝鲜语：-ㄴ 채로
韩语「-ㄴ 채로」与「まま」很接近；但日语可接名词「〜のまま」，韩语没有对应形式，要改说「그대로」。
易错点

エアコンをつけるまま寝てしまい、風邪をひいた。 → つけたまま（表示状态持续要用「た形 + まま」，「つけるまま」不合法。）
