今日语法 3 条

〜てある
발음〜테아루
…着（有意为之的结果状态）
他动词て形 + ある；结果状态常用 が，已完成的准备可用 を。
表示某人有意做了某事后，其结果状态一直保留，主语多为物。
하이리쿠치니치즈가와떼아리마스.
入り口に地図がはってあります。
入口处贴着一张地图。
테이부루노우에니오사라가나라베테아따.
テーブルの上にお皿が並べてあった。
桌上摆着盘子。
비이루나라레이조우코니이레테아루요.
ビールなら冷蔵庫に入れてあるよ。
啤酒的话，我放在冰箱里了。
朝鲜语：-아/어 있다
韩语 -아/어 있다 可表状态持续，但不像日语 てある 那样明确区分他动词与自动词；日语用 が 提示结果主体，韩语用 이/가。
易错点

机に本が置くてあります。 → 机に本が置いてあります。（置く的て形是置いて。）

〜とき
발음〜토키
…的时候
动词普通形／い形容词／な形容词+な／名词+の + とき
表示某一动作或状态发生的时间，前后主语可以不同。
코도모노토키,요쿠카와데오요기마시타.
子どものとき、よく川で泳ぎました。
我小时候经常在河里游泳。
니뽄에이쿠토키,아타라시이카반오카이마시타.
日本へ行くとき、新しいかばんを買いました。
去日本之前，我买了一个新包。
니뽄에이따토키,토모다치니오미야게오카이마시타.
日本へ行ったとき、友達にお土産を買いました。
去日本的时候，我在当地给朋友买了礼物。
朝鲜语：-(으)ㄹ 때
韩语 -(으)ㄹ 때 与 とき 对应，但日语要注意 な形容词加 な、名词加 の；韩语统一用 -(으)ㄹ 때，无词性变化。
易错点

子どもののとき、よく川で泳ぎました。 → 子どものとき、よく川で泳ぎました。（名词修饰名词只用「の」，不能叠用两个 の）

〜間 / 〜間に
발음〜아이다 / 〜아이다니
在…期间；在…期间内
动词ている形／动词辞书形／名词+の + 間（に）
「間」表示整段时间持续，「間に」表示在这段时间内的某一时点。
나쓰야스미노아이다,소후노이에니이마시타.
夏休みの間、祖父の家にいました。
暑假期间我住在爷爷家。
하하가네테이루아이다니,헤야오소우지시타.
母が寝ている間に、部屋を掃除した。
趁母亲睡觉时，我打扫了房间。
덴샤오마떼이루아이다,즈또혼오욘데이타.
電車を待っている間、ずっと本を読んでいた。
等电车的时候，我一直在看书。
朝鲜语：-는 동안
韩语 -는 동안 对应 間，-는 동안에 对应 間に；但日语 間に 的后项多为一次性动作，韩语 에 的区分没有这么严格。
易错点

母が寝ている間で、部屋を掃除した。 → 母が寝ている間に、部屋を掃除した。（表示时间段用 間，不能用 間で）
