今日语法 2 条

韩语对应하지 않으면 …할 수 없다
韩语提示按整块理解。换成日语时先套接续「Verb-nai / i-Adj-ku + ない / na-Adj + でない / 名词 + でない + ことには」，再看下面的例句。
〜ないことには
발음〜나이코토니와
如果不…就无法…
Verb-nai / i-Adj-ku + ない / na-Adj + でない / 名词 + でない + ことには
지싸이니아떼하나시테미나이코토니와,돈나히토카와카라나이.
実際に会って話してみないことには、どんな人か分からない。
You can't tell what someone is like unless you actually meet and talk to them.
샤초우노쿄카가데나이코토니와,코노푸로제쿠토와하지메라레나이.
社長の許可が出ないことには、このプロジェクトは始められない。
We can't start this project unless the president gives permission.
韩语对应하기는 하지만
韩语提示按整块理解。换成日语时先套接续「动词普通形 + ことは + 动词普通形 + が / i-Adj + ことは + i-Adj + が / na-Adj + な + ことは + na-Adj + だ + が」，再看下面的例句。
〜ことは〜が
발음〜코토와〜가
…倒是…，不过…
动词普通形 + ことは + 动词普通形 + が / i-Adj + ことは + i-Adj + が / na-Adj + な + ことは + na-Adj + だ + が
아노에이가,미타코토와미타케도,토추우데네테시마따.
あの映画、見たことは見たけど、途中で寝てしまった。
I did watch that movie, but I fell asleep halfway through.
코노헤야와히로이코토와히로이가,에키카라카나리토오이.

This apartment is spacious, sure, but it's quite far from the station.
