今日语法 3 条

韩语对应-(으)ㄹ 것이 틀림없다
韩语用틀림없다、분명하다表强推断，语气偏书面；日常更多用것 같다，弱于に違いない。
普通形 + に 違いない
一定是…；肯定…（强烈推断）
動詞・い形 普通形 / 名詞・な形 词干（＋である 可省）+ に違いない；礼貌体 に違いありません
基于证据的高置信推断，语气比 かもしれない（G0045）强、比 はず（G0053）更带主观断定
카레와모우카에따니치가이아리마센.
彼はもう帰ったに違いありません。
他肯定已经回去了。
코노네단와야스스기루.세이루니치가이나이.
この値段は安すぎる。セールに違いない。
这价格太便宜，肯定是促销。
易错点

彼は学生だに違いない。 → 彼は学生に違いない。（名词/な形 接 に違いない 一般去掉 だ（或 である）；中文「一定是学生」直译保留 だ 错）

韩语对应-(으)ㄹ 리가 없다 / -(으)ㄹ 수는 없다
韩语ㄹ 리가 없다表绝无可能，ㄹ 수는 없다表情理上不能；两形区分与日语相近。
普通形 + わけが ない / V辞書形 + わけには いかない
不可能…／不能…（わけにはいかない）
普通形 + わけがない（强烈否定可能性）；辞書形 + わけにはいかない（因情理/规则不能做）
わけがない 是「绝无可能」；わけにはいかない 是「（道理上）不能这么做」，两形意义不同勿混
카레가손나코토오이우와케가아리마센.
彼がそんなことを言うわけがありません。
他不可能说那种话。
明日試験があるので、遊びに行くわけにはいきません。
明天有考试，不能去玩。
易错点

彼が来るわけがないでした。 → 彼が来るわけがありませんでした。（过去礼貌形可用「わけがありませんでした」，不能说「ないでした」。）

韩语对应-다고 해서 다 …는 것은 아니다
韩语用「다고 해서 다…는 아니다」表未必，比日语とは限らない冗长，口语常说꼭 그런 건 아니다。
普通形 + と は 限らない
未必…；不一定…；不见得…
動詞・い形 普通形 / 名詞・な形（＋だ 常省）+ とは 限らない；常与 必ずしも／すべて／〜からといって 呼应
否定「一概如此」，修正以偏概全；礼貌体 とは 限りません
타카이모노가카나라즈시모요이토와카기리마센.
高いものが必ずしも良いとは限りません。
贵的东西未必就好。
센세이다카라토이떼,난데모시떼이루토와카기리마센.
先生だからといって、何でも知っているとは限りません。
虽说是老师，也未必什么都懂。
易错点

高いとは限らないません。 → 高いとは限りません。（否定礼貌形可说限りません，不叠加ない和ません。）
