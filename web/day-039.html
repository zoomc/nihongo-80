今日语法 4 条

韩语对应-게 하다
韩语 -게 하다 与使役对应，但日语使役对象用 に 还是 を 取决于动词；韩语统一用 을/를 或 에게，需按语义判断。
〜せる / 〜させる
발음〜세루 / 〜사세루
让…做；使…做
五段动词未然形+せる；一段动词未然形+させる；する→させる；来る→来させる
表示使役，可指命令、允许或放任，视上下文而定。
母は毎日弟に野菜を食べさせる。
母亲每天让弟弟吃蔬菜。
코오치와마이니치,센슈타치오하시라세타.
コーチは毎日、選手たちを走らせた。
教练每天让选手们跑步。
息子が行きたいと言ったので、一人で旅行に行かせました。
儿子说想去，我就让他一个人去旅行了。
易错点

母は毎日弟を野菜を食べさせる。 → 母は毎日弟に野菜を食べさせる。（使役对象用 に，不能再用 を 标记同一成分）

韩语对应-게 시킴을 당하다
韩语没有专门的使役被动词尾，通常说 -하도록 강요받다 或 -게 되다；日语有固定的使役受身活用，语气更强调被迫。
〜せられる / 〜させられる
발음〜세라레루 / 〜사세라레루
被迫做…
五段动词未然形 + せられる（部分动词常缩约为 される）；一段动词未然形 + させられる
表示不情愿地被迫做某事，含有受害或无奈的语气。
코도모노코로,하하니마이니치피아노오렌슈우사세라레타.
子どものころ、母に毎日ピアノを練習させられた。
小时候母亲每天逼我练钢琴。
에키데산주뿜모마타사레마시타.
駅で三十分も待たされました。
我在车站被迫等了三十分钟。
카이샤노노미카이데우타오우타와사레타.
会社の飲み会で歌を歌わされた。
公司聚会上我被逼着唱了歌。
易错点

母に野菜を食べさせられますた。 → 母に野菜を食べさせられました。（礼貌过去形为「食べさせられました」。）

韩语对应-자 / -(으)ㄹ게
韩语 -자 表提议，-(으)ㄹ게 表说话人意志；日语同一个意志形兼表两者，靠语境和语气区分。
〜おう / 〜よう
발음〜오우 / 〜요우
…吧；我要…
五段动词词尾改お段+う；一段动词去る+よう；する→しよう；来る→来よう
表示提议、劝诱或说话人自己的意志，口语中常用于自言自语。
쓰카레타네.스코시야스모우.
疲れたね。少し休もう。
累了吧，稍微休息一下吧。
슈우마쓰,이쑈니에이가오미요우요.
週末、一緒に映画を見ようよ。
周末一起去看电影吧。
よし、今日から毎日日記を書こう。
好，从今天起我每天写日记。
易错点

週末、一緒に映画を見ろうよ。 → 週末、一緒に映画を見ようよ。（見る 是上一段动词，意志形是「見よう」，不是「見ろう」）

韩语对应-(으)려고 하다
韩语 -(으)려고 하다 与 ようと思う 对应；但日语用「と思っている」可表持续的想法，韩语则靠现在时或 고 있다 区分。
〜(よ)うと思う
발음〜우토오모우
我想…；打算…
动词意志形 + と思う／と思っている
表示说话人正在考虑或已下的决心，持续想法用「と思っている」。
코토시노나쓰와우미니이코우토오모떼이마스.
今年の夏は海に行こうと思っています。
今年夏天我想去海边。
아시타와하야쿠오키테,코우엔오하시로우토오모우.
明日は早く起きて、公園を走ろうと思う。
我打算明天早起去公园跑步。
아타라시이파소콘오카오우토오모따케도,야메마시타.
新しいパソコンを買おうと思ったけど、やめました。
我本来想买台新电脑，后来放弃了。
易错点

今年の夏は海に行きようと思っています。 → 今年の夏は海に行こうと思っています。（行く 是五段动词，意志形是「行こう」，不是「行きよう」）
