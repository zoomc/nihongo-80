# Day 003 · 吃饭与点单｜N も、これ / それ / あれ / どれ は N です

- 阶段：P0｜60 分钟｜常规日
- Can-do：在「吃饭与点单」场景里，用 N も 说清一件事

## 新词 9

- **何**（なん）什么  
  例：これは何ですか。（这是什么？）
- **いくら**（いくら）多少钱  
  例：これはいくらですか。（这个多少钱？）
- **円**（えん）日元（货币单位）  
  例：百円です。（一百日元。）
- **今**（いま）现在  
  例：今、何時ですか。（现在几点？）
- **今日**（きょう）今天  
  例：今日は月曜日です。（今天是周一。）
- **明日**（あした）明天  
  例：明日、学校へ行きます。（明天去学校。）
- **昨日**（きのう）昨天  
  例：昨日は日曜日でした。（昨天是周日。）
- **朝**（あさ）早晨  
  例：朝ご飯を食べます。（吃早饭。）
- **時間**（じかん）时间；小时  
  例：時間がありません。（没时间。）

## 语法

- **N も**：…也…
  接续：名詞 + も（替代 は/が/を）
  朝鲜语：도（韩语도同样替代主格/宾格助词，但能与는/은叠加成도는；日语も不能与は叠加。）
- **これ / それ / あれ / どれ は N です**：这/那/那是…
  接续：指示代名词 + は + 名詞 + です
  朝鲜语：이것 / 그것 / 저것 / 어느 것（韩语指示三分与日语相同，但修饰名词要用이/그/저且与것分写；日语可直接连体。）
