③ 语法 7 分钟

と（并列／共同／引用）
名詞 + と + 名詞／動詞；引用从句 + と + 思う/言う
和…／与…（一起）；「…」地

完全并列、共同动作对象、引用内容

友達と映画を見ます。
和朋友看电影。
朝鲜语：와/과 / 하고 / (이)라고
韩语并列用와/과、口语하고，引用用라고且随词性变；日语と一形通用。

易错：友達も映画を見ます。 → 友達と映画を見ます。（「も」是追加「也」，共同动作用 と；中文「和/也」易混）

から ～ まで
名詞（时/处） + から + 名詞 + まで
从…到…

时间/空间的起点与终点，成对使用

九時から五時まで勉強します。
从九点学习到五点。
駅から学校まで行きます。
从车站走到学校。
朝鲜语：부터 ~ 까지
韩语起点用부터、终点까지，与日语基本对应；但韩语时间起点口语可用에，日语から不可省。

易错：九時から五時に 勉強します。 → 九時から五時まで勉強します。（终点用 まで，に 是时点/归着；中文「到五点」误对应 に）
