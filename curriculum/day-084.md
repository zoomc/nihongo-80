# Day 084 · 〜とか（hearsay）、〜って、〜ということだ

- 阶段：P4｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜とか（hearsay）**：听说…；好像说…
  接续：普通形 + とか（句末，或用「とかで」表原因）
  朝鲜语：-다고 하던데（옮긴다던데 对照 引っ越すとか，适合转述还没证实的消息。句中的 本とか雑誌とか 则是用 とか 举例。）
- **〜って**：说是…；所谓…
  接续：普通形 + って；名词 + って（表话题）
  朝鲜语：-대（韩语「-대」是口语转述缩略，与「って」很像；但日语「って」还能当话题助词（「〜って何？」），韩语要用「-는」。）
- **〜ということだ**：据说…；也就是说…
  接续：普通形 + ということだ
  朝鲜语：-다고 한다 / …라는 뜻이다（传闻用 -다고 한다，例如 列車は遅れるということだ。概括意义可用 …라는 뜻이다，日本语常在前面说 つまり。）
