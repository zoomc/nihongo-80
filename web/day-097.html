今日语法 3 条

〜さえ〜ば
발음〜사에〜바
只要…就…
名词 + さえ + ば形；动词ます形词干 + さえ + すれば；动词て形 + さえ + いれば
表示只要满足这一条件，其余都不成问题。
코노아푸리사에아레바,도코데모니혼고노벤쿄우가데키루.
このアプリさえあれば、どこでも日本語の勉強ができる。
只要有这个应用，在哪儿都能学日语。
지칸사에아레바,모또료코우니이키타인데스가.
時間さえあれば、もっと旅行に行きたいんですが。
只要有时间，我还想多去旅行。
쿠스리오논데네테사에이레바,스구니나오리마스요.
薬を飲んで寝てさえいれば、すぐに治りますよ。
只要吃了药好好躺着，很快就会好。
朝鲜语：-기만 하면
韩语「-기만 하면」与「さえ〜ば」对应；但日语「さえ」位置固定在各成分后，韩语统一贴在动词后，语序处理不同。
易错点

このアプリさえあってば、どこでも日本語の勉強ができる。 → さえあれば（「さえ」后要接ば形「あれば」，「あってば」不合法。）

〜こそ
발음〜코소
正是…；才是…
名词 + こそ（可加「が」成「こそが」）
强烈提示焦点，表“正是这个，不是别的”。
「이쓰모아리가토우.」「이에,코치라코소.」
「いつもありがとう。」「いえ、こちらこそ。」
“一直谢谢你。”“不，我才是。”
코토시코소,타바코오야메루쓰모리다.
今年こそ、たばこをやめるつもりだ。
今年我一定要把烟戒掉。
마이니치노치이사나도료쿠코소가,오오키나세이코우니쓰나가루.
毎日の小さな努力こそが、大きな成功につながる。
正是每天的小努力带来了巨大的成功。
朝鲜语：-야말로
韩语「-야말로」与「こそ」几乎一致；但日语「こちらこそ」已成固定寒暄，韩语对应「저야말로」，礼貌度需注意。
易错点

毎日の小さな努力をこそが、大きな成功につながる。 → 努力こそが（「こそ」可与「が」连用成「こそが」，但不能叠在「を」后再接「が」。）

〜として
발음〜토시테
作为…；以…身份
名词 + として；名词 + としての + 名词
表示身份、资格、立场或名义。
아니와,엔지니아토시테아메리카노카이샤데하타라이테이루.
兄は、エンジニアとしてアメリカの会社で働いている。
哥哥作为工程师在美国公司工作。
この町は、温泉地として有名です。
这个镇作为温泉地很有名。
社会人としての責任を持って行動してください。
请以社会人的责任感行事。
朝鲜语：-로서
韩语「-로서」表资格，与「として」对应；但韩语另有「-로써」表手段，日语「として」不表手段，切勿混用。
易错点

兄は、エンジニアのとしてアメリカの会社で働いている。 → エンジニアとして（「として」直接接名词，不加「の」；修饰名词时才用「としての」。）
