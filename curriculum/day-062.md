## 新词 25

- **期間**（きかん）期间｜韩语参考：기간（期间，时期）<br>
  例：治るのにどのくらいの期間がかかりますか。（治好需要多长时间？）
- **機関**（きかん）机构；机关｜韩语参考：기관（机关）<br>
  例：その機関は１９６０年代後半に設立された。（那个机构成立于六十年代后期。）
- **効く**（きく）有效；见效｜韩语参考：듣다（见效，有效） / 먹혀들다（见效，起效，听进去）<br>
  例：この薬は頭痛によく効きます。（这种药治头疼很管用。）
- **機嫌**（きげん）心情；情绪｜韩语参考：비위（想法，心情，情绪）<br>
  例：彼は他人の機嫌を損ねないように気をつけている。（他注意不去惹别人不高兴。）
- **気候**（きこう）气候｜韩语参考：기후（气候）<br>
  例：その国は気候が温和だ。（那个国家气候温和。）
- **岸**（きし）岸｜韩语参考：기슭 / 물가<br>
  例：彼らはその船を岸にあげた。（他们把船拖上了岸。）
- **生地**（きじ）布料；面料｜韩语参考：감（布料，料子） / 옷감（衣料，布料）<br>
  例：生地を預ければドレスを仕立ててくれますか。（把布料交给你们，能给我做条连衣裙吗？）
- **技師**（ぎし）工程师｜韩语参考：엔지니어（工程师）<br>
  例：トムは電気技師です。（汤姆是电气工程师。）
- **記者**（きしゃ）记者｜韩语参考：기자（记者）<br>
  例：記者は話されたことはすべて書き留めた。（记者把说过的话全都记了下来。）
- **傷**（きず）伤；瑕疵｜韩语参考：티（瑕疵，疵点 ，疵瑕） / 흠（瑕疵，缺损） / 상처（伤口，伤）<br>
  例：ここに傷があるので安くしてください。（这里有瑕疵，请便宜一点。）
- **期待**（きたい）期待｜韩语参考：기대（期待，期望） / 기대치（期望值，期待值）<br>
  例：とにかく万事うまくいくように期待しよう。（总之就指望一切顺利吧。）
- **帰宅**（きたく）回家｜韩语参考：귀가（回家）<br>
  例：何が彼を帰宅する気にさせたのか。（是什么让他想回家的呢？）
- **貴重**（きちょう）宝贵｜韩语参考：귀중하다<br>
  例：あれは貴重な経験だった。（那是一次宝贵的经历。）
- **議長**（ぎちょう）议长｜韩语参考：의장（议长）<br>
  例：彼らはスミスさんを議長に任命した。（他们任命史密斯先生为议长。）
- **きちんと**（きちんと）好好地；端正｜韩语参考：바로（端正地，正确地） / 단정히（端正地，正经地）<br>
  例：私の時計はきちんと動いている。（我的表走得很准。）
- **きつい**（きつい）紧；够呛｜韩语参考：째다（瘦，紧，挤） / 뻑뻑하다（紧）<br>
  例：トムは頭にきつい一発を受けた。（汤姆头上挨了重重一击。）
- **気付く**（きづく）察觉｜韩语参考：채다（猜到，察觉，看出）<br>
  例：彼は危険に気づいていなかった。（他没有察觉到危险。）
- **寄付**（きふ）捐赠｜韩语参考：기부（捐赠，捐献，赠送） / 기증（捐赠）<br>
  例：彼女は赤十字に寄付した。（她向红十字会捐了款。）
- **希望**（きぼう）希望｜韩语参考：희망（希望，愿望） / 가망（指望，希望） / 바람（希望，期望，期待）<br>
  例：これが彼のたった一つの希望であった。（这是他唯一的希望。）
- **基本**（きほん）基础；基本｜韩语参考：기본（基本，基础）<br>
  例：父は園芸の基本を教えてくれた。（父亲教了我园艺的基础。）
- **決まり**（きまり）规矩；规定｜韩语参考：규정（规定，规章） / 법도（法度，规矩，礼仪）<br>
  例：学校の決まりは守らないといけないぞ。（学校的规矩可得遵守。）
- **気味**（きみ）有点…的迹象（常接在名词或动词连用形后）｜韩语参考：기미（苗头，迹象，征兆） / 기운（气势 ，迹象，征兆，苗头）<br>
  例：今日は風邪気味なので、早めに寝ます。（今天有点感冒，所以早点睡。）
- **奇妙**（きみょう）奇怪｜韩语参考：기묘하다<br>
  例：これはとても奇妙な手紙です。（这是一封非常奇怪的信。）
- **義務**（ぎむ）义务｜韩语参考：의무（义务）<br>
  例：このような義務があるなんて知らなかった。（我不知道还有这样的义务。）
- **疑問**（ぎもん）疑问｜韩语参考：의문（疑问）<br>
  例：子供には疑問がたくさんあります。（孩子心里有很多疑问。）

## 语法

- **〜ことだ**：最好…；应该…
  接续：动词辞书形/ない形 + ことだ
  朝鲜语：-는 게 좋다 / -아/어야 한다（韩语建议多用「-는 게 좋다」；日语「ことだ」更简短、更像训示，主语常省略，语气略强。）
- **〜ことはない**：不必…；用不着…
  接续：动词辞书形 + ことはない
  朝鲜语：-(으)ㄹ 필요는 없다（韩语「-ㄹ 필요는 없다」直译“没有必要”；日语「ことはない」还隐含“你想多了”的安慰，语气更主观。）
- **〜ことにしている**：习惯上…；坚持…
  接续：动词辞书形/ない形 + ことにしている
  朝鲜语：스스로 정해 놓고 …하다 / -기로 하고 실천하다（매일 걷기로 했다 对照 毎日歩くことにした，只说明做了决定；歩くことにしている 则说明现在把每天走路当作自定规则。）
