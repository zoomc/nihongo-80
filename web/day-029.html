Day 029 · 使役形（～せる／させる）、～てみる / ～てしまう / ～ておく、N が V(他動詞)て ある、Vて + いく / くる

语法 4 条

使役形（～せる／させる）
让／使…（做）
五段 う段→あ段+せる；一段 去る+させる；カ変 来させる；サ変 させる
表使役/强制/允许；他动词句使役对象用 に，自动词句用 を
韩语对应-게 하다 / -시키다
시키다 与 -게 하다 都可以理解使役；日语需再判断使役对象的助词。句中已有被读的内容を 时，让谁读用 人に。
센세이 와 가쿠세이 니 혼 오 요마세마시타.
先生は学生に本を読ませました。
老师让学生读书。
易错易混点
  • ✗ 先生は学生を本を読ませました。✓ 先生は学生に本を読ませました。句子里已经有 を（本を），使役对象改用 に（学生に），不能两个 を。
  • ✗ 読みさせました✓ 読ませました。五段动词的使役是 あ段＋せる：読む→読ませる，不是 読み＋させる。
～てみる / ～てしまう / ～ておく
발음～테미루 / ～테시마우 / ～테오쿠
试着…／…完了／事先…
動詞て形 + みる／しまう／おく
补助动词：てみる 尝试、てしまう 完了/遗憾、ておく 事先准备
韩语对应-아/어 보다 / -아·어 버리다 / -아·어 두다
韩语分别用보다(尝试)、버리다(完了/遗憾)、두다(预先)，与日语三形基本对应。
코노료우리 오 타베테미마스.
この料理を食べてみます。
尝尝这道菜。
혼 오 욘데시마이마시타.
本を読んでしまいました。
把书看完了。
易错易混点
  • ✗ 先に予約しておくつもり：予約しおきます。✓ 予約しておきます。みる／しまう／おく 都接在て形后：「先订好」是 予約しておく。
N が V(他動詞)て ある
발음N 가 V테 아루
（人为地）已经…着；事先做好了…
他動詞て形 + ある；结果状态常用 が；已做好的准备也可用 を（例：本を置いてある）
表示某人有意为之、结果留存至今的状态，常用于准备已完成；不接自动词
韩语对应-아/어 있다
韩语结果状态用아/어 있다，不强调人为施事；日语てある暗示某人有意为之，语感不同。
쓰쿠에 노 우에 니 혼 가 오이테아리마스.
机の上に本が置いてあります。
桌上放着书（事先摆好的）。
호테루 노 요야쿠 가 시테아리마스.
ホテルの予約がしてあります。
酒店已经（事先）订好了。
易错易混点
  • ✗ ドアが開いてあります。✓ ドアが開いています。（人为打开并保持则 開けてあります）開く 是自动词，不能接 てある。“门开着”是 開いています；人为打开并保持才说 開けてあります。
Vて + いく / くる
발음V테 + 이쿠 / 쿠루
…下去／…起来（趋势）；去…再来／…过来（移动）
動詞 て形 + いく／くる；いく・くる 按五段/カ変变形（ていきます／てきました）
空间：做完某动作后去/来；时间：状态从现在向将来（いく）或从过去向现在（くる）变化
韩语对应-아/어 가다 / -아·어 오다
韩语가다/오다补助同样表时间趋势，以说话人为基准；与日语いく/くる方向基准相近。
코레카라 모 니혼고 오 벤쿄우시테이키마스.
これからも日本語を勉強していきます。
今后也会继续学下去。
아메 가 후떼키마시타.
雨が降ってきました。
下起雨来了。
易错易混点
  • ✗ これから勉強しています。✓ これからも勉強していきます。「今后继续学下去」用 〜ていく；ている 只表示“现在正在”。
  • ✗ 雨が降っていきました。✓ 雨が降ってきました。雨“下起来（朝现在）”用 〜てくる；ていく 是朝未来、远离说话人。
