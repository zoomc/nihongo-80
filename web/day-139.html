今日语法 2 条

〜のもとで / 〜のもとに
발음〜노모토데 / 〜노모토니
在…指导或条件下
名词 + のもとで / 名词 + のもとに
韩语对应…의 지도 아래 / …라는 조건 아래
导师指导常说「指導のもとで」。规则或共同目标作条件时也可说「合意のもとに」。
와타시 와 다이가쿠인 데, 유우메이나쿄우주 노 모토 데 켄큐우 오 쓰즈케타.
私は大学院で、有名な教授のもとで研究を続けた。
研究生期间，我在一位著名教授的指导下继续开展研究。
아카루이타이요우 노 모토데, 코도모타치 가 겐키 니 아손데이루.
明るい太陽のもとで、子どもたちが元気に遊んでいる。
孩子们在明媚的阳光下活泼地玩耍。

易错点 先生をもとで研究する → 先生のもとで研究する（表示在谁的指导或管辖下，用「名词＋のもとで」。）

〜抜きで / 〜抜きに
발음〜누키데 / 〜누키니
省去…；撇开…
名词 + 抜きで / 名词 + 抜きに / 名词 + 抜きの + 名词
韩语对应…을/를 빼고 / …없이는
「話抜きで」是主动略去，「協力抜きには」是少了某项就难以完成。修饰名词用「抜きの」。
今日は仕事の話抜きで、ゆっくり楽しみましょう。
今天先别谈工作，好好放松吧。
彼の協力抜きには、このプロジェクトは成功しなかっただろう。
没有他的协助，这个项目恐怕就不会成功。

易错点 協力の抜きには成功しなかった → 協力抜きには成功しなかった（用「名词＋抜き」表达省去某要素，和「協力なしには」结构相似。）
