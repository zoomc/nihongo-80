# Day 073 · 〜だけでなく、〜さえ〜ば、〜こそ

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜だけでなく**：不仅…而且…
  接续：普通形 + だけでなく；な形容词可接词干（上手だけでなく）或 な；名词直接接
  朝鲜语：-뿐만 아니라（韩语「-뿐만 아니라」也可表示追加；日语な形容词既可见词干直接接「だけでなく」，也可用「なだけでなく」，应按实际表达判断。）
- **〜さえ〜ば**：只要…就…
  接续：名词 + さえ + ば形；动词ます形词干 + さえ + すれば；动词て形 + さえ + いれば
  朝鲜语：-기만 하면（韩语「-기만 하면」与「さえ〜ば」对应；但日语「さえ」位置固定在各成分后，韩语统一贴在动词后，语序处理不同。）
- **〜こそ**：正是…；才是…
  接续：名词 + こそ（可加「が」成「こそが」）
  朝鲜语：-야말로（韩语「-야말로」与「こそ」几乎一致；但日语「こちらこそ」已成固定寒暄，韩语对应「저야말로」，礼貌度需注意。）
