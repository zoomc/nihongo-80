# Day 002 · N は N ではありません / じゃない、N は N でした、N も

## 新词 25

- **七**（なな）七（なな／しち）｜韩语参考：칠 / 일곱<br>
  例：七時に起きます。（七点起床。）
- **八**（はち）八｜韩语参考：팔（八） / 여덟（八）<br>
  例：八日から休みます。（从八号开始休息。）
- **九**（きゅう）九（きゅう／く）｜韩语参考：구（九）<br>
  例：九時です。（九点。）
- **十**（じゅう）十｜韩语参考：십（十）<br>
  例：十人います。（有十个人。）
- **何**（なん）什么（在 です、时刻或某些量词前读 なん）｜韩语参考：무엇 / 뭐<br>
  例：お仕事は何ですか。（您是做什么工作的？）
- **いくら**（いくら）多少钱｜韩语参考：얼마<br>
  例：これはいくらですか。（这个多少钱？）
- **円**（えん）日元（货币单位）｜韩语参考：엔（일본 화폐 단위）<br>
  例：百円です。（一百日元。）
- **今**（いま）现在｜韩语参考：시방（刚刚，现在） / 이제（现在） / 인제（现在，到现在）<br>
  例：今、何時ですか。（现在几点？）
- **今日**（きょう）今天｜韩语参考：금일（今日，今天） / 오늘（今天，今日）<br>
  例：今日は月曜日です。（今天是周一。）
- **明日**（あした）明天（日常会话）｜韩语参考：내일（明天）<br>
  例：明日、学校へ行きます。（明天去学校。）
- **昨日**（きのう）昨天｜韩语参考：어제（昨天，昨日） / 어저께（在昨天，在昨日）<br>
  例：昨日は日曜日でした。（昨天是周日。）
- **朝**（あさ）早晨｜韩语参考：아침（早上，早晨）<br>
  例：朝ご飯を食べます。（吃早饭。）
- **時間**（じかん）时间；小时｜韩语参考：시간（时间）<br>
  例：時間がありません。（没时间。）
- **時計**（とけい）钟表；手表｜韩语参考：시계<br>
  例：時計を見ます。（看表。）
- **毎日**（まいにち）每天｜韩语参考：매일<br>
  例：毎日、学校へ行きます。（每天去学校。）
- **今週**（こんしゅう）本周｜韩语参考：금주（本周，这周，这星期）<br>
  例：今週は忙しいです。（这周很忙。）
- **月曜日**（げつようび）星期一｜韩语参考：월요일（星期一，周一，礼拜一）<br>
  例：月曜日に試験があります。（周一有考试。）
- **火曜日**（かようび）星期二｜韩语参考：화요일（星期二，周二，礼拜二）<br>
  例：火曜日に試験があります。（周二有考试。）
- **水曜日**（すいようび）星期三｜韩语参考：수（周三，星期三） / 수요일（星期三，周三，礼拜三）<br>
  例：水曜日は休みです。（周三休息。）
- **木曜日**（もくようび）星期四｜韩语参考：목요일（星期四，周四，礼拜四）<br>
  例：木曜日に映画を見ます。（周四看电影。）
- **金曜日**（きんようび）星期五｜韩语参考：금요일（星期五，周五，礼拜五）<br>
  例：金曜日は忙しいです。（周五很忙。）
- **土曜日**（どようび）星期六｜韩语参考：토（星期六，周六，礼拜六） / 토요일（星期六，周六，礼拜六）<br>
  例：土曜日に買い物します。（周六购物。）
- **日曜日**（にちようび）星期日｜韩语参考：일요일（星期日， 星期天，周日，礼拜天）<br>
  例：日曜日は休みです。（周日休息。）

  例：家に帰ります。（回家。）

  例：学校へ行きます。（去学校。）

## 语法

- **N は N ではありません / じゃない**：…不是…
  接续：名词 + ではありません／じゃありません（礼貌体）；名词 + ではない／じゃない（普通体）
  朝鲜语：이/가 아닙니다（학생이 아닙니다、의사가 아닙니다 按收音选 이/가。日语名词后直接接 ではありません，熟人间常说 じゃない。）
- **N は N でした**：…（过去）是…
  接续：名詞 + は + 名詞 + でした
  朝鲜语：이었습니다 / 였습니다（韩语过去按有无收音选이었/였，且分层级；日语でした只有一形，无收音条件。）
- **N も**：…也…
  接续：名詞 + も（替代 は/が/を）
  朝鲜语：도（韩语 도 和日语 も 都可表示追加，常替换主格或宾格助词；叠加其他助词须按具体语境判断。）
