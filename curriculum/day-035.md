- **下げる**（さげる）降低；放下｜韩语参考：낮추다（压低，降低，放低） / 떨구다（降低） / 떨어뜨리다（降低）<br>

## 语法

- **〜間 / 〜間に**：在…期间；在…期间内
  接续：动词ている形／动词辞书形／名词+の + 間（に）
  朝鲜语：-는 동안（韩语 -는 동안 对应 間，-는 동안에 对应 間に；但日语 間に 的后项多为一次性动作，韩语 에 的区分没有这么严格。）
- **〜そうだ（appearance）**：看起来…；好像要…
  接续：动词ます形去ます／い形容词去い／な形容词词干 + そうだ
  朝鲜语：-아/어 보이다（韩语 -아/어 보이다 表外观，但与日语 そうだ 不同，不能用于「即将发生」的预测；那种场合韩语用 -(으)ㄹ 것 같다。）
- **〜そうだ（hearsay）**：听说…；据说…
  接续：动词普通形／い形容词 + そうだ；な形容词・名词 + だ + そうだ
  朝鲜语：-다고 하다（韩语 -다고 하다 是间接引语，与传闻 そうだ 对应；但日语 そうだ 前接名词要加 だ，韩语则用 -(이)라고 하다。）
- **〜らしい（hearsay/conjecture）**：好像…；据说…
  接续：动词普通形／い形容词／な形容词词干／名词 + らしい
  朝鲜语：-(으)ㄴ/는 모양이다（韩语 모양이다 偏重迹象推断，传言则用 -다고 하다；日语 らしい 兼有传闻与推断两种用法，范围更宽。）
