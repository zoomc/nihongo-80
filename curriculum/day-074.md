## 新词 25

- **クリスマス**（クリスマス）圣诞节｜韩语参考：성탄（圣诞日，圣诞节） / 성탄절（圣诞节） / 크리스마스（圣诞节）<br>
  例：いいクリスマスを過ごしましたか。（圣诞节过得好吗？）
- **狂う**（くるう）失常；错乱｜韩语参考：돌다（失常，疯）<br>
  例：あなたの時計、時間は狂いませんか。（你的表走时准吗？）
- **グループ**（グループ）小组｜韩语参考：그룹（小组）<br>

- **苦しい**（くるしい）痛苦；难受｜韩语参考：괴롭다（痛苦，难过） / 고통스럽다（痛苦，难受）<br>

  例：彼女はどうして良いか途方に暮れた。（她不知如何是好，束手无策。）

- **軍**（ぐん）军队｜韩语参考：군（军，军队） / 군대（部队，军队）<br>

- **軍隊**（ぐんたい）军队｜韩语参考：군대（部队，军队） / 군（军，军队）<br>

  例：私達はいろいろなゲームをした。（我们玩了好几种游戏。）

## 语法

- **〜も〜ば〜も**：既…又…；也…也…
  接续：名词 + も + ば形 + 名词 + も；名词 + も + い形容词ければ + 名词 + も
  朝鲜语：-기도 하고 -기도 하다（韩语「-기도 하고 -기도 하다」只并列；日语「も〜ば〜も」用ば形连接，书面感更强，前半须是完整谓语。）
- **〜らしい（typical of）**：像…样的；典型的…
  接续：名词 + らしい（らしくない 表“不像”）
  朝鲜语：-다운（韩语「-다운」同样表“符合其本色”；但日语「らしい」还有传闻用法，韩语传闻用「-라고 한다」，不会混淆。）
- **〜っぽい**：有点…；容易…；带…色
  接续：名词/动词ます形词干/い形容词词干 + っぽい
  朝鲜语：-스럽다（韩语「-스럽다」多带正面或中性色彩；日语「っぽい」常含“不够纯正”的轻微贬义，语气更随意。）
