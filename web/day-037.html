今日语法 4 条

〜方
발음〜카타
…的方法；…的方式
动词ます形去ます + 方（かた）
把动作名词化，表示做某事的方法，常与「使い方／読み方」搭配。
韩语对应-는 방법
쓰는 방법 对照 書き方。「写汉字的方法」整句是 漢字の書き方，动词变成复合名词后，原来的对象 漢字 用 の 连接。
코노키카이 노 쓰카이카타 오 오시에테쿠다사이.
この機械の使い方を教えてください。
请告诉我这台机器的使用方法。
코노칸지 노 요미카타 가 와카리마센.
この漢字の読み方が分かりません。
我不知道这个汉字怎么读。
소보 니 오이시이미소시루 노 쓰쿠리카타 오 나라따.
祖母においしいみそ汁の作り方を習った。
我跟奶奶学了做味噌汤的方法。
易错易混点
  • ✗ この機械を使い方を教えてください。✓ この機械の使い方を教えてください。「使い方」是名词短语，前面的名词要用 の 连接，不能同时保留 を
〜中
발음〜추우／주우
正在…中；整个…；全…
名词 + 中（ちゅう／じゅう）
读 ちゅう 表示正在进行的活动，读 じゅう 表示整个范围或期间。
韩语对应-중 / -내내
韩语 -중 对应 ちゅう（회의 중），-내내 对应 じゅう（하루 종일）；日语同一个汉字两种读法，韩语用不同词尾区分。
치치 와 이마, 덴와추우데스.
父は今、電話中です。
父亲现在正在打电话。
키노우 와 이치니치주우아메 가 후떼이타.
昨日は一日中雨が降っていた。
昨天一整天都在下雨。
코노우타 와 세카이주우 데 시라레테이루.
この歌は世界中で知られている。
这首歌全世界都知道。
易错易混点
  • ✗ 父は今、電話の中です。✓ 父は今、電話中です。表示正在打电话用「電話中」，不是「電話の中」
〜つもり
발음〜쓰모리
打算…；计划…
动词辞书形／动词ない形 + つもりだ
表示说话人已形成的意图，否定形表示不打算做。
韩语对应-(으)ㄹ 생각이다
韩语 -(으)ㄹ 생각이다 与 つもり 接近，但日语 つもり 可用于第二、三人称的确认；韩语 생각이다 多用于第一人称。
나쓰야스미 와 호까이도우 오 료코우스루쓰모리데스.
夏休みは北海道を旅行するつもりです。
暑假我打算去北海道旅行。
쿄우 와 오사케 오 노마나이쓰모리데스.
今日はお酒を飲まないつもりです。
今天我不打算喝酒。
다이가쿠 오 데타라, 도우스루쓰모리데스 카.
大学を出たら、どうするつもりですか。
大学毕业后你打算做什么？
易错易混点
  • ✗ 夏休みは北海道を旅行しつもりです。✓ 夏休みは北海道を旅行するつもりです。つもり 前接辞书形，不是ます形去ます
〜予定
발음〜요테이
预定…；计划…
动词辞书形 + 予定だ；名词 + の + 予定だ
表示已安排好的日程或计划，语气比つもり更客观。
韩语对应-(으)ㄹ 예정이다
출장 예정입니다 对照 出張の予定です；去出差也可用 出張する予定です。日语名词和动词小句的接续不同。
라이게쓰, 오오사카 니 히꼬스요테이데스.
来月、大阪に引っ越す予定です。
下个月我预定搬到大阪。
카이기 와 산지 니 오와루요테이데스.
会議は三時に終わる予定です。
会议预定三点结束。
出発は朝八時の予定です。
出发时间定在早上八点。
易错易混点
  • ✗ 来月、大阪に引っ越すの予定です。✓ 来月、大阪に引っ越す予定です。动词接 予定 直接用辞书形，不用 の；名词才用 の
