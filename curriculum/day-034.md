# Day 034 · ～に なる / ～く なる / ～に する、～と 思う / ～と 言う

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～に なる / ～く なる / ～に する、～と 思う / ～と 言う」造两句自己的话，表达：变成…／使…变得…；觉得…／说「…」

## 新词 19

- **みんな**（みんな）大家；全部｜韩语参考：말끔（干净地，利落地，全部） / 몽땅（都，全部）<br>
  例：女の子はほとんどみんなやさしい。（女孩子几乎都很温柔。）
- **六日**（むいか）六天；六号｜韩语参考：엿새 / 육 일<br>
  例：４月５日か６日に会っていただけませんか。（能不能在四月五号或六号见一面？）
- **向こう**（むこう）对面；那边｜韩语参考：건너（对面） / 고쪽（那边） / 그쪽（那边）<br>
  例：その男の子は向こうにいます。（那个男孩在对面。）
- **六つ**（むっつ）六个｜韩语参考：여섯 개<br>
  例：彼は６行のうちに６つまちがいをした。（他在六行里出了六处错。）
- **村**（むら）村庄｜韩语参考：촌（村子，村庄，乡村） / 동네（小区，社区，村庄） / 마을（村子，村庄）<br>
  例：町は村よりも大きい。（镇比村大。）
- **目**（め）眼睛｜韩语参考：눈（眼睛）<br>
  例：彼女はきれいな目をしている。（她有一双漂亮的眼睛。）
- **メートル**（メートル）米；公尺｜韩语参考：미터（米）<br>
  例：前の人から1メートル離れて並んでください。（请和前面的人隔开一米排队。）
- **眼鏡**（めがね）眼镜｜韩语参考：안경<br>
  例：私はメガネがなくては読めない。（我不戴眼镜就看不了书。）
- **もう一度**（もういちど）再一次｜韩语参考：한 번 더<br>
  例：もう一度ゆっくりお話しください。（请再慢慢说一遍。）
- **持つ**（もつ）拿；持有｜韩语参考：갖다（持有，有） / 집다（握，拿） / 가지다（持有，有）<br>
  例：コートを持ちましょうか。（我来帮你拿外套吧？）
- **もっと**（もっと）更；更加｜韩语参考：더（更，更加） / 더욱（更加，进一步，越来越，愈加）<br>
  例：父がもっと長生きしていたらなあ。（父亲要是能多活几年就好了。）
- **物**（もの）东西；物品｜韩语参考：것（东西，事，的） / 물건（东西，物品，物件）<br>
  例：どちらのかばんがあなたの物ですか。（哪个包是你的？）
- **門**（もん）门；大门｜韩语参考：문（路，门，渠道，途径）<br>
  例：ジョンは門のところまで出てきた。（约翰一直走到门口。）
- **問題**（もんだい）问题；题目｜韩语参考：문제（题，问题）<br>
  例：問題はお金がないということです。（问题是我们没钱。）
- **八百屋**（やおや）蔬菜店｜韩语参考：채소 가게<br>
  例：その八百屋は客にとても親切だ。（那家菜店对客人很热情。）
- **易しい**（やさしい）容易；简单｜韩语参考：쉽다<br>
  例：もっと易しい事を聞いて下さい。（请问点简单些的。）
- **休み**（やすみ）休息；休假｜韩语参考：참（中间休息时间）<br>
  例：学校はクリスマスで休みになった。（学校因圣诞节放假了。）
- **八つ**（やっつ）八个｜韩语参考：여덟 개<br>
  例：そこに八つの小石があった。（那里有八颗小石子。）
- **山**（やま）山｜韩语参考：산（山）<br>
  例：その山はどれくらいの高さですか。（那座山有多高？）

## 语法

- **～に なる / ～く なる / ～に する**：变成…／使…变得…
  接续：名詞/な形 + に + なる；い形 + く + なる；他动词 〜に/く する
  朝鲜语：-아/어지다 / -게 하다（韩语变化用아/어지다，人为改变用게 하다；无日语なる/する的自动他动对立。）
- **～と 思う / ～と 言う**：觉得…／说「…」
  接续：普通形从句 + と + 思う／言う
  朝鲜语：-다고 생각하다 / -라고 말하다（韩语引用按句类选다고/라고/냐고，动词要变化；日语と引用保留原形即可。）

## 汉字 4

- **用** 使用；事情；用途｜音：ヨウ｜训：もち.いる
- **度** 程度；次数；每次｜音：ド、ト、タク｜训：たび、-た.い
- **持** 拿；持有｜音：ジ｜训：も.つ、-も.ち、も.てる
- **以** 以；用；因为｜音：イ｜训：もっ.て
