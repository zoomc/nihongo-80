# Day 072 · 〜だろう、〜んです / 〜のです

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「〜だろう、〜んです / 〜のです」造两句自己的话，表达：大概…吧；（解释）是…的；因为…

## 新词 19

- **忘れ物**（わすれもの）落下的东西｜韩语参考：두고 온 물건<br>
  例：今日忘れ物をした。（今天我把东西落下了。）
- **笑う**（わらう）笑｜韩语参考：웃다（笑）<br>
  例：しかし、彼はめったに笑いませんでした。（不过他很少笑。）
- **割れる**（われる）碎；裂｜韩语参考：깨지다 / 갈라지다<br>
  例：プラスチックは割れにくい。（塑料不容易碎。）
- **結構**（けっこう）相当；够好；不用了｜韩语参考：꽤 / 충분하다 / 괜찮습니다（사양）<br>
  例：この仕事は結構大変です。（这工作相当够呛。）
- **かなり**（かなり）相当；颇为｜韩语参考：꽤（颇，相当，还）<br>
  例：今日はかなり寒いです。（今天相当冷。）
- **だいぶ**（だいぶ）相当（含变化）｜韩语参考：꽤 / 상당히<br>
  例：病気はだいぶ良くなりました。（病好得差不多了。）
- **すっかり**（すっかり）完全；全然（状态全变）｜韩语参考：맨（完全，全部） / 감감（全然） / 아주（完全，永远）<br>
  例：すっかり忘れていました。（完全忘了。）
- **しっかり**（しっかり）牢牢地；扎实地；振作｜韩语参考：단단히 / 제대로 / 정신 차리고<br>
  例：しっかり勉強してください。（请扎扎实实地学。）
- **わざわざ**（わざわざ）特意；专程｜韩语参考：모처럼（特意，难得，好容易）<br>
  例：わざわざ来てくださってありがとうございます。（谢谢您特意前来。）
- **せっかく**（せっかく）好不容易；特意；难得｜韩语参考：모처럼 / 어렵게<br>
  例：せっかくの休みなのに、雨です。（难得放假却下雨了。）
- **かえって**（かえって）反倒；反而｜韩语参考：오히려 / 도리어<br>
  例：安い物を買って、かえって高くつきました。（买了便宜货反倒更花钱。）
- **むしろ**（むしろ）宁可；莫如；倒不如｜韩语参考：차라리 / 오히려<br>
  例：疲れるなら、むしろ休んだほうがいい。（累的话倒不如休息更好。）
- **ところで**（ところで）对了；话说回来（转话题）｜韩语参考：그런데 / 참<br>
  例：ところで、明日の予定は？（对了，明天安排是什么？）
- **それとも**（それとも）还是；或者（选择疑问）｜韩语参考：또는（或，或者，要么）<br>
  例：コーヒーにしますか、それともお茶にしますか。（要咖啡，还是茶？）
- **そのうえ**（そのうえ）加之；而且｜韩语参考：게다가<br>
  例：安いし、そのうえ品質もいい。（便宜，而且质量还好。）
- **それでも**（それでも）尽管如此；即便那样｜韩语参考：그래도 / 그렇더라도<br>
  例：雨が降りました。それでも試合は続きました。（下雨了，即便如此比赛仍继续。）
- **そのため**（そのため）因此；为此｜韩语参考：그 때문에 / 이를 위해<br>
  例：渋滞でした。そのため、遅れました。（堵车了，因此迟到了。）
- **意味**（いみ）意思；含义｜韩语参考：뜻（意，意思） / 의미（含义）<br>
  例：この言葉の意味を教えてください。（请告诉我这个词的意思。）
- **理由**（りゆう）理由；缘由｜韩语参考：까닭（缘由，缘故） / 이유（理由）<br>
  例：遅刻した理由を説明してください。（请说明迟到的理由。）

## 语法

- **〜だろう**：大概…吧
  接续：动词普通形／い形容词／な形容词／名词 + だろう
  朝鲜语：-(으)ㄹ 것이다 / -겠다（韩语 -(으)ㄹ 것이다 与 だろう 对应，-겠다 更偏主观意志或推测；日语 だろう 只表推测，不表意志。）
- **〜んです / 〜のです**：（解释）是…的；因为…
  接续：动词普通形／い形容词 + んです；な形容词+な／名词+な + んです
  朝鲜语：-ㄴ/는 것이다 / -거든요（韩语 -거든요 与 んです 的解释语气接近，但日语 んです 还可用于提问求解释；韩语 거든요 只用于陈述。）

## 汉字 4

- **現** 现在；出现；现实｜音：ゲン｜训：あらわ.れる、あらわ.す、うつつ、うつ.つ
- **調** 调查；调整｜音：チョウ｜训：しら.べる、しら.べ、ととの.う、ととの.える
- **化** 变化；化成｜音：カ、ケ｜训：ば.ける、ば.かす、ふ.ける、け.する
- **当** 命中；相当；当前｜音：トウ｜训：あ.たる、あ.たり、あ.てる、あ.て、まさ.に、まさ.にべし
