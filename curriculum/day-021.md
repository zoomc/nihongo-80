# Day 021 · 〜に（place of existence）、〜に（indirect object）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜に（place of existence）、〜に（indirect object）」造两句自己的话，表达：在…（存在场所）；向…（动作的对象）

## 新词 19

- **食堂**（しょくどう）食堂；餐厅｜韩语参考：식당（食堂）<br>
  例：食堂はセルフサービスでした。（食堂是自助式的。）
- **知る**（しる）知道｜韩语参考：알다（知道，明白）<br>
  例：ぼくは知らないし、気にもしない。（我不知道，也不在意。）
- **白**（しろ）白色｜韩语参考：하양（白色，白）<br>
  例：黒に黒をたしても白にはならぬ。（黑上加黑也变不成白。）
- **白い**（しろい）白的｜韩语参考：하얗다<br>
  例：白いベルトがついてるのがいいな。（我想要那条带白色腰带的。）
- **新聞**（しんぶん）报纸｜韩语参考：신문（报纸）<br>
  例：ジョンのことが新聞に出ていた。（报纸上登了约翰的事。）
- **吸う**（すう）吸；抽（烟）｜韩语参考：먹다（抽，吸） / 빨다（吸，吮吸） / 마시다（吸，呼吸）<br>
  例：この紙はインクを吸わない。（这种纸不吸墨。）
- **スカート**（スカート）裙子｜韩语参考：치마（裙，裙子）<br>
  例：スカートを見せていただけませんか。（能让我看看那条裙子吗？）
- **少ない**（すくない）少｜韩语参考：작다（小，少） / 적다（少，小，欠缺）<br>
  例：読書の時間がますます少なくなっている。（读书的时间越来越少。）
- **すぐに**（すぐに）马上｜韩语参考：금세（马上，立马，立刻） / 금방금방（马上，立马，快速地）<br>
  例：すぐに書かなければなりませんか。（必须马上写吗？）
- **涼しい**（すずしい）凉爽｜韩语参考：서늘하다（凉，凉爽） / 선선하다（凉丝丝，凉爽） / 시원하다（凉爽，凉快）<br>
  例：日増しに涼しくなっていく。（一天天凉快起来。）
- **ストーブ**（ストーブ）取暖炉｜韩语参考：난로<br>
  例：私は古いストーブに１０ドルの値をつけた。（我给那台旧炉子出价十美元。）
- **スプーン**（スプーン）勺子｜韩语参考：수저（勺子，勺儿，汤匙，调羹） / 숟갈（勺子，勺儿，汤匙，调羹） / 숟가락（勺子，勺儿，汤匙，调羹）<br>
  例：スプーンをいただけますか。（能给我一把勺子吗？）
- **スポーツ**（スポーツ）运动｜韩语参考：운동（运动） / 스포츠（体育，运动，竞赛）<br>
  例：ビリーはスポーツがうまいです。（比利很擅长运动。）
- **ズボン**（ズボン）裤子｜韩语参考：바지（裤子）<br>
  例：ちょっとこのズボンにつめて。（请把这条裤子改瘦一点。）
- **住む**（すむ）居住｜韩语参考：살다 / 거주하다<br>
  例：どうしてアメリカに住んでいたの？（你为什么以前住在美国？）
- **スリッパ**（スリッパ）拖鞋｜韩语参考：슬리퍼（拖鞋）<br>
  例：スリッパをはいてください。（请穿上拖鞋。）
- **座る**（すわる）坐｜韩语参考：앉다（坐）<br>
  例：父と母は木の下に座っていました。（父亲和母亲坐在树下。）
- **背**（せ）身高；背｜韩语参考：등（背，脊背，背部） / 키（身高，身长，个子，个儿，个头儿）<br>
  例：トムはジャックと背が同じくらいだ。（汤姆和杰克个子差不多高。）
- **生徒**（せいと）学生｜韩语参考：학생（学生）<br>
  例：この学校はたくさんの生徒がいます。（这所学校有很多学生。）

## 语法

- **〜に（place of existence）**：在…（存在场所）
  接续：名词（场所）+ に + ある／いる
  朝鲜语：에（존재 장소）（韩语 에 表存在场所，与 に 对应；但韩语 있다 不区分有无生命，日语必须区分 ある／いる。）
- **〜に（indirect object）**：向…（动作的对象）
  接续：名词（人）+ に
  朝鲜语：에게（대상）（韩语对人用 에게/한테，对物用 에；日语统一用 に，需根据动词和名词性质判断是对象还是场所。）
