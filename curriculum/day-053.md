## 新词 25

- **油**（あぶら）油｜韩语参考：기름（油）<br>
  例：オリーブの実から油が取れます。（橄榄果可以榨油。）
- **誤り**（あやまり）错误｜韩语参考：오류（谬误，错误） / 잘못（错，错误） / 착오（错误，谬误）<br>
  例：私の誤りは彼の怒りを招いた。（我的错误招来了他的怒气。）
- **表れ**（あらわれ）体现；显露出来的迹象｜韩语参考：표현 / 나타남<br>
  例：この結果は努力の表れです。（这个结果体现了付出的努力。）
- **現れる**（あらわれる）出现｜韩语参考：서다（有，出现） / 나타나다（出现，露面） / 출현하다（出现）<br>
  例：２０人の警官が現場に現れた。（二十名警察出现在现场。）
- **ある**（ある）某个（连体词，后接名词）｜韩语参考：어떤<br>
  例：ある日、知らない番号から電話が来た。（有一天，一个陌生号码打来了电话。）
- **あるいは**（あるいは）或者；也许｜韩语参考：또는（或，或者，要么） / 혹은（或者）<br>
  例：ガスで調理しますか、あるいは電気ですか。（用煤气做饭，还是用电。）
- **アルバム**（アルバム）相册；专辑｜韩语参考：앨범（相册，影集，照相簿） / 음반（唱片，专辑） / 사진첩（相册）<br>
  例：彼は私にアルバムを見せてくれた。（他给我看了相册。）
- **泡**（あわ）泡沫｜韩语参考：거품（泡沫，水分）<br>
  例：くだける波が泡を作った。（碎浪形成了泡沫。）
- **合わせる**（あわせる）配合；合并｜韩语参考：맞추다（合着，配合，按照） / 합치다（合，合并，汇合）<br>
  例：あなたの計画を私に合わせなさい。（把你的计划配合我的来。）
- **哀れ**（あわれ）可怜｜韩语参考：불쌍하다<br>
  例：彼女は哀れを誘う有様だった。（她的样子令人心酸。）
- **案**（あん）方案｜韩语参考：안（提案，方案）<br>
  例：どちらの案がよりよいと思いますか。（你觉得哪个方案更好。）
- **暗記**（あんき）背诵｜韩语参考：암기<br>
  例：彼はその会話を暗記しようとした。（他试图把那段对话背下来。）
- **安定**（あんてい）稳定｜韩语参考：안정（安稳，稳定）<br>
  例：今日の政治状況はそれほど安定していない。（今天的政治局势不太稳定。）
- **あんなに**（あんなに）那么｜韩语参考：저리（那么，如此） / 그리도（如此，那么） / 저다지（如此，那么）<br>
  例：あんなに怒るなんて彼らしくない。（那么生气可不像他。）
- **あんまり**（あんまり）不太｜韩语参考：그다지（부정과 함께）<br>
  例：この話はあんまり人に言いたくない。（这件事我不太想跟别人说。）
- **胃**（い）胃｜韩语参考：위（胃）<br>
  例：食物は胃の中で消化される。（食物在胃里消化。）
- **委員**（いいん）委员｜韩语参考：위원（委员）<br>
  例：委員は全員出席している。（委员全都出席了。）
- **いえ**（いえ）不｜韩语参考：아니요<br>
  例：いえ、こちらこそありがとうございます。（哪里，我才应该谢谢您。）
- **意外**（いがい）意外；出乎意料｜韩语参考：의외（意外） / 뜻밖（意外，出乎意料） / 상상외（出乎意料，意外）<br>
  例：君にここで会うのは全く意外だ。（在这里见到你真是太意外了。）
- **行き**（いき）去程｜韩语参考：가는 길<br>
  例：私は歯医者行きを延ばさねばならない。（我不得不推迟去看牙医。）
- **息**（いき）呼吸｜韩语参考：숨（呼吸）<br>
  例：おぼれかけた人は息を吹き返した。（快淹死的人缓过气来了。）
- **勢い**（いきおい）势头｜韩语参考：세（势头）<br>
  例：勢いに流されているんですよ。（你是被势头推着走。）
- **維持**（いじ）维持｜韩语参考：유지（维持，维护）<br>
  例：この車の維持は高くつく。（养这辆车很费钱。）
- **意識**（いしき）意识；顾及｜韩语参考：의식（意识）<br>
  例：このお料理は、パリのエスプリを意識して、味付けしてみました。（这道菜是顾及巴黎风味调味的。）
- **異常**（いじょう）异常｜韩语参考：이상（异常，反常，不正常）<br>
  例：そんなにたくさん食べるのは異常だ。（吃那么多是不正常的。）

## 语法

- **V ば形 + 同一動詞 辞書形 + ほど**：越…越…
  接续：动词 ば形 + 同一动词辞书形 + ほど；い形 〜ければ〜いほど；な形 〜なら〜なほど／〜であれば〜であるほど。
  朝鲜语：-(으)면 -(으)ㄹ수록（韩语用면…ㄹ수록前后同词，结构与日语ば…ほど对应；但韩语可省略前项只留수록。）
- **N(＋助詞) + さえ／こそ／すら；V ば形 前 + さえ…ば**：甚至…／只要…就／正是…／连…都
  接续：さえ/すら 取代 が・を 或接在助词后（にさえ／でさえ）；さえ…ば 用 条件形(ば)；こそ 强调主语/原因（〜からこそ）
  朝鲜语：-조차 / -야말로 / -마저（韩语조차表连…都(多否定)、마저表连…也(消极)、야말로表正是，分工比日语さえ/すら细。）
- **普通形 + くせに / ものの / とはいえ**：明明…却（责备）／虽然…但是／虽说…然而
  接续：くせに：动词／い形普通形、な形容词 + な、名词 + の；ものの：普通形；とはいえ：名词或普通形 + とはいえ
  朝鲜语：-(으)ㄴ/는 주제에 / -기는 하지만 / 그렇다고는 해도（くせに 接近 주제에，责备色彩强。ものの 可对照 -기는 하지만，承认事实后加保留。とはいえ 也可置于句首，像 그렇다고는 해도。）
