# Day 089 · 〜だらけ、〜切る / 〜切れない、〜かける

- 阶段：P4｜60 分钟｜听力日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜だらけ**：满是…；净是…
  接续：名词 + だらけ
  朝鲜语：-투성이（韩语「-투성이」常带负面色彩；日语「だらけ」也常用于负面事物，并可接抽象名词，如「間違いだらけ」。）
- **〜切る / 〜切れない**：…完；…不了
  接续：动词ます形词干 + 切る／切れない
  朝鲜语：끝까지 다 …하다 / 다 …하지 못하다（食べ切る 可对照 다 먹다；食べ切れない 对照 다 못 먹다。否定「完全做不到」时要用 〜切れる 的否定，而非只把 〜切る 变否定。）
- **〜かける**：…了一半；刚要…
  接续：动词ます形词干 + かける；动词ます形词干 + かけの + 名词
  朝鲜语：-다 말다（韩语「-다 말다」表“做到一半就停”，与「かける」对应；但日语还能表“刚开始、眼看要”，韩语要用「-려다」，含义更宽。）
