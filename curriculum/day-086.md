# Day 086 · 〜に対して、〜について

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜に対して、〜について」各造一句自己的话，表达：对…；与…相对；关于…

## 新词 23

- **計**（けい）计划；计算｜韩语参考：계획 / 계산<br>
  例：一年の計は元旦にあり。（一年之计在于元旦。）
- **敬意**（けいい）敬意｜韩语参考：경의（敬意）<br>
  例：親に対して敬意を表さなければいけない。（对父母必须表示敬意。）
- **経営**（けいえい）经营｜韩语参考：경영（经营）<br>
  例：彼は町でスーパーを経営している。（他在镇上经营一家超市。）
- **景気**（けいき）景气；行情｜韩语参考：경기 / 시황<br>
  例：コンピューター業界は景気がいい。（电脑行业行情很好。）
- **警告**（けいこく）警告｜韩语参考：경고（警告，告诫）<br>
  例：彼は私の警告に全く注意を払わなかった。（他完全没把我的警告当回事。）
- **計算**（けいさん）计算｜韩语参考：계산（计算） / 셈（计算，算数）<br>
  例：旅行の総費用を計算してくれますか。（能帮我算一下旅行的总费用吗？）
- **刑事**（けいじ）刑警；刑事｜韩语参考：형사（刑事）<br>
  例：その泥棒は刑事を見ると走って逃げた。（那个小偷一看见刑警就跑了。）
- **掲示**（けいじ）公告；告示｜韩语参考：게시（告示，公布）<br>
  例：掲示には「全席予約済み」とあった。（公告上写着「所有座位已预订」。）
- **芸術**（げいじゅつ）艺术｜韩语参考：예술（艺术）<br>
  例：彼は芸術のために大金を寄付した。（他为艺术捐了一大笔钱。）
- **ケース**（ケース）案例；盒子｜韩语参考：사례 / 상자<br>
  例：眼鏡をケースに入れました。（把眼镜放进了盒子。）
- **ゲーム**（ゲーム）游戏｜韩语参考：게임（游戏，比赛）<br>
  例：私達はいろいろなゲームをした。（我们玩了好几种游戏。）
- **怪我**（けが）受伤｜韩语参考：부상（负伤，受伤） / 손상（损伤，受伤）<br>
  例：ラグビーをしているとき、彼はけがをした。（他打橄榄球的时候受了伤。）
- **劇**（げき）戏剧｜韩语参考：연극<br>
  例：劇はちょうど定刻に始まった。（戏正好准时开演。）
- **劇場**（げきじょう）剧场｜韩语参考：극장（剧场，戏院） / 공연장（剧场，演出场地）<br>
  例：さあ劇場に着いたぜ。（喏，到剧场了。）
- **化粧**（けしょう）化妆｜韩语参考：화장（化妆）<br>
  例：こってり化粧した顔は異様である。（浓妆艳抹的脸显得很怪异。）
- **けち**（けち）小气；寒酸｜韩语参考：좀생원（斗筲，小气鬼）<br>
  例：彼はけちで、お金を使いたがりません。（他很小气，不愿意花钱。）
- **欠陥**（けっかん）缺陷｜韩语参考：결함（缺陷，毛病）<br>
  例：このシステムには明らかな欠陥がある。（这个系统有明显的缺陷。）
- **結局**（けっきょく）结果；终究｜韩语参考：결국（终究，归根到底） / 필경（终究，最终）<br>
  例：ゆっくりと着実なのが結局勝つ。（稳扎稳打的最终会赢。）
- **決心**（けっしん）决心｜韩语参考：결심（决心，下定决心） / 결의（决心）<br>
  例：すぐ決心するようにしてください。（请尽快下定决心。）
- **欠席**（けっせき）缺席｜韩语参考：결석（缺席，缺勤）<br>
  例：欠席された友人たちのために、乾杯しましょう。（为没能到场的朋友们干杯吧。）
- **決定**（けってい）决定｜韩语参考：결정（决定） / 생각（想，决定）<br>
  例：会合の日にちと場所が決定された。（聚会的时间和地点已经定了。）
- **欠点**（けってん）缺点｜韩语参考：결점（缺点，弱点） / 흠（缺点，缺陷，瑕疵） / 단점（缺点）<br>
  例：欠点があるけどやはり彼が好きです。（他虽然有缺点，我还是喜欢他。）
- **月曜**（げつよう）星期一｜韩语参考：월요일<br>
  例：国会は来週月曜に開かれる。（国会下周一召开。）

## 语法

- **〜に対して**：对…；与…相对
  接续：名词 + に対して；动词/い形容词/ナ形容词 + な + のに対して
  朝鲜语：-에 대해서（韩语「-에 대해서」只表对象；日语「に対して」还常用于前后对比，相当于韩语「-는 반면」，用法更广。）
- **〜について**：关于…
  接续：名词 + について；名词 + についての + 名词
  朝鲜语：-에 대해서（韩语「-에 대해서」与「について」基本对应；但日语修饰名词须用「についての」，韩语无此变化，容易漏写「の」。）
