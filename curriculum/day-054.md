## 新词 25

- **泉**（いずみ）泉；喷泉｜韩语参考：샘（泉，泉水）<br>
  例：泉はおよそ１７０フィートの高さまで温水を吹き出す。（喷泉把温水喷到约一百七十英尺高。）
- **いずれ**（いずれ）早晚；哪个｜韩语参考：언젠가 / 어느 쪽<br>
  例：人間はいずれ死ぬのだ。（人早晚都会死。）
- **以前**（いぜん）以前｜韩语参考：이전（以前，之前） / 앞（前，以前） / 예（以前）<br>
  例：彼女はもはや以前の彼女ではない。（她已经不是从前的她了。）
- **板**（いた）板｜韩语参考：판 / 널빤지<br>
  例：この鉄の板はすずでメッキしてある。（这块铁板镀了锡。）
- **偉大**（いだい）伟大｜韩语参考：위대하다<br>
  例：リンカーンは偉大な政治家であった。（林肯是伟大的政治家。）
- **抱く**（いだく）怀抱；怀有｜韩语参考：안다（抱着，怀有）<br>
  例：母への感謝の気持ちを抱いています。（怀着对母亲的感激之情。）
- **いたずら**（いたずら）恶作剧；淘气｜韩语参考：장난 / 개구쟁이짓<br>
  例：私はいたずらな子供を大目に見る事ができない。（我没法容忍淘气的孩子。）
- **痛み**（いたみ）疼痛｜韩语参考：통증（疼痛）<br>
  例：ここにしつこい痛みがあります。（我这里一直疼。）
- **至る**（いたる）达到｜韩语参考：이르다（达到） / 다다르다（达到）<br>
  例：その語は広い意味を持つに至った。（那个词有了很广的含义。）
- **いち**（いち）集市｜韩语参考：시장<br>
  例：市は月曜ごとに立つ。（集市每周一开。）
- **位置**（いち）位置｜韩语参考：위치（位置，位于）<br>
  例：私はパレードが見えるいい位置にいた。（我站在能看清游行的好位置。）
- **一時**（いちじ）一时；暂时｜韩语参考：일시（一时，一会儿）<br>
  例：彼は一時ここに住んでいた。（他曾在这里住过一阵。）
- **一度に**（いちどに）一次；同时｜韩语参考：한꺼번에<br>
  例：一度にひとつのことをするようにしなさい。（请一次只做一件事。）
- **市場**（いちば）集市｜韩语参考：장（集市） / 장터（集市） / 저자（集市）<br>
  例：彼は市場に出す牛を育てている。（他养牛用来上市。）
- **一家**（いっか）一家｜韩语参考：일가（一家子，一家） / 한집（一家，一家人） / 일가족（一家，一家人）<br>
  例：ジョンソン一家はパーティーをするのが大好きだ。（约翰逊一家很喜欢办聚会。）
- **いつか**（いつか）总有一天｜韩语参考：언젠가<br>
  例：彼女はいつかあの山に登るだろう。（她总有一天会爬上那座山。）
- **一種**（いっしゅ）一种｜韩语参考：일종（一种）<br>
  例：記事の論調は一種の悲観論だった。（文章的论调是一种悲观论。）
- **いつでも**（いつでも）随时；总是｜韩语参考：무시로（无时无刻，随时）<br>
  例：私はいつでも喜んでお手伝いします。（我随时都乐意帮忙。）
- **一般**（いっぱん）一般；普通｜韩语参考：일반（普通）<br>
  例：その理論はまだ一般に認められていない。（那个理论还没有被普遍接受。）
- **一方**（いっぽう）一方面；另一方面｜韩语参考：일방（一边，一方，单方） / 일편（一方面，既……又……） / 한쪽（一边，一方，一面，一头，一端）<br>
  例：一方は赤で、また一方は白である。（一个是红的，另一个是白的。）
- **いつまでも**（いつまでも）永远；一直｜韩语参考：영영（永远地，完全）<br>
  例：私はいつまでも彼の名を覚えている。（我会永远记得他的名字。）
- **移動**（いどう）移动｜韩语参考：이동（移动）<br>
  例：彼らはあちこちへと移動してきます。（他们到处迁移。）
- **従兄弟**（いとこ）堂兄弟；表兄弟｜韩语参考：사촌（堂表亲，堂表兄弟姐妹） / 고종사촌（姑表亲，姑表兄弟，姑表姐妹）<br>
  例：彼は私の兄ではなくて、いとこである。（他不是我哥哥，是我表兄弟。）
- **稲**（いね）稻子｜韩语参考：나락（稻子）<br>
  例：稲は雨の多い地域で作られる。（稻子种在雨水多的地区。）
- **居眠り**（いねむり）打瞌睡｜韩语参考：졸기<br>
  例：授業中に居眠りすることは許しません。（不许上课时打瞌睡。）

## 语法

- **普通形 + わりに(は) / N + に しては**：（相较…）却…；按…来说倒是…
  接续：動詞・い形 普通形 / 名詞＋の + わりに；名詞 + にしては；后项是与前项预期不符的评价
  朝鲜语：-에 비해 / -치고는（韩语에 비해表相较，치고는表按…来说；日语わりに偏不匹配，にしては偏身份标准。）
- **V ます形(去ます) + かねない / かねる**：难保不会…、恐怕会…／难以…、不便…
  接续：動詞 ます形 去 ます + かねない／かねる；かねる 按一段动词变形（かねます／かねた）
  朝鲜语：-(으)ㄹ 수도 있다 / -기 어렵다（韩语ㄹ 수도 있다表恐怕会(坏结果)，委婉拒绝用하기 어렵습니다；かねる的立场限制韩语须另加说明。）
