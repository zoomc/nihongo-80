# Day 120 · 〜ごとに、〜最中に

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜ごとに、〜最中に」造两句自己的话，表达：每…；每隔…；正当…的时候

## 新词 14

- **支払**（しはらい）支付｜韩语参考：지불<br>
  例：どのような支払方法がありますか。（有哪些支付方式？）
- **支払う**（しはらう）支付｜韩语参考：치르다（支付，付，付出） / 지불하다（支付，付给，付款）<br>
  例：私はその本に３ドル支払った。（我为那本书付了三美元。）
- **死亡**（しぼう）死亡｜韩语参考：사망（死亡） / 운명（去世，死亡） / 죽음（死亡）<br>
  例：彼は母親が死亡したという電報を受け取った。（他收到一封电报，说他母亲去世了。）
- **資本**（しほん）资本｜韩语参考：자본（资本，资金）<br>
  例：彼らには次の工場を建設するだけの資本がある。（他们有足够的资本再建一座工厂。）
- **しまい**（しまい）姐妹｜韩语参考：자매<br>
  例：彼の姉妹は二人とも美人です。（他的两个姐妹都是美女。）
- **しまう**（しまう）收拾；做完｜韩语参考：치우다 / ~해 버리다<br>
  例：本とノートをしまいなさい。（把书和笔记本收起来。）
- **しまった**（しまった）糟糕｜韩语参考：아차（糟糕） / 아뿔싸（糟糕，坏了）<br>
  例：しまった！ウッカリして、携帯電話をお店に忘れてきちゃった。（糟糕！我一不小心把手机忘在店里了。）
- **自慢**（じまん）自豪；自夸｜韩语参考：자랑 / 자랑하다<br>
  例：われわれは体力を自慢した。（我们对自己的体力很自豪。）
- **事務**（じむ）事务；总务｜韩语参考：사무（业务，事务）<br>
  例：退職する前に彼は事務を渡した。（退休前他把事务交接了。）
- **示す**（しめす）表示；出示｜韩语参考：뜻하다（代表，表示，意味着） / 표하다（表示，表达） / 내보이다（出示，露出）<br>
  例：その子は何の恐怖も示さなかった。（那孩子没有表现出任何恐惧。）
- **占める**（しめる）占据；占有｜韩语参考：점하다（占，占据） / 차지하다（占据，占有）<br>
  例：ギャンブルで味を占めるとなかなか止められない。（赌博一旦尝到甜头就很难停下来。）
- **霜**（しも）霜｜韩语参考：서리（霜）<br>
  例：今朝、地面は霜で覆われていた。（今天早上地面覆盖着霜。）
- **じゃあ**（じゃあ）那么｜韩语参考：그럼<br>
  例：「安いですね。じゃあ10ヤードください」小娘が答えた。（「真便宜。那我要十码。」小姑娘答道。）
- **借金**（しゃっきん）欠债；借款｜韩语参考：빚 / 차입금<br>
  例：君は借金を払うべきだ。（你应该还清债务。）

## 语法

- **〜ごとに**：每…；每隔…
  接续：名词 + ごとに；动词辞书形 + ごとに
  朝鲜语：-마다（韩语「-마다」兼表“每”和“每隔”；日语要区分「ごとに」（每）与「おきに」（每隔）。）
- **〜最中に**：正当…的时候
  接续：动词ている + 最中に；名词 + の + 最中に
  朝鲜语：-는 중에（韩语「-는 중에」只表“进行中”；日语「最中に」还隐含“被打断、扫兴”的语感。）
