# v6 原创阅读与阶段练习

## 内容与范围

`knowledge/seeds/assessments.jsonl` 有 39 道原创 AI 草稿题，覆盖 27 天：每七天（Day 7–147）各 1 道短情境阅读；Day 45、95、130 阶段练习及 Day 110、132、148 自测各 3 题，每组为两道信息提取题和一道语境语法题。题目包含通知、预约、时间、条件和因果等；选项是原创，没有复制受限教材或官方试题。阶段题两道阅读共用一段材料。它们是轻量练习，覆盖不全，不是 JLPT 官方试题、标准化模考或分数预测，也没有听力和自由产出评估。Day 1 原诊断标签不在本题集覆盖范围内。

所有条目均为 `source: original`、`review_status: ai_draft`；未经日语教师逐题审校，难度、已学词覆盖率和真人完成时间未验证。需要依据学生实际错题审阅，不应将单次答对视为掌握。题面内正确选项仅是种子的私有数据，构建后的公开网页不能直接包含种子或答案、解析。

## 接口和集成

`assessment_v6.build_for_day(day)` 接受 1–150 的整数或含 `day` 的课程字典，返回该日私有题目列表；无题时为空列表。每项有 `qid`、`id`、`type`、`passage`、`prompt`、四个乱序 `options`、`answer`、`knowledge_ids`、`targets`、`assessment`、`review_status`、`rationale`、`h` 和 `oh`。题号摘要覆盖阅读材料、题面、选项、答案、目标及检测类型；选项顺序稳定。`knowledge_ids` 始终为空，语境语法题也只记作练习证据，不改变知识卡掌握。

在同一个出题入口组合题目、向 CLI 和 Worker 注册相同私有答案，并在公开投影中增加 `passage`，但不公开 `answer`、`rationale`、种子或私有答案表。哈希可被枚举，不是保密措施。建议用这些题替换部分当日六题，避免增加总量；最终题量、课程块描述与提交完成规则必须由接入方一起核验，不能把页面访问当作完成。实际展示结果和真实学习用时尚待验证。

## 专项结构核查（2026-11-07）

临时 Python 校验逐行检查 39 条：种子 ID 唯一，4 个选项均非重复且包含答案，正文、题干及目标非空，全部为 original / ai_draft；遍历 150 天并比对整数与字典调用结果，确认所有生成题空 knowledge_ids、选项散列与答案散列一致。计数：weekly 21、stage 9、mock 9；6 个阶段/自测日各 3 题。此项仅证明结构及确定性，不证明题意无歧义、语法难度适配或端到端记录成功。未修改状态数据库，未新增正式测试。
