# Day 085 · N + に 基づいて / を もとに / どおり(に)、V ば形 + 同一動詞 辞書形 + ほど

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「N + に 基づいて / を もとに / どおり(に)、V ば形 + 同一動詞 辞書形 + ほど」造两句自己的话，表达：基于…／以…为依据／按照…；越…越…

## 新词 14

- **命**（いのち）生命；命<br>
  例：その犬は少女の命を救った。（那条狗救了女孩的命。）
- **違反**（いはん）违反｜朝鲜语：위반<br>
  例：それはルール違反です。（那是违反规则的。）
- **衣服**（いふく）衣服｜朝鲜语：의복<br>
  例：彼らは衣服をほとんど着用しない。（他们几乎不穿衣服。）
- **居間**（いま）起居室；客厅<br>
  例：彼らは居間でお茶を飲んでいます。（他们在客厅喝茶。）
- **今に**（いまに）不久；早晚<br>
  例：今にバチがあたるぞ。（早晚会遭报应的。）
- **今にも**（いまにも）眼看就要<br>
  例：トムは今にもここに来るはずです。（汤姆应该马上就要来了。）
- **否**（いや）不；不是<br>
  例：いや、当初の考えはそうでした。（不，最初的想法是这样的。）
- **以来**（いらい）以来｜朝鲜语：이래<br>
  例：１９８８年以来トムに会っていません。（自1988年以来就没见过汤姆。）
- **依頼**（いらい）委托；请求｜朝鲜语：의뢰<br>
  例：彼女は彼に資金を集めるように依頼した。（她委托他去筹集资金。）
- **いらいら**（いらいら）焦躁；烦躁<br>
  例：ビルは試験のことでいらいらしている。（比尔因为考试的事心烦。）
- **いらっしゃい**（いらっしゃい）欢迎；请进<br>
  例：いるだけ持っていらっしゃい。（你要多少就拿多少吧。）
- **医療**（いりょう）医疗｜朝鲜语：의료<br>
  例：彼は医療に一生を捧げた。（他把一生献给了医疗事业。）
- **岩**（いわ）岩石<br>
  例：この岩は何に似ていますか。（这块岩石像什么？）
- **祝い**（いわい）祝贺；庆祝<br>
  例：私は彼の卒業祝いに電報を打った。（我发了电报祝贺他毕业。）

## 语法

- **N + に 基づいて / を もとに / どおり(に)**：基于…／以…为依据／按照…
  接续：名詞 + に基づいて（依据资料/规则/数据）；名詞 + をもとに（以…为素材/基础）；名詞 + どおり(に)（照原样、按预定）
  朝鲜语：-에 근거해 / -을 바탕으로 / -대로（韩语에 근거해表依据、을 바탕으로表以…为基础、대로表按照，与日语三形基本对应。）
- **V ば形 + 同一動詞 辞書形 + ほど**：越…越…
  接续：動詞 条件形(ば) + 同じ動詞 辞書形 + ほど；い形 ければ＋い形＋ほど；な形 なら＋な形＋ほど
  朝鲜语：-(으)면 -(으)ㄹ수록（韩语用면…ㄹ수록前后同词，结构与日语ば…ほど对应；但韩语可省略前项只留수록。）

## 汉字 4

- **側** 侧；旁边｜音：ソク｜训：かわ、がわ、そば
- **任** 责任；委托｜音：ニン｜训：まか.せる、まか.す
- **引** 拉；引用｜音：イン｜训：ひ.く、ひ.ける
- **求** 要求；寻求｜音：キュウ、グ｜训：もと.める
