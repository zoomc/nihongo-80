# Day 143 · 〜ますように

- 阶段：P4｜60 分钟｜听力日
- Can-do：用「〜ますように」造两句自己的话，表达：但愿…；希望…

## 新词 14

- **トランプ**（トランプ）扑克牌｜韩语参考：카드（扑克牌） / 트럼프（扑克） / 카드놀이（纸牌，扑克）<br>
  例：トランプでごまかすのはよくないことだ。（打牌作弊是不好的。）
- **取り上げる**（とりあげる）拿起；没收｜韩语参考：들어 올리다 / 압수하다<br>
  例：彼女はガラスの花瓶を取り上げた。（她拿起了一个玻璃花瓶。）
- **努力**（どりょく）努力｜韩语参考：노력（努力，下工夫）<br>
  例：彼はその問題を解こうと努力した。（他努力想解开那道题。）
- **ドレス**（ドレス）连衣裙；礼服｜韩语参考：드레스（(连衣裙式)礼服）<br>
  例：あのドレスは彼女によく似合う。（那条连衣裙很适合她。）
- **取れる**（とれる）脱落；能取到｜韩语参考：떨어지다 / 얻을 수 있다<br>
  例：オリーブの実から油が取れます。（橄榄果能榨出油。）
- **泥**（どろ）泥｜韩语参考：진흙<br>
  例：彼はブーツの泥をこすり落とした。（他刮掉了靴子上的泥。）
- **トン**（トン）吨｜韩语参考：톤（吨）<br>
  例：この荷物は一トンあります。（这批货重一吨。）
- **とんでもない**（とんでもない）岂有此理；哪里的话｜韩语参考：천만에요 / 터무니없다<br>
  例：彼女が歌手だなんてとんでもない。（说她是歌手，简直荒唐。）
- **どんな**（どんな）什么样的｜韩语参考：뭔（什么） / 무슨（什么） / 아무（任何，什么）<br>
  例：私はどんな戦争にも反対だ。（我反对任何形式的战争。）
- **どんなに**（どんなに）多么｜韩语参考：좀（多么） / 암만（多么） / 오죽（多么，多）<br>
  例：君は私がどんなに心配しているかを知らない。（你不知道我有多担心。）
- **トンネル**（トンネル）隧道｜韩语参考：굴（隧道） / 터널（隧道）<br>
  例：汽車はトンネルを通り抜けた。（火车穿过了隧道。）
- **名**（な）名字；名声｜韩语参考：이름（名字，名称）<br>
  例：私はいつまでも彼の名を覚えている。（我会永远记得他的名字。）
- **なお**（なお）仍然；另外｜韩语参考：여전히 / 또한<br>
  例：あとで起こったことはなお悪かった。（后来发生的事更糟。）
- **仲**（なか）关系；交情｜韩语参考：사이（关系）<br>
  例：私は彼とは訪問し合う仲だ。（我和他是互相串门的交情。）

## 语法

- **〜ますように**：但愿…；希望…
  接续：动词ます形词干 + ように（ませんように 表否定祈愿）
  朝鲜语：-기를 바랍니다（韩语祈愿用「-기를 바랍니다」，需有完整主句；日语「ますように」可单独成句，主语省略，形式更短。）
