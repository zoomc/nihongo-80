今日语法 4 条

〜間 / 〜間に
발음〜아이다 / 〜아이다니
在…期间；在…期间内
动词ている形／动词辞书形／名词+の + 間（に）
「間」表示整段时间持续，「間に」表示在这段时间内的某一时点。
韩语对应-는 동안
留守の間に来た 是外出期间发生了一次事，对照 집을 비운 동안에 왔다。留守の間ずっと待っていた 则覆盖那段时间的一个持续动作。
나쓰야스미 노 아이다, 소후 노 이에 니 이마시타.
夏休みの間、祖父の家にいました。
暑假期间我住在爷爷家。
하하 가 네테이루아이다 니, 헤야 오 소우지시타.
母が寝ている間に、部屋を掃除した。
趁母亲睡觉时，我打扫了房间。
덴샤 오 마떼이루아이다, 즈또혼 오 욘데이타.
電車を待っている間、ずっと本を読んでいた。
等电车的时候，我一直在看书。

易错点 母が寝ている間で、部屋を掃除した。 → 母が寝ている間に、部屋を掃除した。（表示时间段用 間，不能用 間で）

〜そうだ（appearance）
발음〜소우다
看起来…；好像要…
动词ます形去ます／い形容词去い／な形容词词干 + そうだ
根据眼前所见推测外观或即将发生的变化，不能用于传闻。
韩语对应-아/어 보이다
韩语 -아/어 보이다 表外观，但与日语 そうだ 不同，不能用于「即将发生」的预测；那种场合韩语用 -(으)ㄹ 것 같다。
そのカレー、辛そうだね。
那个咖喱看起来好辣啊。
소라 가 쿠라이데스 네. 아메 가 오리소우데스.
空が暗いですね。雨が降りそうです。
天好暗，好像要下雨了。
히사시부리 니 아따소후 와 겐키소우다따.
久しぶりに会った祖父は元気そうだった。
好久不见的爷爷看起来很健康。

易错点 空が暗いですね。雨が降りるそうです。 → 空が暗いですね。雨が降りそうです。（降る 是五段动词，接 そうだ 要用ます形去ます「降り」，不是「降りる」）

〜そうだ（hearsay）
발음〜소우다
听说…；据说…
动词普通形／い形容词 + そうだ；な形容词・名词 + だ + そうだ
转述从别处听来的信息，信息来源用「〜によると」提示。
韩语对应-다고 하다
韩语 -다고 하다 是间接引语，与传闻 そうだ 对应；但日语 そうだ 前接名词要加 だ，韩语则用 -(이)라고 하다。
텐키요호우 데 와, 아시타 와 유키 가 후루소우데스.
天気予報では、明日は雪が降るそうです。
天气预报说明天会下雪。
駅前の本屋は来月なくなるそうだ。
听说车站前的书店下个月要关门。
린산 노 오니이산 와 이샤다소우데스.
リンさんのお兄さんは医者だそうです。
听说小林先生的哥哥是医生。

易错点 天気予報では、明日は雪が降るだそうです。 → 天気予報では、明日は雪が降るそうです。（动词普通形直接接 そうだ，不用 だ）

〜らしい（hearsay/conjecture）
발음〜라시이
好像…；据说…
动词普通形／い形容词／な形容词词干／名词 + らしい
根据传闻或迹象推断，语气比そうだ更客观、委婉。
韩语对应-(으)ㄴ/는 모양이다 / -다고 한다
韩语 모양이다 偏重迹象推断，传言则用 -다고 하다；日语 らしい 兼有传闻与推断两种用法，范围更宽。
에키 노 치카쿠 니 아타라시이카페 가 데키타라시이.
駅の近くに新しいカフェができたらしい。
车站附近好像新开了一家咖啡店。
헤야 노 덴키 가 키에테이루. 모우네타라시이.
部屋の電気が消えている。もう寝たらしい。
房间的灯关着，看来他们已经睡了。
아노미세 노 라아멘 와 토테모유우메이라시이데스.
あの店のラーメンはとても有名らしいです。
听说那家店的拉面很有名。

易错点 あの店のラーメンはとても有名だらしいです。 → あの店のラーメンはとても有名らしいです。（名词和な形容词直接接 らしい，不加 だ）
