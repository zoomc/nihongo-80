# Day 044 · 普通形 + んです / のだ、N に Vて ほしい / Vないで ほしい

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「普通形 + んです / のだ、N に Vて ほしい / Vないで ほしい」造两句自己的话，表达：（是）因为…；其实是…（说明/强调语气）；希望（别人）做…／希望别…

## 新词 19

- **踊り**（おどり）舞蹈｜韩语参考：춤（舞蹈）<br>
  例：私のガールフレンドは踊りがうまい。（我女朋友跳舞跳得好。）
- **踊る**（おどる）跳舞｜韩语参考：춤추다（跳舞） / 무용하다（跳舞）<br>
  例：なぜ彼と踊らなかったの？（为什么没跟他跳舞？）
- **驚く**（おどろく）吃惊｜韩语参考：놀라다（惊吓，吃惊）<br>
  例：母はそのニュースを聞いて驚いた。（母亲听到那个消息很吃惊。）
- **お祭り**（おまつり）祭典；庙会｜韩语参考：축제<br>
  例：お祭りでロブスターを食べました。（在庙会上吃了龙虾。）
- **お見舞い**（おみまい）探望｜韩语参考：병문안<br>
  例：彼女のお見舞いに行こうよ。（我们去探望她吧。）
- **お土産**（おみやげ）土特产；伴手礼｜韩语参考：기념품 / 특산품<br>
  例：これは北海道からのお土産です。（这是从北海道带来的特产。）
- **思い出す**（おもいだす）想起｜韩语参考：나다（想起，想到） / 기억나다（记起，想起） / 상기하다（想起，记起）<br>
  例：あなたを見るとお兄さんを思い出します。（一看到你就想起你哥哥。）
- **思う**（おもう）想；认为｜韩语参考：느끼다（认为，觉得，感到） / 여기다（认为，看作） / 생각하다（想，思考）<br>
  例：晴れだと思うよ。（我觉得会放晴。）
- **おもちゃ**（おもちゃ）玩具｜韩语参考：노리개（玩具） / 노리갯감（玩具）<br>
  例：あのおもちゃは木で作られている。（那个玩具是木头做的。）
- **表**（おもて）正面；表面｜韩语参考：겉（外面，表面，表） / 밖（表，表面） / 거죽（皮，表皮，表面）<br>
  例：この紙はどちらが表だか見分けがつかない。（这张纸分不清哪面是正面。）
- **親**（おや）父母｜韩语参考：부모（父母） / 어버이（父母）<br>
  例：私たちは親をあてにしてはいけない。（我们不能依赖父母。）
- **泳ぎ方**（およぎかた）游法｜韩语参考：수영하는 방법<br>
  例：君に泳ぎ方を教えよう。（我来教你游泳的方法。）
- **下りる**（おりる）下来；下车｜韩语参考：나오다（下来，出来） / 내려서다（下，下来） / 내려오다（下来）<br>
  例：一行は、歩いてその山を下りた。（一行人步行下了那座山。）
- **折る**（おる）折断；折叠｜韩语参考：꺾다（折，折断） / 포개다（叠，折叠） / 분지르다（折断，掰断）<br>
  例：その紙を四つ折りにしなさい。（把那张纸折成四折。）
- **お礼**（おれい）道谢｜韩语参考：감사 / 사례<br>
  例：息子に成り代わってお礼を申し上げます。（我代表儿子向您道谢。）
- **折れる**（おれる）断；折｜韩语参考：부러지다（折，折断）<br>
  例：医者は彼の折れた足をついだ。（医生给他接好了断腿。）
- **終わり**（おわり）结束｜韩语参考：종말（结局，结束，下场）<br>
  例：さぁ、一日を終わりとしましょう。（好了，今天就到此结束吧。）
- **カーテン**（カーテン）窗帘｜韩语参考：커튼（窗帘）<br>
  例：カーテンが風になびいた。（窗帘随风飘动。）
- **海岸**（かいがん）海岸｜韩语参考：해안（海岸，海边） / 해변가（海岸，海滨，海边） / 해안가（海岸，海边）<br>
  例：このバスは、海岸に行きますか。（这趟公交去海岸吗？）

## 语法

- **普通形 + んです / のだ**：（是）因为…；其实是…（说明/强调语气）
  接续：動詞・い形 普通形 + んです；な形・名詞 + な + んです；礼貌体 んです，简体 のだ／んだ
  朝鲜语：-거든요 / -는데요 / -잖아요（韩语说明语气由거든요、는데요、잖아요等分担；日语んです一形统合，须按语境选择。）
- **N に Vて ほしい / Vないで ほしい**：希望（别人）做…／希望别…
  接续：動詞 て形 + ほしい；否定 ない形 + で + ほしい；动作主体用 に（或 が）
  朝鲜语：-아/어 주기를 바라다（韩语希望别人做用주기를 바라다，对长辈须加시；日语てほしい不宜直接对长辈说。）
