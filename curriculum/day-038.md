# Day 038 · ～かもしれない / ～でしょう、～なければ ならない

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「～かもしれない / ～でしょう、～なければ ならない」造两句自己的话，表达：也许…／大概…吧；必须…／不得不…

## 新词 20

- **片付ける**（かたづける）整理；收拾；解决<br>
  例：部屋を片付けてください。（请把房间收拾好。）
- **直す**（なおす）修理；改正<br>
  例：間違いを直します。（我把错误改过来。）
- **続ける**（つづける）继续（他动）<br>
  例：日本語の勉強を続けています。（我一直在继续学日语。）
- **始める**（はじめる）开始（他动）<br>
  例：新しい仕事を始めます。（我开始新工作。）
- **決める**（きめる）决定（他动）<br>
  例：旅行の日を決めました。（定好了旅行的日子。）
- **調べる**（しらべる）调查；查阅<br>
  例：図書館で言葉を調べます。（在图书馆查词。）
- **比べる**（くらべる）比较<br>
  例：二つの店の値段を比べます。（比较两家店的价格。）
- **慣れる**（なれる）习惯（自动）<br>
  例：日本の生活に慣れました。（我习惯了日本的生活。）
- **遅れる**（おくれる）迟到；落后<br>
  例：会議に遅れてしまいました。（开会迟到了。）
- **間に合う**（まにあう）赶得上；来得及<br>
  例：急げば、始発に間に合います。（快点的话能赶上首班车。）
- **足りる**（たりる）够；足够<br>
  例：時間が足りません。（时间不够。）
- **挨拶**（あいさつ）寒暄；问候；致辞<br>
  例：先生に挨拶をします。（向老师打招呼。）
- **お願い**（おねがい）请求；拜托<br>
  例：ちょっとお願いがあります。（有件事想拜托你。）
- **説明**（せつめい）说明；解释<br>
  例：使い方を説明してください。（请说明一下用法。）

- **洗濯**（せんたく）洗衣服；洗涤<br>
  例：週末に洗濯をします。（周末洗衣服。）

  例：友達と映画の約束をしました。（和朋友约好了看电影。）

## 语法

- **～かもしれない / ～でしょう**：也许…／大概…吧
  接续：普通形 + かもしれない；普通形 + でしょう
  朝鲜语：-(으)ㄹ지도 모르다 / -겠다（韩语不确定用ㄹ지도 모르다，较强推量用겠다或ㄹ 것이다；でしょう无对应敬语分层。）
- **～なければ ならない**：必须…／不得不…
  接续：動詞ない形（去ない） + ければ + ならない
  朝鲜语：-아/어야 하다 / -지 않으면 안 되다（韩语义务用아/어야 하다，更强用아/어야만 하다；敬语하셔야 합니다，日语无此分层。）
