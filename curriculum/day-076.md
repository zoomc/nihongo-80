## 新词 25

- **現象**（げんしょう）现象｜韩语参考：현상（现象）<br>
  例：生物学者はその現象の観察に集中した。（生物学家集中观察那个现象。）
- **現状**（げんじょう）现状｜韩语参考：현주소（现状）<br>
  例：彼は現状を大いに嘆いた。（他对现状大为感叹。）
- **建設**（けんせつ）建设｜韩语参考：건설<br>
  例：その金は体育館の建設に当てられた。（那笔钱被用于体育馆的建设。）
- **現代**（げんだい）现代；当代｜韩语参考：현대（现代） / 당대（当下，当代）<br>
  例：私は現代の音楽はあまり好きではない事を認めます。（我承认我不太喜欢现代音乐。）
- **建築**（けんちく）建筑；建设｜韩语参考：건축（建筑，建造）<br>
  例：彼らは家の建築にとりかかった。（他们开始盖房子了。）
- **見当**（けんとう）估计；头绪｜韩语参考：가늠（估计，估摸，掂量，估量） / 가량（估计，估摸，估量） / 대중（估计，掂量）<br>
  例：それがどこにあるのか、およその見当はついている。（它大概在哪儿，我心里有点数。）
- **現場**（げんば）现场｜韩语参考：현장（现场） / 현지（现场，实地）<br>
  例：警察はまもなく現場に着くだろう。（警察很快就会到现场。）
- **憲法**（けんぽう）宪法｜韩语参考：헌법（宪法）<br>

- **権利**（けんり）权利｜韩语参考：권리（权利）<br>

- **濃い**（こい）浓；深｜韩语参考：짙다（深） / 진하다（浓，稠）<br>
  例：コーヒーはどんなふうにしましょうか。濃いブラックがいいですか。（咖啡要怎么弄？浓的黑咖啡可以吗？）
- **恋**（こい）恋爱｜韩语参考：사랑 / 연애<br>
  例：それは片思いの恋だった。（那是一场单相思。）
- **恋人**（こいびと）恋人｜韩语参考：연인（恋人）<br>
  例：私は恋人を「ダーリン」と呼びます。（我叫我的恋人「达令」。）
- **幸運**（こううん）幸运｜韩语参考：행운（幸运）<br>
  例：私は幸運にもよい席がとれました。（我运气好，弄到了好座位。）
- **講演**（こうえん）演讲；报告｜韩语参考：강연（演讲，讲演，讲座）<br>
  例：今夜の講演は誰ですか。（今晚的演讲是谁讲？）
- **効果**（こうか）效果｜韩语参考：효과（效果，功效，效力，成效，作用）<br>
  例：その新薬はすぐに効果を示した。（那种新药很快就见效了。）
- **硬貨**（こうか）硬币｜韩语参考：동전<br>

- **高価**（こうか）高价；昂贵｜韩语参考：고가（高价）<br>
  例：そんな高価な本は買えないよ。（那么贵的书我可买不起。）

  例：私の兄は試験に合格できなかった。（我哥哥没能通过考试。）

  例：あなたと席を交換しよう。（跟你换个座位吧。）

  例：航空料金の方が鉄道料金より高い。（机票比火车票贵。）
- **光景**（こうけい）景象｜韩语参考：광경（景象，情景，情境）<br>
  例：その光景を見てぎょっとした。（看到那番景象，我吓了一跳。）
- **合計**（ごうけい）合计｜韩语参考：합계（合计，总计） / 도합（总共，共计，合计）<br>
  例：この数字の列を合計しなさい。（把这一列数字加起来。）
- **攻撃**（こうげき）攻击｜韩语参考：공격（攻击） / 가격（攻击，加以攻击）<br>
  例：急所を除くすべての攻撃を認める。（除要害部位外，其他攻击都允许。）

## 语法

- **まるで〜ようだ**：简直像…一样
  接续：まるで + 名词 + の + ようだ；まるで + 普通形 + ようだ
  朝鲜语：마치 -ㄴ 것 같다（韩语「마치」与日语「まるで」一样起强调作用；但韩语比喻常用「-처럼」，日语「ようだ」是断定结句，句法位置不同。）
- **〜に違いない**：一定…；肯定…
  接续：普通形 + に違いない；名词 + に違いない（不加「だ」）
  朝鲜语：-임에 틀림없다（韩语「-임에 틀림없다」同样表强推断；但日语名词后不加「だ」，韩语要加「임」，这是最容易出错的地方。）
- **〜に決まっている**：必然…；肯定…
  接续：普通形 + に決まっている；名词 + に決まっている
  朝鲜语：-기 마련이다（韩语「-기 마련이다」偏客观规律；日语「に決まっている」带强烈断定和反驳语气，主观得多。）
