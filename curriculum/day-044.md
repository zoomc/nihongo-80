# Day 044 · 〜ように（purpose）、〜ようになる、〜てほしい

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ように（purpose）**：为了…；以便…
  接续：动词辞书形／动词ない形 + ように
  朝鲜语：-도록（-도록 可帮助理解目的。像 忘れないように／잊지 않도록、聞こえるように／들리도록，强调让某个状态实现；有意执行的直接目标常用 ために。）
- **〜ようになる**：变得能…；开始…
  接续：动词辞书形／动词ない形 + ようになる
  朝鲜语：-게 되다（韩语 -게 되다 与 ようになる 对应度很高，但日语常用可能形+ようになる表能力变化，韩语则直接用 -게 되다。）
- **〜てほしい**：希望（别人）做…
  接续：动词て形 + ほしい；动词ない形 + でほしい
  朝鲜语：-아/어 주기를 바라다（韩语 -아/어 주기를 바라다 与 てほしい 对应，但更正式；日语 てほしい 可直接用于日常请求，语气比韩语表达更随意。）
