# Day 031 · 〜です、〜だ

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜です、〜だ」造两句自己的话，表达：是…（礼貌断定）；是…（普通断定）

## 新词 20

- **引く**（ひく）拉；查（词典）｜韩语参考：끌다（引，拉） / 당기다（拉，拖，拽）<br>
  例：カーテンがゆっくり引かれた。（窗帘被慢慢地拉上了。）
- **弾く**（ひく）弹奏（乐器）｜韩语参考：치다（弹，弹奏，打） / 타다（弹，弹奏，演奏）<br>
  例：ギターをひくのはおもしろい。（弹吉他很有意思。）
- **低い**（ひくい）低；矮｜韩语参考：낮다（低，矮，低洼） / 얕다（浅，低，矮） / 옅다（矮）<br>
  例：ラジオの音を低くして下さい。（请把收音机的声音调小。）
- **左**（ひだり）左；左边｜韩语参考：좌（左）<br>
  例：アラビア語は右から左へ書きます。（阿拉伯语是从右往左写的。）
- **一つ**（ひとつ）一个；一样｜韩语参考：하나 / 한 개<br>
  例：車にはハンドルが一つある。（汽车有一个方向盘。）
- **一月**（ひとつき）一个月｜韩语参考：한 달<br>
  例：金がなくなる頃にはもうひと月ある。（到钱花完的时候还有一个月。）
- **一人**（ひとり）一个人；独自｜韩语参考：한 사람 / 혼자<br>
  例：どうしてあなたは一人になったの？（你怎么变成一个人了？）
- **暇**（ひま）空闲；余暇｜韩语参考：짬（空，空闲） / 틈（暇，余暇） / 사이（空儿，空闲）<br>
  例：ジョンはひどく急いでいたので話をする暇もなかった。（约翰急得连说话的空都没有。）
- **百**（ひゃく）百｜韩语参考：백（百）<br>
  例：百年後にはみな同じになる。（一百年后大家都一样了。）
- **病気**（びょうき）生病；疾病｜韩语参考：우환（疾病） / 질병（疾病）<br>
  例：ボブはいったい病気なのだろうか。（鲍勃到底是不是病了？）
- **昼**（ひる）中午；白天｜韩语参考：낮（白天，白日，日间） / 점심（中午） / 점심때（中午，晌午，午饭时间）<br>
  例：昼はホットドッグを食べたんだ。（中午吃了个热狗。）
- **昼御飯**（ひるごはん）午饭｜韩语参考：점심밥<br>
  例：昼ご飯を食べに外に出ませんか。（要不要出去吃午饭？）
- **広い**（ひろい）宽；宽广｜韩语参考：넓다（宽敞，宽阔，宽广） / 크다（大，宽，广） / 너르다（宽，宽广）<br>
  例：この通りは広いが、あまり長くない。（这条街很宽，但不太长。）
- **フィルム**（フィルム）胶卷；胶片｜韩语参考：필름（胶卷）<br>
  例：カラーフィルムを一本ください。（请给我一卷彩色胶卷。）
- **封筒**（ふうとう）信封｜韩语参考：봉투（信封） / 겉봉（信封） / 편지봉투（信封）<br>
  例：だれがこの封筒を破って開けたのか。（是谁把这个信封撕开的？）
- **プール**（プール）游泳池｜韩语参考：풀（游泳场，游泳池，泳池）<br>
  例：サウナとプールがあります。（有桑拿和游泳池。）
- **フォーク**（フォーク）叉子｜韩语参考：포크（叉子，餐叉）<br>
  例：フォークでパスタを食べます。（用叉子吃意大利面。）
- **吹く**（ふく）吹；刮｜韩语参考：불다（刮，吹）<br>
  例：あの日は強い風が吹いていました。（那天刮着大风。）
- **服**（ふく）衣服｜韩语参考：옷（衣服，衣裳，服装）<br>
  例：この服はわたしにはもったいない。（这件衣服给我穿太可惜了。）
- **二つ**（ふたつ）两个｜韩语参考：두엇（两三，两个左右）<br>
  例：二つのうちでどちらが高いですか。（两个当中哪个更贵？）

## 语法

- **〜です**：是…（礼貌断定）
  接续：名词／な形容词 + です；い形容词 + です
  朝鲜语：입니다（韩语正式礼貌判断常用 입니다，例如 학생입니다、의사입니다；日常礼貌体可用 이에요／예요，形式受词尾影响。日语名词与な形容词常接です。）
- **〜だ**：是…（普通断定）
  接续：名词／な形容词 + だ
  朝鲜语：이다（韩语 이다 是普通体断定，与 だ 对应；但韩语 이다 可随收音变为 이야/야，日语 だ 形式固定，且不能接 です。）

- **代** 代替；时代；费用｜音：ダイ、タイ｜训：か.わる、かわ.る、かわ.り、か.わり、-がわ.り、-が.わり、か.える、よ、しろ
