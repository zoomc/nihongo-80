# Day 141 · 〜ぶり

- 阶段：P4｜60 分钟｜听力日
- Can-do：用「〜ぶり」造两句自己的话，表达：隔了…才；…的样子

## 新词 14

- **通り**（とおり）大街；通风｜韩语参考：거리（大街，街头，马路） / 길거리（大街，街头，马路）<br>
  例：この煙突は通りが悪くなった。（这个烟囱的排烟变差了。）
- **通り過ぎる**（とおりすぎる）走过；经过｜韩语参考：지나가다（途径，经过） / 지나치다（走过，路过） / 지나다니다（经过，路过）<br>
  例：私はその暗い道を通り過ぎた。（我走过了那条昏暗的路。）
- **都会**（とかい）城市；都市｜韩语参考：도회（城市，都市）<br>
  例：あの人達は都会の生活にあこがれている。（那些人向往城市生活。）
- **時**（とき）时候；时间｜韩语参考：날（时候） / 때（时，时候） / 시（时，时候）<br>
  例：１２才の時彼は声変わりした。（他十二岁时变了声。）
- **解く**（とく）解开；解除｜韩语参考：풀다（解开，解答） / 끄르다（解开） / 풀어내다（化解，解开）<br>
  例：彼は重責を解かれた。（他被免去了重任。）
- **毒**（どく）毒｜韩语参考：독（毒）<br>
  例：この魚は毒がない。（这种鱼没有毒。）
- **得意**（とくい）擅长；得意｜韩语参考：득의（得意）<br>
  例：あなたは数学が得意ですか。（你擅长数学吗？）
- **読書**（どくしょ）读书｜韩语参考：독서（读书）<br>
  例：母はメガネなしでは読書できない。（母亲不戴眼镜就没法看书。）
- **独身**（どくしん）单身；未婚｜韩语参考：독신（单身） / 단신（独身，单身）<br>
  例：彼は一生独身で過ごした。（他一生独身。）
- **特徴**（とくちょう）特征；特点｜韩语参考：특징（特征，特点，特色）<br>
  例：スクラムはラグビーの特徴だ。（并列争球是橄榄球的一大特色。）
- **独特**（どくとく）独特；特有｜韩语参考：독특하다<br>
  例：ナチズムはドイツ独特のものでしたか。（纳粹主义是德国特有的吗？）
- **独立**（どくりつ）独立｜韩语参考：독립（独立，自立）<br>
  例：彼女は両親から独立している。（她已不依赖父母，独立生活。）
- **解ける**（とける）解开；解出｜韩语参考：풀리다（解开，解答） / 풀어지다（破解，解开）<br>
  例：彼も私もその数学の問題が解けた。（他和我都解出了那道数学题。）
- **どこか**（どこか）某处；总觉得｜韩语参考：어딘가 / 왠지<br>
  例：どこかおかしいと一目で私にはわかりました。（我一眼就看出有些不对劲。）

## 语法

- **〜ぶり**：隔了…才；…的样子
  接续：期间名词 + ぶり；动词ます形词干 + ぶり
  朝鲜语：-만에（韩语「-만에」与「ぶりに」对应；但日语「ぶり」还能接动词词干表“…的样子」（仕事ぶり），韩语不能直译。）
