# Day 082 · 普通形 + と は 限らない、Vて + いただけませんか / もらえませんか

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「普通形 + と は 限らない、Vて + いただけませんか / もらえませんか」造两句自己的话，表达：未必…；不一定…；不见得…；能否请您…（很礼貌的请求）

## 新词 14

- **アルバム**（アルバム）相册；专辑<br>
  例：彼は私にアルバムを見せてくれた。（他给我看了相册。）
- **泡**（あわ）泡沫<br>
  例：くだける波が泡を作った。（碎浪形成了泡沫。）
- **合わせる**（あわせる）配合；合并<br>
  例：あなたの計画を私に合わせなさい。（把你的计划配合我的来。）
- **哀れ**（あわれ）可怜<br>
  例：彼女は哀れを誘う有様だった。（她的样子令人心酸。）
- **案**（あん）方案<br>
  例：どちらの案がよりよいと思いますか。（你觉得哪个方案更好。）
- **暗記**（あんき）背诵｜朝鲜语：암기<br>
  例：彼はその会話を暗記しようとした。（他试图把那段对话背下来。）
- **安定**（あんてい）稳定｜朝鲜语：안정<br>
  例：今日の政治状況はそれほど安定していない。（今天的政治局势不太稳定。）
- **あんなに**（あんなに）那么<br>
  例：あんなに怒るなんて彼らしくない。（那么生气可不像他。）
- **あんまり**（あんまり）不太<br>
  例：この手の本はあまり読まない。（这类书我不太读。）
- **胃**（い）胃｜朝鲜语：위<br>
  例：食物は胃の中で消化される。（食物在胃里消化。）
- **委員**（いいん）委员｜朝鲜语：위원<br>
  例：委員は全員出席している。（委员全都出席了。）
- **いえ**（いえ）不<br>
  例：いえ、こちらこそありがとうございます。（哪里，我才应该谢谢您。）
- **意外**（いがい）意外；出乎意料｜朝鲜语：의외<br>
  例：君にここで会うのは全く意外だ。（在这里见到你真是太意外了。）
- **行き**（いき）去程<br>
  例：私は歯医者行きを延ばさねばならない。（我不得不推迟去看牙医。）

## 语法

- **普通形 + と は 限らない**：未必…；不一定…；不见得…
  接续：動詞・い形 普通形 / 名詞・な形（＋だ 常省）+ とは 限らない；常与 必ずしも／すべて／〜からといって 呼应
  朝鲜语：-다고 해서 다 …는 것은 아니다（韩语用「다고 해서 다…는 아니다」表未必，比日语とは限らない冗长，口语常说꼭 그런 건 아니다。）
- **Vて + いただけませんか / もらえませんか**：能否请您…（很礼貌的请求）
  接续：動詞 て形 + いただく（谦让）可能形 いただけませんか；或 もらう 可能形 もらえませんか
  朝鲜语：-아/어 주시겠어요?（韩语敬语请求用주시겠어요，比주세요客气；日语いただけませんか用否定疑问，韩语用肯定疑问加시겠。）
