今日语法 3 条

韩语对应이/가 아닙니다
韩语否定用이/가 아니다，助词随收音变化；日语では可缩成じゃ，韩语无对应缩略。
N は N ではありません / じゃない
발음N 와 N 데와아리마센 / 자나이
…不是…
名詞 + は + 名詞 + ではありません（口语 じゃない）
判断句否定，礼貌体
와타시와센세이데와아리마센.
私は先生ではありません。
我不是老师。
易错点

私は先生ないです。 → 私は先生ではありません。（把「ではありません」拆成「ない＋です」，中文「不是」直译导致词类错误；「じゃありません」是合法的口语礼貌否定，不在纠错范围。）

韩语对应이었습니다 / 였습니다
韩语过去按有无收音选이었/였，且分层级；日语でした只有一形，无收音条件。
N は N でした
발음N 와 N 데시타
…（过去）是…
名詞 + は + 名詞 + でした
判断句过去式，礼貌体
키노우와니치요우비데시타.
昨日は日曜日でした。
昨天是周日。
易错点

昨日は日曜日です。 → 昨日は日曜日でした。（时间词「昨日」要求过去，中文「是」无时态变化易漏 でした）

韩语对应도
韩语 도 和日语 も 都可表示追加，常替换主格或宾格助词；叠加其他助词须按具体语境判断。
N も
발음N 모
…也…
名詞 + も（替代 は/が/を）
表同类追加；替代格助词，不与 は 叠加
와타시모가쿠세이데스.
私も学生です。
我也是学生。
易错点

私はも学生です。 → 私も学生です。（「も」本身已含「也」，要替换 は，不能 は+も 并存）
