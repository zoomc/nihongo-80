# Day 114 · 〜くせに、〜から〜にかけて

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜くせに、〜から〜にかけて」各造一句自己的话，表达：明明…却…；从…到…期间

## 新词 24

- **登山**（とざん）登山｜韩语参考：등산（登山）<br>
  例：その靴は登山には向かないよ。（那双鞋不适合登山。）
- **都市**（とし）城市；都市｜韩语参考：도시（都市，城市）<br>
  例：この都市の面積はどれくらいか。（这座城市面积有多大？）
- **年月**（としつき）岁月；年月｜韩语参考：세월 / 연월<br>
  例：あれだけのコインを収集するのにどれだけの年月がかかりましたか。（收集那么多硬币花了多少年月。）
- **図書**（としょ）图书；书籍｜韩语参考：도서（图书，读物）<br>
  例：私のところの図書は自由にお使い下さい。（我这里的书你可以随便用。）
- **年寄**（としより）老人｜韩语参考：노인<br>
  例：お年寄りをからかってはいけません。（不可以捉弄老人。）
- **閉じる**（とじる）关闭；合上｜韩语参考：닫다（关闭，关门，关张） / 덮다（合上）<br>
  例：彼は目を閉じて彼女にキスをした。（他闭着眼睛吻了她。）
- **途端**（とたん）刚一…就｜韩语参考：~하자마자<br>
  例：これをきいたとたん、彼は真っ青になった。（一听这话，他脸色刷地白了。）
- **土地**（とち）土地；地产｜韩语参考：토지（土地） / 땅（地皮，宅基地，土地）<br>
  例：彼は父親の大きな土地を相続した。（他继承了父亲的一大片土地。）
- **トップ**（トップ）首位；顶端｜韩语参考：톱（顶点，顶端，顶尖，最高，首席）<br>
  例：彼はもう少しの所でトップの部にはいるところだった。（他差点就进入最高一档。）
- **届く**（とどく）送到；够得着｜韩语参考：가다（传到，送到）<br>
  例：私あての手紙は届いていますか？（有寄给我的信吗？）
- **とにかく**（とにかく）总之；无论如何｜韩语参考：암튼（反正，总之） / 아무튼（反正，总之） / 어쨌건（不管怎样，无论如何，反正）<br>
  例：とにかく、試験が終わってほっとしたよ。（总之，考试结束，我松了口气。）
- **飛ばす**（とばす）放飞；跳过｜韩语参考：거르다（落，跳过） / 건너다（跳过，隔，空） / 날리다（使飞扬，放飞）<br>
  例：私たちはその鳥を飛ばした。（我们放那只鸟飞走了。）
- **飛び出す**（とびだす）跑出去；冲出｜韩语参考：뛰어나가다（跑出去） / 뛰쳐나가다（跑出去）<br>
  例：猫が部屋から飛び出した。（猫从房间里冲了出来。）
- **留める**（とめる）固定；留住｜韩语参考：고정하다 / 붙잡아 두다<br>
  例：木片は１本の留め木で留めてある。（木片用一根木钉固定着。）
- **友**（とも）朋友｜韩语参考：벗（朋友，友人） / 동무（朋友，伙伴） / 친구（朋友，好友， 友人，故旧）<br>
  例：まさかの時の友こそ真の友。（患难之交才是真朋友。）
- **共に**（ともに）一起；共同｜韩语参考：함께（一起，共同，与共）<br>
  例：私と共に来てくれませんか。（能跟我一起来吗？）
- **土曜**（どよう）星期六｜韩语参考：토（星期六，周六，礼拜六） / 토요일（星期六，周六，礼拜六）<br>
  例：土曜に学校がありますか。（星期六有课吗？）
- **虎**（とら）老虎｜韩语参考：호랑이（老虎）<br>
  例：万一虎がおりから出てきたらどうしますか。（万一老虎从笼子里出来怎么办？）
- **ドライブ**（ドライブ）开车游玩｜韩语参考：드라이브<br>
  例：ドライブするのはどうですか。（开车去兜风怎么样？）
- **トラック**（トラック）卡车｜韩语参考：트럭（卡车，货车）<br>
  例：トラックが荷物を運んでいます。（卡车正在运货。）
- **ドラマ**（ドラマ）电视剧；戏剧｜韩语参考：드라마（电视剧，连续剧）<br>
  例：ナポレオンの一生はすばらしいドラマだった。（拿破仑的一生是一出精彩的戏剧。）
- **トランプ**（トランプ）扑克牌｜韩语参考：카드（扑克牌） / 트럼프（扑克） / 카드놀이（纸牌，扑克）<br>
  例：トランプでごまかすのはよくないことだ。（打牌作弊是不好的。）
- **取り上げる**（とりあげる）拿起；没收｜韩语参考：들어 올리다 / 압수하다<br>
  例：彼女はガラスの花瓶を取り上げた。（她拿起了一个玻璃花瓶。）
- **努力**（どりょく）努力｜韩语参考：노력（努力，下工夫）<br>
  例：彼はその問題を解こうと努力した。（他努力想解开那道题。）

## 语法

- **〜くせに**：明明…却…
  接续：动词普通形/い形容词/ナ形容词な/名词の + くせに
  朝鲜语：-ㄴ 주제에（韩语「-ㄴ 주제에」与「くせに」一样带强烈贬义，对应度很高；但日语语气更冲，正式场合须换「のに」。）
- **〜から〜にかけて**：从…到…期间
  接续：名词 + から + 名词 + にかけて
  朝鲜语：-에서 -에 걸쳐（韩语「-에서 -에 걸쳐」与「から〜にかけて」对应，都偏书面；日语中间不能插「まで」。）
