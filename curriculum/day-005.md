- **薬**（くすり）药｜韩语参考：약（药）<br>
  例：薬を飲みます。（吃药。）
- **雨**（あめ）雨｜韩语参考：비（雨）<br>
  例：雨が降っています。（正在下雨。）
- **天気**（てんき）天气｜韩语参考：날씨（天气） / 일기（天气） / 천기（天气；气象）<br>
  例：今日はいい天気です。（今天天气好。）
- **猫**（ねこ）猫｜韩语参考：고양이（猫）<br>
  例：部屋に猫がいます。（房间里有猫。）
- **映画**（えいが）电影｜韩语参考：영화（电影）<br>
  例：映画を見ます。（看电影。）
- **音楽**（おんがく）音乐｜韩语参考：음악（音乐）<br>
  例：音楽を聞きます。（听音乐。）
- **食べる**（たべる）吃｜韩语参考：먹다（吃）<br>
  例：ご飯を食べます。（吃饭。）
- **飲む**（のむ）喝；吞（药）｜韩语参考：먹다（喝） / 마시다（喝，饮） / 들이마시다（喝）<br>
  例：水を飲みます。（喝水。）
- **行く**（いく）去｜韩语参考：가다<br>
  例：学校へ行きます。（去学校。）
- **来る**（くる）来｜韩语参考：오다（来，来到） / 나오다（来，出来）<br>
  例：友達が来ます。（朋友要来。）
- **見る**（みる）看；观看｜韩语参考：보다（看）<br>
  例：映画を見ます。（看电影。）
- **買う**（かう）买｜韩语参考：끊다（买） / 받다（买，沽） / 뽑다（买，购买）<br>
  例：本を買います。（买书。）
- **する**（する）做；干｜韩语参考：들다（做，服侍，伺侯）<br>
  例：宿題をします。（做作业。）
- **ある**（ある）有；存在（无生命）｜韩语参考：있다（사물）<br>
  例：机の上に本があります。（桌上有书。）
- **いる**（いる）有；在（有生命）｜韩语参考：있다（사람·동물）<br>
  例：部屋に猫がいます。（房间里有猫。）
- **なる**（なる）变成；成为｜韩语参考：되다（成为，变为）<br>
  例：医者になりました。（当上医生了。）
- **書く**（かく）写｜韩语参考：쓰다（写） / 적다（写）<br>
  例：名前を書いてください。（请写名字。）
- **読む**（よむ）读；念｜韩语参考：읽다（读，朗读）<br>
  例：本を読みます。（读书。）
- **話す**（はなす）说；讲｜韩语参考：말하다（说，讲） / 얘기하다（说，讲）<br>
  例：日本語を話します。（说日语。）
- **聞く**（きく）听；问｜韩语参考：듣다（听） / 묻다（问） / 질문하다（提问，问）<br>
  例：駅で道を聞きました。（我在车站问了路。）
- **起きる**（おきる）起床；起来｜韩语参考：일어나다（起，起来）<br>
  例：七時に起きます。（七点起床。）
- **借りる**（かりる）借（入）；向人借｜韩语参考：꾸다（借） / 얻다（借取，借） / 빌리다（借）<br>
  例：図書館で本を借ります。（在图书馆借书。）
- **教える**（おしえる）教；告诉｜韩语参考：이르다（告诉） / 가르치다（教，教授，传授）<br>
  例：日本語を教えます。（教日语。）
- **帰る**（かえる）回；回家｜韩语参考：돌아오다（回，回来，归来）<br>
  例：家に帰ります。（回家。）
- **休む**（やすむ）休息；请假；睡｜韩语参考：쉬다（休息，歇）<br>
  例：会社を休みます。（向公司请假。）

## 语法

- **で（动作场所／手段／材料／原因）**：在…／用…／因为…
  接续：名詞 + で
  朝鲜语：에서 / (으)로（도서관에서 공부하다 的 에서 和 자전거로 가다 的 로 在日语都用 で。存在地点换成 に：図書館に本がある。）
- **へ（移动方向）**：往／向…
  接续：名詞 + へ + 移動動詞
  朝鲜语：(으)로（東へ進む 对应 동쪽으로 가다。方向助词 へ 写法固定、这里读 e；在 行く 等动词前也可用 に，突出目的地。）
- **と（并列／共同／引用）**：和…／与…（一起）；「…」地
  接续：名詞 + と + 名詞／動詞；引用从句 + と + 思う/言う
  朝鲜语：와/과 / 하고 / (이)라고（并列可对照 와/과、하고，共同动作可对照 하고 함께。引述时韩语按句型选 -다고、-(이)라고、-냐고 等，日语引述的标记是 と。）
