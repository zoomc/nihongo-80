## 新词 25

- **大臣**（だいじん）大臣；部长｜韩语参考：장관 / 대신<br>
  例：私は大臣自身と話した。（我和大臣本人谈过了。）
- **対する**（たいする）面对；对于｜韩语参考：대하다（面对面） / 향하다（对于）<br>
  例：原子力事故に対して最大限の努力を尽くしております。（我们正为应对核事故竭尽全力。）
- **大戦**（たいせん）大战｜韩语参考：대전（大战）<br>
  例：あの家の繁栄は大戦中からのことだ。（那个家族的兴旺是从大战时期开始的。）
- **大部分**（だいぶぶん）大部分｜韩语参考：대부분（大部分，大多，大都）<br>
  例：彼女は本に収入の大部分を費やす。（她把大部分收入花在书上。）
- **タイプライター**（タイプライター）打字机｜韩语参考：타자기（打字机）<br>
  例：私のタイプライターにさわらないで。（别碰我的打字机。）
- **逮捕**（たいほ）逮捕｜韩语参考：체포（逮捕，拘捕，捉拿）<br>
  例：その男性はスパイとして逮捕された。（那名男子作为间谍被逮捕了。）
- **ダイヤ**（ダイヤ）时刻表；钻石｜韩语参考：다이아（金刚石，钻石）<br>
  例：列車はダイヤどおりに動いている。（列车正按时刻表运行。）
- **太陽**（たいよう）太阳｜韩语参考：태양（太阳，希望） / 해（太阳）<br>
  例：マリーゴールドは太陽とともに起きる。（万寿菊随太阳一同升起。）
- **平ら**（たいら）平坦｜韩语参考：평평하다<br>
  例：あの山の頂上は平らだ。（那座山的山顶是平的。）
- **大陸**（たいりく）大陆｜韩语参考：대륙（大陆）<br>
  例：アフリカは大陸であるが、グリーンランドはそうではない。（非洲是大陆，格陵兰则不是。）
- **倒す**（たおす）弄倒；推翻｜韩语参考：넘기다（弄倒） / 넘어트리다（放倒，推倒，弄倒） / 무너뜨리다（推翻，打倒）<br>
  例：シート横にあるノブを前に動かし、シートを倒します。（把座椅旁的旋钮向前扳，将椅背放倒。）
- **タオル**（タオル）毛巾｜韩语参考：수건（毛巾） / 타월（毛巾，手巾）<br>
  例：タオルは全く役に立たなかった。（毛巾一点也没派上用场。）
- **だが**（だが）但是｜韩语参考：그러나<br>
  例：あなたに手紙を書くつもりだったのだが。（我本来打算给你写信的。）
- **互い**（たがい）互相｜韩语参考：서로<br>
  例：この二人の兄弟は互いに似ている。（这两兄弟长得很像。）
- **宝**（たから）宝物｜韩语参考：보물（宝物，宝贝） / 보배（宝物，宝贝） / 보물단지（宝贝，宝物，财宝）<br>
  例：富は一生の宝、知は万代の宝。（财富是一生之宝，知识是万代之宝。）
- **宅**（たく）家；府上｜韩语参考：집 / 댁<br>
  例：ワシントン市の友人宅に泊まります。（我要住在华盛顿市的朋友家。）
- **だけど**（だけど）不过；但是｜韩语参考：하지만（可是，但是） / 그렇지마는（即便是那样，但是）<br>
  例：ねえ、元気がないみたいだけど。（喂，你好像没什么精神啊。）
- **確かめる**（たしかめる）确认；查明｜韩语参考：확인하다<br>
  例：窓が閉まっているか確かめとけ。（确认一下窗户关好了没有。）
- **多少**（たしょう）多少；稍微｜韩语参考：다소（多少） / 다과（多少，多寡） / 약간（稍微，有些）<br>
  例：今朝は空気が多少冷たい。（今天早上空气有点凉。）
- **経つ**（たつ）时间流逝｜韩语参考：흐르다（流，流淌，流逝）<br>
  例：時が経つうちに彼は心変わりした。（随着时间流逝，他变了心。）
- **達する**（たっする）达到｜韩语参考：달하다（达到） / 오르다（达到） / 이르다（达到）<br>
  例：彼らはそれで合意に達するだろう。（他们会就此达成协议吧。）
- **だって**（だって）因为；就连｜韩语参考：왜냐하면 / ~조차<br>
  例：子供にだってそんな事は分かるよ。（那种事连小孩都懂。）
- **たっぷり**（たっぷり）充足；足够｜韩语参考：듬뿍（足够地，充分地） / 넉넉히（足够地，充足地，充分地） / 충분히（充分地，充足地）<br>
  例：まだ時間はたっぷりある。（时间还很充裕。）
- **たとえ**（たとえ）纵然；假设｜韩语参考：설령 / 가령<br>
  例：たとえどんなことがあってもあきらめません。（无论发生什么，我都不会放弃。）
- **谷**（たに）山谷｜韩语参考：골짜기（山沟，山谷） / 산골짝（山谷，山沟）<br>
  例：谷は彼の呼び声でこだました。（山谷回荡着他的喊声。）

## 语法

- **〜たら〜た**：…了之后发现…
  接续：动词た形 + ら … た形
  朝鲜语：-았더니（韩语「-았더니」正好对应“做了之后发现”；但日语「たら」还兼表条件，需靠后半句的过去时和发现语气判断。）
- **〜たって / 〜だって**：即使…也…（口语）
  接续：动词た形 + って；い形容词词干 + くたって；ナ形容词/名词 + だって
  朝鲜语：-아도（韩语「-아도/어도」是标准形式，不分书面口语；日语「たって」带明显随意感，正式场合须换「ても」。）
- **〜ないことはない**：并非不…；也不是不能…
  接续：动词ない形/い形容词くない/ナ形容词でない + ことはない
  朝鲜语：-지 않은 것은 아니다（韩语「-지 않은 것은 아니다」与日语结构几乎一致；但日语常省略后半句留白，韩语一般要把话说完整。）
