## 新词 25

- **怪我**（けが）受伤｜韩语参考：부상（负伤，受伤） / 손상（损伤，受伤）<br>
  例：ラグビーをしているとき、彼はけがをした。（他打橄榄球的时候受了伤。）
- **劇**（げき）戏剧｜韩语参考：연극<br>
  例：劇はちょうど定刻に始まった。（戏正好准时开演。）
- **劇場**（げきじょう）剧场｜韩语参考：극장（剧场，戏院） / 공연장（剧场，演出场地）<br>
  例：さあ劇場に着いたぜ。（喏，到剧场了。）
- **化粧**（けしょう）化妆｜韩语参考：화장（化妆）<br>
  例：こってり化粧した顔は異様である。（浓妆艳抹的脸显得很怪异。）
- **けち**（けち）小气；寒酸｜韩语参考：좀생원（斗筲，小气鬼）<br>
  例：彼はけちで、お金を使いたがりません。（他很小气，不愿意花钱。）
- **欠陥**（けっかん）缺陷｜韩语参考：결함（缺陷，毛病）<br>
  例：このシステムには明らかな欠陥がある。（这个系统有明显的缺陷。）
- **結局**（けっきょく）结果；终究｜韩语参考：결국（终究，归根到底） / 필경（终究，最终）<br>
  例：ゆっくりと着実なのが結局勝つ。（稳扎稳打的最终会赢。）
- **決心**（けっしん）决心｜韩语参考：결심（决心，下定决心） / 결의（决心）<br>
  例：すぐ決心するようにしてください。（请尽快下定决心。）
- **欠席**（けっせき）缺席｜韩语参考：결석（缺席，缺勤）<br>

- **決定**（けってい）决定｜韩语参考：결정（决定） / 생각（想，决定）<br>

- **欠点**（けってん）缺点｜韩语参考：결점（缺点，弱点） / 흠（缺点，缺陷，瑕疵） / 단점（缺点）<br>

- **月曜**（げつよう）星期一｜韩语参考：월요일<br>
  例：国会は来週月曜に開かれる。（国会下周一召开。）
- **結論**（けつろん）结论｜韩语参考：결론（结论，结尾） / 마무리（结论，收尾，结尾）<br>
  例：二人は同じ結論に到達した。（两人得出了同样的结论。）
- **煙**（けむり）烟｜韩语参考：연기（烟，烟气）<br>
  例：エレベーターから煙の臭いがします。（电梯里有一股烟味。）
- **券**（けん）票；券｜韩语参考：표（票，券）<br>
  例：この券は２週間有効です。（这张券两周内有效。）
- **県**（けん）县｜韩语参考：현（일본의 행정구역）<br>

- **喧嘩**（けんか）吵架｜韩语参考：쌈（打仗，吵架） / 싸움질（吵架，打仗） / 쌈박질（吵架，打仗）<br>
  例：ケンとけんかしたのか。（你跟健吵架了？）
- **見解**（けんかい）见解｜韩语参考：견해（见解，看法）<br>
  例：あなたの見解は私とは正反対です。（你的看法和我的正相反。）
- **限界**（げんかい）极限；界限｜韩语参考：한계（界限，边界，局限，极限）<br>
  例：あらゆるものに限界がある。（任何事物都有极限。）

- **言語**（げんご）语言｜韩语参考：언어（语言）<br>
  例：ドイツ語はやさしい言語ではありません。（德语不是一门容易的语言。）
- **健康**（けんこう）健康｜韩语参考：건강（健康）<br>
  例：煙草をすうことは健康に悪い。（吸烟对健康有害。）
- **検査**（けんさ）检查｜韩语参考：검사（检查）<br>
  例：検査は全くおざなりなものだった。（那次检查完全是敷衍了事。）
- **現在**（げんざい）现在；目前｜韩语参考：현재（现在，目前，此时） / 지금（现在，当前，眼下）<br>
  例：私は現在の地位に満足している。（我对现在的职位很满意。）
- **現実**（げんじつ）现实｜韩语参考：현실（现实） / 생시（醒着，现实）<br>
  例：あなたの夢が現実のものとなった。（你的梦想变成了现实。）

## 语法

- **〜的**：…上的；…式的
  接续：名词 + 的（てき）；修饰名词可用 的な，也有直接连接的词组，如経済的理由
  朝鲜语：-적（韩语「-적」来自同一汉字词，用法高度相似；但韩语接「으로/인」，日语换成「に/な」，词形对应不齐。）
- **〜ような / 〜ように（like）**：像…一样；如同…
  接续：名词 + の + ような/ように；普通形 + ような/ように
  朝鲜语：-같은（韩语「-같은」修饰名词、「-같이」修饰动词，分工与日语相似；但日语名词前必须加「の」，韩语不加。）
