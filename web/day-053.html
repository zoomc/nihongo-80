今日语法 3 条

V辞書形 / Vない形 + ことが ある
有时会…／有时不…（泛指倾向）
動詞 辞書形／ない形 + ことが ある；ある 可变形（ことがあります／あった）
表示偶尔发生、有时会那样；与 〜たことがある（G0042，曾经做过）时态语义都不同
이소가시쿠테,히루고한오와스레루코토가아리마스.
忙しくて、昼ご飯を忘れることがあります。
忙起来有时会忘了吃午饭。
카레와타마니치코쿠스루코토가아리마스.
彼はたまに遅刻することがあります。
他偶尔会迟到。
朝鲜语：-곤 하다 / -기도 하다
韩语곤 하다表过去反复习惯，기도 하다表有时；日语ことがある现在形表偶尔，时态限制不同。
易错点

北海道へ行くことがあるです。 → 北海道へ行くことがあります。（「ことがある」结句接礼貌体应为「ことがあります」，「あるです」不合法；另「〜たことがある」表曾经做过（见 compare G0042），与表「有时会」的辞书形「〜ことがある」语义不同。）

V意志形 + と 思う / と する
打算…／正要…、试图…
動詞 意志形（五段 お段+う／一段 よう／する→しよう／来る→こよう）+ と 思う／と する
(よ)うと思う 表说话人打算（现在/将来）；(よ)うとする 表正要开始做或尝试做
니치요우비와에이가오미요우토오모떼이마스.
日曜日は映画を見ようと思っています。
周日打算看电影。
데카케요우토시타라,아메가후떼키마시타.
出かけようとしたら、雨が降ってきました。
正要出门时下起雨来了。
朝鲜语：-(으)ㄹ 생각이다 / -(으)려고 하다
韩语打算用ㄹ 생각이다，正要或试图用려고 하다；日语と思う还含推测，韩语更明确表意志。
易错点

映画を見ると思います。 → 映画を見ようと思います。（「打算看」须用意志形 見よう；用辞书形 見る 变成「觉得会看」，中文「想看」直译错）

N / Vた形 / V辞書形 / Vて + ばかり
刚…；净是…、只…；一味…
名詞 + ばかり；動詞 た形 + ばかり（刚做完）；辞書形 + ばかり（只等/只剩）；て形 + ばかり いる（光顾着做）
多义：①刚…②净/只③一味做；数量或程度超出预期，常带负面语感
니뽄니키타바카리데스.
日本に来たばかりです。
刚来日本不久。
카레와게이무바카리시테이마스.
彼はゲームばかりしています。
他光打游戏。
코노미세와네담바카리타카쿠테,아지와후쓰우데스.
この店は値段ばかり高くて、味は普通です。
这家店光价格贵，味道一般。
朝鲜语：방금 / -만 / -기만 하다
韩语「刚」用방금、「只」用만、「一味」用기만 하다，三义分用；日语ばかり一形靠语境。
易错点

日本に来るばかりです。 → 日本に来たばかりです。（「刚来」用 た形 来たばかり，不能用辞书形；中文「刚」直译不体现 た 易错）
