# Day 020 · 〜に（time）、〜に（destination）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「〜に（time）、〜に（destination）」造两句自己的话，表达：在…（某时点）；去／来／回…（目的地）

## 新词 19

- **四**（し）四｜韩语参考：사 / 넷<br>
  例：列車でならここからたった四分だ。（坐电车的话，从这里只要四分钟。）
- **塩**（しお）盐｜韩语参考：소금（盐，咸盐）<br>
  例：このスープは塩が少し足りない。（这汤盐放得有点少。）
- **辞書**（じしょ）词典｜韩语参考：사전（辞典，词典）<br>
  例：それはどの辞書にもでています。（那在任何词典里都有。）
- **下**（した）下面｜韩语参考：밑（下面，小） / 아래（下，下面）<br>
  例：クッキーはテーブルの下にいる。（饼干在桌子底下。）
- **七**（しち）七｜韩语参考：칠 / 일곱<br>
  例：どういっても七時までにいかないと。（不管怎样，七点前都得过去。）
- **質問**（しつもん）提问；问题｜韩语参考：질문（提问）<br>
  例：あの先生に質問してもいいですよ。（可以向那位老师提问。）
- **自動車**（じどうしゃ）汽车｜韩语参考：자동차（汽车）<br>
  例：自動車にひかれたのではないですか。（他是不是被车撞了？）
- **死ぬ**（しぬ）死｜韩语参考：죽다（死）<br>
  例：その少年は死んだものとしてあきらめられた。（人们认定那个少年已死，放弃了寻找。）
- **字引**（じびき）词典｜韩语参考：사전（辞典，词典）<br>
  例：ジョンソンさんはまるで生き字引です。（约翰逊先生简直是一部活词典。）
- **自分**（じぶん）自己｜韩语参考：저（自己） / 자기（自己） / 자신（自身，自己）<br>
  例：自分でそれをしなければならない。（那件事得自己做。）
- **閉まる**（しまる）关闭｜韩语参考：닫히다<br>
  例：あいにく店は閉まっていた。（不巧店已经关门了。）
- **締める**（しめる）系紧；勒紧｜韩语参考：죄다（勒紧，拧紧，弄紧，扣紧） / 조르다（捆紧，勒紧） / 조이다（勒紧，拧紧，弄紧，扣紧）<br>
  例：いつもシートベルトを締めなさい。（要始终系好安全带。）
- **閉める**（しめる）关上｜韩语参考：닫다<br>
  例：どうかドアを閉めてくれませんか。（能不能请你把门关上？）
- **じゃ**（じゃ）那么｜韩语参考：그럼<br>
  例：じゃあ、キーをもらえますか。（那么，能把钥匙给我吗？）
- **写真**（しゃしん）照片｜韩语参考：사진（照片，相片）<br>
  例：なんてキレイな写真なんでしょう。（多漂亮的照片啊。）
- **シャツ**（シャツ）衬衫｜韩语参考：남방（花衬衫） / 셔츠（衬衫）<br>
  例：シャツにアイロンをかけてください。（请把衬衫熨一下。）
- **シャワー**（シャワー）淋浴｜韩语参考：샤워（淋浴） / 샤워기（淋浴器）<br>
  例：シャワーの水が出ません。（淋浴不出水。）
- **授業**（じゅぎょう）课；上课｜韩语参考：수업<br>
  例：それは授業の終わりだった。（那是课结束的时候。）
- **しょうゆ**（しょうゆ）酱油｜韩语参考：간장<br>
  例：同社は醤油その他の食品を生産する。（该公司生产酱油等食品。）

## 语法

- **〜に（time）**：在…（某时点）
  接续：名词（时间）+ に
  朝鲜语：에（시간）（韩语时点可用 에，日语具体时点常用 に；两种语言的相对时间词是否加助词都需看实际用法，不可机械对应。）
- **〜に（destination）**：去／来／回…（目的地）
  接续：名词（场所）+ に + 行く／来る／帰る
  朝鲜语：에（도착점）（韩语 에 与 に 对应；但韩语 가다 的目的地也可用 로，日语 へ 与之相近，に 更强调到达。）
