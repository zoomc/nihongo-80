今日语法 3 条

韩语对应-기로 되어 있다
韩语「-기로 되어 있다」同样表既定安排；但日语还能暗示“规定如此、实际未必”，带距离感，韩语较少这层含义。
〜ことになっている
발음〜코토니나떼이루
规定…；按理…
动词辞书形/ない形 + ことになっている
陈述集体规定、既定安排或社会惯例，不由个人意志决定。
この寮では、夜十一時までに戻ることになっている。
这栋宿舍规定晚上十一点前必须回来。
라이게쓰카라오오사카노시샤데하타라쿠코토니나떼이마스.
来月から大阪の支社で働くことになっています。
安排我从下个月起去大阪分公司工作。
토쇼칸노나카데와,노미모노오논데와이케나이코토니나떼이루.
図書館の中では、飲み物を飲んではいけないことになっている。
图书馆规定里面不能喝饮料。
易错点

この寮では、夜十一時までに戻ることになっているです。 → 戻ることになっています（「ことになっている」是普通体，礼貌说法是「ことになっています」。）

韩语对应-할 것
韩语规章也用「-할 것」，与日语「こと」结句几乎一致；但禁止句韩语用「-하지 말 것」，日语用「ないこと」。
〜こと（instruction）
발음〜코토
必须…；不得…
动词辞书形/ない形 + こと（用于告示、规章结句）
用于书面规章、通知，条列必须做或禁止做的事。
레포오토와,라이슈우노킨요우비마데니테이슈쓰스루코토.
レポートは、来週の金曜日までに提出すること。
报告须在下周五前提交。
토쇼칸노혼니,센오히카나이코토.
図書館の本に、線を引かないこと。
不得在图书馆的书上画线。
시켄추우와,스마호노덴겐오키떼오쿠코토.
試験中は、スマホの電源を切っておくこと。
考试期间须关闭手机电源。
易错点

レポートは、来週の金曜日までに提出しますこと。 → 提出すること。（「こと」结句要求动词辞书形在前，不能嵌入「ます」。）

韩语对应-라고 말하다
韩语引用用「-라고」，需按词类换「-으라고/-라고」；日语统一用「ように」，不随词类变化，容易漏掉「に」。
〜ように言う / 〜ように頼む
발음〜요우니이우 / 〜요우니타노무
让…做；转告…
动词辞书形/ない形 + ように言う／ように頼む／ように伝える
转述委托、命令或指示的内容，常用于间接引语。
이샤니,오사케오노미스기나이요우니이와레타.
医者に、お酒を飲みすぎないように言われた。
医生嘱咐我别喝太多酒。
토나리노헤야노히토니,요루와온가쿠노오토오치이사쿠스루요우니타노다.
隣の部屋の人に、夜は音楽の音を小さくするように頼んだ。
我请隔壁房间的人晚上把音乐关小。
山下さんに、明日の会議に遅れないように伝えてください。
请转告山下先生明天开会不要迟到。
易错点

医者に、お酒を飲みすぎませんように言われた。 → 飲みすぎないように言われた（转述请求或指示用「〜ないように」；「〜ませんように」是祈愿，不能作引用内容。）
