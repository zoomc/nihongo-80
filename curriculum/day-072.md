# Day 072 · 〜ほど、〜くらい / 〜ぐらい（extent）、〜さえ

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜ほど**：到了…的程度
  接续：普通形 + ほど；名词 + ほど
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」与「ほど」基本对应；但日语「ほど」还用于「〜ほど〜ない」比较句，韩语要用「-만큼」。）
- **〜くらい / 〜ぐらい（extent）**：到…地步；至少…
  接续：普通形 + くらい／ぐらい；名词 + くらい
  朝鲜语：-(으)ㄹ 정도로（울 것 같을 정도로 무서웠다 对照 泣きそうなくらい怖かった。数字后的 くらい 表大约，语气里表示程度的 くらい 常跟 ほど 接近。）
- **〜さえ**：连…都…
  接续：名词 + さえ／でさえ／にさえ
  朝鲜语：-조차（-조차 对照「连…都」，如 이름조차 잊었다／名前さえ忘れた。后面是 ば 时，さえ 又可限定最低条件。）
