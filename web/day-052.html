Day 052 · N + に 対して / に 関して、N / V辞書形 + に 伴って / に つれて / に 従って、N + に 基づいて / を もとに / どおり(に)

语法 3 条

N + に 対して / に 関して
발음〜니타이시테 / 〜니칸시테
对…（针对对象/对比）／关于…（书面）
名詞 + に対して（动作/态度的对象，或「与此相对」的对比）；名詞 + に関して（＝について 的书面语）
に対して 后接对人/物的动作、态度或对比；に関して 多用于正式文书、新闻
韩语对应-에 대해 / -에 관해
制度について／制度に関して 对照 제도에 관해，针对人的态度 客に対して丁寧に 对照 손님을 대할 때 정중하게。对比从句用 のに対して，可对应 반면에。
先生に対して失礼なことを言いました。
对老师说了失礼的话。
この問題に関して、後ほど報告します。
关于这个问题稍后汇报。
易错易混点
  • ✗ 先生に対してに失礼しました。✓ 先生に対して失礼しました。に対して 已经含 に，不用再加。
  • ✗ 環境問題について対して議論します。✓ 環境問題に関して議論します。について 和 に関して 选一个就够；再叠 に対して 意思会乱。
N / V辞書形 + に 伴って / に つれて / に 従って
발음〜니토모나떼
随着…（前项变化，后项也跟着变化）
过程 + につれて／に伴って／に従って 常接随之发生的变化；名词 + に従って 也可表示遵循指示、规则。
书面，表伴随变化；につれて/に従って 偏比例变化，に伴って 偏伴随发生（常带同时性）
韩语对应-에 따라 / -(으)면서
韩语伴随变化用에 따라或면서，比例变化多用ㄹ수록；日语三形语感细分更多。
키온 가 아가루 니쓰레테, 우리아게 가 후에마스.
気温が上がるにつれて、売上が増えます。
随着气温升高，销量增加。
技術の進歩に伴って、仕事のやり方が変わりました。
随着技术进步，工作方式变了。
易错易混点
  • ✗ 気温が上がるにつれて、ビールがおいしいです。✓ 気温が上がるにつれて、ビールが売れるようになります。につれて 后面的动词也要跟着变（売れる、高くなる），不能是静态的 おいしい。
  • ✗ 気温の上がるにつれて✓ 気温が上がるにつれて、…につれて 直接接辞书形，中间不加 の。
N + に 基づいて / を もとに / どおり(に)
발음〜니쿠즈이테
基于…／以…为依据／按照…
名詞 + に基づいて（依据资料/规则/数据）；名詞 + をもとに（以…为素材/基础）；名詞 + どおり(に)（照原样、按预定）
书面；に基づいて 偏「依据权威来源」，をもとに 偏「以…为材料加工」，どおり 偏「不改动地照做」
韩语对应-에 근거해 / -을 바탕으로 / -대로
韩语에 근거해表依据、을 바탕으로表以…为基础、대로表按照，与日语三形基本对应。
調査結果に基づいて、報告書を作成しました。
依据调查结果写成了报告。
요테이도오리 니, 카이기 오 하지메마스.
予定どおりに、会議を始めます。
按预定开始会议。
易错易混点
  • ✗ 資料に基づいてに書きました。✓ 資料に基づいて書きました。に基づいて 已经含 に，不用再加。
  • ✗ アンケート結果をに基づいて改善します。✓ アンケート結果に基づいて改善します。に基づいて 前面用 に（結果に基づいて）；を 是 もとに 的搭配。
