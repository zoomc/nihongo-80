# Day 043 · 〜て（reason）、〜し、〜けど / 〜けれども、〜ために

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜て（reason）**：因为…（造成某种状态）
  接续：动词て形／い形容词去い+くて／な形容词・名词+で
  朝鲜语：-아서/어서（韩语 -아서/어서 与 て 的原因用法对应，但日语 て 形还可表并列、先后，功能更多；韩语需靠上下文或另加连接词。）
- **〜し**：既…又…；而且…
  接续：动词普通形／い形容词 + し；な形容词・名词 + だ + し
  朝鲜语：-고（韩语 -고 可并列理由，但语气中性；日语 し 暗示「还有别的理由」，主观色彩更强，韩语常需加 -기도 하고 才接近。）
- **〜けど / 〜けれども**：但是…；虽然…
  接续：句子普通形 + けど／けれども（礼貌体可直接接）
  朝鲜语：-지만（가고 싶지만 시간이 없어요 对照 行きたいけど時間がないです。句末 けど 常用于委婉表达或等对方接话，韩语常用 -는데요。）
- **〜ために**：为了…；因为…
  接续：动词辞书形／动词た形 + ために；名词 + の + ために
  朝鲜语：-기 위해(서) / 때문에（韩语 -기 위해(서) 表目的，때문에 表原因，两者形式不同；日语 ために 一个形式兼表目的与原因，需靠前接成分判断。）
