今日语法 3 条

〜ごとに
발음〜고토니
每…；每隔…
名词 + ごとに；动词辞书形 + ごとに
表示以某单位等间隔重复，或“每一个都各自不同”。
韩语对应-마다
韩语「-마다」兼表“每”和“每隔”；日语要区分「ごとに」（每）与「おきに」（每隔）。
코노바스와주우고훈고토니데테이마스.
このバスは十五分ごとに出ています。
这趟公交每十五分钟一班。
키세쓰고토니,미세노카자리가카와루.
季節ごとに、店の飾りが変わる。
每个季节店里的装饰都会变。
一回使うごとにポイントがたまるカードです。
这是每用一次就积分的卡。

易错点 このバスは十五分おきごとに出ています。 → 十五分ごとに（「おき」与「ごと」都表间隔，不能叠加，二者择一。）

〜最中に
발음〜사이추우니
正当…的时候
动词ている + 最中に；名词 + の + 最中に
表示某动作正值高潮时另一事突然发生，多含妨碍意味。
韩语对应-는 중에
韩语「-는 중에」只表“进行中”；日语「最中に」还隐含“被打断、扫兴”的语感。
大事な会議の最中に、携帯電話が鳴ってしまった。
正开重要会议时，手机响了。
료우리오시테이루사이추우니,테이덴니나따.
料理をしている最中に、停電になった。
正做饭时停电了。
이마,시켄노사이추우다카라,로우카데와시즈카니시테쿠다사이.
今、試験の最中だから、廊下では静かにしてください。
现在正在考试，请在走廊保持安静。

易错点 大事な会議最中に、携帯電話が鳴ってしまった。 → 会議の最中に（「最中」是名词，接名词要加「の」，说「会議の最中に」。）

〜ついでに
발음〜쓰이데니
顺便…
动词辞书形/た形 + ついでに；名词 + の + ついでに
表示利用做某事的机会，顺便再做另一件事。
韩语对应-는 김에
韩语「-는 김에」同样表“顺便”，与「ついでに」对应；但日语可接名词+の，韩语只接动词。
유우빈쿄쿠에이쿠쓰이데니,코노테가미모다시테키테쿠레루?
郵便局へ行くついでに、この手紙も出してきてくれる？
你去邮局的话，顺便帮我把这封信寄了好吗？
쿄우토에슈쪼우시타쓰이데니,무카시노토모다치니아떼키타.
京都へ出張したついでに、昔の友達に会ってきた。
去京都出差时，顺便见了老朋友。
카이모노노쓰이데니,토쇼칸니혼오카에시타.
買い物のついでに、図書館に本を返した。
买东西时顺便把书还给了图书馆。

易错点 京都へ出張するのついでに、昔の友達に会ってきた。 → 出張したついでに（动词直接接「ついでに」，只有名词才加「の」。）
