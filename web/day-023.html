③ 语法 6 分钟

〜で（place of action）
名词（场所）+ で
在…（做某事）

表示动作发生的场所，与存在场所的 に 相对。

図書館で本を読みます。
我在图书馆看书。
きのう、デパートでくつを買いました。
昨天在百货商店买了鞋。
駅の前で友達を待ちました。
我在车站前等朋友。
朝鲜语：에서（동작 장소）
韩语 에서 与 で 对应，에 表存在；日语 で 与 に 的分工和韩语 에서 与 에 基本一致，较易迁移。

易错：図書館に本を読みます。 → 図書館で本を読みます。（动作发生场所用 で，に 表存在或到达）

〜で（means）
名词（工具／手段／语言／材料）+ で
用…；靠…；以…

表示手段、工具、交通方式、语言或材料。

毎日電車で会社へ行きます。
每天坐电车去公司。
はしでご飯を食べます。
用筷子吃饭。
日本語で手紙を書きました。
我用日语写了信。
朝鲜语：로/으로（수단）
韩语 로/으로 表手段，与 で 对应；但日语 で 还表语言和材料，韩语语言用 로，材料常用 로 或 으로，范围相近。

易错：毎日電車に会社へ行きます。 → 毎日電車で会社へ行きます。（交通手段用 で，に 表到达点）
