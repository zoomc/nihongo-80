# v5 总览：150 天 N3 学习系统

> 状态：v5.1 已实现部分流程；验收与未完成项见 reports/v5_review_codex.md。
> 上游：v4 已有 SQLite 状态、FSRS、静态页、CLI。v5 是**减法 + 重构**，不是推倒重来。

## 1. 定位

**网页是资源包，不是学校。会话是老师，不是复读机。**

学习者：彦祖，朝鲜族，朝鲜语母语，假名有底子但不熟，目标 150 天达到 N3 覆盖 + 真题 55–65%。

三条不可妥协：

1. 每天 **60 分钟**（网页 42 + 会话 18），听力包含在网页 42 分钟内。
2. 网页只放**当天要学的东西**，不放统计、图表、系统术语。
3. 所有状态落盘，任何 agent 都能接手，不靠聊天记忆。

## 2. 三层架构

```
教学层  主会话（周规划/诊断/调难度）  ──┐
        每日会话（发链接/答疑/考核/日报） ├─ 只通过文件交换
资源层  静态页 day-NNN.html（5 块）     │
数据层  SQLite state.db + seeds/        ┘
```

**没有父子会话 API**。WorkBuddy 会话之间不共享上下文、没有消息回传，所以用**文件协议 + CLI** 做编排，见 `02_SESSION_PROTOCOL.md`。这套协议对 Claude Code、Codex、Cursor 同样成立，因为它们都能读文件、跑命令。

## 3. 与 v4 的差异

| 项 | v4 | v5 |
|---|---|---|
| 周期 | 80 天 | 150 天 |
| 每天 | 60 分钟网页 | 60 分钟（网页 42 + 会话 18） |
| 网页 | 仪表盘（热力图/雷达/诊断/回传码面板） | 5 块学习内容 |
| 词汇 | 340 | 约 2,700（新增 2,360） |
| 语法 | 96 | 276（新增 180） |
| 听力 | 每天自建 TTS | Day 47 起每周 3 次原创 TTS（三题），尚无真人音频 |
| 会话 | 用户手动粘 briefing | 文件协议 + 任务卡 + 日报 |
| 记录 | state.db + 会话记忆 | state.db + `STATE.md` + `days/day-NNN/` |

## 4. 原则（写给未来的 agent）

1. **DB 权威数值，MD 权威意图**。正确率、到期卡看 `state.db`；今天要干什么看 `STATE.md`。
2. **只读的东西不写**。`STATE.md`、`brief.md` 由脚本生成，人和 agent 只读；要改计划，改 `plan/` 并跑 CLI。
3. **不编造进度**。没做的题不写 attempts；没听懂的词不标掌握。
4. **答对不等于学会**。只有 `targets` 命中的能力卡才推进，`context` 只出现在题面。
5. **每天可放弃**。没完成就记 incomplete，不补假数据；主会话按真实进度重排。
