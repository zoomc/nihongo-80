今日语法 3 条

〜最中に
动词ている + 最中に；名词 + の + 最中に
〜最中に
正当…的时候
表示某动作正值高潮时另一事突然发生，多含妨碍意味。
大事な会議の最中に、携帯電話が鳴ってしまった。
正开重要会议时，手机响了。
料理をしている最中に、停電になった。
正做饭时停电了。
今、試験の最中だから、廊下では静かにしてください。
现在正在考试，请在走廊保持安静。
朝鲜语：-는 중에
韩语「-는 중에」只表“进行中”；日语「最中に」还隐含“被打断、扫兴”的语感。
易错点

大事な会議最中に、携帯電話が鳴ってしまった。 → 会議の最中に（「最中」是名词，接名词要加「の」，说「会議の最中に」。）

〜ついでに
动词辞书形/た形 + ついでに；名词 + の + ついでに
〜ついでに
顺便…
表示利用做某事的机会，顺便再做另一件事。
郵便局へ行くついでに、この手紙も出してきてくれる？
你去邮局的话，顺便帮我把这封信寄了好吗？
京都へ出張したついでに、昔の友達に会ってきた。
去京都出差时，顺便见了老朋友。
買い物のついでに、図書館に本を返した。
买东西时顺便把书还给了图书馆。
朝鲜语：-는 김에
韩语「-는 김에」同样表“顺便”，与「ついでに」对应；但日语可接名词+の，韩语只接动词。
易错点

京都へ出張するのついでに、昔の友達に会ってきた。 → 出張したついでに（动词直接接「ついでに」，只有名词才加「の」。）

〜おかげで
动词普通形/い形容词/ナ形容词な/名词の + おかげで
〜おかげで
多亏…；托…的福
表示因某原因得到好结果，含感谢语气。
先輩が手伝ってくれたおかげで、仕事が早く終わった。
多亏前辈帮忙，工作很快就做完了。
薬が効いたおかげで、熱が下がった。
多亏药效，烧退了。
駅が近いおかげで、雨の日も楽に通勤できる。
幸好离车站近，下雨天通勤也轻松。
朝鲜语：-덕분에
韩语「-덕분에」与「おかげで」对应；但日语还能用于讽刺（「おかげで遅れた」），韩语同样可以，需靠上下文判断。
易错点

駅が近いのおかげで、雨の日も楽に通勤できる。 → 駅が近いおかげで（い形容词直接接「おかげで」，只有名词才加「の」。）
