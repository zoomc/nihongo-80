Day 041 · 〜ば、〜たら、〜なら、〜と（conditional）

语法 4 条

〜ば
발음〜바
如果…
五段词尾改え段 + ば；一段去 る + れば；い形容词去 い + ければ；な形容词／名词用 なら 或 であれば。
表示假定条件，后项多为自然结果、建议或请求。
韩语对应-(으)면
싸면 사겠다 对照 安ければ買う。形容词状态作条件时，后项完全可以是意志；若是同一人先完成动作再接受指令，常用 着いたら電話して。
この道をまっすぐ行けば、駅に着きます。
沿着这条路一直走，就会到车站。
야스케레바, 카이타이데스.
安ければ、買いたいです。
如果便宜的话，我想买。
와카라나이코토 가 아레바, 이쓰 데모 키이테쿠다사이.
分からないことがあれば、いつでも聞いてください。
有不懂的地方，请随时问我。
易错易混点
  • ✗ 安いければ、買いたいです。✓ 安ければ、買いたいです。い形容词说“如果…”是去掉 い 加 ければ：安ければ。
〜たら
발음〜타라
如果…；…之后
动词た形 + ら；い形容词去い+かったら；な形容词・名词+だったら
表示假定条件，或前项完成后发生后项，口语中最常用。
韩语对应-(으)면 / -았/었더니
韩语 -(으)면 表条件，-았/었더니 表前项完成后的发现；日语 たら 一个形式兼表两者，使用范围更广。
에키 니 쓰이타라, 덴와시테쿠다사이.
駅に着いたら、電話してください。
到了车站，请给我打电话。
もし明日雨だったら、家で映画を見よう。
如果明天下雨，我们就在家看电影吧。
아쓰카따라, 마도 오 아케테 모 이이데스 요.
暑かったら、窓を開けてもいいですよ。
如果热的话，可以打开窗户。
易错易混点
  • ✗ もし明日雨たら、家で映画を見よう。✓ もし明日雨だったら、家で映画を見よう。名词和な形容词要用「だったら」，不能直接接 たら
〜なら
발음〜나라
如果是…的话
动词普通形／い形容词／な形容词／名词 + なら
承接对方已知或提到的话题，就此事给出判断、建议或条件。
韩语对应-(이)라면 / -다면
韩语 -(이)라면 与名词搭配，-다면 与动词、形容词搭配；日语 なら 前接形式不随词性变化，接续更简单。
쿄우토 에 이쿠나라, 아키 가 이이데스 요.
京都へ行くなら、秋がいいですよ。
如果你要去京都，秋天最合适。
파소콘 노 코토나라, 아니 니 키쿠토이이 요.
パソコンのことなら、兄に聞くといいよ。
电脑方面的事，问我哥哥就好。
손나니네무이나라, 쿄우 와 하야쿠네타라?
そんなに眠いなら、今日は早く寝たら？
那么困的话，今天早点睡怎么样？
易错易混点
  • ✗ 京都へ行くなれば、秋がいいですよ。✓ 京都へ行くなら、秋がいいですよ。なら 前接普通形，动词不用「なれば」
〜と（conditional）
발음〜토
一…就…；如果…就…
动词辞书形／ない形／い形容词 + と；な形容词・名词 + だ + と
表示反复出现的自然结果、必然条件或机械性反应，后项不能是意志、请求。
韩语对应-(으)면
버튼을 누르면 불이 켜진다 对照 ボタンを押すと電気がつく。と 适合规律、自动反应和叙事中的发现；若后句要对听者发请求，通常换成 たら。
코노보탄 오 오스토, 오차 가 데마스.
このボタンを押すと、お茶が出ます。
按下这个按钮，茶就会出来。
하루 니 나루토, 사쿠라 가 사키마스.
春になると、桜が咲きます。
一到春天，樱花就开了。
코노미치 오 미기 니 마가루토, 히다리 니 유우빈쿄쿠 가 아리마스.
この道を右に曲がると、左に郵便局があります。
沿这条路向右转，左边有一家邮局。
易错易混点
  • ✗ ボタンを押すと、係員を呼んでください。✓ ボタンを押したら、係員を呼んでください。请对方做某个动作时用 たら；と 多用于装置自动反应，如 押すと明かりがつく。
