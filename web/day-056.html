今日语法 3 条

〜し
발음〜시
既…又…；而且…
动词普通形／い形容词 + し；な形容词・名词 + だ + し
列举两个以上理由或特征，暗示还有其他，后项多为综合判断。
코노헤야와히로이시,에키카라치카이시,토테모키니이떼이마스.
この部屋は広いし、駅から近いし、とても気に入っています。
这个房间又宽敞，离车站又近，我很喜欢。
쿄우와아메다시,쓰카레테이루시,도코니모이키타쿠나이.
今日は雨だし、疲れているし、どこにも行きたくない。
今天又下雨，人又累，哪儿都不想去。
모우오소이시,소로소로카에로우카.
もう遅いし、そろそろ帰ろうか。
时间也不早了，我们差不多回去吧。
朝鲜语：-고
韩语 -고 可并列理由，但语气中性；日语 し 暗示「还有别的理由」，主观色彩更强，韩语常需加 -기도 하고 才接近。
易错点

この部屋は広いだし、駅から近いだし、とても気に入っています。 → この部屋は広いし、駅から近いし、とても気に入っています。（い形容词直接接 し，不加 だ）

〜けど / 〜けれども
발음〜케도 / 〜케레도모
但是…；虽然…
句子普通形 + けど／けれども（礼貌体可直接接）
表示转折，或用来缓和语气、引出请求与铺垫。
코노미세와타카이케도,오이시이.
この店は高いけど、おいしい。
这家店贵，但很好吃。
스미마센,에키니이키타인데스케도,도우이케바이이데스카.
すみません、駅に行きたいんですけど、どう行けばいいですか。
不好意思，我想去车站，请问怎么走？
何度も電話したけれども、誰も出なかった。
我打了好几次电话，但没人接。
朝鲜语：-지만
韩语 -지만 与 けど 对应，但日语 けど 还可放在句末缓和语气、引出下文；韩语 -지만 一般不能这样独立使用。
易错点

この店は高いだけど、おいしい。 → この店は高いけど、おいしい。（い形容词接 けど 不加 だ）

〜ために
발음〜타메니
为了…；因为…
动词辞书形／动词た形 + ために；名词 + の + ために
前接意志动词表目的，前接名词或过去形表原因，后者较书面。
日本の大学に入るために、毎日勉強しています。
为了考进日本的大学，我每天学习。
家族のために、一生懸命働いている。
我为了家人拼命工作。
오오유키노타메니,덴샤가토마리마시타.
大雪のために、電車が止まりました。
因为大雪，电车停运了。
朝鲜语：-기 위해(서) / 때문에
韩语 -기 위해(서) 表目的，때문에 表原因，两者形式不同；日语 ために 一个形式兼表目的与原因，需靠前接成分判断。
易错点

大雪のためで、電車が止まりました。 → 大雪のために、電車が止まりました。（名词接 ために 用「の」，不是「で」）
