## 新词 25

- **全て**（すべて）全部｜韩语参考：다（全部，最好） / 전부（全部）<br>
  例：人間は全て平等である。（所有人都是平等的。）
- **済ませる**（すませる）做完；办完｜韩语参考：끝내다 / 마치다<br>
  例：私はまだ朝食を済ませていません。（我还没吃完早饭。）
- **鋭い**（するどい）尖锐；敏锐｜韩语参考：거칠다（尖锐） / 날카롭다（尖锐，敏锐） / 뾰족하다（尖，尖锐）<br>
  例：ここに鋭い痛みがあります。（这里有一阵刺痛。）
- **せい**（せい）缘故；因为｜韩语参考：탓 / 때문<br>
  例：あなたの頭痛は過労のせいだ。（你的头痛是过劳造成的。）
- **性**（せい）性；性质｜韩语参考：성（性）<br>
  例：習い性となる。（习惯成自然。）
- **正**（せい）正；正确｜韩语参考：정（正） / 정-（正）<br>
  例：彼の言ったことは全て正しかった。（他说的一切都是对的。）
- **請求**（せいきゅう）索要；请求｜韩语参考：청구 / 요청<br>
  例：われわれは彼の借金の支払いを請求した。（我们要求他偿还借款。）
- **税金**（ぜいきん）税金｜韩语参考：세금<br>
  例：新しい税金がワインにかせられた。（葡萄酒被征收了新税。）
- **清潔**（せいけつ）清洁；干净｜韩语参考：청결（清洁，洁净）<br>
  例：彼女はいつも髪を清潔にしている。（她总是把头发保持得很干净。）
- **制限**（せいげん）限制｜韩语参考：제한（限制，限定）<br>
  例：彼女はやせるために食事を制限した。（她为了减肥限制了饮食。）
- **成功**（せいこう）成功｜韩语参考：성공（成功）<br>
  例：成功。おめでとうございます。（成功了。恭喜您。）
- **正式**（せいしき）正式｜韩语参考：정식（正式）<br>
  例：彼は息子を正式の相続人と認めた。（他承认儿子为正式的继承人。）
- **精神**（せいしん）精神｜韩语参考：정신（精神） / 정신머리（精神，脑子）<br>
  例：精神は肉体とともに発達させるべきである。（精神应当与肉体一同发展。）
- **成人**（せいじん）成年人｜韩语参考：성인（成人，成年人） / 어른（成年人，大人）<br>
  例：その映画は成人しかみられない。（那部电影只有成年人才能看。）
- **精々**（せいぜい）充其量；尽量｜韩语参考：기껏해야 / 힘껏<br>
  例：狭い部屋をせいぜい広く使った。（尽量把狭小的房间用得更宽敞些。）
- **成績**（せいせき）成绩｜韩语参考：성적（成绩）<br>
  例：学校の成績は普通でしたよ。（学校的成绩很一般。）
- **製造**（せいぞう）制造｜韩语参考：제조（制造）<br>
  例：その時計はスイスで製造されている。（那块表在瑞士制造。）
- **贅沢**（ぜいたく）奢侈；奢华｜韩语参考：사치（奢侈）<br>
  例：彼女はぜいたくに暮らしている。（她过着奢侈的生活。）
- **成長**（せいちょう）成长｜韩语参考：성장（生长，成长）<br>
  例：彼女は成長して美しい婦人になった。（她长大后成了美丽的妇人。）
- **制度**（せいど）制度｜韩语参考：제도（制度）<br>
  例：この制度には改良の余地がない。（这个制度没有改良的余地。）
- **青年**（せいねん）青年｜韩语参考：청년（青年）<br>
  例：あの長髪の青年は粗野だ。（那个长发的青年很粗野。）
- **製品**（せいひん）产品；制品｜韩语参考：제품（产品，制品）<br>
  例：この製品は美しく仕上がっている。（这件产品做得很精美。）
- **責任**（せきにん）责任｜韩语参考：책임（责任） / 책임감（责任感，责任心）<br>
  例：けんかは両方に責任がある。（打架双方都有责任。）
- **石油**（せきゆ）石油｜韩语参考：석유（石油）<br>
  例：彼らは石油を船に積み込んでいる。（他们正在把石油装上船。）
- **世間**（せけん）世间；社会｜韩语参考：세간（世间） / 세상（世上，世间）<br>
  例：彼は世間でいう音楽の真の愛好者だ。（他是世人所说的真正的音乐爱好者。）

## 语法

- **〜ついでに**：顺便…
  接续：动词辞书形/た形 + ついでに；名词 + の + ついでに
  朝鲜语：-는 김에（韩语「-는 김에」同样表“顺便”，与「ついでに」对应；但日语可接名词+の，韩语只接动词。）
- **〜おかげで**：多亏…；托…的福
  接续：动词普通形/い形容词/ナ形容词な/名词の + おかげで
  朝鲜语：-덕분에（韩语「-덕분에」与「おかげで」对应；但日语还能用于讽刺（「おかげで遅れた」），韩语同样可以，需靠上下文判断。）
