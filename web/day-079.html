今日语法 3 条

〜ば〜ほど
발음〜바〜호도
越…越…
动词ば形 + 同一动词辞书形 + ほど；い形容词ければ + い形容词 + ほど；ナ形容词なら + ナ形容词な + ほど
表示随着前项程度加深，后项程度也随之变化。
日本語は、勉強すればするほど面白くなる。
日语越学越有意思。
스마호노가멘와오오키케레바오오키이호도미야스이가,모치아루쿠노와타이헨다.
スマホの画面は大きければ大きいほど見やすいが、持ち歩くのは大変だ。
手机屏幕越大越容易看，但带着走很麻烦。
헤야가시즈카나라시즈카나호도,요쿠네무레루.
部屋が静かなら静かなほど、よく眠れる。
房间越安静，睡得越好。
朝鲜语：-면 -ㄹ수록
韩语「-ㄹ수록」一个形式即可；日语要把同一词重复两次（すればするほど），形式负担更重。
易错点

日本語は、勉強するすればするほど面白くなる。 → 勉強すればするほど（前项必须用ば形「すれば」，「するすれば」不合法。）

〜ほど
발음〜호도
到了…的程度
普通形 + ほど；名词 + ほど
举出极端例子说明程度之高，常与「〜ない」呼应表最高级。
키노우와,타떼이라레나이호도쓰카레테이타.
昨日は、立っていられないほど疲れていた。
昨天累得站都站不住。
시켄니고우카쿠시타토키이테,나미다가데루호도우레시카따.
試験に合格したと聞いて、涙が出るほどうれしかった。
听说考试合格，高兴得流下眼泪。
코노아타리와,요루니나루토코와이호도시즈카다.
このあたりは、夜になると怖いほど静かだ。
这一带到了晚上静得让人害怕。
朝鲜语：-ㄹ 정도로
韩语「-ㄹ 정도로」与「ほど」基本对应；但日语「ほど」还用于「〜ほど〜ない」比较句，韩语要用「-만큼」。
易错点

このあたりは、夜になると怖いなほど静かだ。 → 怖いほど（い形容词直接接「ほど」，不加「な」。）

〜くらい / 〜ぐらい（extent）
발음〜쿠라이 / 〜구라이
到…地步；至少…
普通形 + くらい／ぐらい；名词 + くらい
表程度之高，或举最低限度的例子表“至少”。
오나카가이타쿠테,아루케나이쿠라이다따.
おなかが痛くて、歩けないくらいだった。
肚子疼得几乎走不动。
토나리노헤야노온가쿠가우루사쿠테,지분노코에모키코에나이구라이다.
隣の部屋の音楽がうるさくて、自分の声も聞こえないぐらいだ。
隔壁音乐太吵，连自己的声音都听不见。
지분노헤야구라이,지분데소우지시나사이.
自分の部屋ぐらい、自分で掃除しなさい。
至少自己的房间自己打扫。
朝鲜语：-ㄹ 정도로
韩语「-ㄹ 정도로」对应程度用法；“至少”韩语要说「적어도」，日语用「くらい」一并承担，范围更宽。
易错点

おなかが痛くて、歩けないのくらいだった。 → 歩けないくらいだった（动词、い形容词直接接「くらい」，不加「の」。）
