# Day 113 · 〜さえ〜ば、〜こそ

- 阶段：P3｜60 分钟｜听力日
- Can-do：用「〜さえ〜ば、〜こそ」造两句自己的话，表达：只要…就…；正是…；才是…

## 新词 14

- **好み**（このみ）喜好｜韩语参考：기호（嗜好，喜好，爱好） / 입맛（口味，喜好）<br>
  例：特にお好みの色とかおありですか。（您有特别喜欢的颜色吗？）
- **好む**（このむ）喜好｜韩语参考：좋아하다<br>
  例：彼は飛行機での海外旅行を好む。（他喜欢坐飞机出国旅行。）
- **コピー**（コピー）复印；副本｜韩语参考：복사（复印） / 카피（复制，复印） / 복사본（复印件，副本）<br>
  例：このページをコピーして下さい。（请把这一页复印一下。）
- **小麦**（こむぎ）小麦｜韩语参考：밀（小麦）<br>
  例：この小麦は粉にされる。（这些小麦被磨成面粉。）
- **小屋**（こや）小屋｜韩语参考：작은 집 / 오두막<br>
  例：遠くに小屋が見えた。（远处能看到一间小屋。）
- **これら**（これら）这些｜韩语参考：이것들<br>
  例：これらのクッキーは星の形をしている。（这些饼干是星星形状的。）
- **頃**（ころ）时候；左右｜韩语参考：녘（时候） / 무렵（时候，时分） / 언저리（左右）<br>
  例：おひる頃やっと太陽が顔を出した。（快到中午时太阳才露出来。）
- **殺す**（ころす）杀｜韩语参考：죽이다（杀，消弱）<br>
  例：おまえはオレを殺そうとしている。（你想杀了我。）
- **転ぶ**（ころぶ）摔倒｜韩语参考：넘어지다（跌倒，倒下，摔倒）<br>
  例：転んで手首を痛めました。（我摔倒伤了手腕。）
- **今回**（こんかい）这次｜韩语参考：이번（这次，这回）<br>
  例：今回はしくじれないぞ。（这次可不能失手。）
- **今後**（こんご）今后｜韩语参考：차후（此后，以后，今后，日后） / 향후（往后，此后，今后，从今以后）<br>
  例：今後気をつけなくてはなりません。（今后必须多加小心。）
- **こんなに**（こんなに）这么｜韩语参考：이리（这么，如此） / 이다지（如此，这么） / 이리도（如此，这么）<br>
  例：どうして帰りがこんなに遅くなったの。（怎么回来得这么晚？）
- **困難**（こんなん）困难｜韩语参考：곤란（困难，窘迫） / 어려움（困难）<br>
  例：彼の言ってる事を理解するのは困難だ。（要理解他说的话很困难。）
- **今日**（こんにち）今日；如今｜韩语参考：오늘 / 오늘날<br>
  例：彼は宿題を今日終えねばならない。（他今天必须把作业做完。）

## 语法

- **〜さえ〜ば**：只要…就…
  接续：名词 + さえ + ば形；动词ます形词干 + さえ + すれば；动词て形 + さえ + いれば
  朝鲜语：-기만 하면（韩语「-기만 하면」与「さえ〜ば」对应；但日语「さえ」位置固定在各成分后，韩语统一贴在动词后，语序处理不同。）
- **〜こそ**：正是…；才是…
  接续：名词 + こそ（可加「が」成「こそが」）
  朝鲜语：-야말로（韩语「-야말로」与「こそ」几乎一致；但日语「こちらこそ」已成固定寒暄，韩语对应「저야말로」，礼貌度需注意。）
