今日语法 3 条

（场所）に ～ がある / いる
발음니 ～ 가아루 / 이루
（某地）有…
場所 + に + 物/人 + が + ある／いる
存在句：无生命用 ある，有生命用 いる；主体用 が
헤야니네코가이마스.
部屋に猫がいます。
房间里有猫。
에키노마에니미세가아리마스.
駅の前に店があります。
车站前有店。
朝鲜语：에 ~ 이/가 있다 / 계시다
韩语存在动词不分有无生命，一律있다，敬语用계시다；日语必须分ある/いる。
易错点

部屋に猫があります。 → 部屋に猫がいます。（猫是有生命，用 いる；中文「有」不分 animate，日语 ある/いる 必须分）

い形容词（～い です）
…（い形容词谓语）
い形容詞 + です
い形容词作谓语，礼貌体直接加 です，不再加 だ
코노혼와타카이데스.
この本は高いです。
这本书贵。
朝鲜语：형용사 어간 + 다 / -아·어요
韩语形容词作谓语要加终结词尾，敬语靠어요/습니다；日语い形直接加です。
易错点

本は高いだ。 → 本は高いです。（い形容词后不能接 だ；「です」已是礼貌体，中文「是」诱发了 だ）

な形容词（～です）
…（な形容词谓语）
な形容詞語幹 + です／だ
な形容词词干后接 です；连体形加 な，副词形加 に
코노헤야와시즈카데스.
この部屋は静かです。
这个房间安静。
카노조와겐키데스.
彼女は元気です。
她很精神。
朝鲜语：형용사(하다형)
韩语 하다 类形容词修饰名词时通常变成 -한，如 조용한 방；日语な形容词连体用 な。
易错点

部屋は静かだ。 → 部屋は静かです。（「部屋は静かだ。」本身合法（な形容词普通体）。本题要求礼貌体时才改成 静かです；不要把它当成语法错误。）
