# Day 119 · 〜かける、〜ようにする

- 阶段：P4｜60 分钟｜听力日
- Can-do：用「〜かける、〜ようにする」各造一句自己的话，表达：…了一半；刚要…；尽量…；设法做到…

## 新词 22

- **馬鹿**（ばか）傻瓜；荒唐｜韩语参考：바보（白痴，笨蛋，傻瓜） / 머저리（傻瓜，蠢货，呆子） / 얼간이（傻瓜，笨蛋）<br>
  例：なんという馬鹿なことだろう。（这是多么荒唐的事啊。）
- **博士**（はかせ）博士｜韩语参考：박사<br>
  例：彼は心理学博士の学位を持っている。（他拥有心理学博士学位。）
- **計る**（はかる）测量｜韩语参考：재다（测量，测，量） / 측량하다（测量，测定）<br>
  例：さあ、あなたの体温を計りましょう。（来，给你量一下体温。）
- **吐く**（はく）吐；说出｜韩语参考：뱉다（说出来，爆出） / 게우다（吐，呕吐） / 토하다（吐）<br>
  例：気分が悪くて、食べた物を吐きました。（身体不舒服，把吃的东西吐了出来。）

- **博物館**（はくぶつかん）博物馆｜韩语参考：박물관（博物馆）<br>

- **激しい**（はげしい）激烈；猛烈｜韩语参考：세차다（强劲，猛烈） / 가열차다（强烈，激烈，热烈） / 가열하다（激烈，狂热）<br>

- **はさみ**（はさみ）剪刀｜韩语参考：가위（剪刀）<br>

- **破産**（はさん）破产｜韩语参考：파산（破产）<br>
  例：かけごとのために彼は破産した。（他因赌博破了产。）
- **端**（はし）边缘；端｜韩语参考：끝（头，尖，端） / 가장자리（边，边缘）<br>

- **始まり**（はじまり）开始；开端｜韩语参考：머리（开始，开头） / 시발（开端，开头） / 시작（开始，开端，开头，起始，起头）<br>

- **パス**（パス）通行证；传球｜韩语参考：패스（传球）<br>

- **パスポート**（パスポート）护照｜韩语参考：여권（护照） / 패스（护照） / 패스포트（护照）<br>

- **働き**（はたらき）工作；作用｜韩语参考：일 / 작용<br>
  例：働きすぎると体によくないだろう。（工作过度对身体不好。）
- **バッグ**（バッグ）包；手提包｜韩语参考：백（袋，皮包，手提包） / 가방（包，背包，提包）<br>
  例：バッグはどこに置けばいいですか。（包放在哪里好？）

## 语法

- **〜かける**：…了一半；刚要…
  接续：动词ます形词干 + かける；动词ます形词干 + かけの + 名词
  朝鲜语：-다 말다（韩语「-다 말다」表“做到一半就停”，与「かける」对应；但日语还能表“刚开始、眼看要”，韩语要用「-려다」，含义更宽。）
- **〜ようにする**：尽量…；设法做到…
  接续：动词辞书形／动词ない形 + ようにする
  朝鲜语：-도록 하다（韩语 -도록 하다 与 ようにする 对应，但韩语还常用 -기로 하다 表决定；日语 ようにする 强调持续的努力，不含「决定」义。）
