今日语法 3 条

〜ように言う / 〜ように頼む
발음〜요우니이우 / 〜요우니타노무
让…做；转告…
动词辞书形/ない形 + ように言う／ように頼む／ように伝える
转述委托、命令或指示的内容，常用于间接引语。
이샤니,오사케오노미스기나이요우니이와레타.
医者に、お酒を飲みすぎないように言われた。
医生嘱咐我别喝太多酒。
토나리노헤야노히토니,요루와온가쿠노오토오치이사쿠스루요우니타노다.
隣の部屋の人に、夜は音楽の音を小さくするように頼んだ。
我请隔壁房间的人晚上把音乐关小。
山下さんに、明日の会議に遅れないように伝えてください。
请转告山下先生明天开会不要迟到。
朝鲜语：-라고 말하다
韩语引用用「-라고」，需按词类换「-으라고/-라고」；日语统一用「ように」，不随词类变化，容易漏掉「に」。
易错点

医者に、お酒を飲みすぎませんように言われた。 → 飲みすぎないように言われた（转述请求或指示用「〜ないように」；「〜ませんように」是祈愿，不能作引用内容。）

〜ようとする
발음〜요우토스루
想要…；正要…
动词意志形 + とする（否定形：ようとしない）
表示尝试做某动作，或动作即将发生的瞬间。
ドアを開けようとしたが、鍵がかかっていて開かなかった。
我想开门，但锁着打不开。
家を出ようとしたとき、急に雨が降り出した。
正要出门时，突然下起雨来。
弟は何度注意しても、部屋を片付けようとしない。
弟弟不管怎么提醒，都不肯收拾房间。
朝鲜语：-려고 하다
韩语「-려고 하다」也表意图，但“正要…的瞬间”日语说「ようとしたとき」，韩语多用「-려던 참에」，形式不同。
易错点

ドアを開けますようとしたが、鍵がかかっていた。 → 開けようとした（「ようとする」前接意志形「開けよう」，不能插入「ます」。）

〜そうにない / 〜そうもない
발음〜소우니나이 / 〜소우모나이
看样子不会…；不像会…
动词ます形词干 + そうにない／そうもない
从现状判断某事难以实现，是样态「そうだ」的否定。
코노아메와,유우가타마데야미소우니나이.
この雨は、夕方までやみそうにない。
这场雨看样子到傍晚也停不了。
시고토가오오스기테,쿄우주우니와오와리소우모나이.
仕事が多すぎて、今日中には終わりそうもない。
工作太多，今天之内看样子做不完。
콘나니타쿠산노료우리,후타리데와타베키레소우니나이네.
こんなにたくさんの料理、二人では食べきれそうにないね。
这么多菜，两个人看样子吃不完。
朝鲜语：-ㄹ 것 같지 않다
韩语没有专门对应，常说「-ㄹ 것 같지 않다」；日语「そうにない」依据眼前迹象，主观判断色彩更强。
易错点

この雨は、夕方までやむそうにない。 → やみそうにない（「そうにない」前接ます形词干「やみ」，「やむそう」不是合法形式。）
