# Day 109 · 〜てばかりいる、〜ばいい

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜てばかりいる、〜ばいい」各造一句自己的话，表达：老是…；一味…；…就行；…才好

## 新词 25

- **知事**（ちじ）知事；县长｜韩语参考：지사（일본 광역자치단체장）<br>
  例：彼は知事と長年の付き合いです。（他和知事有多年的交情。）
- **知識**（ちしき）知识｜韩语参考：지식（知识）<br>
  例：私のドイツ語の知識は貧弱です。（我的德语知识很贫乏。）
- **父親**（ちちおや）父亲｜韩语参考：부친（父亲） / 아버지（父亲，爸爸）<br>
  例：その少年は父親に似ている。（那个少年像他父亲。）
- **知能**（ちのう）智能；智力｜韩语参考：지능（智能）<br>
  例：イルカは非常に知能の高い動物です。（海豚是智力非常高的动物。）
- **地平線**（ちへいせん）地平线｜韩语参考：지평선（地平线） / 지평（地平线）<br>
  例：月が地平線の上にあった。（月亮在地平线上方。）
- **地方**（ちほう）地方；地区｜韩语参考：지방（地区） / 고장（地方，家乡）<br>
  例：彼は今年の夏、東北地方を旅行した。（今年夏天他到东北地区旅行了。）
- **茶**（ちゃ）茶；棕色｜韩语参考：차（茶，茶水）<br>
  例：その猫の一方は黒で、もう一方は茶だ。（那两只猫一只是黑的，另一只是棕色的。）
- **チャンス**（チャンス）机会｜韩语参考：기회（机会，机遇，时机）<br>
  例：お願いだ！俺にチャンスをくれ。（求你了！给我一次机会。）
- **ちゃんと**（ちゃんと）好好地；确实｜韩语参考：제대로<br>
  例：この道具はちゃんと使えばとても役に立つ。（这个工具好好使用的话非常有用。）
- **中**（ちゅう）中；其中｜韩语参考：중（中，中等）<br>
  例：１０人中３人はビデオを持っている。（十个人中有三个人有录像机。）
- **注**（ちゅう）注释｜韩语参考：주（注，注释）<br>
  例：注はページの下欄についている。（注释在页面下方。）
- **中央**（ちゅうおう）中央；中间｜韩语参考：중앙（正中央，中心） / 가운데（中间，正中，中央）<br>
  例：私たちはその部屋の中央に座った。（我们坐在房间中央。）
- **中学**（ちゅうがく）初中｜韩语参考：중학교（初中）<br>
  例：彼は中学時代小説ばかり読んでいた。（他初中时净读小说。）
- **中古**（ちゅうこ）二手的｜韩语参考：중고<br>
  例：その中古の冷蔵庫はひどい代物だった。（那台二手冰箱是个糟糕的玩意儿。）
- **中止**（ちゅうし）中止；取消｜韩语参考：중지（中止，中断） / 취소（取消，解除）<br>
  例：暴風雨のため道路工事が中止された。（由于暴风雨，道路施工中止了。）
- **駐車**（ちゅうしゃ）停车｜韩语参考：주차（停车，停放车辆）<br>
  例：彼にどこに駐車したのか聞いてください。（请问他把车停在哪里了。）
- **昼食**（ちゅうしょく）午饭｜韩语参考：점심<br>
  例：今日は昼食をとる時間がない。（今天没时间吃午饭。）
- **中心**（ちゅうしん）中心｜韩语参考：중심（中心，正中） / 중앙（正中央，中心）<br>
  例：その町の中心にすてきな公園がある。（镇中心有个漂亮的公园。）
- **注目**（ちゅうもく）注目；关注｜韩语参考：주목（注目，注视，关注）<br>
  例：ご注目下さい。（请注意。）
- **注文**（ちゅうもん）订购；点菜｜韩语参考：주문（订购，订货）<br>
  例：あなたのためにデザートを注文した。（我给你点了甜点。）
- **長期**（ちょうき）长期｜韩语参考：장기（长期）<br>
  例：長期にわたる病気のあとでジェーンはカウチ・ポテトになった。（久病之后，简变成了整天窝在沙发上的人。）
- **調子**（ちょうし）状况；调子｜韩语参考：상태 / 곡조<br>
  例：あなたの新しい車は調子よく動いていますか。（你的新车跑得顺吗？）
- **頂上**（ちょうじょう）山顶｜韩语参考：정상（顶峰，山顶）<br>
  例：私達はついに頂上へたどり着いた。（我们终于到达了山顶。）
- **ちょうだい**（ちょうだい）请给我；领受｜韩语参考：줘 / 받다<br>
  例：市民の皆様の御意見をちょうだいする予定です。（我们计划征求市民的意见。）
- **貯金**（ちょきん）存款；存钱｜韩语参考：저금（存款，存钱，储蓄）<br>
  例：彼女はお金をたくさん貯金している。（她存了很多钱。）

## 语法

- **〜てばかりいる**：老是…；一味…
  接续：动词て形 + ばかりいる
  朝鲜语：-기만 하다（韩语「-기만 하다」只表“只做某事”，不带褒贬；日语「てばかりいる」几乎总含批评。）
- **〜ばいい**：…就行；…才好
  接续：动词ば形 + いい；い形容词ければ + いい
  朝鲜语：-면 된다（韩语「-면 된다」与「ばいい」对应；但日语「ばいいのに」可表惋惜、责备，韩语要用「-면 좋을 텐데」。）
