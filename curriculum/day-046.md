## 3. 新语法（含先修）
- `G0074` **V辞書形 + ため(に) / 普通形・N の + ため(に)** — 为了…（目的）／因为…、由于…（原因）｜接续：目的：意志动词 辞書形 + ため(に)；原因：普通形（多为 た形/ている/ない）或 名詞 + の + ため(に)
- `G0091` **普通形 + ものだから / もので** — 因为…（所以…）；由于…｜接续：動詞・い形 普通形 + ものだから；な形・名詞 + な/だ + ものだから；もので 更书面

## 4. 新汉字（中日差异）
- `K0117` **続** 音:ゾク 训:つづく｜中文「续」xù；日语 続 音读 ゾク、训读 つづく（続く）；但「手続き」てつづき 中读 つづき（训读），不读 しゅぞく；「手続き」是「手续」，不能按「手+续」字面猜读音。
- `K0133` **意** 音:イ 训:｜中文「意」yì；日语 意 音读 イ，「意味」いみ 是「意思/含义」、「意見」いけん、「注意」ちゅうい；中文「意」单用少，日语「意」构成大量抽象词，须按 イ 验证，此字无常用训读。
