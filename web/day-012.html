今日语法 3 条

～たい / ～たがる
발음～타이 / ～타가루
想（做）…／（第三人称）想…
動詞ます形（去ます） + たい；第三人称 + たがる
たい 通常用于说话人愿望或询问对方；叙述他人外显愿望常用 たがる，也可通过引用、传闻等交代他人愿望。
韩语对应-고 싶다 / -고 싶어 하다
韩语常用 -고 싶다 表自己愿望、询问对方或转述内容；观察他人的愿望常用 -고 싶어 하다。日语也须按叙述视角选择。
미즈가노미타이데스.
水が飲みたいです。
想喝水。
에이가가미타이데스.
映画が見たいです。
想看电影。

易错点 飲みたいだ。 → 飲みたいです。（「たい」是い形容词型，结句用 です，不接 だ）

～ましょう / ～ませんか
발음～마쇼우 / ～마센카
（一起）…吧／要不要…？
動詞ます形（去ます） + ましょう／ませんか
ましょう 表提议/意志；ませんか 是委婉邀约
韩语对应-(으)ㅂ시다 / -(으)ㄹ래요?
韩语提议用ㅂ시다，邀约用ㄹ래요；对长辈ㅂ시다不礼貌，须换ㄹ까요。
이쑈니에이가오미마센카.
一緒に映画を見ませんか。
一起看电影好吗？
소로소로카에리마쇼우.
そろそろ帰りましょう。
差不多回去吧。

易错点 映画を見るましょう。 → 映画を見ましょう。（「ましょう」前接ます形词干（見），不接辞书形 見る）

～が ほしい
발음～가 호시이
想要（某物）
名詞 + が + ほしい（です）
表说话人想要某物；对象用 が，不是 を；第三人称用 ほしがる
韩语对应이/가 갖고 싶다 / 원하다
韩语갖고 싶다限第一人称，第三人称用갖고 싶어 하다；원하다偏书面。
아타라시이파소콘가호시이데스.
新しいパソコンがほしいです。
想要新电脑。

易错点 パソコンを ほしいです。 → パソコンがほしいです。（「ほしい」对象格用 が；中文「想要(某物)」是动宾，直译成 を 错）
