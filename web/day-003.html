Day 003 · これ / それ / あれ / どれ は N です、N の N

语法 2 条

これ / それ / あれ / どれ は N です
발음코레 / 소레 / 아레 / 도레 와 N 데스
这/那/那是…
指示代名词 + は + 名詞 + です
コソアド 指示词：近称/中称/远称/疑问
韩语对应이것 / 그것 / 저것 / 어느 것
이것／그것／저것 可以单独作名词，对应 これ／それ／あれ。修饰名词时改用 이 책／그 책／저 책，对应 この本／その本／あの本；「哪本」是 どの本。
코레 와 혼데스.
これは本です。
这是书。
소레 와 이쿠라데스 카.
それはいくらですか。
那个多少钱？
易错易混点
  • ✗ これは本を買います。✓ この本を買います。「这本书」是 この本，この 后面必须跟名词；これ 只能单独用，如 これを買います。
N の N
발음N 노 N
…的…；所属/修饰
名詞 + の + 名詞
连体修饰、所属、同位；中文「的」的对应，但不可滥用
韩语对应N의 N
韩语의多表所属，口语常省略；修饰关系更常用名词直接并列，使用范围比日语の窄。
와타시 노 혼데스.
私の本です。
是我的书。
니혼고 노 센세이데스.
日本語の先生です。
是日语老师。
易错易混点
  • ✗ 私は本です。✓ 私の本です。「我的书」是 私の本。中文的“我的”要换成 の，不是 は。
  • ✗ 静かな の 部屋✓ 静かな部屋な形容词接名词用 な（静かな部屋），不用 の。
