# Day 025 · 可能形、条件形（ば／たら／なら／と）、～に なる / ～く なる / ～に する、～と 思う / ～と 言う

- 阶段：P2｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **可能形**：能／会…（动词可能形）
  接续：五段 う段→え段+る；一段 去る+られる；カ変 来られる；サ変 できる
  朝鲜语：-(으)ㄹ 수 있다（韩语可能用ㄹ 수 있다短语，不改动词形态；日语靠一段/五段变形，宾语可を→が。）
- **条件形（ば／たら／なら／と）**：如果…／一…就…（条件形总览）
  接续：と：固定反应、惯例或叙述中的发现；ば：把条件作为判断依据；たら：假设或前动作完成之后；なら：承接已提出的话题或计划。
  朝鲜语：-(으)면（韩语 -(으)면 能涵盖多种条件。日语若先到车站才打电话，用 着いたら；若提出去京都前先买票，用 行くなら。）
- **～に なる / ～く なる / ～に する**：变成…／使…变得…
  接续：名詞/な形 + に + なる；い形 + く + なる；他动词 〜に/く する
  朝鲜语：-아/어지다 / -게 하다（韩语变化用아/어지다，人为改变用게 하다；无日语なる/する的自动他动对立。）
- **～と 思う / ～と 言う**：觉得…／说「…」
  接续：普通形从句 + と + 思う／言う
  朝鲜语：-다고 생각하다 / -라고 말하다（韩语间接引语按句型选 -다고／-(이)라고／-냐고；日语直接引用原话时保留原来的语体，间接表达自己的判断通常用普通形接 と。）
