③ 语法 7 分钟

N / Vた形 / V辞書形 / Vて + ばかり
名詞 + ばかり；動詞 た形 + ばかり（刚做完）；辞書形 + ばかり（只等/只剩）；て形 + ばかり いる（光顾着做）
刚…；净是…、只…；一味…

多义：①刚…②净/只③一味做；数量或程度超出预期，常带负面语感

日本に来たばかりです。
刚来日本不久。
彼はゲームばかりしています。
他光打游戏。
この店は値段ばかり高くて、味は普通です。
这家店光价格贵，味道一般。
朝鲜语：방금 / -만 / -기만 하다
韩语「刚」用방금、「只」用만、「一味」用기만 하다，三义分用；日语ばかり一形靠语境。

易错：日本に来るばかりです。 → 日本に来たばかりです。（「刚来」用 た形 来たばかり，不能用辞书形；中文「刚」直译不体现 た 易错）

V辞書形/Vている/Vた形 + ところ(だ/に/を/で)
辞書形 + ところだ（正要）；ている + ところだ（正在）；た形 + ところだ（刚做完）；ところに/を/で 后接外部动作或发现
正要…／正在…／刚…；在…时候；…之际

把动作切成「即将/进行/刚完」的时间点；ところを 多用于被看见/被打断（含被动、抱歉语气）

今から出かけるところです。
正要出门。
ご飯を食べているところに電話がかかってきました。
正吃饭时来了电话。
駅に着いたところです。
刚到车站。
朝鲜语：-(으)려고 하다 / -고 있다 / -(으)ㄴ 참이다
韩语正要려고 하다、正在고 있다、刚ㄴ 참이다；日语ところだ按だ/に/を/で四形变化。

易错：今から出かけたところです。 → 今から出かけるところです。（「正要出门」用 辞书形 出かけるところ；た形 变成「刚出去」，中文「正要」直译错）
