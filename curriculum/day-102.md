## 语法

- **〜を除いて**：除…之外
  接续：名词 + を除いて / 名词 + を除き / 名词 + を除く + 名词
  朝鲜语：을 제외하고（韩语提示按整块理解。换成日语时先套接续「名词 + を除いて / 名词 + を除き / 名词 + を除く + 名词」，再看下面的例句。）
- **〜かのようだ**：仿佛…似的
  接续：动词普通形 / i-Adj + かのようだ / na-Adj + である + かのようだ / 名词 + である + かのようだ
  朝鲜语：인 것처럼（韩语提示按整块理解。换成日语时先套接续「动词普通形 / i-Adj + かのようだ / na-Adj + である + かのようだ / 名词 + である + かのようだ」，再看下面的例句。）
