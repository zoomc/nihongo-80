# Day 048 · V辞書形 / Vない形 + ように する、V辞書形/Vない形 + ことに する / なる、V辞書形 / Vない形 + ことが ある

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **V辞書形 / Vない形 + ように する**：努力做到…／设法不…（有意识地做）
  接续：動詞 辞書形／ない形 + ように + する；する 按 サ変 变形（ようにしています／ようにした）
  朝鲜语：-도록 하다（韩语 -도록 하다 可表努力或指示；日语ようにする可用于自己的安排，也可用于要求他人注意。）
- **V辞書形/Vない形 + ことに する / なる**：（自己）决定…／（结果）定为…、将要…
  接续：动词辞书形／ない形 + ことにする（决定）／ことになる（安排、结果）。
  朝鲜语：-기로 하다 / -게 되다（韩语自己决定用기로 하다，外部决定或结果用게 되다；与日语ことにする/なる对应整齐。）
- **V辞書形 / Vない形 + ことが ある**：有时会…／有时不…（泛指倾向）
  接续：動詞 辞書形／ない形 + ことが ある；ある 可变形（ことがあります／あった）
  朝鲜语：-곤 하다 / -기도 하다（偶发可用 -는 때가 있다 或 -기도 하다；持续一段时期的习惯才适合 -곤 하다。日语 凍ることがある 是有时结冰，凍ったことがある 指结过冰。）
