# Day 068 · 〜的、〜ような / 〜ように（like）

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜的**：…上的；…式的
  接续：名词 + 的（てき）；修饰名词可用 的な，也有直接连接的词组，如経済的理由
  朝鲜语：-적（韩语「-적」来自同一汉字词，用法高度相似；但韩语接「으로/인」，日语换成「に/な」，词形对应不齐。）
- **〜ような / 〜ように（like）**：像…一样；如同…
  接续：名词 + の + ような/ように；普通形 + ような/ように
  朝鲜语：…같은 / …같이 / …처럼（先生のような人 可对照 선생님 같은 사람，先生のように読む 对照 선생님처럼 읽다。日语名词接 よう 前加 の，句中再根据修饰对象选 な／に。）
