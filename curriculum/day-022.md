# Day 022 · 〜より、〜の方が〜より、〜と〜とどちらが

- 阶段：P1｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜より**：比…
  接续：比较基准（名词或普通形）+ より；优胜的一项可用 は 或 の方が 表明。
  朝鲜语：보다（배보다 사과가 싸다 对照 梨よりりんごの方が安い。两种语言都把比较标记放在基准后面；日语可先说主项 りんごは，再说 梨より。）
- **〜の方が〜より**：…比…更…
  接续：名词 + の方が + 名词 + より + 形容词
  朝鲜语：가/이 더 …（用 자전거가 더 빠르다 记优势侧，歩くより自転車の方が速い 中 方が 也放在优势侧。也可用 自転車は徒歩より速い 省去 方。）
- **〜と〜とどちらが**：…和…哪个更…？
  接续：名词 + と + 名词 + とどちらが + 形容词 + か
  朝鲜语：A와 B 중 어느 쪽이（韩语用 와/과 중 어느 쪽이，日语用 と〜とどちらが；韩语需加 중，日语靠 どちら 本身表两者。）
