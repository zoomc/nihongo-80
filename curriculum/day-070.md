## 新词 25

- **指す**（さす）指；指向｜韩语参考：짚다（指） / 가리키다（指，指着，指出）<br>
  例：＆という記号は、ａｎｄを指す。（「＆」这个符号指的是 and。）
- **座席**（ざせき）座位｜韩语参考：좌석（坐席，座位） / 자리（座位，席位）<br>
  例：鞄を座席の下に置いてください。（请把包放在座位下面。）
- **誘う**（さそう）邀请；引诱｜韩语参考：권하다 / 유혹하다<br>
  例：ウラウラとした日差しに誘われて、眠りに落ちた。（暖洋洋的阳光让人犯困，我不知不觉睡着了。）
- **札**（さつ）纸币｜韩语参考：지폐<br>
  例：１０００円札をくずしていただけませんか。（能帮我把一千日元换开吗？）
- **作家**（さっか）作家｜韩语参考：작가（作家）<br>
  例：その作家は私たちによく知られています。（那位作家我们很熟悉。）
- **作曲**（さっきょく）作曲｜韩语参考：작곡（作曲，谱曲）<br>
  例：この音楽はバッハによって作曲された。（这首曲子是巴赫作的。）
- **ざっと**（ざっと）大致；粗略｜韩语参考：대충（大概，大致，大体） / 슬쩍（草草地，大致地） / 슬쩍슬쩍（大致地，草草地）<br>
  例：私はパンフレットにざっと目をとおした。（我大致浏览了一遍小册子。）
- **さっぱり**（さっぱり）清爽；完全（不）｜韩语参考：상쾌하다 / 전혀（부정과 함께）<br>
  例：私はこの手のことにはさっぱりだ。（这类事我完全不懂。）
- **さて**（さて）那么｜韩语参考：자 / 그런데<br>
  例：さて、次の問題を考えましょう。（那么，来想想下一道题吧。）
- **砂漠**（さばく）沙漠｜韩语参考：사막（沙漠）<br>
  例：サハラは広大な砂漠です。（撒哈拉是一片广阔的沙漠。）
- **差別**（さべつ）歧视；区别｜韩语参考：차별（差别，不平等，歧视）<br>
  例：その週間は差別とは関係がなかった。（那一周和歧视问题没有关系。）
- **作法**（さほう）礼节；礼法｜韩语参考：예법（礼法） / 예절（礼节，礼貌，礼仪）<br>
  例：彼は作法がぎこちない。（他的礼节举止很生硬。）
- **様々**（さまざま）各种各样｜韩语参考：여러 가지<br>
  例：庭には様々な花が咲き乱れていた。（院子里各种花开得繁盛。）
- **覚ます**（さます）弄醒；醒｜韩语参考：깨우다<br>
  例：その物音が私を眠りから覚まさせた。（那声响把我从睡梦中弄醒了。）
- **覚める**（さめる）醒｜韩语参考：깨어나다<br>
  例：その音で彼女は眠りから覚めた。（那声音把她从睡梦中吵醒了。）
- **左右**（さゆう）左右｜韩语参考：좌우（左右）<br>
  例：彼は怒って首を左右に振った。（他生气地左右摇头。）
- **皿**（さら）盘子｜韩语参考：접시<br>
  例：彼女はテーブルの上に皿を置いた。（她把盘子放在桌上。）
- **参考**（さんこう）参考｜韩语参考：참고（参考，参照，参酌）<br>
  例：参考のためにカタログをお送りください。（请寄一份目录供参考。）
- **賛成**（さんせい）赞成｜韩语参考：찬성（赞成，赞同）<br>
  例：私たちの計画に賛成してくれますか。（你赞成我们的计划吗？）
- **酸素**（さんそ）氧气｜韩语参考：산소（氧，氧气）<br>
  例：酸素が無ければ生きられない。（没有氧气就无法生存。）
- **氏**（し）氏；先生｜韩语参考：씨 / 성씨<br>
  例：亡くなったスミス氏は医者でした。（已故的史密斯先生是医生。）
- **詩**（し）诗｜韩语参考：시（诗）<br>
  例：この詩は誰が書いたのですか。（这首诗是谁写的？）
- **幸せ**（しあわせ）幸福｜韩语参考：행복（幸福）<br>
  例：金持ちが幸せとは限らない。（有钱人不一定幸福。）
- **ジーンズ**（ジーンズ）牛仔裤｜韩语参考：청바지（牛仔裤）<br>
  例：私は日曜日はたいていジーンズをはいている。（我星期天大多穿牛仔裤。）
- **ジェット機**（ジェットき）喷气式飞机｜韩语参考：제트기（喷气式飞机）<br>
  例：ジェット機は東京に着陸した。（喷气式飞机在东京降落了。）

## 语法

- **〜気がする**：感觉…；总觉得…
  接续：普通形 + 気がする；ナ形容词 + な + 気がする；名词 + の + ような + 気がする
  朝鲜语：-ㄴ 기분이 들다（韩语「-ㄴ 기분이 들다」偏情绪感受；日语「気がする」还能用于记忆和判断的模糊确信，范围更广。）
- **〜ずに**：不…就…；没…而…
  接续：动词ない形词干 + ずに（する→せずに）
  朝鲜语：-지 않고（韩语「-지 않고」不分书面口语；日语「ずに」限书面正式，「ないで」才是口语，需按文体选择。）
- **〜まま**：就那样…；保持着…
  接续：动词た形/ない形 + まま；い形容词 + まま；ナ形容词 + な + まま；名词 + の + まま
  朝鲜语：-ㄴ 채로（韩语「-ㄴ 채로」与「まま」很接近；但日语可接名词「〜のまま」，韩语没有对应形式，要改说「그대로」。）
