# Day 128 · 〜とすれば / 〜としたら

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜とすれば / 〜としたら」造两句自己的话，表达：假设…的话

## 新词 19

- **スケート**（スケート）滑冰｜韩语参考：스케이트（滑冰）<br>
  例：とても寒いからスケートが出来るよ。（天很冷，可以滑冰了。）
- **少しも**（すこしも）一点也不｜韩语参考：조금도（부정과 함께）<br>
  例：コックさんは少しも手を抜いていません。（厨师一点也没有偷工减料。）
- **過ごす**（すごす）度过｜韩语参考：나다（度过） / 지내다（度过） / 지우다（度过）<br>
  例：いいクリスマスを過ごしましたか。（圣诞节过得好吗？）
- **筋**（すじ）筋；情节｜韩语参考：힘줄（筋，腱）<br>
  例：その小説の筋はわからない。（我不明白那本小说的情节。）
- **勧める**（すすめる）劝；推荐｜韩语参考：권하다（建议，推荐）<br>
  例：父は私にピアノを習うように勧めた。（父亲劝我去学钢琴。）
- **進める**（すすめる）推进｜韩语参考：진행시키다<br>
  例：その計画は進められている。（那个计划正在推进。）
- **スター**（スター）明星｜韩语参考：별（巨星，明星） / 스타（明星）<br>
  例：スターの野球選手はよくサインを求められる。（明星棒球选手常被要求签名。）
- **スタイル**（スタイル）风格；体型｜韩语参考：체（体格，体型） / 스타일（风格，作风）<br>
  例：ダンスはスタイルをよくするのにいい。（跳舞有助于改善体形。）
- **スタンド**（スタンド）看台；加油站｜韩语参考：관람석 / 주유소<br>
  例：次のスタンドまでどのくらいありますか。（到下一个加油站还有多远？）
- **頭痛**（ずつう）头痛｜韩语参考：두통（头痛，头疼）<br>
  例：今日は少し頭痛がする。（今天有点头痛。）
- **ずっと**（ずっと）一直；…得多｜韩语参考：죽（一直） / 쭉（一直） / 그저（一直）<br>
  例：この時計はあれよりもずっと高価だ。（这块表比那块贵得多。）
- **すてき**（すてき）漂亮；极好｜韩语参考：멋지다<br>
  例：彼らはすてきな家を持っている。（他们有一栋漂亮的房子。）
- **既に**（すでに）已经｜韩语参考：이미（已经）<br>
  例：私はもう既に朝食を済ませました。（我已经吃过早饭了。）
- **すなわち**（すなわち）即；也就是说｜韩语参考：즉 / 다시 말해<br>
  例：すなわち彼はそれをしたくないのだ。（也就是说，他不想做那件事。）
- **スピーチ**（スピーチ）演讲｜韩语参考：연설<br>
  例：私たちは彼にスピーチを頼んだ。（我们请他做演讲。）
- **全て**（すべて）全部｜韩语参考：다（全部，最好） / 전부（全部）<br>
  例：人間は全て平等である。（所有人都是平等的。）
- **済ませる**（すませる）做完；办完｜韩语参考：끝내다 / 마치다<br>
  例：私はまだ朝食を済ませていません。（我还没吃完早饭。）
- **鋭い**（するどい）尖锐；敏锐｜韩语参考：거칠다（尖锐） / 날카롭다（尖锐，敏锐） / 뾰족하다（尖，尖锐）<br>
  例：ここに鋭い痛みがあります。（这里有一阵刺痛。）
- **せい**（せい）缘故；因为｜韩语参考：탓 / 때문<br>
  例：あなたの頭痛は過労のせいだ。（你的头痛是过劳造成的。）

## 语法

- **〜とすれば / 〜としたら**：假设…的话
  接续：动词普通形／い形容词 + とすれば・としたら；名词及な形容词可视表达使用 だとしたら 或 としたら
  朝鲜语：-라고 한다면（韩语「-라고 한다면」偏传闻假设；日语「としたら」只是单纯设想，不含传闻，语气更轻。）
