Day 025 · 可能形、条件形（ば／たら／なら／と）、～に なる / ～く なる / ～に する、～と 思う / ～と 言う

语法 4 条

可能形
能／会…（动词可能形）
五段 う段→え段+る；一段 去る+られる；カ変 来られる；サ変 できる
表能力/可能；对象助词常由 を 变 が（日本語が話せる）
韩语对应-(으)ㄹ 수 있다
韩语可能用ㄹ 수 있다短语，不改动词形态；日语靠一段/五段变形，宾语可を→が。
니혼고 가 하나시세마스.
日本語が話せます。
会说日语。
易错易混点
  • ✗ 話せできます。✓ 話せます。可能形本身已经含“能”，后面不能再加 できる。話せます 就够了。
条件形（ば／たら／なら／と）
如果…／一…就…（条件形总览）
と：固定反应、惯例或叙述中的发现；ば：把条件作为判断依据；たら：假设或前动作完成之后；なら：承接已提出的话题或计划。
四大条件形的变形总览；各自语用限制见 G0038
韩语对应-(으)면
韩语 -(으)면 能涵盖多种条件。日语若先到车站才打电话，用 着いたら；若提出去京都前先买票，用 行くなら。
야스케레바카이마스.
安ければ買います。
便宜就买。
아메 가 후따라이키마센.
雨が降ったら行きません。
下雨就不去。
易错易混点
  • ✗ 雨が降るたら、家にいます。✓ 雨が降ったら、家にいます。たら 前面接た形（降ったら），不接辞书形（降るたら）。
～に なる / ～く なる / ～に する
발음～니 나루 / ～쿠 나루 / ～니 스루
变成…／使…变得…
名詞/な形 + に + なる；い形 + く + なる；他动词 〜に/く する
なる 自动词表自然变化，する 他动词表人为改变
韩语对应-아/어지다 / -게 하다
韩语变化用아/어지다，人为改变用게 하다；无日语なる/する的自动他动对立。
카레 와 이샤 니 나리마시타.
彼は医者になりました。
他当上医生了。
헤야 가 시즈카 니 나리마시타.
部屋が静かになりました。
房间变安静了。
易错易混点
  • ✗ 部屋を静かになりました。✓ 部屋が静かになりました。／部屋を静かにしました。なる 是自动词，变化的主体用 が；“把房间弄安静”是人为改变，才用 を＋する。
  • ✗ 寒いに なりました✓ 寒くなりました。い形容词变“变得…”用 〜くなる（寒くなる）；になる 给名词和な形容词。
～と 思う / ～と 言う
발음～토 오모우 / ～토 이우
觉得…／说「…」
普通形从句 + と + 思う／言う
引用助词 と；从句用普通形，不用 です/ます
韩语对应-다고 생각하다 / -라고 말하다
韩语间接引语按句型选 -다고／-(이)라고／-냐고；日语直接引用原话时保留原来的语体，间接表达自己的判断通常用普通形接 と。
아시타 와 아메다 토 오모이마스.
明日は雨だと思います。
我觉得明天会下雨。
카레 와 이키타쿠나이 토 이이마시타.
彼は行きたくないと言いました。
他说不想去。
易错易混点
  • ✗ 明日は雨です と思います。✓ 明日は雨だと思います。引用内容要用普通体：雨だと思う。です 不能直接接 と思います。
  • ✗ 明日は雨だ 思います。✓ 明日は雨だと思います。引用必须加 と：雨だと思います，不能直接连。
