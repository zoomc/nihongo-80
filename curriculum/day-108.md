## 语法

- **〜ことに（は）**：令人…的是
  接续：Verb-ta / i-Adj / na-Adj + な + ことに（は）
  朝鲜语：하게도（韩语提示按整块理解。换成日语时先套接续「Verb-ta / i-Adj / na-Adj + な + ことに（は）」，再看下面的例句。）
- **〜ことだから**：以某人的为人来看
  接续：名词 + の + ことだから
  朝鲜语：이라면 틀림없이（韩语提示按整块理解。换成日语时先套接续「名词 + の + ことだから」，再看下面的例句。）
