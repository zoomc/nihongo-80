# Day 116 · 〜ますように、〜ふりをする

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜ますように、〜ふりをする」各造一句自己的话，表达：但愿…；希望…；假装…

## 新词 24

- **何か**（なにか）某物；什么｜韩语参考：무슨（什么）<br>
  例：ここまでのところで何か落としていることはありませんか。（到这里为止，有没有落下什么东西？）
- **なにも**（なにも）什么也（不）｜韩语参考：아무것도（부정과 함께）<br>
  例：過ちのない者は何も作り出せない。（不犯错的人什么也创造不出来。）
- **鍋**（なべ）锅｜韩语参考：냄비<br>
  例：ここに手のないナベがある。（这里有一口没有把手的锅。）
- **生**（なま）生的；鲜的｜韩语参考：날것 / 신선함<br>
  例：ゴムをすると確かに性感が落ちるので、出来れば生でしたいです。（戴避孕套确实会影响感觉，所以可能的话想不用。）
- **怠ける**（なまける）懒惰；懈怠｜韩语参考：게으름 피우다<br>
  例：彼は勉強を怠けている。（他学习很懈怠。）
- **波**（なみ）波浪｜韩语参考：물결（水波，波浪） / 파도（波涛，浪涛，波浪）<br>
  例：船は波のなすがままになっている。（船随波浪摆布。）
- **涙**（なみだ）眼泪｜韩语参考：눈물（眼泪，泪水）<br>
  例：２粒の涙が彼女のほおを流れ落ちた。（两滴眼泪顺着她的脸颊流下来。）
- **悩む**（なやむ）烦恼；苦恼｜韩语参考：고민되다（苦恼，发愁） / 고민하다（苦恼，发愁）<br>
  例：悩んでも何の利益にもならない。（烦恼也没有任何好处。）
- **縄**（なわ）绳子｜韩语参考：끈（绳子，绳索，线） / 줄（绳，绳子） / 밧줄（绳子，麻绳）<br>
  例：彼は縄で木に縛り付けられた。（他被绳子绑在树上。）
- **何で**（なんで）为什么｜韩语参考：왜（为什么）<br>
  例：何で彼女はそんなことをしたのか。（她为什么做那种事？）
- **何でも**（なんでも）什么都；任何｜韩语参考：무엇이든<br>
  例：この犬は何でもほとんど食べます。（这条狗几乎什么都吃。）
- **何とか**（なんとか）设法；好歹｜韩语参考：어떻게든<br>
  例：急げば何とか間に合うと思います。（快一点的话，我想总能赶上。）
- **似合う**（にあう）适合；相配｜韩语参考：받다（相配，适合） / 어울리다（谐调，相配，般配）<br>
  例：あのドレスは彼女によく似合う。（那条连衣裙很适合她。）
- **苦手**（にがて）不擅长；怕｜韩语参考：서투르다 / 꺼리다<br>
  例：私は数学は苦手だ。（我不擅长数学。）
- **握る**（にぎる）握；掌握｜韩语参考：잡다（掌握，执掌） / 쥐다（握，攥） / 그러쥐다（掌握，掌控）<br>
  例：彼らが眠っている間私がハンドルを握った。（他们睡觉时由我握着方向盘。）
- **日**（にち）日；号｜韩语参考：일（日）<br>
  例：土日月の午前１０時半から午後４時まで開館。（周六、周日、周一上午10点半到下午4点开放。）
- **日常**（にちじょう）日常；平常｜韩语参考：일상（日常，日常生活，平常）<br>
  例：日常の運動はあなたのためになる。（日常运动对你有好处。）
- **日曜**（にちよう）星期日｜韩语参考：일요일<br>
  例：銀行は日曜にはやってません。（银行星期天不营业。）
- **日光**（にっこう）日光；阳光｜韩语参考：일광（日光） / 햇발（阳光，日光） / 햇볕（阳光，日光）<br>
  例：この部屋はあまり日光が当たらない。（这个房间晒不到多少太阳。）
- **にっこり**（にっこり）笑眯眯｜韩语参考：빙글（笑眯眯地，微微地） / 빙그레（笑眯眯地，微微地） / 해죽해죽（笑眯眯地）<br>
  例：彼女はにっこり笑ってそういった。（她笑眯眯地这样说了。）
- **日中**（にっちゅう）白天；日中｜韩语参考：날（白天） / 낮（白天，白日，日间） / 대낮（白天，大白天）<br>
  例：会社が日中合弁で経営しています。（这家公司由日中合资经营。）
- **日本**（にっぽん）日本｜韩语参考：일본<br>
  例：日本は中国の東方にある。（日本位于中国的东面。）
- **入場**（にゅうじょう）入场｜韩语参考：입장（入场，进场）<br>
  例：この切符で２名入場できます。（这张票可以两人入场。）
- **人気**（にんき）人气；受欢迎｜韩语参考：인기（人气）<br>
  例：人気がでて彼女はうぬぼれた。（走红之后她变得自负了。）

## 语法

- **〜ますように**：但愿…；希望…
  接续：动词ます形词干 + ように（ませんように 表否定祈愿）
  朝鲜语：-기를 바랍니다（韩语祈愿用「-기를 바랍니다」，需有完整主句；日语「ますように」可单独成句，主语省略，形式更短。）
- **〜ふりをする**：假装…
  接续：动词普通形/い形容词/ナ形容词な/名词の + ふりをする
  朝鲜语：-는 척하다（韩语「-는 척하다」与「ふりをする」对应；但日语「ふり」是名词，要用「〜のふり」，韩语直接接「척」。）
