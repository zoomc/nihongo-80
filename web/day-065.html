今日语法 3 条

韩语对应-는 반면에
韩语「-는 반면에」只表对比；日语「一方で」还能表“同时进行的两件事”，范围更宽。
〜一方で
발음〜이뽀우데
一方面…；同时…
普通形 + 一方で；ナ形容词 + な + 一方で；名词 + である + 一方で
并列同一事物的两个侧面，或表两件事同时进行。
インターネットは便利な一方で、危険な面もある。
互联网很方便，另一方面也有危险的一面。
코노카이샤와큐우료우가타카이이뽀우데,야스미가토테모스쿠나이.
この会社は給料が高い一方で、休みがとても少ない。
这家公司工资高，但休假很少。
카노조와카이샤데하타라쿠이뽀우데,요루와다이가쿠인니카요떼이루.
彼女は会社で働く一方で、夜は大学院に通っている。
她一边在公司上班，晚上一边读研究生。
易错点

インターネットは便利だ一方で、危険な面もある。 → 便利な一方で（ナ形容词接「一方で」要用「な」，「便利だ一方で」不合法。）

韩语对应-에 대해서
韩语「-에 대해서」只表对象；日语「に対して」还常用于前后对比，相当于韩语「-는 반면」，用法更广。
〜に対して
발음〜니타이시테
对…；与…相对
名词 + に対して；动词/い形容词/ナ形容词 + な + のに対して
表动作或态度的对象，也用于前后对比。
오캬쿠사마니타이시테,손나이이카타오시테와이케나이.
お客様に対して、そんな言い方をしてはいけない。
对客人不能那么说话。
아타라시이제이킨니타이스루한타이노코에가타카마떼이루.
新しい税金に対する反対の声が高まっている。
反对新税的声音越来越大。
토우쿄우와하레테이루노니타이시테,오오사카와아사카라오오아메다.
東京は晴れているのに対して、大阪は朝から大雨だ。
东京是晴天，而大阪从早上就下大雨。
易错点

東京は晴れているに対して、大阪は朝から大雨だ。 → 晴れているのに対して（动词、形容词小句后接对比的「に対して」要用「のに対して」，不能直接接。）

韩语对应-에 대해서
韩语「-에 대해서」与「について」基本对应；但日语修饰名词须用「についての」，韩语无此变化，容易漏写「の」。
〜について
발음〜니쓰이테
关于…
名词 + について；名词 + についての + 名词
指出谈话、思考或调查的主题。
今日の授業では、日本の食文化について話し合いました。
今天的课上我们讨论了日本饮食文化。
아타라시이쇼우힌니쓰이테노시쓰몬와,코치라노메이루아도레스마데오오쿠리쿠다사이.
新しい商品についての質問は、こちらのメールアドレスまでお送りください。
关于新产品的疑问请发到这个邮箱。
소노지켄니쓰이테,케이사쓰와마다나니모하뾰우시테이나이.
その事件について、警察はまだ何も発表していない。
关于那起事件，警方还没有任何发布。
易错点

今日の授業では、日本の食文化をについて話し合いました。 → 食文化について（「について」本身已含助词功能，不能再叠「を」。）
