# Day 097 · 〜もの / 〜もん、〜ものだから / 〜もので

- 阶段：P3｜60 分钟｜常规日
- Can-do：用「〜もの / 〜もん、〜ものだから / 〜もので」造两句自己的话，表达：因为…嘛（撒娇辩解）；因为…；由于…

## 新词 20

- **考え**（かんがえ）想法｜韩语参考：생각（念头，想法） / 소리（声音，想法，消息）<br>
  例：あなたの考えを言ってください。（请说说你的想法。）
- **感覚**（かんかく）感觉｜韩语参考：감각（感觉）<br>
  例：私は指に感覚が無かった。（我的手指没有知觉。）
- **観客**（かんきゃく）观众｜韩语参考：관객（观众） / 손님（观众，访客）<br>
  例：そのショーで観客は大喜びだった。（那场演出让观众非常开心。）
- **歓迎**（かんげい）欢迎｜韩语参考：환영（欢迎）<br>
  例：あなたはうちのクラスで歓迎されています。（你在我们班很受欢迎。）
- **観察**（かんさつ）观察｜韩语参考：관찰（观察）<br>
  例：科学は観察に基づいている。（科学建立在观察之上。）
- **感じ**（かんじ）感觉｜韩语参考：감（感觉） / 느낌（感觉，感受）<br>
  例：その部屋は居心地の良い感じがした。（那个房间让人感觉很舒服。）
- **感謝**（かんしゃ）感谢｜韩语参考：감사（感谢）<br>
  例：ご協力に感謝します。（感谢您的协助。）
- **患者**（かんじゃ）患者；病人｜韩语参考：환자（患者，病人）<br>
  例：私はあなたの第一号の患者になるわ。（我就当你的第一个病人吧。）
- **勘定**（かんじょう）结账；计算｜韩语参考：셈（计算，清点） / 계산（计算）<br>
  例：勘定は合計５００ドルになる。（账算下来一共五百美元。）
- **感情**（かんじょう）感情｜韩语参考：감정（感情）<br>
  例：声の調子が感情を伝える事もある。（语调有时也能传达感情。）
- **感じる**（かんじる）感觉；感到｜韩语参考：알다（感到） / 감각하다（感觉）<br>
  例：私はときどき悲しく感じる。（我有时会感到悲伤。）
- **感心**（かんしん）佩服｜韩语参考：감복（佩服，钦佩） / 탄복（叹服，佩服，钦佩）<br>
  例：私はむすこの才能にいささか感心している。（我对儿子的才能有点佩服。）
- **関心**（かんしん）兴趣；关心｜韩语参考：관심（关注，关心，兴趣）<br>
  例：私は美術に非常な関心を抱いています。（我对美术非常有兴趣。）
- **関する**（かんする）关于｜韩语参考：관하다（关于）<br>
  例：彼女は動物に関する本を書いた。（她写了一本关于动物的书。）
- **完成**（かんせい）完成｜韩语参考：완성（完成）<br>
  例：新しい鉄道はまだ完成していない。（新铁路还没有完工。）
- **完全**（かんぜん）完全；完美｜韩语参考：완전（完全，完整，完美）<br>
  例：完全を求めるとかえって失敗する。（一味追求完美反而会失败。）
- **監督**（かんとく）导演；监管｜韩语参考：감독（教练，导演）<br>
  例：その店は警察の監督のもとにある。（那家店处在警方的监管之下。）
- **管理**（かんり）管理｜韩语参考：관리（管理，掌管）<br>
  例：彼に財産管理を任せた。（我把财产管理交给了他。）
- **完了**（かんりょう）完成｜韩语参考：완료（完了，完成）<br>
  例：君たちいつ準備は完了するつもりだい。（你们打算什么时候准备好？）
- **関連**（かんれん）关联｜韩语参考：연관（关联，相关，有关，联系）<br>
  例：この事実はお互いに関連し合っている。（这些事实彼此相关联。）

## 语法

- **〜もの / 〜もん**：因为…嘛（撒娇辩解）
  接续：普通形 + もの／もん（多与「だって」呼应）
  朝鲜语：-니까(요)（韩语「-니까(요)」只表原因，不带撒娇色彩；日语「もん」几乎总带“我也有苦衷”的辩解语气，只用于亲近关系。）
- **〜ものだから / 〜もので**：因为…；由于…
  接续：普通形 + ものだから；ナ形容词 + な + ものだから；名词 + な + ものだから
  朝鲜语：-는 통에（韩语「-는 통에」多引出坏结果；日语「ものだから」不限好坏，重点在“说明并求得谅解”，语气更软。）

## 汉字 4

- **断** 切断；拒绝；判断｜音：ダン｜训：た.つ、ことわ.る、さだ.める
- **石** 石头｜音：セキ、シャク、コク｜训：いし
- **違** 不同；违背｜音：イ｜训：ちが.う、ちが.い、ちが.える、-ちが.える、たが.う、たが.える
- **消** 消失；熄灭；消除｜音：ショウ｜训：き.える、け.す
