Day 031 · V ます形(去ます) + やすい / にくい、Vます形(去ます)/い形(去い)/な形词干 + すぎる、あげる / くれる / もらう

语法 3 条

V ます形(去ます) + やすい / にくい
발음V 마스카타치 + 야스이 / 니쿠이
容易…／难以…
動詞 ます形 去 ます + やすい・にくい；整体按 い形容詞 变形（読みやすくない／読みやすかった）
表示做该动作的难易程度（不是能力），主语多用 が；偏客观属性
韩语对应-기 쉽다 / -기 어렵다
쓰기 쉽다／쓰기 어렵다 对照 書きやすい／書きにくい。韩语用 -기 把动作名词化；日语先找 ます形，再去 ます。
코노혼 와 요미야스이데스.
この本は読みやすいです。
这本书好读。
코노펜 와 카키니쿠이데스.
このペンは書きにくいです。
这支笔不好写。
易错易混点
  • ✗ この本は読むやすいです。✓ この本は読みやすいです。やすい 接ます形词干（読みやすい），不接辞书形。
  • ✗ この問題は分かりやすいでした。✓ この問題は分かりやすかったです。やすい 按い形容词变化，过去是 やすかった。
Vます形(去ます)/い形(去い)/な形词干 + すぎる
过于…；…得过头
动词ます形去 ます、い形容词去 い、な形容词用词干 + すぎる；如 食べすぎる／熱すぎる／静かすぎる。
超过适度；な形/名词直接接（静かすぎる／甘すぎる），不加 な；食べすぎる 是复合动词
韩语对应너무 / -기에는 너무
韩语너무是副词，直接修饰谓语；日语すぎる是后缀，须接词干，且可单独作谓语。
타베스기테오하라 가 이타이데스.
食べすぎてお腹が痛いです。
吃多了肚子疼。
코노쿠쓰 와 타카스기마스.
この靴は高すぎます。
这鞋太贵了。
易错易混点
  • ✗ 食べるすぎます。✓ 食べすぎます。すぎる 接ます形词干（食べすぎる），不接辞书形。
  • ✗ 静かなすぎます。✓ 静かすぎます。な形容词接 すぎる 要去掉 な：静かすぎる。
あげる / くれる / もらう
발음아게루 / 쿠레루 / 모라우
给…；别人给我…；从…得到
给予者 は/が 接受者 に 物 を あげる；给予者 が 我方 に 物 を くれる；接受者 は 给予者 に/から 物 を もらう
按给与方向和视角选择：我给别人用あげる，别人给我用くれる，我收到用もらう。
韩语对应주다 / 받다
韩语 주다 不分方向，日语必须按「谁给谁」区分 あげる／くれる；韩语 받다 对应 もらう，但日语 もらう 的来源可用 に 或 から。
와타시 와 오토우토 니 후루이게이무 오 아게타.
私は弟に古いゲームをあげた。
我把旧的游戏机给了弟弟。
아네 가 탄조우비 니 카와이이카반 오 쿠레마시타.
姉が誕生日にかわいいかばんをくれました。
姐姐在我生日时送了我一个可爱的包。
토모다치 카라 료코우 노 오미야게 오 모라따.
友達から旅行のおみやげをもらった。
我收到了朋友旅行带回来的特产。
易错易混点
  • ✗ 私は弟に古いゲームをくれた。✓ 私は弟に古いゲームをあげた。くれる 的给予者必须是他人，不能是「私」；我给别人要用 あげる
