# Day 070 · 〜気がする、〜ずに、〜まま

- 阶段：P3｜60 分钟｜常规日
- Can-do：在单选题中辨认今天的词义、读音和句型用法。

## 语法

- **〜気がする**：感觉…；总觉得…
  接续：普通形 + 気がする；ナ形容词 + な + 気がする；名词 + の + ような + 気がする
  朝鲜语：-(으)ㄴ/는 것 같다 / …한 느낌이 들다（「好像在哪儿见过」可说 어디선가 본 것 같다，对照 どこかで会った気がする。気がする 常把它说成自己的隐约感觉。）
- **〜ずに**：不…就…；没…而…
  接续：动词ない形词干 + ずに（する→せずに）
  朝鲜语：-지 않고（-지 않고 对照 ないで／ずに。ずに 常见于较正式的叙述，普通会话也能用。する 是例外，写 せずに。）
- **〜まま**：就那样…；保持着…
  接续：动词た形/ない形 + まま；い形容词 + まま；ナ形容词 + な + まま；名词 + の + まま
  朝鲜语：-ㄴ 채로（韩语「-ㄴ 채로」与「まま」很接近；但日语可接名词「〜のまま」，韩语没有对应形式，要改说「그대로」。）
