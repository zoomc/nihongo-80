# Day 135 · 〜ということだ

- 阶段：P4｜60 分钟｜常规日
- Can-do：用「〜ということだ」造两句自己的话，表达：据说…；也就是说…

## 新词 22

- **地位**（ちい）地位｜韩语参考：지위（地位）<br>
  例：彼は会社で高い地位にあります。（他在公司地位很高。）
- **地域**（ちいき）地区；区域｜韩语参考：지역（地域，地区，区域） / 지구（地区）<br>
  例：この地域は雨が続くでしょう。（这个地区会持续下雨吧。）
- **チーズ**（チーズ）奶酪｜韩语参考：치즈（奶酪）<br>
  例：ジョージは朝にたくさんのチーズを食べた。（乔治早上吃了很多奶酪。）
- **チーム**（チーム）团队；队｜韩语参考：팀（组，小组，团队）<br>
  例：彼はチームでダントツの好選手だ。（他是队里遥遥领先的好选手。）
- **知恵**（ちえ）智慧｜韩语参考：지혜（智慧） / 슬기（智慧）<br>
  例：彼は知恵のある人だ。（他是个有智慧的人。）
- **地下**（ちか）地下；地下室｜韩语参考：지하（地下）<br>
  例：彼は地下活動の疑いをかけられた。（他被怀疑从事地下活动。）
- **違い**（ちがい）差别；不同｜韩语参考：차이（差异，差别） / 차이점（差异，不同点）<br>
  例：実際両者にはほとんど違いがない。（实际上两者几乎没有差别。）
- **違いない**（ちがいない）一定；肯定｜韩语参考：틀림없다<br>
  例：再婚した今、彼はもっと幸福に違いない。（再婚之后，他现在一定更幸福。）
- **近頃**（ちかごろ）近来；最近｜韩语参考：근래（近来，最近） / 요새（近来，日来，最近） / 요즘（最近，近来，这阵子）<br>
  例：近ごろ彼女から便りがない。（最近没有她的消息。）
- **地球**（ちきゅう）地球｜韩语参考：지구（地球）<br>
  例：彼らは地球が平らであると信じた。（他们相信地球是平的。）
- **地区**（ちく）地区｜韩语参考：지구（地区）<br>
  例：あなたはこの地区をよく知っていますか。（你熟悉这一地区吗？）
- **遅刻**（ちこく）迟到｜韩语参考：지각（迟到）<br>
  例：遅刻するのではないかと心配した。（我担心会不会迟到。）
- **知事**（ちじ）知事；县长｜韩语参考：지사（일본 광역자치단체장）<br>
  例：彼は知事と長年の付き合いです。（他和知事有多年的交情。）
- **知識**（ちしき）知识｜韩语参考：지식（知识）<br>
  例：私のドイツ語の知識は貧弱です。（我的德语知识很贫乏。）
- **父親**（ちちおや）父亲｜韩语参考：부친（父亲） / 아버지（父亲，爸爸）<br>
  例：その少年は父親に似ている。（那个少年像他父亲。）
- **知能**（ちのう）智能；智力｜韩语参考：지능（智能）<br>
  例：イルカは非常に知能の高い動物です。（海豚是智力非常高的动物。）
- **地平線**（ちへいせん）地平线｜韩语参考：지평선（地平线） / 지평（地平线）<br>
  例：月が地平線の上にあった。（月亮在地平线上方。）
- **地方**（ちほう）地方；地区｜韩语参考：지방（地区） / 고장（地方，家乡）<br>
  例：彼は今年の夏、東北地方を旅行した。（今年夏天他到东北地区旅行了。）
- **茶**（ちゃ）茶；棕色｜韩语参考：차（茶，茶水）<br>
  例：その猫の一方は黒で、もう一方は茶だ。（那两只猫一只是黑的，另一只是棕色的。）
- **チャンス**（チャンス）机会｜韩语参考：기회（机会，机遇，时机）<br>
  例：お願いだ！俺にチャンスをくれ。（求你了！给我一次机会。）
- **ちゃんと**（ちゃんと）好好地；确实｜韩语参考：제대로<br>
  例：この道具はちゃんと使えばとても役に立つ。（这个工具好好使用的话非常有用。）
- **中**（ちゅう）中；其中｜韩语参考：중（中，中等）<br>
  例：１０人中３人はビデオを持っている。（十个人中有三个人有录像机。）

## 语法

- **〜ということだ**：据说…；也就是说…
  接续：普通形 + ということだ
  朝鲜语：-다는 것이다（韩语「-다는 것이다」与「ということだ」对应；但日语同一形式兼表传闻和“也就是说”，韩语要靠不同形式区分。）
