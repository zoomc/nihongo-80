# Day 113 · 租房与邻居｜〜ほど、〜くらい / 〜ぐらい（extent）

- 阶段：P3｜60 分钟｜听力日
- Can-do：在「租房与邻居」场景里，用 〜ほど 说清一件事

## 新词 14

- **指す**（さす）指；指向  
  例：＆という記号は、ａｎｄを指す。（「＆」这个符号指的是 and。）
- **座席**（ざせき）座位｜朝鲜语：좌석  
  例：鞄を座席の下に置いてください。（请把包放在座位下面。）
- **誘う**（さそう）邀请；引诱  
  例：ウラウラとした日差しに誘われて、眠りに落ちた。（暖洋洋的阳光让人犯困，我不知不觉睡着了。）
- **札**（さつ）纸币  
  例：１０００円札をくずしていただけませんか。（能帮我把一千日元换开吗？）
- **作家**（さっか）作家｜朝鲜语：작가  
  例：その作家は私たちによく知られています。（那位作家我们很熟悉。）
- **作曲**（さっきょく）作曲｜朝鲜语：작곡  
  例：この音楽はバッハによって作曲された。（这首曲子是巴赫作的。）
- **ざっと**（ざっと）大致；粗略  
  例：私はパンフレットにざっと目をとおした。（我大致浏览了一遍小册子。）
- **さっぱり**（さっぱり）清爽；完全（不）  
  例：私はこの手のことにはさっぱりだ。（这类事我完全不懂。）
- **さて**（さて）那么  
- **砂漠**（さばく）沙漠｜朝鲜语：사막  
  例：サハラは広大な砂漠です。（撒哈拉是一片广阔的沙漠。）
- **差別**（さべつ）歧视；区别｜朝鲜语：차별  
  例：その週間は差別とは関係がなかった。（那一周和歧视问题没有关系。）
- **作法**（さほう）礼节；礼法  
  例：彼は作法がぎこちない。（他的礼节举止很生硬。）
- **様々**（さまざま）各种各样  
  例：庭には様々な花が咲き乱れていた。（院子里各种花开得繁盛。）
- **覚ます**（さます）弄醒；醒  
  例：その物音が私を眠りから覚まさせた。（那声响把我从睡梦中弄醒了。）

## 语法

- **〜ほど**：到了…的程度
  接续：普通形 + ほど；名词 + ほど
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」与「ほど」基本对应；但日语「ほど」还用于「〜ほど〜ない」比较句，韩语要用「-만큼」。）
- **〜くらい / 〜ぐらい（extent）**：到…地步；至少…
  接续：普通形 + くらい／ぐらい；名词 + くらい
  朝鲜语：-ㄹ 정도로（韩语「-ㄹ 정도로」对应程度用法；“至少”韩语要说「적어도」，日语用「くらい」一并承担，范围更宽。）

## 汉字 4

- **命** 生命；命令｜音：メイ、ミョウ｜训：いのち
- **福** 福气；幸福｜音：フク｜训：
- **望** 希望；眺望｜音：ボウ、モウ｜训：のぞ.む、もち
- **非** 非；错误；否定｜音：ヒ｜训：あら.ず
