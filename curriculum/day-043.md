# Day 043 · 〜てしまう / 〜ちゃう、〜ておく、〜てみる

- 阶段：P2｜60 分钟｜听力日
- Can-do：用「〜てしまう / 〜ちゃう、〜ておく、〜てみる」造两句自己的话，表达：…完了；不小心…；结果…；预先…好；…着（保持状态）；试着做…（看看效果）

## 新词 20

- **このごろ**（このごろ）近来｜韩语参考：요즘<br>
  例：このごろは読書する時間が少しはある。（近来多少有点读书的时间。）
- **細かい**（こまかい）细小；琐碎｜韩语参考：잘다（细小） / 가늘다（细，细小，细碎） / 사소하다（琐碎，微不足道）<br>
  例：彼はひどく金に細かい。（他在钱上斤斤计较。）
- **ごみ**（ごみ）垃圾｜韩语参考：쓰레기（垃圾）<br>
  例：毎週月曜日にゴミを集めにきます。（每周一来收垃圾。）
- **込む**（こむ）拥挤｜韩语参考：붐비다（拥挤）<br>
  例：今晩は列車がとても込んでいる。（今晚列车非常拥挤。）
- **米**（こめ）米｜韩语参考：쌀（米，大米）<br>
  例：日本人は米を食べて生きている。（日本人靠吃米生活。）
- **ごらんになる**（ごらんになる）看（敬）｜韩语参考：보시다（높임）<br>
  例：私たちの新居をご覧になってはいかがですか。（您来看看我们的新居怎么样？）
- **これから**（これから）今后｜韩语参考：지금부터 / 앞으로<br>
  例：これからも人生を楽しんでください。（今后也请享受人生。）
- **怖い**（こわい）可怕｜韩语参考：무섭다（怕，害怕，可怕，恐惧）<br>
  例：私は怖かったよりもびっくりした。（我与其说害怕，不如说吓了一跳。）
- **壊す**（こわす）弄坏｜韩语参考：버리다（弄坏，毁） / 부수다（弄坏，毁坏） / 망가뜨리다（破坏，打碎，弄坏，整坏）<br>
  例：その事が彼のすべての夢を壊した。（那件事打碎了他所有的梦想。）
- **壊れる**（こわれる）坏掉｜韩语参考：고장 나다 / 부서지다<br>
  例：このイヤホンは壊れています。（这副耳机坏了。）
- **コンサート**（コンサート）音乐会｜韩语参考：음악회（音乐会）<br>
  例：コンサートはどうだった？（音乐会怎么样？）
- **今度**（こんど）这次；下次｜韩语参考：담（以后，下次） / 금번（这一次，这次，此次，此回） / 다음（以后，下次）<br>
  例：今度の土曜日、テニスをしませんか。（这个星期六去打网球吧？）
- **コンピュータ**（コンピュータ）电脑｜韩语参考：컴퓨터<br>
  例：そのコンピューターは新しいです。（那台电脑是新的。）
- **今夜**（こんや）今晚｜韩语参考：오늘 밤<br>
  例：今夜、パーティーを開きます。（今晚举行派对。）
- **最近**（さいきん）最近｜韩语参考：최근（最近；近来） / 근래（近来，最近） / 요즘（最近，近来，这阵子）<br>
  例：最近は読書の時間がほとんどない。（最近几乎没有读书的时间。）
- **最後**（さいご）最后｜韩语参考：최후（最后） / 끝（尽头，最后，终） / 마지막（最后，最终，末了）<br>
  例：最後の試験は来月にまたがるだろう。（最后一场考试大概会拖到下个月。）
- **最初**（さいしょ）最初｜韩语参考：최초（最初） / 애초（最初，当初） / 초두（起初，最初）<br>
  例：私は最初からその事は知っていた。（那件事我一开始就知道。）
- **坂**（さか）坡道｜韩语参考：비탈길<br>
  例：私は何度も転びながら、坂を下っていった。（我摔了好几次，一路走下了坡。）
- **探す**（さがす）寻找｜韩语参考：찾다（寻，觅，访，寻找，查）<br>
  例：私は貸間を探しているところです。（我正在找出租的房子。）
- **下がる**（さがる）下降｜韩语参考：내리다（下降，下跌） / 내려가다（降，下降） / 하락하다（下落，下降）<br>
  例：ロープから下がっていなさい。（抓住绳子往下退。）

## 语法

- **〜てしまう / 〜ちゃう**：…完了；不小心…；结果…
  接续：动词て形 + しまう（口语缩约 ちゃう／じゃう）
  朝鲜语：-아/어 버리다（韩语 -아/어 버리다 同样表完成或遗憾，语气很接近；但日语 しまう 还可中性表「全部做完」，韩语 버리다 的懊悔色彩更强。）
- **〜ておく**：预先…好；…着（保持状态）
  接续：动词て形 + おく（口语缩约 とく）
  朝鲜语：-아/어 두다（韩语 -아/어 두다 也表预先做好并保持状态，对应度很高；日语口语缩约 とく 在韩语中没有同类的音变形式。）
- **〜てみる**：试着做…（看看效果）
  接续：动词て形 + みる
  朝鲜语：-아/어 보다（韩语 -아/어 보다 与 てみる 基本对应；但日语 てみる 只能接动作动词，韩语 보다 的搭配范围略宽。）
