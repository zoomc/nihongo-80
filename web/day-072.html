Day 072 · 〜ほど、〜くらい / 〜ぐらい（extent）、〜さえ

语法 3 条

〜ほど
발음〜호도
到了…的程度
普通形 + ほど；名词 + ほど
举出极端例子说明程度之高，常与「〜ない」呼应表最高级。
韩语对应-ㄹ 정도로
韩语「-ㄹ 정도로」与「ほど」基本对应；但日语「ほど」还用于「〜ほど〜ない」比较句，韩语要用「-만큼」。
키노우 와, 타떼이라레나이 호도 쓰카레테이타.
昨日は、立っていられないほど疲れていた。
昨天累得站都站不住。
시켄 니 고우카쿠시타 토 키이테, 나미다 가 데루 호도 우레시카따.
試験に合格したと聞いて、涙が出るほどうれしかった。
听说考试合格，高兴得流下眼泪。
코노아타리 와, 요루 니 나루토코와이 호도 시즈카다.
このあたりは、夜になると怖いほど静かだ。
这一带到了晚上静得让人害怕。
易错易混点
  • ✗ このあたりは、夜になると怖いなほど静かだ。✓ 怖いほどい形容词直接接 ほど，不加 な。
〜くらい / 〜ぐらい（extent）
발음〜쿠라이 / 〜구라이
到…地步；至少…
普通形 + くらい／ぐらい；名词 + くらい
表程度之高，或举最低限度的例子表“至少”。
韩语对应-(으)ㄹ 정도로
울 것 같을 정도로 무서웠다 对照 泣きそうなくらい怖かった。数字后的 くらい 表大约，语气里表示程度的 くらい 常跟 ほど 接近。
오나카 가 이타쿠테, 아루케나이 쿠라이 다따.
おなかが痛くて、歩けないくらいだった。
肚子疼得几乎走不动。
토나리 노 헤야 노 온가쿠 가 우루사쿠테, 지분 노 코에 모 키코에나이 구라이 다.
隣の部屋の音楽がうるさくて、自分の声も聞こえないぐらいだ。
隔壁音乐太吵，连自己的声音都听不见。
지분 노 헤야 구라이, 지분 데 소우지시나사이.
自分の部屋ぐらい、自分で掃除しなさい。
至少自己的房间自己打扫。
易错易混点
  • ✗ おなかが痛くて、歩けないのくらいだった。✓ 歩けないくらいだった动词、い形容词直接接 くらい，不加 の。
〜さえ
발음〜사에
连…都…
名词 + さえ／でさえ／にさえ
挑出一个意外、极端或本应容易满足的例子，强调「连……都」。
韩语对应-조차
-조차 对照「连…都」，如 이름조차 잊었다／名前さえ忘れた。后面是 ば 时，さえ 又可限定最低条件。
이소가시쿠테, 히루고한 오 타베루지칸 사에 나카따.
忙しくて、昼ご飯を食べる時間さえなかった。
忙得连吃午饭的时间都没有。
콘나칸탄나몬다이 와, 쇼우가쿠세이 데 사에 토케루.
こんな簡単な問題は、小学生でさえ解ける。
这么简单的问题，连小学生都会。
카노조 와 신유우 니 사에 혼토우 노 코토 오 하나시사나카따.
彼女は親友にさえ本当のことを話さなかった。
她连最好的朋友都没说实话。
易错易混点
  • ✗ 忙しくて、昼ご飯を食べる時間がさえなかった。✓ 時間さえなかったさえ 取代 が／を，不能说 時間がさえ。
