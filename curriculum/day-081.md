# Day 081 · 普通形 + に 違いない、普通形 + わけが ない / V辞書形 + わけには いかない

- 阶段：P2｜60 分钟｜常规日
- Can-do：用「普通形 + に 違いない、普通形 + わけが ない / V辞書形 + わけには いかない」造两句自己的话，表达：一定是…；肯定…（强烈推断）；不可能…／不能…（わけにはいかない）

## 新词 20

- **当たる**（あたる）碰；照；中｜韩语参考：맞다（对，中，正确）<br>
  例：私は顔に冷たい風が当たるのを感じた。（我感到冷风吹在脸上。）
- **あちこち**（あちこち）到处｜韩语参考：곳곳（到处，各地，处处，各处） / 여기저기（到处，这里那里） / 요기조기（这里那里，这儿那儿，到处）<br>
  例：本が部屋のあちこちに散らばっていた。（书散落在房间各处。）
- **あっ**（あっ）啊｜韩语参考：참（啊）<br>
  例：あっ、財布を忘れた。（啊，忘带钱包了。）
- **扱う**（あつかう）处理；对待｜韩语参考：다루다（处理，办理） / 취급하다（处理，处置）<br>
  例：心理学は人間の感情を扱う。（心理学研究人的情感。）
- **集まり**（あつまり）聚会｜韩语参考：모임<br>
  例：ごく内輪の集まりなのです。（是个很小的内部聚会。）
- **当てる**（あてる）碰；猜｜韩语参考：대다（接触，碰，贴）<br>
  例：かろうじて車に当てられずにすんだ。（好不容易才没被车撞到。）
- **あと**（あと）痕迹｜韩语参考：흔적<br>
  例：その女性の顔には悲しみの跡があった。（那位女士脸上带着悲伤的痕迹。）
- **穴**（あな）洞｜韩语参考：구멍（窟窿，洞，孔）<br>
  例：注意して！道路に穴があいてるよ。（小心！路上有个洞。）
- **油**（あぶら）油｜韩语参考：기름（油）<br>
  例：オリーブの実から油が取れます。（橄榄果可以榨油。）
- **誤り**（あやまり）错误｜韩语参考：오류（谬误，错误） / 잘못（错，错误） / 착오（错误，谬误）<br>
  例：私の誤りは彼の怒りを招いた。（我的错误招来了他的怒气。）
- **粗**（あら）瑕疵｜韩语参考：허물（毛病，缺点，缺陷，短处，瑕疵）<br>
  例：あら、アンジェラと呼んでください。（哎呀，请叫我安杰拉。）
- **嵐**（あらし）暴风雨｜韩语参考：폭풍（暴风，飓风，狂风） / 폭풍우（暴风雨，狂风暴雨，狂风骤雨）<br>
  例：この風は嵐の印だ。（这风是暴风雨的前兆。）
- **新た**（あらた）新的｜韩语参考：새롭다<br>
  例：彼女は記憶を新たにするためにその写真を見た。（她看那张照片来刷新记忆。）
- **あらゆる**（あらゆる）所有｜韩语参考：모든（全，所有）<br>
  例：私はあらゆる言論の自由に賛成だ。（我赞成人人都有言论自由。）
- **現す**（あらわす）显现｜韩语参考：드러내다（露出，显现）<br>
  例：＆のマークはａｎｄの文字を表す。（「＆」这个符号表示 and。）
- **表す**（あらわす）表示；表达｜韩语参考：나타내다（表示，露出） / 표현하다（表达，表示，表述）<br>
  例：＆のマークはａｎｄの文字を表す。（「＆」这个符号表示 and。）
- **現れ**（あらわれ）体现｜韩语参考：표현 / 나타남<br>
  例：それは彼女の性格の表れだ。（那是她性格的体现。）
- **現れる**（あらわれる）出现｜韩语参考：서다（有，出现） / 나타나다（出现，露面） / 출현하다（出现）<br>
  例：２０人の警官が現場に現れた。（二十名警察出现在现场。）
- **或**（ある）某个｜韩语参考：어떤<br>
  例：ある学生に会うところです。（正要见某个学生。）
- **あるいは**（あるいは）或者；也许｜韩语参考：또는（或，或者，要么） / 혹은（或者）<br>
  例：ガスで調理しますか、あるいは電気ですか。（用煤气做饭，还是用电。）

## 语法

- **普通形 + に 違いない**：一定是…；肯定…（强烈推断）
  接续：動詞・い形 普通形 / 名詞・な形 词干（＋である 可省）+ に違いない；礼貌体 に違いありません
  朝鲜语：-(으)ㄹ 것이 틀림없다（韩语用틀림없다、분명하다表强推断，语气偏书面；日常更多用것 같다，弱于に違いない。）
- **普通形 + わけが ない / V辞書形 + わけには いかない**：不可能…／不能…（わけにはいかない）
  接续：普通形 + わけがない（强烈否定可能性）；辞書形 + わけにはいかない（因情理/规则不能做）
  朝鲜语：-(으)ㄹ 리가 없다 / -(으)ㄹ 수는 없다（韩语ㄹ 리가 없다表绝无可能，ㄹ 수는 없다表情理上不能；两形区分与日语相近。）
