今日语法 2 条

〜だろう
动词普通形／い形容词／な形容词／名词 + だろう
〜だろう
大概…吧
表示说话人的推测，把握较大，口语常用。
明日はたぶん晴れるだろう。
明天大概会晴吧。
彼女はもう家に着いただろう。
她大概已经到家了吧。
この問題は子どもには難しいだろうと思います。
我觉得这个问题对孩子来说大概太难了。
朝鲜语：-(으)ㄹ 것이다 / -겠다
韩语 -(으)ㄹ 것이다 与 だろう 对应，-겠다 更偏主观意志或推测；日语 だろう 只表推测，不表意志。
易错点

明日はたぶん晴れるでしょうだ。 → 明日はたぶん晴れるでしょう。（でしょう 已是礼貌断定，不能再加 だ）

〜んです / 〜のです
动词普通形／い形容词 + んです；な形容词+な／名词+な + んです
〜んです / 〜のです
（解释）是…的；因为…
用于说明原因、补充背景，或向对方寻求解释，口语色彩强。
どうしたんですか。顔色が悪いですよ。
怎么了？你脸色不太好。
すみません、遅れました。電車が止まっていたんです。
对不起我迟到了，因为电车停运了。
日本語で手紙を書きたいんですが、手伝ってくれませんか。
我想用日语写封信，你能帮我吗？
朝鲜语：-ㄴ/는 것이다 / -거든요
韩语 -거든요 与 んです 的解释语气接近，但日语 んです 还可用于提问求解释；韩语 거든요 只用于陈述。
易错点

電車が止まっていたのだです。 → 電車が止まっていたんです。（のだ 接礼貌体是「のです」，不能作「のだです」）
