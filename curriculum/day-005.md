# Day 005 · を（宾语／移动经过）、に（时点／归着点／存在场所／对象）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「を（宾语／移动经过）、に（时点／归着点／存在场所／对象）」造两句自己的话，表达：把…（标宾语）；在／于／向…

## 新词 20

- **肉**（にく）肉｜韩语参考：살（肉） / 고기（肉）<br>
  例：肉を買います。（买肉。）
- **魚**（さかな）鱼｜韩语参考：물고기 / 생선（문맥에 따라）<br>
  例：魚が好きです。（喜欢鱼。）
- **野菜**（やさい）蔬菜｜韩语参考：야채（蔬菜） / 채소（菜，蔬菜）<br>
  例：野菜を買います。（买蔬菜。）
- **パン**（パン）面包｜韩语参考：빵（面包）<br>
  例：パンを食べます。（吃面包。）
- **料理**（りょうり）菜肴；烹饪｜韩语参考：요리（烹饪，烹调）<br>
  例：料理を作ります。（做菜。）
- **電車**（でんしゃ）电车（轨道交通）｜韩语参考：전차（电车） / 전동차（电动车，电车）<br>
  例：電車で行きます。（坐电车去。）
- **バス**（バス）公交车｜韩语参考：버스（公共汽车，公交车）<br>
  例：バスに乗ります。（上公交。）
- **車**（くるま）汽车；车｜韩语参考：차（车，车辆） / 자동차（汽车）<br>
  例：車で会社へ行きます。（开车去公司。）
- **自転車**（じてんしゃ）自行车｜韩语参考：자전거（自行车）<br>
  例：自転車で学校へ行きます。（骑车去学校。）
- **飛行機**（ひこうき）飞机｜韩语参考：비행기（飞机）<br>
  例：飛行機で旅行します。（坐飞机旅行。）
- **父**（ちち）(我)父亲｜韩语参考：아버지（父亲，爸爸）<br>
  例：父は会社員です。（我父亲是公司职员。）
- **母**（はは）(我)母亲｜韩语参考：어머니（母亲，妈妈）<br>
  例：母は医者です。（我母亲是医生。）
- **兄**（あに）(我)哥哥｜韩语参考：형（哥，哥哥） / 오빠（哥哥） / 오라비（哥哥）<br>
  例：兄は東京にいます。（我哥哥在东京。）
- **姉**（あね）(我)姐姐｜韩语参考：누나（姐姐） / 언니（姐姐）<br>
  例：姉は学生です。（我姐姐是学生。）
- **弟**（おとうと）(我)弟弟｜韩语参考：동생（弟弟；妹妹） / 아우（弟弟） / 남동생（弟弟）<br>
  例：弟に本を貸します。（借书给弟弟。）
- **妹**（いもうと）(我)妹妹｜韩语参考：동생（弟弟；妹妹） / 여동생（妹妹） / 누이동생（妹妹）<br>
  例：妹は元気です。（我妹妹很精神。）
- **家族**（かぞく）家人；家庭｜韩语参考：가족（家庭，家人） / 식구（家人）<br>
  例：家族と旅行します。（和家人旅行。）
- **子供**（こども）孩子；小孩｜韩语参考：애（孩子，小孩） / 아이（小孩，孩子） / 어린애（小孩）<br>
  例：子供が公園にいます。（孩子在公园。）
- **彼**（かれ）他；男朋友｜韩语参考：그（他）<br>
  例：彼は学生です。（他是学生。）
- **彼女**（かのじょ）她；女朋友｜韩语参考：그녀（她） / 여자 친구（女朋友）<br>
  例：彼女は元気です。（她很精神。）

## 语法

- **を（宾语／移动经过）**：把…（标宾语）
  接续：名詞 + を + 他動詞
  朝鲜语：을/를（韩语宾格助词按收音选을/를，口语可省略；日语を还能表移动经过，韩语该义也用를。）
- **に（时点／归着点／存在场所／对象）**：在／于／向…
  接续：名詞 + に
  朝鲜语：에 / 에게（韩语存在场所用에，人的对象用에게/한테；日语に一形多义，韩语须按对象分开。）

- **毎** 每｜音：マイ｜训：
- **週** 周；星期｜音：シュウ｜训：
- **曜** 曜；星期｜音：ヨウ｜训：
