今日语法 3 条

〜だけでなく
발음〜다케데나쿠
不仅…而且…
普通形 + だけでなく；な形容词可接词干（上手だけでなく）或 な；名词直接接
追加事项，后项常用「も」，是口语化的“不仅…而且”。
韩语对应-뿐만 아니라
韩语「-뿐만 아니라」也可表示追加；日语な形容词既可见词干直接接「だけでなく」，也可用「なだけでなく」，应按实际表达判断。
코노미세 와 료우리 가 오이시이 다케 데나쿠, 네단 모 야스이.
この店は料理がおいしいだけでなく、値段も安い。
这家店不仅菜好吃，价格也便宜。
지신 노 아토, 미즈 다케 데나쿠덴키 모 토마떼시마따.
地震の後、水だけでなく電気も止まってしまった。
地震后不仅停水，连电也停了。
彼女は歌が上手なだけでなく、自分で曲も作っている。
她不仅唱得好，还自己作曲。

易错点 日本語だけなくて、中国語も話します。 → 日本語だけでなく、中国語も話します。（并列补充可用「だけでなく」，不能写成「だけなくて」。）

〜さえ〜ば
발음〜사에〜바
只要…就…
名词 + さえ + ば形；动词ます形词干 + さえ + すれば；动词て形 + さえ + いれば
表示只要满足这一条件，其余都不成问题。
韩语对应-기만 하면
韩语「-기만 하면」与「さえ〜ば」对应；但日语「さえ」位置固定在各成分后，韩语统一贴在动词后，语序处理不同。
코노아푸리 사에 아레바, 도코 데모 니혼고 노 벤쿄우 가 데키루.
このアプリさえあれば、どこでも日本語の勉強ができる。
只要有这个应用，在哪儿都能学日语。
지칸 사에 아레바, 모또료코우 니 이키타인데스가.
時間さえあれば、もっと旅行に行きたいんですが。
只要有时间，我还想多去旅行。
쿠스리 오 논데네테 사에 이레바, 스구 니 나오리마스 요.
薬を飲んで寝てさえいれば、すぐに治りますよ。
只要吃了药好好躺着，很快就会好。

易错点 このアプリさえあってば、どこでも日本語の勉強ができる。 → さえあれば（「さえ」后要接ば形「あれば」，「あってば」不合法。）

〜こそ
발음〜코소
正是…；才是…
名词 + こそ（可加「が」成「こそが」）
强烈提示焦点，表“正是这个，不是别的”。
韩语对应-야말로
韩语「-야말로」与「こそ」几乎一致；但日语「こちらこそ」已成固定寒暄，韩语对应「저야말로」，礼貌度需注意。
「이쓰모아리가토우.」「이에, 코치라 코소.」
「いつもありがとう。」「いえ、こちらこそ。」
“一直谢谢你。”“不，我才是。”
코토시 코소, 타바코 오 야메루쓰모리다.
今年こそ、たばこをやめるつもりだ。
今年我一定要把烟戒掉。
마이니치 노 치이사나도료쿠 코소 가, 오오키나세이코우 니 쓰나가루.
毎日の小さな努力こそが、大きな成功につながる。
正是每天的小努力带来了巨大的成功。

易错点 毎日の小さな努力をこそが、大きな成功につながる。 → 努力こそが（「こそ」可与「が」连用成「こそが」，但不能叠在「を」后再接「が」。）
