今日语法 1 条

韩语对应한 사실로 보아
韩语提示按整块理解。换成日语时先套接续「动词普通形 / i-Adj / na-Adj + な / na-Adj + である / 名词 + である + ことから」，再看下面的例句。
〜ことから
발음〜코토카라
从…这一事实推断
动词普通形 / i-Adj / na-Adj + な / na-Adj + である / 名词 + である + ことから
この坂は、昔から桜の名所であることから「桜坂」と呼ばれている。
This slope is called 'Sakura-zaka' because it has long been a famous spot for cherry blossoms.
現場に靴の跡が残っていたことから、犯人は外から侵入したと考えられる。
Given the footprints left at the scene, the culprit is thought to have entered from outside.
