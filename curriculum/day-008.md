# Day 008 · （场所）に ～ がある / いる、い形容词（～い です）

- 阶段：P1｜60 分钟｜常规日
- Can-do：用「（场所）に ～ がある / いる、い形容词（～い です）」造两句自己的话，表达：（某地）有…；…（い形容词谓语）

## 新词 20

- **借りる**（かりる）借（入）；向人借｜韩语参考：꾸다（借） / 얻다（借取，借） / 빌리다（借）<br>
  例：図書館で本を借ります。（在图书馆借书。）
- **教える**（おしえる）教；告诉｜韩语参考：이르다（告诉） / 가르치다（教，教授，传授）<br>
  例：日本語を教えます。（教日语。）
- **帰る**（かえる）回；回家｜韩语参考：돌아오다（回，回来，归来）<br>
  例：家に帰ります。（回家。）
- **休む**（やすむ）休息；请假；睡｜韩语参考：쉬다（休息，歇）<br>
  例：会社を休みます。（向公司请假。）
- **分かる**（わかる）懂；明白｜韩语参考：알다（知道，明白）<br>
  例：日本語が分かります。（懂日语。）
- **高い**（たかい）贵；高｜韩语参考：높다（高） / 크다（大，高，长，壮阔） / 비싸다（贵）<br>
  例：この本は高いです。（这本书贵。）
- **安い**（やすい）便宜｜韩语参考：싸다（便宜，贱） / 헐하다（廉价，贱，便宜）<br>
  例：電車よりバスのほうが安いです。（公交比电车便宜。）
- **大きい**（おおきい）大｜韩语参考：크다（大，高，长，壮阔）<br>
  例：大きい家です。（大房子。）
- **小さい**（ちいさい）小｜韩语参考：작다（小， 矮）<br>
  例：小さい部屋です。（小房间。）
- **新しい**（あたらしい）新｜韩语参考：새롭다（新）<br>
  例：新しいパソコンがほしいです。（想要新电脑。）
- **美味しい**（おいしい）好吃；美味｜韩语参考：맛나다（好吃，可口） / 맛있다（好吃，可口，香） / 맛깔나다（可口，美味）<br>
  例：この料理は美味しいです。（这道菜好吃。）
- **忙しい**（いそがしい）忙｜韩语参考：바쁘다（忙，忙碌，紧张）<br>
  例：今週は忙しいです。（这周很忙。）
- **寒い**（さむい）冷（天气/体感）｜韩语参考：춥다（冷）<br>
  例：今日は昨日ほど寒くないです。（今天没昨天冷。）
- **好き**（すき）喜欢｜韩语参考：좋아하다<br>
  例：魚が好きです。（喜欢鱼。）
- **元気**（げんき）精神；健康；有活力｜韩语参考：건강하다 / 활기차다<br>
  例：彼女は元気です。（她很精神。）
- **静か**（しずか）安静；宁静｜韩语参考：조용하다<br>
  例：この部屋は静かです。（这个房间安静。）
- **便利**（べんり）方便；便利｜韩语参考：편리（便利，方便）<br>
  例：この地図は便利です。（这张地图很方便。）
- **とても**（とても）非常；很｜韩语参考：된통（很，厉害） / 매우（非常，极其，很） / 몹시（十分，非常，太）<br>
  例：この本はとても高いです。（这本书很贵。）
- **少し**（すこし）稍微；一点｜韩语参考：좀（一点点，有一点） / 살짝（稍微） / 슬쩍（稍微）<br>
  例：少し休みます。（稍微休息一下。）
- **いつも**（いつも）总是；平时｜韩语参考：노상（老是，总是） / 매양（回回，总是，老是） / 백날（天天，总是）<br>
  例：いつも電車で行きます。（总是坐电车去。）

## 语法

- **（场所）に ～ がある / いる**：（某地）有…
  接续：場所 + に + 物/人 + が + ある／いる
  朝鲜语：에 ~ 이/가 있다 / 계시다（韩语存在动词不分有无生命，一律있다，敬语用계시다；日语必须分ある/いる。）
- **い形容词（～い です）**：…（い形容词谓语）
  接续：い形容詞 + です
  朝鲜语：형용사 어간 + 다 / -아·어요（韩语形容词作谓语要加终结词尾，敬语靠어요/습니다；日语い形直接加です。）
