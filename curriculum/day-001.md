# Day 001 · 问候与自我介绍｜N は N です、〜か（or）

- 阶段：P0｜60 分钟｜常规日
- Can-do：在「问候与自我介绍」场景里，用 N は N です 说清一件事

## 新词 9

- **私**（わたし）我  
  例：私は学生です。（我是学生。）
- **あなた**（あなた）你；您  
  例：あなたは先生ですか。（您是老师吗？）
- **さん**（さん）…先生／…小姐（敬称）  
  例：田中さんは先生です。（田中是老师。）
- **こんにちは**（こんにちは）你好（白天问候）  
  例：こんにちは、元気ですか。（你好，你好吗？）
- **こんばんは**（こんばんは）晚上好  
  例：こんばんは、お元気ですか。（晚上好，您好吗？）
- **おはようございます**（おはようございます）早上好（敬体）  
  例：おはようございます。（早上好。）
- **ありがとうございます**（ありがとうございます）谢谢（敬体）  
  例：ありがとうございます。（谢谢。）
- **すみません**（すみません）对不起；劳驾／借过  
  例：すみません、駅はどこですか。（劳驾，车站在哪？）
- **一**（いち）一  
  例：りんごを一つください。（请给我一个苹果。）

## 语法

- **N は N です**：…是…
  接续：名詞 + は + 名詞 + です
  朝鲜语：입니다 / 이에요（韩语敬语由终结词尾입니다/이에요承担，日语靠です；名词后还须按有无收音选은/는。）
- **〜か（or）**：…或…
  接续：名词 + か + 名词
  朝鲜语：나/이나（韩语 나/이나 兼表选择和列举，日语 か 表选择、や 表列举，分工更明确。）

## 汉字 4

- **日** 太阳；日子；日本｜音：ニチ、ジツ｜训：ひ、か
- **月** 月亮；月份｜音：ゲツ、ガツ｜训：つき
- **火** 火；星期二｜音：カ｜训：ひ
- **水** 水；星期三｜音：スイ｜训：みず
